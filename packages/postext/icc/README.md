## Provenance

- The colord profiles are those of colord 1.4.8 (`/usr/share/color/icc/colord`),
  generated by `cd-create-profile` from the characterization data in
  colord's `data/profiles/*.iccprofile.xml`, each released under CC0.
- `fogra51.icc` and `fogra52.icc` were built with ArgyllCMS 3.5.0 from Fogra's
  characterization data (`https://www.color.org/chardata/FOGRA51.txt`,
  `FOGRA52.txt`) with the black generation colord uses for its FOGRA profiles:

  ```
  colprof -qm -kp 0.0 0.3 0.94 0.94 0.48 -l300 [-Z m for FOGRA52] FOGRA51
  ```

  They are released under CC0 like the colord set. ECI's own `PSOcoated_v3.icc`
  and `PSOuncoated_v3_FOGRA52.icc` describe the same conditions but may not be
  redistributed; a user who has them (or a profile from their printer) can
  upload it as a custom profile.

The table's metadata lives in `src/color/catalogue.ts`; keep both in sync.
