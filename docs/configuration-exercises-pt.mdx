# Configuração: exercícios


## Estilos de exercício

A propriedade `exerciseStyles` declara os estilos nomeados que um exercício escolhe com `:::exercise{style="…"}`. Um estilo é a forma de uma família de exercícios; as perguntas e as respostas continuam no Markdown (veja [Exercícios](/pt/docs/exercises)). Um estilo, `exercise`, vem por padrão, de modo que o delimitador funciona sem nenhuma configuração; declarar `exerciseStyles` o substitui, e o primeiro estilo declarado é o que vale para um exercício sem `style`. Todos os campos são opcionais, e os padrões seguem a língua do documento onde as escolas fazem diferente: rótulos das alternativas, letras de verdadeiro ou falso, a disposição da conta de dividir, as palavras impressas.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### Número

`number` define o número do exercício. Um número solto sai em negrito, na cor principal, seguido de ponto; um número com forma é um algarismo branco dentro de um círculo, de um quadrado ou de um quadrado arredondado na cor principal, sem nada depois.

A tela pode ter seus próprios ajustes de exercícios: `htmlViewer.overrides` também aceita `exercises` e `exerciseStyles`, mesclados sobre os do livro antes de o visualizador HTML diagramar. Assim, o impresso mantém as soluções no fim do capítulo enquanto a tela as esconde, ou a tela tira as áreas de escrita, que não servem para nada a quem lê.

```ts
const config: PostextConfig = {
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [{ id: 'exercise', area: { kind: 'none' }, blank: { minWidth: { value: 6, unit: 'em' } } }],
    },
  },
};
```

### Avaliação

Por padrão, um exercício é de prática: o leitor verifica quantas vezes quiser, recomeça e olha a resposta. Quatro ajustes o transformam numa prova, para o livro em `exercises.digital` e para um estilo no seu `digital`, que prevalece nos exercícios desse estilo:

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** conta quantas vezes Verificar é apertado numa tentativa. O botão mostra quantas restam (“Verificar (restam 2)”); quando acabam, ele passa a dizer “Sem mais verificações”, as respostas ficam travadas e a nota continua na barra.
- **`reset`** e **`maxResets`**: Recomeçar apaga as respostas e abre uma nova tentativa, com as verificações de volta. `maxResets: 1` permite recomeçar uma vez, duas tentativas no total, e o botão mostra quantas vezes restam; `reset: false` tira o botão.
- **`showSolution`**: `'always'`, sempre; `'afterCheck'`, depois que a tentativa foi verificada; `'noChecksLeft'`, quando as verificações acabaram ou todas as respostas estão certas; `'never'`, nunca. Enquanto as verificações são limitadas, ver a resposta encerra a tentativa.
- **`passingScore`** é a nota com base na qual um pacote SCORM informa aprovado ou reprovado (veja [Pacotes SCORM](/pt/docs/configuration-html-folio-epub#pacotes-scorm-postext-scorm)).

As palavras dos botões seguem o idioma do documento. Com `check: 'instant'` não há botão Verificar, então `maxChecks` não se aplica; os outros ajustes, sim. As verificações e os recomeços usados ficam guardados com as respostas: num LMS, um pacote SCORM os guarda no próprio LMS, então eles valem em qualquer dispositivo; numa página HTML ou num livro EPUB, ficam no navegador do leitor, e quem apaga os dados do navegador começa do zero.
