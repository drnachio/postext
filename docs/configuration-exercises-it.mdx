# Configurazione: esercizi


## Stili degli esercizi

La proprietà `exerciseStyles` dichiara gli stili con nome che un esercizio sceglie con `:::exercise{style="…"}`. Uno stile è la forma di una famiglia di esercizi; domande e risposte restano nel Markdown (vedi [Esercizi](/it/docs/exercises)). Per impostazione predefinita è incluso uno stile, `exercise`, così il blocco funziona senza alcuna configurazione; dichiarare `exerciseStyles` lo sostituisce, e il primo stile dichiarato è quello che prende un esercizio senza `style`. Ogni campo è facoltativo, e i valori predefiniti seguono la lingua del documento dove le scuole hanno usi diversi: lettere delle opzioni, lettere di vero/falso, disposizione della divisione in colonna, parole stampate.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### Numero

`number` imposta il numero dell’esercizio. Un numero semplice è in grassetto, nel colore principale, seguito da un punto; un numero in una forma è una cifra bianca dentro un cerchio, un quadrato o un quadrato arrotondato del colore principale, senza nulla dopo.

Lo schermo può avere impostazioni degli esercizi proprie: `htmlViewer.overrides` accetta anche `exercises` ed `exerciseStyles`, che si sovrappongono a quelli del libro prima che il visualizzatore HTML impagini.
```ts
const config: PostextConfig = {
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [{ id: 'exercise', area: { kind: 'none' }, blank: { minWidth: { value: 6, unit: 'em' } } }],
    },
  },
};
```

### Valutazione

Per impostazione predefinita un esercizio serve per allenarsi: il lettore verifica tutte le volte che vuole, ricomincia e guarda la soluzione. Quattro impostazioni lo trasformano in un test, per il libro in `exercises.digital` e per uno stile nel suo `digital`, che prevale per gli esercizi di quello stile:

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** conta quante volte si preme Verifica in un tentativo. Il pulsante mostra quante verifiche restano («Verifica (ancora 2)»); quando sono finite mostra «Nessuna verifica rimasta», le risposte si bloccano e il punteggio resta sulla barra.
- **`reset`** e **`maxResets`**: Ricomincia cancella le risposte e apre un nuovo tentativo, che ha di nuovo tutte le sue verifiche. `maxResets: 1` permette di ricominciare una volta, quindi due tentativi in tutto, e il pulsante mostra quante volte si può ancora ricominciare; `reset: false` toglie il pulsante.
- **`showSolution`**: `'always'`; `'afterCheck'`, dopo che il tentativo è stato verificato; `'noChecksLeft'`, quando le sue verifiche sono finite o tutte le sue risposte sono risultate giuste; `'never'`. Finché le verifiche sono limitate, mostrare la soluzione chiude il tentativo.
- **`passingScore`** è la soglia rispetto a cui un pacchetto SCORM indica superato o non superato (vedi [Pacchetti SCORM](/it/docs/configuration-html-folio-epub#pacchetti-scorm-postext-scorm)).

Le parole dei pulsanti seguono la lingua del documento. Con `check: 'instant'` non c’è il pulsante Verifica, quindi `maxChecks` non si applica; le altre impostazioni sì. Le verifiche usate e le volte in cui si è ricominciato si conservano con le risposte: in un LMS, un pacchetto SCORM le conserva nell’LMS, quindi valgono su qualsiasi dispositivo; in una pagina HTML o in un libro EPUB restano nel browser del lettore, e chi ne cancella i dati riparte da capo.
