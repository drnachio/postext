# 配置

**Postext的每一项版面决定都由同一个配置对象控制。**

`PostextConfig`控制页面尺寸、分栏方式、正文排印、标题样式、文档语言（`locale`）等。所有属性都是可选的：Postext自带一套合理的默认值，参照的是传统书籍排版。你只需写出想改的部分。

```ts
import { buildDocument } from 'postext';

const document = buildDocument(content, {
  page: { sizePreset: '21x28', dpi: 300 },
  layout: { layoutType: 'double', gutterWidth: { value: 0.5, unit: 'cm' } },
  bodyText: { fontFamily: 'EB Garamond', fontSize: { value: 9, unit: 'pt' } }, // 9 pt覆盖默认的8 pt
  headings: { fontFamily: 'Open Sans' },
});
```

引擎如何处理这份配置，概览见[架构](/zh/docs/architecture)一页。


## 内容一览

这份参考分为二十个页面。下面每一组是一个页面，后面列出它包含的各节。

**[页面与版式](/zh/docs/configuration-page-layout)**

- [页面](/zh/docs/configuration-page-layout#页面)：尺寸、页边距、基线网格、裁切线、[页码编号](/zh/docs/configuration-page-layout#页码编号)、[装订](/zh/docs/configuration-page-layout#装订)。
- [版式](/zh/docs/configuration-page-layout#版式)：栏数、栏间距、栏线、[竖排](/zh/docs/configuration-page-layout#竖排)。

**[页眉与页脚](/zh/docs/configuration-headers-footers)**

- [页眉与页脚](/zh/docs/configuration-headers-footers#页眉与页脚)：每页的文本、线条、方框和图像元素，支持占位符、奇偶页、页面角色和定位。

**[正文](/zh/docs/configuration-text)**

- [正文](/zh/docs/configuration-text#正文)：排印、对齐与断行、[引用块](/zh/docs/configuration-text#引用块)、[诗歌](/zh/docs/configuration-text#诗歌)、[制表位](/zh/docs/configuration-text#制表位)和[首字下沉](/zh/docs/configuration-text#首字下沉)。

**[断词与语言](/zh/docs/configuration-language)**

- [断词](/zh/docs/configuration-language#断词)：断词模式、不断开的词、齐左排的文字。
- [文档语言](/zh/docs/configuration-language#文档语言)：顶层的`locale`，决定断词的后备语言、内置资源类型、表格和拆开的标注框接续处印的文字、写入无障碍PDF的语言标签，以及由它决定的[数字](/zh/docs/configuration-language#文档数字)（`numerals`）和[文本方向](/zh/docs/configuration-language#文本方向)（`direction`）；另见Postext排版所支持的[语言与文字](/zh/docs/configuration-language#语言与文字)。从右到左书籍的说明见[阿拉伯文排版](/zh/docs/arabic-layout)。
- [语言与文字](/zh/docs/configuration-language#语言与文字)：Postext能排的文字体系，以及分别讲解它们的页面。
- [阿拉伯文](/zh/docs/configuration-language#阿拉伯文)：阿拉伯文的字形、kashida、元音符号与数字。

**[标题](/zh/docs/configuration-headings)**

- [标题](/zh/docs/configuration-headings#标题)：共享默认值以及H1–H6各自的覆盖设置。

**[孤行与各栏齐底](/zh/docs/configuration-page-flow)**

- [段首孤行、段末孤行、孤字与不拆分规则](/zh/docs/configuration-page-flow#段首孤行段末孤行孤字与不拆分规则)：`bodyText`中让行与块在换栏时不被拆开的键。
- [各栏齐底](/zh/docs/configuration-page-flow#各栏齐底)：让每一栏底部齐平的各种手段，按编辑处理时的先后顺序排列。

**[列表与数学公式](/zh/docs/configuration-lists-math)**

- [无序列表](/zh/docs/configuration-lists-math#无序列表)与[有序列表](/zh/docs/configuration-lists-math#有序列表)：项目符号、编号、嵌套。
- [数学公式](/zh/docs/configuration-lists-math#数学公式)：LaTeX渲染、缩放、颜色、外边距。

**[注释与引用](/zh/docs/configuration-notes-references)**

- [脚注](/zh/docs/configuration-notes-references#脚注)：`footnotes`，用`[^id]`引用的注放在哪里、怎样编号、是什么样子。
- [行号](/zh/docs/configuration-notes-references#行号)：`lineNumbers`，在诗歌或正文的页边每隔五行印一个行号；哪些行计数，从哪里重新计数，行号放在哪一侧。
- [交叉引用](/zh/docs/configuration-notes-references#交叉引用)：`crossRefs`，`:ref`的编号或页码前后印出的文字，以及它的默认样式。
- [引用](/zh/docs/configuration-notes-references#引用)：`citations`，引用格式，以及引用和参考文献的样子。
- [印刷版中的链接](/zh/docs/configuration-notes-references#印刷版中的链接)：`links`，印刷页面怎样交代链接的网址：不加、括号里的网址，或带网址和二维码的注释。
- [目录](/zh/docs/configuration-notes-references#目录)：`:::toc`排出的内容，包括条目排印、前导符、页码、作者行、篇条目。
- [索引](/zh/docs/configuration-notes-references#索引)：`:::index`排出的内容，包括条目排印、缩进、页码分隔符与页码范围、字母分组、排序语言。

**[东亚排版](/zh/docs/configuration-east-asian)**

- [东亚排版](/zh/docs/configuration-east-asian#东亚排版)：`cjk`，涵盖中文、日文和韩文的地区惯例与断行、两端对齐时行内空白的分配、标点宽度与悬挂、汉字与拉丁字母之间的空白、字符网格、竖排中的直立数字，以及着重号、注音、双行夹注和汉文训读记号。完整指南见[中文排版](/zh/docs/chinese-layout)和[日文排版](/zh/docs/japanese-layout)。

**[资源与表格](/zh/docs/configuration-resources)**

- [资源类型](/zh/docs/configuration-resources#资源类型)：图、表及自定义类型的分类编号。
- [表格样式](/zh/docs/configuration-resources#表格样式)（含[命名表格样式](/zh/docs/configuration-resources#命名表格样式)）与[题注样式](/zh/docs/configuration-resources#题注样式)：表格资源及其题注的排印与装饰。
- [图示样式](/zh/docs/configuration-resources#图示样式)：把嵌入的SVG图示改成单一油墨的颜色，用于专色印刷。
- [乐谱样式](/zh/docs/configuration-resources#乐谱样式)：`scoreStyle` 和 `scoreStyles`，所有乐谱的谱表大小、音乐字体、间距和小节号。
- [视频样式](/zh/docs/configuration-resources#视频样式)：`videoStyle`，印在视频封面上的播放标记和二维码，以及HTML阅读器和EPUB中播放器提供的功能。

**[样式与篇](/zh/docs/configuration-styles)**

- [段落样式](/zh/docs/configuration-styles#段落样式)：供`:::paragraphs`容器使用的命名样式，如参考文献、术语表、注释。
- [行内标签样式](/zh/docs/configuration-styles#行内标签样式)：`chipStyles`，行内`:chip[…]`的命名样式，如词库里的词框、键帽、标签。
- [高亮样式](/zh/docs/configuration-styles#高亮样式)：`markStyles`，行内`:mark[…]`的命名样式，即衬在高亮短语下面、可以跨行的色带。
- [代码清单](/zh/docs/configuration-styles#代码清单)：`codeStyle`，即```` ``` ````清单的字体、框、制表符宽度、过长的行、行号和记号颜色，语法着色及其高亮器接口，以及用代码字体排的行内代码。
- [篇](/zh/docs/configuration-styles#篇)：`:::part`容器生成的篇名页，包括奇偶页、版心、篇名页的设计、正文的字体排印。
- [标题样式](/zh/docs/configuration-styles#标题样式)：供`{style="…"}`标题使用的命名样式，如不编号的章、带独立书眉的前辅文，以及页面几何和配色。

**[标注框](/zh/docs/configuration-callouts)**

- [标注框样式](/zh/docs/configuration-callouts#标注框样式)：供`:::callout`容器使用的带框注释、提示和学习目标。

**[练习设置](/zh/docs/configuration-exercises)**

- [练习样式](/zh/docs/configuration-exercises#练习样式)：`exerciseStyles`，即`:::exercise`块的题号样子、题目要求的字体、选项序号、填空处、书写区、方格、除法竖式和答案颜色。[全书设置](/zh/docs/configuration-exercises#全书设置)：`exercises`，即教师用书、答案印在哪里、打乱顺序的随机种子和屏幕版本。指南见[练习](/zh/docs/exercises)。

**[漫画设置](/zh/docs/configuration-comics)**

- [漫画](/zh/docs/configuration-comics#漫画)：`comics`，包括漫画页的画框和格间距、分格样式、嵌字、对白框样式和角色表。指南见[漫画](/zh/docs/comics)。

**[模板页设置](/zh/docs/configuration-composed-pages)**

- [页面模板](/zh/docs/configuration-composed-pages#页面模板)：`pageTemplates`，包括模板页的框、组和装饰，模板之间的继承，以及奇偶页变体。[标注样式](/zh/docs/configuration-composed-pages#标注样式)：`labelStyles`，即放在图片锚点上的标注的外观。[框的外观](/zh/docs/configuration-composed-pages#框的外观)：`frameLooks`，即模板页的一段内容用`look="…"`采用的有名称的颜色组合。模板可能出现的所有问题见[页面模板警告](/zh/docs/configuration-composed-pages#页面模板警告)。

**[字体、颜色与输出](/zh/docs/configuration-fonts-colors-viewers)**

- [单位与颜色](/zh/docs/configuration-fonts-colors-viewers#单位与颜色) + [调色板](/zh/docs/configuration-fonts-colors-viewers#调色板)：`Dimension`、`ColorValue`、命名颜色。
- [自定义字体](/zh/docs/configuration-fonts-colors-viewers#自定义字体)：在Google Fonts之外声明用户上传的字体族。
- [数字样式](/zh/docs/configuration-fonts-colors-viewers#数字样式)：`figureStyle`按文本样式选用旧式数字、等高数字、等宽数字或比例数字，取自字体的OpenType特性。
- [HTML阅读器](/zh/docs/configuration-fonts-colors-viewers#html阅读器)：HTML后端的目标栏宽与断行。
- [Canvas查看器](/zh/docs/configuration-fonts-colors-viewers#canvas查看器)：`canvasViewer`，沙盒Canvas标签页中并排两页之间、以及上下两排之间的间距。
- [PDF生成（配置）](/zh/docs/configuration-fonts-colors-viewers#pdf生成配置)：PDF后端的书签大纲、无障碍（带标签的）输出、强制色彩空间。
- [印刷输出（配置）](/zh/docs/configuration-fonts-colors-viewers#印刷输出配置)：`print`，包括PDF/X-1a和PDF/X-4、ICC输出特性文件、黑色（只用K的灰色、叠印、复合黑）、以CMYK定义的颜色、印前检查和印刷预览。
- [对比度检查（配置）](/zh/docs/configuration-fonts-colors-viewers#对比度检查配置)：`contrast`，按WCAG AA或AAA检查文字与底色的对比度，既按屏幕计算，也按输出特性文件的纸张计算；还检查细得不宜印刷的反白字。
- [正文检查（配置）](/zh/docs/configuration-fonts-colors-viewers#正文检查配置)：`checks.contentInConfig`，找出设计中直接存放书的正文、而不是占位符的文字，并可为书名和出版社设置允许的短语。
- [书页视图（配置）](/zh/docs/configuration-fonts-colors-viewers#书页视图配置)：3D书本视图的纸种、装订、台面和光照。
- [调试](/zh/docs/configuration-fonts-colors-viewers#调试)：编辑器中的可视化叠加层，以及写作时的警告。

**[以编程方式使用](/zh/docs/configuration-programmatic-usage)**

- [以编程方式使用](/zh/docs/configuration-programmatic-usage#以编程方式使用)：`buildDocument`、它报告的警告、解析器、缓存。
- [在Web Worker中运行排版](/zh/docs/configuration-programmatic-usage#在web-worker中运行排版)：在主线程之外构建，并可取消。

**[PDF文件](/zh/docs/configuration-pdf-output)**

- [生成PDF](/zh/docs/configuration-pdf-output#生成pdf)：`postext-pdf`，字体提供函数、中日韩字体、工作线程和可付印的文件。

**[HTML、3D书本、EPUB与SCORM](/zh/docs/configuration-html-folio-epub)**

- [集成HTML阅读器](/zh/docs/configuration-html-folio-epub#集成html阅读器)与[生成PDF](/zh/docs/configuration-pdf-output#生成pdf)：端到端的完整做法。
- [3D书本（`postext-folio`）](/zh/docs/configuration-html-folio-epub#3d书本postext-folio)：把排好的文档显示成一本摊开在桌上的印刷书，读者可以翻页。
- [EPUB电子书](/zh/docs/configuration-html-folio-epub#epub电子书postext-epub)：由同一份排版生成固定版式和流式版式的EPUB 3文件，并用EPUBCheck检查。
- [SCORM包](/zh/docs/configuration-html-folio-epub#scorm包postext-scorm)：把章和节做成供学习管理系统使用的SCO，其中的练习会报告得分。

**[.postext文件包](/zh/docs/configuration-bundles)**

- [文件包（`.postext`文件）](/zh/docs/configuration-bundles#文件包postext文件)：整本书装在一个文件里，用代码创建、打开和构建`.postext`文件包。
