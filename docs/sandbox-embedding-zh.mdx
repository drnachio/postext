# 沙盒：智能体、嵌入与预设


## 智能体：WebMCP

沙盒通过[WebMCP](https://webmachinelearning.github.io/webmcp/)（`document.modelContext`）把自己的工具交给在浏览器里工作的智能体，助手于是直接操作这本书，而不必在界面上一下一下地点。无需任何设置：只要沙盒在屏幕上，这些工具就已注册；本站其他部分也会在每个页面上注册几个自己的工具（搜索文档和排版食谱、把页面读成Markdown、在沙盒里打开一份食谱、切换语言和主题）。

这些工具是为设计者凭眼睛反复调整的过程设计的：改一点，看看页面，再改。

- **看**——`sandbox_get_state`、`sandbox_render_page`、`sandbox_inspect_pages`、`sandbox_inspect_point`、`sandbox_inspect_comic`、`sandbox_get_warnings`：这本书及其章节和页码范围，以及界面上的情况（选区、提示、等待回答的询问）；任意一页按指定宽度输出的JPEG、PNG或WebP，或裁出一部分细看，需要时带印刷预览；同一页的数据（各个块和行、每栏排了多满、哪些是松散行或以断词结尾）；页面上某一点是什么（对应的源文本行、链接及其去向、表格的单元格）；漫画页的分格和对白框；以及“检查”在任意一章或整本书里发现的问题，不论屏幕上是哪一章、哪个查看器。
- **改**——`sandbox_set_config`、`sandbox_get_config`、`sandbox_find_setting`、`sandbox_rename_design_item`、`sandbox_remove_design_item`、`sandbox_language_defaults`、`sandbox_print_profile`、`sandbox_save_layout_as_template`、`sandbox_edit_text`、`sandbox_write_text`、`sandbox_read_text`、`sandbox_search_text`、`sandbox_replace_text`、`sandbox_select_text`、`sandbox_undo_text`、`sandbox_manage_chapters`、`sandbox_save_resource`、`sandbox_save_font`、`sandbox_edit_comic`、`sandbox_import_word`、`sandbox_apply_word_edits`：按路径修改任何设置（`bodyText.fontSize`、`page.margins.top`、`headings.levels[level=2].fontSize`、`header.elements[id=titleOdd].italic`）；用精确的查找替换修改文字，并可撤销；管理章节、图片、SVG图、视频、带格式的表格、字体，以及漫画的分格和对白框；导入Word文档并映射其样式。每次修改都会回报各项修改前后的值和每一章的页数；修改设置时还会回报引擎最终解析出的值，以及随之改变的其他设置；引擎无法解析的值会被拒绝，什么也不改。在多语言的书里，`scope`指明一项设置是在所有语言的通用设置中读写，还是只在屏幕上的版本中读写。
- **显示**——`sandbox_set_view`、`sandbox_go_to_page`、`sandbox_run_viewer`：查看器标签页、侧栏、单章或整本书、缩放、适应方式和跨页显示、阅读字号、印刷预览、画在页面上的参考线、Folio的放大镜，以及屏幕上显示哪一页（按页码、按一段文字、按锚点或按EPUB目录的条目）；重新生成PDF或EPUB、打印、播放页面上的视频。
- **保存**——`sandbox_list_books`、`sandbox_open_book`、`sandbox_save_book`、`sandbox_import_book`、`sandbox_import_idml`、`sandbox_export`、`sandbox_word_templates`、`sandbox_answer`：列出示例书和你的项目（带封面）；导入`.postext`文件；把InDesign文档（IDML）读成一本新书；把这本书（或一本没有打开的书）导出为PDF、EPUB、HTML、`.postext`、Word、IDML、Markdown，或把设置导出为JSON；管理Word导入用的模板；回答沙盒提出的询问。
- **设计**——`sandbox_list_designs`、`sandbox_save_design`、`sandbox_try_design`、`sandbox_end_design_trial`、`sandbox_apply_design`、`sandbox_import_design`、`sandbox_export_design`、`sandbox_delete_design`：版面设计面板的图库，保存、试用并保留或放弃设计，直接或作为章节样式应用，读写设计文件。

修改书的工具会等排版完成，所以下一张截图拍到的总是新的页面；无论屏幕上是哪个标签页，页面都会为工具单独排版并绘制。无法撤回的操作（删除章节、资源或项目，恢复原版，用Word文档覆盖文字，替换你自己的那份副本）会标为“有后果”，浏览器可以先征得你的同意。和使用界面时一样，一切都留在你的浏览器里：沙盒本身访问不到的东西，工具也访问不到。

WebMCP还是草案：Chrome以源试用（origin trial）的形式提供，也可通过`chrome://flags/#enable-webmcp-testing`开启。在没有WebMCP的浏览器里，同样的工具放在`window.postextWebMcp`上（`listTools()`、`executeTool(name, args)`），供能在页面里运行脚本的智能体使用。嵌入沙盒时，设`webmcp={false}`就不注册这些工具（见[属性](#属性)）。

[WebMCP](/zh/docs/webmcp)页面说明可以让智能体做哪些事，以及每个工具的调用方式，并附有示例。


## 独立使用

沙盒是一个React包`postext-sandbox`，位于postext仓库中，没有发布到npm。同一pnpm工作区中的React应用像网站（`apps/web`）那样依赖它，写作`"postext-sandbox": "workspace:*"`；它的对等依赖是React和React DOM（18或更高版本）以及`postext`：

```bash
pnpm add postext-sandbox@workspace:* postext@workspace:*
```

```tsx
import { PostextSandbox } from 'postext-sandbox';

function App() {
  return (
    <PostextSandbox
      initialMarkdown="# Hello World"
      initialConfig={{ layout: { layoutType: 'double' } }}
      onMarkdownChange={(md) => console.log(md)}
      onConfigChange={(cfg) => console.log(cfg)}
    />
  );
}
```

### CSS要求

这个包使用Tailwind CSS工具类，这些类引用CSS自定义属性。宿主应用必须提供以下变量：

- `--background`、`--foreground`——基础颜色
- `--surface`——浮起表面的颜色；`--surface-2`——鼠标悬停的行和高亮选项的颜色（缺省时回退到`--background`）
- `--slate`——弱化文字的颜色
- `--rule`——边框/分隔线颜色；`--rule-strong`——悬停控件上更醒目的线（缺省时回退到`--slate`）
- `--brand`——强调色：当前面板的标记、焦点环、开关和选中的选项
- `--brand-hover`——悬停时的强调色
- `--brand-soft`——选中选项背后半透明的强调色填充（缺省时回退到`--surface`）
- `--brand-contrast`——开关打开时的滑块（缺省时回退到`--background`）
- `--destructive`——破坏性操作和错误的颜色
- `--accent-blue`——链接/强调颜色
- `--font-sans`——界面字体
- `--font-mono`——等宽字体（用于代码编辑器）
- `--font-display`、`--brand-blue`、`--brand-gilt`——活动栏中默认标志的字体和颜色，可选（缺省时回退到Georgia、`#2b4acb`和`#d8a21a`）

网站在深色主题中把`--brand`设为金色，在浅色主题中设为蓝色。早期版本读取`--gilt`和`--gilt-hover`；沙盒已不再使用它们。

弹出层、菜单和工具提示通过portal渲染在`document.body`下，所以要在`:root`（或`body`）上定义这些变量，而不只是在包裹沙盒的元素上。宿主的Tailwind构建必须扫描这个包的源代码（在Tailwind 4中为`@source "…/postext-sandbox/src/**/*.tsx"`），才能生成它用到的工具类。


## 预设文件包格式

附录。预设来源是一个通过HTTP提供的目录，根目录下有`index.json`，列出各个预设目录；每个预设目录包含`preset.json`清单，以及清单引用的Markdown、资源和字体文件。仓库中`scripts/presets/`下的工具生成的文件包正是这种结构；从沙盒导出的`.postext`文件，就是把这样一个目录打成的zip压缩包（不含`index.json`）。

```
<presets-root>/
  index.json
  <preset-dir>/
    preset.json
    chapters/              每章一个.md，按顺序排列（版本1清单则只指定一个文档）
    resources/             图：.svg / .png / .jpg / .jpeg / .webp / .gif（+ 可选的.pdf印刷母版）
    fonts/                 .otf / .ttf / .woff2，每个文件一个字体样式
```

### `index.json`

```jsonc
{
  "version": 1,
  "presets": [
    {
      "id": "acme-journal",          // 稳定的id，[a-z0-9-]
      "dir": "acme-journal",         // 相对于index.json的目录名
      "name": "Acme Journal",
      "description": "Two-column journal article",   // 可选
      "locale": "en",                 // 可选
      "default": true,                // 可选，最多一个
      "locales": ["en", "es"],        // 可选：文件包包含的所有语言
      "openLocale": "en",             // 可选：未指定语言时打开所用的语言
      "thumbnail": "thumbnail.jpg",   // 可选：选择器中显示的预览图
      "license": "CC BY 4.0",         // 可选：显示为标签
      "credits": "Text and images: ESO",  // 可选：描述下方的一行
      "tags": ["magazine", "two-column"], // 可选
      "binding": "left"               // 可选：网站书架绘制书脊的那一边（右侧装订的书用"right"）
    }
  ]
}
```

### `preset.json`

```jsonc
{
  "version": 2,
  "id": "acme-journal",
  "name": "Acme Journal",
  "description": "Two-column journal article",       // 可选
  "locale": "en",                                     // 可选
  "default": true,                                    // 可选
  "configVersion": 22,                                // 可选：`config`所遵循的配置规则版本
  // 与索引条目相同的可选展示字段：
  // "locales", "openLocale", "thumbnail", "license", "credits", "tags"

  // 书的各章，按顺序排列；也可以每种语言一个列表
  "chapters": [
    { "title": "Introduction", "file": "chapters/01-introduction.md" },
    { "title": "Methods", "file": "chapters/02-methods.md" }
  ],
  // "chapters": { "en": [ … ], "es": [ … ] },
  // 版本1清单改用单个文档，仍然可以接受：
  // "version": 1, "markdown": "article.md"  （或语言→文件的映射）

  // 可选的PostextConfig JSON（页面、页边距、分栏、字体排印……）。
  // 不要在这里放customFonts：字体来自下面的`fonts`数组。
  "config": { },

  "resources": [
    {
      "id": "fig-1-1",                 // 在Markdown中引用（:ref）
      "typeId": "figure",              // 资源类型id（figure、table……）
      "kind": "svg",                   // "svg" | "bitmap" | "table"
      "file": "resources/fig-1-1.svg", // 仅svg/bitmap，相对于preset.json
      "width": 240.5,                  // 可选，pt（svg）/ px（bitmap）
      "resolution": 300,               // 可选，仅bitmap：自然印刷尺寸下的ppi
      "pdfFile": "resources/fig-1-1.pdf", // 可选，仅svg：矢量印刷母版（见说明）
      "height": 180,                   // 可选
      "caption": "Caption text",
      "altText": "Accessible description",            // 可选
      "safeArea": { "x": 0.18, "y": 0.25, "width": 0.5, "height": 0.6 }, // 可选，仅svg/bitmap：始终显示的部分，以图片的比例表示
      "placement": { "position": "top", "span": "column" },  // 可选
      "note": "Source: ...",                          // 可选
      "table": { "model": { "rows": [[{ "content": "A", "isHeader": true }]], "headerRowCount": 1 } }
                                                      // 仅用于kind "table"
    }
  ],

  "fonts": [
    {
      "name": "Some Family",           // 配置中使用的字体族名
      "fallback": "Source Serif 4",    // 可选：宽度相近的开放字体，用于文件包没有带上的字形
      "variants": [
        { "weight": 400, "style": "normal", "file": "fonts/SomeFamily-Regular.otf" },
        { "weight": 400, "style": "italic", "file": "fonts/SomeFamily-Italic.otf" },
        { "weight": 700, "style": "normal", "file": "fonts/SomeFamily-Bold.otf" }
      ]
    }
  ]
}
```

说明：

- `preset.json`中的`id`必须与`index.json`条目一致；预设加载后，清单中的`description`、`locale`和`default`会覆盖索引中的值，展示字段`locales`、`openLocale`、`license`、`credits`和`tags`也是如此。`openLocale`是`locales`中的一项，指链接或点击没有指定语言时书打开所用的语言（首页的书架也链接到它）：原作的语言与读者的语言不同时，就要设置它。《紅樓夢》示例设为`zh-Hant`，这样讲英语的读者不会一律打开它的英译本。不设置时由界面语言决定。选择器把`locales`（或`locale`）中的每种语言和许可证显示为标签，把出处信息显示在描述下方，并用`thumbnail`（相对于预设目录的一张小页面图）代替该行的勾选标记列；从预设复制出的书（**建立我的副本**）把它保留为封面。`apps/web/public/presets/`下的公开示例预设用到了所有字段，并附有一个`CREDITS.md`，写明每段文字和每张图片的许可证和来源。
- `configVersion`（可选）指明`config`和`localized`中各配置所遵循的配置规则。所有写出清单的程序都把它设为引擎的`CONFIG_VERSION`，当前版本为21。没有它的清单是postext 1.4或更早版本写出的，其标题分页、公式字号、行内图周围的间距（正文中和框中）、标题标记、首字下沉、冒号行下方空间、框断开、破折号和复合词连字符处的断行、齐左排的文字、标题下拆分以及段落容器下方的间距，都按1.4的排法读取（见[持久化](/zh/docs/sandbox-books-saving#持久化)下的*postext 1.4及更早版本保存的标题分页*、*postext 1.5之前保存的公式字号*、*postext 1.5之前保存的行内图*、*postext 1.5之前保存的框内行内图*、*postext 1.5之前保存的标题标记和首字下沉*、*postext 1.5之前保存的冒号后列表*、*postext 1.5之前保存的框断开*、*postext 1.5之前保存的破折号和不齐行文字*、*postext 1.5之前保存的复合词*、*postext 1.5之前保存的标题下拆分*和*postext 1.5之前保存的段落容器*）；标记为3到7的清单（1.5的预发布版）只固定其后各版规则带来的变化：为3时，固定公式字号、行内间距、规则6的五项、规则7的两项和规则8的三项；为4时，固定行内间距以及规则6、7、8的各项；为5时，固定规则6、7、8的各项；为6时，固定规则7和8的各项；为7时，只固定规则8的各项。标记为8到20的清单由postext 1.5至1.57写出，会得到其标记之后各版规则的固定措施，列在[postext 1.4及更早版本写出的文件包](/zh/docs/configuration-bundles#postext-14及更早版本写出的文件包)中；标记为20或更低的清单逐键读取每个`localized`配置，其顶层键整体替换共用的同名键。手写清单并按现行规则排版时，把它设为21。
- `view`（可选）说明沙盒如何打开文件包：`{ "canvasScope": "book" }`在Canvas上排出整本书（见[书与章](/zh/docs/sandbox-books-saving#书与章)）；省略时，Canvas一次显示一章。导出的书如果设置了它，会一并带上。超过200章的书无论文件包怎么要求，都一次打开一章。
- `start`（可选）说明文件包只含一本更长的书的一部分时，这本书从哪里开始：`{ "pageIndexOffset": 57, "pageNumbering": { "startAt": 58 }, "headings": { "h1": 3 } }`让它从第58页（偶数页）、第4章开始。它就是第一章的`continuation`（`buildDocument`）；沙盒从这里开始排整本书，把书存为项目时随书保存，导出时再写回去。没有面板可以编辑它。`localized`的条目可以为自己的版本带一个`start`。
- `localized`（可选）存放双语文件包的各语言覆盖项：`{ "es": { "config": { … }, "resources": [ { "id": "fig-1", "caption": "…", "note": "…", "altText": "…" } ] } }`。沙盒按哪种语言选取章，就应用哪种语言的覆盖项：它们叠加在共用的`config`之上（该语言设置得不同的字段，在`configVersion` 21下逐字段合并，见[通用设置与各语言覆盖](/zh/docs/configuration-bundles#通用设置与各语言覆盖)），也叠加在共用的`resources`之上（题注、附注、替代文字和表格单元格按id合并）；没有条目的语言沿用共用的文字。条目还可以带自己的`view`，在该版本中覆盖共用的`view`：《紅樓夢》的各个中文版本以整本书打开，而Joly的英译本整本绘制要慢得多，所以一次打开一章（`"en": { "view": { "canvasScope": "chapter" } }`）。
- `chapters`（版本2）是按书中顺序排列的`{ title, file }`列表，或语言→列表的映射；`markdown`（版本1）是一个文件名或语言→文件的映射。两种情况下，沙盒都选取与所请求语言匹配的条目（先是完全相同的标签，不区分大小写；然后是相同语言和相同文字，所以`zh-TW`先读`zh-Hant`再读`zh-Hans`；然后是相同语言的另一种文字，所以`zh-TW`读者打开以不带地区的`zh`为键的文件包时会得到中文；然后是预设自身的`locale`，最后是第一个条目），并且只读取该语言的章文件。章的`title`为空时，取自文件中的第一个一级标题。沙盒总是写出版本2。
- 对于`svg`和`bitmap`资源，`width`/`height`是可选的：缺少时，加载时从文件中读取。位图还可以带`resolution`（自然印刷尺寸下的ppi）和`fileResolution`（文件标明的分辨率，配置设了`layout.bitmapResolution: 'file'`时在加载时读取）。
- `pdfFile`（仅限svg资源）指向一个单页PDF，其中以矢量形式包含同一幅图，通常是SVG所源自的Illustrator原稿或PDF导出文件。PDF导出时原样嵌入这一页（字体、渐变和色彩空间都完整保留），而不用SVG；Canvas和HTML预览仍使用SVG。在单色模式下它会被忽略，因为该模式的重新着色只处理SVG标记；文件缺失时只会丢掉母版，不会丢掉图。在资源详情中编辑SVG源代码会解除母版（母版是为原来的源代码制作的），从此PDF导出跟随编辑后的SVG；恢复原版（书库面板中的**恢复原版…**）即可找回母版。没有母版的SVG，如果不超出PDF后端支持的子集（基本形状、路径、编组、`use`、裁剪路径、纯色填充和描边、不透明度，以及用文档能加载的字体排出的`text`/`tspan`文字，先找自定义字体，再找Google托管的字体族），就作为矢量路径输出，否则以600 dpi栅格化。
- SVG中的`text`在各处都用书的字体渲染：预览和EPUB在显示SVG之前，把其文字指定的字体嵌入SVG（`<img>`看不到页面的字体），自定义字体族按上传的文件嵌入，Google字体族则嵌入包含所需字符的Fontsource文件；PDF导出把这些文字排成真正可选中的文本，使用同样的嵌入字体。在`font-family`中写的字体族名要与“字体”面板中显示的名称完全一致。不想嵌入字体的资源，可以在清单条目中写`"inlineFonts": false`（`svg.inlineFonts`）。
- SVG源代码编辑器只允许在文本节点（着色显示）内输入，以免意外破坏图；编辑器标题栏中的锁按钮会打开全部源代码（坐标、颜色、结构），再次锁定时会重新扫描文本节点。
- `table.model`是Postext的`TableModel`：`rows`是按行排列的单元格数组（`content`，可选的`colSpan`、`rowSpan`、`isHeader`、`align`、`verticalAlign`），`headerRowCount`是开头的表头行数，`columnWidths`是可选的相对列宽数组。`table.styleId`可以指定配置的`tableStyles`之一。
- 字体文件存入IndexedDB，所用的id由预设id和文件路径生成；应用预设时，其字体族会追加到`config.customFonts`中；`index.json`缺失或格式错误时，不会产生预设，但也不报错。
- 文件包不能外传的字体族，用`"redistributable": false`和空的`variants`列出；再加上`"fallback"`，写一个宽度相近的开放字体族的名称，沙盒、命令行和引擎的宿主就用它来排这个家族的字形（自postext 1.42起）。没有它，书会退到默认字体，断行位置也随之改变。
- `<preset-dir>/fingerprint.json`是可选的，在开发路由上是**虚拟的**：不存在这个文件时，`GET`会返回`{ "fingerprint": "<sha1 hex>", "files": <n> }`，它根据目录的文件元数据计算（深度不超过四层的每个文件的相对路径、修改时间和大小，跳过点文件和`node_modules`），从不读取文件内容，并带有`Cache-Control: no-store`。沙盒轮询它以跟踪文件包的修改（见[书库面板](/zh/docs/sandbox#书库面板)）。静态主机可以提供结构相同的真实`fingerprint.json`，也可以不提供，这时它的预设不会被跟踪。
