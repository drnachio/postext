# أغلفة الطباعة

**نسخ الكتاب المطبوعة في إعداداته `production`، وتصميم الغلاف هو الإعداد `cover`، ونصه مستند Markdown من مستندات الكتاب.**

صفحات الكتاب شيء، والفرخ الذي يلفّها شيء آخر. ففرخ الغلاف أعرض من صفحتين: يحمل الغلاف الخلفي والكعب والغلاف الأمامي جنبًا إلى جنب، وأحيانًا أجنحة، ويتغيّر مع كل طبعة جديدة يتغيّر فيها عدد الصفحات أو الورق. يبنيه Postext من ثلاثة أجزاء من الكتاب:

- **الإنتاج**: النسخ التي يُطبع بها الكتاب (غلاف ورقي، غلاف مقوّى)، ولكل منها تجليدها وردمكها وكعبها. وهو من الكتاب لا من تصميمه، ولا يقرؤه شيء في إخراج الصفحات.
- **تصميم الغلاف**: الخلفيات والصور والمربّعات والشعارات ومربّعات النص والتشطيبات، موضوعة على لوحات الفرخ. وهو جزء من التصميم، تشترك فيه نسخ الكتاب كلها وكتب السلسلة الواحدة.
- **نص الغلاف**: مستند Markdown فيه كتلة لكل لوحة. والغلاف الأمامي والكعب اللذان يتركهما فارغين يأخذان العنوان والعنوان الفرعي والمؤلف من البيانات الوصفية للكتاب في كل بناء، فيصل العنوان المصحَّح إلى الغلاف دون نسخه.

ومن هذه الثلاثة يُخرج المحرّك نفسه الذي يُخرج الصفحات الغلافَ، ويذهب ملف PDF إلى المطبعة بهامش النزف للفرخ وعلامات الطيّ.

## نسخ الكتاب

النسخة هي الكتاب كما يصنعه تجليد واحد. فالرواية التي تصدر بغلاف ورقي وبغلاف مقوّى لها نسختان على الصفحات نفسها: لكل منهما تجليدها وردمكها وفرخ غلافها.

```ts
import type { PostextConfig } from 'postext';

const config: PostextConfig = {
  page: { width: { value: 150, unit: 'mm' }, height: { value: 230, unit: 'mm' } },
  folio: { paper: { type: 'uncoated', grammage: 90, bulk: 1.3 } },
  production: {
    versions: [
      { id: 'paperback', name: 'غلاف ورقي', binding: 'perfect', isbn: '978-84-0000-000-4', flaps: true },
      {
        id: 'hardcover', name: 'غلاف مقوّى', binding: 'case-flat', isbn: '978-84-0000-001-1',
        flaps: true, // في الغلاف المقوّى: غلاف واقٍ
        caseMaterial: 'cloth',
        spineText: { direction: 'topToBottom' },
      },
    ],
  },
};
```

تسمّي كل نسخة تجليدها بمعرّف ملف تعريف، أو تحمل ملف التعريف نفسه. والحقول:

- `id` و`name`: ما تُختار به النسخة (`--print-version` في سطر الأوامر) وما تُعرض به.
- `binding`: ملف تعريف تجليد (انظر أدناه).
- `isbn`: ردمك هذه النسخة (ISBN)، بعشرة أرقام أو بثلاثة عشر، بالشرطات أو بدونها. ولكل تجليد من تجليدات الكتاب ردمكه. والردمك الصالح يُطبع رمزًا شريطيًا على ظهر الفرخ الخارجي: على الغلاف الواقي للغلاف المقوّى الذي يلبسه، وإلا فعلى الكسوة أو على الغلاف اللين.
- `isbnAddOn`: خمسة أرقام تُطبع بعد الرمز الشريطي. وفي إسبانيا لا يحمل سعرًا: لا تسمح به وكالة الردمك إلا إذا بدأ بالرقم 9، لاستعمال الناشر نفسه (`90000` تعني بلا سعر).
- `workIsbn`: ردمك العمل كاملًا، لمجلد من سلسلة أو من عمل في عدة مجلدات. يحمل الرمز الشريطي `isbn` المجلد، ويُطبع هذا نصًّا بجانبه. فإن غاب طُبع هناك `isbn` السلسلة.
- `flaps`: في الغلاف اللين أجنحة، وفي الغلاف المقوّى غلاف واقٍ.
- `caseMaterial`: في الغلاف المقوّى، `printed` (الغلاف مطبوع ومغلّف بطبقة لامعة فوق الكرتون، وهو الافتراضي) أو `cloth` (قماش مختوم، يكون عادة تحت غلاف واقٍ).
- `overrides`: مقاسات بالمليمتر تضعها هذه النسخة لنفسها فوق مقاسات ملف تعريفها، حين تطلب المطبعة مجرى مفصل مختلفًا لهذا الكتاب وحده.
- `spineOverride`: عرض الكعب بالمليمتر كما تعطيه المطبعة، بدل المحسوب.
- `spineText`: كيف يُكتب على الكعب: `direction` صاعدًا (`bottomToTop`، المعتاد في إسبانيا والافتراضي) أو نازلًا (`topToBottom`، كما يفضّل معيار ISO 6357)، و`minSpine`، أرقّ كعب يحمل نصًّا (6 مم افتراضيًا).

ويسمّي `production.collection` السلسلة أو العمل متعدد المجلدات الذي ينتمي إليه الكتاب:

```ts
production: {
  collection: {
    name: 'مكتبة البحر',
    isbn: '978-84-0000-010-3',
    catalogue: [
      { id: 'reefs', title: 'الشعاب', resource: 'cover-reefs' },
      { id: 'tides', title: 'المدّ والجزر', resource: 'cover-tides' },
      { id: 'abyss', title: 'الأعماق', resource: 'cover-abyss' },
    ],
    volume: 'tides',
  },
},
```

- `name`: اسم السلسلة.
- `isbn`: ردمك العمل كاملًا، يُطبع نصًّا بجانب الرمز الشريطي لكل نسخة لا تسمّي `workIsbn` خاصًّا بها.
- `catalogue`: عناوين السلسلة بترتيبها، لكل منها `id` و`title` و`resource` اختياري لصورة (غلافه الأمامي في الغالب). يُنضِّدها `::catalogue` في نص الغلاف أسطرًا، وعنصر `catalogue` في التصميم صورًا، على أوراق البطانة أو الغلاف الخلفي.
- `volume`: `id` المدخل الذي هو هذا الكتاب في الفهرس، ويُميَّز حيثما نُضِّد الفهرس. وتذكر فحوص الإعدادات أي `volume` لا يسمّي مدخلًا من الفهرس.

مقاسات هذه الملفات مأخوذة من المواصفات التي تنشرها المطابع ودور التجليد؛ وحيث تختلف، تُؤخذ القيمة التي يعطيها أكثرها. وهي نقطة بداية. أما مقاسات مطبعتك فتوضع في ملف تعريف من ملفات الكتاب، في `production.bindings`، وهو ينتقل مع الكتاب، فتجده الحزمة إذا فُتحت في مكان آخر:

```ts
production: {
  bindings: [{
    id: 'my-printer-perfect',
    name: 'تجليد حراري، مطبعتي',
    printer: 'مطابع المثال',
    style: 'perfect',
    signature: 32,
    measures: { bleed: 5, hingeScore: 7, flapWidth: { ratio: 0.6, of: 'width', min: 70, max: 110 } },
    accepts: { trim: { max: { width: 240, height: 320 } }, spine: { min: 4, max: 45 } },
  }],
  versions: [{ id: 'paperback', name: 'غلاف ورقي', binding: 'my-printer-perfect' }],
},
```

- `style`: ‏`perfect` أو `sewnSoftcover` أو `caseFlat` أو `caseRound`.
- `signature`: عدد صفحات الملزمة. يُقرَّب عدد الصفحات صعودًا إلى عدد صحيح من الملازم لحساب الكعب، ويذكر الفحص عدد الصفحات البيضاء التي يضيفها ذلك.
- `measures`: ما يُترك منها يأخذ القيم الافتراضية للنوع.
- `accepts`: أصغر مقاس قطع وأكبره (`trim.min` و`trim.max`، ولكل منهما `width` و`height` بالمليمتر)، وأرقّ كعب وأعرضه (`spine.min` و`spine.max`) مما تستطيع المطبعة تجليده. والكتاب الخارج عنها يأخذ تنبيهًا في الفحوص بدل غلاف لا يمكن لأحد تجليده.

كل مقاس بالمليمتر، ويُكتب بإحدى ثلاث طرق ليخدم ملف تعريف واحد كل المقاسات:

- **رقم**: القيمة نفسها لأي مقاس (3 مم ثابتة).
- **درجات**: قائمة من `{ upTo: { width, height }, mm }`، تُستعمل أول درجة يدخل المقاس في `upTo` الخاص بها، والأخيرة، بلا `upTo`، لكل ما هو أكبر. والمطبعة التي تزيد سماكة الكرتون في الكتب الكبيرة تكتبها هكذا.
- **نسبة من المقاس**: `{ ratio, of, min, max }`، نسبة من `width` المقاس (الافتراضي) أو من `height`، محصورة بين `min` و`max`. والأجنحة تُكتب هكذا عادة.

### الورق والكعب

الكعب هو سماكة الصفحات مضافًا إليها سماح التجليد. وسماكة الورقة (صفحتين) هي وزن ورقها بالغرام مضروبًا في معامل انتفاخه، بالميكرومتر: ورق 90 غ/م² بمعامل 1.3 يعطي ورقة سماكتها 0.117 مم. والصفحات هي صفحات الكتاب كما أُخرجت، مقرَّبة صعودًا إلى عدد صحيح من الملازم. وتُحسب كل صفحة على ورقها: ورق الكتاب هو `folio.paper`، وسلسلة الصفحات المطبوعة على ورق آخر (كتلة `:::paper`، أو قسم من اللوحات على ورق مصقول) تُحسب بورقها، بالقاعدة نفسها التي يعرض بها [Folio](/ar/docs/configuration-html-folio-epub) الكتاب.

فالكعب يتبع الكتاب. حين يضيف تعديلٌ ملزمة، يزداد عرض الكعب، ويتسع الفرخ، ويتحرك كل عنصر موضوع على الغلاف الأمامي أو الخلفي مع لوحته. وحين تقيس المطبعة نموذجًا تجريبيًا وتعطي رقمًا، يضبطه `spineOverride`، ويذكر الفحص الرقمين كليهما. والكعب الأرقّ من `spineText.minSpine` لا يحمل نصًّا.

ويمكن أيضًا حفظ ورق من أوراق الكتاب ملفَّ تعريف، في `production.papers`: الورق الذي يعرفه Folio (`type` و`grammage` و`bulk` وتشطيبه ودرجة لونه) مع `id` و`name` و`supplier` (المورّد) و`commercialName` (الاسم التجاري).

### الملفات من كتاب إلى آخر

تنتقل ملفات تعريف التجليد والورق بين الكتب، وبين الأشخاص، في ملف `.postext-production.json`. يكتب `exportProductionProfiles(papers, bindings)` واحدًا، ويقرؤه `importProductionProfiles(data)` مع مشكلات المدخلات التي أغفلها. وفي لوحة الغلاف في Sandbox زرّان لهما.

للنسخة ذات الغلاف اللين فرخ واحد هو غلافها. وللغلاف المقوّى كسوته، وغلاف واقٍ إذا كان `flaps` مفعّلًا، وورقة بطانة أمامية وأخرى خلفية. والكتاب المنضَّد من اليمين إلى اليسار (وكل كتاب يُجلَّد من اليمين: كتاب صيني أو ياباني عمودي، أو ما فيه `page.binding: 'right'`) يُعكس فرخه: اللوحة الأمامية على اليسار والخلفية على اليمين. وفي الكتاب العمودي تُنضَّد نصوص المناطق في أسطر عمودية، ويجري نص الكعب على طوله دون تدوير، فلا يُعمل بـ`spineText.direction`.

في كل منطقة مساحة آمنة، تبعد `safeMargin` عن كل طيّة وحدّ قطع، وللكعب هامشه الأضيق عبره. ويرسم Sandbox الطيّات والتحزيزات والمساحات الآمنة فوق الفرخ؛ ويرسم ملف PDF علامات الطيّ في الحاشية خارج هامش النزف.

## تصميم الغلاف

الإعداد `cover` هو تصميم الغلاف. وهو، كبقية التصميم، لا يقول ما يُكتب على الغلاف، بل كيف يبدو فقط، ولا يغيّر إخراج الصفحات:

```ts
cover: {
  background: { hex: '#1f3f99', model: 'hex' },
  image: { resourceId: 'cover-art', area: 'front', focus: { x: 0.5, y: 0.35 } },
  zones: { spine: { hex: '#14295f', model: 'hex' } },
  verticalAlign: { front: 'bottom', back: 'middle' },
  barcodeMagnification: 0.9,
  mirrorMargin: 5,
},
```

- `background`: خلفية الفرخ كله.
- `image`: مورد من موارد الكتاب، صورة نقطية أو SVG، يملأ الفرخ كله (`area: 'sheet'`، الافتراضي) أو الغلاف الأمامي وحده (`'front'`)، مقصوصًا ليغطيه حول `focus` (بكسور من الصورة).
- `zones`: خلفية لكل منطقة، فوق خلفية الفرخ وصورته.
- `verticalAlign`: موضع نص كل منطقة فيها: `top` (الافتراضي) أو `middle` أو `bottom`. ونص الكعب يتوسّطه عرضًا دائمًا.
- `barcodeMagnification`: حجم الرمز الشريطي بالنسبة إلى الحجم الاسمي، من 0.8 إلى 2 (الافتراضي 1). وما دون 0.8 يُضبط على 0.8 ويذكر الفحص ذلك.
- `mirrorMargin`: النزف المعكوس (أدناه).

### العناصر والمؤثرات والشعارات

فوق الخلفيات يضع التصميم ثلاث قوائم من العناصر، تُرسم كل منها من الخلف إلى الأمام: `elements` تحت النص، و`effects` فوقه، و`logos` فوق كل شيء. والعنصر صورة (`kind: 'image'` مع `resourceId`)، أو مربّع لون (`'box'`)، أو شكل ملوّن (`'shape'`)، أو فهرس السلسلة (`'catalogue'`، انظر أدناه)، وله `id` من حروف وأرقام و`-` و`_`.

يوضع العنصر بحسب المنطقة التي يقف فيها، فيتحرك معها حين يزداد عرض الكعب أو يتغيّر التجليد:

```ts
elements: [
  { id: 'band', kind: 'box', zone: 'back', x: -3, y: 180, width: 0, height: 24,
    to: { zone: 'front', x: 153 }, color: { hex: '#d8a21b', model: 'hex' } },
  { id: 'seal', kind: 'shape', zone: 'front', x: 100, y: 20, width: 30, height: 30,
    basis: { width: 150, height: 230 }, color: { hex: '#ffffff', model: 'hex' }, opacity: 0.8,
    path: [{ closed: true, nodes: [{ x: 0.5, y: 0 }, { x: 1, y: 1 }, { x: 0, y: 1 }] }] },
],
logos: [{ id: 'publisher', kind: 'image', zone: 'spine', x: 1, y: 205, width: 8, height: 12,
  resourceId: 'logo', clearance: 2 }],
```

- `zone` و`x` و`y` و`width` و`height`: مربّعه، بالمليمتر من الزاوية العليا اليسرى للمنطقة. ويجوز أن يخرج عن المنطقة إلى ما يليها أو إلى هامش النزف.
- `basis`: حجم منطقته حين وُضع. فإذا صار حجم المنطقة الآن غيره، لأن مقاس الكتاب تغيّر أو زاد عرض الكعب، تحجّم العنصر معها: المربّع والشكل على كل محور، والصورة بالتساوي حول مركزها مع حفظ نِسبها. ومن دونه يبقى العنصر كما وُضع.
- `to`: مربّع أو شكل يمتد عبر عدة مناطق، كشريط من الغلاف الخلفي إلى الأمامي: حافته اليمنى، بالمليمتر من يسار المنطقة التي ينتهي فيها (`to.zone` و`to.x`)، وعرض تلك المنطقة حين وُضع (`to.basis`). وعندئذ تتبع كل حافة منطقتها.
- `color` و`opacity`: لون المربّع أو الشكل، وعتامة أي عنصر (من 0 إلى 1). وتحتفظ الصورة بشفافيتها.
- `fit`: كيف تملأ الصورة مربّعها: كاملة داخله (`contain`، الافتراضي) أو مغطّية إياه مع القص (`cover`).
- `path`: شكل مرسوم بعُقد، بكسور من مربّعه (0، 0 زاويته العليا اليسرى؛ و1، 1 زاويته السفلى اليمنى)، فيتمدد الشكل مع المربّع. لكل جزء `nodes` خاصة به، وهو `closed` أو مفتوح؛ وللعقدة `x` و`y`، ومقبضا المنحنى الداخل إليها (`in`) والخارج منها (`out`).
- `outline`: مضلّعات مغلقة بكسور من المربّع، مستشفّة من صورة، لغشاء أو تشطيب على شكلها.
- `clip`: صورة مقصوصة على محيط، فلا تظهر الصورة إلا داخل شكل رسمها.
- `bleed`: بعد هامش التصميم في النزف المعكوس، `mirror` (الافتراضي) يعكس العنصر مع الخلفية؛ و`own` يرسمه كما هو فوق الطيّة.
- `clearance` (للشعارات): المساحة الخالية بالمليمتر حول الشعار التي لا ينبغي أن يدخلها شيء آخر.

ويستطيع المربّع أو الشكل أن يحمل أيضًا مؤثرات لا يرسمها نمط إطار في الصفحة: `radius` لزوايا مستديرة بالمليمتر، و`stroke` لحدّ (`color`، و`width` بالمليمتر)، و`gradient` من لونه إلى `to` بزاوية `angle` درجة (0: من اليسار إلى اليمين؛ 90: من الأعلى إلى الأسفل)، و`shadow` (`color` و`opacity`، ومدى سقوطه `x` و`y` بالمليمتر، ونعومته `blur`). والتدرّج أو الظل يجعل العنصر صورة مستقلة، تُرسم بدقة ملف PDF.

ويصفّ عنصر `catalogue` صور عناوين السلسلة في شبكة داخل مربّعه، فتظهر السلسلة على ورقة بطانة دون وضع كل غلاف باليد:

```ts
elements: [
  { id: 'series', kind: 'catalogue', zone: 'flyleaf', x: 15, y: 40, width: 120, height: 150,
    columns: 3, gap: 4, stroke: { color: { hex: '#d8a21b', model: 'hex' }, width: 0.8 } },
],
```

- `columns`: عدد الصور في كل صف (افتراضيًا كل العناوين في صف واحد).
- `gap`: المسافة بين الصور بالمليمتر (3 افتراضيًا).
- `first` و`last`: أول عنوان يُعرض وآخره، بموضعهما في الفهرس عدًّا من 1، لتقسيم فهرس طويل بين صفحتين (افتراضيًا كلها).
- `fit`: تغطي كل صورة خليتها مقصوصة (`cover`، وهو الافتراضي هنا)، أو تقع فيها كاملة (`contain`).
- `stroke` و`radius`: الحدّ الذي يحيط بعنوان الكتاب نفسه (`collection.volume`). وبلا `stroke` لا يُميَّز.

والعنوان الذي لا `resource` له يترك خليته فارغة، والسلسلة التي لا فهرس لها لا يُرسم لها شيء. ومع `basis` تتحجّم الخلايا مع المنطقة كما يتحجّم العنصر.

### النزف المعكوس

يتوقف رسم الغلاف عادة عند حدّ القطع، وتمتد الطيّة الداخلية للغلاف المقوّى 15 مم بعده حول الكرتون. ومع `mirrorMargin` يُرسم التصميم ذلك العدد من المليمترات بعد حدّ القطع (2 على الأقل)، وما بعده تُعكس الخلفية والعناصر حتى حافة الفرخ، فتكمل الطيّة الداخلية وهامش النزف الصورة بدل أن يظهر شريط فارغ. ويعطي `designMargin` في ملف التعريف الهامش الذي تتوقعه المطبعة. والعنصر المعلَّم بـ`bleed: 'own'` لا يُعكس.

### مربّعات النص

كل منطقة إطار نص قائم بذاته. ويضيف `textBoxes` إطارات توضع باليد، لاقتباس عبر الغلاف الأمامي، أو سطر عند ذيل الكعب، أو تعليق فوق صورة:

```ts
textBoxes: [
  { name: 'praise', rect: { x: 18, y: 30, width: 110, height: 40 }, verticalAlign: 'middle' },
  { name: 'spine-foot', rect: { x: 158, y: 200, width: 6, height: 25 }, rotate: -90 },
],
```

- `name`: حروف وأرقام و`-` و`_`، ولا يكون اسم منطقة. وبه يملأ نص الغلاف المربّع.
- `rect`: موضعه على الفرخ، بالمليمتر من زاوية هامش النزف.
- `rotate`: ‏`-90` يدير النص ربع دورة ليُقرأ صاعدًا على الكعب، و`90` ليُقرأ نازلًا.
- `verticalAlign`: ‏`top` أو `middle` أو `bottom`.

### التشطيبات والألواح التقنية

`finishes` هي ما تضيفه المطبعة بعد الأحبار، كل منها فوق شكل من أشكال التصميم:

```ts
finishes: [
  { id: 'title-foil', process: 'foil', sheen: 'gloss', shape: { element: 'seal' } },
  { id: 'spot-uv', process: 'varnish', shape: { box: { zone: 'front', x: 0, y: 0, width: 150, height: 120 } } },
  { id: 'relief', process: 'emboss', shape: { element: 'publisher' } },
],
```

- `process`: ‏`varnish` أو `foil`، يُطبع على لوح خاص به (حبر له [تشطيب](/ar/docs/special-inks-die-cuts#التشطيبات))؛ أو `emboss` أو `deboss`، قالب نقش بارز أو غائر.
- `ink`: اللون الخاص للورنيش أو للرقائق. افتراضيًا الورنيش `Varnish` والرقائق `Gold foil`.
- `sheen`: ‏`gloss` (الافتراضي) أو `satin` أو `matte` أو `softTouch`.
- `shape`: ما يغطيه التشطيب: مربّع خاص به (`{ box }`، يوضع كما يوضع العنصر)، أو شكل عنصر أو مؤثر أو شعار (`{ element: id }`؛ وهو محيط الصورة إن كان لموردها محيط)، أو محيط محفوظ في مربّع خاص به (`{ outline, box }`).

النقش البارز أو الغائر لا يطبع شيئًا. يذهب شكله إلى المطبعة على لوح تقني، بجانب [خط القص](/ar/docs/special-inks-die-cuts#خط-القص-في-ملف-pdf): لوح `Separation` اسمه `Emboss` أو `Deboss` يذكره الفحص قبل الطباعة ولا ترسمه أي بروفة. ومنه يصنع المجلّد قالب النقش.

### تصميم لكل فرخ

يتألف الغلاف المقوّى من عدة أفراخ، وكلها تأخذ افتراضيًا تصميم الكتاب `cover`. ويعطي `sheets` فرخًا تصميمًا خاصًّا به، يحلّ محل تصميم الكتاب على ذلك الفرخ:

```ts
cover: {
  image: { resourceId: 'jacket-art', area: 'sheet' },
  sheets: {
    case: {
      background: { hex: '#1d2a44', model: 'hex' },
      finishes: [{ id: 'spine-foil', process: 'foil', shape: { box: { zone: 'spine', x: 1, y: 20, width: 8, height: 80 } } }],
    },
    endpapers: { background: { hex: '#efe6d2', model: 'hex' } },
    endpaperBack: {
      background: { hex: '#efe6d2', model: 'hex' },
      elements: [{ id: 'series', kind: 'catalogue', zone: 'flyleaf', x: 15, y: 40, width: 120, height: 150, columns: 3 }],
    },
  },
},
```

وأسماء الأفراخ:

- `case`: كسوة الغلاف المقوّى، كقماش مختوم بالرقائق المعدنية تحت غلاف واقٍ مطبوع.
- `jacket`: الغلاف الواقي.
- `endpapers`: ورقتا البطانة معًا؛ و`endpaperFront` و`endpaperBack`: إحداهما، مقدَّمة على `endpapers`.
- `cover`: غلاف الكتاب ذي الغلاف اللين، أو كسوة الغلاف المقوّى الذي لا تصميم `case` له.

وكلٌّ منها تصميم كامل، فيه كل حقول `cover` إلا `sheets`، ولا يأخذ شيئًا من تصميم الكتاب: في المثال لا تظهر صورة الغلاف الواقي على الكسوة. والفرخ الذي لا تصميم خاصًّا به يأخذ تصميم الكتاب.

## نص الغلاف

نص الغلاف مستند Markdown من مستندات الكتاب، يُحفظ بجانب فصوله. وكل كتلة فيه تملأ منطقة واحدة أو مربّع نص واحدًا باسمه:

```md
:::frame{slot="back"}
مدينة تحفظ كتبها تحت الأرض، وفتاة تقرؤها بصوت عالٍ.

:::paragraphs{style="cover-praise"}
«رواية تُقرأ في جلسة واحدة.» — *صحيفة*
:::
:::

:::frame{slot="flapFront"}
**سلمى الخطيب** وُلدت في حلب عام 1984. و*المكتبة السفلية* روايتها الثانية.
:::

:::frame{slot="praise"}
*الفائزة بجائزة الرواية الأولى*
:::
```

يُنضَّد النص بطباعة الكتاب: أنماط فقراته وأنماط حروفه وخطوطه. وستة أنماط فقرات خاصة بالغلاف، ويجوز للكتاب أن يعيد تعريفها: `cover-title` و`cover-subtitle` و`cover-author` و`cover-spine`، ولفهرس السلسلة (انظر أدناه) `cover-catalogue` و`cover-catalogue-current`. والغلاف الأمامي والكعب اللذان يتركهما Markdown فارغين يأخذان عنوان الكتاب وعنوانه الفرعي ومؤلفه من بياناته الوصفية، منضَّدة بهذه الأنماط، في كل بناء: ولا تُنسخ أبدًا إلى نص الغلاف. والإطار `front` أو `spine` يستبدل بها نصه.

والإطار المخصّص لموضع ليس في الفرخ (جناح في فرخ بلا أجنحة، أو غلاف خلفي في ورقة بطانة) يُغفل، ويذكر الفحص ذلك؛ ويُغفل كذلك الإطار الثاني للموضع نفسه. واكتب نص الغلاف فقراتٍ وأنماطَ فقرات: فالعنوان `#` يأخذ التصميم الذي يعطيه الكتاب لعناوين فصوله.

ونص غلاف واحد يخدم كل النسخ وكل الأفراخ. والكتاب متعدد اللغات يجوز أن يعطي كل لغة نصها.

### نص لفرخ واحد

الإطار الذي يسمّي فرخًا بـ`sheet` لا يُنضَّد إلا على ذلك الفرخ، وهناك يأخذ موضعه مقدَّمًا على الإطار الذي لا يسمّي فرخًا. وبهذا يحمل الغلاف المقوّى تحت غلافه الواقي اسم السلسلة وحده على وجهه، بينما يبقى على وجه الغلاف الواقي العنوان المأخوذ من البيانات الوصفية:

```md
:::frame{slot="front" sheet="case"}
**مكتبة البحر**
:::

:::frame{slot="flyleaf" sheet="endpapers"}
*من أرشيف الناشر*
:::
```

ويأخذ `sheet` أسماء `cover.sheets`، اسمًا واحدًا أو عدة أسماء تفصل بينها مسافات (`sheet="case jacket"`). وكسوة الغلاف المقوّى تُدعى `case` و`cover` معًا، فالإطار المسمّى `cover` يبلغها أيضًا، أما المسمّى `case` فلا يبلغ إلا الكسوة؛ والمسمّى `endpapers` يبلغ ورقتي البطانة كلتيهما. والإطار الفارغ لفرخ واحد، المغلق في الحال (`:::frame{slot="back" sheet="case"}` يليه `:::`)، يترك تلك المنطقة خالية على ذلك الفرخ: يأخذ الموضع من الإطار المشترك بين الأفراخ كلها ولا يضع فيه شيئًا. وعلى الوجه أو الكعب يمنع أيضًا العنوان الذي كانت البيانات الوصفية ستضعه. والاسم الذي ليس لأي فرخ يُذكر (`coverFrameSheetUnknown`)، والإطار الذي لا يسمّي فرخًا غيره يُترك.

### فهرس السلسلة

يُنضِّد `::catalogue`، في سطر مستقل داخل إطار، عناوين `production.collection.catalogue` بترتيبها، فقرة لكل عنوان: رقمه، ثم مسافة نصف مربّع، ثم العنوان. وتُنضَّد العناوين بنمط `cover-catalogue`، بحجم المتن ومحاذاة البداية، وعنوان الكتاب نفسه (`collection.volume`) بنمط `cover-catalogue-current`، بخط عريض.

```md
:::frame{slot="flyleaf" sheet="endpaperFront"}
**في السلسلة نفسها**

::catalogue{numbers="I" last=6}
:::

:::frame{slot="flyleaf" sheet="endpaperBack"}
::catalogue{numbers="I" first=7}
:::
```

- `numbers`: نمط العدّ للأرقام: `1` (الافتراضي)، و`01`، و`I`، و`i`، و`A`، و`a`، أو `none` لعناوين بلا أرقام.
- `first` و`last`: أول عنوان يُنضَّد وآخره، بموضعهما عدًّا من 1، لتقسيم قائمة طويلة بين ورقتي البطانة. ويحتفظ كل عنوان برقم موضعه في القائمة كاملة.

والكتاب الذي لا فهرس لسلسلته لا يُنضَّد له شيء في هذا الموضع.

وتقرأ فحوص الإعدادات أيضًا `production` و`cover` كأي إعداد آخر: المفتاح غير المعروف، والقيمة من نوع خاطئ، والردمك غير الصالح، كلها تُذكر مع مسارها. ويُفحص كل تصميم في `cover.sheets` كما يُفحص تصميم الغلاف نفسه، ويُذكر أيضًا اسم فرخ ليس من الأسماء الستة، و`columns` و`first` و`last` لعنصر فهرس ليست أعدادًا صحيحة من 1 فصاعدًا، و`gap` سالب، و`collection.volume` لا يسمّي عنوانًا من الفهرس.

ويمر ملف PDF للغلاف بـ[الفحص قبل الطباعة](/ar/docs/configuration-pdf-output) نفسه الذي يمر به ملف الكتاب: دقة صوره، والأسود، وتغطية الحبر، وتشطيباته وألواحه التقنية.

## في Sandbox

لوحة **الغلاف**، في الشريط الجانبي، تضم النسخ المطبوعة وغلافها:

- **النسخ**: **إضافة غلاف ورقي** أو **إضافة غلاف مقوّى**، ثم لكل نسخة اسمها وتجليدها وردمكها ورمزها الإضافي وردمك العمل، وأجنحتها أو غلافها الواقي، ومادة الغلاف المقوّى، والكعب الذي تعطيه المطبعة، واتجاه نص الكعب وأرقّ كعب يحمله. ويتجاوز **مقاسات هذه النسخة** مقاسات ملف التعريف لهذه النسخة وحدها.
- **الفرخ**: الفرخ المعروض (الغلاف، أو الغلاف الواقي، أو ورقة البطانة الأمامية أو الخلفية)، وصفحاته وكعبه وحجمه.
- **التصميم على الفرخ**: يحوّل **التحرير على الفرخ** الفرخ إلى أداة تصميم. تُضاف مربّعات النص ومربّعات اللون والأغشية والصور والشعارات والتشطيبات من شريطها، وتُسحب ويُغيَّر حجمها على الفرخ، فتلتقط الطيّات والمساحات الآمنة وبعضها بعضًا (ويوقف Alt الالتقاط). وتحرّك مفاتيح الأسهم العنصر المحدّد 1 مم، و10 مم مع Shift. وتسرد **الطبقات** العناصر التي تحت النص، ومربّعات النص، والعناصر التي فوق النص، والشعارات، والتشطيبات، وترتّبها. وتضبط حقول العنصر المحدّد موضعه ولونه وعتامته، وكيف تملأ الصورة مربّعها، ونصف قطر زواياه، وحدّه، وتدرّجه، وظله، وما يفعله بعد النزف المعكوس، وهل يتحجّم مع لوحته، ومساره أو محيطه أو قصّه. وإعادة تسمية مربّع نص تنقل نصه في Markdown الغلاف معه.
- **النصوص**: محرّر Markdown لكل منطقة ولكل مربّع نص. ويعرض الغلاف الأمامي والكعب ما يأخذانه من البيانات الوصفية حتى يُعطيا **نص خاص**.
- **السلسلة**: اسم السلسلة وردمكها.
- **ملفات المطبعة**: **تنزيل PDF للفرخ**، مكتوبًا بإعدادات PDF للكتاب (فضاء الألوان، وملف تعريف الإخراج، وPDF/X)، و**تنزيل الغلاف الأمامي** صورةً.
- **الفحوص**: الفحوص المذكورة أعلاه.
- **ملفات تعريف المطبعة**: ملفات تعريف التجليد، منسوخة من ملف مدمج ومضبوطة على مقاسات المطبعة، كل مقاس بالمليمتر أو بنسبة من المقاس أو بدرجات بحسب حجم المقاس، مع ما يساويه في هذا الكتاب؛ وملفات تعريف الورق مع مورّدها واسمها التجاري؛ و**تصدير الملفات** و**استيراد ملفات** لملف `.postext-production.json`.

وتُحرَّر في لوحة الغلاف أيضًا تصاميم الأفراخ المفردة، ونصوص الفرخ الواحد، وعنصر الفهرس، ومجلد الكتاب في السلسلة.

وتضم مجموعة **تصميم الغلاف** في لوحة التصميم الخلفيات والصورة ومحاذاة نص المناطق وحجم الرمز الشريطي والنزف المعكوس. وكل تغيير في لوحة الغلاف خطوة في سجل التراجع.

وكثيرًا ما تأتي صور الغلاف ملفات طباعة. فلوحة الموارد تقرأ ملف PDF، أو ملف Illustrator محفوظًا بتوافق PDF، صورةً لكل صفحة بدقة 300 بكسل في البوصة على خلفية شفافة، وتقرأ ملفات TIFF وPSD بحجمها الكامل. أما ملف EPS فلا يُقرأ: تطلب اللوحة حفظه بصيغة PDF.

## من سطر الأوامر

ينضّد `postext cover` فرخًا واحدًا من نسخة:

```bash
postext cover book.postext -o cover.pdf
postext cover book.postext --print-version hardcover --sheet jacket -o jacket.pdf
postext cover book.postext -o front.jpg --dpi 300
```

يختار `--print-version` النسخة (الأولى افتراضيًا)، و`--sheet` الفرخ (`cover` أو `jacket` أو `endpaper-front` أو `endpaper-back`). والمسار الذي ينتهي بـ`.png` أو `.jpg` أو `.webp`، أو `--format`، يرسم لوحة واحدة بدل ملف PDF: الغلاف الأمامي، ما لم يسمِّ `--zone` غيرها (`back` أو `spine` أو `flapFront` أو `flapBack`، أو `sheet` للفرخ كله). وتنطبق خيارات PDF (`--color-space` و`--pdfx` و`--profile` وغيرها) كما في `postext pdf`. انظر [سطر الأوامر](/ar/docs/command-line).

## من الشيفرة

يضم `postext/production` سلسلة الغلاف كلها. يأخذ `buildCover` إعدادات الكتاب، ونسخةً، والصفحات المُخرَجة (من أجل الكعب)، وMarkdown الغلاف، والبيانات الوصفية، والموارد، ويعيد الغلاف مستندًا من صفحة واحدة:

```ts
import { buildDocument } from 'postext';
import { buildCover } from 'postext/production';
import { renderToPdf } from 'postext-pdf';

const book = buildDocument(content, config);
const cover = buildCover({
  config,
  version: 'paperback',
  pages: book.pages,
  markdown: coverMarkdown,
  metadata: content.metadata,
  resources: content.resources,
  sheet: 'cover',
});
if (!('config' in cover)) throw new Error(cover.issues.map((i) => i.kind).join(', '));

const doc = buildDocument(cover.content, cover.config);
const pdf = await renderToPdf([doc], {
  fontProvider,
  resourceBytes: (fileId) => cover.files[fileId] ?? bookFiles[fileId],
});
```

يعطي `cover.sheet` حجم الفرخ ومناطقه بالمليمتر، و`cover.sheets` كل أفراخ النسخة مع كعبها، و`cover.issues` الفحوص. ويجوز أن يكون `pages` عدد صفحات أيضًا، كلها على ورق الكتاب.

وتكشف بقية الوحدة كل خطوة:

- **الردمك**: يقرأ `parseIsbn` الردمك ويتحقق منه، ويرسم `isbnBarcodeSvg` رمزه الشريطي EAN-13 مع الرمز الإضافي، و`ean13CheckDigit` و`isbnCaption` البقية.
- **المقاسات والأفراخ**: يحسب `resolveBindingMeasures` مقاسات ملف تعريف لمقاس قطع، و`resolveLength` مقاسًا واحدًا، و`checkProfileAccepts` الحدود؛ و`spineFromRuns` و`pageRunsOf` و`signaturePages` و`leafMm` الكعب؛ و`softcoverSheet` و`caseSheet` و`jacketSheet` و`endpaperSheet` كل فرخ، و`versionSheets` أفراخ نسخة.
- **التصميم**: يركّب `coverPage` قالب صفحة الفرخ، و`coverSource` الـMarkdown الذي يُخرج منه، و`coverZoneBox` مربّع منطقة، و`placeCoverElement` و`coverElementRect` موضع عنصر، و`basicShape` و`pathData` و`flattenCoverPath` أشكاله؛ و`coverSheetNames` و`coverDesignFor` التصميم الذي يأخذه الفرخ، و`withCatalogue` و`expandCatalogueText` صور الفهرس وأسطره.
- **ملفات التعريف والإعدادات**: `BUILT_IN_BINDING_PROFILES` و`DEFAULT_BINDING_MEASURES` و`DEFAULT_SPINE_TEXT` و`exportProductionProfiles` و`importProductionProfiles` و`readProductionConfig`، الذي يقرأ كتلة `production` من بيانات غير موثوقة ويذكر ما أسقطه.
- **Folio**: يعطي `folioOfBook` إعدادات Folio بتجليد النسخة الأولى، و`productionFolioBinding` و`folioVersionOf` تجليد نسخة مختارة.

## في ملف `.postext`

تحمل الحزمة الإعدادين `production` و`cover` في إعداداتها، ونص الغلاف في `cover.md` بجانب الفصول. واللغة التي لها نص غلاف خاص بها تحمله في `cover/<language>.md`. ويعيده `openBundle` (من `postext/bundle`) في `coverMarkdown`، ويأخذه `createBundle` بالطريقة نفسها. انظر [الحزم](/ar/docs/configuration-bundles).

## Folio وEPUB

يجلّد عرض Folio الكتاب كما تجلّده نسخته الأولى: التجليد الحراري والغلاف اللين المخيط يصيران كتابًا بغلاف ورقي، والغلاف المقوّى تجليدًا فنيًا، ويُرسم كعب الغلاف على كعب الكتاب. وكتاب EPUB الذي يكتبه سطر الأوامر أو Sandbox يأخذ الغلاف الأمامي المطبوع صورةً لغلافه حين تكون للكتاب نسخة مطبوعة ولا يسمّي صورة أخرى.

## الحدود

- يحسب الكعب الصفحات كما أُخرجت. والكتاب الذي تتغيّر صفحاته بعد صنع الغلاف يحتاج إلى صنع غلافه من جديد؛ ويتبع الكعب وكل لوحة من تلقاء نفسها.
- المقاسات الافتراضية نقطة بداية مأخوذة من مواصفات منشورة. اطلب من المطبعة مقاساتها واحفظها في ملف تعريف.
- لا يُكتب إلا ملف PDF وصيغ الصور. ولا تُكتب حزمة IDML لفرخ الغلاف.
- العنوان `#` في نص الغلاف يأخذ تصميم عناوين فصول الكتاب؛ فنضِّد عناوين الغلاف بأنماط الفقرات.
