# Configuration

**Every layout decision in Postext is driven by a single configuration object.**

`PostextConfig` controls page dimensions, column layout, body text typography, heading styles, the document language (`locale`), and more. Every property is optional — Postext ships with sensible defaults inspired by traditional book typography. You only need to specify what you want to change.

```ts
import { buildDocument } from 'postext';

const document = buildDocument(content, {
  page: { sizePreset: '21x28', dpi: 300 },
  layout: { layoutType: 'double', gutterWidth: { value: 0.5, unit: 'cm' } },
  bodyText: { fontFamily: 'EB Garamond', fontSize: { value: 9, unit: 'pt' } }, // 9 pt overrides the 8 pt default
  headings: { fontFamily: 'Open Sans' },
});
```

For an overview of how the engine processes this configuration, see the [Architecture](/en/docs/architecture) page.


## Index

The reference is split into nine pages. Each group below is one page, followed by the sections it holds.

**[Page and layout](/en/docs/configuration-page-layout)**

- [Page](/en/docs/configuration-page-layout#page) — size, margins, baseline grid, cut lines, [binding](/en/docs/configuration-page-layout#binding).
- [Layout](/en/docs/configuration-page-layout#layout) — column count, gutters, rules, [vertical writing](/en/docs/configuration-page-layout#vertical-writing).
- [Headers & footers](/en/docs/configuration-page-layout#headers--footers) — per-page text and rule elements with placeholders, parity, and alignment.

**[Text and headings](/en/docs/configuration-text)**

- [Body text](/en/docs/configuration-text#body-text) — typography, hyphenation, tab stops, orphans and widows.
- [Document language](/en/docs/configuration-text#document-language) — the top-level `locale`: hyphenation fallback, built-in resource types and the continuation strings of tables and split callouts, the language tagged into an accessible PDF; the [digits](/en/docs/configuration-text#document-digits) (`numerals`) and the [text direction](/en/docs/configuration-text#text-direction) (`direction`) it implies; and the [languages and scripts](/en/docs/configuration-text#languages-and-scripts) Postext sets. The guide to right-to-left books is [Arabic layout](/en/docs/arabic-layout).
- [Headings](/en/docs/configuration-text#headings) — shared defaults and H1–H6 overrides.
- [Unordered lists](/en/docs/configuration-text#unordered-lists) and [Ordered lists](/en/docs/configuration-text#ordered-lists) — bullets, numbering, nesting.
- [Math](/en/docs/configuration-text#math) — LaTeX rendering, scale, colour, margins.

**[Notes and references](/en/docs/configuration-notes-references)**

- [Footnotes](/en/docs/configuration-notes-references#footnotes) — `footnotes`: where the notes cited with `[^id]` go, how they are numbered and how they look.
- [Line numbers](/en/docs/configuration-notes-references#line-numbers) — `lineNumbers`: the number of every fifth line of verse, or of the text, in the margin; what is counted, where the count starts again, which side the numbers stand on.
- [Cross-references](/en/docs/configuration-notes-references#cross-references) — `crossRefs`: the words printed around the number or the page of a `:ref`, and its default style.
- [Citations](/en/docs/configuration-notes-references#citations) — `citations`: the citation style, and the look of citations and of the bibliography.
- [Table of contents](/en/docs/configuration-notes-references#table-of-contents) — what `:::toc` prints: entry typography, leaders, page numbers, author lines, part rows.
- [Back-of-book index](/en/docs/configuration-notes-references#back-of-book-index) — what `:::index` prints: entry typography, indents, page-number separators and ranges, letter groups, sorting language.

**[East Asian typography](/en/docs/configuration-east-asian)**

- [East Asian typography](/en/docs/configuration-east-asian#east-asian-typography) — `cjk`: the regional conventions and line breaking of Chinese, Japanese and Korean text, how their justified lines are spread, punctuation widths and hanging, the space between Han and Latin, the character grid, upright numbers in vertical text, and the marks, ruby, warichu notes and kanbun marks. The guides to all of it are [Chinese layout](/en/docs/chinese-layout) and [Japanese layout](/en/docs/japanese-layout).

**[Resources and tables](/en/docs/configuration-resources)**

- [Resource types](/en/docs/configuration-resources#resource-types) — typed numbering for figures, tables, and custom kinds.
- [Table style](/en/docs/configuration-resources#table-style) (with [named table styles](/en/docs/configuration-resources#named-table-styles)) and [Caption style](/en/docs/configuration-resources#caption-style) — typography and decoration for table resources and their captions.
- [Diagram style](/en/docs/configuration-resources#diagram-style) — single-ink recolouring of embedded SVG diagrams for spot-colour printing.
- [Video style](/en/docs/configuration-resources#video-style) — `videoStyle`: the play mark and the QR code printed over a video's poster, and what its players offer in the HTML viewer and in EPUB.

**[Styles and parts](/en/docs/configuration-styles)**

- [Paragraph styles](/en/docs/configuration-styles#paragraph-styles) — named styles for `:::paragraphs` containers: bibliographies, glossaries, notes.
- [Chip styles](/en/docs/configuration-styles#chip-styles) — `chipStyles`: named styles for the inline `:chip[…]`: the box of a word bank, a keyboard key, a tag.
- [Code listings](/en/docs/configuration-styles#code-listings) — `codeStyle`: the face, box, tab width, long lines, line numbers and token colours of ```` ``` ```` listings, the syntax colouring and its highlighter hook, and inline code in a code face.
- [Callout styles](/en/docs/configuration-styles#callout-styles) — boxed notes, tips and objectives for `:::callout` containers.
- [Parts](/en/docs/configuration-styles#parts) — part-divider pages for `:::part` containers: parity, body area, opener design, body typography.
- [Heading styles](/en/docs/configuration-styles#heading-styles) — named styles for `{style="…"}` headings: unnumbered chapters, front matter with its own running heads, geometry and palette.

**[Comics settings](/en/docs/configuration-comics)**

- [Comics](/en/docs/configuration-comics#comics) — `comics`: the frame and gutters of comic pages, panel styles, lettering, balloon styles and the cast. The guide is [Comics](/en/docs/comics).
