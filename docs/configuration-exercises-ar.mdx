# الإعدادات: التمارين


## أنماط التمارين

تعرّف الخاصية `exerciseStyles` الأنماط المسمّاة التي يختارها التمرين بـ`:::exercise{style="…"}`. النمط شكلُ عائلة من التمارين؛ أما الأسئلة والإجابات فتبقى في Markdown (انظر [التمارين](/ar/docs/exercises)). يأتي افتراضيًا نمط واحد هو `exercise`، فتعمل الحاوية دون أي إعداد؛ وتعريف `exerciseStyles` يستبدله، وأول نمط مُعرَّف هو الذي يأخذه التمرين الذي لا `style` له. كل الحقول اختيارية، والقيم الافتراضية تتبع لغة المستند حيث تختلف المدارس: تسميات الخيارات، وعلامتا صح وخطأ، وطريقة كتابة القسمة المطوّلة، والكلمات المطبوعة.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Noto Kufi Arabic' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### الرقم

تضبط `number` رقم التمرين. الرقم المجرد عريض، باللون الرئيسي، تليه نقطة؛ والرقم داخل شكل أبيض في قرص أو مربع أو مربع مستدير الزوايا باللون الرئيسي، ولا يليه شيء.

```ts
const config: PostextConfig = {
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [{ id: 'exercise', area: { kind: 'none' }, blank: { minWidth: { value: 6, unit: 'em' } } }],
    },
  },
};
```

### التقييم

التمرين في الوضع الافتراضي تدريب: يتحقق القارئ من إجاباته متى شاء، ويبدأ من جديد، ويطّلع على الحل. وتجعله أربعة إعدادات اختبارًا، للكتاب في `exercises.digital`، وللنمط في `digital` الخاصة به، وهي التي تسري على تمارين ذلك النمط:

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** تعدّ مرات الضغط على «تحقّق» في المحاولة. ويذكر الزر كم بقي منها («تحقّق (بقي 2)»)؛ وحين تنفد يصير «لم يبقَ تحقّق»، وتُقفل الإجابات، وتبقى الدرجة على الشريط.
- **`reset`** و<strong>`maxResets`</strong>: يمسح «أعد المحاولة» الإجابات ويبدأ محاولة جديدة تعود معها مرات التحقق. و`maxResets: 1` تسمح ببداية جديدة واحدة، أي بمحاولتين في المجموع، ويذكر الزر كم بقي منها؛ و`reset: false` تزيل الزر.
- **`showSolution`**: `'always'`؛ و`'afterCheck'`، بعد التحقق من المحاولة؛ و`'noChecksLeft'`، حين تنفد مرات التحقق أو تكون الإجابات كلها صحيحة؛ و`'never'`. وما دامت مرات التحقق محدودة فإن عرض الحل ينهي المحاولة.
- **`passingScore`** هي ما تُبلغ حزمة SCORM عن النجاح أو الرسوب بالقياس إليه (انظر [حزم SCORM](/ar/docs/configuration-html-folio-epub#حزم-scorm-postext-scorm)).

وتتبع كلمات الأزرار لغة المستند. ومع `check: 'instant'` لا يوجد زر «تحقّق»، فلا تنطبق `maxChecks`؛ أما الإعدادات الأخرى فتنطبق. وتُحفظ مرات التحقق والبدايات الجديدة المستعملة مع الإجابات: في نظام إدارة التعلم تحفظها حزمة SCORM فيه، فتسري على أي جهاز؛ وفي صفحة HTML أو كتاب EPUB تبقى في متصفح القارئ، ومن يمسح تخزين متصفحه يبدأ من جديد.
