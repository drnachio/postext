# Bücher aus zusammengesetzten Seiten

**Sie bauen eine Schulbuchseite aus einer Vorlage, füllen sie mit Text aus dem Markdown, beschriften eine Karte, übersetzen die Seite und beheben, was nicht passt; danach fügen Sie einen Baum, Notizen auf einer Karte, eine Seite mit Fotokarten und eine Modulbibliothek hinzu.**

Eine Schulbuchseite besteht aus Kästen: einem Titelband, einem Text, einem Kasten für eine Definition, einem für eine Aufgabe und einer Karte. Postext setzt eine solche Seite nach einer **Seitenvorlage**, die die Kästen (ihre Rahmen) enthält; das Markdown legt nur fest, welche Wörter in welchen Rahmen kommen. Diese Seite führt die ganze Arbeit in der Sandbox vor, an einem bestehenden Buch, dem Sie eine Seite hinzufügen. Die Referenzseiten erklären, was jedes Feld und jede Markdown-Zeile bewirkt; hier machen Sie jeden Schritt einmal, der Reihe nach, und sehen, was er ändert: [Zusammengesetzte Seiten](/de/docs/composed-pages) für das Markdown, [Konfiguration › Zusammengesetzte Seiten](/de/docs/configuration-composed-pages) für die Vorlage, [Sandbox: zusammengesetzte Seiten](/de/docs/sandbox-composed-pages) für die Bildschirme.

Sie brauchen nur einen Browser. Alles geschieht in der Sandbox, und was Sie ändern, bleibt in Ihrem Browser.

## 1. Das Buch öffnen

Das Buch heißt *Our river* und ist eine Einheit aus einem Schulbuch für das dritte Schuljahr, die in den [Rezepten](/de/cookbook/children-textbook-pages) als Rezept Nº 156 erscheint. Der Fluss, die Orte und die Bilder sind dafür erfunden. Sie hat neun Seiten, darunter eine gemalte Karte über eine Doppelseite, und liegt auf Spanisch, Katalanisch und Englisch vor.

[Öffnen Sie es in der Sandbox](/de/sandbox#recipe=children-textbook-pages&lang=en). Beim ersten Besuch wird es als eines Ihrer eigenen Bücher unter **Bücher** abgelegt, sodass Sie es frei ändern dürfen; mit `lang=es` oder `lang=ca` im Link erhalten Sie die anderen Ausgaben. Rufen Sie später denselben Link noch einmal auf, fragt die Sandbox, ob sie Ihre Kopie öffnen oder durch die veröffentlichte ersetzen soll.

Zwei Dinge vorab, bevor Sie etwas anfassen:

- Die Leiste über der Vorschau hat einen Umschalter mit **Inhalt** und **Gestaltung**. Im Modus Inhalt bearbeiten Sie Wörter, im Bedienfeld **Text** oder auf der Seite. Im Modus Gestaltung bearbeiten Sie Seitenvorlagen und Stile, und der Text ist schreibgeschützt. **Alt+Umschalt+M** (**⌥⇧M** auf dem Mac) wechselt zwischen beiden.
- Das Bedienfeld **Text** zeigt ein Kapitel als Markdown. Jede zusammengesetzte Seite ist ein Block, der mit `::::page{template="…"}` beginnt und mit vier Doppelpunkten endet. Klicken Sie in der Vorschau auf Wörter einer Seite, springt die Einfügemarke an die entsprechende Stelle im Markdown.

## 2. Eine Seitenvorlage anlegen

Die neue Seite wird eine Wiederholungsseite: ein Titelband, darunter ein kurzer Text und zwei Kästen, einer zum Erinnern an das Gelernte und einer zum Ausprobieren. Dafür braucht sie eine Vorlage mit vier Rahmen.

1. Wechseln Sie zu **Gestaltung** und öffnen Sie links das Bedienfeld **Gestaltung**. Wählen Sie **Seite und Spalten**, dann **Seitenvorlagen**. Die Liste zeigt jede Vorlage des Buchs mit einer Zeichnung ihrer Rahmen.
2. Klicken Sie auf **Neu**. Eine Vorlage namens *Neue Vorlage* öffnet sich. Geben Sie ihr die **ID** `review` (das ist der Name, den das Markdown verwendet) und den **Namen** `Review page` (so zeigt ihn dieses Bedienfeld). Die ID darf Kleinbuchstaben, Ziffern und Bindestriche enthalten.
3. Die Vorlage beginnt mit einem Rahmen, `text`, bei dem **Nimmt den freien Text der Seite auf** eingeschaltet ist. Machen Sie ihn zum Titelband: **Name (Slot)**: `title`; **Kastenstil**: `portada`, das blaue Band, das das Buch schon für seine Titel verwendet; schalten Sie **Nimmt den freien Text der Seite auf** aus; **Nimmt auf**: *Ebene 1*, damit dieser Rahmen die erste `#`-Überschrift der Seite erhält.
4. Klicken Sie auf **Rahmen hinzufügen**. Der neue Rahmen öffnet sich unter der Liste der Rahmen. **Name (Slot)**: `text`, und schalten Sie **Nimmt den freien Text der Seite auf** ein: Alles, was die Seite außerhalb eines Rahmens schreibt, kommt hierher.
5. Fügen Sie einen Rahmen hinzu. **Name (Slot)**: `remember`. **Kastenstil**: `dato`, ein getönter Kasten mit Etikett. **Kleinste Höhe**: 30 mm, damit der Kasten eine gute Größe behält, auch wenn sein Text kurz ist.
6. Fügen Sie einen letzten Rahmen hinzu. **Name (Slot)**: `try`. **Kastenstil**: `actividad`, ein Kasten mit einem Streifen an der Seite. **Kleinste Höhe**: 30 mm.
7. Stellen Sie bei `text`, `remember` und `try` die **Breite** auf *Bis zum Rand* und die **Höhe** auf *Sein Inhalt*. Dann füllen die Rahmen die Breite der Seite aus und sind so hoch wie ihr Text.
8. Klicken Sie unter **Gruppen** auf **Gruppe hinzufügen**. Nennen Sie sie `column`, lassen Sie sie *Gestapelt* und setzen Sie den **Abstand zwischen Rahmen** auf 6 mm. Haken Sie unter **Rahmen der Gruppe, in Seitenreihenfolge** die vier Rahmen an, und zwar in der Reihenfolge, in der sie stehen sollen, den Titel zuerst: Die Liste nummeriert die Rahmen, und mit den Pfeilen verschieben Sie einen nach oben oder unten. Eine Gruppe setzt ihre Rahmen untereinander und schiebt die unteren weiter, wenn ein Rahmen wächst: Ein längerer Text im ersten Kasten drückt den zweiten nach unten, statt ihn zu überdecken.

<Screenshot src="/docs-shots/de/template.webp" alt="Das Bedienfeld Gestaltung bei Seitenvorlagen mit der Vorlage Review page: ihre vier Rahmen und ihre Gruppe; auf der Seite dieselben Rahmen mit gestrichelten Umrissen." caption="Die Vorlage: vier Rahmen und eine Gruppe. Auf der Seite sind die gestrichelten Rechtecke die Rahmen; die grünen Angaben zeigen, wie die Größe jedes Rahmens bestimmt wird." />

In der Vorlage steht kein Wort Text. Nichts, was Sie eingestellt haben, legt fest, wie der Titel lautet oder was in den Kästen steht: Der Kastenstil bestimmt das Aussehen eines Rahmens, die Gruppe die Reihenfolge der Rahmen. Zur selben Vorlage führen noch andere Wege. Im Modus Gestaltung können Sie mit der Maus einen Rahmen an einer leeren Stelle einer zusammengesetzten Seite aufziehen und die vorhandenen Rahmen verschieben oder in der Größe ändern (siehe [Sandbox: zusammengesetzte Seiten](/de/docs/sandbox-composed-pages#seitenvorlagen)); **Duplizieren** kopiert eine Vorlage, damit Sie die Kopie abwandeln können; **Layout als Vorlage speichern** macht aus einer zusammengesetzten Seite, die Ihnen gefällt, eine neue Vorlage.

## 3. Die Seite aus dem Markdown füllen

1. Wechseln Sie zu **Inhalt**, öffnen Sie das Bedienfeld **Text** und drücken Sie **Strg+Ende** (**Cmd+↓** auf dem Mac), um ans Ende des Kapitels zu springen.
2. Klicken Sie in der Werkzeugleiste des Bedienfelds Text auf **Zusammengesetzte Seite**. Eine Auswahl zeigt die Seitenvorlagen des Buchs, jede als Zeichnung ihrer leeren Rahmen. Wählen Sie *Review page*.
3. Die Sandbox schreibt die Seite für Sie, mit einem leeren Rahmen je Slot, und markiert das Wort `title` in der Überschrift. Überschreiben Sie es mit dem Titel.

```md
::::page{template="review"}
# Check what you have learned

A river changes as it runs from the mountains to the sea. Read the boxes, then answer them in your own words.

:::frame{slot="remember" label="Remember"}
A spring gives a trickle, streams join into a river, and the river widens as it nears the sea.
:::

:::frame{slot="try" label="Try it"}
Draw a river from its spring to the sea. Write the names of the three courses on your drawing.
:::
::::
```

Die Überschrift geht in den Rahmen, der Ebene 1 aufnimmt, der Absatz danach in den Rahmen, der den freien Text aufnimmt, und jedes `:::frame` in den Rahmen seines `slot`. Das `label` ist der Text auf dem Etikett eines Kastens. Auf der Leinwand steht die Seite als Seite 10 hinter den neun Seiten der Einheit: Eine zusammengesetzte Seite beginnt immer eine neue Seite.

<Screenshot src="/docs-shots/de/fill.webp" alt="Das Bedienfeld Text mit dem Markdown der neuen Seite und daneben die fertige Seite mit blauem Titel, einem Absatz und zwei Kästen mit Etiketten." caption="Die Seite im Markdown und auf der Leinwand." />

Beachten Sie, was das Markdown nicht sagt: keine Position, keine Größe, keine Farbe. Das gehört zur Vorlage, und dasselbe Markdown sähe mit einer anderen Vorlage gesetzt anders aus.

## 4. Die Karte beschriften

Die Seiten 6 und 7 zeigen eine gemalte Karte über die Doppelseite. Ihre Wörter sind nicht Teil des Bilds. Jeder Name darauf ist eine Zeile Markdown im `:::figure`-Block der Karte:

```md
:::figure{resource="mapa" slot="mapa"}
::label[Spring]{at="nacimiento"}
::label[Molinar]{at="molinar"}
::label[Lower course]{at="bajo"}
:::
```

`at` gibt einen **Anker** an: einen festen Punkt im Bild, der einmal in der Ressource des Bilds festgelegt wird und für alle Sprachen gilt. So fügen Sie die Steinbrücke von Molinar hinzu:

1. Gehen Sie im Bedienfeld Text zur Abbildung der Karte (suchen Sie nach `at="bajo"`) und fügen Sie unter der letzten Beschriftung eine Zeile ein: `::label[Stone bridge]{at="bridge"}`.
2. Öffnen Sie **Prüfungen**. Die Liste hat für Seite 6 einen Eintrag *Beschriftung an einem unbekannten Anker*: Das Bild hat keinen Anker namens `bridge`. Klicken Sie im Eintrag auf die Schaltfläche mit der Nadel, *Anker bridge im Bild setzen*.
3. Ein Dialog zeigt die Karte mit ihren vorhandenen Ankern. Der Name `bridge` ist unter *Beschriftungen ohne Anker (1)* ausgewählt. Klicken Sie im Bild auf die Stelle, an der die Brücke steht.
4. Stellen Sie den **Beschriftungsstil** des neuen Ankers auf `pueblo`, den Stil der Orte, und klicken Sie auf **Speichern**.

<Screenshot src="/docs-shots/de/anchor.webp" alt="Der Dialog Anker: die Karte mit ihren Punkten, der neue Anker bridge ausgewählt und sein Feld Beschriftungsstil." caption="Der neue Anker entsteht mit einem Klick ins Bild; dank seines Beschriftungsstils sieht die Beschriftung aus wie die Ortsnamen." />

<Screenshot src="/docs-shots/de/map.webp" alt="Die Karte über die Seiten 6 und 7 mit der neuen Beschriftung Stone bridge auf der Brücke, neben den Beschriftungen der Orte." caption="Die Beschriftung steht an dem Punkt, den Sie angeklickt haben, in den eigenen Schriften des Buchs." />

Das Wort *Stone bridge* steht im Markdown, der Punkt gehört zum Bild. Übersetzen Sie die Seite, steht am selben Anker ein anderes Wort.

## 5. Die Seite übersetzen

Eine Übersetzung ist dieselbe Vorlage mit anderen Wörtern. Die Sandbox führt sie als weitere Ausgabe desselben Buchs: Über die Werkzeugleiste am linken Rand der Leinwand wechseln Sie zwischen den Ausgaben, und das Bedienfeld Prüfungen prüft alle (siehe [Ausgaben eines Buchs](/de/docs/sandbox-previews#ausgaben-eines-buchs)). Die Leiste erscheint, wenn der Zeiger diesen Rand erreicht; mit der Schaltfläche zum Anheften bleibt sie offen. So legen Sie eine an:

1. Öffnen Sie **Bücher**, klicken Sie bei Ihrem Buch auf **⋯** und wählen Sie **Sprache hinzufügen …**. Wählen Sie die Sprache und klicken Sie auf **Hinzufügen und öffnen**. Die Sandbox kopiert die angezeigte Ausgabe in eine neue, stellt deren **Dokumentsprache** auf die gewählte Sprache und öffnet sie. Silbentrennung, Anführungszeichen und die Wörter, die die Engine selbst setzt (etwa *Fortsetzung* an der Stelle, an der ein Kasten geteilt wird), richten sich nach dieser Sprache. Der Text ist noch der des Originals.
2. Übersetzen Sie im Bedienfeld **Text** die Wörter und lassen Sie alles andere stehen.

Die Bilder, die Anker, die Kästen und ihre Farben werden mitkopiert und machen keine Arbeit. Die Wiederholungsseite sieht in der spanischen Kopie so aus:

```md

# Repasa lo aprendido

Un río cambia mientras baja de las montañas al mar. Lee los recuadros y respóndelos con tus propias palabras.

:::frame{slot="remember" label="Recuerda"}
Un manantial da un hilo de agua, los arroyos se unen en un río y el río se ensancha al acercarse al mar.
:::

:::frame{slot="try" label="Inténtalo"}
Dibuja un río desde su manantial hasta el mar. Escribe en tu dibujo el nombre de los tres cursos.
:::
::::
```

## 6. Prüfen, was nicht passt

Wörter sind von Sprache zu Sprache unterschiedlich lang, und ein Kasten, der den englischen Text fasste, fasst den spanischen vielleicht nicht. Das Bedienfeld Prüfungen findet solche Rahmen. Um es auszuprobieren, fügen Sie in den Rahmen `remember` der übersetzten Seite drei oder vier weitere Absätze mit beliebigem Text ein, sodass er mehr enthält, als auf der Seite Platz hat.

Auf der Seite ist der Rahmen jetzt rot umrandet, und ein Band unter seinem unteren Rand zeigt, wie viel Platz fehlt (*26 mm zu kurz*). Unter **Prüfungen**, bei *Zusammengesetzte Seiten*, erklärt der Eintrag *Text passt nicht in seinen Rahmen*, was der Satz versucht hat, bevor er aufgab (erst mehr Platz von den Rahmen ringsum, dann kleineren Text), und bietet die Auswege als Schaltflächen an:

- *den Text auf 82,5 % verkleinern lassen (fit.minScale)* lässt den Text dieses Rahmens bis auf diese Größe schrumpfen. Das eignet sich, wenn nur wenige Zeilen zu viel sind.
- *auf der nächsten Seite fortsetzen (overflow.continueIn)* setzt, was nicht passt, auf eine Seite, die hinter dieser eingefügt wird. Das eignet sich für einen längeren Text.
- *etwa 495 Zeichen kürzen* ändert nichts. Es wählt den Text des Rahmens aus und zeigt, wie viel Sie kürzen müssen.

Eine Schaltfläche, die die Vorlage ändert (und damit jede Seite, die nach ihr gesetzt ist), fragt zuerst nach und nennt die betroffene Einstellung. Klicken Sie auf **Ändern**. Die Seite wird neu gesetzt, der Kasten endet mit dem Fortsetzungsvermerk (*Continúa*), und der Rest läuft oben auf einer eingefügten Seite weiter. **Cmd/Strg+Z** nimmt die Änderung zurück. **Verschiebungen** in derselben Werkzeugleiste am Rand der Leinwand öffnet *Was sich bewegt hat und warum*: eine Liste der Rahmen, deren Größe oder Position der Satz geändert hat, damit ihr Inhalt hineinpasst, jeweils mit einer Begründung.

<Screenshot src="/docs-shots/de/checks.webp" alt="Das Bedienfeld Prüfungen mit dem Eintrag Text passt nicht in seinen Rahmen und drei Schaltflächen mit Lösungen; daneben die Seite, deren erster Kasten rot umrandet ist, mit einem Band und der Angabe 26 mm zu kurz." caption="Ein Rahmen, der nicht passt, und die Lösungen, die der Satz für ihn errechnet hat." />

Ein Buch, das nichts festlegt, beginnt mit **Nur Probleme**: Die Maßstabsplaketten erscheinen, sobald Sie **Alle** wählen. Die Sandbox merkt sich Ihre Wahl in diesem Browser. Das Buch kann sie für alle festlegen, die nicht gewählt haben: `debug.fitMarks` (`"all"`, `"problems"` oder `"none"`) und `debug.fitMarksMinScale`, das die Plakette bei einem Rahmen weglässt, der in diesem Maßstab oder größer gesetzt ist (mit `0.95` wird nur markiert, was unter 95 % liegt). Diese Marken gehören zur Leinwand: PDF, HTML-Ansicht, EPUB und Folio zeichnen sie nie. Seit postext 1.52.

Ein Kasten mit Fotos und ihren Bildunterschriften (Rahmen, die in ihm verankert sind, je eine Unterschrift `below` ihrem Foto) wächst nicht von selbst, wenn eine Übersetzung die Unterschriften länger macht: Sie laufen aus dem Kasten und über das, was darunter liegt. Öffnen Sie den Rahmen des Kastens im Vorlagen-Editor und stellen Sie **Wächst mit den Rahmen darin** auf *Die darin verankerten Rahmen* (`growWith: "children"` in der Vorlage). Der Kasten reicht dann bis zum Fuß der untersten Unterschrift plus seinem unteren Innenabstand, Fläche, Rand und Reiter folgen, und die Rahmen darunter rücken nach unten. *Die gewählten Rahmen* nimmt stattdessen eine Liste von Namen. Es zählen die Rahmen, die an einem Punkt der Oberkante des Kastens verankert sind, und die an diesen verankerten; ein Rahmen, der am Fuß oder an der Mitte des Kastens verankert ist, zählt nicht, und ein gedrehter Kasten wächst nicht. Seit postext 1.52.

## 7. Auf der Seite und im Text auswählen

Die Seite und ihr Markdown folgen einander.

- **Von der Seite zum Text.** Klicken Sie auf die Wörter eines Rahmens: Die Einfügemarke springt zu diesem Absatz im Bedienfeld Text, und ein Pfad unter der Vorschau zeigt, wo Sie sind (*Seite 10 › column › try › Absatz 1*). Im Modus Gestaltung wählt derselbe Klick stattdessen den Rahmen für den Vorlageneditor aus.
- **Vom Text zur Seite.** Setzen Sie die Einfügemarke in einen Absatz: Der Absatz und der Rahmen, der ihn enthält, werden auf der Seite umrandet, und derselbe Pfad zeigt, wo sie liegen.
- **Von einer Prüfung aus.** Klicken Sie auf einen Eintrag im Bedienfeld Prüfungen, und die Sandbox führt Sie zur Seite, wählt den Rahmen aus und setzt die Einfügemarke an seinen Text. In einem Buch mit mehreren Ausgaben wechselt sie zu der Ausgabe, die das Problem hat.

<Screenshot src="/docs-shots/de/select.webp" alt="Die Seite mit dem zweiten Kasten orange umrandet und das Bedienfeld Text, das den ausgewählten Rahmen in seinem Markdown zeigt." caption="Ein Klick auf die Seite setzt die Einfügemarke in ihr Markdown, und der Pfad unter der Vorschau zeigt, welcher Rahmen es ist." />

## 8. Einen Baum mit Verbindern zeichnen

Ein Ideenbaum, ein Organigramm und eine Zeitleiste bestehen aus Kästen, die Linien verbinden. In Postext sind die Kästen Rahmen und die Linien **Verbinder**: Linien der Dekoration einer Vorlage, die Rahmen miteinander verbinden. Ein Verbinder wird gezeichnet, nachdem die Rahmen ihre endgültigen Rechtecke haben. Er folgt also einem Kasten, der mit einem längeren Text oder mit den Wörtern einer anderen Sprache wächst, und die Vorlage braucht kein Bild der Linien. Sie zeichnen den Baum einmal, als **Modul** (ein Block aus Rahmen, den jede zusammengesetzte Seite aufnehmen kann), und das Markdown legt fest, wie viele Äste er hat.

1. Öffnen Sie in **Gestaltung** den Abschnitt **Seite und Spalten › Module** und klicken Sie auf **Neues Modul**. Ein Modul namens *Modul* erscheint in der Liste, mit einem Rahmen, `text`. Klicken Sie auf seinen Stift (*Modul Modul bearbeiten*): Der Vorlageneditor öffnet sich an Ort und Stelle, mit eingeschaltetem Schalter **Modul**.
2. Geben Sie ihm die **ID** `tree` und den **Namen** `Tree of ideas`. Wählen Sie den Rahmen `text` und machen Sie ihn zur Spitze des Baums: **Name (Slot)** `root`, **Kastenstil** `dato`, **Breite** *Bis zum Rand*, **Höhe** *Sein Inhalt*, und schalten Sie **Nimmt den freien Text der Seite auf** aus.
3. Klicken Sie auf **Rahmen hinzufügen**. **Name (Slot)**: `branch`; **Kastenstil**: `dato`; **Kleinste Höhe**: 20 mm.
4. Klicken Sie unter **Gruppen** auf **Gruppe hinzufügen**. Nennen Sie sie `branches` und wählen Sie **Raster**: **Spalten** 3, **Abstand zwischen Spalten** und **Abstand zwischen Zeilen** 6 mm. Wählen Sie unter **Eine Rahmengruppe wiederholen** `branch` als **Hauptrahmen**: Das Raster setzt einen `branch` für jeden Eintrag, den die Seite ihm gibt. Stellen Sie **Eigenes Rechteck** auf *Rahmen root*, **Relative Position** auf *Unter* und **Versatz Y** auf 12 mm, damit das Raster unter der Wurzel beginnt, wie hoch sie auch ist.
5. Klicken Sie unter **Dekoration** auf **Verbinder hinzufügen**. Stellen Sie in seiner Karte **Beginnt bei** auf *Rahmen root* und drücken Sie unter **Führt zu** auf *Jedes branch* (die Enden der Linie sind die gedrückten Schaltflächen). Stellen Sie **Verlauf** auf *Baum*, **Radius der Knicke** auf 2 mm, **Linienstärke** auf 1,5 pt und **Endzeichen** auf *Pfeil*. **Auf der Seite wählen** erledigt dasselbe mit der Maus, im Modus Gestaltung: Klicken Sie auf den Rahmen, an dem die Linie beginnt, dann auf jeden Rahmen, zu dem sie führt; ein zweiter Klick nimmt ein Ende wieder heraus, und Escape beendet die Auswahl.

Jetzt die Wörter. Wechseln Sie zu **Inhalt** und setzen Sie im Bedienfeld **Text** die Einfügemarke in die Wiederholungsseite aus Abschnitt 3. Zurück in **Module** nennt die Liste **Seite zum Einfügen** diese Seite; klicken Sie bei *Tree of ideas* auf die Schaltfläche zum Einfügen. Die Sandbox schreibt vor die schließende Zeile der Seite einen Block `:::module{template="tree"}` mit einem leeren Rahmen je Slot. Weil die Vorlage `review` noch keine Gruppe für Module hatte, fügt sie ihr unter dem letzten Rahmen eine hinzu. Schreiben Sie die Wörter in die leeren Rahmen:

```md
:::module{template="tree"}
:::frame{slot="root"}
**A river** gives us
:::
:::frame{slot="branch"}
Water to drink and to water the fields
:::
:::frame{slot="branch"}
Power to turn a mill
:::
:::frame{slot="branch"}
A place to play and to paddle
:::
:::
```

Jedes `:::frame{slot="branch"}` ist ein Ast. Kopieren Sie einen, und die Seite hat vier Kästen und vier Linien; nehmen Sie einen heraus, und sie hat zwei. Der Verbinder nennt `branch[*]`, also jeden Ast, den die Seite hat; die Linien folgen dem Markdown, ohne dass sich am Modul etwas ändert.

<Screenshot src="/docs-shots/de/tree.webp" alt="Das Bedienfeld Gestaltung mit dem Modul Tree of ideas, geöffnet bei der Karte seines Verbinders, und die Wiederholungsseite mit einem Kasten oben, von dem Linien mit Pfeilen zu drei Kästen darunter führen." caption="Der Baum: eine Wurzel, ein Raster, das den Ast wiederholt, und ein Verbinder zu jedem Ast." />

Ein Organigramm ist dasselbe Modul mit anderen Rahmen: eine Karte für die Leitung des Teams, ein Raster, das ein Foto und einen Namen wiederholt, und ein Verbinder im Verlauf Baum zu jeder Karte. Für eine Zeitleiste stellen Sie **Lage des Balkens** auf 0: kein Balken, sondern ein Lot von der Datumsleiste zu jeder Karte.

## 9. Notizen auf einer Karte, mit Zeigern und Legende

Eine Seite mit Notizen rund um eine Karte: Jede Notiz hat eine Linie zu dem Ort, von dem sie spricht, die Karte hat eine Legende zu ihren Zeichen, und ein Name steht abseits seines Punkts, mit einer Linie zurück zu ihm. Keine dieser Linien gehört zum Gemälde.

Das Buch hat das Gemälde zweimal: `mapa` mit den Namen der Seiten 6 und 7, und `rio`, dasselbe Bild ohne Anker, klein auf der Inhaltsseite gesetzt. Diese Seite verwendet `rio`, damit die Punkte, die Sie hinzufügen, keinen Namen der Doppelseite verschieben.

1. Legen Sie eine Seitenvorlage an wie in Abschnitt 2. **ID** `map-notes`, **Name** `Map with notes`. Ihre Rahmen: `title` (**Kastenstil** `portada`, **Nimmt auf** *Ebene 1*), `text` (**Nimmt den freien Text der Seite auf**), `map` (**Breite** *Bis zum Rand*) sowie `note-1`, `note-2` und `note-3` (**Kastenstil** `dato`, **Breite** 56 mm, **Kleinste Höhe** 26 mm). Stapeln Sie `title`, `text` und `map` in einer Gruppe `column` mit 6 mm zwischen den Rahmen, und legen Sie die Notizen in eine Gruppe `notes`, *In einer Reihe*, mit 8 mm dazwischen. Hängen Sie `note-1` an *Rahmen map*, *Unter*, 14 mm tiefer.
2. Schreiben Sie die Seite ans Ende des Kapitels:

```md
::::page{template="map-notes"}
# Along the river

The map shows the valley of the Aldara. Each note tells you about one place on it: follow its line to find the place.

:::figure{resource="rio" slot="map"}
::label[Spring]{at="spring" style="agua"}
:::label{at="key" style="key"}
:icon[]{glyph="●" color="ink"} Town
:icon[]{line="solid" color="agua"} River
:icon[]{line="dashed" color="ink"} Path
:::
:::

:::frame{slot="note-1" label="The dam"}
The dam holds the water back in a lake. In dry months it lets some out, so the river never runs empty.
:::

:::frame{slot="note-2" label="Molinar"}
Molinar grew round its bridge and its mill. The mill wheel turned with the water of the river.
:::

:::frame{slot="note-3" label="Aldamar"}
At Aldamar the river meets the sea. Fishing boats leave the harbour every morning.
:::
::::
```

`:::label{at="key" style="key"}` ist eine mehrzeilige Beschriftung: Jede Zeile ist ein Eintrag der Legende. `:icon[…]{…}` ist ein Symbol in der Zeile: ein Zeichen, ein Linienmuster oder ein Bild des Buchs. Die Schaltfläche **Symbol für eine Beschriftung** in der Werkzeugleiste des Bedienfelds Text schreibt eines an die Einfügemarke, mit Farbe und Größe; in den eckigen Klammern steht, was ein Bildschirmleser dafür sagt, und leere Klammern bedeuten, dass die Wörter daneben schon alles sagen.
3. Geben Sie der Legende ihr Aussehen. Klicken Sie in **Gestaltung › Abbildungen und Tabellen › Beschriftungsstile** auf **Beschriftungsstil hinzufügen**, setzen Sie seine ID auf `key`, seine Schrift auf Fredoka in 10,5 pt, eine weiße **Unterlage** mit einem **Innenabstand der Unterlage** von 2,5 mm, einen **Umriss** und einen **Eckenradius** von 1,5 mm, und schalten Sie unter **Zeilen und Legende** die Option **Legende** ein. Die Symbole stehen dann in einer eigenen Spalte, und die Wörter jedes Eintrags beginnen an einer Kante.
4. Setzen Sie die Punkte. **Prüfungen** meldet *Beschriftung an einem unbekannten Anker* für `spring` und `key`. Klicken Sie bei einem der Einträge auf die Schaltfläche mit der Nadel: Der Dialog Anker von `rio` öffnet sich, mit beiden Namen unter *Beschriftungen ohne Anker*. Klicken Sie für `spring` auf den Wasserfall oben links im Gemälde und für `key` auf die untere linke Ecke; stellen Sie die **Ausrichtung** der Legende auf *Anfang* und ihre **Vertikale Ausrichtung** auf *Unten*, damit sie von ihrem Punkt aus nach oben und nach rechts wächst. Klicken Sie dann auf den Staudamm, die Mühle und den Hafen und nennen Sie die drei neuen Anker in ihren Zeilen `dam`, `mill` und `harbour`.
5. Setzen Sie den Namen der Quelle abseits ihres Punkts. Wählen Sie `spring` und schalten Sie unter **Beschriftung und Hinweislinie** die Option **Abseits des Punkts** ein. Ziehen Sie den Griff der Beschriftung nach oben in den Himmel und stellen Sie **Hinweislinie** auf *An*: Die Linie von der Beschriftung zum Wasserfall wird schon beim Ziehen gezeichnet. Klicken Sie auf **Speichern**.
6. Zeichnen Sie die Zeiger. Wählen Sie im Modus **Gestaltung** auf der Seite `note-1`: Neben der Mitte seiner rechten Seite erscheint ein runder Griff. Ziehen Sie ihn auf den Staudamm; während des Ziehens zeigt die Karte ihre Anker, und beim Loslassen entsteht ein Verbinder von der Notiz zum Anker `dam` mit einem Punkt am Ende. Verfahren Sie ebenso von `note-2` zu `mill` und von `note-3` zu `harbour`. Die Gruppe **Zeiger** des Rahmens listet sie auf; über sie fügen Sie einen Zeiger auch mit der Tastatur hinzu oder ändern ihn.

<Screenshot src="/docs-shots/de/map-notes.webp" alt="Die Seite Along the river im Modus Gestaltung: die Karte mit einer Legende in der unteren linken Ecke, darunter drei Notizen mit je einer Linie zu einem Ort der Karte, und im Bedienfeld Gestaltung die Gruppe Zeiger der zweiten Notiz." caption="Jede Notiz zeigt auf einen Anker des Bilds; die Legende und die Namen sind Zeilen des Markdown." />

Ein Zeiger endet am Punkt des Ankers im Bild, durch Beschnitt und Skalierung hindurch, und findet die Mühle deshalb auch dann noch, wenn die Karte kleiner gesetzt oder auf ihren Sicherheitsbereich beschnitten wird. Er wird über die Rahmen gezeichnet und ist daher über dem Bild zu sehen. Eine Notiz, die stattdessen ohne eigenen Platz auf die Karte gesetzt wird, meldet Prüfungen als *Rahmen unter einem anderen Rahmen*, mit den Lösungen (siehe [Sandbox: zusammengesetzte Seiten](/de/docs/sandbox-composed-pages#überlappungen-und-zeichen-auf-etiketten)).

## 10. Eine Seite mit Fotokarten

Eine Seite mit Karten (Fotos mit einer Legende darunter, Porträts mit einem Namen) ist eine Karte, viele Male gezeichnet. Ein **Raster, das einen Rahmensatz wiederholt**, zeichnet die Karte einmal, und die Seite hat so viele Karten, wie ihr Markdown schreibt.

1. Legen Sie eine Vorlage `photos` an (**Name** `Photo cards`) mit `title` (`portada`, *Ebene 1*) und `text` (der freie Text), gestapelt in einer Gruppe `column`, 6 mm voneinander entfernt.
2. Fügen Sie einen Rahmen `photo` hinzu: **Kastenstil** `foto`, gehängt an *Rahmen text*, *Unter*, 6 mm tiefer. Fügen Sie einen Rahmen `caption` hinzu: **Kastenstil** `dato`, **Breite** *Sein Inhalt*, gehängt an *Rahmen photo*, *Unter*, 2 mm tiefer.
3. Fügen Sie eine Gruppe `cards` hinzu: **Raster**, **Spalten** 3, **Abstand zwischen Spalten** 6 mm, **Abstand zwischen Zeilen** 12 mm. Unter **Eine Rahmengruppe wiederholen** ist der **Hauptrahmen** `photo`; haken Sie `caption` unter **Rahmen, die dazugehören** an. Der Hauptrahmen nimmt die Breite einer Zelle an; die Legende hängt an ihm, so wie die Vorlage sie zeichnet.
4. Schreiben Sie die Seite:

```md
::::page{template="photos"}
# People and the river

People use the river in many ways. Look at the photos and say what each person is doing.

:::frame{slot="photo"}
::resource{id="riego"}

:::frame{slot="caption"}
Watering the fields
:::
:::

:::frame{slot="photo"}
::resource{id="molino"}

:::frame{slot="caption"}
Grinding wheat
:::
:::

:::frame{slot="photo"}
::resource{id="piraguas"}

:::frame{slot="caption"}
Paddling a canoe
:::
:::

:::frame{slot="photo"}
::resource{id="limpieza"}

:::frame{slot="caption"}
Cleaning the banks
:::
:::
::::
```

Jedes `:::frame{slot="photo"}` ist eine Karte, und das `:::frame{slot="caption"}` darin geht in die Legende dieser Karte. Die Karten füllen die Reihen von der Seite aus, an der eine Zeile beginnt, die vierte eröffnet also eine zweite Reihe. Im Modus Gestaltung heißen die Rahmen nach ihrer Karte: `photo[2]` und `caption[2]` sind die zweite Karte.

<Screenshot src="/docs-shots/de/grid.webp" alt="Die Seite People and the river mit vier Fotos in einem Raster aus drei Spalten und einer Legende unter jedem, und das Bedienfeld Gestaltung mit der Gruppe cards: Raster, drei Spalten und Eine Rahmengruppe wiederholen." caption="Die Karte ist einmal gezeichnet; das Markdown gibt vier, und das Raster setzt vier." />

Ein fünftes Foto nimmt die nächste Zelle, ein siebtes beginnt eine dritte Reihe. Eine Ausgabe in einer anderen Sprache kann mit derselben Vorlage mehr oder weniger Karten haben. **Höchstzahl der Einträge** begrenzt das Raster (was darüber hinausgeht, kommt in den freien Text, und Prüfungen meldet *Mehr Einträge, als das Raster fasst*), und **Inhalt, der nicht passt, läuft weiter in** *Eine danach hinzugefügte Seite* am Hauptrahmen trägt die Reihen, die nicht passen, als Ganzes auf eine hinzugefügte Seite.

## 11. Eine Modulbibliothek für eine Reihe

**Seite und Spalten › Module** ist die Modulbibliothek des Buchs. Jedes Modul ist mit seinen Rahmen gezeichnet und mit seiner ID benannt; dazu steht, wie viele Blöcke des Markdown es auf wie vielen Seiten verwenden (*1 Block auf 1 Seite* beim Baum), ein Stift, der es im Vorlageneditor öffnet, und die Schaltfläche, die es in die unter **Seite zum Einfügen** gewählte Seite einfügt. **Neues Modul** beginnt ein weiteres. Wer ein Modul umbenennt, schreibt jeden `:::module`-Block um, der es nennt.

<Screenshot src="/docs-shots/de/modules.webp" alt="Der Abschnitt Module des Bedienfelds Gestaltung: die Liste Seite zum Einfügen, das Modul Tree of ideas mit der Angabe 1 Block auf 1 Seite und die Schaltfläche Neues Modul." caption="Die Bibliothek: jedes Modul, wo das Buch es verwendet, und wie es in eine Seite kommt." />

Eine Seite nimmt Module in einer Gruppe auf, bei der **Nimmt die Module der Seite auf** eingeschaltet ist, untereinander in der Reihenfolge des Markdown. Die nächste Seite kann also einen Baum unter einem Kasten oder zwei Bäume enthalten, ohne neue Vorlage: Das Markdown legt fest, welche Blöcke in welcher Reihenfolge kommen, die Module zeichnen sie.

Module können auch nebeneinander stehen. Stellen Sie **Rahmen** der Modulgruppe auf **In einer Reihe** oder **Raster**, oder fügen Sie eine zweite Gruppe mit **Nimmt die Module der Seite auf** hinzu, wählen Sie die erste unter **In der Gruppe** und haken Sie ihre **Module, die sie aufnimmt** an: Jede Folge dieser Module im Markdown bildet eine Reihe des Stapels. Die **Breite in seiner Gruppe** eines Moduls, in seinem Editor eingestellt, steht in der Bibliothek unter seinem Namen.

Die Bücher einer Reihe (*Our river* für das dritte Schuljahr, *Our coast* für das vierte) teilen sich ihre Module, indem sie sich die Gestaltung teilen:

- **In der Sandbox.** Beginnen Sie das nächste Buch als Kopie dieses Buchs (**Bücher**, **⋯** beim Buch, **Duplizieren**) und schreiben Sie seine Kapitel; Vorlagen, Module und Stile kommen mit der Kopie. Bei einem Buch, das es schon gibt, speichert **Exportieren** im Kopf des Bedienfelds Gestaltung die Gestaltung, und **Importieren** im anderen Buch setzt sie an die Stelle von dessen Gestaltung.
- **Aus dem Code.** Halten Sie die Modulvorlagen in einer Datei und fügen Sie sie den `pageTemplates` jedes Buchs der Reihe hinzu:

```ts
// series/modules.js: the tree and the other modules of the series
export const seriesModules = [
  { id: 'tree', name: 'Tree of ideas', role: 'module', frames: [/* root, branch */], groups: [/* branches */],
    decoration: { elements: [{ kind: 'connector', id: 'connector-1', routing: 'tree', from: { to: '#root' }, to: [{ to: '#branch[*]' }] }] } },
];

// our-coast/config.js
import { seriesModules } from '../series/modules.js';
export const config = { /* … */ pageTemplates: [...seriesModules, ...pagesOfThisBook] };
```

Eine Änderung an einem Modul (eine dickere Linie, ein anderer Kastenstil) erreicht dann beim nächsten Satz jede Seite jedes Buchs, das es verwendet, und die Wörter bleiben im Markdown jedes Buchs.

## Was das Markdown sagt und was die Gestaltung zeichnet

Die Seiten der Abschnitte 8 bis 11 folgen einer Regel. Das Markdown sagt, **was** auf die Seite kommt und **wie viel**: die Wörter jedes Kastens, wie viele Äste, Notizen, Karten und Einträge der Legende, welches Modul zuerst kommt. Die Gestaltung zeichnet jedes Ding **einmal**: die Kästen, ihre Plätze, die Linien zwischen ihnen, das Aussehen der Legende, die Größe einer Zelle. Deshalb braucht eine Übersetzung keine eigene Vorlage, deshalb verwendet eine Seite mit fünf Fotos die Vorlage einer Seite mit vier, und deshalb kann eine Reihe ihre Module teilen. Eine Vorlage enthält nie die Wörter einer Seite, und das Markdown enthält nie eine Position oder eine Farbe.
