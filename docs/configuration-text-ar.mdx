### مواضع الجدولة

يسرد `bodyText.tabStops` المواضع التي تذهب إليها الجدولة: `:tab`، أو محرف جدولة في فقرة لها مواضع (انظر [صيغة المستند › الجدولة ومواضع الجدولة](/ar/docs/document-format-inline#الجدولة-ومواضع-الجدولة) للترميز وطريقة تنضيد السطر). وتستبدل بها `tabStops` في نمط الفقرة لفقراته، و`body.tabStops` في نمط الإطار داخل إطاراته؛ والقائمة الفارغة لا تحدّد أي موضع. وكل موضع `TabStop`:

```ts
bodyText: {
  tabStops: [
    { position: { value: 30, unit: 'mm' } },
    { position: 'end', align: 'end', leader: '.', leaderGap: { value: 2, unit: 'pt' } },
  ],
  tabInterval: { value: 10, unit: 'mm' },
}
```

يضيف `tabInterval` مواضع كل مسافة منه بدءًا من بداية عرض السطر، بعد آخر موضع في القائمة؛ ومن دونه تكون الجدولة التي بعد آخر موضع مسافة بين كلمتين. ومحرف الجدولة المكتوب في النص لا يكون جدولة إلا في فقرة لنمطها مواضع أو مسافة، خاصة به أو مأخوذة من المتن؛ وفي غير ذلك يبقى المسافة بين كلمتين كما كان دائمًا، فيُخرَج المستند المحفوظ كما كان ولا يحتاج إلى تثبيت.

تُفحص المواضع مع بقية الإعدادات (انظر [تحذيرات الإعدادات](/ar/docs/configuration-fonts-colors-viewers#تحذيرات-الإعدادات)): الخاصية غير المعروفة في الموضع (`leaders`) تُصدر التحذير `unknownConfigKey` مع أقرب خاصية إليها؛ والقيمة `align` التي ليست إحدى الكلمات الأربع تُصدر `unknownConfigValue`، ويُنضَّد الموضع بقيمة `'start'`؛ والقيمة `position` التي ليست طولًا ولا `'end'` ولا نسبة مئوية تُصدر `unknownConfigValue` مع `used: 'none'`، ويُستبعد الموضع.

لون خط الإرشاد وخطه هما لون الفقرة وخطها؛ ولا إعداد خاصًا بهما بعد.

### الحروف الاستهلالية

يمكن أن تُفتتح فقرة المتن بحرف استهلالي: يُنضَّد حرفها الأول كبيرًا بجوار أسطرها الأولى، فتقصر هذه الأسطر بمقدار عرض الحرف ومسافة فاصلة، وتُنضَّد كأي أسطر أخرى (تكسرها Knuth–Plass، وتُضبط، وتُقسَّم كلماتها بالواصلة). ويعطي نمطُ الفقرة حرفًا استهلاليًا للفقرة الأولى من كل مجموعة `:::paragraphs` منضَّدة به (ولكل فقرة فيها مع `each: true`، كما في فهرس من المداخل)؛ ويعطيه مستوى العنوان أو نمط العنوان لأول فقرة متن بعد العنوان (انظر الحقل `dropCap` في [تجاوزات كل مستوى](/ar/docs/configuration-headings#تجاوزات-كل-مستوى) و[أنماط الفقرات](/ar/docs/configuration-styles#أنماط-الفقرات) و[أنماط العناوين](/ar/docs/configuration-styles#أنماط-العناوين)). ويُبحث عن الفقرة التي تلي العنوان بتجاوز أسطر فتح الحاويات وإغلاقها، والتوجيهات، والإطارات التي خرجت من التدفق، والأشكال العائمة، كما يفعل `indentAfterHeading`؛ أما الفقرة الواقعة داخل إطار أو عنصر قائمة أو اقتباس أو قصيدة أو حاشية فلا تأخذه أبدًا. وفي النص، تفعّله `{dropcap}` وتعطّله `{dropcap=false}` وتحدّد أسطره `{dropcap=N}` لذلك الفصل أو لتلك المجموعة، حين تُكتب في سطر عنوان أو في سطر فتح `:::paragraphs` (انظر [صيغة المستند › الحروف الاستهلالية](/ar/docs/document-format#الحروف-الاستهلالية)). منذ postext 1.23.

إطار الصفحة المركّبة ليس صندوقًا: إنه نصٌّ جارٍ، وتأخذ فقراته الحرف الاستهلالي كما تأخذه فقرات التدفّق، من مجموعة `:::paragraphs` أو نمط فقرة أو مستوى عنوانٍ في الإطار نفسه (والعنوان الذي يرسله القالب إلى إطار خاص به، `takes: 'h1'`، يعطي الحرف الاستهلالي لمستواه للفقرة التي تليه في Markdown إذا كانت تلك الفقرة أول نص إطار التدفّق، منذ postext 1.39). والمجموعة التي تطلب حرفًا استهلاليًا داخل إطار `:::callout` تُنضَّد بلا حرف استهلالي وتُصدر التحذير `dropCap` (`inBox`). منذ postext 1.38. ولا تُقطع الفقرة التي يفتتحها حرف استهلالي قبل آخر سطر يغطّيه الحرف، لا في سلسلة إطارات (`next`) ولا في إطار يستمر في صفحة أخرى، كما في التدفّق: تنتقل كاملة، ولا تُقطع هناك إلا إذا افتتحت إطارًا أقصر من تلك الأسطر، مع تحذير `dropCap` (`split`). منذ postext 1.39.

```ts
headings: {
  levels: [
    { level: 1, dropCap: { lines: 3, fontFamily: 'Libre Bodoni', fontWeight: 700, color: { hex: '#8b2e2a', model: 'hex', paletteId: 'accent' }, leadIn: { words: 3 } } },
  ],
},
```

كيف يُنضَّد الحرف:

- **الحجم.** يُقاس ارتفاعا الحروف الكبيرة، للنص وللحرف الاستهلالي، من خطّيهما (حبر الحرف `H`؛ وحبر الحرف الاستهلالي نفسه في النص الصيني أو الياباني)، والخط الذي لا يعطي مقاييس الحبر تُحتسب حروفه الكبيرة 0.72 من حجمه. والحجم الافتراضي يناسب أي زوج من الخطوط، فلا حاجة إلى تصحيح لكل خط. أما `dropCap` في النص التصميمي فيحتفظ بقيمته الثابتة 0.72 (انظر [عناصر النص](/ar/docs/configuration-headers-footers#عناصر-النص)).
- **الحرف وكلمته.** يأخذ الحرف الاستهلالي عناقيد حرفية كاملة. ويتابع باقي الكلمة الأولى بعده بلا مسافة؛ والكلمة ذات الحرف الواحد (*A*، *Y*) تحتفظ بالمسافة التي تليها في أول السطر الأول. وتسقط إزاحة السطر الأول الخاصة بالفقرة. ويقرأ النسخُ والبحث وخريطة المصدر ومؤشر الكتابة في Sandbox الفقرةَ كما كُتبت: النص المجرّد للكتلة يشمل الحرف، و`plainStart` للسطر الأول يُعدّ بعده، و`VDTBlock.dropCap` يتضمّن مداه وهندسته في الجزء الذي فيه السطر الأول.
- **الحرف الاستهلالي البارز** (`lines: 1` مع `fontSize` أكبر، أو `sink` أقل من `lines`) يعلو فوق السطر الأول، وتُبقي الفقرة ذلك الارتفاع خاليًا فوقها، بأسطر شبكة كاملة، فلا يُطبع فوق النص الذي يسبقها.
- **القطع.** لا تُقطع الفقرة أبدًا قبل السطر رقم `sink`: بل تنتقل كاملة إلى العمود أو الصفحة التالية، إلا إذا كانت وحدها في عمود فارغ لا يتسع لتلك الأسطر، فتنكسر مع ذلك وتُصدر تحذير `dropCap`. والعنوان المُبقى مع نصه يُبقي تلك الأسطر تحته. والجزء الذي يتابع في العمود التالي لا حرف استهلاليًا فيه، وأسطره بالعرض الكامل؛ وإذا انكسرت الفقرة مرة أخرى لعمود بعرض آخر، احتفظت أسطرها الأولى بإزاحتها. ويجوز لموازنة الأعمدة أن ترخي الفقرة أو تشدّها كأي فقرة أخرى، ولا تضيف أبدًا فراغًا بين الأسطر المقصّرة.
- **أنظمة الكتابة.** تقصر الأسطر من جهة البداية: اليسار في النص اللاتيني، واليمين في العربية والعبرية. والحرف الذي يتصل بما بعده (العربية والسريانية وإنكو) لا يُفصل، وتُطلق الفقرة تحذير `dropCap`؛ وتأخذ الصينية واليابانية الأفقيتان حرفًا استهلاليًا من محرف واحد (首字下沉). ولا يأخذه النص العمودي (مع تحذير). ولا تأخذه كذلك الفقرة التي لا تُفتتح بحرف ولا برقم (إحالة، أو صيغة، أو علامة حاشية) (مع تحذير).
- **المخرجات.** يرسم Canvas وعارض HTML وEPUB ذو التخطيط الثابت الحرفَ الاستهلالي بجوار الأسطر؛ ويكتبه HTML مباشرةً قبل نص السطر الأول بلا فاصل بينهما، فيقرأ قارئ الشاشة الكلمة كاملة. وفي ملف PDF الموسوم يكون الحرف الاستهلالي جزءًا من `P` الخاص بالفقرة، ويكون مع باقي كلمته `Span` قيمة `/ActualText` فيه هي الكلمة: فيقرأ استخراج النص *Long before*، ولا يقرأ *L ong before* أبدًا. ويضبطه EPUB القابل لإعادة التدفق بخاصية CSS `initial-letter` (الأسطر والنزول)، ويجعله عائمًا حيث لا يدعمها نظام القراءة.

تُفحص هذه الإعدادات مع بقية الإعدادات (انظر [تحذيرات الإعدادات](/ar/docs/configuration-fonts-colors-viewers#تحذيرات-الإعدادات)): الخاصية غير المعروفة في الحرف الاستهلالي أو في كلمات استهلاله تُصدر التحذير `unknownConfigKey`؛ وقيمة `punctuation` أو `shortParagraph` التي ليست من قيمها المقبولة، أو قيمة `lines` أو `sink` أو `characters` التي ليست عددًا صحيحًا من 1 فصاعدًا، تُصدر `unknownConfigValue`، وتُستخدم القيمة الافتراضية. والحروف الاستهلالية معطّلة افتراضيًا، فلا يتغيّر أي مستند محفوظ.

### عائلة واحدة لكل `fontFamily`

`fontFamily` — هنا وفي كل حقل آخر لعائلة الخط (`headings.fontFamily`، و`tableStyle.bodyFontFamily`، و`separatorFontFamily`، و`fontFamily` لنمط شارة أو لعنصر تصميم…) — يحدّد عائلة **واحدة**. فمخرجات Canvas وHTML وPDF يجب أن تنضّد شكل الخط نفسه، وPDF يضمّن خطًا واحدًا لكل عائلة بلا سلسلة بدائل، فلا يوجد ما ترجع إليه سلسلة خطوط CSS. والسلسلة تُنضَّد بعائلتها الأولى، ويصدر عنها [تحذير إعدادات](/ar/docs/configuration-fonts-colors-viewers#تحذيرات-الإعدادات):

```ts
bodyText: { fontFamily: "'EB Garamond', Georgia, serif" } // set in EB Garamond
```

حمّل تلك العائلة قبل الإخراج (انظر [الخطوط المخصّصة](/ar/docs/configuration-fonts-colors-viewers#الخطوط-المخصّصة) ومزوّد الخطوط في [إنتاج ملفات PDF](/ar/docs/configuration-pdf-output#توليد-ملفات-pdf))؛ وإن كانت غائبة، يقيس المتصفح بخطه الافتراضي، أيًّا كان ما تقوله بقية السلسلة. الفاصلة داخل علامات التنصيص جزء من الاسم (`'"Foo, Bar"'` عائلة واحدة).
