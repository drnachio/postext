# 印刷封面

**书的印刷版本写在它的`production`设置中；封面的设计是`cover`设置；封面的文字是书中的一篇Markdown文档。**

书页是一回事，包住书页的那张纸是另一回事。封面版面比两个页面还宽：封底、书脊和封面并排在上面，有时还有勒口；每次重印只要页数或纸张变了，它也跟着变。Postext用书的三个部分来做它：

- **生产信息**：书印成的各个版本（平装、精装），每个版本有自己的装订、ISBN和书脊。它属于书，不属于书的设计，书页的排版完全不读它。
- **封面的设计**：底色、图片、色块、标志、文本框和工艺，放在版面的各个区域上。它是设计的一部分，书的所有版本共用，同一丛书的各本书也可以共用。
- **封面的文字**：一篇Markdown文档，每个区域一个块。它留空的封面和书脊，在每次生成时取书的元数据中的书名、副标题和作者，所以改正书名后封面自动更新，不用复制。

封面由排书页的同一个引擎按这三部分排出，PDF带着版面的出血和折线标记交给印厂。

## 书的版本

一个版本就是某一种装订做出来的书。一部小说同时出平装和精装，就是同一套书页上的两个版本：各有自己的装订、ISBN和封面版面。

```ts
import type { PostextConfig } from 'postext';

const config: PostextConfig = {
  page: { width: { value: 150, unit: 'mm' }, height: { value: 230, unit: 'mm' } },
  folio: { paper: { type: 'uncoated', grammage: 90, bulk: 1.3 } },
  production: {
    versions: [
      { id: 'paperback', name: '平装', binding: 'perfect', isbn: '978-84-0000-000-4', flaps: true },
      {
        id: 'hardcover', name: '精装', binding: 'case-flat', isbn: '978-84-0000-001-1',
        flaps: true, // 精装书上即护封
        caseMaterial: 'cloth',
        spineText: { direction: 'topToBottom' },
      },
    ],
  },
};
```

每个版本用配置的id指定装订，也可以直接带上配置本身。各个字段：

- `id`和`name`：如何选择这个版本（命令行的`--print-version`）以及显示的名称。
- `binding`：装订配置（见下文）。
- `isbn`：这个版本的ISBN，ISBN-10或ISBN-13，带不带连字符都可以。一本书的每种装订各有一个ISBN。有效的ISBN会以条码印在封底上。
- `isbnAddOn`：印在条码后面的五位数字。西班牙的附加码不带价格：ISBN机构只允许以9开头的附加码，供出版社自用（`90000`表示无价格）。
- `workIsbn`：整部作品的ISBN，用于丛书中的一卷或多卷本作品的一卷。条码用这一卷的`isbn`，这个ISBN以文字印在条码旁边。
- `flaps`：平装书上是勒口；精装书上是护封。
- `caseMaterial`：精装书壳的材料，`printed`（印好的封面覆膜后裱在纸板上，默认）或`cloth`（布面烫印，通常外加护封）。
- `overrides`：这个版本自己设定、覆盖配置的尺寸（mm），用于印厂对这一本书要求不同中缝等情况。
- `spineOverride`：印厂给出的书脊宽度（mm），代替计算值。
- `spineText`：书脊文字的排法：`direction`为由下往上（`bottomToTop`，西班牙的通常做法，也是默认值）或由上往下（`topToBottom`，ISO 6357推荐的方向）；`minSpine`是能印文字的最窄书脊（默认6 mm）。

`production.collection`指定书所属的丛书或多卷本作品，带它自己的ISBN（以文字印在这一卷的ISBN旁边），以及书目`catalogue`，每一项有`id`、`title`和可选的图片`resource`，用于环衬。

### 装订配置

装订配置描述一家印厂如何装订：一种装订样式、它的尺寸以及能做什么。Postext为每种样式自带一个通用配置，按16页一个印张计算：

这些配置的尺寸取自印厂和装订厂公开的规格；各家说法不一时，取多数给出的数值。它们只是起点。印厂自己的数据放在书的配置中，即`production.bindings`，它随书一起走，文件包在别处打开时也能找到：

```ts
production: {
  bindings: [{
    id: 'my-printer-perfect',
    name: '胶装，我的印厂',
    printer: 'Gráficas Ejemplo',
    style: 'perfect',
    signature: 32,
    measures: { bleed: 5, hingeScore: 7, flapWidth: { ratio: 0.6, of: 'width', min: 70, max: 110 } },
    accepts: { trim: { max: { width: 240, height: 320 } }, spine: { min: 4, max: 45 } },
  }],
  versions: [{ id: 'paperback', name: '平装', binding: 'my-printer-perfect' }],
},
```

- `style`：`perfect`、`sewnSoftcover`、`caseFlat`或`caseRound`。
- `signature`：每个印张的页数。计算书脊时页数向上补足为整数个印张，检查会说明因此增加了多少空白页。
- `measures`：没写的尺寸取该样式的默认值。
- `accepts`：印厂能装订的最小和最大成品尺寸（`trim.min`、`trim.max`，各有以mm计的`width`和`height`），以及最窄和最宽的书脊（`spine.min`、`spine.max`）。超出范围的书会得到一条检查，而不是一个没人能装订的封面。

所有尺寸都以mm计，有三种写法，好让一个配置适用于各种开本：

- **一个数**：任何开本都一样（例如3 mm的飘口）。
- **分档**：一个`{ upTo: { width, height }, mm }`列表，取成品尺寸能放进其`upTo`的第一档；最后一档不写`upTo`，用于更大的开本。大开本书要加厚纸板的印厂就这样写。
- **成品尺寸的比例**：`{ ratio, of, min, max }`，成品`width`（默认）或`height`的一个比例，限制在`min`和`max`之间。勒口通常这样写。

### 纸张与书脊

书脊等于书页的厚度加上装订的余量。一张纸（两页）的厚度是纸张克重乘以松厚度，单位为微米：90 g/m²、松厚度1.3的纸，一张厚0.117 mm。页数是排好的书的页数，向上补足为整数个印张。每一页按它自己的纸张计算：书的纸张是`folio.paper`，用另一种纸的一段页面（`:::paper`块、一组铜版纸插页）按自己的纸张计算，规则与[Folio](/zh/docs/configuration-html-folio-epub)显示书本时相同。

所以书脊跟着书走。一次修改增加了一个印张，书脊就变宽，版面也变宽，放在封面或封底上的每个元素都随所在区域移动。印厂量了样书给出数字时，用`spineOverride`设定它，检查会同时记下两个数。书脊窄于`spineText.minSpine`时不印文字。

书用到的纸张也可以保存为配置，放在`production.papers`中：Folio认识的纸种（`type`、`grammage`、`bulk`，以及表面和色调），加上`id`、`name`、供应商`supplier`和商品名`commercialName`。

### 在书之间传递配置

装订配置和纸张配置可以在书之间、在人之间传递，形式是一个`.postext-production.json`文件。`exportProductionProfiles(papers, bindings)`写出这个文件，`importProductionProfiles(data)`把它读回来，并报告略过了哪些条目及原因。沙盒的封面面板有这两个按钮。

## 版面及其区域

版面由并排的几块区域（zone）组成，每块就是版面折好后的某个部分：

    <tr><th>版面</th><th>区域，从左到右</th></tr>
  </thead>
  <tbody>
    <tr><td>平装封面</td><td><code>flapBack</code>（有勒口时）、<code>back</code>、<code>spine</code>、<code>front</code>、<code>flapFront</code>（有勒口时）</td></tr>
    <tr><td>书壳</td><td><code>back</code>、<code>jointBack</code>、<code>spine</code>、<code>jointFront</code>、<code>front</code>，四周有包边</td></tr>
    <tr><td>护封</td><td><code>flapBack</code>、<code>back</code>、<code>spine</code>、<code>front</code>、<code>flapFront</code></td></tr>
    <tr><td>环衬</td><td><code>pastedown</code>、<code>hinge</code>、<code>flyleaf</code></td></tr>
  </tbody>
</table>

平装版本只有一张版面，就是封面。精装有书壳；`flaps`打开时还有护封；另有前环衬和后环衬。从右到左排的书（以及右侧装订的书：竖排的中文或日文书，或设了`page.binding: 'right'`的书）版面是镜像的：封面在左，封底在右。竖排书的各区文字竖排，书脊文字顺着书脊向下排，不旋转，因此`spineText.direction`不起作用。

每个区域内有安全区，距每条折线和裁切线`safeMargin`，书脊横向另有更窄的边距。沙盒在版面上画出折线、压痕和安全区；PDF在出血外的辅助区画出折线标记。

## 封面的设计

`cover`设置是封面的设计。和设计的其他部分一样，它不规定封面上写什么，只规定封面的样子，也不改变书页的排版：

```ts
cover: {
  background: { hex: '#1f3f99', model: 'hex' },
  image: { resourceId: 'cover-art', area: 'front', focus: { x: 0.5, y: 0.35 } },
  zones: { spine: { hex: '#14295f', model: 'hex' } },
  verticalAlign: { front: 'bottom', back: 'middle' },
  barcodeMagnification: 0.9,
  mirrorMargin: 5,
},
```

- `background`：整张版面的底色。
- `image`：书中的一张位图或SVG资源，铺满整张版面（`area: 'sheet'`，默认）或只铺满封面（`'front'`），以`focus`（图片的比例坐标）为中心裁切。
- `zones`：每个区域的底色，叠在版面的底色和图片之上。
- `verticalAlign`：每个区域的文字在区域中的位置：`top`（默认）、`middle`或`bottom`。书脊的文字总是横向居中。
- `barcodeMagnification`：条码相对于标准尺寸的大小，0.8至2（默认1）。低于0.8时按0.8设置，检查会说明。
- `mirrorMargin`：镜像出血（见下文）。

### 元素、效果和标志

在底色之上，设计放置三个项目列表，每个列表从后往前画：`elements`在文字下方，`effects`在文字上方，`logos`在最上面。一个项目是一张图片（`kind: 'image'`，带`resourceId`）、一个色块（`'box'`）或一个色形（`'shape'`），并有一个由字母、数字、`-`和`_`组成的`id`。

项目按所在区域定位，所以书脊变宽或装订改变时，它随区域移动：

```ts
elements: [
  { id: 'band', kind: 'box', zone: 'back', x: -3, y: 180, width: 0, height: 24,
    to: { zone: 'front', x: 153 }, color: { hex: '#d8a21b', model: 'hex' } },
  { id: 'seal', kind: 'shape', zone: 'front', x: 100, y: 20, width: 30, height: 30,
    basis: { width: 150, height: 230 }, color: { hex: '#ffffff', model: 'hex' }, opacity: 0.8,
    path: [{ closed: true, nodes: [{ x: 0.5, y: 0 }, { x: 1, y: 1 }, { x: 0, y: 1 }] }] },
],
logos: [{ id: 'publisher', kind: 'image', zone: 'spine', x: 1, y: 205, width: 8, height: 12,
  resourceId: 'logo', clearance: 2 }],
```

- `zone`、`x`、`y`、`width`、`height`：它的框，以mm计，从区域左上角算起。它可以超出区域，伸到相邻区域或出血里。
- `basis`：放置它时所在区域的尺寸。书的开本变了或书脊变宽，区域尺寸不同时，项目随之缩放：色块和色形在两个方向上分别缩放，图片以中心为基准等比缩放。不写时，项目保持放置时的样子。
- `to`：跨区域的色块或色形，比如从封底贯穿到封面的色带：它的右边缘，以mm计，从它结束的区域的左边算起（`to.zone`、`to.x`），以及放置时那个区域的宽度（`to.basis`）。这样两条边各自跟随自己的区域。
- `color`和`opacity`：色块或色形的颜色，以及任何项目的不透明度（0至1）。图片保留自己的透明度。
- `fit`：图片如何填充它的框：完整放在框内（`contain`，默认）或铺满框并裁切（`cover`）。
- `path`：由节点画出的形状，坐标是框的比例（0, 0为左上角；1, 1为右下角），所以形状随框伸缩。每一部分有自己的`nodes`，是闭合的（`closed`）或开放的；节点有`x`和`y`，以及进入它的曲线控制柄（`in`）和离开它的控制柄（`out`）。
- `outline`：从图片描出的闭合多边形，坐标是框的比例，用于做成图片形状的半透明层或工艺。
- `clip`：按轮廓裁切的图片，使图片只在插图自身的形状内显示。
- `bleed`：超出镜像出血的设计边距之后，`mirror`（默认）让项目随底色镜像出去；`own`按原样绘制，盖在镜像之上。
- `clearance`（标志）：标志四周不许别的东西进入的空白，以mm计。

色块或色形还可以带上页面框样式画不出的效果：`radius`是圆角半径（mm），`stroke`是边框（`color`和以mm计的`width`），`gradient`是从它的颜色渐变到`to`，角度为`angle`度（0：从左到右；90：从上到下），`shadow`是阴影（`color`、`opacity`、以mm计的偏移`x`和`y`，以及柔和程度`blur`）。有渐变或阴影的项目会变成单独的一张图片，按PDF的分辨率绘制。

### 镜像出血

封面的画面通常止于裁切线，而精装书壳的包边要越过裁切线15 mm，绕到纸板背面。设置`mirrorMargin`后，设计画到裁切线外这么多mm（至少2），再往外，底色和元素以镜像方式延伸到版面边缘，这样包边和出血接续画面，而不是露出一条空白。配置中的`designMargin`给出印厂期望的边距。标为`bleed: 'own'`的元素不做镜像。

### 文本框

每个区域本身就是一个文本框。`textBoxes`添加手动放置的框，用于封面上的一段引语、书脊底部的一行字或图片上的说明：

```ts
textBoxes: [
  { name: 'praise', rect: { x: 18, y: 30, width: 110, height: 40 }, verticalAlign: 'middle' },
  { name: 'spine-foot', rect: { x: 158, y: 200, width: 6, height: 25 }, rotate: -90 },
],
```

- `name`：字母、数字、`-`和`_`，不能与区域同名。封面的Markdown按这个名称填充文本框。
- `rect`：它在版面上的位置，以mm计，从出血的角算起。
- `rotate`：`-90`把文字转四分之一圈，沿书脊由下往上读；`90`由上往下读。
- `verticalAlign`：`top`、`middle`或`bottom`。

### 工艺与技术印版

`finishes`是印厂在印完油墨后加上的工艺，每一项作用在设计中的一个形状上：

```ts
finishes: [
  { id: 'title-foil', process: 'foil', sheen: 'gloss', shape: { element: 'seal' } },
  { id: 'spot-uv', process: 'varnish', shape: { box: { zone: 'front', x: 0, y: 0, width: 150, height: 120 } } },
  { id: 'relief', process: 'emboss', shape: { element: 'publisher' } },
],
```

- `process`：`varnish`（上光）或`foil`（烫印），印在单独的专色印版上（带[工艺](/zh/docs/special-inks-die-cuts#工艺)的油墨）；或者`emboss`（凸印）或`deboss`（凹印），用压凸版。
- `ink`：上光或烫印的专色。默认上光为`Varnish`，烫印为`Gold foil`。
- `sheen`：`gloss`（亮光，默认）、`satin`、`matte`或`softTouch`。
- `shape`：工艺覆盖的范围：一个单独的框（`{ box }`，与元素的放法相同），某个元素、效果或标志的形状（`{ element: id }`；资源有轮廓时就是图片的轮廓），或者放在单独框中的已保存轮廓（`{ outline, box }`）。

凸印和凹印不印任何东西。它的形状放在一块技术印版上交给印厂，和[模切线](/zh/docs/special-inks-die-cuts#pdf中的模切线)放在一起：一个名为`Emboss`或`Deboss`的`Separation`，印前检查会列出它，任何打样都不绘制它。装订厂据此制作压凸版。

## 封面的文字

封面的文字是书中的一篇Markdown文档，和各章放在一起。每个块按名称填充一个区域或一个文本框：

```md
:::frame{slot="back"}
一座把书藏在地下的城市，和一个为人朗读这些书的女孩。

:::paragraphs{style="cover-praise"}
“一部让人一口气读完的小说。”——《某报》
:::
:::

:::frame{slot="flapFront"}
**安娜·佩雷斯**，1984年生于萨拉戈萨。《地下图书馆》是她的第二部小说。
:::

:::frame{slot="praise"}
*首部小说奖获奖作品*
:::
```

文字按书的字体排印设置排出：书的段落样式、字符样式和字体。有四个段落样式是封面专用的，书可以重新定义它们：`cover-title`、`cover-subtitle`、`cover-author`和`cover-spine`。Markdown留空的封面和书脊，每次生成时取书的元数据中的书名、副标题和作者，用这些样式排出：它们从不复制到封面的文字中。`front`或`spine`框用自己的文字代替它们。

版面上没有的槽位（没有勒口的版面上的勒口、环衬上的封底）的框会被略去，检查会说明；同一个槽位的第二个框也会被略去。封面的文字请用段落和段落样式来写：`#`标题会套用书给章标题的设计。

一份封面文字适用于所有版本和所有版面。多语言的书可以给每种语言各写一份。

## 在沙盒中

侧栏中的**封面**面板管理印刷版本及其封面：

- **版本**：**添加平装**或**添加精装**，然后是每个版本的名称、装订、ISBN、附加码和全套ISBN，勒口或护封，书壳的材料，印厂给定的书脊，书脊文字的方向以及能印文字的最窄书脊。**此版本的尺寸**只为这个版本覆盖配置中的尺寸。
- **版面**：显示哪张版面（封面、护封、前环衬或后环衬），以及它的页数、书脊和尺寸。
- **在版面上设计**：**在版面上编辑**把版面变成设计器。文本框、色块、半透明层、图片、标志和工艺从它的工具栏添加，在版面上拖动和调整大小，吸附到折线、安全区和彼此（按住Alt关闭吸附）。方向键把所选项目移动1 mm，按住Shift移动10 mm。**图层**列出文字下方的项目、文本框、文字上方的项目、标志和工艺，并调整它们的顺序。所选项目的字段设置它的位置、颜色、不透明度、图片如何填充框、圆角半径、边框、渐变和阴影、超出镜像出血后的处理、是否随区域缩放，以及它的路径、轮廓或裁切。给文本框改名时，它在封面Markdown中的文字随之移动。
- **文字**：每个区域和每个文本框一个Markdown编辑器。封面和书脊显示它们从元数据取来的内容，直到给它们**自定文字**为止。
- **丛书**：丛书的名称和ISBN。
- **印厂文件**：**下载版面PDF**，按书的PDF设置（色彩空间、输出配置文件、PDF/X）写出；**下载封面图**，以图片形式下载封面。
- **检查**：上面列出的检查。
- **印厂配置**：从内置配置复制并按印厂尺寸调整的装订配置，每个尺寸可以按毫米、按成品尺寸的比例或按开本分档设定，并显示对这本书的实际数值；带供应商和商品名的纸张配置；以及用于`.postext-production.json`文件的**导出配置**和**导入配置**。

版面设计面板的**封面设计**分组包含底色、图片、各区域文字的对齐方式、条码大小和镜像出血。封面面板中的每次修改都是撤销历史中的一步。

封面用的图片常常是印刷文件。资源面板把PDF或以PDF兼容方式保存的Illustrator文件读成每页一张图片，300 ppi，透明背景；TIFF和PSD文件保持原始尺寸。EPS文件无法读取：面板会提示把它另存为PDF。

## 在命令行中

`postext cover`排出一个版本的一张版面：

```bash
postext cover book.postext -o cover.pdf
postext cover book.postext --print-version hardcover --sheet jacket -o jacket.pdf
postext cover book.postext -o front.jpg --dpi 300
```

`--print-version`选择版本（默认第一个），`--sheet`选择版面（`cover`、`jacket`、`endpaper-front`或`endpaper-back`）。路径以`.png`、`.jpg`或`.webp`结尾，或给出`--format`时，画出一个区域而不是写PDF：默认是封面，除非`--zone`指定别的区域（`back`、`spine`、`flapFront`、`flapBack`，或表示整张版面的`sheet`）。PDF选项（`--color-space`、`--pdfx`、`--profile`等）的用法与`postext pdf`相同。见[命令行](/zh/docs/command-line)。

## 在代码中

`postext/production`包含封面的整条流程。`buildCover`接受书的配置、一个版本、排好的书页（用于计算书脊）、封面的Markdown、元数据和资源，返回一个只有一页的文档形式的封面：

```ts
import { buildDocument } from 'postext';
import { buildCover } from 'postext/production';
import { renderToPdf } from 'postext-pdf';

const book = buildDocument(content, config);
const cover = buildCover({
  config,
  version: 'paperback',
  pages: book.pages,
  markdown: coverMarkdown,
  metadata: content.metadata,
  resources: content.resources,
  sheet: 'cover',
});
if (!('config' in cover)) throw new Error(cover.issues.map((i) => i.kind).join(', '));

const doc = buildDocument(cover.content, cover.config);
const pdf = await renderToPdf([doc], {
  fontProvider,
  resourceBytes: (fileId) => cover.files[fileId] ?? bookFiles[fileId],
});
```

`cover.sheet`给出版面的尺寸和各区域（mm），`cover.sheets`给出这个版本的每张版面及其书脊，`cover.issues`给出检查结果。`pages`也可以是一个页数，全部按书的纸张计算。

模块的其余部分开放了每一步：

- **ISBN**：`parseIsbn`读取并校验ISBN，`isbnBarcodeSvg`画出带附加码的EAN-13条码，`ean13CheckDigit`和`isbnCaption`负责其余部分。
- **尺寸与版面**：`resolveBindingMeasures`算出配置在某个成品尺寸下的各项尺寸，`resolveLength`算出单项尺寸，`checkProfileAccepts`检查限制；`spineFromRuns`、`pageRunsOf`、`signaturePages`和`leafMm`计算书脊；`softcoverSheet`、`caseSheet`、`jacketSheet`和`endpaperSheet`生成各种版面，`versionSheets`生成一个版本的全部版面。
- **设计**：`coverPage`组成版面的页面模板，`coverSource`生成用来排版的Markdown，`coverZoneBox`给出区域的框，`placeCoverElement`和`coverElementRect`给出项目的位置，`basicShape`、`pathData`和`flattenCoverPath`处理它的形状。
- **配置与设置**：`BUILT_IN_BINDING_PROFILES`、`DEFAULT_BINDING_MEASURES`、`DEFAULT_SPINE_TEXT`、`exportProductionProfiles`、`importProductionProfiles`和`readProductionConfig`；最后这个从不可信的数据中读取`production`块，并报告丢弃了什么。
- **Folio**：`folioOfBook`给出带第一个版本装订方式的Folio设置，`productionFolioBinding`和`folioVersionOf`给出所选版本的设置。

## 在`.postext`文件中

文件包在配置中带有`production`和`cover`设置，封面的文字作为`cover.md`放在各章旁边。某种语言有自己的封面文字时，存为`cover/<language>.md`。`openBundle`（来自`postext/bundle`）以`coverMarkdown`返回它，`createBundle`也以同样的方式接收。见[文件包](/zh/docs/configuration-bundles)。

## Folio与EPUB

Folio视图按书的第一个版本装订：无线胶装或锁线平装显示为平装，书壳显示为精装，书脊上画着封面的书脊。命令行或沙盒写出的EPUB，在书有印刷版本且没有指定其他封面图片时，用印刷封面的封面部分作为封面图片。

## 限制

- 书脊按排好的页数计算。封面做好之后书页又有变化，就要重新生成封面；书脊和各个区域会自动跟上。
- 默认尺寸是取自公开规格的起点。请向印厂要他们的数据，并保存在配置中。
- 只写出PDF和图片格式，不写出封面版面的IDML包。
- 封面文字中的`#`标题会套用书的章标题设计；封面上的标题请用段落样式。
