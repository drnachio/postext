# 設定

**Postextのレイアウトに関する判断は、すべて1つの設定オブジェクトで決まります。**

`PostextConfig`は、ページの寸法、段組み、本文の文字組み、見出しのスタイル、文書の言語（`locale`）などを制御します。プロパティはすべて省略できます。Postextには伝統的な書籍組版にならった無理のない既定値が用意されているので、指定するのは変えたい項目だけで済みます。

```ts
import { buildDocument } from 'postext';

const document = buildDocument(content, {
  page: { sizePreset: '21x28', dpi: 300 },
  layout: { layoutType: 'double', gutterWidth: { value: 0.5, unit: 'cm' } },
  bodyText: { fontFamily: 'EB Garamond', fontSize: { value: 9, unit: 'pt' } }, // 9 pt overrides the 8 pt default
  headings: { fontFamily: 'Open Sans' },
});
```

エンジンがこの設定をどう処理するかの概要は、[アーキテクチャー](/ja/docs/architecture)のページを参照してください。


## 内容一覧

このリファレンスは9つのページに分かれています。以下の各グループが1つのページで、その下にそのページの節を挙げます。

**[ページとレイアウト](/ja/docs/configuration-page-layout)**

- [ページ](/ja/docs/configuration-page-layout#ページ)：サイズ、余白、ベースライングリッド、トンボ、[綴じ](/ja/docs/configuration-page-layout#綴じ)。
- [レイアウト](/ja/docs/configuration-page-layout#レイアウト)：段数、段間、段間罫、[縦組み](/ja/docs/configuration-page-layout#縦組み)。
- [柱とノンブル](/ja/docs/configuration-page-layout#柱とノンブル)：ページごとに置くテキスト要素と罫線要素。プレースホルダー、奇偶、そろえ位置を指定できます。

**[本文と見出し](/ja/docs/configuration-text)**

- [本文](/ja/docs/configuration-text#本文)：文字組み、ハイフネーション、タブ位置、オーファンとウィドウ。
- [文書の言語](/ja/docs/configuration-text#文書の言語)：最上位の`locale`。ハイフネーションのフォールバック、組み込みのリソースタイプ、表と分割された囲みの続きを示す文字列、アクセシブルなPDFにタグ付けされる言語を決めます。そこから導かれる[数字](/ja/docs/configuration-text#文書の数字)（`numerals`）と[テキストの方向](/ja/docs/configuration-text#テキストの方向)（`direction`）、Postextが組める[言語と文字体系](/ja/docs/configuration-text#言語と文字体系)もここで説明します。右から左に組む本のガイドは[アラビア語の組版](/ja/docs/arabic-layout)です。
- [見出し](/ja/docs/configuration-text#見出し)：共通の既定値と、H1〜H6ごとの上書き。
- [箇条書きリスト](/ja/docs/configuration-text#箇条書きリスト)と[番号付きリスト](/ja/docs/configuration-text#番号付きリスト)：行頭記号、番号付け、入れ子。
- [数式](/ja/docs/configuration-text#数式)：LaTeXの描画、倍率、色、余白。

**[注と参照](/ja/docs/configuration-notes-references)**

- [脚注](/ja/docs/configuration-notes-references#脚注)：`footnotes`。`[^id]`で引いた注を置く場所、番号の付け方、見た目。
- [行番号](/ja/docs/configuration-notes-references#行番号)：`lineNumbers`。詩の行や本文の5行ごとの番号を余白に印字します。数える行、数え直す位置、番号を置く側。
- [相互参照](/ja/docs/configuration-notes-references#相互参照)：`crossRefs`。`:ref`の番号やページの前後に印字する語と、その既定のスタイル。
- [引用](/ja/docs/configuration-notes-references#引用)：`citations`。引用スタイルと、引用および参考文献の見た目。
- [目次](/ja/docs/configuration-notes-references#目次)：`:::toc`が出力する内容。項目の文字組み、リーダー、ページ番号、著者の行、部の行。
- [索引](/ja/docs/configuration-notes-references#索引)：`:::index`が出力する内容。項目の文字組み、字下げ、ページ番号の区切りと範囲、頭文字ごとのグループ、並べ替えの言語。

**[東アジアの組版](/ja/docs/configuration-east-asian)**

- [東アジアの組版](/ja/docs/configuration-east-asian#東アジアの組版)：`cjk`。中国語・日本語・韓国語のテキストの地域ごとの慣習と行分割、両端そろえの行の空け方、約物の幅とぶら下げ、漢字とラテン文字の間のスペース、文字グリッド、縦組みでの数字の正立、そして圏点、ルビ、割注、漢文の訓点。全体のガイドは[中国語の組版](/ja/docs/chinese-layout)と[日本語の組版](/ja/docs/japanese-layout)です。

**[リソースと表](/ja/docs/configuration-resources)**

- [リソースの種類](/ja/docs/configuration-resources#リソースの種類)：図、表、独自の種類に付ける種類別の番号。
- [表スタイル](/ja/docs/configuration-resources#表スタイル)（[名前付きの表スタイル](/ja/docs/configuration-resources#名前付きの表スタイル)を含む）と[キャプションスタイル](/ja/docs/configuration-resources#キャプションスタイル)：表リソースとそのキャプションの文字組みと装飾。
- [ダイアグラムスタイル](/ja/docs/configuration-resources#ダイアグラムスタイル)：特色印刷のために、埋め込んだSVGのダイアグラムを単色に塗り替えます。
- [動画スタイル](/ja/docs/configuration-resources#動画スタイル)：`videoStyle`。動画のポスターに重ねる再生マークとQRコード、HTMLビューアーとEPUBでプレーヤーが備える機能。

**[スタイルと部](/ja/docs/configuration-styles)**

- [段落スタイル](/ja/docs/configuration-styles#段落スタイル)：`:::paragraphs`コンテナー用の名前付きスタイル。参考文献、用語集、注記などに使います。
- [チップスタイル](/ja/docs/configuration-styles#チップスタイル)：`chipStyles`。行内の`:chip[…]`用の名前付きスタイル。語群の枠、キーボードのキー、タグなどに使います。
- [コードリスト](/ja/docs/configuration-styles#コードリスト)：`codeStyle`。```` ``` ````のコードリストの書体、枠、タブ幅、長い行、行番号、字句の色、構文の色分けとそのハイライタのフック、そしてコードの書体で組むインラインコード。
- [囲みスタイル](/ja/docs/configuration-styles#囲みスタイル)：`:::callout`コンテナー用の、枠で囲んだ注記、ヒント、学習目標。
- [部](/ja/docs/configuration-styles#部)：`:::part`コンテナー用の部扉ページ。奇偶、本文領域、扉のデザイン、本文の文字組み。
- [見出しスタイル](/ja/docs/configuration-styles#見出しスタイル)：`{style="…"}`を付けた見出し用の名前付きスタイル。番号のない章や、独自の柱、ジオメトリー、パレットを持つ前付けに使います。

**[漫画の設定](/ja/docs/configuration-comics)**

- [漫画](/ja/docs/configuration-comics#漫画)：`comics`。漫画のページの枠と間白、コマのスタイル、写植、吹き出しのスタイル、登場人物。ガイドは[漫画](/ja/docs/comics)です。

**[フォント、色、出力](/ja/docs/configuration-fonts-colors-viewers)**

- [単位と色](/ja/docs/configuration-fonts-colors-viewers#単位と色)、[カラーパレット](/ja/docs/configuration-fonts-colors-viewers#カラーパレット)：`Dimension`、`ColorValue`、名前付きの色。
- [カスタムフォント](/ja/docs/configuration-fonts-colors-viewers#カスタムフォント)：ユーザーがアップロードしたフォントファミリーを、Google Fontsと並べて宣言します。
- [HTMLビューアー](/ja/docs/configuration-fonts-colors-viewers#htmlビューアー)：HTMLバックエンドの目標段幅と行分割。
- [PDF生成（設定）](/ja/docs/configuration-fonts-colors-viewers#pdf生成設定)：PDFバックエンドのしおり、アクセシブルな（タグ付きの）出力、色空間の強制。
- [印刷出力（設定）](/ja/docs/configuration-fonts-colors-viewers#印刷出力設定)：`print`の設定。PDF/X-1aとPDF/X-4、ICC出力プロファイル、黒の扱い（K版のみのグレー、オーバープリント、リッチブラック）、CMYKで指定した色、プリフライト、印刷プレビュー。
- [Folioビューアー（設定）](/ja/docs/configuration-fonts-colors-viewers#folioビューアー設定)：3Dの本のビューアーの用紙、綴じ、表面、光。
- [デバッグ](/ja/docs/configuration-fonts-colors-viewers#デバッグ)：エディター用の視覚的なオーバーレイと、執筆中の警告。

**[プログラムからの利用](/ja/docs/configuration-programmatic-usage)**

- [プログラムからの利用](/ja/docs/configuration-programmatic-usage#プログラムからの利用)：`buildDocument`とそれが報告する警告、リゾルバー、キャッシュ。
- [Web Workerでレイアウトを実行する](/ja/docs/configuration-programmatic-usage#web-workerでレイアウトを実行する)：キャンセルできる、メインスレッド外でのビルド。
- [HTMLビューアーの統合](/ja/docs/configuration-programmatic-usage#htmlビューアーの統合)と[PDFの生成](/ja/docs/configuration-programmatic-usage#pdfの生成)：最初から最後まで通した実例。
- [3Dの本（`postext-folio`）](/ja/docs/configuration-programmatic-usage#3dの本postext-folio)：組み上がった文書を、机の上に開いて置いた印刷本として表示します。読者はページをめくれます。
- [EPUBの本](/ja/docs/configuration-programmatic-usage#epubの本postext-epub)：同じレイアウトから作る固定レイアウトとリフロー型のEPUB 3ファイルと、EPUBCheckによる検査。
- [バンドル（`.postext`ファイル）](/ja/docs/configuration-programmatic-usage#バンドルpostextファイル)：本をまるごと1つのファイルに収めます。コードから`.postext`アーカイブを作成し、開き、ビルドします。
