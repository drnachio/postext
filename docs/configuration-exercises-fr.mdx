# Configuration : exercices


## Styles d’exercice

La propriété `exerciseStyles` déclare les styles nommés qu’un exercice choisit avec `:::exercise{style="…"}`. Un style est la forme d’une famille d’exercices ; les questions et les réponses restent dans le Markdown (voir [Exercices](/fr/docs/exercises)). Un style, `exercise`, est fourni par défaut : le délimiteur fonctionne donc sans aucune configuration. Déclarer `exerciseStyles` le remplace, et le premier style déclaré est celui que prend un exercice sans `style`. Tous les champs sont facultatifs, et les valeurs par défaut suivent la langue du document là où les usages scolaires diffèrent : lettres des propositions, lettres vrai/faux, disposition de la division posée, mots imprimés.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activite',
      box: 'cadre-activite',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'seyes', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { binome: { glyph: '👥' } },
    },
    { id: 'qcm', extends: 'activite', options: { layout: 'row', columns: 4 } },
  ],
};
```

### Numéro

`number` règle le numéro de l’exercice. Un numéro nu est en gras, dans la couleur principale, suivi d’un point ; un numéro dans une forme est un chiffre blanc dans un disque, un carré ou un carré arrondi de la couleur principale, sans rien après.

L’écran peut avoir ses propres réglages d’exercices : `htmlViewer.overrides` accepte aussi `exercises` et `exerciseStyles`, fusionnés avec ceux du livre avant la mise en page de la visionneuse HTML.
```ts
const config: PostextConfig = {
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [{ id: 'exercise', area: { kind: 'none' }, blank: { minWidth: { value: 6, unit: 'em' } } }],

  },
};
```

### Évaluation

Par défaut, un exercice sert à s’entraîner : le lecteur vérifie autant de fois qu’il le veut, recommence et regarde la solution. Quatre réglages en font un contrôle, pour le livre dans `exercises.digital` et pour un style dans son `digital`, qui l’emporte pour les exercices de ce style :

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** compte les appuis sur Vérifier pendant une tentative. Le bouton indique combien il en reste (« Vérifier (encore 2) ») ; une fois qu’ils sont épuisés, il affiche « Plus de vérifications », les réponses se verrouillent et le score reste sur la barre.
- **`reset`** et **`maxResets`** : Recommencer efface les réponses et ouvre une nouvelle tentative, qui retrouve toutes ses vérifications. `maxResets: 1` permet de recommencer une fois, soit deux tentatives en tout, et le bouton indique combien il en reste ; `reset: false` retire le bouton.
- **`showSolution`** : `'always'` ; `'afterCheck'`, une fois la tentative vérifiée ; `'noChecksLeft'`, une fois ses vérifications épuisées ou toutes ses réponses vérifiées justes ; `'never'`. Tant que les vérifications sont limitées, afficher la solution met fin à la tentative.
- **`passingScore`** est le seuil par rapport auquel un paquet SCORM indique réussi ou échoué (voir [Paquets SCORM](/fr/docs/configuration-html-folio-epub#paquets-scorm-postext-scorm)).

Les mots des boutons suivent la langue du document. Avec `check: 'instant'`, il n’y a pas de bouton Vérifier : `maxChecks` ne s’applique donc pas, mais les autres réglages s’appliquent. Les vérifications et les recommencements déjà utilisés sont conservés avec les réponses : dans un LMS, un paquet SCORM les garde dans le LMS, et ils valent sur n’importe quel appareil ; dans une page HTML ou un livre EPUB, ils restent dans le navigateur du lecteur, et un lecteur qui efface les données du navigateur repart de zéro.
