# Sandbox：エージェント、埋め込み、プリセット


## エージェント：WebMCP

Sandboxは、[WebMCP](https://webmachinelearning.github.io/webmcp/)（`document.modelContext`）を通じて、ブラウザーで動くエージェントに専用のツールを渡します。アシスタントは画面をクリックしてたどる代わりに、本そのものを直接扱えます。設定は要りません。Sandboxが画面にある間はツールが登録されており、このサイトのほかのページもそれぞれいくつかのツールを登録します（ドキュメントとレシピ集の検索、ページをMarkdownとして読む、レシピをSandboxで開く、言語とテーマの切り替え）。

ツールは、デザイナーが目で確かめながら繰り返す手順、つまり「変える、ページを見る、また変える」のために作られています。

- **見る** — `sandbox_get_state`, `sandbox_render_page`, `sandbox_inspect_pages`, `sandbox_inspect_point`, `sandbox_inspect_comic`, `sandbox_get_warnings`：本とその章、ページの範囲、そして画面で起きていること（選択範囲、通知、回答待ちの確認）。任意のページを指定した幅のJPEG、PNG、WebPにしたもの、または細部を見るための切り抜き（求めれば印刷プレビュー付き）。同じページのデータ（ブロックと行、各段がどこまで埋まっているか、どの行がゆるいか、どの行が分割された語で終わっているか）。ページ上の1点にあるもの（ソースの行、リンクとその行き先、表のセル）。漫画のページのコマと吹き出し。そして、画面にどの章とどのビューアーが出ていても、任意の章または本全体について検査が見つけたもの。
- **変える** — `sandbox_set_config`, `sandbox_get_config`, `sandbox_find_setting`, `sandbox_rename_design_item`, `sandbox_remove_design_item`, `sandbox_language_defaults`, `sandbox_print_profile`, `sandbox_save_layout_as_template`, `sandbox_edit_text`, `sandbox_write_text`, `sandbox_read_text`, `sandbox_search_text`, `sandbox_replace_text`, `sandbox_select_text`, `sandbox_undo_text`, `sandbox_manage_chapters`, `sandbox_save_resource`, `sandbox_save_font`, `sandbox_edit_comic`, `sandbox_import_word`, `sandbox_apply_word_edits`：パスで指定する任意の設定（`bodyText.fontSize`、`page.margins.top`、`headings.levels[level=2].fontSize`、`header.elements[id=titleOdd].italic`）、完全一致の検索と置換による本文の編集（取り消しもできます）、章、画像、SVGの図、動画、書式つきの表、フォント、漫画のコマと吹き出し、スタイルを対応づけて読み込むWord文書。変更すると、各値の変更前と変更後、それぞれの章が何ページになったかが返ります。設定については、エンジンが実際に使う値と、それに連動して変わったほかの設定も返ります。エンジンが扱えない値は受け付けられず、何も変わりません。複数の言語で書かれた本では、`scope`で、設定をすべての言語の共通設定で読み書きするか、画面に出ている版だけで読み書きするかを指定します。
- **表示する** — `sandbox_set_view`, `sandbox_go_to_page`, `sandbox_run_viewer`：ビューアーのタブ、サイドパネル、章か本全体か、拡大率、合わせ方と見開き、読者側の文字サイズ、印刷プレビュー、ページに描くガイド、Folioの拡大鏡、そして画面に出ているページ（ページ番号、本文の一節、アンカー、EPUBの目次の項目で指定）。PDFやEPUBの再生成、印刷、ページ上の動画の再生。
- **保存する** — `sandbox_list_books`, `sandbox_open_book`, `sandbox_save_book`, `sandbox_import_book`, `sandbox_import_idml`, `sandbox_export`, `sandbox_word_templates`, `sandbox_answer`：サンプルと自分のプロジェクトとその表紙、`.postext`ファイルの読み込み、InDesign文書（IDML）から新しい本への読み込み、開いている本（または開いていない本）のPDF、EPUB、HTML、`.postext`、Word、IDML、Markdown、設定のJSONへの書き出し、Word読み込みのテンプレート、そしてSandboxからの確認への回答。
- **デザイン** — `sandbox_list_designs`、`sandbox_save_design`、`sandbox_try_design`、`sandbox_end_design_trial`、`sandbox_apply_design`、`sandbox_import_design`、`sandbox_export_design`、`sandbox_delete_design`：デザインパネルのギャラリー、デザインの保存、試用と保持・破棄、即時または章スタイルとしての適用、デザインファイルの読み書き。

本を変更するツールは組版が終わるのを待つので、次の画像はいつも新しいページのものです。ページは、画面にどのタブが出ていても、ツールのために組まれて描かれます。取り消せない操作（章、リソース、プロジェクトの削除、元の状態への復元、Word文書による本文の上書き、手元の本の置き換え）には、影響の大きい操作であることを示す印が付いています。そのため、ブラウザーは実行前に確認を求めることができます。画面で操作するときと同じく、すべてはお使いのブラウザーの中にとどまります。ツールがアクセスできるのは、Sandbox自身がアクセスできるものだけです。

WebMCPは草案の段階です。Chromeではオリジントライアルとして、また`chrome://flags/#enable-webmcp-testing`で使えます。WebMCPのないブラウザーでは、同じツールが`window.postextWebMcp`にあり（`listTools()`、`executeTool(name, args)`）、ページ内でスクリプトを実行できるエージェントが使えます。Sandboxを埋め込むときは、`webmcp={false}`でツールを登録しないようにできます（[Props](#props)を参照）。

[WebMCP](/ja/docs/webmcp)のページでは、エージェントに頼めることと各ツールの呼び出し方を例とともに説明しています。


## 単体での利用

Sandboxは`postext-sandbox`というReactパッケージで、postextのリポジトリにあり、npmには公開されていません。同じpnpmワークスペースのReactアプリケーションは、Webサイト（`apps/web`）と同じく`"postext-sandbox": "workspace:*"`で依存します。ピア依存はReactとReact DOM（18以降）、そして`postext`です。

```bash
pnpm add postext-sandbox@workspace:* postext@workspace:*
```

```tsx
import { PostextSandbox } from 'postext-sandbox';

function App() {
  return (
    <PostextSandbox
      initialMarkdown="# Hello World"
      initialConfig={{ layout: { layoutType: 'double' } }}
      onMarkdownChange={(md) => console.log(md)}
      onConfigChange={(cfg) => console.log(cfg)}
    />
  );
}
```

### CSSの要件

このパッケージは、CSSカスタムプロパティを参照するTailwind CSSのユーティリティクラスを使います。ホストアプリケーションは次の変数を用意する必要があります。

- `--background`、`--foreground`：基本色
- `--surface`：一段浮いた面の色。`--surface-2`：ホバーした行と強調表示した選択肢（`--background`にフォールバック）
- `--slate`：控えめなテキストの色
- `--rule`：境界線と区切り線の色。`--rule-strong`：ホバーしたコントロールの濃い罫線（`--slate`にフォールバック）
- `--brand`：アクセントカラー。アクティブなパネルの目印、フォーカスリング、スイッチ、選択した選択肢に使います
- `--brand-hover`：ホバー時のアクセントカラー
- `--brand-soft`：選択した選択肢の背後に敷く半透明のアクセントの塗り（`--surface`にフォールバック）
- `--brand-contrast`：オンのスイッチのつまみ（`--background`にフォールバック）
- `--destructive`：破壊的な操作とエラーの色
- `--accent-blue`：リンクとアクセントの色
- `--font-sans`：UIのフォントファミリー
- `--font-mono`：等幅のフォントファミリー（コードエディター用）
- `--font-display`、`--brand-blue`、`--brand-gilt`：アクティビティバーにある既定のロゴマークの書体と色（省略可。フォールバックはGeorgia、`#2b4acb`、`#d8a21a`）

このWebサイトでは、`--brand`をダークテーマで金色、ライトテーマで青にしています。以前のバージョンは`--gilt`と`--gilt-hover`を読んでいましたが、現在のSandboxはこれらを使いません。

ポップオーバー、メニュー、ツールチップは`document.body`上のポータルに描画されるため、変数はSandboxを包む要素だけでなく、`:root`（または`body`）に定義してください。ホストのTailwindのビルドは、パッケージが使うユーティリティクラスが生成されるよう、パッケージのソースを走査する必要があります（Tailwind 4では`@source "…/postext-sandbox/src/**/*.tsx"`）。


## プリセットバンドルの形式

付録です。プリセットの配信元は（HTTPで配信される）ディレクトリーで、そのルートにはプリセットのディレクトリーを列挙した`index.json`があります。各ディレクトリーには`preset.json`マニフェストと、それが参照するMarkdown、リソース、フォントのファイルが入ります。リポジトリーの`scripts/presets/`にあるツールはまさにこの形でバンドルのひな形を作り、Sandboxから書き出した`.postext`ファイルは、そうしたディレクトリーの1つを（`index.json`を除いて）zip圧縮したものです。

```
<presets-root>/
  index.json
  <preset-dir>/
    preset.json
    chapters/              one .md per chapter, in order (a version 1 manifest names a single document instead)
    resources/             figures: .svg / .png / .jpg / .jpeg / .webp / .gif (+ optional .pdf print masters)
    fonts/                 .otf / .ttf / .woff2 single faces
```

### `index.json`

```jsonc
{
  "version": 1,
  "presets": [
    {
      "id": "acme-journal",          // stable id, [a-z0-9-]
      "dir": "acme-journal",         // directory name relative to index.json
      "name": "Acme Journal",
      "description": "Two-column journal article",   // optional
      "locale": "en",                 // optional
      "default": true,                // optional, at most one
      "locales": ["en", "es"],        // optional: every locale the bundle carries
      "openLocale": "en",             // optional: the locale it opens in when none is asked for
      "thumbnail": "thumbnail.jpg",   // optional: preview shown in the picker
      "license": "CC BY 4.0",         // optional: shown as a tag
      "credits": "Text and images: ESO",  // optional: one line under the description
      "tags": ["magazine", "two-column"], // optional
      "binding": "left"               // optional: the edge the website's shelf draws the spine on ("right" for a right-bound book)
    }
  ]
}
```

### `preset.json`

```jsonc
{
  "version": 2,
  "id": "acme-journal",
  "name": "Acme Journal",
  "description": "Two-column journal article",       // optional
  "locale": "en",                                     // optional
  "default": true,                                    // optional
  "configVersion": 22,                                // optional: the configuration rules `config` is written for
  // The same optional showcase fields as the index entry:
  // "locales", "openLocale", "thumbnail", "license", "credits", "tags"

  // The book's chapters, in order — or one list per locale
  "chapters": [
    { "title": "Introduction", "file": "chapters/01-introduction.md" },
    { "title": "Methods", "file": "chapters/02-methods.md" }
  ],
  // "chapters": { "en": [ … ], "es": [ … ] },
  // Version 1 manifests use a single document instead and are still accepted:
  // "version": 1, "markdown": "article.md"  (or a locale → file map)

  // Optional PostextConfig JSON (page, margins, columns, typography...).
  // Do NOT put customFonts here: fonts come from the `fonts` array below.
  "config": { },

  "resources": [
    {
      "id": "fig-1-1",                 // referenced from markdown (:ref)
      "typeId": "figure",              // resource type id (figure, table, ...)
      "kind": "svg",                   // "svg" | "bitmap" | "table"
      "file": "resources/fig-1-1.svg", // svg/bitmap only, relative to preset.json
      "width": 240.5,                  // optional, pt (svg) / px (bitmap)
      "resolution": 300,               // optional, bitmap only: ppi at its natural print size
      "pdfFile": "resources/fig-1-1.pdf", // optional, svg only: vector print master (see notes)
      "height": 180,                   // optional
      "caption": "Caption text",
      "altText": "Accessible description",            // optional
      "safeArea": { "x": 0.18, "y": 0.25, "width": 0.5, "height": 0.6 }, // optional, svg/bitmap only: the part always shown, in fractions of the picture
      "placement": { "position": "top", "span": "column" },  // optional
      "note": "Source: ...",                          // optional
      "table": { "model": { "rows": [[{ "content": "A", "isHeader": true }]], "headerRowCount": 1 } }
                                                      // kind "table" only
    }
  ],

  "fonts": [
    {
      "name": "Some Family",           // family name used by the config
      "fallback": "Source Serif 4",    // optional: an open family of similar width for faces the bundle leaves out
      "variants": [
        { "weight": 400, "style": "normal", "file": "fonts/SomeFamily-Regular.otf" },
        { "weight": 400, "style": "italic", "file": "fonts/SomeFamily-Italic.otf" },
        { "weight": 700, "style": "normal", "file": "fonts/SomeFamily-Bold.otf" }
      ]
    }
  ]
}
```

補足：

- `preset.json`の`id`は`index.json`のエントリーと一致させる必要があります。マニフェストの`description`、`locale`、`default`は、プリセットを読み込んだ時点でindexの値を上書きします。ショーケース用のフィールド`locales`、`openLocale`、`license`、`credits`、`tags`も同様です。`openLocale`は`locales`のいずれかで、リンクやクリックで言語が指定されないときに本を開く言語です（ホームページの書棚もこの言語にリンクします）。原典が読者の言語でない場合に設定します。『紅樓夢』のショーケースは`zh-Hant`を設定しているので、英語を使う読者全員に英訳が開いてしまうことはありません。設定しない場合はインターフェースの言語で決まります。選択画面では、`locales`（または`locale`）のすべての言語とライセンスがタグとして、クレジットが説明の下に表示され、行のチェックマークの列の代わりに`thumbnail`（プリセットのディレクトリーからの相対パスで指定する小さなページ画像）が表示されます。プリセットから複製した本（**自分用に複製**）は、これを表紙として引き継ぎます。`apps/web/public/presets/`にある公開ショーケースのプリセットはすべてのフィールドを使い、各テキストと画像のライセンスと出典を記した`CREDITS.md`を同梱しています。
- `configVersion`（省略可）は、`config`と`localized`の設定がどの設定規則に基づいて書かれているかを示します。書き出すものはすべて、エンジンの`CONFIG_VERSION`（このバージョンでは21）を設定します。これがないマニフェストはpostext 1.4以前で書き出されたもので、見出しの改ページ、数式のサイズ、インラインの図の前後のアキ（本文中と囲みの中）、見出しの文字書式、ドロップキャップ、コロンの行の下の余地、囲みの分割、ダッシュと複合語のハイフンでの改行、行末不ぞろいのテキスト、見出し直下の分割、段落コンテナーの下のアキは、1.4の組み方どおりに読み込まれます（[作業内容の保存](/ja/docs/sandbox-books-saving#作業内容の保存)の「postext 1.4以前に保存された見出しの改ページ」「postext 1.5より前に保存された数式のサイズ」「postext 1.5より前に保存されたインラインの図」「postext 1.5より前に保存された囲み内のインラインの図」「postext 1.5より前に保存された見出しの文字書式とドロップキャップ」「postext 1.5より前に保存されたコロンの後のリスト」「postext 1.5より前に保存された囲みの分割」「postext 1.5より前に保存されたダッシュと行末不ぞろいのテキスト」「postext 1.5より前に保存された複合語」「postext 1.5より前に保存された見出し直下の分割」「postext 1.5より前に保存された段落コンテナー」を参照）。3〜7が記録されたもの（1.5のプレリリース）には、それより後の規則の分の固定だけが適用されます。3の場合は数式のサイズ、インラインのアキ、規則6の5つの固定、規則7の2つ、規則8の3つ、4の場合はインラインのアキと規則6、7、8の固定、5の場合は規則6、7、8の固定、6の場合は規則7と8の固定、7の場合は規則8の固定だけです。8〜20が記録されたもの（postext 1.5〜1.57で書き出したもの）には、記録された値より後の規則の固定が適用されます。その一覧は[postext 1.4以前で書き出したバンドル](/ja/docs/configuration-bundles#postext-14以前で書き出したバンドル)にあります。また、20以下が記録されたものは`localized`の各設定をキー単位で読み、そのトップレベルのキーが共有のキーを丸ごと置き換えます。現在の規則に合わせてマニフェストを手で書く場合は21を設定します。
- `view`（省略可）は、Sandboxがバンドルをどう開くかを指定します。`{ "canvasScope": "book" }`はCanvasで本全体を組みます（[本と章](/ja/docs/sandbox-books-saving#本と章)を参照）。省略するとCanvasは1章ずつ表示します。設定されていれば、書き出した本にも含まれます。200章を超える本は、指定にかかわらず1章ずつ開きます。
- `start`（省略可）は、バンドルがもっと長い本の一部だけを収めているときに、本がどこから始まるかを示します。`{ "pageIndexOffset": 57, "pageNumbering": { "startAt": 58 }, "headings": { "h1": 3 } }`なら、58ページ（偶数ページ）、第4章から始まります。最初の章の`continuation`（`buildDocument`）と同じものです。Sandboxはそこから本をレイアウトし、プロジェクトとして保存するときは本と一緒に保持し、書き出すときに書き戻します。これを編集するパネルはありません。`localized`の項目には、その版専用の`start`を書けます。
- `localized`（省略可）は、多言語バンドルの言語ごとの上書きを保持します。`{ "es": { "config": { … }, "resources": [ { "id": "fig-1", "caption": "…", "note": "…", "altText": "…" } ] } }`のように書きます。章を選んだ言語の上書きが、共有の`config`（その言語が異なる値にしたフィールドで、`configVersion` 21ではフィールド単位でマージされます。[共通設定と言語ごとの上書き](/ja/docs/configuration-bundles#共通設定と言語ごとの上書き)を参照）と`resources`（キャプション、注記、代替テキスト、表のセルをidでマージ）の上に適用されます。エントリーのない言語は共有の文言を使います。エントリーには独自の`view`を含めることもでき、その版では共有のものより優先されます。『紅樓夢』は中国語の版を本全体で開き、全体の描画がずっと遅いJolyの英訳は1章ずつ開きます（`"en": { "view": { "canvasScope": "chapter" } }`）。
- `chapters`（バージョン2）は本の順に並べた`{ title, file }`のリスト、または言語→リストのマップです。`markdown`（バージョン1）はファイル名、または言語→ファイルのマップです。どちらの場合も、Sandboxは要求された言語に一致するエントリーを選び、その言語の章ファイルだけを読み込みます。選ぶ順序は、大文字と小文字の違いを除いてタグが完全に一致するもの、次に言語と字体が同じもの（`zh-TW`は`zh-Hans`より先に`zh-Hant`を読みます）、次に字体が異なる同じ言語（素の`zh`をキーにしたバンドルでは、`zh-TW`の読者に中国語が渡ります）、次にプリセット自身の`locale`、最後に最初のエントリーです。章の`title`が空の場合は、ファイルの最初のレベル1見出しから取ります。Sandboxはつねにバージョン2で書き出します。
- `width` / `height`は、`svg`と`bitmap`のリソースでは省略できます。ない場合は読み込み時にファイルから読み取ります。ビットマップには`resolution`（原寸で印刷したときのppi）と`fileResolution`（ファイルに記載された解像度。設定で`layout.bitmapResolution: 'file'`を指定しているときは読み込み時に読み取ります）も指定できます。
- `pdfFile`（svgリソースのみ）は、同じ図をベクターで収めた1ページのPDFを指します。典型的には、SVGの元になったIllustratorのオリジナルやPDF書き出しです。PDFの書き出しでは、SVGの代わりにそのページをそのまま（フォント、グラデーション、色空間を保って）埋め込みます。CanvasとHTMLのプレビューは引き続きSVGを使います。単色モードでは無視されます。単色モードの色替えの処理はSVGのマークアップにしか作用しないためです。ファイルがなくても失われるのはマスターだけで、図は残ります。リソースの詳細でSVGのソースを編集するとマスターは外れ（マスターは編集前のソースに合わせて作られたものです）、以後、PDFの書き出しは編集後のSVGに従います。マスターを戻すには、元の状態に戻します（**本**パネルの**元に戻す…**）。マスターのないSVGは、PDFバックエンドのサブセット（基本図形、パス、グループ、`use`、クリップパス、単色の塗りと線、不透明度、文書が読み込めるフォント（まずカスタムフォント、次にGoogleがホストするファミリー）で組まれた`text` / `tspan`の連なり）に収まる場合はベクターパスとして出力され、それ以外は600 dpiでラスタライズされます。
- SVGの`text`は、どの出力でも本のフォントで描画されます。プレビューとEPUBは、SVGを表示する前に、そのテキストが指定するフェイスをSVGに埋め込みます（`<img>`からはページのフォントが見えないため）。カスタムファミリーはアップロードしたファイルを、Googleのファミリーはその文字を収めるFontsourceのファイルを埋め込みます。PDFの書き出しは、同じ埋め込みフェイスを使い、選択可能な実際のテキストとして組みます。`font-family`にはファミリー名を、**フォント**パネルに表示されるとおりに正確に書いてください。リソースのマニフェストの項目に`"inlineFonts": false`と書くと、埋め込みを無効にできます（`svg.inlineFonts`）。
- SVGのソースエディターでは、誤って図を壊さないよう、テキストノード（色付きで表示）の中でしか入力できません。ヘッダーの鍵ボタンを押すと、座標、色、構造を含むソース全体を編集できるようになり、再びロックするとテキストノードを探し直します。
- `table.model`はPostextの`TableModel`です。`rows`はセル（`content`と、省略可能な`colSpan`、`rowSpan`、`isHeader`、`align`、`verticalAlign`）を行ごとに並べた配列、`headerRowCount`は先頭のヘッダー行の数、`columnWidths`は列の相対的な幅の比を表す省略可能な配列です。`table.styleId`では、設定の`tableStyles`のいずれかを指定できます（省略可）。
- フォントファイルは、プリセットのidとファイルパスから導いたidでIndexedDBに保存され、プリセットを適用したときにそのファミリーが`config.customFonts`に追加されます。`index.json`がない場合や形式が正しくない場合は、エラーにはならず、プリセットがないものとして扱われます。
- バンドルで再配布できないファミリーは、`"redistributable": false`と空の`variants`を付けて記載します。`"fallback"`に幅の近いオープンなファミリーの名前を加えると、Sandbox、コマンドライン、エンジンのホストは、このファミリーのフェイスをそのファミリーで組みます（postext 1.42以降）。指定しない場合、本は既定のフォントで組まれ、改行位置も変わります。
- `<preset-dir>/fingerprint.json`は省略可能で、開発用のルートでは**仮想**のファイルです。そのファイルがない場合、`GET`は`{ "fingerprint": "<sha1 hex>", "files": <n> }`を`Cache-Control: no-store`付きで返します。値はディレクトリーのファイルのメタデータ（4階層までのすべてのファイルの相対パス、更新日時、サイズ。ドットファイルと`node_modules`は除外）から計算し、ファイルの内容は使いません。Sandboxはこれをポーリングしてバンドルの編集を追跡します（[「本」パネル](/ja/docs/sandbox#本パネル)を参照）。静的ホストは、同じ形の実際の`fingerprint.json`を配信することも、まったく配信しないこともできます。配信しない場合、そのプリセットは追跡されません。
