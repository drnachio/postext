# Configuració: requadres


## Estils de requadre

La propietat `calloutStyles` declara els estils de requadre amb nom que el document aplica amb un contenidor `:::callout{type="…"}`: notes, consells, advertiments, objectius d'aprenentatge, qualsevol contingut separat del text corregut dins d'una caixa amb fons de color o amb vora. Per defecte s'inclou un estil neutre, `note` (fons gris clar, sense vora, sense franja, sense icona, sense títol), de manera que `:::callout` funciona sense cap configuració; si declares `calloutStyles`, substitueixes aquesta llista per defecte.

```ts
const config: PostextConfig = {
  calloutStyles: [
    { id: 'note', name: 'Nota' },
    {
      id: 'objectives',
      name: "Objectius d'aprenentatge",
      title: 'Objectius',
      stripe: { enabled: true, side: 'left' },
      icon: { kind: 'glyph', glyph: '✓' },
      titleStyle: { textTransform: 'uppercase' },
      lists: { bulletChar: '–' },
    },
    {
      id: 'warning',
      title: 'Advertiment',
      backgroundEnabled: false,
      border: { enabled: true, color: { hex: '#AA0000', model: 'hex' }, width: { value: 1, unit: 'pt' } },
      borderRadius: { value: 1, unit: 'mm' },
      titleStyle: { color: { hex: '#AA0000', model: 'hex' } },
    },
  ],
};
```

```md
:::callout{type="objectives"}
- Descriure les parts del fanal.
- Retallar el ble en fer-se fosc.
:::

:::callout{type="warning" title="No toquis la lent"}
El vidre continua calent una hora després d'apagar la flama.
:::
```

### Cantonades, costats i pestanyes unides

Una caixa no ha de ser per força un rectangle amb quatre cantonades iguals i una sola vora. Des de postext 1.48, un estil pot arrodonir unes cantonades i no unes altres, dibuixar la vora només en alguns costats i fer créixer la pestanya des de la caixa com una sola forma: la fitxa d'un llibre de text amb la pestanya del títol i el cos en un sol contorn, dibuixada per l'estil i no pintada en una imatge darrere de la pàgina.

```ts
calloutStyles: [
  // Arrodonida només a dalt, un filet a sobre de la caixa i un peu més gruixut.
  { id: 'ficha', background: { model: 'hex', hex: '#fff4d6' },
    borderRadius: { topLeft: { value: 3, unit: 'mm' }, topRight: { value: 3, unit: 'mm' } },
    border: { enabled: false, color: { model: 'hex', hex: '#c58b00' }, width: { value: 0.75, unit: 'pt' },
      sides: { top: { enabled: true }, bottom: { enabled: true, width: { value: 2, unit: 'pt' } } } } },
  // Una targeta amb la pestanya que creix des de la vora superior.
  { id: 'tarjeta', background: { model: 'hex', hex: '#ffffff' }, borderRadius: { value: 3, unit: 'mm' },
    border: { enabled: true, color: { model: 'hex', hex: '#2a6f97' }, width: { value: 1, unit: 'pt' } },
    label: { position: 'top-left', inset: { value: 4, unit: 'mm' }, joined: true, fillet: { value: 2, unit: 'mm' },
      color: { model: 'hex', hex: '#2a6f97' } } },
]
```

- **Cantonades.** `borderRadius` és una sola longitud per a les quatre cantonades, o bé `{ topLeft, topRight, bottomRight, bottomLeft }`. Una cantonada que no surt a l'objecte queda recta. Les cantonades són les del full. Dues cantonades no ocupen mai més que el costat que hi ha entre totes dues; cadascuna cedeix en proporció.
- **Costats.** `border.sides.top`, `right`, `bottom` i `left` admeten `enabled`, `color` i `width`, i cada camp que no s'hi indica és el de tota la vora. Una caixa amb vora només a dalt és `border: { enabled: false, sides: { top: { enabled: true } } }`, o `enabled: true` amb els altres tres costats desactivats. La vora interior d'un costat segueix el seu gruix, de manera que una cantonada arrodonida entre un costat prim i un de gruixut fa la corba com la dibuixa CSS.
- **Pestanya unida.** Amb `label.joined: true`, la pestanya i la caixa són un sol contorn, un sol fons (el `background` de la caixa; el `background` propi de la pestanya no es pinta) i una sola vora que envolta la pestanya. La pestanya s'aguanta sobre la vora, fora de la caixa tant com fa d'alta: el seu `offset` ha de ser `0` (qualsevol altre valor es dona com a `unknownConfigValue` i es llegeix com a `0`). Les cantonades exteriors prenen el radi de la cantonada de la caixa on s'enganxa, i les cantonades interiors, on toca la caixa, les arrodoneix `fillet` (per defecte, aquest mateix radi). Una pestanya arran del costat de la caixa (amb un `inset` de menys de mig píxel) puja recta des d'aquell costat. Dona a les paraules un color que es llegeixi sobre el fons de la caixa (`label.color`), perquè la pestanya ja no té fons propi. Amb `label.ownBackground: true`, una pestanya unida es pinta amb el `background` propi de l’etiqueta, sobre l’emplenament de la caixa i sota la vora, de manera que una pestanya blanca pot seure en una caixa tenyida, o una de color en una caixa sense emplenament.
- **Cantonades de la pestanya.** `label.borderRadius` dona a la pestanya cantonades pròpies: una longitud, o `{ topLeft, topRight, bottomRight, bottomLeft }` sobre les cantonades del full, com el `borderRadius` de la caixa. Una pestanya separada de la caixa és recta si no les fixa. Una pestanya unida arrodoneix amb ell les dues cantonades exteriors (`topLeft` i `topRight` en una pestanya a dalt, `bottomLeft` i `bottomRight` a baix); sense valor, prenen el radi de la cantonada de la caixa. Els acords conserven `fillet` en tots dos casos.
- **Pestanyes a baix.** `position: 'bottom-right'`, `'bottom-left'`, `'bottom-start'` o `'bottom-end'` penja la pestanya del peu de la caixa, sola o unida: és la pestanya de dalt capgirada, `offset` per sota del peu i el `rule` al llarg del peu. No hi ha pestanyes laterals: les paraules d'una pestanya van de través.

Totes les sortides dibuixen aquestes formes: el canvas i el PDF, com a contorns vectorials; el visor HTML i l'EPUB de maquetació fixa, amb CSS per cantonada i per costat. L'EPUB de maquetació fluida escriu les cantonades i els costats al seu CSS i compon una pestanya unida com una pestanya normal. El `look.border.color` d'un marc canvia el color de tots els costats, i la paleta d'una part canvia el de cadascun. Un estil amb totes les cantonades i tots els costats iguals es maqueta com abans.

### Un glif a la pestanya

`label.icon` pot posar un caràcter d'una font en lloc d'una imatge: `kind: 'glyph'` amb `glyph: '◉'`. La pestanya no necessita cap recurs d'imatge, i el glif pren el color de les paraules llevat que en fixi un de propi, de manera que un mateix estil serveix per a totes les tintes d'un llibre. Des de postext 1.48.

```ts
label: {
  position: 'top-left', background: { model: 'hex', hex: '#0885bf' }, color: { model: 'hex', hex: '#ffffff' },
  icon: { kind: 'glyph', glyph: '◉', placement: 'inside', scale: 1.1 },
}
```

### Estils basats en un altre

`extends` indica un altre estil de `calloutStyles`, i els camps que l'estil no fixa els agafa d'aquell estil. Els objectes com `padding`, `border`, `titleStyle` o `fixed` es combinen clau per clau, de manera que un estil pot canviar només un costat del farciment o només `fixed.offset`; un color o una longitud s'agafen sencers; `id` i `name` no s'hereten mai. Un estil base es pot basar, al seu torn, en un altre. Un llibre amb requadres en molts llocs pot tenir un estil per a l'aspecte i un estil mínim per a cada lloc:

```ts
calloutStyles: [
  {
    id: 'caja',
    background: { model: 'hex', hex: '#dff0fa' },
    padding: { top: { value: 3, unit: 'mm' }, right: { value: 4, unit: 'mm' }, bottom: { value: 3, unit: 'mm' }, left: { value: 4, unit: 'mm' } },
  },
  { id: 'caja-p5', extends: 'caja', placement: 'fixed', fixed: { offset: { x: { value: 12, unit: 'mm' }, y: { value: -40, unit: 'mm' } } } },
  { id: 'caja-p9', extends: 'caja', placement: 'fixed', fixed: { anchor: { to: 'container', edge: 'top-right' } } },
]
```

Si canvies l'aspecte de `caja`, tots els requadres el segueixen, cadascun al seu lloc. Un `extends` que no correspon a cap estil genera l'avís `calloutStyleExtendsUnknown` (que proposa l'id més semblant; l'estil queda independent, amb els valors de sèrie), i els estils que es basen els uns en els altres en bucle generen `calloutStyleExtendsCycle` (queden independents fins que un d'ells es basa en un estil de fora del bucle). Al Sandbox, ho fixa el camp **Basat en** d'un estil de requadre; si suprimeixes un estil en què se'n basen d'altres, els seus paràmetres s'escriuen en aquests estils, de manera que els requadres no canvien. A la secció **Estils de marc**, si fusiones amb **Comparar només l'aspecte** i **Deixar cada requadre on és** està activat (per defecte), un estil amb requadres en una altra posició es conserva com un d'aquests estils mínims, i cap requadre no es mou. Des de postext 1.39.

### El contenidor `:::callout`

Una línia `:::callout{type="<id>"}` obre la caixa, i una línia amb només `:::` la tanca. La línia d'obertura admet cinc atributs: `type` (l'id de l'estil), `title` (substitueix el títol de l'estil), `span`, `placement` i `columns` (substitueixen els valors de l'estil). El contingut que hi ha entremig es compon dins de la caixa: un títol opcional i després els paràgrafs, llistes, cites, fórmules o recursos inserits, cadascun amb la tipografia `body` / `lists` de l'estil (els encapçalaments conserven els estils habituals). Els marges entre els elements es fusionen com en el text corregut; l'interior surt de la retícula de base, i el flux hi torna després de la caixa amb un mínim de `marginBottom` per sota (la retícula té prioritat i el marge és un mínim, la mateixa convenció que segueixen els recursos). En canvi, un estil amb `snapToGrid: false` conserva el `marginBottom` exacte, i el text que ve després de la caixa queda fora de la retícula fins al següent encapçalament o final de llista. Un encapçalament just abans d'un requadre s'hi manté unit.

Límits d'aquesta versió:

- Un requadre es manté sencer tret que el seu estil indiqui `keepTogether: false`. Quan no cap a l'espai que queda a la columna, passa sencer a la columna o pàgina següent; també des d'una columna buida que les bandes de flotants o un topall de banda han escurçat, sempre que hi càpiga en una columna completa. Una caixa més alta que una columna completa es parteix al seu lloc, com una de divisible; només es col·loca igualment, i desborda, la que no es pot partir per cap punt (una figura o taula més alta que la columna, o un `splitMinLines` que cap tall no compleix); en aquest cas, la maquetació registra un avís `calloutOverflow` (`VDTDocument.warnings`), que el Sandbox llista. Un grup `:::columns` es talla com la caixa que l'envolta, entre les seves subcolumnes (des de postext 1.25); només es manté sencer, i pot desbordar de la mateixa manera, amb `layout.flowColumns: false` o dins d'una caixa niada. Una caixa divisible deixa enrere la part que hi cap (elements sencers, o les línies d'un paràgraf respectant `splitMinLines` a cada costat; n'hi ha prou amb una figura, una taula o una fórmula en bloc en un costat) i continua en una caixa sense icona a la columna o pàgina següent, sense títol tret que l'estil el repeteixi i, opcionalment, amb un indicador sota la part que queda enrere (vegeu [Marques d'un requadre partit](#marques-dun-requadre-partit)).
- Els flotants cedeixen el lloc a una caixa indivisible. Quan el bloc que ve després de la referència d'una figura és un requadre `keepTogether`, no s'aprofita un espai lliure que deixaria la caixa sense cap columna de la banda actual on anar a parar (la columna de la referència o una columna buida posterior, on la caixa hauria cabut abans del flotant): la figura passa a l'espai lliure següent, normalment la pàgina següent, i la caixa continua en el flux, tal com ho faria un caixista, en lloc d'expulsar la caixa de la pàgina i deixar la columna només amb la figura.
- `span: 'page'` en una disposició de diverses columnes converteix la caixa en un **bloc d'amplada de pàgina**: es compon a tota l'amplada de l'àrea de contingut i divideix la pàgina en bandes de columnes. Les columnes de text de sobre es tanquen a la línia de tall, la caixa ocupa una columna pròpia a tota l'amplada i a sota comença una banda nova de columnes de text, de manera que el flux continua sota la caixa a totes les columnes. Allà on les columnes estan *anivellades* (al principi d'una pàgina, just sota un encapçalament d'obertura amb `span: 'page'`, just sota un altre bloc d'amplada de pàgina o just sota una banda superior de flotants), la caixa simplement talla en aquell punt. Si arriba a mitja pàgina, amb les columnes desiguals, es compon com ho faria un caixista: el text de sobre es talla anivellat a totes les columnes (el motor repeteix la col·locació amb les columnes de la banda escurçades al mateix nombre de línies de retícula, de manera que el text passa de manera natural d'una columna a l'altra i continuen aplicant-se totes les regles d'òrfenes, de vídues i d'encapçalaments units al text), la caixa ocupa l'amplada de la pàgina i les columnes continuen a sota. El tall costa un parell de passades de col·locació més; si la línia de tall no deixa lloc per a la caixa i per al mínim de línies de vídua de text de cos a sota, o si després d'uns quants intents no encaixa cap disposició, la caixa passa al principi de la pàgina següent. El text de sobre respecta el tall: un paràgraf que no pot començar en les poques línies que queden en una columna sota una figura passa a la columna següent (i la figura queda sola a la seva columna), i quan un bloc encara passaria del tall, el tall baixa una línia en lloc de quedar-se on acaba aquell bloc. Una caixa partida que obre la banda també es talla en aquell punt, de manera que la resta no passa mai del tall. Amb `headings.balancing.beforeSpan` (el valor per defecte), la banda anterior es talla anivellada al final (com la banda de tancament d'un capítol) i, quan l'estil permet partir la caixa (`keepTogether: false`), la part de la caixa que cap sota les columnes anivellades tanca la pàgina i la resta obre la següent; amb `beforeSpan: false`, la pàgina anterior simplement s'equilibra com sempre, sense forçar un salt de pàgina. Un encapçalament just abans d'un bloc d'amplada de pàgina no hi queda unit. En disposicions d'una sola columna, `span: 'page'` és simplement en línia.
- `placement: 'fixed'` treu la caixa del flux: es compon (`width: 'auto'` s'ajusta al títol; `'fill'` agafa l'amplada de la columna de text sota el punt d'ancoratge) i es fixa a la pàgina on apareix en el flux, a la posició que descriuen `fixed.anchor` / `fixed.offset` (per defecte, la cantonada inferior esquerra de l'àrea de contingut). Les columnes de text que cobreix cedeixen aquella zona (retallada per baix, o per dalt quan la columna encara és buida), exactament com una banda de flotants; quan la zona ja conté text, un flotant o un bloc d'amplada de pàgina, la caixa passa a la pàgina següent. Una caixa fixa que tanca el capítol (perquè el bloc següent és una obertura de capítol, un `:::part`, una caixa barrera de flotants o el final del document) primer anivella les columnes de sobre (`headings.balancing.trailing`), de manera que una pàgina final curta acaba anivellada i amb el distintiu a sota. La caixa i el seu contingut es desen a `page.floats` i es pinten fora del retall de la columna en tots els backends.
- `placement: 'top' | 'bottom'` fa **flotar** la caixa com un recurs: surt del flux on apareix i ocupa la primera banda lliure a partir d'aquest punt (el peu de la pàgina actual amb `'bottom'`, o la part de dalt o de baix de la pàgina següent que obre el flux), a l'amplada de la columna (`span: 'column'`) o a tota l'amplada de l'àrea de contingut (`span: 'page'`); el text que ve després omple la pàgina que ha deixat. El marc i el contingut van a `page.floats`, com els d'una caixa fixa. Una caixa flotant que encapçala una pàgina nova es col·loca abans de les figures que esperen aquella pàgina, i una figura citada en una pàgina anterior que llavors hi cap a sota ocupa la resta d'aquella pàgina encara que quedin menys de tres línies de text (una pàgina galeria: caixa i figura, sense text entremig). Una caixa `span: 'side'` no flota mai: s'apila al costat del text sigui quin sigui el `placement`. Amb un valor de `columns` superior a 1 (a l'estil o com a atribut de la línia d'obertura, des de postext 1.18), una caixa `span: 'column'` ocupa aquest nombre de columnes contigües: la part de dalt d'una sèrie de columnes buides que comencen a la mateixa altura, o el peu de la columna en curs i de les columnes buides que la segueixen, com a `:::callout{placement="top" columns="2"}`.
- `width: 'auto'` només s'ajusta al títol; el contingut no es té en compte.
- Un `:::callout` niat dins d'un altre requadre és una caixa independent: es compon amb el seu propi estil (fons, vora, radi, farciment, franja, títol, icona, marcador, pestanya, tipografia) a tota l'amplada interior de la caixa mare, s'apila com un element més, i el seu `marginTop` / `marginBottom` es fusiona amb el dels elements veïns. El `span` i el `placement` (de la línia d'obertura o de l'estil) no es tenen en compte (una caixa niada sempre segueix el flux dins de la caixa mare), igual que `floatBarrier` i `snapToGrid`. Les caixes es poden niar a qualsevol profunditat i poden anar dins d'un grup `:::columns` (cadascuna sencera, en una columna). Quan la caixa mare es parteix, el tall cau abans o després d'una caixa niada, o dins seu si el seu estil permet partir-la; cada fragment torna a dibuixar els marcs que travessa el tall, i una caixa niada que continua del fragment anterior perd el títol i la icona, com una continuació de primer nivell.
- Un grup `:::columns{count=N}` … `:::` entre el contingut compon aquests elements en `N` columnes d'amplada igual, separades per `columnGap`, dins de la caixa: la seqüència es talla pels límits de bloc o de línia que anivellen millor les columnes (un paràgraf o un element de llista tallat a mitges continua a dalt de la columna següent, sense el pic), cada columna comença a la part superior del grup, i el grup fa l'alçada de la columna més alta; els elements posteriors recuperen tota l'amplada. Una caixa que es parteix (`keepTogether: false`, o més alta que una columna) també talla dins d'un grup, entre les columnes: un grup en serpentina omple les columnes per torns i continua al fragment següent, i un grup en paral·lel (`breaks`) continua cada fil per separat (des de postext 1.25; vegeu [Format del document › `:::columns`](/ca/docs/document-format-directives#columns)). Un `gap` a la línia d'obertura substitueix `columnGap` per a aquell grup, i `rule` traça un filet al llarg de cada espai entre columnes. Serveix per a un resum de punts clau a dues columnes o per a les taules d'un requadre ample posades una al costat de l'altra.
- El sisè atribut de la línia d'obertura, `label`, s'imprimeix a la pestanya `label` de l'estil (vegeu més amunt): `:::callout{type="recuadro" label="RECUADRO 1-1" title="La regla del octeto"}`; sense estil de pestanya l'atribut s'ignora.

Al VDT, la caixa és un bloc de marc de `type: 'callout'`, amb la decoració (fons, franja, icona, títol) a `designOverlay`, seguit dels blocs de contingut a la mateixa columna; el marc i cada bloc de contingut porten el `containerId` del bloc delimitat. Una caixa niada és un marc `type: 'callout'` propi entre el contingut, seguit dels seus blocs; aquests blocs conserven el `containerId` del bloc de primer nivell (la col·locació i l'equilibratge continuen veient una sola unitat) i hi afegeixen `calloutPath`, els identificadors de contenidor dels blocs niats que els envolten, del més extern al més intern (el d'un marc niat és l'última entrada). El PDF etiquetat dona a cada caixa niada un `Div` dins del de la caixa mare. Les imatges d'icona es resolen com les dels recursos: el registre d'imatges del canvas, l'opció `resourceImageUrl` de l'HTML i el proveïdor `resourceBytes` del PDF. L'EPUB de maquetació fluida escriu la icona en primer lloc dins del seu requadre, amagada a les tecnologies d'assistència, i la fa flotar on la dibuixa la pàgina: sobre una franja lateral, en una columna pròpia o en una cantonada superior; un llibre vertical la col·loca al llarg de les seves línies. Una imatge pintada d'un sol color (`tint`, un color `#rrggbb`) entra al llibre com una còpia de l'SVG en aquell color; un mapa de bits hi conserva els seus colors.

```ts
const resolved = resolveCalloutStylesConfig(config.calloutStyles, resolvedBodyText, resolvedHeadings, resolvedUnorderedLists, config.locale);
// => cada camp heretat s'omple des de les seccions resoltes; el locale
//    opcional tria la llengua de les cadenes de continuació

const minimal  = stripCalloutStylesDefaults(config.calloutStyles);
// => undefined per al `note` per defecte; s'eliminen els valors estàtics per defecte
```

### Tipografia dins d'un requadre

Una caixa `:::callout` (un *requadre*, com en diuen el tauler Estils de requadre del Sandbox i el [format del document](/ca/docs/document-format)) compon el contingut amb la tipografia `body` i `lists` del seu estil; tota la resta conserva els estils del document:

- **Els paràgrafs** agafen el `body` de la caixa: font, cos, interlineat, color, colors d'èmfasi, gruixos, `italic`, `smallCaps`, alineació, partició de mots, sagnat i espaiat entre paràgrafs. Un camp sense definir hereta el valor de `bodyText`. Un color d'èmfasi heretat conserva el vincle amb la paleta, així que les negretes, les cursives i les etiquetes de `:ref` d'una caixa canvien amb `colorPalette` igual que fora de la caixa. (Fins a postext 1.4, la negreta d'una caixa es quedava en `#295AA3` fos quin fos el color principal.)
- **Les llistes de pics** agafen el `lists` de la caixa (caràcter de pic, color, mida, gruix i lletra del glif, sagnat, separació, espaiat entre elements, marges) per sobre d'`unorderedLists`, i el seu text és el de la caixa. Un `lists.bulletChar` o un `lists.color` diferent del del document (`unorderedLists`) substitueix el pic o el color de tots els nivells; si és igual o no es defineix, cada nivell conserva els seus (`unorderedLists.levels`), de manera que els guions dels nivells niats es mantenen dins de la caixa.
- **Les llistes ordenades** agafen `lists.indent`, `gap` i `itemSpacing`, i també `lists.color` sempre que l'estil el defineixi, encara que coincideixi amb el color de pic del document; si l'estil no el defineix, els números queden en `orderedLists.color`. (Fins a postext 1.4, el color només arribava als números si era diferent d'`unorderedLists.color`, així que no servia de res donar-los justament aquest color.) El número (la font, el cos i el separador) ve dels `orderedLists` globals, perquè `lists` només té camps de pic: és allà on es dona estil als números d'una caixa.
- **Els `:::paragraphs` dins d'una caixa** fan servir el seu estil de paràgraf, també en caixes niades. Els camps que l'estil no defineix hereten el valor del `bodyText` del document, no del `body` de la caixa (ni tampoc la cursiva ni les versaletes de la caixa).
- **Els grups `:::columns`** no tenen estil propi: totes les columnes comparteixen la tipografia de cos i de llistes de la caixa, i `columnGap` fixa la separació entre elles.
- **Les cites** agafen la font, el cos, els gruixos i les versaletes del text de la caixa (en cursiva i en gris, com en el text corregut). **Els encapçalaments** conserven els seus estils, i **les fórmules en bloc**, la configuració de matemàtiques.
- **Les figures i les taules** conserven els estils de peu i de taula del document, a l'amplada interior de la caixa; els gruixos normal i negreta segueixen els del `body` de la caixa.
- **Els xips** conserven el seu estil de xip; una mida en `em` es mesura sobre el cos del text de la caixa.
- **`:::space`** es mesura en línies del text de la caixa (vegeu [`:::space`](/ca/docs/document-format-directives#space) per saber quan es descarta).
- **Una caixa niada** agafa tot el seu propi estil; el `span`, el `placement`, el `floatBarrier` i el `snapToGrid` no es tenen en compte.

**Notes amb sagnat francès.** Les notes al peu d'una taula, una llegenda numerada o una llista de fonts pengen la marca davant del text: la marca a la vora interior de la caixa, i el text i totes les línies següents una mica més endins. `body.hangingIndent` (des de postext 1.71) ho fa amb tots els paràgrafs d'una caixa o d'un marc amb aquest estil:

- **Una longitud** situa totes les línies llevat de la primera a aquesta distància de la vora interior de la caixa, com el `hangingIndent` d'un estil de paràgraf (vegeu [Estils de paràgraf](/ca/docs/configuration-styles#estils-de-paràgraf)). La primera línia comença a la vora, o a `body.firstLineIndent` si l'estil el fixa ell mateix; un sagnat de primera línia heretat de `bodyText` cedeix el lloc.
- **`true`** llegeix `body.firstLineIndent` com el sagnat de totes les línies llevat de la primera, igual que `bodyText.hangingIndent` al text corrent; `false` compon la caixa sense sagnat francès en un llibre on el text de cos en porta. Sense valor, la caixa pren `bodyText.hangingIndent`.

Una tabulació a la mateixa posició porta el text que segueix la marca fins a la vora de les línies següents, sigui quina sigui l'amplada de la marca:

```ts
calloutStyles: [{
  id: 'notes',
  padding: { top: { value: 0, unit: 'mm' }, right: { value: 0, unit: 'mm' }, bottom: { value: 0, unit: 'mm' }, left: { value: 0, unit: 'mm' } },
  body: {
    fontSize: { value: 7, unit: 'pt' },
    hangingIndent: { value: 4.5, unit: 'mm' },
    tabStops: [{ position: { value: 4.5, unit: 'mm' } }],
  },
}],
```

```markdown
:::callout{type="notes"}
\*	Els preus inclouen el lliurament dins de la ciutat.

\*\*	Els socis paguen la meitat; la rebaixa no se suma a altres ofertes i val fins al final de la temporada.
:::
```

Cada nota és un paràgraf propi; entre la marca i el text hi va un caràcter de tabulació o `:tab`. L'asterisc va escapat, perquè `*` i una tabulació al principi d'una línia obren un element de llista. Les línies es mesuren així, de manera que el canvas, el PDF, la llista de visualització i l'EPUB (amb `padding-inline-start` i un `text-indent` negatiu) les componen igual, i l'exportació a Word escriu el mateix sagnat francès. Els elements de llista conserven el seu propi sagnat (`lists.indent`, `lists.gap`), i un paràgraf dins d'un bloc `:::paragraphs`, el del seu estil. Un `firstLineIndent` negatiu continua comptant com a `0`: la primera línia no pot començar dins del marge interior de la caixa. Una cita dins d'una caixa penja amb la caixa quan `hangingIndent` és `true`; amb una longitud, només porten sagnat francès els paràgrafs propis de la caixa.

### Marques d'un requadre partit

Quan una caixa es parteix entre columnes o pàgines (`keepTogether: false`, o una caixa més alta que una columna), cada part posterior a la primera comença sense el títol ni la icona i, per defecte, res no indica al lector que la caixa continua. Dues opcions afegeixen les marques que fan servir els llibres o els guions:

- **`repeatTitle: true`** repeteix el títol al principi de cada continuació, seguit de `continuedSuffix` («Punts clau (cont.)» per defecte). La repetició té l'estil del títol, així que amb `textTransform: 'uppercase'` dona el «HAMLET (CONT.)» d'un guió. La icona i la pestanya es queden a la primera part.
- **`continuesMarkerEnabled: true`** posa `continuesMarker` («Continúa» en un document en castellà, «Continued» en anglès) sota l'última línia de cada part que continua, dins de la caixa, amb la font i el cos del text de la caixa: en cursiva tret que `continuesMarkerItalic` sigui `false`, i alineat a la dreta tret que `continuesMarkerAlign` sigui `'left'` o `'center'`. L'indicador ocupa espai a la part que tanca la pàgina, i el punt de tall es tria perquè hi càpiga.

```ts
calloutStyles: [{
  id: 'parlamento',
  keepTogether: false,
  titleStyle: { textTransform: 'uppercase' },
  repeatTitle: true,
  continuedSuffix: '(CONT.)',
  continuesMarkerEnabled: true,
  continuesMarker: '(SEGUEIX)',
  continuesMarkerAlign: 'center',
  continuesMarkerItalic: false,
}],
```

```md
:::callout{type="parlamento" title="Hamlet"}
Un parlament prou llarg per passar del peu de la pàgina…
:::
```

La part que tanca la pàgina acaba amb «(SEGUEIX)» i la pàgina següent comença amb «HAMLET (CONT.)». Totes dues són elements de paginació: en un PDF accessible són artefactes, i a l'HTML s'amaguen a les tecnologies d'assistència, de manera que el títol es llegeix una sola vegada. Al VDT són blocs de text de `designOverlay` marcats amb `artifact: true`.

### Dissenys de requadre

`design` col·loca els elements d'un disseny d'encapçalament (textos, imatges, filets, caixes; vegeu [Extensió i disseny avançat](/ca/docs/configuration-headings#extensió-i-disseny-avançat)) en una banda sota el títol del requadre, a tota la seva amplada interior. El contingut del requadre segueix la banda, amb la separació del títol entre tots dos. Un requadre partit entre columnes o pàgines dibuixa la banda només a la primera part. Des de postext 1.45.

<table>
  <thead>
    <tr>
      <th>Propietat</th>
      <th>Tipus</th>
      <th>Per defecte</th>
      <th>Descripció</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>enabled</code></td>
      <td><code>boolean</code></td>
      <td><code>true</code></td>
      <td>Un disseny s'activa tan bon punt es fixa; <code>false</code> el desa a l'estil sense dibuixar la banda.</td>
    </tr>
    <tr>
      <td><code>slot</code></td>
      <td><code>DesignSlot</code></td>
      <td>—</td>
      <td>Els elements, col·locats respecte a la banda: <code>anchor.to: 'container'</code> és la banda, des de sota el títol i a tota l'amplada interior. Els ancoratges <code>'page'</code> i <code>'bleed'</code> no es llegeixen en un requadre.</td>
    </tr>
    <tr>
      <td><code>minHeight</code></td>
      <td><code>Dimension</code></td>
      <td>sense definir</td>
      <td>L'alçada mínima de la banda. Sense aquest valor, la banda fa el que abasten els seus elements; els que porten <code>reserve: false</code> i els ancorats al centre o al peu de la banda no compten.</td>
    </tr>
    <tr>
      <td><code>setsContent</code></td>
      <td><code>boolean</code></td>
      <td><code>false</code></td>
      <td>El disseny imprimeix el contingut del requadre (<code>&#123;boxText&#125;</code>) i el requadre no el torna a compondre sota la banda. Un requadre el disseny del qual fixa el contingut no es parteix mai: passa sencer a la columna o la pàgina següent.</td>
    </tr>
  </tbody>
</table>

Els textos del disseny llegeixen aquests marcadors:

- `{titleText}`: el títol que imprimeix el requadre, el `title` de la tanca o, si no n'hi ha, el de l'estil.
- `{boxText}`: el contingut del requadre com a text pla, un paràgraf o element de llista per línia. Els buits s'ometen.
- `{boxText.<n>}`: el paràgraf o element de llista número `n`, comptant des d'1; buit si el requadre en té menys.
- `{attr.<clave>}`: un atribut escrit a la tanca. Serveix qualsevol nom, a més dels que llegeix la mateixa tanca: `:::callout{type="card" kicker="Nota"}` dona a `{attr.kicker}` el valor `Nota`. Un atribut absent no imprimeix res.
- els marcadors del document `{title}`, `{subtitle}`, `{author}` i `{publishDate}`.

El `resourceId` d'una imatge admet els mateixos marcadors, de manera que cada requadre pot dibuixar un recurs propi. Només un disseny de requadre llegeix `{boxText}`; un disseny d'encapçalament no hi imprimeix res.

Amb `setsContent: true` un sol estil serveix per a tots els requadres de la mateixa forma, cadascun amb les seves paraules. En un quadern de cal·ligrafia cada ratlla de pràctica és un requadre el contingut del qual és la paraula que cal copiar: el disseny imprimeix la paraula en una lletra escolar i després la torna a posar en punts per repassar (`dotted`), tantes vegades com caben a la ratlla (`repeat`; vegeu [Marques en línia i contorns](/ca/docs/configuration-headers-footers#marques-en-línia-i-contorns)).

```ts
calloutStyles: [{
  id: 'practice',
  backgroundEnabled: false,
  border: { enabled: true, color: { hex: '#9aa6b2', model: 'hex' }, width: { value: 0.5, unit: 'pt' } },
  design: {
    setsContent: true,
    minHeight: { value: 16, unit: 'mm' },
    slot: { elements: [
      { kind: 'text', id: 'model', content: '{boxText}', fontFamily: 'Playwrite ES', fontSize: { value: 26, unit: 'pt' },
        placement: { anchor: { to: 'container', edge: 'top-left' } } },
      { kind: 'text', id: 'copies', content: '{boxText}', fontFamily: 'Playwrite ES', fontWeight: 100, fontSize: { value: 26, unit: 'pt' },
        dotted: {}, repeat: { gap: { value: 8, unit: 'mm' } },
        placement: { anchor: { to: '#model', edge: 'right-of' }, offset: { x: { value: 8, unit: 'mm' } } } },
    ] },
  },
}],
```

```md
:::callout{type="practice"}
sol
:::

:::callout{type="practice"}
pa
:::
```

La primera ratlla imprimeix *sol* seguit d'una filera de còpies puntejades de *sol*; la segona fa el mateix amb *pa*, i cap de les dues paraules no es torna a compondre sota la seva banda. Si es canvia la paraula al Markdown, canvien el model i totes les còpies. Amb `setsContent` a `false` el disseny llegeix `{boxText}` igualment, i el contingut es compon sota la banda.

Al VDT els elements de la banda són blocs de disseny al `designOverlay` del marc, al costat del títol.
