# 沙盒

**Postext排版引擎的交互式试验场。**

沙盒提供一个编辑器式的界面。你在这里撰写正文、管理资源和字体、调整版面设计，并在五种同步的视图中实时查看结果：**Canvas**、**PDF**、**书页**（3D呈现的印刷书）、**HTML**和**EPUB 3**。它专为试验而设计。你可以改换字体排印或栏数，尝试把图放在不同位置，观察引擎如何响应。各个面板使用出版行业的说法（书、图、框、书眉），而不是引擎术语，出版从业者不必了解配置结构也能上手。每个控件都支持键盘操作和屏幕阅读器。
## 界面布局

沙盒有三个主要区域：左侧窄窄的**活动栏**用来切换面板，中间可调宽度的**侧栏**放置当前面板，右侧的**视口**有各个输出标签页。各面板的标题栏、视口的标签栏和活动栏顶部的标志格高度相同，因此窗口顶端看上去是贯穿整个窗口的一条横带。

### 活动栏

左边缘的一条窄栏，每个面板对应一个按钮。按钮显示一个图标，图标下方是一个词的标签，鼠标悬停时显示较长的提示（同一段提示也是按钮的无障碍描述）。从上到下依次是：

- **书库**（`Files`图标）：你的书和示例书
- **章节**（`BookOpen`图标）：当前打开的书及其各章
- **正文**（`FileCode`图标）：撰写和编辑当前章的文字
- **资源**（`FolderOpen`图标）：书中使用的图像、SVG图示和表格
- **字体**（`Type`图标）：书中使用的字体，以及你自己的字体文件
- **版面设计**（`Settings2`图标）：页面、字体排印、标题、图、标注框和导出设置
- **检查**（`AlertTriangle`图标）：在版面中发现的排版问题。图标上有一个实时计数徽标，显示当前警告的数量，最多显示`99+`。

点击当前面板的按钮会收起侧栏，点击另一个按钮则切换到对应面板。整个活动栏只占一个Tab焦点位置：方向键（↑ / ↓，首尾循环）、**Home**和**End**在按钮之间移动焦点，Enter或空格键打开获得焦点的面板。

宿主应用可以在活动栏中加入自己的项目：顶部格子里可选的**首页标志链接**（通过`homeUrl`或`homeLink`属性），以及底部的**主题切换**和**语言切换**。整本书以`.postext`文件的形式在书库面板中导入导出，正文面板和版面设计面板的标题栏则各自导出自己那一部分（见[导出与导入](#导出与导入)）。

### 侧栏面板

侧栏可以调整宽度。拖动侧栏与视口之间的分隔条，或者用Tab键让它获得焦点后使用键盘：← / →每次把宽度改变2 %（按住Shift时为10 %），**Home** / **End**分别跳到最窄和最宽。分隔条会向屏幕阅读器报告当前数值，视口始终至少保留200 px。没有面板处于打开状态时，侧栏完全收起；侧栏宽度在会话之间保留。

设置行把标签放在控件旁边，侧栏较窄时则放在控件上方。这是用容器查询实现的，所以跟随的是侧栏的宽度，而不是窗口的宽度。

#### 正文面板

一个CodeMirror 6编辑器，用来编辑本章的Markdown。屏幕阅读器把它读作*章节正文*。它提供：

- **语法高亮**：标题、强调、链接、代码块和引文在视觉上各有区别；以下内容有专门的高亮：**YAML前置元数据**、**LaTeX公式**区域、**行内标签**（`:chip[…]`：方括号和属性加以标记，标签文字着色）、**小型大写字母**（`:smallcaps[…]`：方括号加以标记，文字以小型大写字母显示）、竖排文字的**方向标记**（`:tcy[…]`、`:upright[…]`、`:sideways[…]`：方括号加以标记，文字下加点线），以及**中文标注**（`:dots[…]`、`:name[…]`和`:book[…]`在文字下方画出各自的标记；`:ruby[…]{rt="…"}`和`{紅樓|hóng|lóu}`；`:warichu[…]`的注文以较小字号显示）。输入`:do`、`:na`、`:bo`、`:ru`或`:wa`时会提示相应指令
- **行内标签补全**：在词首输入`:c`会提示`:chip[…]`（光标落在方括号之间）。在`{style="…"}`里会提示已配置的行内标签样式id。
- **小型大写字母补全**：在词首（或紧跟在`*` / `_`之后）输入`:sm`会提示`:smallcaps[…]`，光标落在方括号之间。
- **行号**和当前行高亮
- 长段落**自动换行**
- **从右到左的行**：以阿拉伯字母或希伯来字母开头的行从右到左排列，光标和方向键也随之移动。行内的标记（`{…}`属性、`[^id]`标签、指令名、整个`:ref[fig-1]`、公式、代码、链接地址）保持从左到右，读起来与输入时一样。围栏、前置元数据和以拉丁词开头的行仍从左到右。
- **工具栏**：最前面是**撤销 / 重做**，接着是粗体、斜体、1–3级标题、链接、行内代码、**行内标签**（用`:chip[…]`包住选中内容）、**小型大写字母**（用`:smallcaps[…]`包住选中内容）、引文、有序和无序列表，另有三个插入指令的按钮：
  - `:::pagebreak`
  - `:::space`：一行垂直空白（更多行用`:::space{lines=N}`）
  - `:::numbering{format="decimal" startAt=1}`：插入时带有示例属性，可以自行调整

宿主应用可以通过`extraActions`添加自己的工具栏按钮。编辑器还会把光标和选区报告给预览，由此实现点击定位同步：在渲染结果中点击文字，光标会移到Markdown中对应的位置；预览也可以高亮当前选区。

面板标题栏是一个**章节切换器**：上一章/下一章箭头、本章的序号和标题，以及一个菜单，列出书中的每一章，页码范围一旦确定也会显示出来（见[书与章](#书与章)）。每一章有自己的编辑器实例，所以撤销历史和光标位置按章分别保存。标题栏还提供五个操作：

- **重置**（需要确认）：重新载入当前示例书的**文档部分**。所有章和整套图都换成示例书中的内容（对内置示例而言，就是当前语言的示例文档和示例资源）。版面设计保持不变，只有示例书自带的字体例外。见[书库面板](#书库面板)。
- **导出**：把当前章下载为普通的`.md`文件。多章的书命名为`<book>-<nn>-<chapter>.md`，否则以当前打开的书命名，或命名为`document.md`
- **导入**：用一个`.md`文件的内容替换当前章
- **导入Word文档**：打开一份`.docx`书稿，在做出任何改动之前，先把其中的Word样式对应到Postext样式（见[Word文档](#word文档)）
- **导出为Word**：把当前章或整本书下载为`.docx`，再次导入时所有样式都会恢复

#### 书库面板

活动栏中的第一个面板：你的书和示例书的列表，带**新建**菜单、上一次操作的状态，以及示例书有新版本时显示的横幅。在代码和存储中，书仍然叫作*项目*（project），示例书叫作*预设*（preset）。

点击一本书（或示例书的某个语言标签）就会打开它；书显示出来后，侧栏会转到[章节面板](#章节面板)。点击已经打开的书会直接转过去。行菜单（重命名、复制、下载、隐藏、删除）不会切换面板。当前打开的书在列表中有标记。面板分为两组：

- **我的书**：保存在浏览器中（IndexedDB）的本地可编辑的书。当前打开的那本有标记，它的各章在章节面板中。

  打开你自己的一本书时，工作文档*就是*这本书。对正文、版面设计、图和字体的每一处修改都会自动存入这本书（与`localStorage`一样有1秒的防抖延迟），所以你可以切换到别的书再回来，不会丢失任何内容。新书从标题栏的**新建**菜单创建：
    - **复制当前的书**把当前打开的书连同其中的图和字体复制成一本新书。
    - **空白书**新建一本空书。
    - <strong>打开.postext文件…</strong>导入一个文件。

  你也可以复制任意一行。在你还没有自己的书时，这一组显示空状态，并提供同样的快捷入口。每一行有一个带标签的<strong>⋯</strong>菜单（*“…”的更多操作*），其中有**重命名…**、**复制**、<strong>下载（.postext）</strong>和**删除…**。删除时会在⋯按钮旁边直接请你确认。

  重命名会在行内打开名称和说明两个输入框。在任一输入框中按Enter会同时提交两者，按Escape取消。

  书还带有一张**封面图片**，显示在示例书显示缩略图的位置。复制一本示例书（或另一本书）时，会沿用它的封面。某一行处于重命名状态时，封面本身就是设置封面的控件：点击它选择一张PNG、JPEG、WebP、GIF或SVG图片，或者用旁边的X移除当前封面。封面属于书，而不属于书中的图，导出和导入时随书一起保存。

  没有封面的书会从它的**第一页**（第一章的第一页）取得封面：这一页第一次在Canvas标签页中排版并绘制时，沙盒会在浏览器空闲、字体和页面上的图片都已载入之后，给它拍一张小图（宽240 px，JPEG）。这张图作为书的封面保存，因此下载时会作为文件包的`thumbnail`一并带上。不带缩略图的示例书也以同样的方式获得一张封面，保存在浏览器中（IndexedDB数据库的`presetCovers`存储区，每个示例、每种语言一张），显示在它所在的行中，复制或下载它时也会沿用。已有的封面永远不会被替换，无论它来自示例书、导入的文件、你自己的选择，还是更早的一次截取。你移除的封面会在以后某次访问时重新从第一页截取。

  打开一本书从不需要确认：无论离开的是哪本书，都会先保存。下一本书载入期间，视口显示*正在打开这本书…*，而不是你离开的那本书。删除当前打开的书后，会回到内置示例。

- **示例书**：列在你的书下面，作为起点。文件包本身永远不会改变，但你对示例书的修改会保留下来：第一次修改时，会在浏览器中保存它的一份副本（它的*草稿*），每个示例、每种语言各一份，该行显示*已修改*标签。再次用同一种语言打开这本示例书时，会载入你的版本；从未修改过的示例书则按发布时的样子打开。每一行的⋯菜单提供：
    - **建立我的副本**把示例书变成你自己的书，其中保存文件包各个文件的独立副本，因此以后磁盘上的文件包再有改动也不会影响它。
    - <strong>下载（.postext）</strong>把示例书保存为`.postext`文件。
    - **从列表中隐藏**把示例书从列表中移除（内置示例不能隐藏）。
    - <strong>恢复原版…</strong>丢弃你对这本示例书的修改（所有语言），如果它当前处于打开状态，就在原处载入发布的版本。它会先请你确认，而且只出现在修改过的示例书上。

  有多种语言的示例书，每种语言显示一个标签，顺序与清单文件中列出的顺序一致：繁体中文和简体中文分别是繁和简，其他语言显示语言代码（EN、ES）；悬停提示用界面语言写出语言名称（*载入繁体中文版本*）。原文语言与界面语言不同的示例书（例如附有英文译本的中文小说）会说明它以哪种语言打开（`openLocale`，见[预设文件包格式](#预设文件包格式)），所以点击该行时打开的是原文。

  隐藏的示例书集中在这一组底部一个*已隐藏的示例书*折叠区中，每一本都有**在列表中显示**。这一选择保存在`localStorage`中。

从**新建**菜单打开的`.postext`文件会成为一本新书并处于打开状态。包含多种语言的文件会先询问导入哪一种，默认选中它的原文语言（清单文件中的`locale`）。导出是逐行的操作：当前打开的书所在的行导出屏幕上的内容。`.postext`文件就是把预设文件包目录压缩成的zip（见[导出与导入](#导出与导入)）。

正文面板和版面设计面板中的重置按钮会恢复这本书所复制的那本示例书。空白书或导入的书没有原版，所以打开这类书时这些按钮是隐藏的。

#### 章节面板

活动栏中的第二个面板，只显示当前打开的书。顶部是书名、书的类别（*你的书*，或*示例书*，附带语言，修改后还有*已修改*标签），以及一个⋯菜单，其中是针对这本书的操作：你自己的书有**重命名…**（双击书名效果相同），此外有**复制**或**建立我的副本**、**下载（.postext）**，修改过的示例书还有**恢复原版…**。

下方的**各章**占满面板其余部分，并且单独滚动（见[书与章](#书与章)）。每一章所在的行显示页码范围和字数，当前章有标记。中文、日文或韩文的书改为统计字符：每个汉字、假名或谚文字母计为一个，夹在其中的每个拉丁文单词也计为一个。**添加章**位于面板标题栏中章数的旁边；拖动行的拖动柄（或在拖动柄上按方向键）可以调整顺序；每一章的⋯菜单提供**重命名**、**上移 / 下移**、**按一级标题拆分**、**并入上一章**和**删除**（最后一章永远不能删除）。

##### 示例书（预设）

**预设文件包**是作为一个整体载入的完整起点：各章的Markdown、一份`PostextConfig`、资源（连同位图/SVG数据和表格模型），以及配置所引用的自定义字体文件。面板列出沙盒能访问到的所有预设，并标出当前打开的那个：

- **内置预设**：*Postext指南*，随软件包附带的默认示例书。它始终可用，始终排在列表第一位，并且是**公开的**。它有英文、西班牙文、加泰罗尼亚文、阿拉伯文、简体中文、日文和巴西葡萄牙文七个版本（该行的ES、CA、EN、ع、简、日和PT按钮；`#preset=postext-guide&lang=zh-Hans`链接到中文版，`lang=ar`链接到阿拉伯文版，`lang=ja`链接到日文版，`lang=pt-BR`链接到巴西葡萄牙文版）。阿拉伯文版按阿拉伯文书籍排版：从右到左，右侧装订，使用东阿拉伯数字，字体为Amiri、Noto Kufi Arabic和IBM Plex Sans Arabic，用卡希达（kashida）延长连笔来两端对齐，插图左右镜像并配阿拉伯文标注。中文版有自己的版面设计（Noto Serif SC和Noto Sans SC、大陆标点和断行规则），图中的标注也改成了中文。日文版同样是竖排的书，按日文的规则（JLReq）排版：Noto Serif JP和Noto Sans JP，9.25 pt的正文，每页上下两栏、每栏34字，节标题占三行（行取り），书眉和阿拉伯数字页码横排在天头和地脚，插图配日文标注。每种界面都打开自己语言的指南。从别的界面（用该版的按钮或`lang=`链接）打开的未经修改的中文、日文或阿拉伯文指南，无论界面是哪种语言都保持原来的语言；中文、日文或阿拉伯文界面自己打开的那一版，则和其他版本一样，下次以哪种界面语言打开沙盒，就换成哪种语言。
- **远程预设**：通过HTTP从`presetSources`属性传入的基础URL提供的文件包（见[属性](#属性)）。每个来源要么是公开的，要么是**私有的**。私有预设在列表中带*私有*标签，用于不能离开本机的材料。公开网站只在本地开发时列出私有来源，此时Next.js应用通过`/api/private-presets`提供`POSTEXT_PRIVATE_PRESETS_DIR`所指定的文件夹。生产环境从不列出它。网站的公开来源`/presets`提供其示例书：西班牙语和英语双语的*Bioquímica*、*Deep Sky*、*Don Quijote*、*Physics (OpenStax)*、*Spanish Painting*和*Signals 2020*，有三个版本的《红楼梦》，以及只有英文版的*Paradise Lost*（维里蒂的注释作为脚注，配多雷的插图）。每一本都附有许可证和出处。
- **`default: true`**：标为默认的私有预设会在*原始状态*的沙盒（内置文档未经改动）第一次打开时自动载入。有多个预设带此标记时，`locale`与界面语言相符的那个优先。公开预设从不自动载入。

每一行显示预设的名称、可选的说明、语言标签，以及*私有* / *默认*标签。点击一行会**完整**载入预设：正文、图、版面设计和字体。沙盒先把字体文件和图的数据写入IndexedDB，因此视口永远不会看到只应用了一半的文档。点击一行时，示例书以界面语言打开；但如果你只在另一种语言中修改过它，则打开你最近的版本。双语示例书的语言标签会以对应语言打开它（如果你在该语言中有自己的版本，就打开你的版本）。

**实时预设**。远程预设会被自动跟踪。每次应用预设时，沙盒会记录文件包的*指纹*，以及所应用的Markdown、配置和资源集合的哈希值。页面可见期间，它每3秒轮询一次指纹；标签页重新变为可见或窗口重新获得焦点时，也会立即检查。指纹发生变化时：

- 如果这本书**未经改动**（Markdown、配置和资源的哈希值仍与预设应用时相同），预设会完整地重新应用，面板中会短暂显示一条提示。
- 如果有**本地修改**，这些修改会保留下来。面板顶部出现一条横幅（*这本示例书有新版本。你的修改会保留。*），提供**载入新版本**；它在丢弃你对示例书该语言版本的修改之前会先征求确认。在此期间，活动栏中的书库按钮会显示一个圆点。草稿记得它是基于哪个版本建立的，所以在你载入新版本之前，每次打开它时横幅都会再次出现。草稿中的图如果其文件在新版本中有变化，会保留原来的字节：在写入文件包的新文件之前，草稿会先得到这些文件的独立副本。只有打开示例书时才会跟踪文件包。从示例书复制出来的书保留它自己的副本。

载入时也会执行同样的检查，所以如果你先编辑了文件包再打开沙盒，只要这本书未经改动，沙盒就会载入新版本。指纹来自`<preset-dir>/fingerprint.json`。在开发路由中，这是一个虚拟文件，返回目录的一个只基于元数据的哈希值（见附录[预设文件包格式](#预设文件包格式)）。不提供这个文件的来源不会被跟踪。

#### 资源面板

管理书中的资源：位图图像、SVG图、表和视频。正文用`::resource{id="…"}`块和`:ref{id="…"}`行内引用来引用它们。引用语法和浮动模型见[文档格式 → 资源](/zh/docs/document-format#资源)。

**列表视图**。标题栏显示资源的数量。资源按资源类型名称分组，每组是一个带计数的列表。`typeId`已与任何配置的类型都不匹配的资源归入*未分类*组，以便你仍能找到它们。每一项在题注和id旁边显示一个36 px的缩略图：位图和SVG显示真实预览，视频显示带播放徽标的封面，表显示一个图标字符。书中资源超过六个时，会出现一个**搜索**框（*搜索资源…*），按题注和id过滤列表，并忽略重音符号。书中还没有资源时，空状态会说明如何添加资源，以及如何用`:ref{#id}`把它们放进正文。**新建**下拉菜单提供四种添加方式：

- **上传图像**：PNG、JPEG、WebP或GIF
- **上传SVG**
- **新建表格**：初始为一个2×2的网格，带一行表头
- **添加视频**：一段YouTube或Vimeo视频、一个视频文件，或某个视频的地址（MP4或HLS流；见下文*视频*）。资源类型早于视频功能的书，在添加第一个视频时会得到内置的*视频*类型。

你也可以把磁盘上的文件拖放到面板上，视频文件（MP4、WebM、Ogg、QuickTime）也可以。它们会批量上传，id由文件名转换成的slug生成。不支持的文件会被跳过，并有一条简短的说明报告添加了多少个、跳过了多少个。

**详情视图**。选中一个资源会打开它的编辑器：

- **ID**：可以编辑，并按slug规则校验。重复的id会被标出，永远不会提交；空id会得到一个由题注生成的建议值。重命名时保留已存储的图像或SVG文件。
- **类型**：已配置的资源类型之一
- **题注**：支持行内Markdown（粗体、斜体、代码和`:ref`）。`\\`或行末的反斜杠表示换行；普通的换行符算作一个空格
- **注释**：可选的来源说明、出处或备注，以较小的字号排在资源下方（行内格式和换行规则与题注相同）。它的样式由*题注*设置中的*注释*组决定。
- **替代文字**：供HTML输出使用的无障碍描述
- **表格样式**：对表而言，是这张表所用的命名样式（`table.styleId`）。它要么是*文档表格样式*（默认），要么是设置中声明的某个*表格样式*。没有任何样式声明的id会列为缺失，并以文档表格样式渲染。
- **位置**：
  - **位置**：`auto`（第一个空位，默认值）、`top`、`bottom`或`here`。
  - **跨度**：`column`、`page`或`side`。位置为`here`时不可用。默认值与引擎一致，即`auto` + `column`。
  - **跨栏数**：在多栏页面上，单栏浮动对象横跨的相邻栏数（`placement.columns`），例如报纸四栏中跨两栏的图片。等于页面的栏数时即为通页。书或其中某一章节不止一栏、且跨度为`column`时显示；位置为`here`或资源转向时不显示。
  - **方向**：正放，或者转四分之一圈（顶部朝左或朝右）。转向的资源独占一页，紧贴书脊，所以跨度选择不可用。
  - **宽度**：宽度比例加对齐方式，用于比所在栏窄的浮动体和行内嵌入。对齐方式也用来安放以全宽设置、却比所在位置窄的位图或SVG（比栏窄的位图，或被`layout.fitFiguresToPage`缩小的图），所以对图片它始终可用；对表而言，宽度须小于100%。转向的资源两者都没有。
  - **题注在图旁**：用于一栏半版式中侧栏的开关。它只对栏内浮动体有效，所以位置为`here`时隐藏。
- **数据**：替换位图或SVG文件的上传控件
- **视频**：用于视频资源（[文档格式 › 视频](/zh/docs/document-format#视频)）：
  - **来源**：*YouTube*、*Vimeo*或*文件*。
  - **视频地址**（YouTube、Vimeo）：视频的任意链接。链接指向一个新视频时，会从平台获取它的封面、画面尺寸和标题（替代文字为空时，标题成为替代文字）；**重新获取封面帧**再做一次。不指向该平台任何视频的链接会在字段下方标出。
  - **视频文件**（文件）：上传MP4、WebM、Ogg或QuickTime文件的控件，显示文件的格式、大小和时长。第一张封面取自视频十分之一处。**封面帧**播放文件：停在或拖到你想印出的那一帧，再按**用这一帧作封面**。**正式发布地址**：视频发布后所在的位置（`https://…`），由二维码和PDF链接打开；没有它，印刷版就没有二维码和链接。
  - **视频地址**（文件，且没有上传文件）：视频只从它的地址播放，可以是服务器上的MP4或WebM，也可以是HLS流（`.m3u8`，字段上方标有*HLS流*）。填入地址后会读取视频的尺寸和时长，**封面帧**也从这个地址播放它，HLS同样可以。选取画面需要服务器允许跨源读取（CORS）；否则面板会提示“视频所在的服务器不允许读取其画面（CORS）：请改为上传封面”，这时就上传一张封面。二维码和PDF链接打开这个地址。
  - **封面**：印出的图片及其尺寸，另有一个上传控件，可以换成你自己的图片。
  - **开始（秒）** / **结束（秒）**：播放的片段；0表示不改开头或结尾。
  - **播放器**：这个视频的各项开关（控件、下载按钮、全屏、倍速菜单、画中画、自动播放、静音开始、循环播放、与其他视频同时播放），每项可选*全书设置*、*是*或*否*。只列出该视频播放器支持的开关。
- **安全区**：用于位图和SVG，指图片中任何时候都要显示的部分（`Resource.safeArea`；见[文档格式 › 安全区](/zh/docs/document-format#安全区)）。这一栏显示一张标出安全区的缩略图和安全区的百分比尺寸，图片没有安全区时显示“未设定”，并有**标记安全区** / **编辑安全区**和**移除安全区**按钮。对话框中显示图片：在矩形外拖动画出新的矩形，在矩形内拖动移动它，拖动手柄调整大小；矩形获得焦点时，方向键移动它，Shift加方向键调整大小。*左*、*上*、*宽*、*高*四个字段以百分比设定它，两个预览分别显示安全区允许的最高裁切和最矮裁切。
- **SVG源码**：对SVG图而言，上传控件下方有一个源码编辑器。只有文字节点接受编辑：即`<text>` / `<tspan>`元素的内容，在编辑器中着色显示。在其他地方的输入会被拒绝；在文字节点中输入的`<`、`>`和`&`会被转义，使文件保持格式正确。每次修改在短暂停顿后保存为一个**新的**存储文件，图随之重新渲染（包括单色重着色）。SVG没有文字节点时，编辑器会加以说明。
- **预览**：资源外观的实时示意，用`#`代替编号（实际编号取决于资源在文档中落在哪里）。题注以文档设定的标签开头：类型的题注前缀加编号（`Figure #.`）；编号模板为空的类型只有前缀（`Do.`）；没有题注前缀的类型则什么都没有
- **删除**：先请你确认，并提醒正文中有多少处`::resource` / `:ref`引用会因此失去目标

**表格编辑器**。表资源打开一个交互式网格编辑器：

- **工具栏**：
  - 添加或删除行和列，合并或拆分单元格。
  - 开关表头行或表头列。
  - 设置每个单元格的水平和垂直对齐（顶部、居中或底部）。在较高的行中，单元格内容作为一个整体移动。
  - 设置每个单元格的填充色：一个可以关联调色板的颜色选择器，带清除按钮。填充色写入`TableCell.background`，并显示在网格中。
- **列宽**：网格下方每列一个数字权重（`2, 1, 1`使第一列占一半宽度；留空表示等宽），写入`table.model.columnWidths`。添加或删除列时权重保持对应，*等宽*链接可以清除它们。
- **粘贴为表格**：粘贴TSV（或简单的带引号CSV）会填满网格
- **撤销/重做**：Cmd/Ctrl+Z和Shift+Cmd/Ctrl+Z
- **键盘导航**：Tab / Shift-Tab（换行循环）和方向键在单元格之间移动
- **在预览中点击编辑**：在任一预览标签页中点击表格单元格、题注、注释或SVG图中的一段文字。资源面板会打开这个资源，并让对应字段获得焦点，光标落在所点击的字形上。拖动可以在同一单元格或字段中选择一段范围，双击选中一个词。字段获得焦点期间，它的选区会以高亮的形式映射回页面（选区折叠时显示为一条细光标），Canvas和HTML标签页都是如此。

所有编辑都通过postext核心导出的纯模型函数完成（`addRow`、`addColumn`、`removeRow`、`removeColumn`、`mergeCells`、`unmergeCell`、`setCellContent`、`setAlignment`和`parseTSV`），所以同一个表格模型在沙盒内外的行为完全相同。

#### 字体面板

显示书中使用的字体，并在内置的Google Fonts目录之外管理你自己的字体文件：

- **本书使用的字体**列出版面设计用到的每个字族。每个字族名都用该字体本身排出，并注明其用途（*正文*、*标题*或*其他元素*）和来源（*Google Fonts*或*你的文件*）。字体本身在**版面设计 → 字体排印**和**标题与目录**中更改。
- **你的字体文件**用来添加、重命名和删除自定义字族。
  - 按字重（100–900）和样式（常规 / 斜体）**上传字体文件**。接受的格式为WOFF2、WOFF、TTF和OTF，按文件扩展名识别。文件保存在浏览器的IndexedDB中。
  - 自定义字族出现在每个字体选择器的**自定义**分组中，与Google Fonts的结果并列。自定义字族**优先于**同名的Google字体。
  - 在中文文档中，每个字体选择器首先在*简体中文*或*繁体中文*下列出包含文档所用字符的Google字族（Fontsource的`chinese-simplified`、`chinese-traditional`和`chinese-hongkong`子集），然后才是其余字族。
  - 在阿拉伯文（或其他用阿拉伯字母书写的语言）文档中，每个字体选择器首先在*阿拉伯文*下列出带有Fontsource `arabic`子集的Google字族，书籍字体排在前面（Amiri、Noto Naskh Arabic、Scheherazade New、Markazi Text、Lateef，然后是Noto Kufi Arabic、Reem Kufi、Aref Ruqaa、El Messiri）。预览在第一次排版前加载每种字体的阿拉伯文文件；正文同时用到阿拉伯文和拉丁文时，PDF把两个文件都嵌入。
  - 孤立的字体文件（已不被任何字族使用的上传文件）会自动从IndexedDB中删除。

#### 版面设计面板

一个基于表单的`PostextConfig`编辑器，有五百多个字段。

**概览**。打开版面设计面板时，首先显示概览：

- 一张**本书**卡片，附有页面的实时示意图。示意图按真实比例绘制，显示页边距、栏以及页面和油墨的颜色；页边距为对称设置时画成跨页。竖排的书，文字行从右侧起自上而下画出，各栏画成上下叠置的几层。旁边列出成品尺寸、栏式、书写体系、正文字体和字号，以及调色板。书写体系一行写出文档语言，方向和装订边可以选择时也一并写出（*竖排 · 右侧装订 · 中文（繁體）*，*从右到左 · 右侧装订 · العربية*）；点击它会打开**书写体系**。
- 十三个**设置组**的列表。每组附有一句话的说明，以及你在该组中改动过的分区数量。

**每组一页**。打开一组时，该组的各个分区显示为单独的一页。只构建这一组，因此即使是大部头的书，面板也能保持流畅。

- 面包屑导航（**版面设计 › 组名**）可以返回概览。
- 页面标题下方的标签可以跳到页面上的各个分区。
- 底部的**下一组**链接打开后面的一组。
- 打开一组时，焦点移到页面标题；返回时，焦点回到该组所在的行。
- 当前打开的组在会话之间保留。

各组按浏览顺序排列如下：

- **页面与栏**
  - *页面*：字段分为**尺寸**、**页边距**、**纸张**和**编号**几组。
    - **尺寸**：尺寸预设写明各自的用途：*口袋书*11 × 17、*小说、叙事类*12 × 19、*随笔、手册*17 × 24和*教材、杂志*21 × 28，报纸开本*大报*37.5 × 59.7、*柏林版*31.5 × 47、*小报*28 × 43和*紧凑版*29.7 × 42（postext 1.18起），或者*自定义*。**排版分辨率（每英寸像素）**（`page.dpi`）也在这里：它是排版所用的像素数，不是图片的分辨率，不过按原始尺寸放置的位图就以这么多ppi印刷。
    - **页边距**：每个页边距都与页面示意图关联。指向或聚焦某个页边距字段时，示意图上对应的页边距会着色。**对称**开关把左/右页边距变为对页的内侧/外侧页边距。
    - **纸张**：页面背景色。
    - **编号**：页码格式和起始页码。
  - *栏*：版式从图示卡片中选择：*单栏*（小说、随笔）、*双栏*（教材、杂志、工具书）、*一栏半*（一个主栏加一个窄侧栏，用于注释和小图）或*多栏*（三到八个等宽的栏，用于报纸和杂志，栏数在**栏数**中设定；postext 1.18起）。这一分区还有栏间距、侧栏、**缩小放不下的图**（`layout.fitFiguresToPage`）、**行内图周围的间距**（`layout.inlineResourceGap`）、**框内图周围的间距**（`layout.inlineResourceGapInBoxes`）、**框断开处段落的行数**（`layout.boxChildSplitMinLines`）和**收尾浮动体紧贴正文**（`layout.hugClosingFloats`）。
- **书写体系**。页面开头是“页面与栏”中的那张示意图。它的跨页标有页码：左侧装订的书为2 | 3，右侧装订的书为3 | 2，奇数页在左边；题注会说明书是否右侧装订、文字行是否竖排。
  - *语言和方向*：
    - **文档语言**，中文列为中文（简体）、中文（繁體）和中文（香港），阿拉伯文列为العربية、العربية (مصر)和العربية (المغرب)（地区决定数字等地区默认值）。列表中没有的语言标签（`es-ES`、`zh-TW`、`sv`）显示为一个额外选项，以它所对应的语言命名。更改语言时，如果内置的图和表类型仍是前一种语言的名称，就会随之改名（西班牙文的书改成中文后印出图和表，而不是*Figura*和*Tabla*）；你改过名的类型保留原名。
    - **文字方向**：*自动*（写明它解析成什么，阿拉伯文为从右到左）、*从左到右*或*从右到左*（`direction`）。
    - **书写方向**，从图示卡片中选择：*横排*，或*竖排*，即文字行自上而下、从右到左排列（`layout.writingMode`）。
    - **装订边**：*自动*（写明它解析成什么，竖排或从右到左的书以及从右往左读的漫画书为右边）、*左边*或*右边*（`page.binding`）。
    - **数字**：*自动*（写明语言给出的数字：阿拉伯文为٠ ١ ٢ ٣，马格里布地区的阿拉伯文和其他所有语言为0 1 2 3）、*欧洲数字*、*阿拉伯-印度数字*或*波斯数字*（`numerals`）。
    - **中文默认设置**：<strong>查看…</strong>列出把书设置为中文时会改变哪些设置。选择*简体*或*繁體*以及方向：新的繁体书默认竖排，新的简体书默认横排，已经是中文的书保持原来的方向。每一行显示设置的当前值和改后的值：文档语言（同一书写系统的中文标签，例如`zh-TW`，会保留）；书写方向及其对应的装订边；正文和标题使用SC、TC或HK版本的Noto Serif和Noto Sans（标题一行还会列出各级标题和标题样式自行设定的字体，勾选后这些也改用中文字体）；首行缩进2 em；标题后缩进；段间无空白；两端对齐；不断词；图或圖以及表按章编号（`{h1}-{n}`）；题注排成图1-1　标题（编号前无内容，编号后一个全角空格）；章编号为第一章（`第{1:一}章`，标题前一个全角空格）；编号列表为一、 （一） 1. （1） ①。只列出有差别的项。你自己改过的设置默认不勾选，标为*你的设置*，除非你勾选它，否则保持不变；语言和方向始终会应用，断词也是如此，因为中文文档会自动关闭断词（除非你在断词语言中指定了某种拉丁语言并为它打开了断词）。**应用**一步完成所有勾选的修改；确认信息旁边的**撤销**在同一本书中撤回这一步：它改过的每项设置都回到原来的值，即使此后你改动了同组的其他设置；此后你又改过的设置则保持你留下的样子，确认信息会说明这一点。打开另一本书后，撤销不再可用。
    - **阿拉伯语默认设置**（阿拉伯文文档中显示）：<strong>查看…</strong>列出把书设置为阿拉伯文时会改变哪些设置。先选择字体：*古典*，正文和标题都用Amiri；或*现代*，正文用Noto Naskh Arabic，标题用Noto Kufi Arabic。各行依次是：书原本设为从左到右时，方向改回*自动*（始终应用）；装订边改回*自动*（右边）；两种字体；用没有阿拉伯字母的字体排的设计文本（页眉、页码、篇章页和标题设计）改用标题字体，以免PDF印出空框；行距1.75 em；两端对齐；不断词；书指定了其他数字时改用所在地区的数字；شكل和جدول按章编号；题注排成شكل ١-١: العنوان；章编号为الفصل الأول（`الفصل {1:ordinal}`，标题前加冒号）；编号列表为١- أ- (١)；脚注每页重新编号；编号都使用文档的数字。勾选、*你的设置*、**应用**和**撤销**与中文默认设置相同。
    - **日语默认设置**（日文文档中显示）：<strong>查看…</strong>列出把书设置为日文时会改变哪些设置。先选择书的类型：*竖排 縦組*，即按字符网格排、右侧装订的文库本或单行本小说；或*横排 横組*，即左侧装订的技术书。各行依次是：文档语言和书写方向（始终应用）；装订边改回*自动*；正文和标题用Noto Serif JP和Noto Sans JP（用没有假名的字体排的设计文本也改用它们）；行距1.75 em；竖排页面在这一字号下能容纳的字符网格（每行最多52字）；缩进一个字，段间不加空白；两端对齐、不断词；中文排版设置改回*自动*，让日文设置生效；図和表，题注排成図1-1　…；章编号为第一章（竖排）或第1章（横排）；占三行和两行的标题（行取り）及其缩进；日文列表编号；中文注释设置改回*自动*；在切口竖排页码时改用汉字页码。**应用**和**撤销**与中文默认设置相同。日文书的编辑器工具栏会增加**注音**和**纵中横**两个按钮。见[日文排版](/zh/docs/japanese-layout#在沙盒和排版食谱中)。
  - *东亚排版*（`cjk`）：最上面是**地区规范**（中国大陆、台湾、香港、日本），其后的字段分为九组：**行首行尾**（**断行规则**：无、基本、GB、严格、日文最严格、日文严格、日文宽松；**行首行尾括号减半**；**段首括号**：①、③或顶格；**标点悬挂**）、**标点宽度**（**标点宽度**：开明式、全角、行末半角、半角；**相邻标点挤压**）、**间距**（**汉字与拉丁字母之间的空白**；**？！后空格**）、**竖排文字**（**纵中横数字**：关闭，或最多2、3、4位数字，`cjk.uprightDigits`）、**标注**（**中日文强调**：`*…*`印成着重号还是斜体；**着重号形状**、**着重号填充**和**着重号位置**；**书名（:book）**：括号、波浪线或不加标记，以及所用的**书名号**，《》〈〉或『』「」；**标记颜色**）、**注音**（注音文字的字体、字号、颜色和位置，**注音伸出**、**注音对齐**和**注音中的小假名**）、**割注**（注文的字号、颜色以及前后括号）、**汉文训点**（记号的字号、颜色以及返点的位置）和**字符网格**（每行字数、每页行数、屏幕上显示的网格，以及“字 × 行”读数和网格所决定的页边距）。每个*自动*都跟随文档语言，并写明它解析成什么。在语言不是中文、日文或韩文，而且没有设置其中任何一项的文档中，这一分区只显示一行说明和一个**显示这些设置**按钮；搜索时，任何文档都会显示这些字段。[中文排版](/zh/docs/chinese-layout)和[日文排版](/zh/docs/japanese-layout)解释这些设置的作用；配置键见[东亚排版](/zh/docs/configuration#东亚排版)、[竖排](/zh/docs/configuration#竖排)、[竖排中的数字](/zh/docs/configuration#竖排中的数字)和[装订边](/zh/docs/configuration#装订)。
- **颜色**
  - *调色板*：供每个颜色选择器复用的命名颜色。修改某一项会更新所有引用它的地方。
- **字体排印**
  - *正文*：开头是一份按实际大小排出的**字样**，用当前的字体、字号、行距和颜色，以文档的语言排出：中文书以本书所用的简体或繁体字形显示《紅樓夢》的开头，`*…*`加着重号，文字行竖排时自上而下排列。字样的断行由浏览器决定，页面上的断行由Postext决定。字段分为以下几组：
    - **字体**：字体、字号、行距，以及常规和粗体的字重。
    - **段落**：对齐方式（正文两端对齐时，附有断词、两端对齐的限度和**两端对齐时最大字距**（`bodyText.maxJustifyTracking`）；不两端对齐时，附有**齐左文字断词**及其断词区、**最优断行**和**齐左文字最优断行**（`bodyText.optimalRagged`）；正文两端对齐时，**齐左文字最优断行**跟在**最优断行**后面，供齐左的段落样式和标注框使用；**跨栏断词**（`bodyText.hyphenateAcrossColumns`）在正文两端对齐时位于断词之下，在正文齐左时位于**齐左文字最优断行**之下，且只在该项打开时出现；**复合词断词**（`bodyText.hyphenation.compounds`）与断词语言放在一起）、**破折号后断行**（`bodyText.breakAfterDashes`）、**连字符后断行**（`bodyText.breakAfterHyphens`）、**在下一行重复连字符**（`bodyText.repeatHyphen`）、**强制换行**（`bodyText.hardLineBreaks`）、缩进和段间距。
    - **颜色**：正文、粗体和斜体的颜色。
    - **语言**：文档语言，用该语言本身写出名称。它在**书写体系**中设置；点击这一行会打开那一组。
    - **孤行与短行**（可折叠）：包括**分级孤字罚分**（`bodyText.gradedRuntPenalty`）、**收紧以拉回孤字**（`bodyText.tightenRunts`）、**最大收紧字距**（`bodyText.maxRuntTracking`），以及**冒号与列表不分离**及其**冒号下方的空间**（`bodyText.colonListRoom`）：以冒号结尾的行下方需要多少空间才能与列表留在一起，可以是第一个列表项所需的空间，也可以像postext 1.4及以前那样只需一行。
    - **引文**（可折叠）：`>`引文的颜色、**引文用斜体**、**引文缩进**和**引文首行缩进**（`bodyText.blockquote`）。
    - **诗歌**（可折叠）：**无分隔符的诗**（*逐行*，或*按半句（1.22）*）、**每个空格的缩进**、**转行**（*悬挂*或*靠右*）及其**转行缩进**或**转行标记**、**诗节间距**和**短诗节不拆分**（`bodyText.verse`，逐行排的`:::verse`诗的默认值）。
    - **交叉引用**（可折叠）。
  - *段落样式*（`paragraphStyles`）：供`:::paragraphs{style="…"}`容器使用的命名样式。你可以添加、删除和重命名id，然后设置字体、字号、行距、颜色、粗体和斜体文字的颜色、常规和粗体字重、**斜体**和**小型大写字母**开关、对齐方式、断词、每一行的左缩进、首行缩进和悬挂缩进（从左缩进处量起）、段间距、外边距、**对齐网格**（`paragraphStyles[].snapToGrid`）、**大小写**（`textTransform`，大写）和**行号**（`paragraphStyles[].lineNumbers`：*跟随文档*、*计入*或*不计入*）。未设置的字段继承正文。在各样式之上，**容器下方的间距**（`bodyText.paragraphContainerSpacing`）决定容器下方的空白如何与其后的块相接：*折叠*，或*相加（1.4）*。
  - *行内标签*（`chipStyles`）：供行内`:chip[text]{style="…"}`使用的命名样式。配置中没有任何样式时，显示内置的`chip`样式。你可以添加、删除和重命名id，然后设置：
    - **文字**：字体、字号、颜色、粗体和斜体。每一项在你设置之前都继承周围的文字。
    - **框**：填充色、轮廓粗细和颜色、圆角半径、水平和垂直内边距（可以用**上内边距**和**下内边距**分别设置，使大写字母在圆形标签中居中），以及与相邻词之间的最小间隙。
  - *公式*（`math`），带**独立公式后缩进**（`math.indentAfterDisplay`）和**与引出行不分离**（`math.keepWithLeadIn`）。
  - *脚注*（`footnotes`）：**位置**（栏底或章末）、章末时的**在栏中的位置**、**编号**（按章或连续）、注文的字号、行距、颜色、对齐方式和悬挂缩进、注文上方和注文之间的间距，以及**分隔线**（长度、粗细、颜色）。见[脚注](/zh/docs/configuration#脚注)。
  - *行号*（`lineNumbers`）：**标注行号**、**计数对象**（*诗行*或*所有行*）、**间隔**、**标注第一行**、**重新计数**（从不，或每章、每节、每页、每首诗）及**起始行号**、**位置**（外侧页边或内侧页边、左侧、右侧、行首一侧、行尾一侧、侧栏）、**多栏时**（外侧两边、栏间、每栏旁边）、**与正文的距离**、**对齐**，以及行号的字体、字号、字重、斜体、颜色和**编号格式**。见[行号](/zh/docs/configuration#行号)。
- **标题与目录**
  - *标题*：通用默认值，加上H1–H6各级的设置。其中包括：
    - 大小写、**字距**（`levels[].letterSpacing`，负值表示收紧）、对齐方式（齐左、两端对齐、居中或齐右）、前置分页及奇偶页，以及跨度；
    - **标题后回到网格**开关（`headings.snapToGrid`，默认打开：标题下方的正文回到基线网格上），以及各级的**本级标题后回到网格**（`levels[].snapToGrid`），为该级覆盖上述设置；
    - **标题中的行内标记**开关（`headings.inlineMarks`，默认打开）：标题像段落一样排出其中写的斜体、粗体、上下标、小型大写字母和链接；关闭时，被标记的词按标题自身的样式印出；
    - 各级的**隐藏（结构性）**（`levels[].hidden`）：标题不印任何内容，也不占空间，但仍然分页、编号，并为目录、书眉和PDF书签提供条目；
    - 高级的各级版面设计槽位编辑器，带最小章首高度；标题版面设计中的每个元素都有一个**预留空间**开关（关闭时，它只绘制，不增加标题所预留的高度）；
    - 各栏齐底的调节手段及其各自的上限，以及**收尾标注框**（`balancing.closingBox`）：结束一个短栏的标注框何时移到栏底——最先、在其他手段之后，或从不。
  - *标题样式*（`headingStyles`）：在标题行上用`{style="…"}`应用的命名样式。你可以添加、删除和重命名id，每种样式可以：
    - 选择标题是否编号、是否列入目录，并给它一个自己的编号模板；
    - 关闭**用于书眉**（`runningChapter`），供在章内作为H1排出的图版或地图使用，这样书眉仍显示被它打断的那一章；
    - 覆盖标题的字体排印（包括字距）、分页和跨度、**本级标题后回到网格**和**隐藏（结构性）**；
    - 为这一部分设置自己的书眉，可以从文档的书眉出发修改；
    - 设置其页边距和栏式（包括侧栏的作用和位置，与*栏*中相同，以及它自己的*缩小放不下的图*）；
    - 设置正文样式、列表覆盖设置和调色板颜色。
  - *目录*（`toc`）：`:::toc`列出的标题级别，以及每一级条目的字体排印。它还涵盖不编号的条目、页码、引导点、从标题属性读取的副标题行，以及带有自己版面设计槽位的篇的行。
- **列表**
  - *项目符号列表*，带**顶部对齐网格**（`unorderedLists.snapTopToGrid`），它把列表上方的空白向上取整，使第一项落在基线网格上。
  - *编号列表*：每一级编号后分隔符的字体、字重、斜体、颜色和间隙；**顶部对齐网格**（`orderedLists.snapTopToGrid`），与项目符号列表相同；以及**编号栏**（`orderedLists.numberWidth`）：列表项文字从哪里开始，按它所在的一组列表中最宽的编号（*按组*），或按本章中同一级最宽的编号（*按级*）。
- **图与表**
  - *编号与位置*（`resourceTypes`）：对每种资源类型设置：
    - 名称和简称；
    - 带`{n}`和`{h1}`…`{h6}`占位符的编号模板、计数格式和重置级别，以及题注前缀，并带有“Fig. 1.7”式的实时预览；
    - **位置**组：该类型的默认位置、跨度（栏、页或侧栏）、**跨栏数**（该类型的单栏浮动对象在多栏页面上横跨的相邻栏数；等于页面的栏数时即为通页）和旋转、宽度比例、比所在位置窄的资源的对齐方式（因宽度而变窄的浮动体和嵌入，以及比栏窄的图片），以及题注在图旁的开关；
    - 可折叠的**题注样式覆盖**，只替换你为该类型设置的题注字段（位置、底色条、颜色、字体），其余继承。
  - *题注*（`captionStyle`）：字体、字号、对齐方式，以及位于资源上方还是下方的**位置**。可以加一条**底色条**，带颜色和内边距；标签和说明的样式分别设置。**注释**组设置资源注释的字号、颜色、倾斜、对齐方式和间隙。
  - *表格*（`tableStyle`）：
    - 表体和表头的字体排印，包括表头的**字距**（`headerLetterSpacing`）和**大小写**（`headerTextTransform`），以及填充色；
    - 边框，带一种**线条**模式：全网格、仅横线、外框或无；
    - 外框的**圆角半径**；
    - 单元格内边距；
    - *表体单元格*下的**斑马纹行**（`bodyAlternateBackgroundEnabled`），每隔一行表体填充**交替行颜色**（`bodyAlternateBackground`），该颜色在开关打开时显示。
  - *表格样式*（`tableStyles`）：命名的表格样式。你可以添加、删除和重命名id（重命名时，使用该id的表会一并更新），然后设置*表格*中的任何字段。每个控件在你设置之前显示从*表格*继承的值。
  - *图示*（`diagramStyle`）：**单色**开关，把SVG图示重新着色为同一种油墨的不同浓淡，用于单色印刷；另有一个油墨颜色选择器，默认为调色板的主色。
  - *视频样式*（`videoStyle`）：印在视频封面上的**播放标记**（形状、位置、大小、离边距离、颜色和背景不透明度）和**二维码**（位置、大小、离边距离、纠错级别、留白、颜色和圆角半径）；**输出**：封面是否链接到视频，以及HTML查看器显示播放器还是封面；还有每个视频起始所用的**播放器**开关。其中的**与其他视频同时播放**：开启时，播放一个视频文件不会停下其他视频，一页上的无声循环片段可以一起播放；关闭时，播放它会暂停其他视频。它在HTML查看器和Folio中生效。
- **标注框**
  - *标注框样式*（`calloutStyles`）：供`:::callout{type="…"}`使用的命名样式。你可以添加、复制、删除和重命名id，然后设置：
    - 默认标题、跨度、位置和宽度，以及**跨栏数**：在多栏页面上，浮动的标注框（位置为*自动*、*顶部*或*底部*，跨度为栏）横跨的相邻栏数。`:::callout`的`columns`属性可以覆盖它；
    - 背景、边框、圆角半径和内边距，以及一条边缘**色条**；
    - **图标**：可以是一个文字字符，也可以是从资源面板中选取的SVG/位图。它可以放在行内，也可以作为角标，并可设置所在的角以及非正方形图案的宽度。
    - **标签页**组（`calloutStyles[].label`）：字体、字号、字重、颜色、填充色、圆角、高度、内边距、偏移和内缩，标签页旁的图标资源，以及沿顶边的一条线；
    - 标题的字体排印，包括字距、缩进和**标题行距**（`titleStyle.lineHeight`）；
    - 继承文档正文的正文和列表覆盖设置。其中包括正文的粗体和**斜体颜色**、常规和粗体字重、**斜体**和**小型大写字母**开关，以及项目符号的大小和字重。
    - 框内`:::columns`组的栏间距；
    - **对齐网格**开关（`calloutStyles[].snapToGrid`，默认打开；关闭时，叠放的标注框保留精确的下外边距）；
    - 标记栏、固定锚点、不拆分和拆分最少行数，以及浮动体屏障控件；
    - **栏末的侧边框**选项（`sideAtColumnEnd`），用于其后文字不在同一栏继续的侧边框：放在围栏之前的文字旁边，或放在围栏之后的文字旁边；
    - **拆分的标注框**组：在每个续接部分重复标题并加后缀（`repeatTitle`、`continuedSuffix`），以及在每个未完部分下方加一个续接标记，带文字、对齐方式和斜体（`continuesMarkerEnabled`、`continuesMarker`、`continuesMarkerAlign`、`continuesMarkerItalic`）。这些文字默认使用文档语言。
- **页眉与页脚**
  - *页眉与页脚*：每个槽位中的文字、线条、框和图像元素。
    - **文字元素**：垂直对齐，在自身框内的**文字对齐**（`align`：齐左、居中或齐右，在框比文字宽时可以看出；或者两端对齐，把每段除最后一行外各行的空格拉开以填满框，打开**断词**时还会在音节处拆开单词来填满一行）、行距、字距（负值用于收紧展示性标题）、大小写、自适应、填充或固定的宽度和高度，以及最大宽度。**行内标记**（`inlineMarks`）在元素文字中排出`**bold**`、`*italic*`等行内标记；轮廓用来描出字母的外形：**轮廓粗细**、**轮廓颜色**和**空心字**（`stroke`）。
    - **线条**：水平或垂直。
    - **占位符**，从引擎的允许列表中选取：页码、总页数、全书总页数、标题、副标题、作者、出版日期、章标题和章号、篇标题和篇号，以及表示章属性的`{attr.key}`。页眉和页脚还可以使用页面顶部的章标题和章号`{chapterTitleAtTop}` / `{chapterNumberAtTop}`（见[页面顶部的章](/zh/docs/configuration#页面顶部所属的章)），以及导词`{firstMark.h2}` / `{lastMark.h2}`（点号后面是标题级别或段落样式id；见[导词](/zh/docs/configuration#检索词首标记与尾标记)）。
    - **槽位在哪里出现**：奇偶页，以及**页面**过滤：全部、正文页、章首页、篇分隔页或空白页。
    - **位置**：溢出方式，以及锚定到容器、某个同级元素，或者锚定到**页面** / **出血**边框以做出通到页边的色带；页眉和页脚元素还可以锚定到**外侧页边距**（`'outer'`），即远离书脊的那一侧页边距。
    - 文字元素的**书写方向**：*横排*，或*竖排，行从右到左*（`writingMode`），用于竖排书中沿切口排列的书眉。页眉编辑器中的<strong>切口书眉（竖排）</strong>会添加两个竖排元素：章标题在版心上端往下四个字处，页码在版心下端往上五个字处，都用正文字号的80 %，锚定到外侧页边距（见[竖排文字元素](/zh/docs/configuration#竖排文本元素)）。
    - **首字下沉**组（行数、字体、字重、字号、颜色和间隙）以及段落缩进。带首字下沉的文字无论**溢出**如何设置都会换行；不设字号时，下沉字母的顶端与第一行大写字母的顶端齐平。
    - 其他每个版面设计槽位都提供同样的文字控件。
- **篇**
  - *篇*（`parts`）：
    - **篇名页**（`parts.page`）：关闭后不另起一页，篇的编号、标题和颜色直接从下一段内容开始生效。它也会隐藏下面的设置。
    - `:::part`开始的那一页的奇偶，以及篇之后可选的分页及其奇偶；
    - 篇名页的页边距。它们继承页面页边距，并使用同样的对称内侧/外侧标签。
    - 一个依照页面成品框排版的**篇首版面设计**槽位。它的占位符选择器增加了标题一组：当前标题，以及以阿拉伯数字、罗马数字或字母形式表示的编号。
    - 篇内各块的**正文样式**。它继承正文和列表颜色，并包括列表覆盖设置（编号格式和偏移、外边距、悬挂缩进，以及任务列表的字段）。
- **导出**
  - *印前准备*（`print`和`page.cutLines`），分为四组：
    - **裁切标记与出血**：裁切线、出血，标记的长度、偏移和粗细，以及它们在屏幕上的颜色。
    - **PDF/X与颜色**：**PDF标准**（*无（普通PDF）*、*PDF/X-1a:2003*、*PDF/X-4*）；**输出特性文件**，从十五个免费特性文件中选择（默认FOGRA39，PSO v3条件用FOGRA51和FOGRA52，另有GRACoL、SWOP和新闻纸）；**上传ICC特性文件**，用于印厂给你的特性文件，带有它的**印刷条件**（PDF/X输出意图所写的注册名称）和一个移除它的按钮；**渲染意图**、**黑场补偿**、**图片转换为CMYK**（PDF/X-1a总是转换，所以此时隐藏）和**总墨量上限（%）**。
    - **黑色**：**灰色和黑色只用K**、**100%黑叠印**、**大面积用复合黑**，以及复合黑的C/M/Y/K配方和区域从多大起改用复合黑。
    - **印前检查**：**在检查中进行印前检查**，最低和严重的图像分辨率，最细线宽，多色文字被标出的字号阈值，安全区，方框应出血的距离，以及**检查置入PDF的字体**。

    见[配置 › 印刷输出](/zh/docs/configuration#印刷输出配置)。
  - *PDF*：书签、无障碍（带标签的）PDF和强制色彩空间。CMYK用*印前准备*中的特性文件分色。
  - *网页阅读器（HTML）*：`htmlViewer`设置。
- **Folio**
  - *书页视图（3D）*（`folio`），分为五组：**视角**（倾斜角和转角）、**纸张**（纸种、克重、松厚度及由此得出的纸厚、表面处理、纹理及其强度、纸色、透印）、**装订**（装订方式、封面、封面材料和颜色、书脊图片；*折叠（报纸）*方式把对折一次的纸张一张套一张叠起来，不加任何固定，就像报纸；它和*骑马钉*一样没有可以印字的书脊，所以书脊图片隐藏）、**台面**（桌面材质及其色调）和**光照**（环境光、曝光、阴影）。换一种纸种时，你没有改过的字段会填入该纸种的数值，改过的字段保留你的值。采用报纸开本时，你没有选过的纸种和装订方式显示为*新闻纸*和*折叠（报纸）*。书脊图片从资源面板的位图和SVG中选择。见[书页标签页](#书页标签页)。
- **高级**
  - *屏幕辅助*（`debug`）：**基线网格**（`page.baselineGrid`）放在这里，而不在*页面*之下，此外还有其他检查版面用的叠加显示。
  - *警告*：检查面板报告哪些问题，以及它们的阈值。

**查找设置**。标题栏下方的工具栏对所有组都有效：

- <strong>搜索设置…</strong>按标签、帮助文字和选项名称过滤所有分区中的所有字段。它忽略重音符号，并匹配词首：*marg*能找到*上页边距*和*Margen superior*，*h3*会打开*标题 › H3*。结果按设置组分组。匹配的分区自动展开，不匹配的行和分区被隐藏，命中的文字会高亮。按Escape先清除搜索，再离开输入框。
- **已更改**只显示值与默认值不同的字段。

**帮助文字**。每个字段都有一段简短的说明。屏幕阅读器把它读作字段的描述；在屏幕上它默认隐藏，用该行的<strong>?</strong>按钮（*“…”是什么？*）打开。标题栏中的**显示全部说明**开关一次打开所有说明，这一选择会被记住。

**已更改的值**。面板遵循一致的**覆盖模型**：

- 分区标题带一个徽标，显示其中已更改字段的数量，嵌套的组也计算在内。
- 分区标题只在包含更改时才显示重置按钮（需要确认）。
- 已更改的字段在标签旁有一个圆点（读作*已更改*），并有自己的小重置按钮。
- 保存或导出的永远只是更改过的子树。默认值会被剔除，所以原始状态的沙盒保存的是一份空配置。
- 重置*页面*不影响基线网格，因为网格在*高级*中编辑。

**控件：**

- 选项用下拉菜单表示，每个选项可以带一行说明；选项很少时用分段按钮。
- 开/关设置用开关表示。
- 数字带 − / + 步进按钮。方向键逐级调整数值，按住Shift时步长为十倍，按住Alt时为十分之一。
- 长度带单位选择器，切换单位时会换算数值（cm、mm、in、pt、px、em、rem）。
- 颜色是一个按钮，显示色块和数值。
- 字体选择器可以用方向键浏览。

控件会根据上下文变化。栏间距只在多栏版式中出现；两端对齐设置只在文字两端对齐时出现（齐左文字改为显示**齐左文字断词**；段落样式或标注框在两端对齐或打开了齐左断词时显示它的断词开关）；侧栏百分比只在一栏半版式中出现。修改会立即反映在视口预览中。每个配置选项及其默认值的完整参考，见[配置](/zh/docs/configuration)页面。

面板标题栏还提供**重置**（需要确认；只在版面设计与当前示例书的版面设计不同时显示，它恢复该示例书的版面设计，包括字体）、**导出**和**导入**。见[导出与导入](#导出与导入)。

#### 检查面板

实时诊断，根据正文、版面设计、图和上一次构建重新计算。计数与活动栏按钮上的徽标一致。警告按类别分组，按处理的轻重缓急排序：先是会破坏输出的问题，然后是标记问题，最后是通常条目众多的细微排版问题。每组都可以折叠，并显示其数量：

- **字体**：缺少字族，自定义字族中缺少或重复的字重/样式文件，以及*字族中的字体栈*：`fontFamily`设置中写了一个CSS字体栈（文字用其中第一个字族排出；条目写明该设置的路径）
- **图与表**：`::resource` / `:ref`中未知的资源id（也包括正文所用的图的题注、注释或单元格中的，以及作为表格单元格图像的）、重复的资源id、引用了不存在的资源类型、位图渲染尺寸明显大于其像素尺寸、表格的样式id不对应任何表格样式、表格网格不规整（合并单元格所覆盖的单元格缺失，或某一行有空洞：在表格编辑器中重新合并这些单元格）、文件在存储中缺失或无法解码的图像（显示为占位图），以及没有封面的视频、没有正式发布地址的视频文件（印刷版没有二维码和链接）和不指向任何视频的YouTube或Vimeo地址
- **文字与标记**：
  - 标题层级跳跃（例如H1 → H3），以及中间没有正文的连续标题；
  - 无效或未闭合的`$…$` / `$$…$$`公式；
  - 未知的指令名称（解析器认识的名称都接受：`pagebreak`、`columnbreak`、`space`、`numbering`、`toc`、`callout`、`paragraphs`、`part`和`columns`）、无效的编号或奇偶属性，以及超出0–20行范围的`:::space{lines=N}`；
  - 到文档末尾仍未闭合的`:::`容器围栏（点击它会让编辑器聚焦到开头那一行）；
  - 样式未配置的`:::paragraphs{style="…"}`、`:::callout{type="…"}`、`:chip[…]{style="…"}`或标题`{style="…"}`；
  - 被当作文字印出的`::resource`行——格式错误，或紧贴在段落下方、中间没有空行；
  - *全角标记*：用中文或日文输入法输入的标记（`：：：`、`＃`、`［＾…］`、`｛…｝`、`＊＊…＊＊`），会被当作文字印出；条目会给出应输入的ASCII形式；
  - *属性键未被读取*：用非ASCII字符写的属性键（`作者=曹雪芹`），解析器会忽略它；
  - *前置元数据被忽略*：除第一章外，某一章以前置元数据块开头（只有第一章的前置元数据属于整本书）。
- **版面设计**：
  - 不在引擎允许列表中的页眉和页脚占位符名称（`{attr.…}`和篇的占位符是允许的），以及所需文档元数据缺失的占位符；
  - 版面设计元素之间的循环锚定，或锚定到不存在的元素。这一检查和占位符检查覆盖每个版面设计槽位：书眉、篇首页、篇名页之后的空白左页、目录中篇的行、每一级标题的版面设计，以及每种标题样式的版面设计和其所在部分的书眉。来自标题样式的条目会写出样式名，如`{style="index"} header · #rh → #missing`；来自空白左页或目录中篇的行的条目会写出其设置，如`toc.parts.design · #row → #missing`；
  - 裁剪溢出方式总会截断的文字元素；
  - *标题版面设计被截断*：标题的版面设计高出页面所能容纳的高度——章首页的文字排到了页面底边以外，或栏内版面设计的文字排到了栏底以外（例如小屏幕页面上的一段较长导语）。标题会占用所在页或栏的剩余部分，因此其后的正文从下一页或下一栏开始，但版面设计超出的那部分会丢失；点击条目会聚焦到该标题；
  - *侧栏超出范围*：一栏半版式的侧栏被引擎限制了宽度，以给主栏留出空间；
  - *栏数超出范围*：`multiple`版式的栏数不是3到8之间的整数，被引擎限定；
  - *未知的编号格式*：列表、页码或资源类型使用了引擎不认识的编号格式，此时以阿拉伯数字编号；
  - *未知设置*：标题、某一级标题或某种标题样式中没有的键（例如拼错的`letterSpacng`），引擎会忽略它；有相近的设置时，条目会给出建议。
  - *竖排文字不标行号*：在竖排文档中打开了行号，而竖排文档不标行号。

  最后这四项与*字族中的字体栈*一样，来自配置而不是正文：条目写出设置的路径，点击它不会移动编辑器。
- **排版**：
  - 松散行（词间距被拉开，超过所配置的阈值）；
  - *CJK行排不满*：一行中文、日文或韩文没有排满行长，因为排满会使字符间的扩展超过上限；
  - *标记挤到下一行*和*注音挤到下一行*：着重号、专名号和书名号线，或者注音，需要比段落现有的更大的行间空隙；条目会以em为单位给出这两个数值；
  - 溢出所在栏的标注框；
  - *行内标签碰到相邻行*：某个行内标签的框碰到了上一行或下一行的行内标签（以pt为单位给出重叠量）；上下都没有行内标签的高标签不会被标出；
  - 奇偶连锁；
  - *行号压在侧栏框上*：侧栏中的行号（`lineNumbers.position: 'side'`）落在该栏的框、图注或插图上；两者都照原位印出；
  - *该语言没有断词模式*：文档语言（其断词语言，否则为`locale`）没有随附的断词模式，因此文字按美式英语的模式断词。关闭断词后这条警告会消失。
- **印前检查**，仅在书设为付印时出现（设了PDF/X标准、CMYK PDF或裁切标记），严重问题排在前面：
  - *图像分辨率过低*：图片在印刷尺寸下低于最低分辨率（低于严重阈值时为严重）；
  - *RGB图片*：导出时分色为CMYK，或者在不转换图片的PDF/X-4中保留为RGB；
  - *线条过细*、*多色小字*、*总墨量超出上限*（以CMYK定义的颜色、复合黑配方）；
  - *文字进入安全区*和*止于裁切线内侧附近*（应当出血的方框或图片）；
  - *置入PDF中有未嵌入的字体*、*置入PDF中含RGB*和*置入PDF中含透明*（在PDF/X-1a中为严重），来自每张图的印刷母版。

  每个条目都写明所在页；点击它会在查看器中打开那一页。
- **浏览器**：存储不可用（缺少IndexedDB）

每个条目显示一个图标、一个标题、一行详情，适用时还显示所在的章和源码行（多章的书中显示为*第2章 · 第12行*）。点击带有源码位置的条目，会切换到那一章，并让编辑器聚焦到该处。没有问题时，面板显示**没有问题**。哪些检查会运行，在**版面设计 → 高级 → 警告**中设置。

### 主视口

界面的右侧显示渲染结果。共有五个标签页，每种渲染模式一个，依次为**Canvas**、**PDF**、**书页**、**HTML**和**EPUB 3**。切换标签页不会重新排版：同一个VDT供给所有后端，所以你在不同模式中看到的内容是一致的。只有浏览器支持WebGL2、且屏幕不是手机屏幕时，才提供书页标签页（见[书页标签页](#书页标签页)）。

每个视口都在一个专用的**Web Worker**（`postext/worker`）中运行排版流程。每个视口的`useLayoutWorker` hook持有工作线程的句柄，以可转移的`ArrayBuffer`把字体送入工作线程，并以**后发优先的取消机制**驱动构建——每次按键或拖动滑块时，都会先通过`AbortSignal`中止前一次构建，再开始下一次，所以快速输入永远不会在主线程上堆积过时的工作。卸载视口时，会销毁它的工作线程，并拒绝所有未完成的构建。这里使用的集成方式见[配置 → 在Web Worker中运行排版](/zh/docs/configuration#在web-worker中运行排版)。

#### Canvas标签页

在HTML5的`<canvas>`元素上渲染文档的栅格化预览。它以像素级的精度呈现最终排好的文档的样子，包括文字的精确位置、栏式和资源的安放位置。

Canvas视口顶部的工具栏提供：

- **缩放控件**——放大和缩小（每级1.25倍，范围0.25x–4x）。手动缩放会关闭适应模式。
- **适应模式**——适应页面宽度或适应页面高度。可以开关；窗口大小改变时会自动重新计算。
- **视图模式**——单页（每行一页）或双页跨页（仿照书本的布局：第一页作为右页单独出现在右侧，之后的页面两两组成跨页）。右侧装订的书（`page.binding`，竖排中文）以相反的方向显示跨页：第1页单独在左边，然后是`[3 | 2]`、`[5 | 4]`。在竖排页面上，点击会落在指针下方的字符上，光标是一条横贯该栏的短横。
- **印刷预览**（`Printer`图标）——按印出来的样子显示页面，默认关闭，浏览器会记住这个选择：每种颜色都经*印前准备*中的输出特性文件分色，显示在纸张自身的白色上；大面积黑色显示为复合黑；还画出成品线（蓝色）、出血线（品红）和安全区（绿色虚线），并用红框标出印前检查发现的问题。书页标签页共用这个开关。它只重绘页面，从不重新排版。

页面通过`IntersectionObserver`延迟渲染——只有可见的页面（外加200px的余量）才会绘制到画布上，这样长文档也只占用很少的GPU内存。

#### PDF标签页

通过`postext-pdf`软件包生成当前文档的真正PDF，并在内嵌的浏览器PDF查看器中显示。PDF在首次挂载时以及之后每次重新生成时自动重建，所用的是供给Canvas和HTML标签页的同一个VDT——所以三个后端的断行、分页和资源位置逐像素一致，连Knuth–Plass偶尔接受的超长末行的压缩都相同。

视口右下角的浮动工具栏提供：

- **重新计算**（`RefreshCw`图标）——根据当前的Markdown和配置重建PDF。在改动了不会自动触发重建的设置之后，或字体加载完成之后，可以用它。
- **下载**（`Download`图标）——把当前PDF保存到磁盘。文件名取自文档的第一个H1标题（没有时为`document.pdf`）。
- **打印**（`Printer`图标）——针对内嵌的PDF查看器打开浏览器的打印对话框，大多数浏览器在这里既可以打印，也可以再次另存为PDF。
- **当前章 / 整本书**（标签栏左侧的选择器，只在多于一章的书中出现）——把所有章渲染为一个连续的PDF，而不是默认的当前章（接续其前各章）。更改它会重新生成PDF。Canvas有自己的选择器（见[书与章](#书与章)）。

在底层，沙盒使用一个`createPdfFontProvider()`辅助函数：它从Fontsource的jsdelivr CDN获取按字重区分的静态WOFF2文件，在浏览器中解压为TTF，再通过`renderToPdf`把字节交给`pdf-lib`。之所以需要按字重区分的静态字体（而不是一个可变字体），是为了让粗体文字真正以粗体字重嵌入。在沙盒之外使用同样做法的方式，见[生成PDF](/zh/docs/configuration#生成pdf)。

#### 书页标签页

把书作为印刷品来展示：引擎排好的页面装订成书，摊开放在桌面上，以3D呈现（`postext-folio`，three.js）。页面就是Canvas绘制的结果，逐像素显示，所以文字和Canvas标签页上一样清晰；变化的是页面周围的一切。纸张、装订、桌面和光照来自版面设计面板中的**Folio**组（即`folio`配置）；正文中的`:::paper`段落会把其中的页面印在另一种纸上（见[文档格式 › `:::paper`](/zh/docs/document-format#paper)）。

- **排出的内容。** 书页标签页跟随Canvas的**当前章 / 整本书**选择器。一章显示为它所在的书的一部分：它前后的页面计入两侧书芯的厚度，这一章在跨页中也从它真正所在的一侧打开。右侧装订的书（`page.binding: 'right'`，或竖排的书）呈镜像，向左翻页。
- **翻页。** 抓住页边拖过去：过了一半松手就翻过去，不到一半就落回原处。点击页面也会翻页（右页向前，左页向后）；工具栏的‹ ›按钮，以及书本获得焦点时的方向键、Page Up/Down、Home和End，也都可以翻页。每一叶按自己的纸张弯曲：字典纸卷得很紧，卡纸翻出宽大的弧线，纸板和封面则像硬板一样整块翻动。
- **远距离跳转。** 相距超过十页的页面（在页码框中输入、由永久链接指定、通过链接或文本面板中的光标到达）一次到位：中间的整叠书页作为一个整体掀起，厚度与这些页相同，再落到另一侧。十页以内则逐页翻过。
- **绕着书看。** 按住右键拖动可让视角绕书旋转，最低到偏离正上方70°，用来查看书脊、切口或书芯的厚度。视角停在你放开的位置，翻页时也不变，直到**重置视角**把它平缓地恢复到设置给出的视角（*倾斜角*和*转角*）。**保存为默认视角**把你当前看到的视角存入这两项设置，书会以这个视角打开，重置视角也会回到这里。
- **指针的作用。** 工具栏的三个按钮决定左键（一根手指、一支笔）在书上的作用：**用手翻页**为默认模式，如上所述；**环绕视角**与右键拖动相同，适合触控板或平板；**选择文本**的用法与Canvas标签页相同，作用于眼前所见的书，无论倾斜还是旋转：单击把光标放到文本面板，拖动进行选择，双击选中一个词，单击链接则跟随链接。选择会被记住；书获得焦点时，按H、O、S可切换。
- **跟随编辑器。** 文本面板的光标和选区画在书页上，输入时也保留：页面重新排版后立即显示修改。在编辑器中把光标移到未显示的页面，书会翻到那一页。
- **封面。** 选择*封面：书页外加书壳*时，书用布面、卡纸或皮面的书壳装订，颜色为封面颜色。选择*文档自带的页面*时，第一页是封面，最后一页（落在左页时）是封底：翻开封面之前书是合着的，翻过最后一叶时书又合上。厚书打开时，书脊立在两侧书芯之间。
- **工具栏。** 与Canvas相同的浮动工具栏：**重新计算**、**重置视角**、**保存为默认视角**、三种指针模式、**印刷预览**（经输出特性文件打样的页面，印在书本身的纸上；与Canvas的开关相同）、固定按钮、‹ ›和页码框；页码框接受书中的页码，并翻到它所在的跨页。打开的跨页中右侧那一页就是永久链接所标明的页（`view=folio&page=N`）。
- **设置即时生效。** 书页设置不属于排版：改变纸张、装订或光照只会重绘书本，不会重新排任何一页。
- **在哪里提供。** 这个标签页需要WebGL2，以及短边至少600像素的屏幕：在手机上，3D书本占用的内存超过浏览器给一个标签页的上限，所以那里不显示这个标签页（不支持WebGL2的浏览器也不显示）。窗格宽度小于560像素时，书一次显示一页，书页仍绕着书脊翻动。系统要求减少动画时，跨页直接切换，不播放翻页动画。
- **页面上的视频。** 在三种指针模式中的任何一种下，点击视频的封面，它就在页面上播放，翻动这一叶时画面随纸张弯曲卷起，仍在播放。再点击一次暂停；开始播放另一个视频时，前一个会停止，除非打开了*与其他视频同时播放*；书停在不再显示这个视频的跨页上时，它也会停止。空格键播放或暂停打开的跨页上的视频。打开了*自动播放*的视频在它的跨页第一次出现时自动开始播放；你在页面上点击过之后它才有声音（在此之前静音，点击一次打开声音），指南中的两个视频就是这样设置的。上传的文件和位于某个地址的视频（MP4、HLS）只要服务器允许跨源读取，都能这样播放；YouTube和Vimeo视频照旧翻页（见[文档格式 › Folio视图中的视频](/zh/docs/document-format#folio视图中的视频)）。
- **替代文本。** 每一页都以图像绘制；它的无障碍名称会指引读者到HTML标签页和正文面板查看文字。

#### HTML标签页

在Shadow DOM容器中渲染postext的输出，使其样式与宿主页面完全隔离。版式CSS（字体排印、间距、栏线）注入在shadow root内部，因此既不会受到周围应用样式的影响，也不会泄漏到其中。

Markdown链接在这里和PDF中都是可点击的（见[文档格式 › 链接](/zh/docs/document-format#链接)）。在这个标签页中，点击链接会在新的浏览器标签页中打开目标，沙盒保持打开；`:ref`引用仍在文档内部跳转。

视频在这里播放：YouTube或Vimeo视频用平台的播放器，文件或网址用浏览器的播放器（浏览器本身不能播放HLS时，HLS流通过hls.js播放），播放器选项取自设计面板的*视频样式*和各个视频的设置。在播放器上的点击交给播放器，不会跳到编辑器。**HTML 查看器中**设为*封面*时，这个标签页显示印刷封面，并链接到视频。

视口顶部的工具栏提供：

- **字号缩放控件**——缩小或放大正文，同时保持配置中所有相对尺寸的比例。
- **分栏模式**——单栏（一个可以滚动的长栏）或多栏（栏宽最接近所配置行长的栏数，页面之间水平滚动并自动吸附）。双栏文档保持双栏页面，但阅读器可能显示奇数个栏——比如三栏，而不是拉宽的两栏或挤窄的四栏——如果那样最接近；这时最后一栏属于下一页，只露出一半。*多栏*版式的文档或章节也显示为双栏页面：三到八栏的印刷栏放到屏幕宽度上会窄成细条，所以阅读器把它的文字排成每页两栏，并按行长并排显示尽可能多的栏。右侧装订的书（`page.binding`）在多栏模式下从右到左排列页面：阅读器从最右端开始，‹箭头转到下一页。竖排的书只能以多栏模式阅读：**单栏**按钮不可用，悬停提示会说明原因；你保存的选择会在下一本横排的书中恢复。

栏的几何尺寸由版面设计面板中的<strong>网页阅读器（HTML）</strong>分区（**版面设计 → 导出**）决定：`maxCharsPerLine`以正文字体的字符数设置目标行长，`columnGap`设置多栏模式下栏与栏之间的水平间距，`optimalLineBreaking`在阅读器中开关Knuth–Plass算法。沙盒内部采用的同样做法见[HTML阅读器配置参考](/zh/docs/configuration#html查看器)和端到端的[集成示例](/zh/docs/configuration#集成html查看器)。

#### EPUB 3标签页

用`postext-epub`包把整本书写成一个EPUB 3文件，在标签页内的阅读器中显示，并可下载。文件在浏览器中生成，所用的逐章排版与PDF标签页选**整本书**时相同，因此页码、注释、交叉引用、目录和索引都与PDF印出的一致。这个标签页没有**当前章/整本书**选择器，因为EPUB总是包含整本书。在标签栏左侧的那个位置，它提供EPUB的版式选择（手机上显示为图标）。

EPUB 3有两种版式，由包文件的`rendition:layout`属性声明：

- **固定版式**（`pre-paginated`，英文称fixed layout或FXL）：每一页都保持印刷时的样子。每页是一个独立的文档，尺寸与页面相同，文字的位置与PDF一致，使用书中的字体，但仍是真正的文字，可以选择、搜索和朗读。跨页按印刷本配对，右装订的书（阿拉伯文、竖排中文）从右向左翻页。它保留版面设计：分栏、浮动体、书眉、章首页和确切的断行。适合页面本身就是设计对象的书，如图文书、教材、目录册和杂志，也适合大屏幕的阅读器。在小屏幕上页面会缩小显示，读者需要放大阅读。
- **流式版式**（手机和电脑上的默认版式，也是EPUB的默认版式；英文称reflowable）：正文、图和表按阅读顺序排列，由阅读器按自己的屏幕以及读者所选的字体、字号和边距重新排版。段落由排好的行重新拼合（行末添加的连字符会去掉），图和表跟在引用它们的文字之后，标注框成为旁注（aside），脚注链接到每章末尾的注释并可返回，印刷页码保留为分页标记。从版面设计导出的样式表决定标题、标注框、表格和图注的外观，但页面几何不复存在：没有分栏，没有书眉，没有固定的断行。适合连续的正文，如小说、随笔和报告，也适合手机和电子墨水阅读器。

在没有选择之前，这个标签页在iPad这样的平板电脑上以固定版式打开，因为它的屏幕放得下印刷页，在其他设备上则以流式版式打开。这个选择在下次访问时仍然保留（`postext-sandbox-epub-layout`），切换后文件会立即重新生成。

- **生成。** 第一次打开标签页时生成EPUB，按**重新计算**时再次生成。进度条先统计正在排版的章，再显示写入的各个步骤（字体、图片和封面；页面或章；打包），文件生成完毕或失败时屏幕阅读器会播报。编辑之后，**重新计算**旁边会出现一个箭头，表示文件已与文本不符，与PDF标签页相同。离开标签页或切换版式会中止正在进行的生成。长书需要几秒钟，其间页面不响应操作。
- **文件包含什么。** 元数据取自第一章的前置元数据：`title`、`subtitle`、`author`（一个名字或一个列表）、`publishDate`或`date`、`isbn`或`identifier`、`publisher`、`rights`和`description`；语言取自配置中的`locale`。没有标识符的书会得到一个由项目（或由示例书及其语言）派生的标识符，这样同一本书的所有EPUB在读者的书库中保持同一身份。版面设计中提到的所有字体族都会嵌入：Google Fonts只收入书中实际用到的字符所在的分片；自定义字体族也会收入，标记为不可再分发的除外。图片按存储时的样子收入，SVG以源代码收入并内嵌其字体，从不使用PDF印刷母版。视频文件收入`media/`下，在阅读器的播放器中播放；没有文件字节的视频从其正式发布地址播放，包文件把它声明为远程资源；YouTube或Vimeo视频则显示为链接到视频的封面。封面是书自带的图片（须为至少600像素宽的位图）；否则就把第一页按1600像素宽绘制，并去掉裁切标记的边距。
- **阅读器。** 标签页打开的就是刚写好的文件，与下载的字节完全相同，而不是另做的预览。固定版式显示一页，窗格足够宽时显示一个跨页，并缩放到合适大小；流式版式的书按屏幕分页（竖排中文从上到下），页面从一章接续到下一章。书中的链接在阅读器内跳转；网页和邮件链接在浏览器的新标签页中打开。←/→、Page Up/Page Down、Home和End用于翻页，从右向左的书中←是向前翻。
- **工具栏。** 与PDF标签页相同的浮动工具栏：**重新计算**、固定按钮、显示文件大小的**下载 EPUB**（文件以书名命名）、写入时有提醒才出现的提醒按钮、**目录**（根据书的目录生成的跳转列表）、**增大字号**和**减小字号**（仅流式版式，阅读位置保持不变）、‹ ›，以及固定版式下的页码框。页码框按文件的阅读顺序计页，封面算第1页；各页框架的名称使用印刷页码。
- **提醒。** 提醒按钮列出文件未能按书中原样收入的内容：没有存储文件的图片（原处留下空框）、没有嵌入字形的字体族、字重或字形（阅读器会替换）、因不可再分发而未收入的字体族，以及该版式无法表达的内容。同样的消息也会输出到浏览器控制台。
- **检查文件。** 指南和示例书的两种版式都能通过[W3C EPUBCheck](https://www.w3.org/publishing/epubcheck/) 5.4检查，没有错误或警告。要检查自己的书，下载后运行`epubcheck book.epub`，或者在Apple Books、Thorium Reader或Calibre中阅读。

要在自己的代码中写出同样的文件，见[EPUB电子书](/zh/docs/configuration#epub电子书postext-epub)。

### 手机与小屏幕

宽度小于768像素时，沙盒改用专门的布局：

- **面板。** 面板栏移到窗口底部，按钮和顺序不变。打开的面板覆盖在预览上，而不是排在它旁边；预览留在下面原来的位置，不在Tab键顺序中，所以关上面板时它还停在同一页。
- **顶栏。** 输出标签页、范围选择器（在EPUB标签页上是版式选择）和宿主的控件（大按钮、主题、语言）共用预览上方的横栏。宽度小于640像素时它分成两行：上面是标志、范围选择器和控件，下面是各标签页，平分整个宽度；320像素宽也放得下五个。
- **工具栏。** 预览的浮动工具栏停靠在预览底部，放不下时折到第二行。
- **书页。** 手机屏幕上不提供书页标签页（见[书页标签页](#书页标签页)）。
- **PDF。** 手机和只支持触控的平板无法在页面内显示PDF（Android没有内嵌查看器，iOS只绘制第一页），所以PDF标签页改为显示一张带**打开PDF**按钮的卡片，在新的标签页中打开文件；工具栏的**下载**仍可保存它。

## 书与章

在沙盒中打开的一切都是一本**书**，就像InDesign的书籍文件把每章的文档编成一组：配置、自定义字体和资源集由全书共用，每一**章**是一个独立的Markdown文档。长篇作品（比如一本五百页的教材）可以一章一章地编辑，而编号、交叉引用和导出看到的仍是一个整体文档。

- **结构**在章节面板和正文面板的章节切换器里管理：添加、重命名（双击某一行）、调整顺序、按一级标题把一章拆成多章、把一章并入前一章、删除。每一章都有自己的撤销历史和光标位置。
- **一次一章**。默认情况下，各预览排的是**当前章**，并接续在它之前的各章之后：它的起始页码紧接上一章的最后一页；一级标题继续计数（第4章编号为4，其中的图为4.1、4.2……）；`{chapterNumber}`和`{chapterTitle}`书眉随之更新；左右页的奇偶关系保持不变（章首页补空白页的方式与在全书中间时完全一样）；指向第1章首次提到的图的`:ref`也保留原来的编号。前面各章的页数取自上次显示该章时的版面；从未打开过（或打开后又改过）的章会在后台依次排版，排好之前章节列表显示*页码待定*。对于从新的一页开始的章（默认如此），页码范围是准确的；如果某章的正文本应接着上一页往下排，它会改为从自己那一页的顶部开始。
- **整本书**。Canvas、HTML预览和PDF标签页可以把整本书显示为一个连续的文档：在标签栏左侧的选择器中选**整本书**（有多于一章的书才有此项）。这时Canvas会按顺序排出每一章，每章接在前面各章的页数之后，并把这些文档拼接起来显示。修改某一章只会重排这一章；它之后的各章只有在起始页变化时才重排。章节列表、永久链接中的`chapter=`和`page=`部分以及编辑器同步都跟随当前页所在的章。这个选择随书保存（短篇小说适合作为一个整体阅读，教材适合一次一章），预设也可以通过清单的`view.canvasScope`以这种方式打开。HTML预览与Canvas共用这一选择，并从第一页起把整本书排成一个文档，目录行和URL片段跟随每页所在的章；PDF标签页有自己的选择器。
- **长篇书**。一本120章的书和短书用起来一样。正文面板标题栏里的章节菜单在窗口内滚动，打开时定位到当前章，可以用方向键从这里移动。分篇的书（章中有`:::part`围栏）在菜单和章节面板里把各章列在所属的篇下面，在菜单中点击某一篇会打开它的第一章。超过30章时，菜单顶部有一个搜索框，可以匹配章号（`27`）以及标题和篇名中的词（`埋香`、`卷三`）；按Enter打开第一个匹配项。输入法正在组字时（注音、仓颉、拼音、假名），Enter和方向键归输入法使用：Enter确认转换，不会打开任何章。示例书的章文件每次加载八个；在后台为各章分页期间，章节面板会显示进度（*正在分页34/120*）。超过200章的书，无论书本身或其清单如何要求，Canvas和HTML预览都一次只显示一章：同时排出每一章需要把整本书都放在内存里。低于这个数量的书可以整本打开：《紅樓夢》（129章，约2,000页）在Canvas上大约需要25秒和100 MB内存。PDF标签页仍然可以整本导出任何书。
- **前置部分**。第一章的前置部分就是整本书的前置部分（书名、作者……）。其他章顶部的前置部分块会被忽略，检查面板会给出提示。`buildBundle`遵循同样的规则，所以一本书在沙盒里和在你自己的程序里渲染结果相同。
- **页数**。每一章都作为独立文档排版，因此`{totalPages}`统计的是本章的页数。`{bookTotalPages}`统计整本书：所有章的页数都已知后，各预览会用这个总数重新排每一章（只在页眉、页脚或版面设计打印它时才这样做）。在那之前，一章打印的是截至本章末尾的页数。PDF标签页的**整本书**统计的是它实际排出的页数，因此文件里打印的始终是全书的真实总页数。
- **章首页**。章与章之间不会强制分页：第一个块是一级标题的章，通过该标题自身的*前置分页*设置另起一页，与文档中间开始的章完全一样。
- **同步**。在Canvas或HTML预览中点击任意一章的段落，编辑器就会切换到那一章并放置光标；无论该章位于书中何处，编辑器的光标都会在预览中高亮显示。警告会注明所在的章。
- **已有文档**会作为只有一章的书打开；在添加第二章之前一切照旧。

## 编辑漫画

含有漫画页（`:::page`）或漫画条（`:::strip`）的章，可以直接在页面上编辑：Canvas标签页、HTML标签页以及书页标签页的**选择文本**模式都可以。排在栏中、浮动到页首或横跨整页的漫画条，比所跨宽度窄或排在题注下方的漫画条，也都能用同样的工具编辑，修改写进漫画条自己的围栏行。每次修改都像手动输入一样写进这一章的Markdown，所以编辑器的撤销能把它退回去。标记和嵌字规则见[漫画](/zh/docs/comics)。

- **分格线。** 指针移到两个分格之间的格间距上，会变成调整大小的光标。拖动它就能移动分格线；松开时，新的百分比写入页面的`split`属性（页面没有这个属性时，会把它加到围栏行上），页面随即重新排版。按住Shift时，分格线以5%为步长吸附；按住Alt时只移动离指针较近的一端，使分格线倾斜；任何分格都不会窄于5%。拖动过程中，画面将无法让安全区留在视野内的分格会被标出，并附有提示。每条分格线也是一个可以获得焦点的分隔条：方向键每次移动1%（按住Shift为5%），Enter写入位置，Escape恢复原位。
- **分割与合并。** 分格上方的小工具栏提供**用水平线分割**、**用垂直线分割**（紧接在这一格之后，为新格子加一个空的`::panel`行）和**与下一格合并**：两格之间的分格线去掉，合并后的分格保留第一格的画面，并接收两格的全部台词行。也可以用Tab键到达各个分格：获得焦点的分格会显示轮廓，按H用水平线分割，按V用垂直线分割，按M与下一格合并；页面重新排版后，焦点仍留在这一格上。按Enter打开工具栏，按Escape从工具栏回到分格。
- **对白框。** 拖动对白框就能固定它的位置：松开时，它的台词行得到`at="x% y%"`，即以分格画面的百分比表示的点（分格没有画面时以格子为准），所以无论怎样裁切、拖动分格线或换成译本，固定点都留在画稿的同一位置。相连的一组对白框作为整体移动，由组中第一个对白框固定。获得焦点的对白框可以用方向键每次微移1%（按住Shift为5%）；双击已固定的对白框会删去它的`at`，把它交回自动排放。单击对白框会把编辑器的光标放到它的台词行上。
- **溢出提示。** 对白框移动时，无论用指针还是方向键，预览都会检查它将落在哪里。如果它会盖住脸或避让区，或者会比现在更多地伸出分格，移动中的轮廓变成橙色，分格中的脸和避让区以虚线画出，提示框说明原因：“放在这里会遮住人脸。”“放在这里会遮住图片中需要留空的区域。”“放在这里会超出分格。”带`break`的台词行不会因伸出分格而被标出。这个提示不预测分格中其他对白框会怎样移动来让出位置。
- **尾巴。** 指针移到尾巴尖端上会变成十字准星。把尖端拖到尾巴应当指向的地方：松开时，台词行得到`to="x% y%"`，即以分格画面的百分比表示的点，尾巴转向这个点，并像在嘴前那样在到达之前停住。Escape取消拖动；双击尖端会删去`to`，尾巴重新指向说话人。用键盘时，在获得焦点的对白框上按T转到它的尾巴：方向键把所指的点每次移动1%（按住Shift为5%），Enter写入，Escape恢复原位，Delete删去`to`，再按T回到对白框。
- **说话人与避让区。** 在[资源面板](#资源面板)的图片上，**安全区与嵌字**一栏打开一个有三种模式的对话框。**安全区**标出图片中必须留在视野内的部分。**角色**为每个人物放一个点：在图片上单击，就在那里添加一个说话人，并让它的id获得焦点，这个id必须是脚本使用的说话人键（`maya: …`）；再把它的嘴、头（心声的气泡指向这里）和脸（不会被任何对白框遮挡）拖到位。**避让区**是对白框不得遮挡的矩形，在图片上拖动即可画出。每个标记都可以用方向键移动（按住Shift步长更大），按Delete删除；对话框有自己的撤销，安全区以外的说话人会被标出。
- **设置。** 版面设计面板的**漫画**组包含漫画配置：阅读方向和画面翻转、画框与格间距、默认分格与命名分格样式、嵌字，以及对白框样式，每种对白框样式都附有轮廓预览。
- **编辑器与检查。** 文本编辑器为`:::page`、`:::strip`、`::panel`行以及台词行的键和属性着色。检查面板在相关的行列出漫画警告（无法读取的切分、分格数与格子数不符、放不下的对白框……）；见[漫画 › 漫画警告](/zh/docs/comics#漫画警告)。

## Word文档

书稿通常以Word文件的形式交来。正文面板可以直接导入`.docx`，不需要AI智能体，也不需要安装任何东西，样式的对应方式与InDesign的*置入*相同。**导入Word文档**在浏览器中读取文件（文件不会上传），并打开一个对话框；只有按下**导入**，书才会改变。不是Word文档的文件，例如旧的二进制`.doc`，会被拒绝，并显示一条说明原因的消息；请先在Word中另存为`.docx`。

对话框包含以下几部分，每一部分都可以折叠：

- **原稿质量。** 对书稿准备情况的判断：*样式规范*（可以干净地转换）、*部分使用样式*（有些段落的格式是手动设置的）或*没有样式*（全部为Normal（正文），文字将作为普通段落导入）。下面列出各项计数（段落数、其中使用Normal以外样式的段落数、图片、表格、注释）和发现的情况，每一项都附有出现该情况的几个段落的开头几个字：手动设置格式的段落（字体、字号、颜色、对齐；这些格式不导入，由版面设计决定）、看起来像手动输入标题的加粗短段落、手动输入的编号或项目符号（而不是Word列表）、手动换行符、手动分页符、用来留出间距的空段落、制表符和连续两个空格、修订（保留插入的内容，删除的内容不导入；请先在Word中接受或拒绝）、批注（不导入）、文本框（每个文本框的文字接在其锚定的段落之后）、公式（转换为TeX；请检查）、隐藏文字，以及浏览器无法显示的格式的图片（EMF、WMF、TIFF）。
- **导入模板。** 当前使用的对应方式：*自动*（按样式名称）、一个已保存的模板，或者对于从沙盒导出的文件，*保存在本文档中*。**另存为新模板**会要求输入名称，并把对应方式（包括本文档的所有样式）保存在浏览器中；**保存修改**更新所选模板；下载按钮把模板写成`.json`文件，上传按钮载入这样的文件，这样整个团队可以共用同一个模板。删除模板前会要求确认。下一次导入时，上次使用的模板排在最前面。
- **段落样式。** 文档使用的每一种段落样式，显示使用它的段落数和其中一段的开头几个字，以及它转换成什么：**正文**、**标题**（1到6级中的一级；版面设计中有标题样式时，还可以选择其中之一）、**段落样式**（版面设计中的某个段落样式；连续使用它的段落组成一个`:::paragraphs`组）、**标注框**（连续的段落组成一个该类型的标注框）、**标注框标题**（开始一个以该段文字为标题的标注框）、**引用**、**相邻图片或表的题注**、**新一章的开始**、**Postext Markdown，按原样保留**（文字原样复制，用于在Word中输入的指令）或**不导入**。Word编号列表和项目符号列表中的段落，无论使用什么样式，都会变成Postext列表，并保留编号和嵌套层级。<strong>诗（:::verse，逐行）</strong>把该样式的段落排成一首`:::verse`诗，也可以指定设计中的某个段落样式：Shift+Enter断开一行诗，一个段落是一个诗节，连续的单行段落合成一个诗节，空段落分隔诗节；名为Verse、Poem、诗或诗歌的样式会自动推断为这一项。
- **字符样式。** 字符样式也是如此：**纯文字**、**粗体**、**斜体**、**粗斜体**、**小型大写字母**、**上标**、**下标**、**行内标签**（版面设计中的某个行内标签样式）、**Postext Markdown，按原样保留**或**不导入**。
- **选项。** 手动换行符（Shift+Enter）保留为段落内的换行（在Markdown行末写反斜杠，为默认设置），或用空格连接，或另起一段；手动设置的粗体、斜体、小型大写字母和上下标保留或不导入；加粗的短段落保持为段落，或转为某一级标题；手动分页符不导入（由版面设计决定分页），或保留为`:::pagebreak`；图片和表格是否作为资源添加。
- **Markdown预览**，随对应方式的改变而更新。

对话框底部选择文字的去向：**替换本章**、**在本章之后新建章**或**替换整本书**；后两种在每个一级标题处开始新的一章。图片（PNG、JPEG、GIF、WebP、SVG）成为图资源，表格成为表资源（保留表头行、合并单元格、列宽和单元格底色），每个资源都以`::resource{id="…"}`放在原来的位置，并以相邻的题注段落作为题注；题注中手动输入的标签（*图3.*）不导入，因为Postext会自己给资源编号。脚注和尾注成为Postext脚注（`[^1]`），Word索引项（XE域）成为`:index`标记，链接保持为链接，公式成为`$…$` / `$$…$$`。

在按名称匹配样式之前，自动对应会识别Word自身的角色，无论界面是什么语言（*标题 1*–*6*、*标题*、*引用*、*题注*；目录、索引、页眉和页脚段落不导入），也会识别版面设计中的样式：Word样式的名称与本书的某个段落样式、标注框类型、标题样式或行内标签样式相同时（按id或名称，不区分大小写和重音符号），就对应到该样式。

**导出为Word**把当前打开的章或整本书下载为`.docx`，供他人在Word中编辑。同一个模板反向应用：标题使用Word的标题样式；段落样式、标注框、引用和行内标签使用各自的Word样式（以版面设计中的样式命名，如*标注框: 注释*、*标签: 按键*）；列表变成Word列表，脚注变成Word脚注，链接保持为链接。Word无法显示的内容（前置元数据、围栏行、指令、`:ref`、公式、`:index`标记、资源行）以灰色的*Postext Markup*样式按原样保留。导出整本书时，每一章开头有一个*Postext Chapter*段落。模板随文件一起保存，所以编辑后的文档再次导入时使用同样的对应方式；文档中有章段落时，就作为整本书导入。灰色文字保持不动，文字就会按导出时的样子回来；脚注标签会重新编号（`[^1]`、`[^2]`……），印出来没有区别，`_italic_`会变成`*italic*`。

本对话框不处理的转换（PDF、PowerPoint、EPUB或IDML原稿，或重现原稿的版式规则），请使用[智能体技能](/zh/docs/skill)。

## 持久化

沙盒会自动把你的工作保存到浏览器中：

- **书和配置**——章、当前章和Canvas范围自动保存到`localStorage`的`postext-sandbox-book`下（早期版本保存的单个文档会从`postext-sandbox-markdown`读出，作为只有一章的书，并在第一次保存时迁移）；配置在停止操作1秒后保存，默认值会被去掉，只存储你改过的部分，同时保存其版本号（`postext-sandbox-config-version`）；在有版本号之前保存的配置，按下文*postext 1.4及更早版本保存的标题分页*所述方式读取
- **界面状态**——当前面板和视图标签页、侧边栏宽度、版面设计面板中展开的分组（`postext-sandbox-settings-group`）、其*显示全部说明*开关（`postext-sandbox-settings-help`）和各区块的展开状态、隐藏的示例书、Canvas的缩放/适应/视图模式、HTML的字体缩放和分栏模式、EPUB标签页的版式（`postext-sandbox-epub-layout`），以及工具栏的固定状态，都保存在`localStorage`中
- **打开的书**——你自己的书（*项目*）中当前打开那本的id保存在`localStorage`的`postext-sandbox-project`下；项目本身（章、配置和资源记录；记录为`version: 9`，即引擎的`CONFIG_VERSION`，工作配置和导出的`postext-config.json`也带有这个版本号，因此引擎规则改变时每一项只迁移一次；早期版本的单文档记录在读取时迁移；版本3之前记录的标题分页、版本4之前记录的公式字号、版本5之前记录的行内图下方间距、版本6之前记录的框内行内图上下间距、标题中的标记、首字下沉字号、冒号行下方空间和框的断开，版本7之前记录的破折号处断行和不齐行文字的断行，以及版本8之前记录的标题下拆分、复合词连字符处断行和`:::paragraphs`容器下方的间距，都按下文所述方式固定下来）存放在沙盒IndexedDB数据库的`projects`存储中，其二进制数据与工作文档共用blob和字体存储。当工作文档和所有项目都不再引用某项数据时，它会被垃圾回收
- **编辑过的示例书**——你修改过的示例书（它的章、当前章、Canvas范围、配置和资源记录，以及打开时示例所应用的内容）保存在沙盒IndexedDB数据库的`presetDrafts`存储中，每个示例和内容语言一条记录；其文件与项目的文件一样不会被垃圾回收清掉。恢复原版会删除这条记录
- **示例书封面**——对于没有附带缩略图的示例书，取自其第一页的封面保存在沙盒IndexedDB数据库的`presetCovers`存储中，每个示例和内容语言一条记录（见[书库面板](#书库面板)）。你自己的书把封面保存在其项目记录中。
- **离开时保存**——页面被隐藏或关闭时、通过链接（标志）离开沙盒时，以及打开另一本书之前，待保存的修改会立即写入，而不是等1秒的停顿
- **打开的示例书**——最后加载的预设的id保存在`localStorage`的`postext-sandbox-preset`下，因此各面板的重置按钮在不同会话之间都会恢复这个预设（不再提供的预设会显示为不可用）。该预设应用过的内容（它的文件包指纹，加上Markdown、配置和资源集的哈希值）保存在`postext-sandbox-preset-applied`下，下次访问时据此区分未改动的文档和编辑过的文档
- **资源和字体**——资源记录、它们的二进制blob（位图和SVG）以及自定义字体文件保存在**IndexedDB**中；IndexedDB不可用时（例如某些隐私浏览模式），检查面板中会出现*存储不可用*警告（在*浏览器*下）
- **永久链接**——URL片段标明屏幕上显示的内容，因此重新加载、书签或发给别人的链接都会在同一个查看器中打开同一本书的同一页：`#preset=bioquimica-feduchi&lang=es&view=canvas&chapter=1&page=7`会在Canvas标签页上打开西班牙语的Bioquímica预设，定位到第1章第7页（页面上印的页码）。`view`可以是`canvas`、`pdf`、`folio`、`html`或`epub`；在书页标签页上，页是打开的跨页中右侧那一页。本地项目用`project=ID`表示，即它的存储id，所以只有保存该项目的浏览器才能打开这样的链接。你切换书、标签页和章以及滚动时，沙盒会随时更新这个片段。省略的部分表示保持现状（没有页：该章第一页；没有书：上次打开的那本），浏览器打不开的书会被跳过。在已打开的沙盒的地址栏中粘贴链接，会就地打开它。如果打开页面时用的链接指向的书与上次打开的不同，沙盒会一直显示加载状态，直到链接的书加载完毕，而不会先显示之前那本。宿主还可以用`hashBundles`属性链接到自己的书（见[属性](#属性)）：网站用`#recipe=<slug>&lang=es`打开一份排版食谱中的食谱。第一次访问会把食谱的`.postext`文件导入为你的一本书。之后再访问同一链接，会先询问（*你已有这本书*）：**打开我的副本**打开那本书，包括你的修改；**替换为已发布版本**重新导入食谱（它此后可能已经修正），新书打开后删除你的副本；按Escape则保留你的副本。片段随后改为标明该项目。界面语言保留在路径中（`/en/sandbox`、`/es/sandbox`）；`lang`是双语文件包的内容语言，可以是任何BCP 47标签，以规范大小写保存（`lang=zh-hant`读作`zh-Hant`）。文件包没有列出的标签会打开适用于它的版本：`zh-TW`和`zh-HK`打开繁体中文版（`zh-Hant`），`zh`和`zh-CN`打开简体中文版（`zh-Hans`），`en-GB`打开英文版。只有当文件包没有读者所用文字的版本时，才会读取另一种中文文字：指向一本有`zh-Hans`和英文版本的书的`zh-TW`链接会打开简体中文文本，而不是英文。不带`lang`的链接打开文件包的`openLocale`（如果指定了的话），否则打开界面语言对应的版本。链接中的章和页作用于它打开的版本，之后片段会用该版本自己的标签来标明它（`lang=zh-TW&chapter=28`变为`lang=zh-Hant&chapter=28`）。

**postext 1.4及更早版本保存的标题分页**。在postext 1.4及之前，带有`headings`对象的配置在排一级标题时不分页，除非它明确设置了H1的*前置分页*开关（而且保存时会丢掉关闭的H1分页）；不完整的H1分页设置，缺少的字段取自不分页的默认值；标题样式的分页也是如此，而不是合并到其所在级别的设置上。现在引擎保留每一级的默认值（H1从新的右页开始，即`always-odd`），并把不完整的分页设置合并到默认值上。为了让当时保存的书保持原来的页面，沙盒在读取版本3之前的项目记录或没有版本号的工作配置时，会把这些分页设置写出来：原先分页关闭的，在H1上写`enabled: false`；在H1和标题样式上，于未指定奇偶的`enabled: true`旁边写`parity: 'any'`。版面设计面板随后显示的就是排版时实际使用的分页设置。自postext 1.5起，文件也会记录版本：清单中没有`configVersion`的`.postext`文件，以及没有版本号的`postext-config.json`，都是postext 1.4或更早版本写出的，导入或打开时按同样方式读取（见[postext 1.4及更早版本写出的文件包](/zh/docs/configuration#postext-14及更早版本写出的文件包)）。

**postext 1.5之前保存的公式字号**。在postext 1.4及之前，每个公式都比其*缩放比例*所规定的大1.131倍（见[公式字号](/zh/docs/configuration#数学公式)）。为了让当时保存的书保持原来的页面，沙盒在读取以下内容时会固定这个字号：版本4之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 4`的`.postext`文件，或在此之前导出的`postext-config.json`。*缩放比例*变为保存的比例×1.1312，以`em`为单位的独立公式边距除以1.1312，这样公式及其周围的空白都保持原样。章中没有`$`的书保持不变（`postext-config.json`不含章，所以只要启用了公式就会固定字号），关闭了*启用LaTeX*的书也不变。公式区块随后显示排版时使用的值；把*缩放比例*、*独立公式上边距*和*独立公式下边距*重置，即可按现在的字号排版。固定只写一次：记录以当前版本重新保存，此后按原样读取。当时应用后从未编辑过的预设仍算作未改动（沙盒会与固定后的值比较，标题分页的固定也是如此）：重新加载它或切换书时，不会要求你放弃从未做过的修改，而预设的新版本（例如内置指南的新版本）仍会替换它。

**postext 1.5之前保存的行内图**。在postext 1.4及之前，在正文中行内放置的图或表（位置为*行内（此处）*）只在上方保留一行空白：其后的正文在下一条网格线处继续，不管它离得多近。现在下方也保留同样的一行（**分栏→行内图的上下间距**，*上方和下方*）。为了让当时保存的书保持原来的页面，沙盒在读取版本5之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 5`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有一行嵌入了资源（单独占一行的`::resource{id="…"}`，而不是正文中的提及），就把*行内图的上下间距*设为*仅上方*。`postext-config.json`不含章，所以只要文件较旧就会这样设置。选择*上方和下方*即可按现在的间距排版。

**postext 1.5之前保存的框内行内图**。在postext 1.4及之前，框内行内放置的图或表紧贴其周围的框内文字。现在它上方保留一行框内文字的空白，选择*上方和下方*时下方也保留（**分栏→框内图的上下间距**）。为了让当时保存的书保持原来的页面，沙盒在读取版本6之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 6`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有框在单独一行上嵌入了资源，就关闭*框内图的上下间距*。`postext-config.json`不含章，所以只要文件较旧就会关闭。打开它即可按现在的间距排版。

**postext 1.5之前保存的标题标记和首字下沉**。在postext 1.4及之前，标题中`*italic*`、`**bold**`等标记里的词按标题自身的普通样式打印；没有设置字号的首字下沉与它所跨的所有行等高，顶部高出第一行。现在标题会呈现其中的标记（**标题→标题中的行内标记**），首字下沉的顶部与第一行大写字母的顶部齐平。为了让当时保存的书保持原来的页面，沙盒在读取版本6之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 6`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有标题带有标记，就关闭*标题中的行内标记*（`postext-config.json`不含章，所以只要文件较旧就会关闭）；并把每个首字下沉当时的字号写入其**首字字号**。打开这个开关，或清除字号，即可按现在的规则排版。注意，整个标题都用`*…*`标记的斜体标题届时会变成正体。

**postext 1.5之前保存的冒号后列表**。在postext 1.4及之前，*冒号行随列表*只要冒号结尾的那一行下方还有一行空间，就认为足够放列表，所以如果第一项有两行、按段首孤行和段末孤行规则必须保持完整，它就会移到下一栏，把冒号行单独留在栏底。现在它要求第一项所需的空间（**字体排印→正文→孤行与短行→冒号行下方空间**，*第一项所需*）。为了让当时保存的书保持原来的页面，沙盒在读取版本6之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 6`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有列表跟在以冒号结尾的行之后，就把*冒号行下方空间*设为*一行（1.4）*。`postext-config.json`不含章，所以只要文件较旧就会这样设置。选择*第一项所需*即可按现在的规则排版。

**postext 1.5之前保存的框断开**。在postext 1.4及之前，在段落或列表项内部断开的框，只要框的每一侧都保留了*拆分时每侧保留的行数*，就可能在某一侧只留下该段落或列表项的一行。现在断开处每一侧至少留下段落或列表项的两行（**分栏→框断开处段落的行数**）。为了让当时保存的书保持原来的页面，沙盒在读取版本6之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 6`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有章使用了`:::callout`，就把*框断开处段落的行数*设为1。`postext-config.json`不含章，所以只要文件较旧就会这样设置。把它改回2即可按现在的规则排版。

**postext 1.5之前保存的破折号和不齐行文字**。在postext 1.4及之前，最优断行从不在两词之间紧排的长破折号或短破折号（`say—that’s`）之后结束一行，不齐行文字也总是逐行排，每行排满再排下一行。现在一行可以在这样的破折号之后结束（**字体排印→正文→段落→破折号后断行**），不齐行的正文也用Knuth-Plass断行（**不齐行文字最优断行**）。为了让当时保存的书保持原来的页面，沙盒在读取版本7之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 7`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有章使用了这样的破折号，就关闭*破折号后断行*（`postext-config.json`不含章，所以只要文件较旧就会关闭）；如果配置把某些连续正文设为不齐行，即正文、某个段落样式、框的正文、篇的正文或章节样式的正文，就关闭*不齐行文字最优断行*。打开它们即可按现在的规则排版。

**postext 1.5之前保存的标题下拆分**。在postext 1.4及之前，位于栏底的标题下方的段落，在那里能放下多少行就保留多少行，不管移到下一栏的有多少。现在它还要满足段末孤行（orphan）的最少行数，否则标题会随它一起移走（**标题与目录→标题→标题下的拆分**）。为了让当时保存的书保持原来的页面，沙盒在读取版本8之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 8`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有章包含标题（`postext-config.json`不含章，所以只要文件较旧就会这样设置），并且配置开启了*与下文同栏*和段末孤行控制，就把*标题下的拆分*设为*填满本栏*。把它设为*按规则*即可按现在的规则排版。

**postext 1.5之前保存的段落容器**。在postext 1.4及之前，`:::paragraphs`容器下方的间距取样式自身的值（段间距和下外边距中较大者），加在最后一行下面，之后正文才回到网格上；标题在自身上方保留的间距加在它下面，而正文的段间距不计入。于是标题离参考文献比离段落更远，一组紧凑条目之后的段落离它们又比离其他任何内容都近。现在这个间距与下一个块自身的间距合并，并且至少等于正文的段间距（**字体排印→段落样式→容器下方间距**，*折叠*）。为了让当时保存的书保持原来的页面，沙盒在读取版本8之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 8`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果配置声明了段落样式，并且书中有章使用了`:::paragraphs`容器，就把*容器下方间距*设为*相加（1.4）*。`postext-config.json`不含章，所以只要文件较旧并且声明了段落样式，就会这样设置。选择*折叠*即可按现在的规则排版。

**postext 1.5之前保存的复合词**。在postext 1.4及之前，在没有粗体、斜体或其他格式的段落里，最优断行从不在复合词（`well-known`）的连字符之后结束两端对齐的行，而在带格式的段落里却会。现在每个段落都可以在那里断行（**字体排印→正文→段落→连字符后断行**）。为了让当时保存的书保持原来的页面，沙盒在读取版本8之前的项目记录、以更旧版本号（或无版本号）保存的工作配置、清单版本早于`configVersion: 8`的`.postext`文件，或在此之前导出的`postext-config.json`时，如果书中有章在两个字母之间使用了连字符，就关闭*连字符后断行*（`postext-config.json`不含章，所以只要文件较旧就会关闭）。打开它即可按现在的规则排版。

**postext 1.23之前保存的诗和悬挂缩进样式**。在postext 1.22及之前，各行不含`||`的`:::verse`诗按单独的半句排，每行居中；段落样式的悬挂缩进会取代其首行缩进。现在这样的诗逐行排（**字体排印→正文→诗歌→无分隔符的诗**，*逐行*），同时设置两种缩进的样式，首行从首行缩进开始。为了让当时保存的书保持原来的页面，沙盒在读取版本低于9的项目记录、工作配置或标记低于9的`postext-config.json`导出，且其章节中有这样的诗时，把*无分隔符的诗*设为*按半句（1.22）*，并去掉同时设置了悬挂缩进的样式的首行缩进。章节中有行以反斜杠结尾或有后跟空格的`\\`时（在postext 1.22及以前它们会照样印出），沙盒还会关闭**强制换行**（**字体排印→正文→段落**）；`postext-config.json`导出不带章节，所以总会关闭。

这些固定措施挡住的是上述每项规则变化会造成的移动。1.5版还修复了一些排版错误，而修复没有对应的固定措施，所以在以下情形中，保存的书仍可能出现页面变动：没有版面设计的通栏章标题所在的横带、标题版面设计中的首字下沉、框中的段落、被齐底操作拉开的松散段落、外边距宽于一行的浮动框、带字距的居中或右对齐书眉、通栏章首下方的第二栏、取自在连字符后断开的标题的书眉、比行还宽的词在其自身连字符旁被截断、比行还宽的词的剩余部分（现在保留自己的断点），以及嵌套在另一个列表中的列表之后的那一项（清单见[公式字号](/zh/docs/configuration#数学公式)）。

存储在**各界面语言之间共享**。未经改动的默认文档会在语言切换时换成当前语言的默认Markdown，并重新放入示例资源，所以打开西班牙语沙盒会显示西班牙语示例。用户的任何编辑都会让文档退出这一行为。当配置没有指定语言时（既没有断词语言，也没有`locale`），所有预览都会从界面语言推导出断词语言。

### 导出与导入

一整本书以<strong>`.postext`文件</strong>的形式传递：这是一个zip压缩包，其结构与预设文件包目录完全相同，即`preset.json`、`chapters/*.md`、`resources/*`和`fonts/*`（见[预设文件包格式](#预设文件包格式)）。压缩包还以`layouts.json`携带书的**分页**信息：每章的页数和编号，并标记了生成时所用的引擎版本、配置和资源，因此导入的书打开时已经分好页，只有这些标记不再能担保的部分才重新排版。多语言文件包为每种语言使用各自的配置，所以可以改为每种语言带一个`layouts.<locale>.json`（`layouts.zh-Hant.json`），它先于`layouts.json`读取。当前文档导出它持有的分页；从某一行导出的项目或预设，带的是它上次作为工作书时记录的分页。封面图作为清单的`thumbnail`写入，因此往返之后仍然保留。**书库面板**的**新建**菜单（**打开.postext文件…**）把文件导入为一本新书；每一行的⋯菜单都有自己的**下载（.postext）**，当前打开的书导出的是工作文档。早期版本写出的文件（版本1清单，只有一个`document.md`）导入为只有一章的书。单一语言的书无论界面语言是什么，都保留该语言的图和表标签：从`/en/sandbox`打开的西班牙语文件打印*Figura*和*Tabla*，除非其配置指定了其他资源类型。这个语言是文件指定的语言；文件没有指定时，取其配置所设的语言（先看`locale`，再看断词语言）。导入时接受位于压缩包根目录或某个顶层文件夹下的文件（直接压缩文件夹本身就会是后一种情况；`__MACOSX`条目和点文件会被忽略）。字体作为单独的文件写入，从不放在`config.customFonts`里；导入和导出时都会跳过`.woff`字体并给出警告，缺少字节数据的资源也是如此。把导出的文件解压到`<presets-root>/<dir>/`，并添加一条`index.json`条目，即可把它作为预设提供。

`postext`包读写的也是这些文件（`openBundle`、`createBundle`、`buildBundle`；见[文件包](/zh/docs/configuration#文件包postext文件)）。在这里导出的书可以在你自己的程序中打开，你的程序写出的书也可以在这里打开。这样，沙盒就成了检查和微调程序排版结果的地方：从程序中导出，在这里导入，借助实时预览修改，再次导出，然后载回程序。[智能体技能](/zh/docs/skill)交付的移植结果也是`.postext`文件。

正文和版面设计也可以分别从正文面板和版面设计面板的标题栏导出。

**版面设计面板**的标题栏会下载去掉默认值的`postext-config.json`：

```json
{
  "type": "postext-config",
  "version": 1,
  "config": { ... }
}
```

**正文面板**的标题栏把当前章下载为普通的`.md`文件，它的**导入**按钮用一个`.md`文件的内容替换当前章。版面设计面板的**导入**按钮会打开文件选择器，选取`.json`文件，并按预期的`type`和`version`进行校验；无效文件会被静默忽略。早期版本的`postext-markdown.json`包装格式和合并的`postext-sandbox.json`格式已不再存在。

## 独立使用

沙盒提供为独立的React包（`postext-sandbox`），可以嵌入任何React应用：

```bash
npm install postext-sandbox postext
```

```tsx
import { PostextSandbox } from 'postext-sandbox';

function App() {
  return (
    <PostextSandbox
      initialMarkdown="# Hello World"
      initialConfig={{ layout: { layoutType: 'double' } }}
      onMarkdownChange={(md) => console.log(md)}
      onConfigChange={(cfg) => console.log(cfg)}
    />
  );
}
```

### CSS要求

这个包使用引用CSS自定义属性的Tailwind CSS工具类。宿主应用必须提供以下变量：

- `--background`、`--foreground`——基础颜色
- `--surface`——浮起表面的颜色；`--surface-2`——悬停行和高亮选项的颜色（缺省时回退到`--background`）
- `--slate`——弱化文字的颜色
- `--rule`——边框/分隔线颜色；`--rule-strong`——悬停控件上更醒目的线（缺省时回退到`--slate`）
- `--brand`——强调色：当前面板标记、焦点环、开关和选中的选项
- `--brand-hover`——悬停时的强调色
- `--brand-soft`——选中选项背后半透明的强调色填充（缺省时回退到`--surface`）
- `--brand-contrast`——选中状态开关的滑块（缺省时回退到`--background`）
- `--destructive`——破坏性操作和错误的颜色
- `--accent-blue`——链接/强调颜色
- `--font-sans`——界面字体
- `--font-mono`——等宽字体（用于代码编辑器）
- `--font-display`、`--brand-blue`、`--brand-gilt`——活动栏中默认标志的字体和颜色，可选（缺省时回退到Georgia、`#2b4acb`和`#d8a21a`）

网站在深色主题中把`--brand`设为金色，在浅色主题中设为蓝色。早期版本读取`--gilt`和`--gilt-hover`；沙盒已不再使用它们。

弹出层、菜单和工具提示渲染在`document.body`上的portal中，所以要在`:root`（或`body`）上定义这些变量，而不只是在包裹沙盒的元素上。宿主的Tailwind构建必须扫描这个包的源代码（在Tailwind 4中为`@source "…/postext-sandbox/src/**/*.tsx"`），才能生成它用到的工具类。

## 预设文件包格式

附录。预设来源是一个（通过HTTP提供的）目录，其根目录中有一个列出各预设目录的`index.json`；每个目录包含一个`preset.json`清单，以及它引用的Markdown、资源和字体文件。仓库中`scripts/presets/`下的工具生成的文件包正是这种结构，从沙盒导出的`.postext`文件就是这样一个目录的zip压缩包（不含`index.json`）。

```
<presets-root>/
  index.json
  <preset-dir>/
    preset.json
    chapters/              每章一个.md，按顺序排列（版本1清单则只指定一个文档）
    resources/             图：.svg / .png / .jpg / .jpeg / .webp / .gif（+ 可选的.pdf印刷母版）
    fonts/                 .otf / .ttf / .woff2，每个文件一个字体样式
```

### `index.json`

```jsonc
{
  "version": 1,
  "presets": [
    {
      "id": "acme-journal",          // 稳定的id，[a-z0-9-]
      "dir": "acme-journal",         // 相对于index.json的目录名
      "name": "Acme Journal",
      "description": "Two-column journal article",   // 可选
      "locale": "en",                 // 可选
      "default": true,                // 可选，最多一个
      "locales": ["en", "es"],        // 可选：文件包包含的所有语言
      "openLocale": "en",             // 可选：未指定语言时打开所用的语言
      "thumbnail": "thumbnail.jpg",   // 可选：选择器中显示的预览图
      "license": "CC BY 4.0",         // 可选：显示为标签
      "credits": "Text and images: ESO",  // 可选：描述下方的一行
      "tags": ["magazine", "two-column"], // 可选
      "binding": "left"               // 可选：网站书架绘制书脊的那一边（右侧装订的书用"right"）
    }
  ]
}
```

### `preset.json`

```jsonc
{
  "version": 2,
  "id": "acme-journal",
  "name": "Acme Journal",
  "description": "Two-column journal article",       // 可选
  "locale": "en",                                     // 可选
  "default": true,                                    // 可选
  "configVersion": 8,                                 // 可选：`config`所遵循的配置规则版本
  // 与索引条目相同的可选展示字段：
  // "locales", "openLocale", "thumbnail", "license", "credits", "tags"

  // 书的各章，按顺序排列；也可以每种语言一个列表
  "chapters": [
    { "title": "Introduction", "file": "chapters/01-introduction.md" },
    { "title": "Methods", "file": "chapters/02-methods.md" }
  ],
  // "chapters": { "en": [ … ], "es": [ … ] },
  // 版本1清单改用单个文档，仍然可以接受：
  // "version": 1, "markdown": "article.md"  （或语言→文件的映射）

  // 可选的PostextConfig JSON（页面、页边距、分栏、字体排印……）。
  // 不要在这里放customFonts：字体来自下面的`fonts`数组。
  "config": { },

  "resources": [
    {
      "id": "fig-1-1",                 // 在Markdown中引用（:ref）
      "typeId": "figure",              // 资源类型id（figure、table……）
      "kind": "svg",                   // "svg" | "bitmap" | "table"
      "file": "resources/fig-1-1.svg", // 仅svg/bitmap，相对于preset.json
      "width": 240.5,                  // 可选，pt（svg）/ px（bitmap）
      "pdfFile": "resources/fig-1-1.pdf", // 可选，仅svg：矢量印刷母版（见说明）
      "height": 180,                   // 可选
      "caption": "Caption text",
      "altText": "Accessible description",            // 可选
      "safeArea": { "x": 0.18, "y": 0.25, "width": 0.5, "height": 0.6 }, // 可选，仅svg/bitmap：始终显示的部分，以图片的比例表示
      "placement": { "position": "top", "span": "column" },  // 可选
      "note": "Source: ...",                          // 可选
      "table": { "model": { "rows": [[{ "content": "A", "isHeader": true }]], "headerRowCount": 1 } }
                                                      // 仅用于kind "table"
    }
  ],

  "fonts": [
    {
      "name": "Some Family",           // 配置中使用的字体家族名
      "variants": [
        { "weight": 400, "style": "normal", "file": "fonts/SomeFamily-Regular.otf" },
        { "weight": 400, "style": "italic", "file": "fonts/SomeFamily-Italic.otf" },
        { "weight": 700, "style": "normal", "file": "fonts/SomeFamily-Bold.otf" }
      ]
    }
  ]
}
```

说明：

- `preset.json`中的`id`必须与`index.json`条目一致；预设加载后，清单中的`description`、`locale`和`default`会覆盖索引中的值，展示字段`locales`、`openLocale`、`license`、`credits`和`tags`也是如此。`openLocale`是`locales`中的一项，指链接或点击没有指定语言时书打开所用的语言（首页的书架也链接到它）：原作不是读者所用语言时就设置它，《紅樓夢》示例就设为`zh-Hant`，这样就不会让每个讲英语的读者都打开它的英译本。不设置时由界面语言决定。选择器把`locales`（或`locale`）中的每种语言和许可证显示为标签，把出处信息显示在描述下方，并用`thumbnail`（相对于预设目录的一张小页面图）代替该行的勾选标记列；从预设复制出的书（**建立我的副本**）把它保留为封面。`apps/web/public/presets/`下的公开示例预设用到了所有字段，并附有一个`CREDITS.md`，写明每段文字和每张图片的许可证和来源。
- `configVersion`（可选）指明`config`和`localized`中各配置所遵循的配置规则。自postext 1.5起，所有写出清单的程序都把它设为8。没有它的清单是postext 1.4或更早版本写出的，其标题分页、公式字号、行内图周围的间距（正文中和框中）、标题标记、首字下沉、冒号行下方空间、框断开、破折号和复合词连字符处的断行、不齐行文字、标题下拆分以及段落容器下方的间距，都按1.4的排法读取（见[持久化](#持久化)下的*postext 1.4及更早版本保存的标题分页*、*postext 1.5之前保存的公式字号*、*postext 1.5之前保存的行内图*、*postext 1.5之前保存的框内行内图*、*postext 1.5之前保存的标题标记和首字下沉*、*postext 1.5之前保存的冒号后列表*、*postext 1.5之前保存的框断开*、*postext 1.5之前保存的破折号和不齐行文字*、*postext 1.5之前保存的复合词*、*postext 1.5之前保存的标题下拆分*和*postext 1.5之前保存的段落容器*）；标记为3到7的清单（1.5预发布版）只应用较新规则的固定措施。为3时，是公式字号、行内间距、规则6的五项、规则7的两项和规则8的三项；为4时，是行内间距以及规则6、7、8的固定措施；为5时，是规则6、7、8的固定措施；为6时，是规则7和8的固定措施；为7时，只有规则8的固定措施。手写清单并采用现在的规则时，把它设为8。
- `view`（可选）说明沙盒如何打开文件包：`{ "canvasScope": "book" }`在Canvas上排出整本书（见[书与章](#书与章)）；省略时，Canvas一次显示一章。导出的书如果设置了它，会一并带上。超过200章的书无论要求什么，都一次打开一章。
- `localized`（可选）存放双语文件包的各语言覆盖项：`{ "es": { "config": { … }, "resources": [ { "id": "fig-1", "caption": "…", "note": "…", "altText": "…" } ] } }`。选取章时所依据的那种语言的覆盖项，会叠加在共用的`config`之上（顶层键整体替换，通常是带有翻译过的题注前缀的`resourceTypes`），以及共用的`resources`之上（题注、注释、替代文字和表格单元格按id合并）；没有条目的语言保留共用的文字。条目也可以带自己的`view`，它对该版本覆盖共用的设置：《紅樓夢》的中文版本以整本书打开，而Joly的英译本整本绘制要慢得多，所以一次打开一章（`"en": { "view": { "canvasScope": "chapter" } }`）。
- `chapters`（版本2）是按书中顺序排列的`{ title, file }`列表，或语言→列表的映射；`markdown`（版本1）是一个文件名或语言→文件的映射。两种情况下，沙盒都选取与所请求语言匹配的条目（先是完全相同的标签，不计大小写；然后是相同语言和文字，所以`zh-TW`先读`zh-Hant`再读`zh-Hans`；然后是相同语言的另一种文字，所以`zh-TW`读者打开以裸`zh`为键的文件包时得到中文；然后是预设自身的`locale`，最后是第一个条目），并且只读取该语言的章文件。章的`title`为空时，取自文件中的第一个一级标题。沙盒总是写出版本2。
- 对于`svg`和`bitmap`资源，`width`/`height`是可选的：缺少时在加载时从文件中读取。
- `pdfFile`（仅限svg资源）指向一个单页PDF，其中以矢量形式包含同一幅图，通常是SVG所源自的Illustrator原稿或PDF导出文件。PDF导出时原样嵌入这一页（字体、渐变和色彩空间都完整保留），而不用SVG；Canvas和HTML预览仍使用SVG。在单色模式下它会被忽略，因为该模式的重新着色只处理SVG标记；文件缺失时只会丢掉母版，不会丢掉图。在资源详情中编辑SVG源代码会解除母版（母版是为原来的源代码制作的），从此PDF导出跟随编辑后的SVG；恢复原版（书库面板中的**恢复原版…**）即可找回母版。没有母版的SVG，如果不超出PDF后端支持的子集（基本形状、路径、编组、`use`、裁剪路径、纯色填充和描边、不透明度，以及用文档能加载的字体排出的`text`/`tspan`文字，先找自定义字体，再找Google托管的字体家族），就作为矢量路径输出，否则以600 dpi栅格化。
- SVG中的`text`在各处都用沙盒的自定义字体渲染：预览在解码SVG之前把匹配的`@font-face`数据内联进去（`<img>`看不到页面的字体），PDF导出则把这些文字排成真正可选中的文本，使用同样的嵌入字体。在`font-family`中写的字体家族名要与“字体”下显示的名称完全一致。
- SVG源代码编辑器只允许在文本节点（着色显示）内输入，以免意外破坏图；编辑器标题栏中的锁按钮会打开全部源代码（坐标、颜色、结构），再次锁定时会重新扫描文本节点。
- `table.model`是Postext的`TableModel`：`rows`是按行排列的单元格数组（`content`，可选的`colSpan`、`rowSpan`、`isHeader`、`align`、`verticalAlign`），`headerRowCount`是开头的表头行数，`columnWidths`是可选的相对列宽数组。`table.styleId`可以指定配置的`tableStyles`之一。
- 字体文件以由预设id和文件路径派生的id存入IndexedDB，应用预设时，其字体家族会追加到`config.customFonts`中；`index.json`缺失或格式错误时，不会产生预设，但也不报错。
- `<preset-dir>/fingerprint.json`是可选的，在开发路由上是**虚拟的**：不存在这个文件时，`GET`会返回`{ "fingerprint": "<sha1 hex>", "files": <n> }`，它根据目录的文件元数据计算（深度不超过四层的每个文件的相对路径、修改时间和大小，跳过点文件和`node_modules`），从不读取文件内容，并带有`Cache-Control: no-store`。沙盒轮询它以跟踪文件包的修改（见[书库面板](#书库面板)）。静态主机可以提供形状相同的真实`fingerprint.json`，也可以不提供，这时它的预设不会被跟踪。
