# Livres de pages composées

**Vous construisez une page de manuel à partir d’un gabarit, vous la remplissez avec le texte du Markdown, vous étiquetez une carte, vous traduisez la page et vous corrigez ce qui ne tient pas ; vous ajoutez ensuite un arbre, des notes sur une carte, une page de cartes avec photos et une bibliothèque de modules.**

Une page de manuel scolaire est un assemblage de boîtes : un bandeau de titre, un texte, une boîte pour une définition, une autre pour une activité, une carte. Postext compose une telle page d’après un **gabarit de page** qui contient ces boîtes (ses blocs) ; le Markdown indique seulement quels mots vont dans quel bloc. Ce tutoriel fait tout le travail dans le Sandbox, sur un livre existant, auquel il ajoute une page. Les pages de référence expliquent ce que fait chaque champ et chaque ligne de Markdown ; ici, vous faites chaque chose une fois, dans l’ordre, et vous voyez ce qu’elle change : [Pages composées](/fr/docs/composed-pages) pour le Markdown, [Configuration › Pages composées](/fr/docs/configuration-composed-pages) pour le gabarit, [Sandbox : les pages composées](/fr/docs/sandbox-composed-pages) pour les écrans.

Il vous faut un navigateur, rien d’autre. Tout se passe dans le Sandbox, et ce que vous modifiez reste dans votre navigateur.

## 1. Ouvrir le livre

Le livre s’appelle *Our river*. C’est une unité d’un manuel de CE2, publiée comme recette nº 156 dans le [livre de recettes](/fr/cookbook/children-textbook-pages). La rivière, les villages et les images ont été inventés pour l’occasion. Il compte neuf pages, avec une carte peinte sur deux pages en regard, et il existe en espagnol, en catalan et en anglais.

[Ouvrez-le dans le Sandbox](/fr/sandbox#recipe=children-textbook-pages&lang=en). À la première visite, il s’ajoute à **Livres** comme un livre à vous, que vous pouvez modifier à votre guise ; avec `lang=es` ou `lang=ca` dans le lien, vous obtenez les autres éditions. Si vous revenez plus tard au même lien, le Sandbox demande s’il faut ouvrir votre copie ou la remplacer par la version publiée.

Deux choses à savoir avant de toucher à quoi que ce soit :

- La barre au-dessus de l’aperçu comporte un sélecteur à deux positions, **Contenu** et **Maquette**. En mode Contenu, vous modifiez les mots, dans le panneau **Texte** ou sur la page. En mode Maquette, vous modifiez les gabarits de page et les styles, et le texte est en lecture seule. **Alt+Maj+M** (**⌥⇧M** sur un Mac) passe de l’un à l’autre.
- Le panneau **Texte** montre un chapitre de Markdown. Chaque page composée est un passage qui commence par `::::page{template="…"}` et se termine par une ligne de quatre deux-points. Cliquez sur des mots d’une page dans l’aperçu : le curseur se place sur eux dans le Markdown.

## 2. Faire un gabarit de page

La nouvelle page sera une page de révision : un bandeau de titre, un court texte dessous et deux boîtes, l’une pour se rappeler ce qu’on a appris et l’autre pour s’exercer. Il lui faut un gabarit de quatre blocs.

1. Passez en **Maquette** et ouvrez le panneau **Maquette** à gauche. Choisissez **Page et colonnes**, puis **Gabarits de page**. La liste montre chaque gabarit du livre avec un dessin de ses blocs.
2. Appuyez sur **Nouveau**. Un gabarit nommé *Nouveau gabarit* s’ouvre. Donnez-lui l’**ID** `review` (le nom qu’emploiera le Markdown) et le **Nom** `Review page` (le nom qu’affiche ce panneau). L’ID n’accepte que des minuscules, des chiffres et des tirets.
3. Le gabarit commence avec un seul bloc, `text`, qui **Reçoit le texte libre de la page**. Faites-en le bandeau de titre : **Nom (emplacement)** : `title` ; **Style de bloc** : `portada`, le bandeau bleu que le livre utilise déjà pour ses titres ; désactivez **Reçoit le texte libre de la page** ; **Reçoit le premier titre** : *Niveau 1*, pour que ce bloc reçoive le premier titre `#` de la page.
4. Appuyez sur **Ajouter un bloc**. Le nouveau bloc s’ouvre sous la liste des blocs. **Nom (emplacement)** : `text`, et activez **Reçoit le texte libre de la page** : tout ce que la page contient hors d’un bloc arrive ici.
5. Ajoutez un bloc. **Nom (emplacement)** : `remember`. **Style de bloc** : `dato`, une boîte teintée avec un onglet. **Hauteur minimale** : 30 mm, pour que la boîte garde une bonne taille quand son texte est court.
6. Ajoutez un dernier bloc. **Nom (emplacement)** : `try`. **Style de bloc** : `actividad`, une boîte avec une bande sur le côté. **Hauteur minimale** : 30 mm.
7. Dans `text`, `remember` et `try`, réglez **Largeur** sur *Jusqu’au bord* et **Hauteur** sur *Son contenu* : ils occupent alors toute la largeur de la page et ont la hauteur de leur texte.
8. Sous **Groupes**, appuyez sur **Ajouter un groupe**. Nommez-le `column`, laissez-le *Empilés* et réglez **Espace entre les blocs** sur 6 mm. Sous **Blocs du groupe, dans l’ordre de la page**, cochez les quatre blocs. Cochez-les dans l’ordre où ils se succèdent, le titre d’abord : la liste numérote les blocs, et les flèches font monter ou descendre l’un d’eux d’un rang. Un groupe place ses blocs les uns sous les autres et fait descendre ceux du dessous quand un bloc grandit : un texte plus long dans la première boîte pousse donc la deuxième vers le bas au lieu de déborder sur elle.

<Screenshot src="/docs-shots/fr/template.webp" alt="Le panneau Maquette sur Gabarits de page avec le gabarit Review page : ses quatre blocs et son groupe, et les mêmes blocs tracés en pointillés sur la page." caption="Le gabarit : quatre blocs et un groupe. Sur la page, les boîtes en pointillés sont les blocs, et les étiquettes vertes indiquent comment chacun est dimensionné." />

Le gabarit ne contient aucun mot. Rien de ce que vous avez réglé n’indique quel est le titre ni ce que contiennent les boîtes : le style de boîte donne son aspect à un bloc, et le groupe fixe l’ordre des blocs. On peut aussi arriver au même gabarit par d’autres chemins. En mode Maquette, vous pouvez tracer un bloc à la souris sur un endroit vide d’une page composée, et déplacer ou redimensionner ceux qui existent (voir [Sandbox : les pages composées](/fr/docs/sandbox-composed-pages#gabarits-de-page)) ; **Dupliquer** copie un gabarit pour le modifier ; **Enregistrer la mise en page comme gabarit** fait d’une page composée qui vous plaît un nouveau gabarit.

## 3. Remplir la page depuis le Markdown

1. Passez en **Contenu**, ouvrez le panneau **Texte** et appuyez sur **Ctrl+Fin** (**Cmd+↓** sur un Mac) pour aller à la fin du chapitre.
2. Appuyez sur **Page composée** dans la barre d’outils du panneau Texte. Un sélecteur liste les gabarits de page du livre, chacun dessiné avec ses blocs vides. Choisissez *Review page*.
3. Le Sandbox écrit la page à votre place, avec un bloc vide par emplacement, et sélectionne le mot `title` du titre. Tapez votre titre par-dessus.

```md
::::page{template="review"}
# Check what you have learned

A river changes as it runs from the mountains to the sea. Read the boxes, then answer them in your own words.

:::frame{slot="remember" label="Remember"}
A spring gives a trickle, streams join into a river, and the river widens as it nears the sea.
:::

:::frame{slot="try" label="Try it"}
Draw a river from its spring to the sea. Write the names of the three courses on your drawing.
:::
::::
```

Le titre va dans le bloc qui reçoit le niveau 1, le paragraphe qui le suit dans le bloc qui reçoit le texte libre, et chaque `:::frame` dans le bloc de son `slot`. Le `label` est le texte de l’onglet d’une boîte. La page apparaît dans l’onglet Canvas en page 10, après les neuf pages de l’unité : une page composée commence toujours sur une nouvelle page.

<Screenshot src="/docs-shots/fr/fill.webp" alt="Le panneau Texte avec le Markdown de la nouvelle page, et à côté la page terminée avec un titre bleu, un paragraphe et deux boîtes à onglet." caption="La page dans le Markdown et dans l’onglet Canvas." />

Remarquez ce que le Markdown n’indique pas : aucune position, aucune taille, aucune couleur. Tout cela appartient au gabarit, et le même Markdown mis en page avec un autre gabarit aurait un autre aspect.

## 4. Étiqueter la carte

Les pages 6 et 7 contiennent une carte peinte qui s’étend sur la double page. Ses mots ne font pas partie de l’image : chaque nom est une ligne du Markdown, à l’intérieur du `:::figure` de la carte :

```md
:::figure{resource="mapa" slot="mapa"}
::label[Spring]{at="nacimiento"}
::label[Molinar]{at="molinar"}
::label[Lower course]{at="bajo"}
:::
```

`at` désigne une **ancre** : un point de l’image, défini une seule fois dans la ressource de l’image et commun à toutes les langues. Pour ajouter le pont de pierre de Molinar :

1. Dans le panneau Texte, allez à la figure de la carte (cherchez `at="bajo"`) et ajoutez une ligne sous la dernière étiquette : `::label[Stone bridge]{at="bridge"}`.
2. Ouvrez **Vérifications**. La liste contient une entrée *Étiquette sur une ancre inconnue* pour la page 6 : l’image n’a pas d’ancre nommée `bridge`. Appuyez sur le bouton en forme d’épingle de cette entrée, *Poser l’ancre bridge sur l’image*.
3. Une fenêtre montre la carte et ses ancres. Le nom `bridge` est déjà sélectionné sous *Étiquettes sans ancre (1)*. Cliquez sur l’image à l’endroit où se trouve le pont.
4. Réglez le **Style d’étiquette** de la nouvelle ancre sur `pueblo`, le style des villages, et appuyez sur **Enregistrer**.

<Screenshot src="/docs-shots/fr/anchor.webp" alt="La fenêtre Ancres : la carte avec ses points, la nouvelle ancre nommée bridge sélectionnée et son champ de style d’étiquette." caption="Un clic sur l’image suffit à créer l’ancre ; son style d’étiquette lui donne l’aspect des noms de villages." />

<Screenshot src="/docs-shots/fr/map.webp" alt="La carte sur les pages 6 et 7 avec la nouvelle étiquette Stone bridge sur le pont, à côté des étiquettes des villages." caption="L’étiquette est posée au point où vous avez cliqué, dans les polices du livre." />

Le mot *Stone bridge* est du Markdown ; le point fait partie de l’image. Quand vous traduisez la page, la même ancre reçoit un autre mot.

## 5. Traduire la page

Une traduction, c’est le même gabarit avec d’autres mots. Le Sandbox la conserve comme une autre édition du même livre : une barre d’outils sur le bord gauche de l’aperçu permet de passer d’une édition à l’autre, et le panneau Vérifications les examine toutes (voir [Éditions d’un livre](/fr/docs/sandbox-previews#éditions-dun-livre)). Cette barre apparaît quand le pointeur atteint ce bord, et son bouton d’épingle la garde ouverte. Pour en créer une :

1. Ouvrez **Livres**, appuyez sur **⋯** à côté de votre livre et choisissez **Ajouter une langue…**. Choisissez la langue et appuyez sur **Ajouter et ouvrir**. Le Sandbox copie l’édition affichée dans une nouvelle édition, règle sa **Langue du document** sur la langue choisie et l’ouvre. La césure, les guillemets et les mots que le moteur écrit lui-même (comme *Continued* à l’endroit où une boîte est coupée) suivent cette langue. Le texte, lui, est encore celui de l’original.
2. Dans le panneau **Texte**, traduisez les mots et laissez le reste.

Les images, les ancres, les boîtes et leurs couleurs sont copiées avec le reste et ne demandent aucun travail. Voici à quoi ressemble la page de révision en espagnol :

```md

# Repasa lo aprendido

Un río cambia mientras baja de las montañas al mar. Lee los recuadros y respóndelos con tus propias palabras.

:::frame{slot="remember" label="Recuerda"}
Un manantial da un hilo de agua, los arroyos se unen en un río y el río se ensancha al acercarse al mar.
:::

:::frame{slot="try" label="Inténtalo"}
Dibuja un río desde su manantial hasta el mar. Escribe en tu dibujo el nombre de los tres cursos.
:::
```

## 6. Vérifier ce qui ne tient pas

Les mots n’ont pas la même longueur d’une langue à l’autre : une boîte assez grande pour le texte anglais peut être trop petite pour le texte espagnol. Le panneau Vérifications repère ces blocs. Pour en voir un, collez trois ou quatre paragraphes de n’importe quel texte dans le bloc `remember` de la page traduite, de façon qu’il contienne plus de texte que la page ne peut en accueillir.

La page montre alors le bloc entouré de rouge, avec sous son bord inférieur une bande qui indique la place qui manque (*26 mm de trop*). Dans **Vérifications**, sous *Pages composées*, l’entrée *Le texte déborde de son bloc* indique ce que la mise en page a tenté avant de renoncer (prendre de la place aux blocs voisins, puis réduire le texte) et propose les solutions sous forme de boutons :

- *laissez le texte descendre à 82,5 % (fit.minScale)* autorise le texte de ce bloc à réduire jusqu’à cette taille. C’est la solution pour quelques lignes de trop.
- *faites-le continuer sur la page suivante (overflow.continueIn)* envoie ce qui ne tient pas sur une page ajoutée après celle-ci. C’est la solution pour un texte plus long.
- *coupez environ 495 caractères* ne change rien : il sélectionne le texte du bloc et vous dit combien de caractères retirer.

Un bouton qui modifie le gabarit (et donc toutes les pages composées avec lui) demande d’abord confirmation et précise le réglage concerné. Appuyez sur **Modifier**. La page est recomposée : la boîte se termine par le mot qui signale la coupure (*Continúa*) et la suite reprend en haut d’une page ajoutée. **Cmd/Ctrl+Z** annule la modification. Le bouton **Recomposition**, dans la même barre d’outils au bord de l’aperçu, ouvre *Ce qui a bougé, et pourquoi* : la liste des blocs dont la mise en page a changé la taille ou la position pour y faire tenir leur contenu, avec la raison expliquée en clair.

Tous les repères du canvas ne sont pas des erreurs. Un bloc dont la mise en page a réduit le texte ou les images, dans les limites de son gabarit, porte un contour ambre en tirets et une pastille comme *texte à 90 %* : c’est une information. Les problèmes sont tracés en rouge (un bloc dont le contenu ne tient pas) et en violet (une apparence que la maquette n’a pas). **Repères d’ajustement**, dans la même barre que **Recomposition**, passe par trois réglages :

Un livre qui ne fixe rien commence sur **Problèmes seulement** : les pastilles d’échelle apparaissent quand vous choisissez **Tous**. Le Sandbox garde votre choix dans ce navigateur. Le livre peut le fixer pour qui n’a pas choisi : `debug.fitMarks` (`"all"`, `"problems"` ou `"none"`) et `debug.fitMarksMinScale`, qui retire la pastille d’un bloc composé à cette échelle ou plus (avec `0.95`, seul ce qui passe sous 95 % est signalé). Ces repères appartiennent au canvas : le PDF, la visionneuse HTML, l’EPUB et le Folio ne les tracent jamais. Depuis postext 1.52.

Une boîte avec des photos et leurs légendes (des blocs ancrés à l’intérieur, une légende `below` chaque photo) ne s’agrandit pas d’elle-même quand une traduction allonge les légendes : elles sortent de la boîte et passent sur ce qui se trouve dessous. Ouvrez le bloc de la boîte dans l’éditeur de gabarits et réglez **S’agrandit avec les blocs intérieurs** sur *Les blocs ancrés à l’intérieur* (`growWith: "children"` dans le gabarit). La boîte descend alors jusqu’au pied de la légende la plus basse plus sa marge intérieure du bas, son fond, sa bordure et son onglet suivent, et les blocs du dessous descendent. *Les blocs choisis* prend à la place une liste de noms. Comptent les blocs ancrés à un point du bord supérieur de la boîte et ceux qui sont ancrés à eux ; un bloc ancré au pied ou au milieu de la boîte ne compte pas, et une boîte tournée ne s’agrandit pas. Depuis postext 1.52.

## 7. Sélectionner sur la page et dans le texte

La page et son Markdown restent synchronisés.

- **De la page au texte.** Cliquez sur les mots d’un bloc : le curseur se place sur ce paragraphe dans le panneau Texte, et un chemin sous l’aperçu indique où vous êtes (*Page 10 › column › try › paragraphe 1*). En mode Maquette, le même clic sélectionne plutôt le bloc dans l’éditeur de gabarits.
- **Du texte à la page.** Mettez le curseur dans un paragraphe : le paragraphe et le bloc qui le contient sont entourés sur la page, et le même chemin indique où ils se trouvent.
- **D’une vérification.** Cliquez sur une entrée du panneau Vérifications : le Sandbox vous mène à la page, sélectionne le bloc et place le curseur dans son texte. Dans un livre à plusieurs éditions, il passe à l’édition où se trouve le problème.

## 8. Dessiner un arbre avec des connecteurs

Un arbre d’idées, un organigramme ou une frise chronologique sont des boîtes reliées par des lignes. Dans Postext, les boîtes sont des blocs et les lignes sont des **connecteurs** : des lignes du décor du gabarit qui relient des blocs. Un connecteur est dessiné une fois que les blocs ont leur boîte définitive : il suit donc une boîte qui grandit avec un texte plus long ou avec les mots d’une autre langue, et le gabarit n’a besoin d’aucune image des lignes. Vous dessinez l’arbre une seule fois, sous forme de **module** (un ensemble de blocs que n’importe quelle page composée peut contenir), et le Markdown indique combien il a de branches.

1. Dans **Maquette**, ouvrez **Page et colonnes › Modules** et appuyez sur **Nouveau module**. Un module nommé *Module* s’ajoute à la liste avec un seul bloc, `text`. Appuyez sur son crayon (*Modifier le module Module*) : l’éditeur de gabarits s’ouvre sur place, avec l’interrupteur **Module** activé.
2. Donnez-lui l’**ID** `tree` et le **Nom** `Tree of ideas`. Choisissez le bloc `text` et faites-en le haut de l’arbre : **Nom (emplacement)** `root`, **Style de bloc** `dato`, **Largeur** *Jusqu’au bord*, **Hauteur** *Son contenu*, et désactivez **Reçoit le texte libre de la page**.
3. Appuyez sur **Ajouter un bloc**. **Nom (emplacement)** : `branch` ; **Style de bloc** : `dato` ; **Hauteur minimale** : 20 mm.
4. Sous **Groupes**, appuyez sur **Ajouter un groupe**. Nommez-le `branches` et choisissez **Grille** : **Colonnes** 3, **Espace entre les colonnes** et **Espace entre les rangées** 6 mm. Sous **Répéter un ensemble de blocs**, choisissez `branch` comme **Bloc principal** : la grille pose un `branch` pour chaque élément que la page lui donne. Réglez **Boîte propre** sur *Bloc root*, **Position relative** sur *En dessous* et **Décalage Y** sur 12 mm : la grille commence ainsi sous la racine, quelle que soit la hauteur de celle-ci.
5. Sous **Décor**, appuyez sur **Ajouter un connecteur**. Dans sa fiche, réglez **Part de** sur *Bloc root* et, sous **Va vers**, appuyez sur *Chaque branch* (les extrémités d’une ligne sont les boutons enfoncés). Réglez **Tracé** sur *Arbre*, **Rayon des coudes** sur 2 mm, **Épaisseur de la ligne** sur 1,5 pt et **Marque d'arrivée** sur *Flèche*. **Choisir sur la page** fait la même chose à la souris, en mode Maquette : cliquez sur le bloc d’où part la ligne, puis sur chaque bloc vers lequel elle va ; un second clic retire une extrémité, et Échap met fin au choix.

Passons aux mots. Passez en **Contenu** et placez le curseur sur la page de révision de la section 3, dans le panneau **Texte**. De retour dans **Modules**, la liste **Page où l’insérer** indique cette page ; appuyez sur le bouton d’insertion de *Tree of ideas*. Le Sandbox écrit un bloc `:::module{template="tree"}` avant la ligne qui ferme la page, avec un bloc vide par emplacement, et, comme le gabarit `review` n’en avait pas, il lui ajoute sous son dernier bloc un groupe qui reçoit les modules. Écrivez les mots dans les blocs vides :

```md
:::module{template="tree"}
:::frame{slot="root"}
**A river** gives us
:::
:::frame{slot="branch"}
Water to drink and to water the fields
:::
:::frame{slot="branch"}
Power to turn a mill
:::
:::frame{slot="branch"}
A place to play and to paddle
:::
:::
```

Chaque `:::frame{slot="branch"}` est une branche. Copiez-en un et la page a quatre boîtes et quatre lignes ; retirez-en un et elle en a deux. Le connecteur désigne `branch[*]`, toutes les branches de la page : les lignes suivent donc le Markdown sans que le module change.

<Screenshot src="/docs-shots/fr/tree.webp" alt="Le panneau Maquette avec le module Tree of ideas ouvert sur la fiche de son connecteur, et la page de révision avec une boîte en haut reliée par des lignes fléchées à trois boîtes en dessous." caption="L’arbre : une racine, une grille qui répète la branche, et un connecteur vers chaque branche." />

Un organigramme est le même module avec d’autres blocs : une carte pour la personne qui dirige l’équipe, une grille qui répète une photo et un nom, et un connecteur en arbre vers chaque carte. Une frise chronologique règle **Position de la barre** sur 0 : pas de barre, mais une descente depuis la bande des dates jusqu’à chaque carte.

## 9. Des notes sur une carte, avec des renvois et une légende

Une page de notes autour d’une carte : chaque note a une ligne vers l’endroit dont elle parle, la carte a une légende pour ses signes, et un nom se tient à l’écart de son point, relié à lui par une ligne. Aucune de ces lignes ne fait partie de la peinture.

Le livre contient la peinture deux fois : `mapa`, avec les noms des pages 6 et 7, et `rio`, la même image sans ancres, posée en petit sur la page de sommaire. Cette page utilise `rio` : les points que vous y ajoutez ne déplacent donc aucun nom de la double page.

1. Faites un gabarit de page comme à la section 2. **ID** `map-notes`, **Nom** `Map with notes`. Ses blocs : `title` (**Style de bloc** `portada`, **Reçoit** *Niveau 1*), `text` (**Reçoit le texte libre de la page**), `map` (**Largeur** *Jusqu’au bord*), et `note-1`, `note-2` et `note-3` (**Style de bloc** `dato`, **Largeur** 56 mm, **Hauteur minimale** 26 mm). Empilez `title`, `text` et `map` dans un groupe `column` avec 6 mm entre les blocs, et placez les notes dans un groupe `notes` *En rang*, à 8 mm l’une de l’autre. Accrochez `note-1` à *Bloc map*, *En dessous*, 14 mm plus bas.
2. Écrivez la page à la fin du chapitre :

```md
::::page{template="map-notes"}
# Along the river

The map shows the valley of the Aldara. Each note tells you about one place on it: follow its line to find the place.

:::figure{resource="rio" slot="map"}
::label[Spring]{at="spring" style="agua"}
:::label{at="key" style="key"}
:icon[]{glyph="●" color="ink"} Town
:icon[]{line="solid" color="agua"} River
:icon[]{line="dashed" color="ink"} Path
:::
:::

:::frame{slot="note-1" label="The dam"}
The dam holds the water back in a lake. In dry months it lets some out, so the river never runs empty.
:::

:::frame{slot="note-2" label="Molinar"}
Molinar grew round its bridge and its mill. The mill wheel turned with the water of the river.
:::

:::frame{slot="note-3" label="Aldamar"}
At Aldamar the river meets the sea. Fishing boats leave the harbour every morning.
:::
::::
```

`:::label{at="key" style="key"}` est une étiquette de plusieurs lignes : chaque ligne est une rangée de la légende. `:icon[…]{…}` est un symbole dans la ligne : un glyphe, un échantillon de trait ou une image du livre. Le bouton **Symbole pour une étiquette** de la barre d’outils du panneau Texte en écrit un au curseur, avec sa couleur et sa taille ; les crochets contiennent ce qu’en lit un lecteur d’écran, et des crochets vides indiquent que les mots voisins suffisent.
3. Donnez son aspect à la légende. Dans **Maquette › Figures et tableaux › Styles d’étiquette**, appuyez sur **Ajouter un style d’étiquette**, donnez-lui l’identifiant `key`, la police Fredoka en 10,5 pt, un **Fond** blanc avec une **Marge intérieure du fond** de 2,5 mm, un **Contour** et un **Rayon des coins** de 1,5 mm, puis, sous **Lignes et légende**, activez **Légende**. Les symboles se rangent alors dans une colonne à part et les mots de chaque rangée commencent sur un même bord.
4. Placez les points. **Vérifications** liste *Étiquette sur une ancre inconnue* pour `spring` et `key`. Appuyez sur le bouton en forme d’épingle de l’une de ces entrées : la fenêtre Ancres de `rio` s’ouvre avec les deux noms sous *Étiquettes sans ancre*. Cliquez sur la cascade en haut à gauche de la peinture pour `spring`, et sur le coin inférieur gauche pour `key` ; réglez l’**Alignement** de la légende sur *Début* et son **Alignement vertical** sur *Bas*, pour qu’elle grandisse vers le haut et vers la droite depuis son point. Cliquez ensuite sur le barrage, le moulin et le port, et nommez les trois nouvelles ancres `dam`, `mill` et `harbour` dans leurs lignes.
5. Écartez le nom de la source de son point. Choisissez `spring` et, sous **Étiquette et ligne de rappel**, activez **Loin de son point**. Faites glisser la poignée de l’étiquette vers le haut, dans le ciel, et réglez **Ligne de rappel** sur *Oui* : la ligne qui va de l’étiquette à la cascade se dessine pendant que vous faites glisser. Appuyez sur **Enregistrer**.
6. Tracez les renvois. En mode **Maquette**, choisissez `note-1` sur la page : une poignée ronde apparaît près du milieu de son côté droit. Faites-la glisser sur le barrage ; les ancres de la carte s’affichent pendant le glissé, et le dépôt écrit un connecteur de la note vers l’ancre `dam`, avec un point à son extrémité. Faites de même de `note-2` vers `mill` et de `note-3` vers `harbour`. Le groupe **Renvois** du bloc les liste ; c’est par lui qu’on en ajoute ou qu’on en modifie un au clavier.

<Screenshot src="/docs-shots/fr/map-notes.webp" alt="La page Along the river en mode Maquette : la carte avec une légende dans son coin inférieur gauche, trois notes dessous, chacune reliée par une ligne à un endroit de la carte, et le groupe Renvois de la deuxième note dans le panneau Maquette." caption="Chaque note renvoie à une ancre de l’image ; la légende et les noms sont des lignes du Markdown." />

Un renvoi aboutit au point de l’ancre dans l’image, recadrage et échelle compris : il trouve donc encore le moulin quand la carte est réduite ou coupée à sa zone de sécurité. Il est peint par-dessus les blocs, et se voit donc sur l’image. Une note posée sur la carte elle-même, sans place à elle, est signalée par Vérifications comme *Bloc caché par un autre bloc*, avec les corrections (voir [Sandbox : les pages composées](/fr/docs/sandbox-composed-pages#chevauchements-et-onglets-à-glyphe)).

## 10. Une page de cartes avec photos

Une page de cartes (des photos avec une légende sous chacune, des portraits avec un nom) est une seule carte dessinée plusieurs fois. Une **grille qui répète un jeu de blocs** dessine la carte une fois, et la page a autant de cartes que son Markdown en écrit.

1. Faites un gabarit `photos` (**Nom** `Photo cards`) avec `title` (`portada`, *Niveau 1*) et `text` (le texte libre) empilés dans un groupe `column`, à 6 mm l’un de l’autre.
2. Ajoutez un bloc `photo` : **Style de bloc** `foto`, accroché à *Bloc text*, *En dessous*, 6 mm plus bas. Ajoutez un bloc `caption` : **Style de bloc** `dato`, **Largeur** *Son contenu*, accroché à *Bloc photo*, *En dessous*, 2 mm plus bas.
3. Ajoutez un groupe `cards` : **Grille**, **Colonnes** 3, **Espace entre les colonnes** 6 mm, **Espace entre les rangées** 12 mm. Sous **Répéter un ensemble de blocs**, **Bloc principal** `photo`, et cochez `caption` sous **Blocs qui l’accompagnent**. Le bloc principal prend la largeur d’une cellule ; la légende s’y accroche comme le gabarit la dessine.
4. Écrivez la page :

```md
::::page{template="photos"}
# People and the river

People use the river in many ways. Look at the photos and say what each person is doing.

:::frame{slot="photo"}
::resource{id="riego"}

:::frame{slot="caption"}
Watering the fields
:::
:::

:::frame{slot="photo"}
::resource{id="molino"}

:::frame{slot="caption"}
Grinding wheat
:::
:::

:::frame{slot="photo"}
::resource{id="piraguas"}

:::frame{slot="caption"}
Paddling a canoe
:::
:::

:::frame{slot="photo"}
::resource{id="limpieza"}

:::frame{slot="caption"}
Cleaning the banks
:::
:::
::::
```

Chaque `:::frame{slot="photo"}` est une carte, et le `:::frame{slot="caption"}` qu’il contient va dans la légende de cette carte. Les cartes remplissent les rangées depuis le côté où commence une ligne : la quatrième ouvre donc une deuxième rangée. En mode Maquette, les blocs sont nommés d’après leur carte : `photo[2]` et `caption[2]` forment la deuxième carte.

<Screenshot src="/docs-shots/fr/grid.webp" alt="La page People and the river avec quatre photos dans une grille de trois colonnes et une légende sous chacune, et le panneau Maquette qui montre le groupe cards avec Grille, trois colonnes et Répéter un ensemble de blocs." caption="La carte est dessinée une fois ; le Markdown en donne quatre, et la grille en pose quatre." />

Une cinquième photo prend la cellule suivante ; une septième ouvre une troisième rangée. Une édition dans une autre langue peut avoir plus ou moins de cartes avec le même gabarit. **Nombre maximal d’éléments** plafonne la grille (ce qui dépasse va dans le texte libre, et Vérifications signale *Plus d’éléments que la grille n’en contient*), et **Le contenu qui ne tient pas va vers** *Une page ajoutée après celle-ci*, réglé sur le bloc principal, envoie entières sur une page ajoutée les rangées qui ne tiennent pas.

## 11. Une bibliothèque de modules pour une collection

**Page et colonnes › Modules** est la bibliothèque de modules du livre. Chaque module y est dessiné avec ses blocs et nommé par son identifiant, avec le nombre de blocs du Markdown qui l’utilisent et le nombre de pages où ils se trouvent (*1 bloc sur 1 page* pour l’arbre), un crayon qui l’ouvre dans l’éditeur de gabarits, et le bouton qui l’insère dans la page choisie dans **Page où l’insérer**. **Nouveau module** en commence un autre. Renommer un module réécrit chaque bloc `:::module` qui le désigne.

<Screenshot src="/docs-shots/fr/modules.webp" alt="La section Modules du panneau Maquette : la liste Page où l’insérer, le module Tree of ideas avec la mention 1 bloc sur 1 page, et le bouton Nouveau module." caption="La bibliothèque : chaque module, l’endroit où le livre l’utilise, et le moyen de l’insérer dans une page." />

Une page reçoit des modules dans un groupe où **Reçoit les modules de la page** est activé, l’un sous l’autre dans l’ordre du Markdown. La page suivante peut donc contenir un arbre sous une boîte, ou deux arbres, sans nouveau gabarit : le Markdown dit quels blocs et dans quel ordre, les modules les dessinent.

Les modules peuvent aussi se placer côte à côte. Mettez **Blocs** du groupe de modules sur **En rang** ou **Grille**, ou ajoutez un second groupe avec **Reçoit les modules de la page** activé, choisissez le premier dans **Dans le groupe** et cochez ses **Modules qu’il reçoit** : chaque suite de ces modules dans le Markdown forme une rangée de la pile. La **Largeur dans son groupe** d’un module, réglée dans son éditeur, s’affiche sous son nom dans la bibliothèque.

Les livres d’une collection (*Our river* pour le CE2, *Our coast* pour le CM1) partagent leurs modules en partageant leur maquette :

- **Dans le Sandbox.** Commencez le livre suivant comme une copie de celui-ci (**Livres**, **⋯** sur le livre, **Dupliquer**) et écrivez ses chapitres ; les gabarits, les modules et les styles viennent avec la copie. Pour un livre qui existe déjà, **Exporter**, dans l’en-tête du panneau Maquette, enregistre la maquette, et **Importer**, dans l’autre livre, la met à la place de la maquette de ce livre.
- **Depuis le code.** Gardez les gabarits de module dans un seul fichier et ajoutez-les aux `pageTemplates` de chaque livre de la collection :

```ts
// series/modules.js: the tree and the other modules of the series
export const seriesModules = [
  { id: 'tree', name: 'Tree of ideas', role: 'module', frames: [/* root, branch */], groups: [/* branches */],
    decoration: { elements: [{ kind: 'connector', id: 'connector-1', routing: 'tree', from: { to: '#root' }, to: [{ to: '#branch[*]' }] }] } },
];

// our-coast/config.js
import { seriesModules } from '../series/modules.js';
export const config = { /* … */ pageTemplates: [...seriesModules, ...pagesOfThisBook] };
```

Une modification d’un module (une ligne plus épaisse, un autre style de bloc) atteint alors chaque page de chaque livre qui l’utilise à la prochaine mise en page du livre, et les mots restent dans le Markdown de chaque livre.

## Ce que dit le Markdown et ce que dessine la maquette

Les pages des sections 8 à 11 suivent une même règle. Le Markdown dit **ce qui** va sur la page et **combien** : les mots de chaque boîte, le nombre de branches, de notes, de cartes et de rangées de la légende, le module qui vient en premier. La maquette dessine chaque chose **une seule fois** : les boîtes, leur place, les lignes qui les relient, l’aspect de la légende, la taille d’une cellule. C’est pourquoi une traduction n’a pas besoin de son propre gabarit, pourquoi une page de cinq photos utilise le gabarit d’une page de quatre, et pourquoi une collection peut partager ses modules. Un gabarit ne contient jamais les mots d’une page, et le Markdown ne contient ni position ni couleur.
