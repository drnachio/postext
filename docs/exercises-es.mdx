# Ejercicios

**Las preguntas y sus respuestas están en el Markdown; la forma en que se imprimen es un estilo de ejercicio.**

Un ejercicio es un bloque del capítulo escrito entre `:::exercise` y `:::`. Dentro van el enunciado, las preguntas, las opciones, los huecos con sus respuestas y, si la hay, una solución desarrollada. Postext lee las respuestas en el texto, imprime el ejercicio para el alumno (líneas en blanco, casillas vacías, elementos desordenados), prepara la clave de respuestas y coloca las soluciones donde el libro las pide. El número, las letras de las opciones, el aspecto de un hueco y el pautado de un espacio para escribir salen de [`exerciseStyles`](/es/docs/configuration-exercises#estilos-de-ejercicio); dónde van las soluciones y qué edición se imprime salen de [`exercises`](/es/docs/configuration-exercises#ajustes-del-libro). Con un solo Markdown se obtienen así el libro del alumno, el libro del profesor y una edición interactiva para pantalla.

Un ejercicio se compone como un recuadro hecho de párrafos, chips y dibujos corrientes, de modo que se coloca, se parte entre columnas y páginas, se etiqueta en un PDF accesible y se pinta en todas las salidas igual que cualquier recuadro. Un libro sin ningún `:::exercise` se compone igual que antes.

## El contenedor

```md
:::exercise
Rodea la respuesta correcta.

- [ ] Madrid
- [x] Lisboa
- [ ] Roma
:::
```

Los párrafos con los que empieza el ejercicio, hasta su primera lista, su primer hueco o su banco de palabras, forman el **enunciado**. Se componen con la letra de enunciado del estilo (negrita por defecto), detrás del número del ejercicio. Lo que sigue es el cuerpo, lo que el ejercicio pregunta.

Dentro de un ejercicio caben otros dos contenedores. `:::solution` … `:::` guarda una solución desarrollada o una respuesta modelo en cualquier Markdown; nunca se imprime dentro del ejercicio y va adonde vayan las [soluciones](#soluciones). `:::hint` … `:::` guarda una pista que las ediciones en pantalla muestran cuando el lector la pide; en papel no se imprime.

## Tipos de ejercicio

El desorden tiene semilla: un ejercicio sale desordenado de la misma manera en el Canvas, el PDF, el visor HTML, el EPUB y la clave de respuestas. Cambiando `exercises.seed` se imprime otra versión de un examen.

### Opción múltiple y verdadero o falso

#### Opción múltiple

Una lista de tareas con las opciones correctas marcadas:

```md
:::exercise
¿Qué planeta está más cerca del Sol?

- [ ] Venus
- [x] Mercurio
- [ ] Marte
:::
```

Las opciones se imprimen una por línea, con las letras a), b), c), y las líneas que no caben quedan sangradas bajo el texto de la opción. Si un ejercicio tiene varias preguntas, se escribe una lista numerada cuyos elementos son las preguntas, cada una con su lista de tareas sangrada debajo; las preguntas se numeran 1., 2. y sus opciones se colocan debajo:

```md
:::exercise{columns=3}
Rodea la respuesta correcta.

1. Las raíces de una planta absorben
   - [x] agua
   - [ ] luz
   - [ ] semillas
2. Las hojas fabrican el alimento a partir de
   - [ ] la tierra
   - [ ] el viento
   - [x] la luz del sol
:::
```

Con `columns=3` las opciones van de tres en tres por fila. Las letras y lo que las sigue dependen del idioma del documento: a) en español, en inglés y en las demás lenguas románicas; A. en chino; ア イ ウ en japonés; أ) ب) ج) en árabe. Un estilo puede añadir delante de cada opción una casilla o un círculo para marcar (`options.marker`) o, como en los exámenes chinos y japoneses, un paréntesis （　） al final de la pregunta para escribir la letra (`options.bracket`).

#### Verdadero o falso

```md
:::exercise{type=truefalse}
Indica si es verdadero o falso.

- [x] El Sol es una estrella.
- [ ] La Luna es un planeta.
:::
```

Cada afirmación lleva un número y termina con las dos respuestas al final de la línea, cada una con su casilla: V □ F □. Un elemento marcado es verdadero. Las letras dependen del idioma: V/F en español, catalán, francés, italiano y portugués, T/F en inglés, R/F en alemán, √/× en chino, ○/× en japonés y صح/خطأ en árabe. Un estilo puede imprimir en su lugar un único hueco en el que escribir la respuesta (`trueFalse.look: 'bracket'`).

### Huecos y banco de palabras

`[[respuesta]]` es un hueco, que se imprime como una línea para escribir:

```md
:::exercise{bank}
Completa las frases con las palabras del recuadro.

1. Las raíces absorben el [[agua]] del suelo.
2. Las hojas fabrican el [[alimento]] de la planta.
3. El tallo [[sostiene | sujeta]] las hojas y las flores.

::bank[piedras | viento]
:::
```

- `[[vídeo | video]]`: un hueco con varias respuestas válidas. La clave imprime la primera.
- `[[voy | (va) | vamos]]`: una **elección en línea**. Las opciones se imprimen dentro de la línea, `(voy / va / vamos)`, y la que va entre paréntesis es la correcta: el lector la rodea.
- `[[fue]]{width=6}`: un hueco de seis em de ancho.
- `[[{春天|chūn tiān}]]`: un ruby dentro de un hueco imprime su lectura sobre el hueco, también en el libro del alumno, que escribe los caracteres bajo su pinyin (看拼音写词语) o su kana (漢字の書き取り).
- `\|` es una barra literal dentro de una respuesta, y `\[[` una pareja literal de corchetes.

Todos los huecos de un ejercicio miden lo que su respuesta más larga más 1,5 em, para que la longitud de la línea no delate la respuesta (`blank.width` lo cambia). `bank` imprime las respuestas desordenadas en un banco de palabras con marco, debajo del enunciado. Una línea `::bank[piedras | viento]` coloca el banco donde está escrita y le añade sus palabras como distractores; la línea sola ya pide el banco. `[[…]]` solo se interpreta dentro de un ejercicio: dos corchetes en cualquier otro lugar del libro quedan tal como están escritos.

Un ejercicio que empieza con su texto, sin enunciado, lleva el número al principio del primer párrafo:

```md
:::exercise
Una semana tiene siete [[días]] y un año tiene doce [[meses]].
:::
```

### Relacionar y clasificar

#### Relacionar

Parejas escritas con `->` (o `→`):

```md
:::exercise
Une cada animal con su casa.

- Abeja -> Colmena
- Pájaro -> Nido
- Araña -> Telaraña
- Conejo -> Madriguera
- -> Guarida
:::
```

La columna izquierda se imprime en el orden escrito y la derecha desordenada, con un punto junto a cada elemento para unirlos con una línea. `- -> Guarida` añade a la columna derecha un elemento que no corresponde a ninguno. Con `match.look: 'letters'` la columna derecha lleva letras, y cada elemento de la izquierda un hueco para escribir la letra. `shuffle=false` deja la columna derecha como está escrita.

#### Clasificar

```md
:::exercise{type=sort}
Clasifica estos alimentos según la parte de la planta de la que proceden.

- Raíz: zanahoria, rábano
- Hoja: lechuga, espinaca
- Fruto: tomate, manzana
:::
```

Todos los elementos van desordenados a un banco de palabras, y cada categoría recibe una columna (hasta cuatro) con su nombre y líneas pautadas debajo. Los elementos pueden separarse con comas, puntos y comas, `、`, `，` o `،`.

### Ordenación

#### Ordenar

```md
:::exercise{type=order}
Ordena las etapas de la vida de una planta.

1. La semilla germina.
2. Crece el tallo.
3. Se abren las flores.
4. Aparece el fruto.
:::
```

La lista se escribe en el orden correcto y se imprime desordenada, cada elemento con una casilla para su número.

#### Frases desordenadas

```md
:::exercise{type=scramble}
Ordena las palabras y escribe las frases.

- Las plantas / necesitan / agua
- El Sol / nos da / luz
:::
```

Cada frase se corta por sus barras (por sus espacios si no tiene ninguna), sus trozos se imprimen desordenados y separados por barras, y debajo queda una línea para escribir la frase.

### Marcar palabras

```md
:::exercise{type=mark}
Rodea los verbos: La niña [[riega]] las plantas y el Sol las [[calienta]].
:::
```

El texto se imprime tal cual; las palabras entre `[[…]]` son las que hay que marcar. En las respuestas aparecen rodeadas, o enmarcadas, subrayadas o resaltadas con `mark=box|underline|highlight` en el contenedor, o palabra a palabra con `[[riega]]{mark=underline}`. En pantalla se puede marcar cualquier palabra del texto, y una palabra marcada por error cuenta como respuesta incorrecta.

### Preguntas abiertas y espacio para escribir

```md
:::exercise{type=open lines=4}
¿Por qué necesitan luz las plantas?

:::solution
Porque la usan para fabricar su alimento.
:::
:::
```

Después del enunciado vienen líneas pautadas para escribir: tres por defecto, cuatro aquí con `lines=4`. Si el cuerpo es una lista, cada elemento tiene sus propias líneas. `area` cambia el pautado: `lines` (renglones), `dots` (puntos), `grid` (cuadrícula), `seyes` (la pauta escolar francesa), `tianzige` (田字格, los cuadros en los que los alumnos chinos escriben los caracteres), `box` (un marco vacío, para un dibujo) o `none`. El `:::solution` es la respuesta modelo: se imprime con las soluciones y, en la edición del profesor, aparece escrita sobre las líneas. En pantalla, `area=none` en el contenedor no deja dónde escribir: sirve para un ejercicio que se hace en voz alta o con un compañero. Un estilo con `area.kind` en `none` solo dibuja la zona sin pautar.

`cells` da a los cuadros (`grid` o `tianzige`, cuadrícula cuando el estilo raya líneas) ese número de casillas: `cells=4`. Varios números ponen grupos uno al lado de otro, a un cuadro de distancia, uno por palabra, que pasan a la línea siguiente al llegar al final: `cells="2 2 3"`. La edición del profesor escribe la respuesta modelo un carácter por cuadro, grupo tras grupo.

### Sopas de letras y crucigramas

#### Sopa de letras

```md
:::exercise{type=wordsearch size=10 directions="across down diagonal backwards"}
Busca estas palabras en la sopa de letras.

- TALLO
- HOJA
- FLOR
- SEMILLA
:::
```

Las palabras se colocan en una cuadrícula de letras y la lista se imprime debajo (`hidden` la omite). La cuadrícula crece hasta que cabe la palabra más larga; `size` fija su lado. `directions` admite `across` (horizontal), `down` (vertical), `diagonal` y `backwards` (del revés); por defecto, horizontal, vertical y diagonal. Las letras van en mayúsculas salvo que el estilo diga otra cosa. Si una palabra no se puede colocar, se avisa.

#### Crucigrama

```md
:::exercise{type=crossword}
Resuelve el crucigrama.

- RAIZ: La parte que está bajo tierra
- HOJA: La parte verde que fabrica el alimento
- FLOR: Atrae a las abejas
- TALLO: Sostiene la planta
:::
```

Cada entrada es una palabra y su definición. El motor construye la cuadrícula, numera la primera casilla de cada palabra e imprime debajo las definiciones en dos listas con los rótulos del idioma del documento (Horizontales y Verticales en español, Across y Down en inglés, ヨコのカギ y タテのカギ en japonés).

### Operaciones en vertical

```md
:::exercise{type=arithmetic}
Calcula.

- 345 + 278
- 902 − 456
- 124 × 3
- 864 : 4
:::
```

Cada operación se compone en casillas, como la escribe un alumno: las cifras en columnas, el signo a la izquierda, una raya y casillas vacías para el resultado, con hasta cuatro operaciones por fila. En una página de derecha a izquierda cada operación conserva sus cifras de izquierda a derecha, y las operaciones se suceden de derecha a izquierda. Se leen los signos `+`, `-`, `−`, `×`, `x`, `*`, `·`, `⋅`, `÷`, `:` y `/`, con números enteros o decimales (`12,5 + 3,75`): en una suma o una resta las comas quedan una debajo de otra, y una división entre un decimal no se lee. La división sigue la costumbre escolar del idioma del documento, y `arithmetic.division` elige otra:

- `potence`: el dividendo a la izquierda y el divisor a la derecha dentro de la «casita» en forma de L, el cociente debajo del divisor y el resto abajo, bajo las restas. Es la división de los libros en español, catalán, francés, italiano y portugués.
- `bracket`: el divisor a la izquierda, el dividendo bajo un corchete y el cociente encima. Libros en inglés, chino, japonés y árabe.
- `inline`: `864 : 4 =` y las casillas del cociente en la misma línea, con los pasos debajo. Libros en alemán.

Una multiplicación por un número de dos o más cifras imprime una fila por cada producto parcial, cada una un lugar más a la izquierda, y el resultado bajo una segunda raya (`arithmetic.partialProducts: false` deja solo el resultado). Bajo una división el estilo deja filas para los cálculos: el producto de cada paso y lo que queda, o solo lo que queda cuando la resta se hace de cabeza, como se escribe en los libros españoles, catalanes e italianos (`arithmetic.working`).

### Un primer elemento resuelto

`example` imprime resuelto el primer elemento, en el color de las respuestas: el primer hueco escrito, la opción correcta de la primera pregunta rodeada, la primera pareja unida, la primera frase copiada. En pantalla ese elemento no se pregunta, y su respuesta no entra en el banco de palabras.

## Numeración, referencias y dificultad

Los ejercicios se numeran 1, 2, 3 en cada capítulo. El resto lo decide el estilo: un número suelto, en negrita y seguido de punto (por defecto), o dentro de un círculo, un cuadrado o un cuadrado redondeado (`number.shape`); una palabra delante («Ejercicio 3» con `number.label: true`, en el idioma del documento); el sistema de numeración (`number.format`, por ejemplo los números chinos 一、二、); una plantilla que añade el capítulo (`'{h1}.{n}'`), y dónde vuelve a empezar la cuenta (`number.resetOn`: en cada capítulo, en cada sección o nunca). Los estilos que nombran el mismo `number.counter` comparten la cuenta, y un libro la lleva de un capítulo al siguiente.

`n=12` en un contenedor da a ese ejercicio el número 12, y los siguientes continúan desde el 13. `#id` convierte el ejercicio en destino de `:ref`, que imprime su nombre, «Ejercicio 3» (la palabra de `number.label` si el estilo la fija; si no, la del idioma del documento). `style=number` imprime 3, `style=title` el `title` del contenedor (o el nombre si no lo tiene) y `style=page` su página. La referencia alcanza también los ejercicios de otros capítulos del libro. `level` e `icon` se imprimen detrás del número: las marcas de dificultad y los iconos de actividad que define el estilo.

## Soluciones

### La clave de respuestas

Todo ejercicio que se puede corregir tiene una clave hecha con sus respuestas: la opción correcta (`b) Mercurio`), los huecos en orden (`1 agua · 2 alimento · 3 sostiene`), V o F en cada afirmación, las parejas, el orden, las frases, las palabras del crucigrama con sus números y los resultados de las operaciones. Con la disposición `full` (la predeterminada), detrás de la clave va el `:::solution` del ejercicio. Un ejercicio de respuesta abierta no tiene clave: su respuesta modelo es la solución.

### Dónde se imprimen las soluciones

Lo decide `exercises.solutions.placement` para todo el libro; un estilo puede cambiarlo para sus propios ejercicios.

<table>
  <thead>
    <tr>
      <th>Colocación</th>
      <th>Qué se imprime</th>
    </tr>
  </thead>
  <tbody>
    <tr><td><code>none</code></td><td>Ninguna solución en papel (por defecto). Las ediciones en pantalla sí las tienen.</td></tr>
    <tr><td><code>after</code></td><td>La solución justo detrás de su ejercicio, en un cuerpo menor.</td></tr>
    <tr><td><code>inverted</code></td><td>El mismo recuadro girado cabeza abajo, como lo imprimen los libros de pasatiempos y las revistas infantiles.</td></tr>
    <tr><td><code>chapterEnd</code></td><td>Todas las soluciones del capítulo al final de este, bajo un título en el idioma del documento (Soluciones, Solutions, Lösungen, 参考答案…), cada una detrás del número de su ejercicio.</td></tr>
    <tr><td><code>directive</code></td><td>Solo donde el capítulo escribe <code>:::solutions</code>.</td></tr>

Con `directive`, una línea `:::solutions` imprime las soluciones de los ejercicios anteriores que aún no se han impreso; `title="…"` cambia su título. `:::solutions{scope="book"}`, en un capítulo propio al final, imprime la clave y las soluciones de todos los ejercicios del libro, capítulo a capítulo:

```md
# Solucionario

:::solutions{scope="book"}
```

### Edición del profesor

```json
{ "exercises": { "edition": "teacher" } }
```

imprime cada respuesta en su sitio, en el color de las respuestas (un rojo magenta salvo que el estilo fije `answers.color`): los huecos escritos, las opciones correctas rodeadas o con la casilla rellena, la casilla de V o F rellena, las líneas de relacionar trazadas, los números en las casillas de ordenar, las frases y las palabras clasificadas sobre sus líneas, la respuesta modelo de una pregunta abierta sobre sus renglones, y las palabras del crucigrama y los resultados de las operaciones en sus casillas.

## Avisos

El panel **Revisión** del Sandbox y `collectContentWarnings` avisan de lo que el motor no sabe leer:

- `exerciseUnknownType`: un `type` que no es ninguno de los doce.
- `exerciseUnknownStyle`: un `style` que no nombra ningún estilo de ejercicio (se usa el primero).
- `exerciseNoAnswer`: un ejercicio que se puede corregir pero no tiene nada que corregir: una pregunta sin ninguna opción marcada, huecos sin `[[…]]`, un ejercicio de relacionar sin parejas.
- `exerciseUnreadItem`: un elemento de la lista que su tipo no sabe leer, como una pareja sin `->` o una operación que no está formada por dos números enteros y un signo.
- `exerciseWordUnplaced`: una palabra que no cabe en la sopa de letras o en el crucigrama.
- `exerciseNested`: un ejercicio dentro de otro.
- `solutionOutside`: un `:::solution` o un `:::hint` fuera de un ejercicio. No imprime nada.

## Ejercicios en HTML y EPUB

En el visor HTML y en los libros EPUB los ejercicios se pueden responder. El lector escribe en los huecos y pulsa opciones, afirmaciones, puntos que unir y casillas de una cuadrícula; después comprueba las respuestas, ve la solución o vuelve a empezar. Las respuestas correctas y las incorrectas se señalan con un color y una marca (`digital.correctColor`, `digital.wrongColor`) y se anuncian a los lectores de pantalla. Las respuestas se guardan en el navegador, por libro, y el lector las encuentra en su siguiente visita (`exercises.digital.persist`). Con `exercises.digital.check: 'instant'` cada respuesta se corrige en cuanto se da; con `exercises.digital.interactive: false` las páginas quedan como en papel. La clave de respuestas siempre va dentro del EPUB, sea cual sea la colocación en papel, para que un sistema de lectura que no ejecuta scripts tenga también las respuestas. En un EPUB de maquetación fluida las cuadrículas y las zonas de escritura crecen con el texto del lector, y en una página de derecha a izquierda las casillas que se responden siguen la cuadrícula reflejada. Las parejas se unen pulsando un punto y luego el otro, o arrastrando de uno a otro, y las palabras de un ejercicio de clasificar se arrastran a su columna o se eligen en un menú. La barra lleva solo los botones que hacen algo: no aparece «Comprobar» si no hay nada que comprobar, ni «Ver la solución» si no hay solución, ni barra alguna cuando no hay nada que responder.

Para un examen, el libro o un estilo de ejercicio pueden limitar un intento: cuántas veces se comprueba (`digital.maxChecks`), si se puede volver a empezar y cuántas veces (`digital.reset`, `digital.maxResets`) y cuándo aparece la solución (`digital.showSolution`). Los botones dicen cuántas comprobaciones y cuántos reinicios quedan. Véase [Evaluación](/es/docs/configuration-exercises#evaluación).

La pantalla puede dar a los ejercicios una forma propia mediante `htmlViewer.overrides`, que se combina con la configuración del libro antes de que el visor HTML maquete. El papel conserva la suya:

```ts
const config: PostextConfig = {
  exercises: { solutions: { placement: 'chapterEnd' } },
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [
        { id: 'exercise', blank: { minWidth: { value: 6, unit: 'em' } }, area: { kind: 'none' } },
      ],
    },
  },
};
```

## Ejercicios en un paquete SCORM

Un paquete SCORM (la pestaña **SCORM** del Sandbox, o `postext-scorm` desde código) lleva los ejercicios igual que el visor HTML y envía sus resultados al sistema de gestión del aprendizaje en el que se ejecuta. Cada parte del libro que sigue el LMS informa de una puntuación (las respuestas calificadas correctas sobre el total, según la última comprobación de cada ejercicio), de si está completada (todas las páginas vistas y todos los ejercicios comprobados) y, con `exercises.digital.passingScore`, de si está aprobada. Cada comprobación se escribe también como una interacción, con la respuesta del lector y la correcta. Las respuestas y las comprobaciones gastadas se guardan en el LMS, así que los límites de un intento se mantienen de una visita a otra y de un dispositivo a otro. Véase [Paquetes SCORM](/es/docs/configuration-html-folio-epub#paquetes-scorm-postext-scorm).

## Estilos de ejercicio

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots' },
    },
  ],
};
```

Todos los campos de un estilo, con su tipo y su valor por defecto, están en [Configuración › Ejercicios](/es/docs/configuration-exercises). Un estilo toma su marco de un [estilo de recuadro](/es/docs/configuration-callouts) (`box`), así que un ejercicio puede ir en un recuadro con fondo de color y franja como cualquier otro recuadro del libro. La [skill postext-port](/es/docs/skill) sigue estos mismos pasos cuando adapta los ejercicios de un libro de texto o de un cuaderno.
