# 設定：練習問題


## 練習問題スタイル

`exerciseStyles`プロパティは、練習問題が`:::exercise{style="…"}`で選ぶ名前付きスタイルを宣言します。スタイルは練習問題のまとまりの形を決めるもので、問いと答えはMarkdownに残ります（[練習問題](/ja/docs/exercises)を参照）。既定では`exercise`というスタイルが1つ用意されているので、何も設定しなくてもブロックは使えます。`exerciseStyles`を宣言するとこのスタイルは置き換えられ、`style`を指定しない練習問題には最初に宣言したスタイルが適用されます。項目はすべて省略でき、選択肢の記号、正誤の記号、わり算の筆算の書き方、印刷する語など、学校の慣習が国によって違うところは文書の言語に合わせた既定値になります。

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Noto Sans JP' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### 番号

`number`は練習問題の番号を設定します。形のない番号はメインカラーの太字で、後にピリオドが付きます。形のある番号は、メインカラーの円、四角、角丸の四角の中に白抜きで置かれ、後には何も付きません。

### 評価

既定では、練習問題は練習です。読者は何度でも答え合わせをし、やり直し、解答を見られます。4つの設定で練習問題をテストにできます。本全体については`exercises.digital`で、スタイルについてはそのスタイルの`digital`で設定し、スタイルの練習問題にはスタイルの設定が優先します。

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`**：1回の解答で「答え合わせ」を押した回数を数えます。ボタンには残りの回数が出ます（「答え合わせ（残り2回）」）。使い切るとボタンは「答え合わせは終わりです」になり、答えは固定され、得点がバーに残ります。
- <strong>`reset`</strong>と<strong>`maxResets`</strong>：「やり直す」は答えを消して新しい解答を始め、答え合わせの回数も元に戻ります。`maxResets: 1`なら最初からやり直せるのは1回で、解答は全部で2回になり、ボタンには残りの回数が出ます。`reset: false`にするとボタンがなくなります。
- **`showSolution`**：`'always'`（いつも）、`'afterCheck'`（その回の解答の答え合わせをしたあと）、`'noChecksLeft'`（答え合わせを使い切ったか、答えがすべて正解だったあと）、`'never'`（出さない）。答え合わせの回数が制限されているときは、解答を見るとその回の解答は終わります。
- **`passingScore`**：SCORMパッケージが合格か不合格かを判定する基準です（[SCORMパッケージ](/ja/docs/configuration-html-folio-epub#scormパッケージpostext-scorm)を参照）。

ボタンの文言は文書の言語に従います。`check: 'instant'`では「答え合わせ」ボタンがないので`maxChecks`は働きませんが、ほかの設定は有効です。使った答え合わせとやり直しの回数は、答えと一緒に保存されます。LMSでは、SCORMパッケージがそれをLMSに保存するので、どの端末でも同じ制限が続きます。HTMLページやEPUBの本では読者のブラウザーに保存され、ストレージを消した読者は最初からになります。
