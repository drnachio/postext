# Sandbox：印刷用カバー

> **予備的な版です。** カバーパネルは、Postext で印刷用カバーを管理・作成する最初の試みです。実際の本で最初から最後まで使えますが、作業はまだ多く残っており、形が変わることもあります。

印刷所はカバーを独立した展開図として必要とします。表4・背・表1を並べ、製本によってはそで、ジャケット、くるみのある上製表紙、見返しが加わります。**カバー**パネル（アクティビティバーの `BookCopy` アイコン）は、Postext がすでに知っている本の判型・ページ・用紙からこれらの展開図を作ります。パネルを開いている間、ビューポートには本のページの代わりにパネルで選んだ展開図が表示されます。

## 版

本には複数の版を持たせることができ、それぞれに製本とISBNがあります。**並製を追加**と**上製を追加**で版を作ります。版には名前、**ISBN**（5桁の付加コードがあれば添えて）、シリーズの一冊なら**全巻のISBN**、**製本**（無線綴じまたは糸綴じの並製、角背または丸背の上製）、並製の**そで**、背の文字の向き、そして**印刷所の設定**に印刷所が示す寸法（裁ち落とし、そでの幅、板紙、チリ、溝、くるみ、安全余白）があります。最初の版は、本自体の情報（書名、副題、著者、ISBN）から始まります。

## 背幅と用紙

**背**の幅は、本全体を組んだページ数と用紙の厚さから計算し、折丁単位に丸めて製本の余裕を加えます。**本文用紙**は本のデザインの用紙（Folio の用紙）か、ライブラリの用紙プロファイルです。**差し込みを追加**では、アート紙の口絵のように別の用紙のページを指定します。文字を入れるには細すぎる背は空白のままになり、印刷所のプロファイルでその本を作れない場合はパネルが知らせます。

**プロファイルライブラリ**には、印刷所の用紙と製本のプロファイルを保存します。ファイルに書き出して読み込めば共有できます。

## 文章とデザイン

**カバーの文章**はすべての版に共通で一度だけ書きます。書名、副題、著者、表4の文章、背、そでを Markdown で書きます。各ゾーンの文章は、まず安全領域に重なるボックスとして置かれます。デザイナーで文章ごとに配置して組めます。

**デザイン**はすべての版で同じです。展開図全体の地色、各ゾーンの地色、背景画像（展開図全体か表1だけ）、文字の色があります。端まで届く地色と画像は裁ち落としまで伸びます。

## ライブラリ

- **カバーのギャラリー**には、本の図版とは別に、カバー専用の画像を集めます。PNG、JPEG、SVG、TIFF、PDF または PDF 付きの AI（各ページが背景なしの独立した画像になります）。画像はトレースして輪郭を保存できます。
- **ロゴライブラリ**には、出版社・シリーズのロゴとシールを、それぞれのアイソレーションとともに保存します。
- **シリーズ**には、見返し用の広告カタログをシリーズごとに保存します。上製の**見返し**セクションでは、ページごとに用紙の色と、何も入れない・広告・文章のどれかを選び、溝に隠れる部分を知らせます。
- **カバーのテンプレート**は、カバーのデザインを部分ごと（背景、要素、文章、効果、ロゴ、加工）に保存し、別の本に部分ごとに適用します。ファイルに書き出して読み込めます。

## カバーデザイナー

**カバーデザイナーを開く**（パネル内、またはビューポートの展開図の横）と、Sandbox 全体の上に専用のキャンバスでカバーが表示されます。**プレビュー**は印刷される姿を、ガイド（折りと筋、安全領域、裁ち落としの端）とチェックとともに示します。**編集**では固定のレイヤーで作業します。下から順に**背景**、**移動できる要素**、**編集できるテキスト**、**効果**、**ロゴ**、**特殊加工**です。各レイヤーは作業中に隠せます。

- **要素と効果**は、ギャラリーの画像、色の矩形、ノードを編集できる基本図形で、角丸、罫線、グラデーション、影を付けられます。画像はトレースした輪郭で切り抜いたり、**マスク**（ギャラリーのグレーの画像。白は見せ、黒は隠す）でぼかしたりできます。
- **テキスト**はボックスです。**テキストを追加**で共通テキスト（`{{タイトル}}`、`{{著者}}`…）か独自の文章を置きます。各ボックスはタイトル・サブタイトル・見出し・本文ごとの書体を持ち、背に沿って読めるよう回転できます。
- **ロゴ**はアイソレーションを保ち、**特殊加工**（ニス、ラミネート、箔押し、エンボス）は別の特色版として印刷されます。
- 要素はドラッグで移動、ハンドルでサイズ変更します。Alt でコピーをドラッグ、Cmd（Ctrl）でゾーンに揃え、Shift で縦横比を保ちます。Cmd+C・X・V・D でコピー・カット・ペースト・複製、デザイナーには本とは別の**元に戻す**（Cmd+Z）があります。
- ゾーンに置いた要素は、判型や背幅が変わるとゾーンとともに移動・拡縮します。

## 展開図、チェック、ファイル

**展開図**の選択で、パネルとビューポートに表示するものを選びます。カバー（または上製表紙）、ジャケット、前後の見返し、画面向けの表1（EPUB の表紙と SNS の各サイズ）です。各展開図は裁ち落としを含む寸法と、入稿前のチェック一覧（展開図からはみ出す要素や折りにかかる要素、見つからない画像、収まらない文章）を示します。

- **PDFを書き出す**は、本の印刷設定で展開図を書き出します。裁ち落としとトンボ、各折りの上下の目印、加工はオーバープリントする特色版になります。
- 画面向けの形式は JPEG で書き出します。
- 本の EPUB は表1を表紙に使い、Folio の3D の本はその版のとおりに製本されます（上製または並製、背は展開図から描かれます）。
- 制作情報は本とともにブラウザーに保存され、ギャラリーの画像や使用するロゴ・プロファイルとともに `.postext` パッケージで持ち運べます。
