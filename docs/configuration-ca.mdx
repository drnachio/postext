# Configuració

**Cada decisió de composició a Postext la controla un únic objecte de configuració.**

`PostextConfig` controla les dimensions de pàgina, la disposició de columnes, la tipografia del text de cos, els estils d'encapçalament, la llengua del document (`locale`) i més. Totes les propietats són opcionals — Postext inclou valors per defecte assenyats, inspirats en la tipografia tradicional de llibres. Només cal que especifiquis el que vulguis canviar.

```ts
import { buildDocument } from 'postext';

const document = buildDocument(content, {
  page: { sizePreset: '21x28', dpi: 300 },
  layout: { layoutType: 'double', gutterWidth: { value: 0.5, unit: 'cm' } },
  bodyText: { fontFamily: 'EB Garamond', fontSize: { value: 9, unit: 'pt' } }, // 9 pt sobreescriu el valor per defecte de 8 pt
  headings: { fontFamily: 'Open Sans' },
});
```

Per a una visió general de com el motor processa aquesta configuració, consulta la pàgina d'[Arquitectura](/ca/docs/architecture).


## Índex

La referència està repartida en nou pàgines. Cada grup d'aquesta llista és una pàgina, seguida de les seccions que conté.

**[Pàgina i disposició](/ca/docs/configuration-page-layout)**

- [Pàgina](/ca/docs/configuration-page-layout#pàgina) — mida, marges, retícula de base, marques de tall, [enquadernació](/ca/docs/configuration-page-layout#enquadernació).
- [Disposició](/ca/docs/configuration-page-layout#disposició) — nombre de columnes, espai entre columnes, filets, [escriptura vertical](/ca/docs/configuration-page-layout#escriptura-vertical).
- [Capçaleres i peus](/ca/docs/configuration-page-layout#capçaleres-i-peus) — elements de text i de línia per pàgina amb marcadors, paritat i alineació.

**[Text i encapçalaments](/ca/docs/configuration-text)**

- [Text de cos](/ca/docs/configuration-text#text-de-cos) — tipografia, partició de mots, tabulacions, vídues i òrfenes.
- [Llengua del document](/ca/docs/configuration-text#llengua-del-document) — el `locale` de primer nivell: alternativa per a la partició de mots, tipus de recurs integrats i cadenes de continuació de taules i d'avisos partits, llengua etiquetada en un PDF accessible; les [xifres](/ca/docs/configuration-text#xifres-del-document) (`numerals`) i la [direcció del text](/ca/docs/configuration-text#direcció-del-text) (`direction`) que se'n desprenen; i les [llengües i escriptures](/ca/docs/configuration-text#llengües-i-escriptures) que Postext compon. La guia dels llibres de dreta a esquerra és [Composició àrab](/ca/docs/arabic-layout).
- [Encapçalaments](/ca/docs/configuration-text#encapçalaments) — valors generals i sobreescriptures H1–H6.
- [Llistes no ordenades](/ca/docs/configuration-text#llistes-no-ordenades) i [Llistes ordenades](/ca/docs/configuration-text#llistes-ordenades) — vinyetes, numeració, imbricació.
- [Matemàtiques](/ca/docs/configuration-text#matemàtiques) — renderització LaTeX, escala, color, marges.

**[Notes i referències](/ca/docs/configuration-notes-references)**

- [Notes a peu de pàgina](/ca/docs/configuration-notes-references#notes-a-peu-de-pàgina) — `footnotes`: on van les notes citades amb `[^id]`, com es numeren i quin aspecte tenen.
- [Numeració de línies](/ca/docs/configuration-notes-references#numeració-de-línies) — `lineNumbers`: el número de cada cinquena línia dels versos, o del text, al marge; què es compta, on torna a començar el compte, a quin costat van els números.
- [Referències creuades](/ca/docs/configuration-notes-references#referències-creuades) — `crossRefs`: les paraules que s'imprimeixen al costat del número o la pàgina d'un `:ref`, i el seu estil per defecte.
- [Cites](/ca/docs/configuration-notes-references#cites) — `citations`: l'estil de citació i l'aspecte de les cites i de la bibliografia.
- [Sumari](/ca/docs/configuration-notes-references#índex-de-continguts) — el que imprimeix `:::toc`: tipografia de les entrades, línies de punts, números de pàgina, línies d'autors, files de part.
- [Índex analític](/ca/docs/configuration-notes-references#índex-analític) — el que imprimeix `:::index`: tipografia de les entrades, sagnats, separadors i intervals de pàgines, grups per inicial, llengua d'ordenació.

**[Tipografia de l'Àsia oriental](/ca/docs/configuration-east-asian)**

- [Tipografia de l'Àsia oriental](/ca/docs/configuration-east-asian#tipografia-de-làsia-oriental) — `cjk`: les convencions regionals i el tall de línia del text en xinès, japonès i coreà, com s'eixamplen les seves línies justificades, les amplades de la puntuació i la puntuació penjada, l'espai entre xinès i llatí, la retícula de caràcters, els números que van drets en text vertical, i les marques, el ruby, les notes warichu i les marques de kanbun. Les guies de tot plegat són [Composició xinesa](/ca/docs/chinese-layout) i [Composició japonesa](/ca/docs/japanese-layout).

**[Recursos i taules](/ca/docs/configuration-resources)**

- [Tipus de recurs](/ca/docs/configuration-resources#tipus-de-recurs) — numeració tipada per a figures, taules i tipus personalitzats.
- [Estil de taules](/ca/docs/configuration-resources#estil-de-taules) (amb [estils de taula amb nom](/ca/docs/configuration-resources#estils-de-taula-amb-nom)) i [Estil de peus de recurs](/ca/docs/configuration-resources#estil-dels-peus-de-recurs) — tipografia i decoració de les taules-recurs i els seus peus.
- [Estil de diagrames](/ca/docs/configuration-resources#estil-dels-diagrames) — recoloració a una sola tinta dels diagrames SVG incrustats per a impressió amb tinta plana.
- [Estil de vídeo](/ca/docs/configuration-resources#estil-de-vídeo) — `videoStyle`: la marca de reproducció i el codi QR sobre el pòster d'un vídeo, i el que ofereixen els seus reproductors al visor HTML i en EPUB.

**[Estils i parts](/ca/docs/configuration-styles)**

- [Estils de paràgraf](/ca/docs/configuration-styles#estils-de-paràgraf) — estils amb nom per a contenidors `:::paragraphs`: bibliografies, glossaris, notes.
- [Estils de xip](/ca/docs/configuration-styles#estils-de-xip) — `chipStyles`: estils amb nom per al `:chip[…]` en línia: la caixa d'un banc de paraules, una tecla, una etiqueta.
- [Llistats de codi](/ca/docs/configuration-styles#llistats-de-codi) — `codeStyle`: la lletra, la caixa, l'amplada del tabulador, les línies llargues, els números de línia i els colors dels elements dels llistats ```` ``` ````, l'acoloriment de sintaxi i el seu punt d'enganxament per a ressaltadors, i el codi en línia en una lletra de codi.
- [Estils d'avís](/ca/docs/configuration-styles#estils-davís) — notes, consells i objectius en caixa per a contenidors `:::callout`.
- [Parts](/ca/docs/configuration-styles#parts) — pàgines separadores de part per a contenidors `:::part`: paritat, àrea de cos, disseny d'obertura, tipografia del cos.
- [Estils d'encapçalament](/ca/docs/configuration-styles#estils-dencapçalament) — estils amb nom per a encapçalaments `{style="…"}`: capítols sense numerar, preliminars amb capçaleres pròpies, geometria i paleta.

**[Paràmetres de còmics](/ca/docs/configuration-comics)**

- [Còmics](/ca/docs/configuration-comics#còmics) — `comics`: el marc i els carrers de les pàgines de còmic, els estils de vinyeta, la retolació, els estils de bafarada i el repartiment. La guia és [Còmics](/ca/docs/comics).

**[Fonts, colors i sortida](/ca/docs/configuration-fonts-colors-viewers)**

- [Unitats i colors](/ca/docs/configuration-fonts-colors-viewers#unitats-i-colors) + [Paleta de colors](/ca/docs/configuration-fonts-colors-viewers#paleta-de-colors) — `Dimension`, `ColorValue`, colors amb nom.
- [Fonts personalitzades](/ca/docs/configuration-fonts-colors-viewers#fonts-personalitzades) — declarar famílies tipogràfiques pujades per l'usuari al costat de Google Fonts.
- [Visor HTML](/ca/docs/configuration-fonts-colors-viewers#visor-html) — amplada objectiu de columna i talls per al backend HTML.
- [Generació de PDF (configuració)](/ca/docs/configuration-fonts-colors-viewers#generació-de-pdf-configuració) — outlines, sortida accessible (etiquetada) i espai de color forçat per al backend PDF.
- [Producció per a impremta (configuració)](/ca/docs/configuration-fonts-colors-viewers#producció-per-a-impremta-configuració) — `print`: PDF/X-1a i PDF/X-4, els perfils de sortida ICC, el negre (grisos només en K, sobreimpressió, negre enriquit), els colors definits en CMYK, el preflight i la simulació de la impressió.
- [Visor Folio (configuració)](/ca/docs/configuration-fonts-colors-viewers#visor-folio-configuració) — paper, enquadernació, superfície i llum del visor del llibre en 3D.
- [Depuració](/ca/docs/configuration-fonts-colors-viewers#depuració) — superposicions visuals i avisos d'autoria per a l'editor.

**[Ús programàtic](/ca/docs/configuration-programmatic-usage)**

- [Ús programàtic](/ca/docs/configuration-programmatic-usage#ús-programàtic) — `buildDocument`, els avisos que registra, resolvers, memòries cau.
- [Executar la composició en un Web Worker](/ca/docs/configuration-programmatic-usage#executar-la-composició-en-un-web-worker) — builds fora del fil principal amb cancel·lació.
- [Integrar el visor HTML](/ca/docs/configuration-programmatic-usage#integrar-el-visor-html) i [Generació de PDF](/ca/docs/configuration-programmatic-usage#generació-de-pdf) — receptes completes.
- [Un llibre en 3D (`postext-folio`)](/ca/docs/configuration-programmatic-usage#un-llibre-en-3d-postext-folio) — el document compost com un llibre imprès obert sobre una taula, amb fulls que el lector passa.
- [Llibres EPUB](/ca/docs/configuration-programmatic-usage#llibres-epub-postext-epub) — fitxers EPUB 3 de maquetació fixa i fluida a partir de la mateixa maquetació, i com comprovar-los amb EPUBCheck.
- [Paquets (fitxers `.postext`)](/ca/docs/configuration-programmatic-usage#paquets-fitxers-postext) — un llibre sencer en un sol fitxer: crear, obrir i construir fitxers `.postext` des del codi.
