# Konfiguration: Übungen


## Übungsstile

Die Eigenschaft `exerciseStyles` legt die benannten Stile fest, die eine Übung mit `:::exercise{style="…"}` auswählt. Ein Stil ist die Form einer Familie von Übungen; Fragen und Lösungen bleiben im Markdown (siehe [Übungen](/de/docs/exercises)). Ein Stil, `exercise`, ist standardmäßig dabei, sodass der Block ohne jede Konfiguration funktioniert; wer `exerciseStyles` angibt, ersetzt ihn, und der erste angegebene Stil gilt für jede Übung ohne `style`. Alle Felder sind optional, und wo sich die Schulen unterscheiden, folgen die Standardwerte der Dokumentsprache: Kennbuchstaben der Antworten, Buchstaben für richtig und falsch, die Form der schriftlichen Division, die gedruckten Wörter.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### Nummer

### Bewertung

Standardmäßig dient eine Übung zum Üben: Man prüft so oft man will, beginnt neu und sieht sich die Lösung an. Vier Einstellungen machen daraus einen Test, für das Buch in `exercises.digital` und für einen Stil in seinem `digital`, das für die Übungen dieses Stils Vorrang hat:

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** zählt, wie oft in einem Versuch Prüfen gedrückt wird. Die Schaltfläche zeigt, wie viele Prüfungen bleiben („Prüfen (noch 2)“); sind sie aufgebraucht, steht dort „Keine Prüfung mehr“, die Antworten werden gesperrt und die Punktzahl bleibt auf der Leiste stehen.
- **`reset`** und **`maxResets`**: Neu beginnen löscht die Antworten und beginnt einen neuen Versuch, der wieder alle Prüfungen hat. `maxResets: 1` erlaubt einen Neuanfang, also zwei Versuche insgesamt, und die Schaltfläche zeigt, wie viele bleiben; `reset: false` entfernt die Schaltfläche.
- **`showSolution`**: `'always'`; `'afterCheck'`, sobald der Versuch geprüft wurde; `'noChecksLeft'`, sobald seine Prüfungen aufgebraucht sind oder alle seine Antworten als richtig geprüft wurden; `'never'`. Solange die Prüfungen begrenzt sind, beendet das Zeigen der Lösung den Versuch.
- **`passingScore`** ist die Grenze, an der ein SCORM-Paket bestanden oder nicht bestanden misst (siehe [SCORM-Pakete](/de/docs/configuration-html-folio-epub#scorm-pakete-postext-scorm)).

Die Wörter auf den Schaltflächen folgen der Sprache des Dokuments. Mit `check: 'instant'` gibt es keine Schaltfläche Prüfen, daher gilt `maxChecks` nicht; die übrigen Einstellungen gelten. Die verbrauchten Prüfungen und Neuanfänge werden mit den Antworten gespeichert: In einem LMS bewahrt ein SCORM-Paket sie im LMS auf, sodass sie auf jedem Gerät gelten; in einer HTML-Seite oder einem EPUB-Buch liegen sie im Browser des Lesers, und wer dessen Speicher löscht, fängt von vorn an.
