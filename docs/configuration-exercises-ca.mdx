# Configuració: exercicis


## Estils d'exercici

La propietat `exerciseStyles` declara els estils amb nom que un exercici tria amb `:::exercise{style="…"}`. Un estil és la forma d'una família d'exercicis; les preguntes i les respostes es queden al Markdown (vegeu [Exercicis](/ca/docs/exercises)). Per defecte s'inclou un estil, `exercise`, de manera que el bloc funciona sense cap configuració; si declares `exerciseStyles`, el substitueixes, i el primer estil declarat és el que pren un exercici sense `style`. Tots els camps són opcionals, i els valors per defecte segueixen la llengua del document allà on les escoles fan les coses de manera diferent: les etiquetes de les opcions, les lletres de vertader o fals, la manera de disposar la divisió i les paraules que s'imprimeixen.

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Source Sans 3' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'grid', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### Número

La pantalla pot tenir uns paràmetres d'exercicis propis: `htmlViewer.overrides` també accepta `exercises` i `exerciseStyles`, que es fusionen amb els del llibre abans que el visor HTML faci la maquetació.
```ts
const config: PostextConfig = {
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [{ id: 'exercise', area: { kind: 'none' }, blank: { minWidth: { value: 6, unit: 'em' } } }],
    },
  },
};
```

### Avaluació

Per defecte, un exercici és de pràctica: el lector comprova tantes vegades com vol, torna a començar i mira la solució. Quatre paràmetres el converteixen en un examen, per al llibre a `exercises.digital` i per a un estil al seu `digital`, que mana sobre els exercicis d'aquest estil:

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`** compta les vegades que es prem Comprova en un intent. El botó diu quantes en queden («Comprova (en queden 2)»); quan s'acaben hi posa «Sense més comprovacions», les respostes queden bloquejades i la puntuació es manté a la barra.
- **`reset`** i **`maxResets`**: Torna a començar esborra les respostes i obre un intent nou, amb les comprovacions disponibles de nou. `maxResets: 1` permet tornar a començar una vegada, dos intents en total, i el botó diu quantes vegades en queden; `reset: false` treu el botó.
- **`showSolution`**: `'always'`, sempre; `'afterCheck'`, un cop comprovat l'intent; `'noChecksLeft'`, quan se n'han esgotat les comprovacions o totes les respostes són correctes; `'never'`, mai. Mentre les comprovacions són limitades, veure la solució tanca l'intent.
- **`passingScore`** és la nota segons la qual un paquet SCORM informa d'aprovat o suspès (vegeu [Paquets SCORM](/ca/docs/configuration-html-folio-epub#paquets-scorm-postext-scorm)).

Les paraules dels botons segueixen la llengua del document. Amb `check: 'instant'` no hi ha botó Comprova, de manera que `maxChecks` no s'aplica; els altres paràmetres, sí. Les comprovacions i els reinicis gastats es desen amb les respostes: en un LMS, un paquet SCORM els desa al mateix LMS, i per això valen en qualsevol dispositiu; en una pàgina HTML o en un llibre EPUB es queden al navegador del lector, i qui n'esborra les dades torna a començar de zero.
