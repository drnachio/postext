# التمارين

**الأسئلة وإجاباتها في Markdown، وطريقة طباعتها نمط تمرين.**

التمرين كتلة من الفصل تُكتب بين `:::exercise` و`:::`. في داخلها التعليمة والأسئلة والخيارات والفراغات وإجاباتها، والحل المفصّل إن وُجد. يقرأ Postext الإجابات من النص، ويطبع التمرين للتلميذ (أسطر فارغة، ومربعات خالية، وبنود مخلوطة)، ويبني مفتاح الإجابات، ويضع الحلول حيث يريدها الكتاب. شارة الرقم وتسميات الخيارات وشكل الفراغ وتسطير مساحة الكتابة تأتي من [`exerciseStyles`](/ar/docs/configuration-exercises#أنماط-التمارين)، أما موضع الحلول والطبعة التي تُطبع فيأتيان من [`exercises`](/ar/docs/configuration-exercises#إعدادات-الكتاب). فيخرج من ملف Markdown واحد كتاب التلميذ وكتاب المعلم وطبعة تفاعلية على الشاشة.

يُصفّ التمرين إطارًا من فقرات عادية وشارات ورسوم، فيوضع ويُقسَم بين الأعمدة والصفحات ويُوسَم في ملف PDF الميسَّر ويُرسم في كل المخرجات كما يُعامَل أي إطار. والكتاب الذي لا `:::exercise` فيه يُصفّ كما كان.

## حاوية التمرين

```md
:::exercise
عاصمة المملكة المغربية هي:

- [ ] الدار البيضاء
- [x] الرباط
- [ ] فاس
:::
```

الفقرات التي يبدأ بها التمرين، حتى أول قائمة أو فراغ أو بنك كلمات، هي **التعليمة**. تُصفّ بعد رقم التمرين بخط التعليمة في النمط (العريض افتراضيًا). وما بعدها جسم التمرين، أي المطلوب.

وتوضع داخل التمرين حاويتان. `:::solution` … `:::` تحمل حلًّا مفصّلًا أو إجابة نموذجية بأي Markdown؛ لا تُطبع أبدًا داخل التمرين، وتذهب حيث تذهب [الحلول](#الحلول). و`:::hint` … `:::` تحمل تلميحًا تعرضه طبعات الشاشة لمن يطلبه؛ ولا يظهر في الطباعة.

## أنواع التمارين

الخلط مبني على بذرة: يُخلط التمرين بالطريقة نفسها في اللوحة وPDF وعارض HTML وEPUB ومفتاح الإجابات. غيّر `exercises.seed` لتطبع نسخة أخرى من الاختبار.

### الاختيار من متعدد وصح أو خطأ

#### الاختيار من متعدد

قائمة مهام، وقد أُشّرت الخيارات الصحيحة:

```md
:::exercise
أيّ الكواكب أقرب إلى الشمس؟

- [ ] الزهرة
- [x] عطارد
- [ ] المريخ
:::
```

يُطبع كل خيار في سطر، بالتسميات أ) ب) ج)، وأسطره التالية معلّقة تحت نصه. والأسئلة المتعددة في تمرين واحد قائمة مرقّمة بنودها رؤوس الأسئلة، وتحت كل بند قائمة مهامه بإزاحة؛ فتُرقَّم الأسئلة وتُصفّ خياراتها تحتها:

```md
:::exercise{columns=3}
ضع دائرة حول الإجابة الصحيحة.

1. تمتص جذور النبات
   - [x] الماء
   - [ ] الضوء
   - [ ] البذور
2. تصنع الأوراق الغذاء من
   - [ ] التربة
   - [ ] الرياح
   - [x] ضوء الشمس
:::
```

`columns=3` تصفّ الخيارات ثلاثة في كل صف. والتسميات ولاحقتها تتبع لغة المستند: أ) ب) ج) في العربية، وa) في الإنجليزية واللغات الرومانسية، وA. في الصينية، وア イ ウ في اليابانية. ويمكن أن يضيف النمط مربعًا أو دائرة للتأشير قبل كل خيار (`options.marker`)، أو قوسين （　） بعد رأس السؤال يُكتب فيهما الحرف (`options.bracket`)، كما تفعل الاختبارات الصينية واليابانية.

#### صح أو خطأ

```md
:::exercise{type=truefalse}
ضع علامة في المربع المناسب: صح أو خطأ.

- [x] الشمس نجم.
- [ ] القمر كوكب.
:::
```

تُرقَّم كل عبارة، وتنتهي بالإجابتين في آخر السطر، لكل منهما مربع: صح □ خطأ □. والبند المؤشَّر صحيح. وتتبع العلامتان اللغة: صح/خطأ في العربية، وT/F في الإنجليزية، وV/F في الإسبانية والكتالونية والفرنسية والإيطالية والبرتغالية، وR/F في الألمانية، و√/× في الصينية، و○/× في اليابانية. ويمكن أن يطبع النمط بدلهما فراغًا واحدًا تُكتب فيه الإجابة (`trueFalse.look: 'bracket'`).

### ملء الفراغات وبنك الكلمات

`[[الإجابة]]` فراغ، يُطبع خطًّا يُكتب عليه:

```md
:::exercise{bank}
أكمل الفراغات بالكلمات المناسبة من الإطار.

1. تمتص الجذور [[الماء]] من التربة.
2. تصنع الأوراق [[غذاء]] النبات.
3. تجذب الأزهار [[الحشرات | النحل]].

::bank[الحجارة | الرياح]
:::
```

- `[[مسؤول | مسئول]]`: فراغ يقبل أكثر من إجابة. والأولى هي التي يطبعها المفتاح.
- `[[ذهب | (ذهبت) | ذهبوا]]`: **اختيار داخل السطر**. تُطبع الخيارات في السطر، `(ذهب / ذهبت / ذهبوا)`، والخيار الذي بين قوسين هو الصحيح: يضع القارئ دائرة حوله.
- `[[ذهبت]]{width=6}`: فراغ عرضه ستة em.
- `[[{春天|chūn tiān}]]`: الروبي داخل الفراغ تُطبع قراءتها فوق الفراغ، في كتاب التلميذ أيضًا، فيكتب التلميذ الحروف تحت البينيين (看拼音写词语) أو الكانا (漢字の書き取り).
- `\|` خط عمودي حرفي داخل الإجابة، و`\[[` قوسان مربعان حرفيان.

كل فراغات التمرين بعرض أطول إجاباته مضافًا إليه 1.5 em، فلا يكشف طول الخط إجابته (ويغيّر ذلك `blank.width`). و`bank` تطبع الإجابات في بنك كلمات داخل إطار، مخلوطة، تحت التعليمة. أما السطر `::bank[الحجارة | الرياح]` فيضع البنك في موضعه من التمرين ويضيف إليه كلماته مشتِّتاتٍ، ويطلب البنك وحده من دون `bank`. ولا يُقرأ `[[…]]` إلا داخل تمرين: القوسان المزدوجان في أي موضع آخر من الكتاب يبقيان كما كُتبا.

والتمرين الذي يبدأ بنصه بدل التعليمة يدخل رقمه في أول فقرة:

```md
:::exercise
الأسبوع سبعة [[أيام]]، والسنة اثنا عشر [[شهرًا]].
:::
```

### التوصيل والتصنيف

#### التوصيل

أزواج تُكتب بـ`->` (أو `→`):

```md
:::exercise
صِل كل حيوان بمسكنه.

- النحلة -> الخلية
- العصفور -> العش
- العنكبوت -> البيت
- الأرنب -> الجحر
- -> العرين
:::
```

يُطبع العمود الأول بالترتيب الذي كُتب به، والثاني مخلوطًا، وبجانب كل بند نقطة يُوصل منها بخط. و`- -> العرين` تضيف إلى العمود الثاني بندًا لا يقابله شيء. ومع `match.look: 'letters'` تُعطى بنود العمود الثاني حروفًا، ولكل بند في العمود الأول قوسان يُكتب فيهما الحرف. و`shuffle=false` تُبقي العمود الثاني كما كُتب.

#### التصنيف

```md
:::exercise{type=sort}
صنّف الأطعمة بحسب جزء النبات الذي تأتي منه.

- جذر: الجزر، الفجل
- ورقة: الخس، السبانخ
- ثمرة: الطماطم، التفاح
:::
```

تدخل كل البنود في بنك كلمات، مخلوطة، ولكل فئة عمود (حتى أربعة) عليه اسمها وتحته أسطر. ويمكن الفصل بين البنود بالفاصلة العربية `،` أو بالفاصلة اللاتينية أو الفاصلة المنقوطة أو `、` أو `，`.

### إعادة الترتيب

#### الترتيب

```md
:::exercise{type=order}
رتّب مراحل نمو النبات.

1. تنبت البذرة.
2. تنمو الساق.
3. تتفتح الأزهار.
4. تظهر الثمار.
:::
```

تُكتب القائمة بالترتيب الصحيح وتُطبع مخلوطة، وبجانب كل بند مربع يُكتب فيه رقمه.

#### الكلمات المبعثرة

```md
:::exercise{type=scramble}
رتّب الكلمات لتكوّن جملًا مفيدة.

- يحتاج / النبات / إلى الماء
- تعطي / الشمس / الضوء
:::
```

تُقطَّع كل جملة عند الخطوط المائلة (وعند المسافات إن لم يكن فيها خط مائل)، وتُطبع أجزاؤها مخلوطة بينها خطوط مائلة، وتحتها سطر تُكتب عليه الجملة.

### تعليم الكلمات

```md
:::exercise{type=mark}
ضع دائرة حول الأفعال: [[تسقي]] البنتُ النباتات، و[[تُدفئ]] الشمسُ الأرض.
:::
```

يُطبع النص كما هو؛ والكلمات التي بين `[[…]]` هي المطلوب تعليمها. في الإجابات توضع حولها دائرة، أو مربع، أو يُرسم تحتها خط، أو تُظلَّل، بكتابة `mark=box|underline|highlight` في الحاوية، أو كلمةً كلمة بـ`[[تسقي]]{mark=underline}`. على الشاشة يمكن تعليم أي كلمة في النص، والكلمة المعلَّمة خطأً تُحسب إجابة خاطئة.

### الأسئلة المفتوحة ومساحات الكتابة

```md
:::exercise{type=open lines=4}
لماذا يحتاج النبات إلى الضوء؟

:::solution
يستعمل النبات الضوء ليصنع غذاءه.
:::
:::
```

تلي التعليمةَ أسطرٌ يُكتب عليها: ثلاثة افتراضيًا، وأربعة هنا بـ`lines=4`. وحين يكون الجسم قائمة، تكون لكل بند أسطره. و`area` تغيّر التسطير: `lines`، و`dots`، و`grid` (ورق المربعات)، و`seyes` (تسطير المدارس الفرنسية)، و`tianzige` (田字格، المربعات التي يكتب فيها تلاميذ الصين الحروف)، و`box` (إطار فارغ لرسم)، و`none`. و`:::solution` هي الإجابة النموذجية: تُطبع مع الحلول، وتُكتب على الأسطر في طبعة المعلم. على الشاشة لا يترك `area=none` في الحاوية مكانًا للكتابة، وهو للتمرين الذي يُؤدّى شفهيًا أو مع زميل؛ أما النمط الذي قيمة `area.kind` فيه `none` فيرسم المنطقة بلا تسطير فحسب.

تحدّد `cells` عدد خانات المربعات (`grid` أو `tianzige`، وورق مربعات حين يسطّر النمط أسطرًا): `cells=4`. وتضع عدة أعداد مجموعات متجاورة تفصل بينها خانة، مجموعة لكل كلمة، تنتقل إلى السطر التالي عند نهايته: `cells="2 2 3"`. وتكتب طبعة المعلم الإجابة النموذجية حرفًا في كل خانة، مجموعةً بعد مجموعة.

### البحث عن الكلمات والكلمات المتقاطعة

#### البحث عن الكلمات

```md
:::exercise{type=wordsearch size=10 directions="across down diagonal backwards"}
ابحث عن هذه الكلمات في الشبكة.

- جذر
- ساق
- ورقة
- زهرة
:::
```

توضع الكلمات في شبكة من الحروف، وتُطبع القائمة تحتها (و`hidden` تحذف القائمة). تكبر الشبكة لتتسع لأطول كلمة؛ و`size` تحدد ضلعها. و`directions` تأخذ `across` و`down` و`diagonal` و`backwards`؛ والافتراضي أفقيًا وعموديًا وقطريًا. ويوضع كل حرف في خانته وحده. وتُكتب الحروف اللاتينية كبيرة ما لم يقل النمط غير ذلك، أما الحروف العربية فلا حالة لها فتبقى كما هي. والكلمة التي لا تجد مكانًا في الشبكة يُبلَّغ عنها.

#### الكلمات المتقاطعة

```md
:::exercise{type=crossword}
حُلّ الكلمات المتقاطعة.

- جذر: جزء النبات الذي يكون تحت التربة
- ورقة: الجزء الأخضر الذي يصنع الغذاء
- زهرة: تجذب النحل
- ساق: تحمل النبات
:::
```

كل مدخل كلمة ومفتاحها. يبني المحرك الشبكة، ويرقّم أول خانة من كل كلمة، ويطبع المفاتيح تحتها في قائمتين عنوانهما بلغة المستند (أفقيًا وعموديًا، Across وDown، ヨコのカギ・タテのカギ).

### العمليات العمودية

```md
:::exercise{type=arithmetic}
احسب.

- ٣٤٥ + ٢٧٨
- ٩٠٢ − ٤٥٦
- ١٢٤ × ٣
- ٨٦٤ ÷ ٤
:::
```

تُصفّ كل عملية في خانات، كما يكتبها التلميذ: الأرقام في أعمدة، والإشارة على اليسار، وخط، وخانات فارغة للناتج، وحتى أربع عمليات في الصف. وفي الصفحة المكتوبة من اليمين إلى اليسار تحتفظ كل عملية بأرقامها من اليسار إلى اليمين، وتتوالى العمليات من اليمين إلى اليسار. والإشارات المقروءة هي `+` و`-` و`−` و`×` و`x` و`*` و`·` و`⋅` و`÷` و`:` و`/`، مع أعداد صحيحة أو عشرية (`١٢٫٥ + ٣٫٧٥`): في الجمع والطرح تقع الفواصل العشرية بعضها تحت بعض، ولا تُقرأ القسمة على عدد عشري. وتُقرأ الأرقام الهندية (٠–٩) والفارسية كما تُقرأ الأرقام الغربية، ويُطبع الناتج بأرقام العملية نفسها. والقسمة المطوّلة تتبع عرف المدرسة في لغة المستند، و`arithmetic.division` تختار غيره:

- `bracket`: المقسوم عليه على اليسار، والمقسوم تحت قوس، وخارج القسمة فوقه. في الكتب العربية والإنجليزية والصينية واليابانية.
- `potence`: المقسوم على اليسار، والمقسوم عليه على اليمين تحت زاوية على شكل L، وخارج القسمة تحت المقسوم عليه، والباقي في الأسفل. في الكتب الإسبانية والكتالونية والفرنسية والإيطالية والبرتغالية.
- `inline`: `864 : 4 =` وخانات خارج القسمة في السطر نفسه، والخطوات تحته. في الكتب الألمانية.

الضرب في عدد من رقمين أو أكثر يطبع سطرًا لكل ناتج جزئي، كل سطر منزلةً إلى اليسار، ثم الناتج تحت خط ثانٍ (`arithmetic.partialProducts: false` يترك الناتج وحده). وتحت القسمة المطوّلة يترك النمط أسطرًا لخطواتها: ناتج كل خطوة وما يتبقى، أو ما يتبقى فقط حين يُطرح ذهنيًّا كما تكتبه الكتب الإسبانية والكتالونية والإيطالية (`arithmetic.working`).

### بند أول مُجاب عنه

`example` تطبع البند الأول محلولًا، بلون الإجابات: الفراغ الأول مملوءًا، والخيار الصحيح للسؤال الأول داخل دائرة، والزوج الأول موصولًا، والجملة الأولى مكتوبة. ولا يُسأل عن هذا البند على الشاشة، ولا تدخل إجابته في بنك الكلمات.

## الأرقام والإحالات والصعوبة

تُرقَّم التمارين 1 و2 و3 في كل فصل. والنمط يقرر الباقي: رقم مجرد بالعريض تليه نقطة (الافتراضي) أو داخل قرص أو مربع أو مربع مستدير الزوايا (`number.shape`)، وكلمة قبله («تمرين 3» مع `number.label: true`، بلغة المستند)، ونظام الأرقام (`number.format`، كالأرقام الهندية `'arabic-indic'` أو الصينية 一、二、)، وقالب يضيف رقم الفصل (`'{h1}.{n}'`)، وموضع بدء العدّ من جديد (`number.resetOn`: كل فصل، أو كل قسم، أو أبدًا). والأنماط التي تسمّي `number.counter` نفسه تتشارك عدًّا واحدًا، ويحمله الكتاب من فصل إلى فصل.

`n=12` في الحاوية تعطي التمرين الرقم 12، وتكمل التمارين التالية من 13. و`#id` تجعل التمرين هدفًا لـ`:ref`، فتطبع الإحالة اسمه، «تمرين 3» (الكلمة التي يحددها النمط في `number.label` إن حدد واحدة، وإلا كلمة لغة المستند). و`style=number` تطبع 3، و`style=title` تطبع `title` الحاوية (أو الاسم إن لم يكن لها عنوان)، و`style=page` تطبع صفحته. وتصل الإحالة كذلك إلى تمارين الفصول الأخرى من الكتاب. و`level` و`icon` تُطبعان بعد الرقم: علامات الصعوبة وأيقونات النشاط التي يعرّفها النمط.

## الحلول

### مفتاح الإجابات

لكل تمرين يُصحَّح مفتاح يُبنى من إجاباته: الخيار الصحيح (`ب) عطارد`)، والفراغات بالترتيب (`1 الماء · 2 غذاء · 3 الحشرات`)، و«صح» أو «خطأ» لكل عبارة، والأزواج، والترتيب، والجمل، وكلمات الكلمات المتقاطعة بأرقامها، ونواتج العمليات. ومع التخطيط `full` (الافتراضي) يلي المفتاحَ `:::solution` الخاص بالتمرين. والتمرين المفتوح لا مفتاح له: إجابته النموذجية هي حله.

### موضع طباعة الحلول

يقرر ذلك `exercises.solutions.placement` للكتاب كله؛ ويمكن أن يغيّره النمط لتمارينه.

مع `directive`، يطبع سطر `:::solutions` حلول التمارين التي قبله ولم تُطبع حلولها بعد؛ و`title="…"` تغيّر عنوانه. و`:::solutions{scope="book"}`، في فصل خاص به في آخر الكتاب، يطبع المفتاح والحلول لكل تمارين الكتاب، فصلًا فصلًا:

```md
# الإجابات

:::solutions{scope="book"}
```

### طبعة المعلم

```json
{ "exercises": { "edition": "teacher" } }
```

تطبع كل إجابة في موضعها، بلون الإجابات (أحمر أرجواني ما لم يحدد النمط `answers.color`): الفراغات مملوءة، والخيارات الصحيحة داخل دوائر أو مربعاتها ممتلئة، ومربع «صح» أو «خطأ» ممتلئًا، وخطوط التوصيل مرسومة، والأرقام في مربعات الترتيب، والجمل والكلمات المصنّفة على أسطرها، والإجابة النموذجية للسؤال المفتوح على أسطره، وكلمات الكلمات المتقاطعة ونواتج العمليات في خاناتها.

## الفحوص

تُبلغ لوحة **الفحوص** في Sandbox والدالة `collectContentWarnings` عمّا لا يستطيع المحرك قراءته:

- `exerciseUnknownType`: قيمة `type` ليست من الأنواع الاثني عشر.
- `exerciseUnknownStyle`: قيمة `style` لا تسمّي نمط تمرين (ويُستعمل أول نمط).
- `exerciseNoAnswer`: تمرين يُصحَّح وليس فيه ما يُصحَّح: سؤال بلا خيار مؤشَّر، أو فراغات بلا `[[…]]`، أو توصيل بلا أزواج.
- `exerciseUnreadItem`: بند قائمة لا يستطيع نوع التمرين قراءته، كبند توصيل بلا `->` أو عملية ليست عددين صحيحين وإشارة.
- `exerciseWordUnplaced`: كلمة لم تجد مكانًا في شبكة البحث عن الكلمات أو الكلمات المتقاطعة.
- `exerciseNested`: تمرين داخل تمرين آخر.
- `solutionOutside`: `:::solution` أو `:::hint` خارج تمرين. ولا يُطبع منها شيء.

## التمارين في HTML وEPUB

في عارض HTML وكتب EPUB يمكن الإجابة عن التمارين. يكتب القارئ في الفراغات وينقر الخيارات والعبارات ونقاط التوصيل وخانات الشبكة، ثم يتحقق من إجاباته، أو يعرض الحل، أو يبدأ من جديد. وتظهر الإجابة الصحيحة والخاطئة بلون وعلامة (`digital.correctColor` و`digital.wrongColor`)، وتُعلَن لقارئات الشاشة. وتُحفظ الإجابات في المتصفح، لكل كتاب على حدة، فيجدها القارئ في زيارته التالية (`exercises.digital.persist`). ومع `exercises.digital.check: 'instant'` تُفحص كل إجابة لحظة كتابتها؛ ومع `exercises.digital.interactive: false` تبقى الصفحات كما طُبعت. ومفتاح الإجابات موجود دائمًا في كتاب EPUB، أيًّا كان موضع الحلول في الطباعة، فيجد الإجابات نظامُ القراءة الذي لا يشغّل البرامج النصية. في كتاب EPUB القابل لإعادة التدفق تكبر الشبكات ومساحات الكتابة مع نص القارئ، وفي الصفحة من اليمين إلى اليسار تتبع الخانات المطلوب ملؤها الشبكة المعكوسة. تُوصَل الأزواج بالنقر على نقطة ثم على الأخرى، أو بالسحب من إحداهما إلى الأخرى، وتُسحب كلمات تمرين التصنيف إلى عمودها أو تُختار من قائمة. ولا يحمل الشريط إلا الأزرار التي تؤدي عملًا: لا «تحقّق» حين لا يوجد ما يُتحقَّق منه، ولا «اعرض الحل» حين لا يوجد حل، ولا شريط أصلًا حين لا يوجد ما يُجاب عنه.

وفي الاختبار، يمكن للكتاب أو لنمط تمرين أن يحدّ المحاولة: كم مرة يُتحقَّق منها (`digital.maxChecks`)، وهل تُعاد من البداية وكم مرة (`digital.reset` و`digital.maxResets`)، ومتى يظهر الحل (`digital.showSolution`). وتذكر الأزرار كم بقي من مرات التحقق وإعادة المحاولة. انظر [التقييم](/ar/docs/configuration-exercises#التقييم).

ويمكن أن تأخذ التمارين على الشاشة شكلًا خاصًا بها عبر `htmlViewer.overrides`، الذي يُدمج فوق إعدادات الكتاب قبل أن يصفّ عارض HTML صفحاته. وتحتفظ الطباعة بإعداداتها:

```ts
const config: PostextConfig = {
  exercises: { solutions: { placement: 'chapterEnd' } },
  htmlViewer: {
    overrides: {
      exercises: { solutions: { placement: 'none' } },
      exerciseStyles: [
        { id: 'exercise', blank: { minWidth: { value: 6, unit: 'em' } }, area: { kind: 'none' } },
      ],
    },
  },
};
```

## التمارين في حزمة SCORM

تحمل حزمة SCORM (تبويب **SCORM** في Sandbox، أو `postext-scorm` من الشيفرة) التمارين كما يحملها عارض HTML، وترسل نتائجها إلى نظام إدارة التعلم (LMS) الذي تعمل فيه الحزمة. فكل جزء من الكتاب يتابعه نظام إدارة التعلم يرسل درجة (الإجابات المقيَّمة الصحيحة من مجموعها، بحسب آخر تحقق في كل تمرين)، وهل اكتمل (كل صفحة شوهدت وكل تمرين تُحقِّق منه)، وهل نجح إذا حُدِّدت `exercises.digital.passingScore`. وتُكتب كل مرة تحقق أيضًا تفاعلًا (interaction) فيه إجابة القارئ والإجابة الصحيحة. وتُحفظ الإجابات ومرات التحقق المستعملة في نظام إدارة التعلم، فتسري حدود المحاولة من زيارة إلى التي تليها ومن جهاز إلى آخر. انظر [حزم SCORM](/ar/docs/configuration-html-folio-epub#حزم-scorm-postext-scorm).

```ts
const config: PostextConfig = {

      id: 'activity',

      instruction: { fontFamily: 'Noto Kufi Arabic' },
      options: { marker: 'circle' },

```

كل حقول النمط بأنواعها وقيمها الافتراضية في [الإعدادات › التمارين](/ar/docs/configuration-exercises). ويأخذ النمط إطاره من [نمط إطار](/ar/docs/configuration-callouts) (`box`)، فيمكن أن يوضع التمرين في إطار ملوّن الخلفية بشريط على حافته ككل إطار آخر في الكتاب. وتتبع [مهارة postext-port](/ar/docs/skill) الخطوات نفسها حين تنقل تمارين كتاب مدرسي أو كراسة تمارين.
