# الإعدادات: القصص المصورة


## القصص المصورة

تضبط الخاصية `comics` صفحات القصص المصورة (`:::page`) والشرائط المصورة (`:::strip`) والصفحات المزدوجة: الإطار العام والفواصل التي تُقطع منها الإطارات، وأنماط الإطارات، وكتابة الحوار، وأنماط الفقاعات، وقائمة الشخصيات. ولا يقرؤها إلا المستند الذي فيه قصص مصورة؛ فالمستند الذي ليس فيه شيء منها يُخرَج كما كان يُخرَج تمامًا، والمستند الذي فيه قصص مصورة وليس فيه قسم `comics` يأخذ القيم الافتراضية للغته. ويشرح دليل [القصص المصورة](/ar/docs/comics) الترميز وطريقة كتابة حوار الصفحات.

```ts
const config: PostextConfig = {
  comics: {
    readingDirection: 'auto',
    gutter: { horizontal: { value: 5, unit: 'mm' }, vertical: { value: 2.5, unit: 'mm' } },
    panel: { borderWidth: { value: 0.8, unit: 'pt' }, borderStyle: 'rough' },
    panelStyles: [{ id: 'night', background: { hex: '#14142b', model: 'hex' }, borderColor: { hex: '#ffffff', model: 'hex' } }],
    lettering: { fontSize: { value: 8.5, unit: 'pt' }, textTransform: 'uppercase' },
    balloonStyles: [{ id: 'eerie', shape: 'wavy', italic: true }],
    cast: [{ id: 'maya', name: 'مايا' }, { id: 'tomas', name: 'الجد توماس' }],
  },
};
```

### أنماط الفقاعات

كل مدخل في `comics.balloonStyles` يُطبَّق فوق النمط المدمج الذي يحمل المعرّف نفسه (`speech` و`thought` و`whisper` و`shout` و`radio` و`caption` و`inner` و`note` و`sfx`)، أو فوق `speech` إن كان معرّفه جديدًا. والقيم الافتراضية أدناه قيم `speech`؛ وتسرد [صفحة القصص المصورة](/ar/docs/comics#أنماط-الفقاعات) ما يغيّره كل نمط مدمج. والأطوال بوحدة `em` نسبةً إلى حجم نص الفقاعة.

يتقدّم `color` و`font` في السطر نفسه على قائمة الشخصيات، وتتقدّم قائمة الشخصيات على نمط الفقاعة. ويجوز أن يكون كل لون في القصص المصورة مدخلًا من لوحة الألوان، فيتبعها كأي لون مربوط بها.

```ts
const resolved = resolveComicsConfig(config.comics, 'ja');
// => كل الحقول مملوءة؛ والخطان Zen Antique وDela Gothic One

const minimal = stripComicsDefaults(config.comics, 'ja');
// => undefined حين يكون كل شيء على قيمته الافتراضية

const shout = pickBalloonStyle(resolved, 'shout'); // نمط الصراخ المدمج مع تغييرات الكتاب
const night = pickPanelStyle(resolved, 'night');   // نمط إطار مسمّى، وإلا فالإطار الافتراضي
```
