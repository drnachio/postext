# 配置：练习


## 练习样式

`exerciseStyles`属性声明一组具名样式，练习用`:::exercise{style="…"}`选用。一种样式是一类练习的形式；题目和答案仍然写在Markdown里（见[练习](/zh/docs/exercises)）。默认自带一种样式`exercise`，所以不做任何配置也能使用这个块；一旦声明`exerciseStyles`，就会替换它，声明的第一种样式就是没写`style`的练习所用的样式。所有字段都是可选的；在各国学校习惯不同的地方，默认值随文档语言而定：选项的序号、判断题的两个符号、除法竖式的排法、印出的文字。

```ts
const config: PostextConfig = {
  exerciseStyles: [
    {
      id: 'activity',
      box: 'activity-frame',
      number: { shape: 'disc', background: { hex: '#2a5ea8', model: 'hex' } },
      instruction: { fontFamily: 'Noto Sans SC' },
      options: { marker: 'circle' },
      blank: { look: 'dots', width: 'answer' },
      area: { kind: 'tianzige', lines: 4 },
      level: { glyph: '★', empty: '☆' },
      icons: { pair: { glyph: '👥' } },
    },
    { id: 'quiz', extends: 'activity', options: { layout: 'row', columns: 4 } },
  ],
};
```

### 编号

`number`设定练习的题号。不带形状的题号用粗体、主色，后面跟一个句点；带形状的题号是主色的圆形、方形或圆角方形里的白色数字，后面不加符号。

### 测评

默认情况下，练习只用于练习：读者想检查几次就检查几次，可以重做，也可以查看答案。有四项设置可以把练习变成测验：全书的设在`exercises.digital`中，样式的设在样式的`digital`中，对本样式的练习优先于全书的设置：

```ts
const config: PostextConfig = {
  exercises: { digital: { passingScore: 60 } },
  exerciseStyles: [
    { id: 'exercise' },
    { id: 'test', extends: 'exercise', digital: { maxChecks: 1, maxResets: 1, showSolution: 'noChecksLeft' } },
  ],
};
```

- **`maxChecks`**：统计一次作答中按“检查”的次数。按钮上显示还剩几次（“检查（还剩 2 次）”）；用完后按钮显示“检查次数已用完”，答案被锁定，得分留在按钮栏上。
- <strong>`reset`</strong>和<strong>`maxResets`</strong>：“重做”清除答案，开始新的一次作答，检查次数也随之恢复。`maxResets: 1`允许重新开始一次，即总共两次作答，按钮上显示还剩几次；`reset: false`去掉这个按钮。
- **`showSolution`**：`'always'`；`'afterCheck'`，本次作答检查过之后；`'noChecksLeft'`，检查次数用完或答案全部答对之后；`'never'`。检查次数有限时，查看答案即结束本次作答。
- **`passingScore`**：SCORM包据此报告通过或未通过（见[SCORM包](/zh/docs/configuration-html-folio-epub#scorm包postext-scorm)）。

按钮上的文字随文档语言而定。设`check: 'instant'`时没有“检查”按钮，所以`maxChecks`不起作用，其他设置仍然有效。已用的检查次数和重做次数与答案一起保存：在LMS中，SCORM包把它们保存在LMS里，所以在任何设备上都有效；在HTML页面或EPUB电子书中，它们保存在读者的浏览器里，清除了浏览器存储的读者要从头开始。
