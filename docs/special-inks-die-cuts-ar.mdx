# الأحبار الخاصة والقص بالقالب

**الحبر الخاص لون خاص له تشطيب. والقص بالقالب شكل في الإعدادات يقصه قالب القص في الأوراق.**

كلاهما من شكل الكتاب، فمكانهما الإعدادات. التشطيب لا يحرّك سطرًا أبدًا: يرى الإخراج لونًا، ويرى ملف PDF حبرًا على لوح خاص به، وتقرر العارضات كيف تعرضه. أما القص بالقالب فيغيّر الصفحة، لأن النص يبتعد عن الفتحة، لكن ملف Markdown لا يذكر القالب إلا حيث يحتاج إليه المحتوى.

## الحبر الخامس

الحبر الخامس أي حبر تطبعه المهمة غير السماوي والأرجواني والأصفر والأسود: لون Pantone يجب أن يطابق بدقة، أو لون مؤسسي يمزجه صانع الحبر، أو أحد الأحبار الخاصة أدناه. وهو في Postext لون خاص، أي لون له `model: 'spot'` يسمّي `spot` فيه الحبر، ويعطي مظهره بنسبة 100 % في CMYK (البديل الذي تعرضه البروفة) ودرجته. يطبعه ملف CMYK أو PDF/X على لوح `Separation` يحمل اسم الحبر؛ وترسم الشاشة وملف RGB قيمته `hex`. ويشرح قسم [الألوان الخاصة](/ar/docs/configuration-pdf-output#الألوان-الخاصة) هذا النموذج كاملًا.

[جدول الأحبار](/ar/docs/configuration-pdf-output#جدول-الأحبار) (`print.inks`) هو الموضع الذي يوصف فيه الحبر كما ستتسلمه المطبعة، أيًّا كان الاسم الذي تعطيه إياه الألوان وصور SVG والملفات المستوردة: اسم لوحه، وأسماؤه البديلة، وهل يُطبع بالألوان الأساسية، وبديله، وطباعته الفوقية، وتشطيبه إن كان حبرًا خاصًا.

```ts
import type { PostextConfig } from 'postext';

const config: PostextConfig = {
  colorPalette: [
    { id: 'brand', name: 'Brand blue', value: { hex: '#1f3f99', model: 'spot',
      spot: { name: 'PANTONE 286 C', cmyk: { c: 100, m: 66, y: 0, k: 2 } } } },
  ],
  print: {
    standard: 'pdfx4',
    inks: [{ name: 'PANTONE 286 C', aliases: ['Pantone 286C', 'Corporate blue'] }],
  },
};
```

```ts
interface InkFinish {
  kind: 'metallic' | 'foil' | 'fluorescent' | 'white' | 'varnish';
  sheen?: 'gloss' | 'satin' | 'matte' | 'softTouch';   // يُتجاهل في الأحبار الفلورية والبيضاء.
}
```

يوضع التشطيب على اللون الخاص (`spot.finish`) أو على مدخل الحبر في جدول الأحبار (`print.inks[].finish`)، ويُقدَّم ما في جدول الأحبار. والجدول هو موضع الحبر الذي لا تعرّفه الألوان: ملف SVG أو ملف مستورد يسمّي `Gold` يأخذ تشطيبه المعدني من هناك. والنوع الذي لا يعرفه Postext يُسقط، وكذلك اللمعان الذي لا ينطبق: لا لمعان لحبر فلوري أو أبيض، واللمسة الناعمة للورنيش وحده.

```ts
const config: PostextConfig = {

      spot: { name: 'Gold foil', cmyk: { c: 15, m: 30, y: 70, k: 10 }, finish: { kind: 'foil' } } } },
    { id: 'fluo', name: 'Fluo pink', value: { hex: '#ff3fa4', model: 'spot',
      spot: { name: 'PANTONE 806 C', cmyk: { c: 0, m: 80, y: 0, k: 0 }, finish: { kind: 'fluorescent' } } } },
    { id: 'white', name: 'Opaque white', value: { hex: '#f4f2ec', model: 'spot',
      spot: { name: 'Opaque white', cmyk: { c: 0, m: 0, y: 0, k: 0 }, finish: { kind: 'white' } } } },
    { id: 'uv', name: 'Spot UV', value: { hex: '#e8f0f4', model: 'spot',
      spot: { name: 'Varnish', cmyk: { c: 10, m: 0, y: 0, k: 0 }, finish: { kind: 'varnish', sheen: 'gloss' } } } },
  ],
  print: {
    standard: 'pdfx4',
    inks: [{ name: 'PANTONE 871 C', aliases: ['Gold'], finish: { kind: 'metallic' } }],
  },
};
```

### كيف يُطبع الحبر الخاص

- **لوح خاص به.** يُطبع كل حبر خاص على `Separation` خاص به، باسم اللوح الذي يعطيه إياه جدول الأحبار (`pdfName`، وإلا فاسمه). ولا يرجع أبدًا إلى الألوان الأساسية، إلا إذا نصّ مدخله في جدول الأحبار على `output: 'process'`.
- **الطباعة الفوقية.** الحبر الأبيض والورنيش يُطبعان فوق ما تحتهما ما لم يقل `overprint: false` غير ذلك، في اللون أو في جدول الأحبار: الأبيض يقع تحت الألوان والورنيش فوقها، ولا ينبغي لأي منهما أن يفرّغ الألواح. ولا يفرّغ شيء يُرسم لاحقًا لوحَ الأبيض أو الورنيش، والصور كذلك: يبقى الأبيض تحت الصورة الفوتوغرافية كلها، ولا تفرّغ أرقام الصفحات أو النص المرسوم بعد الورنيش لوحَه، كما في المطبعة، حيث يُطبع الأبيض أولًا والورنيش أخيرًا. ولا يفرّغ اللون الذي تحته إلا أبيضُ ضُبط على `overprint: false`، للنص الأبيض على لوحة ملوّنة. أما الأحبار المعدنية والرقائق والأحبار الفلورية فتُفرَّغ كأي حبر خاص.
- **ترتيب الطباعة.** يحمل الملف الألواح لا ترتيبها. يُطبع الأبيض أولًا والورنيش أخيرًا؛ ويسرد الفحص قبل الطباعة الاثنين (`inkPressOrder`) لتبلغ المطبعة، فهي التي تضبط الترتيب على الآلة. وحيث يلتقي ورنيشان، كاللمسة الناعمة على الصفحة كلها والورنيش اللامع الموضعي على صورها، يضعهما قناع التشطيب بترتيب جدول الأحبار، وكذلك يفعل العرضان *مع اللمعان* و*خريطة التشطيب* وFolio: المدخل اللاحق في الجدول يعلو السابق، والورنيش الذي لا يذكره الجدول يعلو ما يذكره. ضع اللمسة الناعمة أولًا ثم اللامع بعدها، كما تُمدّ على الآلة.
- **المهام ذات الألواح القليلة.** في مهمة [`print.plates`](/ar/docs/configuration-pdf-output#الطباعة-بحبرين)، يُحذف الحبر الأبيض أو الورنيش الذي لا تذكره المهمة، ولا يُسقط على ألواح الألوان، وينبّه التصيير (`finishInkDropped`). أما الأحبار المعدنية والرقائق والأحبار الفلورية فتُسقط كأي حبر خاص آخر.
- **ملفات RGB والرمادي.** الورنيش لا يضع شيئًا على الصفحة؛ والتشطيبات الأخرى ترسم قيمتها `hex`.

### على الشاشة

ترسم عارضات Canvas وHTML وEPUB كل حبر خاص بقيمته `hex`، إلا الورنيش، فهو شفاف لا يُرسم. ومع ذلك أعطِ الورنيش قيمة `hex` خاصة به، لأن عرض الطباعة يميّز الأحبار بقيمة `hex`.

يعرض `RenderPageOptions.finishes` التشطيبات في Canvas:

- `'flat'` (الافتراضي): قيمة `hex` لكل حبر، ولا شيء للورنيش.
- `'sheen'`: شعاع ضوء يعبر الصفحة يضيء الحبر المعدني والرقائق (أكثر كلما زاد اللمعان)، وتوهّج يرفع الحبر الفلوري، ولمعة تُظهر موضع الورنيش.
- `'map'`: الألواح الخاصة بألوان اصطلاحية فوق صفحة باهتة، كما تعلّمها بروفة الطباعة: المعدني والرقائق بالكهرماني، والفلوري بالوردي، والورنيش بالسماوي، والأبيض المعتم بالأزرق.

تقرأ المعاينتان كلتاهما **قناع التشطيب** للصفحة. يعيده `renderFinishMask(page, doc, { scale })`، أو يعيد `undefined` للصفحة التي لا تُرسم بحبر خاص، فلا تكلّف شيئًا. وهو صورة نقطية RGBA: الأحمر هو المعدن (الحبر المعدني والرقائق)، والأخضر هو اللمعان (اللامع 1، والساتان 0.7، والمطفأ 0.4، واللمسة الناعمة 0.2)، والأزرق هو الفلورة، والقناة ألفا هي الأبيض المعتم، وكلها مضروبة في درجة الحبر. والمضيف الذي يضيء صفحاته بنفسه، مثل Folio، يقرؤه مباشرة. وكل ما يُطبع فوق حبر معدني أو رقيقة أو حبر فلوري يفرّغه من القناع، والصور بحسب ظلّها، ما لم يُطبع طباعة فوقية؛ أما الأبيض والورنيش فيبقيان كاملين تحت ما يُرسم بعدهما.

```ts
import { renderFinishMask, renderPageToCanvas } from 'postext';

renderPageToCanvas(page, doc, canvas, { scale: 2, finishes: 'sheen' });
const mask = renderFinishMask(page, doc, { scale: 0.5 });   // undefined إن لم تكن هناك أحبار خاصة
```

### في Folio

يضيء Folio الأحبار الخاصة كما يُظهرها الورق تحت مصابيحه. الحبر المعدني والرقائق يعكسان الغرفة كمعدن مصبوغ بلون الحبر، والرقائق تكاد تكون مرآة. والحبر الفلوري يبدو أسطع من الورق. والأبيض المعتم يغطي لون الورق، فيُقرأ على الكرافت أو الورق الملوّن. والورنيش اللامع يلتقط اللمعات حين تنقلب الورقة، والمطفأ يخفّفها، واللمسة الناعمة تزيلها. وتحت الورنيش اللامع يأخذ المطبوع الانعكاس الحاد لطبقة الورنيش بدل لمعة الورق الألين. ولا تأخذ قناعًا إلا الصفحات التي تحمل حبرًا خاصًا، بنصف دقة الصفحة، فيُرسم الكتاب الخالي منها كما كان.

### ما يقوله الفحص قبل الطباعة عن الأحبار

في مهمة طباعة (بمعيار PDF/X، أو CMYK)، يضيف الفحص قبل الطباعة:

- `spotInkFinish` (معلومة): كل حبر خاص تستعمله الصفحات، مع تشطيبه ولمعانه، ليذكرها طلب الطباعة كلها.
- `inkPressOrder` (معلومة): الأحبار البيضاء التي تُطبع أولًا، والورنيشات التي تُطبع أخيرًا.
- `whiteInkOnWhite` (تنبيه): حبر أبيض في صفحة ورقها أبيض أو غير محدد، حيث لا يظهر شيء. اضبط لون الورق (`page.backgroundColor`) على الورق الذي يُطبع عليه.

الحبر الأبيض أو الورنيش لا يثير `overprintWhite` أبدًا: فهما لا يضعان لونًا عن قصد.

## استنتاج التشطيب من الاسم

```ts
import { guessInkFinish } from 'postext';

guessInkFinish('PANTONE 871 C');   // { kind: 'metallic' }
guessInkFinish('Gold foil');       // { kind: 'foil' }
guessInkFinish('Barniz UVI mate'); // { kind: 'varnish', sheen: 'matte' }
guessInkFinish('PANTONE 286 C');   // undefined
```

يقرأ `guessInkFinish(name)` الاسم الذي تعطيه الحبرَ عيّنةٌ أو فصلٌ لوني أو جدولُ أحبار، ويعيد التشطيب الذي يوحي به، أو `undefined`. وهو يعرف كلمات كل تشطيب وكل لمعان في لغات الموقع العشر وفي الأسماء التي تستعملها كتب العيّنات، ويعرف أرقام Pantone: من 801 إلى 814 فلورية، ومن 871 إلى 877 والسلسلتان 8000 و10000 معدنية. وكلمة الورنيش أو الرقائق تُقدَّم على كلمة اللون (`Gold foil` رقائق، و`Barniz oro` ورنيش)، وكلمة الفلورة على الأبيض، والمعدن على الأبيض (`白金`، البلاتين). وتُستثنى الكلمة الفرنسية `or` لأنها أيضًا أداة العطف الإنجليزية؛ ومع ذلك يُقرأ `Or métallisé` معدنيًا بكلمته الثانية.

إنه اقتراح، ولا شيء يطبّقه دون علمك: يعرضه Sandbox زرًّا، وتذكره مهارة النقل في تقريرها.

ويستعمله [مستورد IDML](/ar/docs/indesign) أيضًا، لعيّنة لون خاص لم يسجّل أي تصدير من Postext تشطيبها، ويذكر كل تخمين في تقريره.

## القص بالقالب

القص بالقالب عمل قالب قص من شفرات فولاذية بعد الطباعة: نافذة في غلاف، أو فتحة تخترق كتابًا مقوّى، أو فهرس إبهامي، أو زوايا مستديرة، أو كتاب مقصوص على محيط بيت. تصف الخاصية `dieCuts` قوالب القص في الكتاب؛ ويبتعد النص عن الفتحة في كل صفحة تقصها.

```ts
interface DieCutsConfig {
  shapes?: DieShape[];                 // أشكال القص في الكتاب.
  pages?: DieCutPlacement[];           // أشكال توضع على الصفحات بأرقامها.
  corners?: { radius: Dimension; edges?: 'fore' | 'all' };
  outline?: { d: string; viewBox?: [number, number] };
}
```

### ثلاث طرق لوضع قالب القص

**برقم الصفحة.** يضع `dieCuts.pages` شكلًا على قائمة من الصفحات: `'5'` أو `'3-12'` أو `'3,7,11-13'`. تعدّ الأرقام صفحات الكتاب بحسب موضعها، و1 أول صفحة فيه، لا أرقام الصفحات المطبوعة. وفي الكتاب ذي الفصول العدة تُعدّ من بداية الكتاب، فيقص الفصل الذي يُخرَج وحده الصفحة الصحيحة.

```ts
const config: PostextConfig = {
  dieCuts: {
    shapes: [
      { id: 'window', name: 'Cover window', shape: 'roundRect',
        x: { value: 40, unit: 'mm' }, y: { value: 60, unit: 'mm' },
        width: { value: 70, unit: 'mm' }, height: { value: 45, unit: 'mm' },
        radius: { value: 4, unit: 'mm' } },
      { id: 'tunnel', shape: 'circle',
        x: { value: 55, unit: 'mm' }, y: { value: 90, unit: 'mm' },
        width: { value: 30, unit: 'mm' }, height: { value: 30, unit: 'mm' },
        leaves: 6, wrap: { gap: { value: 4, unit: 'mm' } } },
    ],
    pages: [
      { pages: '1', die: 'window' },
      { pages: '9', die: 'tunnel' },
    ],
    corners: { radius: { value: 5, unit: 'mm' } },
  },
};
```

**حيث يقرر المحتوى.** تقص الحاوية `:::diecut` كل صفحة يقع فيها محتواها، كما يغيّر [`:::paper`](/ar/docs/document-format-directives#paper) نوع الورق. يبدأ محتواها في صفحة جديدة، ويبدأ كل ما يلي سطر الإغلاق `:::` في صفحة جديدة أيضًا. والحاوية داخل أخرى تقص قالبها هي؛ والقالب الذي لا يوجد في `dieCuts.shapes` يُبلَّغ عنه (**شكل قص غير معروف**، `dieCutUnknown`)، وتُنضَّد تلك الصفحات وحدها ولا تُقص. انظر [`:::diecut`](/ar/docs/document-format-directives#diecut).

```md
:::diecut{die=window}
## انظر في الداخل
تؤطّر النافذة صفحة العنوان التي تحتها.
:::
```

**في قالب صفحة.** في الصفحة المركّبة، يضع عنصر زخرفة من النوع `'cut'` فتحة كما يُوضع أي عنصر مسار، مع `when` و`unless` لحصره في الصفحات التي تطلبه. انظر [عناصر القص في قوالب الصفحات](#عناصر-القص-في-قوالب-الصفحات).

### عناصر القص في قوالب الصفحات

عنصر الزخرفة من النوع `'cut'` فتحة يقصها قالب القص في ورقة كل صفحة مركّبة توضع عليها زخرفة القالب: نافذة في قالب غلاف، أو قصّة إبهام في صفحات الافتتاح بكتاب مرجعي. يوضع ويُحدَّد حجمه كما يُوضع [عنصر المسار](/ar/docs/configuration-headers-footers#عناصر-المسار)، مع `when` و`unless` و`parity` و`pin` كأي عنصر زخرفة، ولا يُرسم أبدًا: يُخرجه الإخراج من الزخرفة ويضعه ضمن قصّات الصفحة، معكوسًا على الوجه الآخر للورقة.

```ts
interface DesignCutElement {
  kind: 'cut';
  id: string;
  placement: ElementPlacement;       // موضع الفتحة وإطارها.
  die?: string;                      // شكل من dieCuts.shapes، ممدود على الإطار.
  d?: string;                        // وإلا فبيانات مسار SVG، بوحدات viewBox.
  viewBox?: [number, number];
  preserveAspectRatio?: 'none' | 'meet';
  leaves?: number;                   // الافتراضي: قيمة القالب، وإلا 1.
  wrap?: false | { gap?: Dimension }; // الافتراضي: قيمة القالب، وإلا 3 مم.
  when?: string; unless?: string; parity?: PageParity; pages?: PageRoleFilter; pin?: boolean;
}
```

محيط الفتحة هو شكل القص الذي يسمّيه `die`، ممدودًا على إطار العنصر (يعطي القالب نوعه ونصف قطر زواياه وبيانات مساره و`leaves` و`wrap`، لا إطاره هو)؛ فإن لم يوجد `die` فبيانات المسار `d`؛ فإن لم يوجد أيٌّ منهما فالإطار نفسه. وتُقدَّم `leaves` و`wrap` الخاصتان بالعنصر على قيم القالب.

```ts
decoration: { elements: [
  { kind: 'cut', id: 'window', die: 'window', unless: 'closed',
    placement: { anchor: { to: 'page', edge: 'top-left' },
      offset: { x: { value: 40, unit: 'mm' }, y: { value: 60, unit: 'mm' } },
      size: { width: { value: 70, unit: 'mm' }, height: { value: 45, unit: 'mm' } } } },
] }
```

لا يلتف النص في إطارات الصفحة المركّبة حول الفتحة بعد: ضع الإطارات بعيدًا عنها، واقرأ `dieCutText` في الفحص قبل الطباعة. وفي قالب الصفحتين المتقابلتين لا يُقسَم عنصر القص بين الصفحتين. وبقية [قوالب الصفحات](/ar/docs/configuration-composed-pages#قوالب-الصفحات) في مرجع الإعدادات.

### الأوراق والانعكاس

الفتحة تخترق الورق، فتقص وجهَي الورقة كليهما. الصفحة 1 صفحة فردية (recto)، وظهرها الصفحة 2 هي الصفحة الزوجية (verso) من الورقة نفسها، وهكذا؛ والفصل الذي يبدأ في موضع متأخر من الكتاب يُعدّ من أول صفحة في الكتاب. والشكل الموضوع على صفحة يقص الوجه الآخر من ورقتها أيضًا، معكوسًا حول حدّ القص: النافذة التي تبعد 40 مم عن الحافة اليسرى لصفحة فردية تبعد 40 مم عن الحافة اليمنى للصفحة الزوجية خلفها. ومع `leaves: 6` تمضي الفتحة عبر الأوراق الخمس التالية أيضًا، في الموضع نفسه من الرزمة، فتقع حيث وضعتها في كل صفحة من ذلك الوجه، ومعكوسة في كل صفحة من الوجه الآخر.

### الزوايا المستديرة والكتب بأشكال مقصوصة

يدوّر `corners` زوايا كل ورقة: افتراضيًا زوايا الحافة الأمامية وحدها (اليمنى في الصفحة الفردية، واليسرى في الزوجية، وبالعكس في الكتاب المجلّد من اليمين)، ويبقى الكعب قائمًا؛ و`edges: 'all'` يدوّر الزوايا الأربع. أما `outline` فيقص كل ورقة على محيط: بيانات مسار SVG بوحدات `viewBox`، ممدودة على حدّ القص في الصفحة الفردية ومعكوسة في الزوجية. وإذا ضُبط الاثنان قُدِّم المحيط.

```ts
dieCuts: {
  outline: { d: 'M0 0.35 L0.5 0 L1 0.35 L1 1 L0 1 Z', viewBox: [1, 1] },   // بيت
}
```

### النص حول الفتحة

كل فتحة، بعد توسيعها بمسافة `wrap.gap`، عائق يلتف النص حوله على وجهَي كل ورقة تقصها، في الصفحات المتدفقة: تقصر الأسطر بجانبها كما تقصر بجانب صورة يلتف حولها النص. والشكل الذي له `wrap: false` يترك النص في مكانه، وكل ما يقع تحت الفتحة يُقص معها.

### خط القص في ملف PDF

يعمل صانع القوالب انطلاقًا من خط القص: محيط كل فتحة، ومحيط الورقة إذا كانت مقصوصة على شكل أو مستديرة الزوايا، على لوح لا تحبّره الآلة أبدًا. ويضبطه `print.dieLine`.

```ts
interface PrintDieLineConfig {
  output?: 'page' | 'none';   // 'page' (الافتراضي): يُرسم في كل صفحة فيها قص.
  ink?: string;               // اسم اللوح. الافتراضي 'Die'.
  cmyk?: CmykPercent;         // بديل اللوح، أي كيف تعرضه البروفات. الافتراضي ماجنتا 100 %.
  width?: Dimension;          // سماكة الخط. الافتراضي 0.25 نقطة.
}
```

يُرسم الخط بعد علامات القص على لوح `Separation` خاص به، بنهايات ووصلات مستديرة، ويُطبع طباعة فوقية، فلا يفرّغ خطًّا أبيض في الألواح التي تحته أبدًا. وهو في ملف PDF الموسوم عنصر زخرفي (artifact). وخارج PDF/X-1a، الذي لا يسمح بالمحتوى الاختياري، يقع في مجموعة محتوى اختياري اسمها **Die line** يستطيع القارئ إخفاءها. ويُدرج اللوح مع أحبار المهمة (يضعه `inspectPrintPdf` في `color.spots`)، ولا تُسقطه مهمة [`print.plates`](/ar/docs/configuration-pdf-output#الطباعة-بحبرين) على ألواحها أبدًا. واسأل صانع القوالب عن الاسم الذي ينبغي أن يحمله اللوح: فكلها مستعملة، `Die` و`CutContour` و`Dieline` و`Troquel`.

تُطبع الصفحة نفسها كاملة: لا يقص ملف PDF الفتحة. وكل ما يقع داخلها يُطبع ثم يُنزع مع الورق.

```ts
print: {
  standard: 'pdfx4',
  dieLine: { ink: 'CutContour', width: { value: 0.5, unit: 'pt' } },
},
```

في سطر الأوامر، يتجاوز `postext pdf --die-line page|none` قيمة `output` لتشغيل واحد (انظر [`pdf`](/ar/docs/command-line#pdf)).

في InDesign، خط القص طبقة. يضع [تصدير IDML](/ar/docs/indesign) الفتحات والحواف المشكّلة على طبقة مقفلة اسمها **Die line**، محدّدة بعيّنة القص ومضبوطة على الطباعة الفوقية، ويقرأ المستورد طبقة كهذه، أو المسارات المحدّدة بعيّنة `CutContour` أو `Die` أو `Dieline` أو `Troquel`، ويعيدها `dieCuts`.

## في العارضات

**Canvas.** يقص `renderPageToCanvas` كل فتحة من الصفحة، والورق الواقع خارج الورقة المقصوصة على شكل أو المستديرة الزوايا، فتُظهر ما خلف اللوحة. ومع الخيار `beneath`، وهو دالة تعيد اللوحة المرسومة لأي صفحة بحسب فهرسها، يرسم في كل فتحة الصفحات التي يراها القارئ من خلالها، إلى العمق الذي تتطابق فيه الفتحات: كل صفحة مقصوصة بفتحات كل الصفحات التي فوقها، وظل خفيف على طول كل حافة قص وخط رفيع لجدار الورق، ورمادي كرتوني داكن بعد نهاية الكتاب (يغيّره الخيار `background` في `composeThrough`). ويرسم `composeThrough(doc, pageIndex, source, target, scale)` التركيب نفسه على لوحة من عندك.

```ts
import { renderPageToCanvas } from 'postext';

const painted = new Map<number, HTMLCanvasElement>();   // الصفحات المرسومة من قبل، بحسب الفهرس
renderPageToCanvas(doc.pages[0]!, doc, canvas, { scale: 2, beneath: (i) => painted.get(i) });
```

**عارض HTML.** تُقص الصفحة التي فيها قص بـ`clip-path: path(evenodd, …)`، أي مربع النزف (أو محيط الورقة) ناقصًا فتحاته. وعلى ورقة الطباعة ترسم الصفحة المركّبة في كل فتحة الصفحات التي تحتها، إلى العمق الذي تتطابق فيه الفتحات، مع ظل خفيف وخط رفيع لجدار الورق على طول كل حافة قص؛ وهذه النسخ مخفية عن قارئات الشاشة ولا تستقبل النقرات. وفي تخطيط الشاشة لا تكون الصفحات صفحات الطباعة، فتُظهر الفتحة هناك خلفية العارض.

**Folio.** يعرض Folio الفتحة كما تبدو في اليد. في الصفحة المفتوحة تُظهر الفتحة الصفحات التي تحتها، إلى العمق الذي تتطابق فيه الفتحات (قد يُظهر الكتاب النفقي صفحة على عمق عشرين ورقة)، مع جدران الورق عند القص واختلاف منظر يتبع زاوية الرؤية. والورقة التي تنقلب فيها فتحة حقيقية، وتسقط الظلال عبرها على الصفحة التي تحتها. وتبقى الفتحة مفتوحة طوال قلب الورقة وبعد أن تستقر، في الغلاف وفي الورقة المقوّاة أيضًا. وبعد نهاية الكتاب تُظهر الفتحة كرتون الغلاف؛ أما الكتاب الذي لا غلاف مقوّى له، وأغلفته صفحاته المطبوعة نفسها (`covers`) أو المؤلف من أفرخ مطوية (`binding.type: 'folded'`)، فتُظهر فيه المكتب، ويسقط الضوء عبرها عليه. وتُقص الزوايا المستديرة والمحيط المقصوص في كل ورقة.

**عارضك الخاص.** تحمل كل صفحة مُخرَجة قصّاتها في `VDTPage.dieCut`: ‏`holes` و`outline` مسارات بوحدات بكسل الصفحة، و`sources` (قالب كل فتحة) و`wrapGapPx`. ويقول `leafSide(doc, i)` هل الصفحة فردية أم زوجية، و`pageBeneath(doc, i)` أي صفحة تقع تحتها (`-1` بعد نهاية الكتاب)، و`seeThrough(doc, i)` الرزمة كلها التي تُظهرها الفتحة مع قص كل طبقة، ويحوّل `dieCutPath2D(cut)` القص إلى `Path2D`.

## في Sandbox

- **الألوان.** في تبويب **خاص** من منتقي الألوان حقلا **التشطيب** و**اللمعان**، ويعرض التشطيب الذي يوحي به اسم الحبر (**تعيين التشطيب: …**). وتضيف قائمة **إضافة حبر خاص** في لوحة الألوان حبرًا جاهزًا: ذهبي أو فضي أو نحاسي معدني، ورقائق ذهبية أو فضية، وأربعة أحبار فلورية، وأبيض معتم، وورنيش لامع أو مطفأ أو ناعم الملمس.
- **جدول الأحبار.** لكل حبر **التشطيب** و**اللمعان**، وتعرض **الأحبار التي تستعملها الألوان** تشطيب كل منها.
- **القص.** يضم **التصميم › الصفحة والأعمدة › القص** أشكال القص، ولكل منها رسم لمحيطه، والصفحات التي تقصها، والزوايا المستديرة، ومحيط الكتاب المقصوص على شكل. ويضبط **التصميم › التصدير › التجهيز للطباعة › خط القص** اللوح. ولزخرفة قالب الصفحة زر **إضافة فتحة قص**، وتختار بطاقتها شكل القص أو بيانات مسار، وتضبط عدد الأوراق ومسافة النص والإطار والموضع.
- **Canvas.** في الكتاب الذي فيه قص يحمل شريط الأدوات **خطوط القص**، الذي يرسم كل قالب خطًّا متقطعًا فوق الصفحة؛ وفي الكتاب الذي فيه أحبار خاصة يحمل **الأحبار الخاصة**، الذي يتنقل بين *مسطحة* و*مع اللمعان* و*خريطة التشطيب*. ويحفظ المتصفح الاثنين. وتُظهر الفتحة الصفحات التي تحتها، إلى العمق الذي تتطابق فيه الفتحات؛ وإذا غيّرت صفحة أبعد منها، أُعيد رسم الصفحات التي تطل عليها.
- **الفحوص.** تظهر نتائج الفحص قبل الطباعة المذكورة أعلاه في **الفحوص** بعناوينها: **حبر خاص**، و**ترتيب طباعة الأحبار الخاصة**، و**حبر أبيض على ورق أبيض**، و**نص تحت القص**، و**قص قريب من حافة القطع**، و**قص في هامش التجليد**، و**شكل قص غير معروف**.

تصف [التصميم والفحوص](/ar/docs/sandbox-design-checks) و[المعاينات](/ar/docs/sandbox-previews#تبويب-canvas) اللوحات كاملة.

## الحدود

- قناع التشطيب لا يرى كل شيء. الصيغة الرياضية المرسومة صورةً بحبر خاص تُفرِّغ بدل أن تُظهر حبرها، ونقاط التدرج بالأحبار الخاصة لا تدخل القناع، وملف SVG الذي يستعمل حبر ورنيش يظل يرسم قيمته `hex` على الشاشة ما لم يُعَد تلوينه. والحبر الأبيض الذي قيمته `hex` على الشاشة `#ffffff` بالضبط لا يمكن تمييزه من الورقة: أعطه قيمة أغمق قليلًا.
- النص داخل إطارات الصفحة المركّبة لا يلتف حول الفتحة بعد: النص المتدفق وحده يفعل. افحص الصفحات المركّبة بـ`dieCutText`.
- عنصر القص في قالب الصفحتين المتقابلتين لا يُقسَم بين الصفحتين.
- يرسم عارض HTML الصفحات التي تحت الفتحة في الصفحات المركّبة على ورقة الطباعة وحدها. وفي Folio تبقى حواف كتلة الصفحات مربعة تحت زوايا الصفحات المستديرة.
- حين يعرض Sandbox فصلًا واحدًا، تُظهر الفتحة في آخر أوراق الفصل اللوح الخلفي بدل الفصل التالي: انتقل إلى الكتاب كله لتراه.
- يطبع ملف PDF الصفحة كاملة ويرسم خط القص: الفتحة عمل صانع القوالب.
