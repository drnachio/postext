# Configuració: còmics


## Còmics

La propietat `comics` configura les pàgines de còmic (`:::page`), les tires (`:::strip`) i les dobles pàgines: el marc i els carrers de què es tallen les vinyetes, els estils de vinyeta, la retolació, els estils de bafarada i el repartiment. Només la llegeixen els documents amb còmics; un document sense còmics es compon exactament igual que abans, i un document amb còmics i sense secció `comics` pren els valors per defecte de la seva llengua. El marcatge i la manera com es retolen les pàgines s'expliquen a [Còmics](/ca/docs/comics).

```ts
const config: PostextConfig = {
  comics: {
    readingDirection: 'auto',
    gutter: { horizontal: { value: 5, unit: 'mm' }, vertical: { value: 2.5, unit: 'mm' } },
    panel: { borderWidth: { value: 0.8, unit: 'pt' }, borderStyle: 'rough' },
    panelStyles: [{ id: 'night', background: { hex: '#14142b', model: 'hex' }, borderColor: { hex: '#ffffff', model: 'hex' } }],
    lettering: { fontSize: { value: 8.5, unit: 'pt' }, textTransform: 'uppercase' },
    balloonStyles: [{ id: 'eerie', shape: 'wavy', italic: true }],
    cast: [{ id: 'maya', name: 'Maya' }, { id: 'tomas', name: 'Avi Tomàs' }],
  },
};
```

### Estils de bafarada

Cada entrada de `comics.balloonStyles` es posa per sobre de l'estil integrat del mateix id (`speech`, `thought`, `whisper`, `shout`, `radio`, `caption`, `inner`, `note`, `sfx`), o per sobre de `speech` si l'id és nou. Els valors per defecte de sota són els de `speech`; la [pàgina Còmics](/ca/docs/comics#estils-de-bafarada) explica què canvia cada estil integrat. Les longituds en `em` són relatives al cos del text de la bafarada.
