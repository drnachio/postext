# الإعدادات: الإطارات


## أنماط الإطارات

تُعرِّف الخاصية `calloutStyles` أنماط الإطارات (callouts) المسمّاة التي يطبّقها المستند بالحاوية `:::callout{type="…"}`: الملاحظات والنصائح والتحذيرات وأهداف التعلّم، وكل محتوى يُفصل عن النص الجاري في إطار ملوّن الخلفية أو محاط بحدّ. يأتي افتراضيًا نمط محايد واحد هو `note` (خلفية رمادية فاتحة، بلا حدّ ولا شريط على حافته (stripe) ولا أيقونة ولا عنوان)، فتعمل `:::callout` دون أي إعداد؛ وتعريف `calloutStyles` يستبدل هذه القائمة الافتراضية.

```ts
const config: PostextConfig = {
  calloutStyles: [
    { id: 'note', name: 'Note' },
    {
      id: 'objectives',
      name: 'Learning objectives',
      title: 'Objectives',
      stripe: { enabled: true, side: 'left' },
      icon: { kind: 'glyph', glyph: '✓' },
      titleStyle: { textTransform: 'uppercase' },
      lists: { bulletChar: '–' },
    },
    {
      id: 'warning',
      title: 'Warning',
      backgroundEnabled: false,
      border: { enabled: true, color: { hex: '#AA0000', model: 'hex' }, width: { value: 1, unit: 'pt' } },
      borderRadius: { value: 1, unit: 'mm' },
      titleStyle: { color: { hex: '#AA0000', model: 'hex' } },
    },
  ],
};
```

```md
:::callout{type="objectives"}
- Describe the parts of the lantern.
- Trim the wick at dusk.
:::

:::callout{type="warning" title="Do not touch the lens"}
The glass stays hot for an hour after the flame is out.
:::
```

### الزوايا والجوانب والألسنة الموصولة

لا يلزم أن يكون الإطار مستطيلًا بأربع زوايا متساوية وحدّ واحد. فمنذ postext 1.48 يستطيع النمط أن يدوّر بعض الزوايا دون بعض، وأن يرسم حدّه على بعض الجوانب وحدها، وأن يُخرج لسانه من الإطار شكلًا واحدًا: بطاقة كتاب مدرسي لسانُ عنوانها ومتنُها محيطٌ واحد، يرسمه النمط بدل أن يُرسم في صورة خلف الصفحة.

```ts
calloutStyles: [
  // Rounded at the top only, a rule over the box and a heavier foot.
  { id: 'ficha', background: { model: 'hex', hex: '#fff4d6' },
    borderRadius: { topLeft: { value: 3, unit: 'mm' }, topRight: { value: 3, unit: 'mm' } },
    border: { enabled: false, color: { model: 'hex', hex: '#c58b00' }, width: { value: 0.75, unit: 'pt' },
      sides: { top: { enabled: true }, bottom: { enabled: true, width: { value: 2, unit: 'pt' } } } } },
  // A card whose tab grows out of its top edge.
  { id: 'tarjeta', background: { model: 'hex', hex: '#ffffff' }, borderRadius: { value: 3, unit: 'mm' },
    border: { enabled: true, color: { model: 'hex', hex: '#2a6f97' }, width: { value: 1, unit: 'pt' } },
    label: { position: 'top-left', inset: { value: 4, unit: 'mm' }, joined: true, fillet: { value: 2, unit: 'mm' },
      color: { model: 'hex', hex: '#2a6f97' } } },
]
```

- **الزوايا.** `borderRadius` طول واحد للزوايا الأربع، أو `{ topLeft, topRight, bottomRight, bottomLeft }`. والزاوية التي لا يذكرها الكائن قائمة. والزوايا زوايا الورقة. ولا تأخذ زاويتان أبدًا أكثر من الجانب الذي بينهما؛ فتتنازل كل منهما بالتناسب.
- **الجوانب.** تأخذ `border.sides.top` و`right` و`bottom` و`left` القيم `enabled` و`color` و`width`، وكل حقل لا يُذكر يؤخذ من الحدّ كله. والإطار الذي له حدّ في أعلاه وحده هو `border: { enabled: false, sides: { top: { enabled: true } } }`، أو `enabled: true` مع إطفاء الجوانب الثلاثة الأخرى. وتتبع الحافة الداخلية لكل جانب عرضَه، فتنحني الزاوية المستديرة بين جانب رفيع وجانب سميك كما ترسمها CSS.
- **اللسان الموصول.** مع `label.joined: true` يكون اللسان والإطار محيطًا واحدًا، وتعبئة واحدة (`background` الإطار؛ ولا تُرسم `background` اللسان نفسه)، وحدًّا واحدًا يدور حول اللسان. ويقف اللسان على الحافة، خارج الإطار بقدر ارتفاعه: ويجب أن يكون `offset` الخاص به `0` (وأي قيمة أخرى تُذكر بالتحذير `unknownConfigValue` وتُقرأ `0`). وتأخذ زواياه الخارجية نصف قطر زاوية الإطار التي يلتصق بها، وتُدوَّر الزوايا الداخلية حيث يلتقي بالإطار بمقدار `fillet` (الافتراضي: نصف القطر نفسه). واللسان المحاذي لجانب الإطار تمامًا (`inset` أقل من نصف بكسل) يصعد مستقيمًا من ذلك الجانب. وأعطِ الكلمات لونًا يُقرأ على تعبئة الإطار (`label.color`)، لأن اللسان لم تعد له تعبئة خاصة به. ومع `label.ownBackground: true` يُلوَّن اللسان الموصول بـ`background` التسمية نفسها، فوق تعبئة الإطار وتحت الحدّ، فيقف لسان أبيض على إطار ملوّن، أو لسان ملوّن على إطار بلا تعبئة.
- **زوايا اللسان.** يمنح `label.borderRadius` اللسانَ زوايا خاصة به: طولًا واحدًا، أو `{ topLeft, topRight, bottomRight, bottomLeft }` على زوايا الصفحة، كما في `borderRadius` الإطار. اللسان المنفصل عن الإطار مربّع الزوايا ما لم تُحدَّد. واللسان الموصول يدوّر بها زاويتيه الخارجيتين (`topLeft` و`topRight` للسان في الأعلى، و`bottomLeft` و`bottomRight` في الأسفل)؛ وإن لم تُحدَّد أخذتا نصف قطر زاوية الإطار. وتبقى الوصلات على `fillet` في الحالتين.
- **الألسنة السفلية.** يعلّق `position: 'bottom-right'` أو `'bottom-left'` أو `'bottom-start'` أو `'bottom-end'` اللسان من أسفل الإطار، عاديًّا أو موصولًا: فهو اللسان العلوي مقلوبًا، على بعد `offset` تحت الأسفل، و`rule` على طول الأسفل. ولا ألسنة جانبية: فكلمات اللسان تجري أفقيًّا.

ترسم كل المخرجات هذه الأشكال: Canvas وPDF محيطاتٍ متجهية، وعارض HTML وEPUB ذو التخطيط الثابت بـCSS لكل زاوية ولكل جانب. ويكتب EPUB القابل لإعادة التدفق الزوايا والجوانب في CSS الخاص به، ويضع اللسان الموصول لسانًا عاديًّا. ويعيد `look.border.color` في إطار الصفحة المركّبة تلوين كل الجوانب، وتعيد لوحة ألوان الجزء تلوين كل جانب منها. والنمط الذي تتشابه كل زواياه وجوانبه يُنضَّد كما كان من قبل.

### أنماط مبنية على غيرها

تحدّد `extends` نمطًا آخر من `calloutStyles`، وكل حقل يتركه النمط دون قيمة يأخذه منه. وتُدمج الكائنات مثل `padding` و`border` و`titleStyle` و`fixed` مفتاحًا مفتاحًا، فيستطيع النمط أن يغيّر جانبًا واحدًا من الحشوة أو `fixed.offset` وحده؛ ويؤخذ اللون أو الطول كاملًا؛ ولا يُورث `id` ولا `name`. ويمكن أن يُبنى النمط الأب بدوره على نمط آخر. والكتاب الذي تقع إطاراته في مواضع كثيرة يحتفظ بنمط واحد لمظهرها وبنمط صغير لكل موضع:

```ts
calloutStyles: [
  {
    id: 'caja',
    background: { model: 'hex', hex: '#dff0fa' },
    padding: { top: { value: 3, unit: 'mm' }, right: { value: 4, unit: 'mm' }, bottom: { value: 3, unit: 'mm' }, left: { value: 4, unit: 'mm' } },
  },
  { id: 'caja-p5', extends: 'caja', placement: 'fixed', fixed: { offset: { x: { value: 12, unit: 'mm' }, y: { value: -40, unit: 'mm' } } } },
  { id: 'caja-p9', extends: 'caja', placement: 'fixed', fixed: { anchor: { to: 'container', edge: 'top-right' } } },
]
```

غيّر مظهر `caja` فتتبعه الإطارات كلها، كلٌّ في موضعه. وإذا لم تشر `extends` إلى أي نمط موجود ظهر التحذير `calloutStyleExtendsUnknown` (يقترح التحذير أقرب معرّف، ويبقى النمط وحده بالقيم المدمجة)، وإذا بُنيت أنماط بعضها على بعض في حلقة ظهر التحذير `calloutStyleExtendsCycle` (تبقى وحدها حتى يُبنى أحدها على نمط من خارج الحلقة). وفي Sandbox يضبطه حقل **مبني على** في نمط الإطار؛ وحذف نمط تُبنى عليه أنماط أخرى يكتب إعداداته فيها، فلا تتغير إطاراتها. وفي قسم **مكتبة أنماط الإطارات**، يُبقي الدمج مع **مقارنة المظهر وحده** النمطَ الذي تقع إطاراته في موضع آخر نمطًا صغيرًا من هذا النوع إذا كان **إبقاء كل إطار في موضعه** مفعّلًا (وهو الافتراضي)، فلا يتحرك أي إطار. منذ postext 1.39.

### الحاوية `:::callout`

يفتح السطرُ `:::callout{type="<id>"}` الإطار، ويغلقه سطر فيه `:::` وحدها. يقبل سطر الفتح خمس سمات: `type` (معرّف النمط)، و`title` (يتجاوز عنوان النمط)، و`span` و`placement` و`columns` (تتجاوز قيم النمط)؛ ويُخرَج المحتوى الواقع بينهما داخل الإطار: عنوان اختياري، ثم الفقرات أو القوائم أو الاقتباسات الكتلية أو الصيغ أو الموارد المضمّنة، وكلٌّ منها يُنضَّد بتنسيق `body` / `lists` من النمط (وتحتفظ العناوين بأنماطها المعتادة). تندمج الهوامش بين العناصر الأبناء كما في النص الجاري؛ ويخرج داخل الإطار عن شبكة خطوط الأساس، ثم يعود التدفق إليها بعد الإطار بمسافة لا تقل عن `marginBottom` تحته (الأولوية للشبكة، والهامش حدّ أدنى، وهو العرف نفسه الذي تتبعه الموارد). أما النمط ذو `snapToGrid: false` فيحتفظ بقيمة `marginBottom` الدقيقة بدلًا من ذلك، ويبقى النص الذي يلي الإطار خارج الشبكة حتى العنوان التالي أو نهاية القائمة. والعنوان الذي يسبق الإطار مباشرةً يبقى معه.

حدود هذا الإصدار:

- يُبقى الإطار كاملًا ما لم يحدّد نمطه `keepTogether: false`. فإن لم تتسع له المساحة المتبقية في العمود انتقل كاملًا إلى العمود أو الصفحة التالية، وكذلك يخرج من عمود فارغ قصّرته نطاقات العناصر العائمة أو حدّ أقصى للنطاق (band cap)، ما دام عمود كامل يتسع له. أما الإطار الأطول من عمود كامل فيُقسم بدلًا من ذلك، كالإطار القابل للتقسيم؛ ولا يوضع رغم ذلك متجاوزًا حدود العمود إلا الإطار الذي لا يقسمه أي قطع (شكل أو جدول أطول من العمود، أو `splitMinLines` لا يحقّقه أي قطع)؛ وعندئذ يسجّل الإخراج التحذير `calloutOverflow` (`VDTDocument.warnings`) يعرضه Sandbox. ومجموعة `:::columns` تُقطع كالإطار الذي يحيط بها، بين أعمدتها الفرعية (منذ postext 1.25)؛ ولا تبقى كاملة، فتتجاوز الحدود بالطريقة نفسها، إلا مع `layout.flowColumns: false` أو داخل إطار متداخل. والإطار القابل للتقسيم يترك الجزء الذي يتسع (عناصر أبناء كاملة، أو أسطر فقرة بما لا يقل عن `splitMinLines` على كل جانب، ويكفي الشكل أو الجدول أو الصيغة المنفصلة وحده لجانب) ثم يستمر في إطار بلا أيقونة في العمود أو الصفحة التالية، بلا عنوان ما لم يكرّره النمط، ومع علامة اختيارية تحت الجزء الذي يتركه (انظر [علامات الإطار المقسوم](#علامات-الإطار-المقسوم)).
- تُفسح العناصر العائمة المجال للإطار غير القابل للتقسيم. فحين تكون الكتلة التي تلي الإشارة إلى شكل مباشرةً إطارًا `keepTogether`، لا تُؤخذ الخانة التي لا تترك للإطار عمودًا من النطاق الحالي يستقر فيه (العمود الذي يحوي الإشارة أو عمود فارغ بعده، وكان يتسع له قبل العنصر العائم): ينتقل الشكل إلى خانته التالية، وهي عادةً الصفحة التالية، ويبقى الإطار في التدفق، كما يضعه المنضِّد، بدلًا من دفع الإطار خارج الصفحة وترك العمود للشكل وحده.
- في التخطيط متعدد الأعمدة يجعل `span: 'page'` الإطارَ **كتلة ممتدة** (span block): يُخرَج بكامل عرض المحتوى ويقسم الصفحة إلى نطاقات أعمدة، فتُغلق أعمدة النص فوقه عند خط القطع، ويأخذ الإطار عمودًا خاصًا به بكامل العرض، ويُفتح تحته نطاق جديد من أعمدة النص، فيستمر التدفق تحت الإطار في كل الأعمدة. وحيث تكون الأعمدة *مستوية* (في أعلى الصفحة، أو مباشرةً تحت عنوان افتتاحي `span: 'page'`، أو مباشرةً تحت كتلة ممتدة أخرى، أو مباشرةً تحت نطاق عائم علوي) يقطع الإطار هناك ببساطة. أما إذا ورد في منتصف الصفحة والأعمدة غير متساوية، فيُوضع كما يضعه المنضِّد: يُقطع النص فوقه قطعًا مستويًا عبر كل الأعمدة (يعيد المحرّك تنفيذ التوزيع وقد قُصّرت أعمدة النطاق إلى العدد نفسه من أسطر الشبكة، فينتقل النص من عمود إلى عمود على نحو طبيعي وتظل كل قواعد الأسطر اليتيمة والأرامل والإبقاء مع التالي سارية)، ويمتد الإطار على الصفحة، وتُستأنف الأعمدة تحته. ويتطلب القطع جولتين إضافيتين من التوزيع؛ وحين لا يترك خط القطع متسعًا للإطار مع الحدّ الأدنى من أسطر النص تحته الذي تفرضه قاعدة الأسطر الأرامل، أو لا يتسع أي ترتيب بعد بضع محاولات، ينتقل الإطار إلى أعلى الصفحة التالية. ويلتزم النص فوقه بالقطع: الفقرة التي لا يمكن أن تبدأ في الأسطر القليلة التي يحتفظ بها عمود تحت شكل فوق القطع تنتقل إلى العمود التالي (فيقف الشكل وحده في عموده)، وحين تظل كتلة ما تتجاوز القطع، يُؤخذ القطع أدنى بسطر بدلًا من موضع انتهاء تلك الكتلة. والإطار المقسوم الذي يفتح النطاق يُقطع هناك أيضًا، فلا تتجاوز بقيته القطع أبدًا. ومع `headings.balancing.beforeSpan` (القيمة الافتراضية) يُقطع النطاق الذي يتركه خلفه قطعًا مستويًا، كالنطاق الذي يختم الفصل، وحين يسمح النمط بالتقسيم (`keepTogether: false`) يختم جزءُ الإطار الذي يتسع تحت الأعمدة المسوّاة الصفحةَ ويفتح الباقي الصفحة التالية؛ ومع `beforeSpan: false` تُوازن الصفحة التي يتركها كالمعتاد، دون فرض فاصل صفحة. والعنوان الذي يسبق الكتلة الممتدة مباشرةً لا ينتقل معها. وفي التخطيطات أحادية العمود يكون `span: 'page'` ببساطة داخل التدفق.
- `placement: 'fixed'` يُخرج الإطار من التدفق: يُخرَج الإطار (`width: 'auto'` يضيق على قدر العنوان، و`'fill'` يأخذ عرض عمود النص تحت نقطة الإرساء) ويُثبَّت في الصفحة التي يرد فيها ضمن التدفق، في الموضع الذي يصفه `fixed.anchor` / `fixed.offset`، وهو افتراضيًا الزاوية السفلية اليسرى من منطقة المحتوى. وتتخلى أعمدة النص التي يغطيها عن تلك المنطقة (تُقطع من الأسفل، أو من الأعلى إن كان العمود لا يزال فارغًا)، تمامًا كنطاق العناصر العائمة؛ وحين تكون المنطقة مشغولة بنص أو عنصر عائم أو كتلة ممتدة، ينتقل الإطار إلى الصفحة التالية. والإطار الثابت الذي يختم الفصل (أي تكون الكتلة التالية صفحة افتتاح فصل، أو `:::part`، أو إطارًا حاجزًا للعناصر العائمة، أو نهاية المستند) يسوّي أولًا الأعمدة فوقه (`headings.balancing.trailing`)، فتنتهي الصفحة الختامية القصيرة مستويةً مع الشارة تحتها. ويقع الإطار وأبناؤه في `page.floats` ويُرسمون خارج قصّ الأعمدة في كل مُخرِج.
- `placement: 'top' | 'bottom'` **يجعل الإطار يطفو** كما يطفو المورد: يغادر التدفق حيث يرد ويأخذ أول نطاق حرّ بعد تلك النقطة (قدم الصفحة الحالية مع `'bottom'`، أو رأس الصفحة التالية التي يفتحها التدفق أو قدمها) بعرض العمود (`span: 'column'`) أو بكامل عرض المحتوى (`span: 'page'`)؛ ويملأ النص الذي يليه الصفحة التي غادرها. ويذهب إطاره وأبناؤه إلى `page.floats`، كما في الإطار الثابت. والإطار العائم الذي يتصدّر صفحة جديدة يوضع قبل الأشكال المنتظرة لتلك الصفحة، والشكل المذكور في صفحة سابقة الذي يتسع بعدئذ تحته يأخذ بقية تلك الصفحة حتى لو بقي أقل من ثلاثة أسطر نص (صفحة معرض: إطار وشكل، بلا نص بينهما). والإطار `span: 'side'` لا يطفو أبدًا: يتراصّ بجانب النص أيًّا كان موضعه. ومع `columns` أكبر من 1 (في النمط أو سمةً في سطر الفتح، منذ postext 1.18) يشغل الإطار `span: 'column'` هذا العدد من الأعمدة المتجاورة: رأس سلسلة من الأعمدة الفارغة التي تبدأ على مستوى واحد، أو أسفل العمود الحالي والأعمدة الفارغة التي تليه، كما في `:::callout{placement="top" columns="2"}`.
- `width: 'auto'` يضيق على قدر العنوان فقط، ويتجاهل العناصر الأبناء.
- `:::callout` المتداخل داخل إطار آخر إطار مستقل: يُخرَج بنمطه الخاص (الخلفية، والحدّ، ونصف قطر الزوايا، والحشوة، والشريط، والعنوان، والأيقونة، والعلامة، واللسان، والتنسيق الطباعي) بكامل العرض الداخلي لأبيه ويتراصّ عنصرًا ابنًا واحدًا فيه، وتندمج `marginTop` / `marginBottom` الخاصة به مع جيرانه. ويُتجاهل `span` و`placement` الخاصان به (من سطر الفتح أو من النمط)، فالإطار المتداخل يجري دائمًا داخل أبيه، ويُتجاهل كذلك `floatBarrier` و`snapToGrid`. وتتداخل الإطارات إلى أي عمق، ويمكن أن تقع داخل مجموعة `:::columns` (كلٌّ منها كاملًا في عمود واحد). وحين ينقسم الأب، يقع القطع قبل الإطار المتداخل أو بعده، أو داخله إن سمح النمط المتداخل بالتقسيم؛ ويعيد كل جزء رسم الإطارات التي يقطعها، والإطار المتداخل المستمر من الجزء السابق يُسقط عنوانه وأيقونته، كتتمة الإطار في المستوى الأعلى.
- مجموعة `:::columns{count=N}` … `:::` بين العناصر الأبناء تُخرج تلك العناصر في `N` أعمدة متساوية العرض، يفصل بينها `columnGap`، داخل الإطار: تُقطع السلسلة عند حدود الكتل أو الأسطر التي تسوّي الأعمدة على أفضل وجه (الفقرة أو عنصر القائمة المقطوع في منتصفه يستمر في رأس العمود التالي بلا نقطة تعداده)، ويبدأ كل عمود من أعلى المجموعة ويكون ارتفاع المجموعة بارتفاع أطول أعمدتها؛ وتعود العناصر التي تليها إلى كامل العرض. والإطار الذي ينقسم (`keepTogether: false`، أو الأطول من عمود) يقطع داخل المجموعة أيضًا، بين أعمدتها: فالمجموعة المتعرّجة (`snake`) تملأ أعمدتها واحدًا بعد آخر وتستمر في الجزء التالي، والمتوازية (`breaks`) تستمر تيارًا تيارًا (منذ postext 1.25؛ انظر [صيغة المستند › `:::columns`](/ar/docs/document-format-directives#columns)). وتحلّ `gap` في سطر الفتح محلّ `columnGap` لتلك المجموعة، وترسم `rule` خطًا على طول كل فاصل بين الأعمدة. استخدمها لملخّص من عمودين للنقاط الرئيسية، أو لوضع جداول إطار عريض جنبًا إلى جنب.
- السمة السادسة في سطر الفتح، `label`، تُطبع على لسان التسمية في النمط (انظر `label` أعلاه): `:::callout{type="box" label="BOX 1-1" title="The octet rule"}`؛ ومن دون `label` في النمط تُتجاهل السمة.

في VDT يكون الإطار كتلة إطار `type: 'callout'` تقع زخرفته (الخلفية، والشريط، والأيقونة، والعنوان) في `designOverlay`، تليها كتلها الأبناء في العمود نفسه؛ وللإطار ولكل ابن `containerId` الخاص بسطر الفتح. والإطار المتداخل كتلة إطار `type: 'callout'` مستقلة بين الأبناء، تليها كتلها؛ وهي تحتفظ بـ`containerId` الخاص بإطار المستوى الأعلى (فيظل التوزيع والموازنة يريان وحدة واحدة) وتضيف `calloutPath`، أي معرّفات الحاويات المتداخلة المحيطة بها، من الخارج إلى الداخل (ومعرّف الإطار المتداخل نفسه هو آخر مدخل). ويعطي ملف PDF الموسوم كل إطار متداخل عنصر `Div` داخل عنصر أبيه. وتُحلّ صور الأيقونات كما تُحلّ صور الموارد: سجلّ الصور في Canvas، والخيار `resourceImageUrl` في HTML، ومزوّد `resourceBytes` في PDF.

```ts
const resolved = resolveCalloutStylesConfig(config.calloutStyles, resolvedBodyText, resolvedHeadings, resolvedUnorderedLists, config.locale);
// => every inherited field filled from the resolved sections; the optional
//    locale picks the language of the continuation strings

const minimal  = stripCalloutStylesDefaults(config.calloutStyles);
// => undefined for the built-in `note` default; static defaults dropped
```

### التنسيق الطباعي داخل الإطار

ينضّد الإطار محتواه بتنسيق `body` و`lists` الخاص به؛ وكل ما عدا ذلك يحتفظ بأنماط المستند:

- **الفقرات** تأخذ `body` الخاص بالإطار: الخط، والحجم، وتباعد الأسطر، واللون، وألوان التوكيد، والأوزان، و`italic`، و`smallCaps`، والمحاذاة، وتقسيم الكلمات بالواصلة، والإزاحة البادئة، والتباعد بين الفقرات. والحقل الذي لم تُحدَّد قيمته يرث `bodyText`. ولون التوكيد الموروث يحتفظ بارتباطه بلوحة الألوان، فيتغيّر النص العريض والمائل وتسميات `:ref` داخل الإطار مع `colorPalette` كما تتغيّر خارجه. (حتى postext 1.4 كان النص العريض في الإطار يبقى `#295AA3` أيًّا كان اللون الرئيسي.)
- **القوائم النقطية** تأخذ `lists` الخاص بالإطار (رمز التعداد، واللون، وحجم الرمز ووزنه وخطه، والإزاحة، والفاصل، والتباعد بين العناصر، والهوامش) فوق `unorderedLists`، ونصّها هو نص الإطار. و`lists.bulletChar` أو `lists.color` المختلف عن قيمة المستند (`unorderedLists`) يستبدل رمز التعداد أو اللون في كل المستويات؛ أما الذي يكرّر قيمة المستند أو لم تُحدَّد قيمته فيترك لكل مستوى قيمته (`unorderedLists.levels`)، فتبقى الشرطات المتداخلة في الإطار.
- **القوائم المرقّمة** تأخذ `lists.indent` و`gap` و`itemSpacing`، وتأخذ `lists.color` متى حدّده النمط، حتى لو كان لون رموز التعداد في المستند؛ والنمط الذي لا يحدّده يُبقي الأرقام بلون `orderedLists.color`. (حتى postext 1.4 لم يكن اللون يصل إلى الأرقام إلا إذا اختلف عن `unorderedLists.color`، فلم يكن لتعيينه على ذلك اللون نفسه أي أثر.) أما الرقم نفسه (خطه وحجمه وفاصله) فيأتي من `orderedLists` العام، لأن `lists` لا يضم إلا حقول رموز التعداد: نسّق أرقام الإطار هناك.
- **`:::paragraphs` داخل الإطار** تستخدم نمط الفقرة الخاص بها، وكذلك في الإطارات المتداخلة. والحقول التي لا يحدّدها النمط ترث `bodyText` الخاص بالمستند، لا `body` الخاص بالإطار (ولا ميله ولا حروفه الكبيرة المصغّرة).
- **مجموعات `:::columns`** لا نمط خاصًا بها: تتشارك الأعمدة كلها تنسيق نص الإطار وقوائمه، ويحدّد `columnGap` الفاصل بينها.
- **الاقتباسات الكتلية** تأخذ خط نص الإطار وحجمه وأوزانه (مائلة ورمادية، كما في النص الجاري)، وحروفه الكبيرة المصغّرة. و**العناوين** تحتفظ بأنماط العناوين؛ و**الصيغ المنفصلة** بإعدادات الرياضيات.
- **الأشكال والجداول** تحتفظ بأنماط التعليقات والجداول في المستند، بالعرض الداخلي للإطار؛ ويتبع وزناها العادي والعريض أوزانَ `body` في الإطار.
- **الشارات (chips)** تحتفظ بنمط الشارة الخاص بها؛ ويُقرأ حجم `em` نسبةً إلى حجم نص الإطار.
- **`:::space`** يُقاس بأسطر نص الإطار (انظر [`:::space`](/ar/docs/document-format-directives#space) لمعرفة المواضع التي يُسقط فيها).
- **الإطار المتداخل** يأخذ نمطه الخاص كاملًا؛ ويُتجاهل `span` و`placement` و`floatBarrier` و`snapToGrid` الخاصة به.

**الحواشي المعلّقة.** الحواشي تحت الجدول، ومفتاح الرموز المرقّم، وقائمة المصادر تُبرز علامتها أمام النص: العلامة عند الحافة الداخلية للإطار، والنص وكل أسطره التالية أبعد قليلًا إلى الداخل. ويصفّ `body.hangingIndent` (منذ postext 1.71) على هذا النحو كل فقرات الإطار أو إطار القالب الذي له هذا النمط:

- **الطول** يضع كل سطر عدا الأول على تلك المسافة من الحافة الداخلية للإطار، كما يفعل `hangingIndent` في نمط الفقرة (انظر [أنماط الفقرات](/ar/docs/configuration-styles#أنماط-الفقرات)). ويبدأ السطر الأول عند الحافة، أو عند `body.firstLineIndent` إذا ضبطه النمط نفسه؛ أما إزاحة السطر الأول الموروثة من `bodyText` فلا تُطبَّق.
- **`true`** يقرأ `body.firstLineIndent` إزاحةً لكل سطر عدا الأول، كما يفعل `bodyText.hangingIndent` في المتن؛ و`false` يصفّ الإطار بلا إزاحة معلّقة في كتاب إزاحة متنه معلّقة. وإن لم يُضبط أخذ الإطار `bodyText.hangingIndent`.

وموضع جدولة عند المسافة نفسها يوصل النص الذي يلي العلامة إلى حافة الأسطر التالية، أيًّا كان عرض العلامة:

```ts
calloutStyles: [{
  id: 'notes',
  padding: { top: { value: 0, unit: 'mm' }, right: { value: 0, unit: 'mm' }, bottom: { value: 0, unit: 'mm' }, left: { value: 0, unit: 'mm' } },
  body: {
    fontSize: { value: 7, unit: 'pt' },
    hangingIndent: { value: 4.5, unit: 'mm' },
    tabStops: [{ position: { value: 4.5, unit: 'mm' } }],
  },
}],
```

```markdown
:::callout{type="notes"}
\*	تشمل الأسعار التوصيل داخل المدينة.

\*\*	يدفع الأعضاء النصف؛ ولا يُجمع هذا التخفيض مع عروض أخرى، ويسري حتى نهاية الموسم.
:::
```

كل حاشية فقرة مستقلة؛ وبين العلامة والنص محرف جدولة أو `:tab`. والنجمة مُهرَّبة، لأن `*` تليها جدولة في أول السطر تفتح عنصر قائمة. وتُقاس الأسطر على هذا النحو، فيصفّها كلٌّ من canvas وPDF وقائمة العرض وEPUB (بـ`padding-inline-start` و`text-indent` سالب) على النحو نفسه، ويكتب التصدير إلى Word الإزاحة المعلّقة نفسها. وتحتفظ عناصر القوائم بإزاحتها (`lists.indent`، `lists.gap`)، والفقرة داخل كتلة `:::paragraphs` بإزاحة نمطها. وتبقى قيمة `firstLineIndent` السالبة محسوبة `0`: فلا يبدأ السطر الأول داخل المسافة الداخلية للإطار. ويأخذ الاقتباسُ الكتلي داخل الإطار الإزاحةَ المعلّقة مع الإطار حين تكون قيمة `hangingIndent` هي `true`؛ أما مع الطول فلا تُعلَّق إلا فقرات الإطار نفسه.

### علامات الإطار المقسوم

حين ينقسم الإطار عبر الأعمدة أو الصفحات (`keepTogether: false`، أو إطار أطول من عمود)، يبدأ كل جزء بعد الأول بلا عنوان ولا أيقونة، ولا شيء افتراضيًا يخبر القارئ بأن الإطار مستمر. ويضيف خياران العلامات التي يستعملها الكتاب أو السيناريو:

- **`repeatTitle: true`** يكرّر العنوان في رأس كل تتمة، متبوعًا بـ`continuedSuffix`، فيكون افتراضيًا «Key points (cont.)». ويأخذ العنوان المكرَّر نمط العنوان، فمع `textTransform: 'uppercase'` يعطي «HAMLET (CONT'D)» كما في السيناريو. وتبقى الأيقونة ولسان التسمية في الجزء الأول.
- **`continuesMarkerEnabled: true`** يضع `continuesMarker` («Continued»، أو «Continúa» في مستند إسباني) تحت السطر الأخير من كل جزء له تتمة، داخل الإطار، بخط نص الإطار وحجمه: مائلًا ما لم يكن `continuesMarkerItalic` مساويًا `false`، ومحاذيًا لليمين ما لم يحدّد `continuesMarkerAlign` القيمة `'left'` أو `'center'`. وتأخذ العلامة مساحة في الجزء الذي تختمه، ويُختار القطع بحيث تتسع لها.

```ts
calloutStyles: [{
  id: 'speech',
  keepTogether: false,
  titleStyle: { textTransform: 'uppercase' },
  repeatTitle: true,
  continuedSuffix: "(CONT'D)",
  continuesMarkerEnabled: true,
  continuesMarker: '(MORE)',
  continuesMarkerAlign: 'center',
  continuesMarkerItalic: false,
}],
```

```md
:::callout{type="speech" title="Hamlet"}
A speech long enough to run over the foot of the page…
:::
```

ينتهي الجزء الذي يختم الصفحة بـ«(MORE)»، وتبدأ الصفحة التالية بـ«HAMLET (CONT'D)». وكلاهما من لوازم ترقيم الصفحات: في ملف PDF الميسَّر هما عنصران زخرفيان (artifacts)، وفي HTML يُخفيان عن التقنيات المساعدة، فيُقرأ العنوان مرة واحدة. وفي VDT هما كتلتا نص في `designOverlay` عليهما العلامة `artifact: true`.

### تصميم الإطار

يضع `design` عناصر تصميم العنوان (نصوص وصور وخطوط ومربعات؛ انظر [الامتداد والتصميم المتقدم](/ar/docs/configuration-headings#الامتداد-والتصميم-المتقدم)) في نطاق تحت عنوان الإطار، على عرضه الداخلي كله. ويأتي محتوى الإطار بعد النطاق، وبينهما فسحة العنوان. والإطار المقسوم عبر الأعمدة أو الصفحات يرسم النطاق في جزئه الأول وحده. منذ postext 1.45.

تقرأ نصوص التصميم هذه العناصر النائبة:

- `{titleText}` — العنوان الذي يطبعه الإطار: `title` السياج، وإلا فعنوان النمط.
- `{boxText}` — محتوى الإطار نصًا عاديًا، فقرة أو بند قائمة في كل سطر. وتُسقط الفارغة.
- `{boxText.<n>}` — الفقرة أو بند القائمة رقم `n`، بدءًا من 1؛ فارغ إذا كان في الإطار أقل من ذلك.
- `{attr.<key>}` — سمة مكتوبة على السياج. أي اسم يصلح، إلى جانب السمات التي يقرؤها السياج نفسه: يعطي `:::callout{type="card" kicker="ملاحظة"}` العنصرَ `{attr.kicker}` القيمة `ملاحظة`. والسمة المفقودة لا تطبع شيئًا.
- عناصر المستند النائبة `{title}` و`{subtitle}` و`{author}` و`{publishDate}`.

ويقبل `resourceId` في الصورة العناصر النائبة نفسها، فيرسم كل إطار موردًا خاصًا به. ولا يقرأ `{boxText}` إلا تصميم الإطار؛ أما تصميم العنوان فلا يطبع مكانه شيئًا.

مع `setsContent: true` يخدم نمط واحد كل الإطارات ذات الشكل الواحد، ولكل منها كلماته. في كرّاسة الخط يكون كل سطر تمرين إطارًا محتواه الكلمة المطلوب نسخها: يطبع التصميم الكلمة بخط مدرسي، ثم يعيدها بنقاط للتتبّع (`dotted`) بقدر ما يتّسع له السطر (`repeat`؛ انظر [العلامات داخل السطر والخطوط المحيطية](/ar/docs/configuration-headers-footers#العلامات-داخل-السطر-والخطوط-المحيطية)).

```ts
calloutStyles: [{
  id: 'practice',
  backgroundEnabled: false,
  border: { enabled: true, color: { hex: '#9aa6b2', model: 'hex' }, width: { value: 0.5, unit: 'pt' } },
  design: {
    setsContent: true,
    minHeight: { value: 16, unit: 'mm' },
    slot: { elements: [
      { kind: 'text', id: 'model', content: '{boxText}', fontFamily: 'Aref Ruqaa', fontSize: { value: 26, unit: 'pt' },
        placement: { anchor: { to: 'container', edge: 'top-left' } } },
      { kind: 'text', id: 'copies', content: '{boxText}', fontFamily: 'Aref Ruqaa', fontSize: { value: 26, unit: 'pt' },
        dotted: {}, repeat: { gap: { value: 8, unit: 'mm' } },
        placement: { anchor: { to: '#model', edge: 'right-of' }, offset: { x: { value: 8, unit: 'mm' } } } },
    ] },
  },
}],
```

```md
:::callout{type="practice"}
قط
:::

:::callout{type="practice"}
شمس
:::
```

يطبع السطر الأول *قط* وتليها نسخ منقّطة منها، ويفعل الثاني الشيء نفسه مع *شمس*، ولا تُنضَّد أي من الكلمتين مرة أخرى تحت نطاقها. وإذا تغيّرت الكلمة في Markdown تغيّر النموذج وكل النسخ. وإذا بقي `setsContent` على `false` قرأ التصميم `{boxText}` كذلك، ونُضِّد المحتوى تحت النطاق.

في VDT تكون عناصر النطاق كتل تصميم على `designOverlay` الخاص بالإطار، بجانب العنوان.
