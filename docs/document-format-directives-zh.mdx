# 文档格式：指令


## 指令

指令是独占一行的控制标记，写作`:::name`或`:::name{attrs}`。大多数指令本身不印出任何东西，只控制版面的定位和编号；`:::toc`、`:::index`和`:::bibliography`则在所在位置印出目录、索引和参考文献。

属性值可以加双引号（<code>"…"</code>）、加单引号（<code>'…'</code>），也可以不加引号（<code>startAt=17</code>）。不带`=`的键是一个值为空的标志。

目前能识别为单行指令的只有`pagebreak`、`numbering`、`columnbreak`、`space`、`toc`、`index`和`bibliography`（`references`、`verse`、`page`、`strip`和`figure`则是有起始行和结束行的块）；其他不属于容器（见下文）的`:::name`行都按段落解析，沙盒会显示**未知指令**警告。引擎也会把它记入文档的`contentWarnings`，作为一条`unknownDirective`（见[配置 › 文档中的警告](/zh/docs/configuration-programmatic-usage#文档中的警告)）。

### 属性值

同一套`key="value"`语法用于标题属性、指令和容器的起始行（`:::name{…}`）、行内引用（`:ref{…}`）、行内标签（`:chip[…]{…}`）、色块（`:swatch{…}`）和索引标记（`:index[…]{…}`）。规则如下：

- **键**以ASCII字母或`_`开头，后面可以是ASCII字母、数字、`_`或`-`。`=`两侧可以有空格；中文输入法打出的全角`＝`与`=`等效；重复的键取最后一个值；没有`=`的键是值为空的标志。用其他文字书写的键（`作者=曹雪芹`）不会被读取，并触发`attributeKeyInvalid`警告；块中的其他键仍然生效。值可以用任何文字。
- **带引号的值**。双引号值可以包含除`"`以外的任何字符，包括单引号；单引号值可以包含除`'`以外的任何字符。因此含双引号的值要放在单引号里：`lead='He said "hi"'`。没有转义，反斜杠是普通字符，所以同时需要两种ASCII引号的值要改用印刷引号（`“…”`、`’`）。值也可以用中文输入法打出的弯引号`“`或直角引号`「`开头，一直延续到对应的`”`或`」`，中间可以有空格：`title=“甲戌本 眉批”`、`title=「脂批」`。
- **不加引号的值**（`startAt=17`、`year=1998`）延续到下一个空格：`title=Hello world`等于`title="Hello"`加上一个标志`world`。
- **不能有花括号**。`{`和`}`不能出现在值中。第一个`}`就结束属性块：值中含花括号的起始行不再是指令，而是段落；在行内，值的剩余部分会漏进正文。在标题中，值里的花括号会使整个块留在标题里：`# Title {note="a {b"}`原样排出。（在postext 1.8及以前，空格后的`{`会重新开始一个块，`b`被当作标志读取。）
- **美元符号是普通文本**。属性在行内公式之前读取，所以`lead="from $5 to $6"`只是文本。
- **只占一行**。属性块从不跨行。
- **标识符**。Pandoc的简写`#key-idea`等于`id="key-idea"`：标题上写`{#sec-method}`，起始行上写`:::callout{#box-safety}`。它为[交叉引用](/zh/docs/document-format-notes-references#交叉引用与锚点)给块命名。

```markdown
# The Long Road {lead='A "road novel", they said' price="$18"}

:::callout{type="note" title='The "fast" path'}
…
:::
```

`::resource{id="…"}`更严格：id必须用双引号，且不能有其他属性（见[资源](/zh/docs/document-format-resources#资源)）。在模板页中还可以加`slot="…"`（见[模板页](#模板页)）。

### 容器

容器把一连串块包起来：起始行是`:::name`或`:::name{attrs}`，接着是任意普通内容（段落、标题、列表、引用块、公式，甚至其他指令），结束行只有一个`:::`。容器可以嵌套；每个结束行`:::`关闭最内层尚未闭合的容器。

```
:::callout{type="note"}
Keep the lantern lit **every** night.

- Check the wick.
- Trim it at dusk.
:::
```

正文流中能识别五种容器名；`:::frame`和`:::module`在[模板页](#模板页)中分别盛放一个框和一个模块的内容，`:::figure`和`:::label`则分别盛放一幅插图和一个多行标注。每种排出来是什么样子，由配置中相应的部分决定：

每种容器接受的属性及其样式设置见[配置](/zh/docs/configuration)。属性值的语法与指令相同。`:::callout`起始行接受`type`（已配置的标注框样式的id；类型未知或缺少时使用第一个样式）、`title`（代替样式的默认标题），以及`span` / `placement`（`column`、`page`或`side`；`here`、`top`、`bottom`或`fixed`），用来为这个框改用不同于样式的范围和位置：

```
:::callout{type="objectives" title="What you will learn" span="page" placement="top"}
- Name the parts of the lantern.
- Trim the wick without touching the glass.
:::
```

浮动框（`placement`为`auto`、`top`或`bottom`）还接受`columns`，即它在多栏页面上横跨的相邻栏数，例如`:::callout{placement="top" columns="2"}`（postext 1.18起）。

框也可以让后面的正文排在它旁边：`wrap`（`left`、`right`、`start`或`end`）、`width`（占栏宽的比例，0到1；未设置时取`layout.wrap.defaultWidth`）和`wrapGap`（长度，如`6pt`），例如`:::callout{wrap="right" width=0.4}`（见[文字绕排](/zh/docs/document-format-resources#文字绕排)；postext 1.24起）。

标注框排成一个框：先是可选的标题，然后是内容，内容用该样式自己的正文和列表排版设置。默认情况下它保持完整，放不下时整体移到下一栏或下一页（比整栏还高的框照样会拆开，而不会超出栏底）；样式设为`keepTogether: false`时，框可以在块之间或行之间拆分，切口两侧至少各留`splitMinLines`行文本，或者一个图、表、行间公式或嵌套框（在段落或列表项内部切开时，切口两侧还至少各留该段落或列表项的`layout.boxChildSplitMinLines`行：默认两行，`splitMinLines`更小时取`splitMinLines`；1.5之前保存、章中含框的书按1读取，即沿用1.4的切法）。拆开后，除第一段外，其余各段开头不带图标（文字仍让出图标所占的位置），也不带标题，除非样式要求重复标题（`repeatTitle`：“Key points (cont.)”）；样式还可以在每个后面还有下文的段落下方加一个“续”标记（`continuesMarkerEnabled`），见[拆分框的标记](/zh/docs/configuration-callouts#拆分框的标记)。通栏框（`span="page"`）把页面切成若干栏带；`span="side"`框离开正文流，进入一栏半版式中只放浮动体的侧栏（`layout.sideColumnRole: 'floats'`），叠放在它所打断的文字旁边，在没有这种侧栏的地方按栏内框排版；`placement="fixed"`框离开正文流，固定在页面坐标上（比如章末页左下角的自我评估徽标），它所覆盖的栏让出这块区域；浮动框（`placement="top"` / `"bottom"`）在出现处离开正文流，占据该位置之后第一个空闲的栏带，即本页底部，或下一页的顶部或底部，而它后面的文字填满它离开的那一页。设为`floatBarrier: true`的样式（通常是章末的“要点”框）使该框成为**浮动体屏障**：在它之前引用的每个图或表都会排在它前面：放进页面的空位，或放在框前新开的页上，所以没有浮动体会跑到本章结尾之后。未知的`:::name`起始行不是容器，该行按文本处理，与未知指令完全相同。

`:::part`起始行接受`number`（按你希望印出的样子写，如`"I"`、`"IV"`、`"3"`；引擎也会解析它，以便设计改用别的格式）和`title`，两者都可以省略。第三个属性`palette="band=#hex"`（多个`id=#hex`对，用逗号分隔）在该篇及其后各章（直到下一篇）中替换颜色：凡链接到这些调色板id的设计颜色（书眉、章首页色带、篇名页设计），以及与它们基础值相同的正文颜色（标题、粗体、引用、项目符号、题注、表格、标注框、行内标签）都随之改变；见[配置 › 篇](/zh/docs/configuration-styles#篇)。这个容器总是自成一页：之前按配置的奇偶分页，正文为单栏、使用`parts.margins`页边距，篇名页设计铺满整页，结束行之后再分一次页。正文通常是该篇所含各章的列表，也可以什么都没有，按`parts.bodyStyle`排版：

```
:::part{number="I" title="Foundations"}
1. The lantern and its parts
2. Trimming the wick
:::

# The lantern and its parts
```

按默认的标题设置，这会得到传统的顺序：篇名页在右页，接着是一个空白左页，章从下一个右页开始。这一页标记为`role: 'part'`，页眉和页脚可以借此跳过它；在之后的每一页上，`{partTitle}` / `{partNumber}`都取当前所在的篇。见配置参考中的[篇](/zh/docs/configuration-styles#篇)。

起始行和结束行前面不需要空行：它们紧贴在段落、列表或引用块下方时，会结束那个块。到文档结尾仍未闭合的容器在结尾处自动闭合，沙盒会给出指向其起始行的**容器未闭合**警告。没有容器打开时多出的`:::`作为可见的段落留在文字中，不会被悄悄丢弃。

### `:::columns`

`:::columns{count=2}` … `:::`组把起始行与结束行之间的块排成`count`个等宽的栏（2到6栏），组后面的文字恢复全宽。在`:::callout`内部，各栏平分框的内宽，栏间距为样式的`columnGap`，按框的正文和列表排版设置排，框的高度以最高的一栏为准。在正文中（postext 1.25起），各栏平分正文栏，栏间距为一行正文，块保留正文自身的排版设置；在多栏页面上加`span="page"`时，组像通栏框一样在页面上切出一条栏带：其上方的各栏齐平收尾，组横跨整个版心排出（各栏相隔一个栏间距），文字在它下方的每一栏中接着排。在单栏页面上，`span="page"`把组排在栏内。组内的标题保留各自的样式、编号和目录条目，组内引用的脚注排到正文栏的底部，组内引用的图照常浮动。

    <tr>
      <td><code>marginBottom</code></td>
      <td>组下方的间距，取长度；<code>0</code>表示不留。在正文中它取代正文的段间距；在框内它是到下一个块之前的间距。自postext 1.28起提供。</td>
    </tr>
  </tbody>
</table>

能整体排下的组在各栏最齐平的地方切开：可以切在块之间，也可以切在段落或列表项的行之间，被切开的段落或列表项在下一栏顶部接着排，不带项目符号。如果用`breaks`固定了各栏的起点，就不会在段落内部切开（例如文字栏旁边配一栏图）。在段落或列表项内部切开时，栏脚至少留`bodyText.widowMinLines`行，下一栏顶部至少留`bodyText.orphanMinLines`行（默认各两行；关闭`avoidWidows`或`avoidOrphans`时为一行），块前的间距到栏顶即消失。在这些规则允许的切点中，组选用使最高一栏最矮的那个：六行和五行的两个段落排成6 | 5，不会排成5 | 1 + 5（postext 1.39起）。

**组前后的间距**。在正文中，组之后跟着正文的段间距（开启`bodyText.paragraphSpacing`时为一行，否则没有），在框内则没有自己的间距。在起始行上写`marginTop`和`marginBottom`可以设定间距：`:::columns{count=3 span="page" marginBottom="0.75em"}`。两者都是最小值，与相邻块自身保留的间距合并，同框的外边距一样。在正文中，文字在组之下回到基线网格，所以间距总是整行；跨栏或跨页拆开的组，上边距归第一部分，下边距归最后一部分。`em`按组所在文字的字号计算；不是长度的值和负值都被忽略。

```md
:::callout{type="summary"}
:::columns{count=2}
- Every element is one kind of atom.
- Electrons live in orbitals.
- A bond shares or transfers electrons.
:::
:::
```

**`breaks`如何计数**。`breaks`按顺序给组内的块编号：段落、列表项（每项一个块）、行间公式、图和表；嵌套的`:::callout`无论包含多少内容都算一个块。指令不算块：两节诗之间的`:::space`不会改变计数。小于2、超出组内最后一个块或不在前一个断点之后的数字会被忽略。在组内，`:::space`像在框内其他地方一样分隔两个块，在组的顶部和各栏的顶部（`breaks`位置或齐平切口）消失；如果想让组从更低的位置开始，把空白放在`:::columns`起始行之前。因此，间距相同的两栏会逐节对齐：

```md
:::callout{type="verse"}
:::columns{count=2 breaks="4"}
The lamp is lit at dusk,

and trimmed before the dawn.

:::space

The keeper sleeps by day.

La lámpara se enciende al anochecer,

y se despabila antes del alba.

:::space

El farero duerme de día.
:::
:::
```

这里第四个块“La lámpara…”开启第二栏；两行`:::space`不计数，在两栏中留出相同的间隙。

#### 分栏组的拆分

自postext 1.25起，组在可用空间里放不下时，会在各栏之间切开，接到下一栏或下一页。可用空间在正文中是本栏余下的部分，在框内是拆开的框（`keepTogether: false`，或比一栏还高的框）的某一段；框内的组在新的框片段中接续：

- **`flow="snake"`**，没有`breaks`时的默认值：组内的块连成一条长条，就像报纸上一篇报道的正文。还要接续的部分依次填满各栏，在切口允许的范围内尽量齐平，可在块之间或段落、列表项的行之间切开（切口两侧至少各留该段落或列表项的`layout.boxChildSplitMinLines`行，默认两行）；最后一部分像整组一样平衡各栏。
- **`flow="parallel"`**，有`breaks`时的默认值：由断点开启的每一段内容是一条流，始终留在自己的栏中。每一部分把每条流都排到可用空间的底部，各条流在下一部分的同一栏中接续，因此并排的一首诗和它的译文逐节保持平齐。没有`breaks`的平行组按蛇形组接续。

组内的嵌套框保持完整，移到下一部分；嵌套框内的组从不切开。放得下的组与以前排得完全一样。`layout.flowColumns: false`保留postext 1.24的规则：框外的分栏组被忽略，组从不切开；1.25之前保存、含有`:::columns`组的书按这种方式读取。沙盒会报告它不认识的`flow`（**未知的分栏走向**），以及宽度不到其文字6 em的栏（**分栏过窄**）。

```md
## 简讯

:::columns{count=3 span="page" rule}
**港口。** 新码头周一启用……

**市场。** 摊位租金维持不变……

**天气。** 傍晚起西部有雨……
:::
```

`:::callout`起始行还接受`label="…"`，即带`label`页签的样式印在框顶角的文字（`:::callout{type="box" label="BOX 1-1" title="The octet rule"}`）。起始行上的其他任何属性都由样式的设计（如果有）读取：`:::callout{type="card" kicker="注意"}`让设计的文字可用`{attr.kicker}`，`{boxText}`则印出框自身的内容（见[配置 › 框的设计](/zh/docs/configuration-callouts#框的设计)）。

嵌在另一个`:::callout`里的`:::callout`是一个独立的框，比如装着若干答题框的练习卡片。它使用自己的样式（底色、边框、圆角、内边距、标题、图标），宽度为外框的整个内宽，与外框的其他块依次堆叠；它的`span`和`placement`会被忽略，因为嵌套框总是在父框内排版。每个结束行关闭最内层仍未闭合的框：

```md
:::callout{type="card"}
The statement of the exercise.

:::callout{type="answer"}
A white answer box with its own border and padding.
:::

:::callout{type="answer"}
A second answer box.
:::
:::
```

外框跨栏或跨页拆分时（`keepTogether: false`，或比一栏还高），嵌套框整体移到下一个片段，除非它自己的样式也允许拆分；每个片段重新绘制其中的边框；接续的嵌套框不带图标，也不带标题，除非它的样式要求重复标题（`repeatTitle`）。

### `:::diecut`

模切属于书的形式：它的形状、尺寸和在页面上的位置是配置中的一个模切形状（`dieCuts.shapes`，见[特种油墨与模切](/zh/docs/special-inks-die-cuts#模切形状)）。由内容决定哪些页面要模切时，把内容放进写明刀模的`:::diecut`容器：

```md
:::diecut{die=window}
## 房子
透过窗口，看见下一页的花园。
:::
```

凡是排入该容器内容的页面都由这个刀模切出，它所在每张纸页的另一面也一样，呈镜像。与`:::paper`一样，内容从新的一页开始，结束行`:::`之后的内容也从新的一页开始。嵌套在另一个`:::diecut`里的`:::diecut`切的是内层的刀模。`die`是唯一的属性。`dieCuts.shapes`中没有的刀模什么也不切：这些页面照样单独排，沙盒列出**未知的模切形状**警告（文档`contentWarnings`中的`dieCutUnknown`）。要按页码模切，请改用`dieCuts.pages`。

### `:::pagebreak`

这个指令本身不指定奇偶，只是让下一个块从新的一页开始。可以用它结束前言、让献词独占一页，或者标记一节的结束。如果同一处既要分页又要重置编号，就在`:::pagebreak`后面接`:::numbering`：编号切换作用于`:::pagebreak`刚刚新开的那一页。

在仍为空的页上分页不起作用，因此它不会添加空白页。它也不会取代紧随其后的标题的`breakBefore`（1级标题默认有）：标题仍会应用自己的奇偶设置，这可能在指令新开的那一页之后再加一个空白页。要让标题恰好从那里开始，关掉它的分页（见**配置 › 标题样式**）。在铺满整页的封面标题之后，分页是可选的：无论单栏还是多栏版式，封面都已占用本页余下的部分，紧接着写一个`:::pagebreak`也无妨。只有当封面的设计没有延伸到页面底部，而正文仍应从下一页开始时，才需要分页（见**配置 › 保留高度**）。

```md
The old chapter ends here.

:::pagebreak{parity="odd"}

# A new chapter
```

开关`center`（`:::pagebreak{center}`，用`center=false`关闭）让分页新开的那一页上的文字在版心中上下居中，竖排时左右居中，即日文篇名页或献词页所说的“ページの左右中央”。浮动体、注释和书眉位置不变，已经排满的页面保持原样。这个开关不会结束这一页：请再用一个`:::pagebreak`结束它。

```md
:::pagebreak{center}

# 上　先生と私

:::pagebreak
```

#### 奇偶属性

`parity`属性接受的五个值与`headings.levels[*].breakBefore.parity`相同：

- `'any'`：默认值，没有奇偶约束，分页只是开一个新页。
- `'odd'` / `'even'`：新页排在跨页中指定的一侧；只有顺延的下一页落在另一侧时，才插入一个空白页。
- `'always-odd'` / `'always-even'`：保证前面的内容与新页之间至少隔一页必需的空白分隔页，然后再满足奇偶要求。这页分隔空白属于**前一**章；为凑奇偶再补的空白页属于后面的内容。

#### 空白页的归属

`VDTPage`模型区分`:::pagebreak`（以及`breakBefore`）可能插入的两类空白页：

- `blankForParity: true`：为满足奇偶约束而插入。在`{chapterTitle}`页眉中，这一页显示**即将开始**的那一章的标题，因为这个空白页只是为了把那一章推到正确的奇偶页上。
- `blankForForce: true`：`'always-*'`模式中必需的前导分隔页。它属于**前一**章，是有意在章末留出的停顿，而不是为下一章补的奇偶页。

空白页沿用哪一部分样式的书眉和调色板，也由这两条规则决定，见[配置 › 标题样式](/zh/docs/configuration-styles#标题样式)。

#### 文档开头的例外

当`:::pagebreak`是文档中的第一个结构（或者带`breakBefore`的标题会引入一个分页）时，只要第一页仍为空，就不执行奇偶约束。下一个块按原文落在第1页，不管要求的奇偶如何，开头不会多出空白页。

### `:::numbering`

`:::numbering`用来在文档中途重新开始页码计数。典型的图书示例：

```md
---
title: "A Book With Front Matter"
---

# Preface

…

:::pagebreak{parity="odd"}
:::numbering{format="decimal" startAt=1}

# Chapter 1
```

前言各页的页码为`i`、`ii`、`iii`……；第一章从页码为`1`的右页开始。

只改格式（不带`startAt`）时，计数接着往下数，比如从`lower-alpha`换成`upper-alpha`而不重新计数。

`format`接受编号格式的任何写法：`roman-lower`和`i`与`lower-roman`等效，`arabic`与`decimal`等效，`一`和`あ`与`japanese-informal`和`hiragana`等效（见[配置 › 编号格式的写法](/zh/docs/configuration-page-layout#编号格式的写法)）。值不属于其中任何一种时，格式保持不变，沙盒会标出这个值。

`lines`重新开始的是[行号](/zh/docs/configuration-notes-references#行号)的计数，而不是页码：下一个计数的行取给定的号，不论`lineNumbers.restart`怎样设置。值不是0或正整数时会被忽略。

```md
## 第二幕

:::numbering{lines=1}
```

### `:::space`

`:::space`在两个块之间留出垂直空白：把结尾的一行与上方文字隔开，把题词或署名稍稍往下推，或者在两段文字之间形成*空行分隔*。Markdown中多加空行做不到这一点：与任何Markdown一样，连续的空行只算一次段落分隔，所以编辑器或格式化工具增删空白时，文档的版面不会变。

```md
The last paragraph of the scene.

:::space

A new scene begins one line lower.

:::space{lines=2}

Two lines lower still.
```

- **`lines`**：空白的大小，以正文行（基线网格）为单位。默认为`1`。整数能让每行文字都保持在网格上，页面上各栏仍能对齐；小数（`lines=0.5`）按原值留出，代价是直到下一个对齐网格的块之前，各栏不再对齐。值不是大于0且不超过20的数字时，按一行处理，沙盒会标出它（**空白大小无效**）。
- **它会叠加**。空白加在两个块之间已有的外边距上（标题的上外边距、列表的下外边距），而不是与之合并。连续两行`:::space`会加两行。
- **遇到分栏或分页就省去**，与LaTeX的`\vspace`一样：在栏顶或页顶它会消失，所以页面不会以一块空白开头；在栏底放不下时，它只是结束这一栏，不把剩余部分带到下一栏。
- **其后的段落顶格排**。`bodyText.indentAfterHeading`关闭时，紧跟在`:::space`后面的段落不带首行缩进，与标题之后一样，这是空行之后继续正文的通常做法。
- **在标注框内**（或`:::columns`组内），它以同样的方式分隔框的子块，以框自身的正文行为单位计量。在框的第一个块之前它会被省去，与在栏顶一样（内边距已经把内容与边框隔开），但有两种情况例外，此时它会留出相应的空间：紧接在框的标题下方，以及框里没有其他内容时（答题框、以行计量的书写空间）。在`:::columns`组的顶部、组内各栏的顶部，以及拆开的框在下一栏或下一页接续部分的顶部，它总是会消失。在`:::paragraphs`容器内，它的作用与正文段落之间相同。
- **与下文同页**的规则把它计算在内：标题后面跟着`:::space`时，如果标题下方放不下这段空白和其后文字的前几行，标题会后移。

练习册的答题框就是一个只有空白的框：问题写在标题里，下面留四行空间。

```md
:::callout{type="answer" title="1. Name the three parts of the lantern."}
:::space{lines=4}
:::
```

如果要的是固定的分栏或分页，而不是空白，请用`:::columnbreak`或`:::pagebreak`。


### `:::verse`

一首诗。`:::verse`有两种排法：**逐行**，大多数诗都这样印；或者qaṣīda的**古典阿拉伯排法**，每一联分成两个半行并排。各行带有半行分隔符（`||`，或两边有空格的`\\`）的诗按阿拉伯排法排，其他的诗逐行排；起始行上的`layout=lines`或`layout=bayt`可以指定其一。

#### 逐行

照印出来的样子写诗：Markdown的一行就是一行诗，诗节之间空一行，行首加空格表示缩进。

```md
:::verse
轻轻的我走了，
  正如我轻轻的来；
我轻轻的招手，
  作别西天的云彩。

那河畔的金柳，
  是夕阳中的新娘；
:::
```

- **诗行**。每个非空行是一行诗，单独按行内Markdown读取：斜体、小型大写、注释和引用都可用。连续的空行只算一次换节。
- **缩进**。每个行首空格宽`indentStep`，默认0.5 em，所以两个空格缩进一个字；制表符算四个空格，全角空格（U+3000）算两个。
- **转行**。比行长稍宽的诗行先收紧词间空格，最多收到其自然宽度的`bodyText.minWordSpacing`（两端对齐文字的收紧下限），保持一行；在起始行上写`tighten=false`或设`bodyText.verse.tighten: false`则改为转行。收紧后仍放不下的诗行在词间空格处转行（中文诗行按中文的断行规则在字间转行）。`turnover=hang`（默认）时，余下部分悬挂在下一行，从该行自身的起点缩进`hang`：诗的段落样式的`hangingIndent`，没有则为2 em（`bodyText.verse.hang`）。`turnover=right`时，余下部分在下一行与行尾对齐，前面加开方括号（`turnoverMark`，默认`[`），这是英语和西班牙语诗集的做法。诗行不断词，除非其段落样式自己设置了`hyphenation: true`。一行诗和它的转行绝不在分栏或分页处分开。
- **诗节**。两个诗节之间的间距是诗的一行行距；`stanzaSpace=0.5`为半行，长度值（`stanzaSpace=6pt`）则精确设定。在基线网格上取整到网格行。分栏和分页优先落在诗节之间；在诗节内部则按段末孤行和段首孤行的规则断开，这时只计该诗节的行数。`keepStanzas=N`让不超过N行的诗节保持完整：俳句用`keepStanzas=3`，短歌用`keepStanzas=5`。
- **位置**。诗以最长的一行为准在版心中居中，各行与诗的起点对齐（`align=center`，散文中引诗的常见排法）；`align=start`让诗与版心起点对齐，这也是竖排的默认值。引出诗的段落，其最后一行与诗的前几行留在一起。
- **错行**。写成`+ …`的行从上一行结束处、隔一个词间空格开始，即诗剧中两个角色共用的一行。如果一行本身以加号开头，写作`\+`。
- **停顿**。起始行上有`keepSpaces`时，行内两个及以上的连续空格保持其宽度；没有时，空格像在任何段落中一样合并为一个。
- **字体与方向**。`style`指定一个段落样式，给出字体、字号、行距、`indent`以及诗上下的间距。`dir`和`lang`设置诗的方向和语言：阿拉伯文书中的拉丁文诗（`dir=ltr`）从其自身的起始一侧缩进。竖排时每行诗是一列，从天头起缩进。

`bodyText.verse`设置所有诗的默认值（见[配置 › 诗歌](/zh/docs/configuration-text#诗歌)）。纯文本输出保留诗的原样：行与行之间一个换行，诗节之间一个空行，所以复制出的段落和搜索都按行读取；流式EPUB把每个诗节排成一个元素，其中各行悬挂转行，带标签的PDF把每个诗节标为一个段落。

**行号**。打开`lineNumbers`时，诗的诗行会被计数（见[配置 › 行号](/zh/docs/configuration-notes-references#行号)）。每个诗行只数一次：转行的部分不编号，诗节之间的空白也不计数。默认每第五行在外侧页边印出行号，每首诗重新计数。按古典阿拉伯排法排的诗每联数一行。起始行上的属性可以调整单首诗：`lineStart=N`给它的第一行编号，`interval=N`设定它自己的间隔，`numbered=false`让它不参加计数。

```md
:::verse{lineStart=37}
…
:::
```

按默认间隔5，这首诗在诗行旁印出40、45等行号。

#### 古典阿拉伯排法

按古典阿拉伯排法排的诗（qaṣīda、qiṭʿa）：每一联（*bayt*）排一行，分成两半，前半行（*ṣadr*）在起始一侧（阿拉伯文为右侧），后半行（*ʿajuz*）在结束一侧，中间留空。每行写一联，两个半行用`||`分开（也可以像维基文库的文本那样，用两边各有一个空格的`\\`）。没有分隔符的行是单独的半行，在诗中居中。

```md
فأنشد يقول:

:::verse
يَا حُرْقَةَ الدَّهْرِ كُفِّي || إِنْ لَمْ تَكُفِّي فَعِفِّي
فَلَا بِحَظِّيَ أُعْطِي || وَلَا بِصَنْعَةِ كَفِّي
:::
```

- **同一宽度**。一首诗的所有半行都排成同一宽度，因此每个前半行都从同一条竖线开始，每个后半行都在另一条竖线结束，韵脚字母上下对齐。宽度取最宽的半行，最多为行长减去中间空白后的一半；用`width`可以指定（`width=55mm`）。每个半行先用卡希达拉到这个宽度（诗比散文拉得更长：`bodyText.kashidaMaxLength`的两倍），再用词间空格；只有一个词、填不满的半行把余下的部分留在中间空白里。
- **中间空白**默认为2 em；用`gap`指定（`gap=3em`，不带单位的数字按em计）。`ornament`在空白正中印一个记号（`ornament="٭"`），它不属于正文。
- **太宽时**。比共同宽度更宽的半行先把词间空格收紧到`bodyText.minWordSpacing`。如果仍然放不下，这一联就错开排：前半行单独一行，靠起始一侧；后半行排在下一行，靠结束一侧。
- **位置**。诗在栏中居中；`align=start`让它靠起始一侧。一联绝不会被分到两栏或两页，整首诗遵循段落的段末孤行与段首孤行规则（三联或更少的诗不拆开）。诗前面引出它的段落（“فأنشد يقول:”）会把最后一行与前几联留在一起。
- **字体**。诗使用正文的字体、字号和行距；`style`为它指定一个段落样式（`style="verse"`），带元音符号（harakat）的诗就是这样得到所需的额外行距的。`dir=ltr`或`dir=rtl`像其他块一样设定方向；在从左到右的书中，用拉丁字母写的诗前半行在左。

诗的纯文本把半行和联分开（一个制表符和一个换行），所以搜索或复制的段落读起来与原文一致；卡希达和装饰记号不包括在内。

### `:::toc`

`:::toc`在所在位置印出目录。它展开为普通的块：`toc.levels`所列级别（默认为1级）的每个标题一个，每个`:::part`一个，所以目录像其他文字一样跨栏跨页排版，点击条目会跳到指令所在行。条目显示标题的编号（`numberingTemplate`的输出，没有时为章的序号）、标题、点状前导符和该标题起始页的页码；启用`toc.subtitle`时，还有第二行，显示某个标题属性，如本章的`{author="…"}`。篇有单独的一行，由`toc.parts.design`设计，用该篇自己的`palette`着色。样式为`numbered: false`的标题列出时不带编号；标题上的`{toc="false"}`会把它排除在外（通常是目录本身的标题）。

在模板页里，设置了`takes: "toc"`的框，或包含该指令的`:::frame`，会排出目录，篇名行、点状前导符和`keep`都照样生效（见[模板页](/zh/docs/composed-pages)）。

```md
# Contents {style="front-matter" toc="false"}

:::toc
```

有两个属性可以单独改变某一处目录印出的内容，不论配置如何。`levels`列出它收录的标题级别：一个范围（`levels="1-2"`）、单个级别（`levels="2"`）或一个列表（`levels="1,3"`）；`toc.levels`没有给出样式的级别，采用其上方最近一级的样式。`keep`让目录的每一组排在同一栏、同一页上，作用与[`toc.groups.keepTogether`](/zh/docs/configuration-notes-references#目录)相同：`keep="part"`让篇行与其各章排在一起，`keep="1"`（直到`"6"`）让该级标题与其下的条目排在一起，`keep="none"`关闭配置中的设置。放不下的组整体移到下一栏或下一页；比一栏还高的组会被拆开，接续的那一栏先重复组首行，再加上“（续）”这样的接续标记。

```md
# Contents {style="front-matter" toc="false"}

:::toc{keep="part" levels="1-2"}
```

页码就是文档实际印出的页码。独立排版的文档会带着上一遍得到的页码标签再排一遍，直到页码不再变化；如果编号在前辅文之后重新开始（即上面的`:::numbering`做法），多排一遍就能稳定下来。单独排版的一章（沙盒预览）则从宿主处接收全书的大纲。见配置参考中的[目录](/zh/docs/configuration-notes-references#目录)。

### `:::index`

`:::index`在所在位置印出书后索引：全书中用`:index[…]`或`:index{term="…"}`标记的词条及其页码，页码随文字移动而更新。它与这些标记一起在[索引](/zh/docs/document-format-notes-references#索引)中介绍。一栏不会刚排完一组的第一条就结束，也不会只差该组最后一条时结束：该组至少在本栏留两条、转到下一栏两条，否则整组移到下一栏（`index.groups.splitMinEntries`）。

```md
# Index {style="index"}

:::index
```

### 段落内的换行

源文本中段落的各行连成一段时，中间加一个空格（中文字符之间不加空格）。要在段落内换行而不另起一段（地址、书信的称呼、题献），在源文本的行末写一个反斜杠，即CommonMark的硬换行，或者写`\\`再加一个空格：

```md
致北码头尽头的\
守塔人：

李明 \\ 北京市东城区王府井大街1号 \\ 100006
```

- 换行前的一行按自然宽度排，与段落末行一样，不拉伸到行长。换行后的文字在同一段落中另起一行，没有首行缩进，上方也不加段间距；有悬挂缩进时，它和首行之后的各行一样悬挂。
- 段落、引用块（`> 第一行\`下接`> 第二行`）、脚注和列表项都可以这样换行。列表项在源文本中只占一行，所以用`\\`换行。
- 段落末尾的反斜杠照样印出，与CommonMark相同；连续两个换行只算一个：要空一行，请另起一段或加一个[`:::space`](#space)。
- 紧贴下一个字符的`\\`不是换行：`\\*`印出一个反斜杠和一个转义的星号，`C:\\Temp`印出两个反斜杠。行内代码和公式中的反斜杠属于代码和公式。
- 行末两个空格是CommonMark的另一种硬换行，这里不算换行：这种空格在编辑器里看不见，许多编辑器还会把它们留在行末，结果会在没人想断的地方断行。
- 从HTML阅读器复制的文字在换行处有换行符，流式EPUB写成`<br/>`，PDF提取的文字在此处断行，导出到Word时写成手动换行符（Shift+Enter），从Word导入时又读回为换行。
- 诗歌请放进[`:::verse`](#verse)块，各行、缩进和诗节都会保留，不必每行写反斜杠。

在postext 1.22及以前，反斜杠会照样印出，各行用空格连接。当时保存的书，如果文字中有以反斜杠结尾的行，或有后跟空格的`\\`，仍按原来的方式读取（`bodyText.hardLineBreaks: false`，见[配置 › postext 1.4及更早版本写出的文件包](/zh/docs/configuration-bundles#postext-14及更早版本写出的文件包)）。

### 标题中的换行

在标题中（或在篇的`title`属性中）写`\\`，可以在标题以标题形式出现的地方强制换行：栏内标题照常排，在该处只显示一个空格；章首页设计的`{titleText}`则在该处换行（文本元素的每种`overflow`模式都是如此）。书眉、`{chapterTitle}`、`{partTitle}`和PDF大纲总是把标题排成一行。在中文或日文中，换行两侧都是汉字或假名时，它读作一个全角空格（对联式标题）；如果其中一侧是数字或拉丁文字（`关于举办 \\ 2026年…`），页面上排出汉字与拉丁文字之间的间距，而PDF书签和文档标题则直接把两半连在一起，与普通中文的写法相同。

```md
# Concepts of health and illness. \\ Community health {author="I. Zango Martín"}
```


## 漫画

漫画页、漫画条和跨页写在`:::page`和`:::strip`两种块中，块内的内容由引擎自己逐行读取。块内的`::panel`行开始各个分格，台词行给分格嵌字。包括版面规则、嵌字和输出在内的完整指南见[漫画](/zh/docs/comics)；设置见[配置 › 漫画](/zh/docs/configuration-comics#漫画)。

### `:::page`

```md
:::page{split="30 [30 | 20 | *] / *" gutter=4mm}
::panel{art=lh-arrive}
caption: 每年夏天，玛雅都要到灯塔住上一个星期。
maya: 爷爷！我来啦！
::panel{art=lh-radio focus="40% 50%"}
tomas: 来得正好。
::panel{art=lh-maya}
maya{thought}: 那个阀门好像松了……
::panel{art=lh-beam bleed}
sfx{rotate=-8}: 咔啦
:::
```

一个`:::page`块就是一页漫画：它另起新页，占满整页，结束的`:::`之后的文字从下一页开始。它的属性有`split`（页面怎样切成格子：以百分比表示的尺寸，行与行之间用`/`分隔，左右并排的分格之间用`|`分隔；方括号列表把一个格子再切一次；`*`表示其余部分；`a~b`表示斜线）、`gutter`（格间距：一个长度，或两个长度，分别用于行与行之间和分格之间；不带单位的数字以毫米计）、`style`（分格样式的名称）、`bleed`、`direction`（`ltr`或`rtl`，也可以写成`dir`）和`spread`（见[跨页](#跨页)）。没有`split`时，各分格按等高的行堆叠。块内不读取Markdown块、容器和指令；`<!-- 注释 -->`仍被识别为注释。

### 台词行

分格中的每一行是一个对白框、旁白框或拟声词，写作`键{属性}: 文字`：

```md
maya: 爷爷！我来啦！
tomas{whisper}: 嘘，你听。
caption{at=bottom-end}: 三条街以外。
sfx{at="62% 40%" rotate=-8 size=1.4}: 咔啦
ben{tail=start}: （从格外）在这儿！
sfx{vertical size=2.6 font="Dela Gothic One"}: ドン
maya: 这句话
  接着写在下一行，\
  在这里换行。
```

- **键**是说话人的id（字母、数字、`_`、`.`、`-`），在每个译本中都相同；`caption`、`sfx`和`note`是保留键。冒号也可以是全角的`：`。
- 花括号里单独的一个词是**对白框样式**（`thought`、`whisper`、`shout`、`radio`、`inner`，或者`comics.balloonStyles`中的样式）；`style=`的作用相同。
- `at`固定对白框的位置：以分格画面的百分比表示的一个点（`at="62% 40%"`），或者一个角或一条边（`top-start`、`top-end`、`bottom-start`、`bottom-end`、`top`、`bottom`）。`to`让尾巴指向画面上的一个点；`tail=none`去掉尾巴，`tail=top|bottom|start|end|left|right`让尾巴指向格外。`join`和`join=false`把对白框与同一说话人的前一个连起来或分开；`break`允许它越过边框，这种越界不会被报告为超出。`rotate`（度）、`skew`（倾斜度数，用于透视中物体上的文字）、`size`（缩放比例，用于拟声词）、`color`和`font`改变它的嵌字。
- `vertical`和`horizontal`（或`mode=vertical`、`mode=horizontal`）设定这一行横排还是竖排，优先于全书的设置：不翻译的`ドン`在横排版本中排成一列，横写的招牌在竖排版本中排成一行。在另一种语言的书中排成的列，遵循它自身文字的规则（含假名时按日文规则）。在竖排的书中，不含中文或日文字符的行本来就横排。
- 缩进两个空格或一个制表符的行接续上面的对白框；行末的反斜杠让文字在那里换行。空行被忽略。
- 文字是行内Markdown：强调（嵌成粗斜体）、`:tcy`、`:ruby`（注音排在基字上，基字从右到左时除外）、`:ltr`和`:rtl`（一段文字保持自己的方向）。脚注和`:ref`标记不被读取。

### `:::strip`

```md
:::strip{split="* | * | *" aspect=3 span=page placement=top}
::panel{art=pip-1}
pip: 早上好，奥托！
::panel{art=pip-2}
::panel{art=pip-3}
otto: 好吗？
:::
```

`:::strip`的内容与漫画页相同，但它作为一个不可拆分的框排在正文中，切成若干分格：`span`（`column`为默认值，或者`page`）、`placement`（`here`为默认值，排在写它的地方；或者`top`、`bottom`、`auto`，像图一样浮动），以及它的尺寸，用`height`（一个长度，不带单位的数字以毫米计）或`aspect`（宽高比：`3`、`4/1`、`4:1`；默认取让分格成为正方形的比例）表示。在多栏页面上设为`here`的通栏漫画条，像通栏框一样在它所在的地方切断各栏。`width`让它比所跨的宽度窄（该宽度的`60%`，或者一个长度），`align`沿文字方向把它放在这个宽度的`start`、`center`（默认值）或`end`。`caption="…"`在它下方按题注样式排出题注；加上`type=figure`（一个资源类型）时，题注带上该类型的标签和编号，漫画条计入该类型的编号序列；加上`id=…`后，可以用`:ref`引用它。没有`split`时，各分格左右并排。漫画条只有写在章的顶层才会被读取。

### 跨页

`:::page{spread}`把一页漫画铺在左右相对的两页上：切分覆盖隔着书脊连在一起的两个版心，去掉它们的内侧页边距，分格可以跨过书脊。跨页从偶数页开始，需要时先加一个空白页。见[漫画 › 跨页](/zh/docs/comics#跨页)。

## 模板页

模板页按配置中的页面模板（`pageTemplates`）排出，内容按名称分配到模板的各个框。完整说明（包括警告）见[模板页](/zh/docs/composed-pages)。

- `::::page{template="…"}` … `::::`就是页面块：以四个或更多冒号开头，以单独一行同样数目的冒号结束。块内以三个冒号开头的块（`:::frame`、`:::callout`、`:::figure`……）用法与别处相同，单独一行的`:::`绝不会结束页面块。以三个冒号开头的`:::page`仍是漫画页。
- `:::frame{slot="…" label="…"}` … `:::`存放同名框的内容，可以是任何Markdown。
- 写在标题（`## Retos {slot="retos-titulo"}`）、`::resource{id="…" slot="…"}`、代码围栏或`:::`容器上的`slot="…"`只把这一个块送到该槽位。没有槽位的内容进入模板的流文框。
- `:::figure{resource="…" slot="…"}` … `:::`放置一个资源及其标注行`::label[文字]{at="…" style="…"}`，`at`是图片的一个锚点，或者一个点`"x% y%"`。插图在正文中也能用。它的`alt`、`caption`和`note`，无论写成起始行属性，还是写成`::alt[…]`、`::caption[…]`和`::note[…]`行，都会在该章替换资源自己的文字（见[模板页 › 图自己的文字](/zh/docs/composed-pages-figures#图自己的文字)）。
- `::label`上的`leader`从标注画一条线到它的锚点，`leader="none"`去掉这条线。插图里的`:::label{at="…" style="…"}` … `:::`逐行写一个标注，地图的图例就需要这样写；`:icon[alt]{glyph="…"}`、`{resource="…"}`或`{line="dashed"}`在标注、题注、附注或表格单元格中放一个符号（见[模板页 › 引线、图例与符号](/zh/docs/composed-pages-figures#引线图例与符号)）。自postext 1.48起。
- 在模板把一张卡片在网格中重复排列的页面里，每个`:::frame{slot="<card>"}`是一张卡片，其中指明卡片另一个框的块进入同一张卡片的那个框（见[模板页 › 重复的槽位](/zh/docs/composed-pages#重复的槽位)）。自postext 1.48起。
- `:::module{template="…" name="…"}` … `:::`盛放页面上一个模块的内容：模块是由模块模板画出、叠放在页面模块组中的一块；其中的槽位属于这个模块自己（见[模板页 › 页面中的模块](/zh/docs/composed-pages#页面中的模块)）。自postext 1.48起。
