本書での変更：青空文庫の注記を組版用の記法に改めた（振り仮名、見出し、字下げ）。外字注記の四字（挘・燄・愷・睜）は当該の文字で組んだ。「底本では」の注記がある三箇所（「私に」「出せなかった」「後始末は」）は青空文庫の訂正に従い、注記は組んでいない。波ダッシュは「〜」、二倍の踊り字（／＼）は「〳〵」で組んだ。序の振り仮名は『漱石全集』編集部が補ったもの（現代仮名遣い）である。

## Text

Natsume Sōseki, *Kokoro*, from Aozora Bunko (card 773; base text: Shūeisha
Bunko, 1991, 10th printing 1995; input j.utiyama, proofreading Itō Tokiya;
published 1999, revised 2010), with the preface, the advertisement and the
newspaper notice of 1914 (cards 4688, 4689, 4687; base text: *Sōseki
zenshū* vol. 16, Iwanami Shoten, 1995; input Sunaba Kiyotaka, proofreading
Kobayashi Shigeo). Public domain. Aozora's bibliographic blocks are
reproduced above, as Aozora asks. Changes: Aozora's notation converted to
Postext markup (readings, headings, indents); the four characters Aozora
describes as 外字 set as Unicode characters; the three corrections Aozora
records followed and their notes left out; the wave dash set as 〜 and the
two-cell repeat mark ／＼ as 〳〵.
