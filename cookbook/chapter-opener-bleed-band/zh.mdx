## 成品一览

入门地质教科书*Earth in Motion*的章首页，页面尺寸210 × 280 mm。第3章在一条赭红色带下开篇，色带从页面顶端出血。带中依次是加了字距的眉题、按作者指定位置断行的标题、一段斜体导语，以及一个168 pt的章号，它立在色带深色底边上，靠近切口。色带下方是两栏两端对齐的正文，一幅板块下沉的剖面图占据页面底部。第4章用青绿色重复同一设计，书边索引、节号、交叉引用和图的标签都随之变色。版面设计只在一级标题上写一次。每章的标题行以属性的形式提供眉题里的主题和导语；某章要换颜色时，再在标题行里指定一个样式。

## 做法

### 1 · 把色带和章号挂在页面上

代码见上文的[简短回答](#简短回答)。色带和它的底边挂在出血框的左上角。与其他没有指定宽度的框或线一样，它们会一直延伸到该框的另一边，因此到达裁切线，设置了`BLEED`后则到达出血边。章号挂在页面的右上角：`y: BAND - 0.8 * NUMERAL * PT`把它的基线放在底边上，`BEARING`把它的框向页边距内移2 mm，以抵消数字的侧空，使墨迹大致与正文边缘对齐。眉题挂在容器上。标题通过`below`锚点挂在眉题下方，导语挂在标题下方，而标题版式中的文字默认换行，所以标题变长时导语会被往下推。导语是一个文本元素，内容来自标题的`lead`属性；如果要加作者行，就再加一个`{attr.author}`，用同样的方式串接。`minHeight: BAND - TOP + AIR`决定正文从哪里开始。章号的框比底边低出其字号的0.2倍（11.9 mm），而章首页会为最低的元素预留空间，所以`AIR`至少要有11.9 mm；小于这个值，正文的起点就由章号的框决定了。

### 2 · 让章标题独占一页

<Excerpt region="levels" />

`span: 'page'`让每章从新的一页开始，并把一级标题排成跨两栏的通栏；`advancedDesign`绘制章首页，代替标题文字，正文从预留高度的下方开始。`breakBefore`加上`parity: 'odd'`让每个章首页都落在右页上，这样章号所挂的右边就是切口。二级标题用`numberingTemplate: '{1}.{2}'`把各节编为3.1、3.2……，并使用色带的颜色；如果再加一个三级标题，用`'{1}.{2}.{3}'`就会编到3.1.1。

### 3 · 章节颜色只定义一次

<Excerpt region="palette" />

配置中的每种颜色都链接到调色板里的某一项。引擎自身的默认颜色链接到`main-color`，所以把这一项指向色带颜色，配置里没有设置的默认颜色也会一并改色。第4章的标题行`# Fire from \\ Below {style="teal" topic="Volcanoes" lead="…"}`选用了这个样式，它会把`band`替换掉，直到下一个一级标题为止。设计元素通过调色板链接跟着替换；与基础`band`相同的文字颜色也会重新着色，所以在<PageRef page={3}>第43、44页</PageRef>上，书边索引、节号和列表编号、交叉引用、题注标签以及章首页底部的页码都变成青绿色。同一行还填入了`{attr.topic}`和`{attr.lead}`，其中的`\\`在作者希望的位置给`{titleText}`断行（[标题属性](/zh/docs/document-format#标题属性)、[标题中的换行](/zh/docs/document-format#标题中的换行)）。

### 4 · 让第一次引用决定图的位置

<Excerpt region="figure" />

`:ref`为所引用的图编号，并把它放进引用段落之后第一个空位。图3.1设为`auto`。它在章首页上被引用时，两栏都还有空间，于是占据了这一页的底部；如果设为`top`浮动体，它就会出现在第42页的顶部，因为浮动体永远不会排在自己的引用之前。图4.1在第43页第二栏的下部被引用，那里已经放不下一条页宽的图带，所以`bottom`把它送到第44页。那是本章最后一页，在最后一页上，引擎会把页脚浮动体提上来，紧贴在最后几行正文之下，上方不留空。

### 5 · 书眉、书边索引和章首页底部页码

<Excerpt region="heads" />

每个页眉元素都挂在页面的一个上角，并用`parity`筛选，所以页码和书边索引总在切口一侧。书边索引的框改为挂在出血框的角上，并随`BLEED`加宽，裁切后仍然出血。`pages: 'body'`让这些元素都不出现在章首页上，章首页的页码由页脚放在页面底部。左页用`{chapterTitle}`标出章名，排成一行，因为`\\`只在章首页里给标题断行。教科书通常在右页标出节名。Postext没有表示节名的占位符，所以右页书眉印的是书名`{title}`；这四页里看不到它，因为两个右页都是章首页。

### 6 · 从第3章开始排这本书

<Excerpt region="build" />

这几页是一本更长的书的第3章和第4章，所以`buildDocument`接收一个`continuation`，其中是第1、2章结束时的计数器。它的`headings`里有`h1: 2`，下一个`#`就是第3章：`{chapterNumber}`印出3，节号从3.1开始，第一幅图编为3.1。`pageNumbering.startAt: 41`让页码从41开始。无论页码是多少，第一页都是右页，因为奇偶按实际页面计算，而`pageIndexOffset`保持为0；第一个页码41恰好是奇数，与之一致。

## 变化

### 加深色带

`BAND`决定色带的深度、章号的位置和正文上方预留的高度。色带加深后，正文会被推到下一页，所以要重新调整每章的篇幅（见最后一条常见问题），或者让各章接排。

```diff
-const BAND = 100; // mm from the trim to the foot of the band
+const BAND = 128; // mm from the trim to the foot of the band
```

### 带出血印刷

出血设为3 mm时，色带、它的底边和书边索引都伸出裁切线3 mm，章号仍然立在底边上，`page.cutLines`也以同样的数值打开。

```diff
-const BLEED = 0; // mm: 0 on screen; about 3 for print, which also switches on page.cutLines
+const BLEED = 3; // mm: 0 on screen; about 3 for print, which also switches on page.cutLines
```

### 为另一章加一种颜色

每种章节颜色就是调色板里多一项、样式里多一个；在那一章的标题行上写`{style="slate"}`。

```diff
   band2: '#2e6f73', // the second chapter colour, a teal; the sea in Figure 3.1
+  band3: '#3d4f6b', // a third chapter colour, a slate blue
@@
-const headingStyles = [{ id: 'teal', palette: { band: palette.band2 } }];
+const headingStyles = [{ id: 'teal', palette: { band: palette.band2 } },
+  { id: 'slate', palette: { band: palette.band3 } }];
```

### 让各章接排

设为`'any'`时，章节从下一页开始。如果上一章在右页结束，新章就从左页开始，前面没有空白页；它的章号挂在页面右边，因而立在订口一侧。这几页不会变化，因为第3章本来就结束在左页上。

```diff
-      { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'odd' },
+      { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'any' },
```

## 常见问题

- 色带高度是固定的，而眉题、标题和导语从上页边距往下挂、向下生长，所以导语长一些或标题排成三行，就会压到底边上。像两个版本那样把导语控制在五行左右，或者根据最长的章首页推算`BAND`。
- 章号`y`的公式假定`lineHeight: 1`。设计文本的基线位于行框自上而下0.8处，只有行框与字号等高时，`0.8 * NUMERAL`才是这段距离。改了行距或锚点，公式也要跟着改。`BEARING`是目测确定的，因为每个数字的侧空都不同（这里的3和4末端相差0.8 mm）。
- 样式的调色板会给设计元素和文字改色，图片则保留绘制时的颜色：图4.1是青绿色，是因为代码用`band2`绘制它；放在第4章里的一幅赭红色图仍会是赭红色。
- 在`parity: 'odd'`下，如果某章比最后一页多出几行，就会留下几乎空白的一页，外加下一个章首页之前的一个空白左页。像这里的两个版本那样调整文字篇幅，并在正文或`BAND`改动后检查每章的最后一页。
