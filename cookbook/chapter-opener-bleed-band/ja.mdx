## できあがり

『Earth in Motion』という、210 × 280 mm判の地質学入門の教科書の章扉です。第3章は、ページ上端から裁ち落としにしたテラコッタ色の帯の下で始まります。帯には字間を広げたキッカー、著者が選んだ位置で改行したタイトル、イタリックのリード文、そして小口側で帯の濃い下端に立つ168 ptの章番号が載ります。帯の下から両端そろえの2段組みが始まり、沈み込むプレートの断面図がページの地を占めます。第4章は同じデザインをティール色で繰り返し、ツメ、節番号、参照、図のラベルまで色が変わります。デザインはレベル1見出しに一度だけ設定します。各章の見出し行が、キッカーの話題とリード文を属性として渡し、章が別の色を取るときはスタイルの名前を指定します。

## 作り方

### 1 · 帯と数字をページから吊るす

コードは上の[手短な答え](#手短な答え)にあります。帯とその下端は、裁ち落とし領域の左上の角から吊るします。幅を指定しないボックスや罫線はどれもそうですが、その枠の反対側の端まで伸びるので、仕上がり線まで届き、`BLEED`を設定すれば裁ち落としまで届きます。数字はページの右上の角から吊るします。`y: BAND - 0.8 * NUMERAL * PT`はベースラインを帯の下端に置き、`BEARING`は数字のサイドベアリングを補うためにボックスを2 mm余白側へ動かすので、インクがおおよそ本文の端にそろいます。キッカーはコンテナーから吊るします。タイトルはキッカーの下に、リード文はタイトルの下に、`overflow: 'wrap'`付きの`below`アンカーで吊るすので、タイトルが長くなるとリード文は下へ押されます。リード文は見出しの`lead`属性で埋まるテキスト要素です。著者名の行を加えるなら、もうひとつ`{attr.author}`を同じようにつなげます。`minHeight: BAND - TOP + AIR`は本文の始まる位置を決めます。数字のボックスは下端よりサイズの0.2倍（11.9 mm）下まで届き、章扉は最も低い要素までのスペースを確保するので、`AIR`は少なくとも11.9 mm必要です。それより小さいと、本文の始まる位置を数字のボックスが決めてしまいます。

### 2 · 章見出しにページを与える

<Excerpt region="levels" />

`span: 'page'`は各章を新しいページで始め、レベル1見出しを2段にまたがって組みます。`advancedDesign`は見出しのテキストの代わりに章扉を描き、本文は確保した高さの下から始まります。`span`だけでは、奇数ページか偶数ページかを問わず次のページを取ります。また`headings`オブジェクトがあると、奇数ページへ改ページするという既定の動作がなくなります。そこで`parity: 'odd'`で改ページを明示し直し、どの章扉も奇数ページに置きます。奇数ページなら、数字の右側のアンカーが小口になります。レベル2では、`numberingTemplate: '{1}.{2}'`が節を3.1、3.2…と帯の色で番号付けします。レベル3に`'{1}.{2}.{3}'`を付ければ、3.1.1へと続きます。

### 3 · 章の色に一度だけ名前を付ける

<Excerpt region="palette" />

設定の中の色は、すべてこれらの項目のどれかにリンクしています。エンジン自身の既定値は`main-color`にリンクしているので、この項目を帯の色に向けると、設定で指定していない既定の色もすべて変わります。第4章の見出し行`# Fire from \\ Below {style="teal" topic="Volcanoes" lead="…"}`はスタイルを選び、次のレベル1見出しまで`band`を入れ替えます。デザインの各要素はパレットのリンクを通じてこの入れ替えに従い、基本の`band`と同じ文字色も塗り直されます。そのため<PageRef page={3}>43ページと44ページ</PageRef>では、ツメ、節とリストの番号、参照、キャプションのラベル、下ノンブルがティール色になります。同じ行が`{attr.topic}`と`{attr.lead}`を埋め、その中の`\\`が`{titleText}`を著者の望む位置で改行します（[見出しの属性](/ja/docs/document-format#見出しの属性)、[タイトル内の改行](/ja/docs/document-format#タイトル内の改行)）。

### 4 · 図は最初の参照に置き場所を決めさせる

<Excerpt region="figure" />

`:ref`は図に番号を付け、それを参照する段落の後の最初の空きスロットに置きます。図3.1は`auto`です。両方の段にまだ余裕があるうちに章扉で参照されるので、そのページの地を取ります。`top`のフロートなら42ページの頭に置かれていたはずです。フロートは自分の参照より上には決して行かないからです。図4.1は43ページの第2段の下のほうで参照され、そこにはもうページ幅の帯が収まらないので、`bottom`が44ページへ送ります。44ページは章の最後のページで、最後のページでは、エンジンが地のフロートを持ち上げ、上に隙間を空けずに本文の最終行の直下に置きます。

### 5 · 柱、ツメ、下ノンブル

<Excerpt region="heads" />

ヘッダーの各要素はページの上の角から吊るし、`parity`で絞り込むので、ノンブルとツメは常に小口側に来ます。ツメのボックスは代わりに裁ち落とし領域の角から吊るし、`BLEED`に応じて幅が広がるので、断裁後も裁ち落としのままです。`pages: 'body'`はこれらを章扉から外します。章扉にはフッターから下ノンブルが付きます。偶数ページの柱は`{chapterTitle}`で章名を1行で示します。`\\`がタイトルを改行するのは章扉の中だけだからです。教科書では奇数ページの柱に節名を入れるのが普通です。Postext 1.4.1には節名のプレースホルダーがないので、奇数ページの柱には本の`{title}`を印刷します。この4ページでは、奇数ページが2つとも章扉なので、それが見えることはありません。

### 6 · 本を第3章から始める

<Excerpt region="build" />

この4ページは長い本の第3章と第4章なので、`buildDocument`には、第1章と第2章が終わった時点のカウンターを持つ`continuation`を渡します。その`headings`に`h1: 2`があるので、次の`#`は第3章になります。`{chapterNumber}`は3を印刷し、節は3.1から番号付けされ、最初の図は3.1になります。`pageNumbering.startAt: 41`はノンブルを41から始めます。偶奇は物理的なページで数え、`pageIndexOffset`を0のままにしているので、最初のページはノンブルが何であっても奇数ページのままです。それに合わせて、最初のノンブル41も奇数にしています。

## アレンジ

### 帯を深くする

`BAND`は帯の深さ、数字の位置、本文の上に確保する高さを決めます。帯を深くすると本文が次のページへ押し出されるので、章ごとに原稿量を合わせ直すか（最後のつまずきを参照）、章を追い込みにします。

```diff
-const BAND = 100; // mm from the trim to the foot of the band
+const BAND = 128; // mm from the trim to the foot of the band
```

### 裁ち落とし付きで印刷する

3 mmの裁ち落としを付けると、帯、その下端、ツメは仕上がり線より3 mm外へはみ出し、数字は下端に立ったままで、`page.cutLines`が同じ値で有効になります。

```diff
-const BLEED = 0; // mm: 0 on screen; about 3 for print, which also switches on page.cutLines
+const BLEED = 3; // mm: 0 on screen; about 3 for print, which also switches on page.cutLines
```

### 別の章の色を足す

章の色ひとつにつき、パレットの項目とスタイルをひとつずつ足します。その章の見出し行に`{style="slate"}`と書きます。

```diff
   band2: '#2e6f73', // the second chapter colour, a teal; the sea in Figure 3.1
+  band3: '#3d4f6b', // a third chapter colour, a slate blue
@@
-const headingStyles = [{ id: 'teal', palette: { band: palette.band2 } }];
+const headingStyles = [{ id: 'teal', palette: { band: palette.band2 } },
+  { id: 'slate', palette: { band: palette.band3 } }];
```

### 章を追い込みにする

`'any'`にすると、章は次のページで始まります。奇数ページで終わった章の次は偶数ページで、前に白ページを挟まずに始まり、数字はページの右端から吊るしているので、のど側に立ちます。第3章はすでに偶数ページで終わっているので、この4ページは変わりません。

```diff
-      { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'odd' },
+      { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'any' },
```

## よくあるつまずき

- 帯の高さは固定ですが、キッカー、タイトル、リード文は天の余白から吊るして下へ伸びるので、リード文が長かったり、タイトルが3行になったりすると、帯の下端にぶつかります。リード文は両方の版と同じく5行程度に収めるか、いちばん長い章扉から`BAND`を求めてください。
- 数字の`y`の式は`lineHeight: 1`を前提にしています。デザインテキストのベースラインは行ボックスの上から0.8の位置にあり、`0.8 * NUMERAL`がその距離に一致するのは、ボックスの高さが活字と同じときだけです。行の高さやアンカーを変えたら、式も変える必要があります。`BEARING`は目で合わせています。数字ごとにサイドベアリングが違うからです（ここでは3と4の終わりが0.8 mmずれています）。
- スタイルのパレットはデザイン要素と文字の色を変えます。画像は描かれた色のままです。図4.1がティール色なのはコードが`band2`で描いているからで、テラコッタ色の図を第4章に置けばテラコッタ色のままです。
- `parity: 'odd'`では、最後のページから数行はみ出した章は、ほとんど空のページと白の偶数ページを残してから次の章扉に進みます。しかもpostext 1.4.1はそのページを本文より短い段で組むので、章の最終行が失われます。ここの両方の版と同じく原稿量を合わせ、本文や`BAND`を変えるたびに各章の最後のページを確かめてください。
