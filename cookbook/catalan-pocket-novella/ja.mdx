## できあがり

ナルシス・ウリェーの『El transplantat』を、『Obres completes』（バルセロナ、1928年）の本文で全編、12 × 18.5 cmの32ページの文庫本に組みます。4つの章の前に、前扉、窯の前に立つパン屋の口絵、赤いイタリックのCormorant Garamondで組んだ本扉、版についての注記が入ります。各章は12行分の深さの版画の下で始まり、ローマ数字は赤です。本文は10.4 ptのCrimson Proで、Institut d’Estudis Catalansが求めるとおりカタルーニャ語の音節で改行します。分割の両側に最低2文字を残し、母音分立の母音のあいだでは分けず、アポストロフィの直後でも分けません。*titil·laven*は*titil-* | *laven*と分け、ハイフンが中点の代わりになります。会話はemダッシュで、引用は«cometes baixes»で組みます。

## 作り方

### 1 · カタルーニャ語をコードで指定する

コードは前出の[手短な答え](#手短な答え)にあります。`locale: 'ca'`でカタルーニャ語のパターンが選ばれ、postext 1.14以降、それはIECの『Llibre d’estil』に従います（[対応するロケール](/ja/docs/justification#対応するロケール)）。パターンはTeXと同じもので、npmパッケージが同梱する3文字ではなく、分割の両側に最低2文字を残すため、*ter-ra*、*cai-xa*、*plu-ja*も分割できます。母音分立の母音は離さず（*cièn-cia*、*ca-mions*）、母音にはさまれた*i*は次の音節の頭になります（*fe-ia*）。*ela geminada*は2つの*l*のあいだで分けます。行は*titil-*で終わり、次の行は*laven*で始まり、どちらにも中点は残りません。Knuth–Plassも中点を除いて行を測ります。

<PageShot page={27} crop="0.06,0.495,0.88,0.085" caption="27ページ。行末のtitil·lavenはtitil- | lavenと組まれます。この32ページで行末に来るl·lはこの1か所だけです。" />

`compounds: false`は、動詞と代名詞を、そのあいだのハイフン以外では分けません（*arrossegar-* | *se*）。IECが好む分け方です（[ハイフネーション](/ja/docs/configuration-text#ハイフネーション)）。代償はゆるい行1つです。7ページでは、`maxJustifyTracking: 10`がほかの行で余りを吸収しても、*d’inaugurar-se*の前の行は語間が1.94倍に広がります。

### 2 · 行がきっちり収まる文庫のページ

<Excerpt region="page" />

地の余白は仕上がりサイズ、天の余白、`LINES`から決まるので、版面には14 ptの行が29行入り、すべての満ページが同じベースラインで終わります。89 mmの行長にはCrimson Proでおよそ64字が入ります。`mirror: true`で、見開きのどちらのページでも16 mmの余白がのど側に来ます（[見開きの余白](/ja/docs/configuration-page-layout#見開きの余白)）。

### 3 · 4つの章に1つの章扉

<Excerpt region="opener" />

`resourceId: '{attr.art}'`は見出しが指定した絵を描くので、`# II {style="capitol" art="cap2"}`は第II章を、ほかの章と同じスタイルのまま専用の版画の下で始めます（[見出しの属性](/ja/docs/document-format#見出しの属性)）。`minHeight`で16行を確保します。絵に12行、数字とその罫に4行で、本文はどの章でもページの17行目から始まります。

### 4 · 第I章の前の4ページ

<Excerpt region="front" />

前付けの各部分は、それぞれ専用のスタイルを持つ1レベル見出しです。`# El transplantat {style="portada"}`はフロントマターの著者と副題を印刷し、見出しを表題として印刷します。スタイルはレベルの改ページを継承するため、どのスタイルでも改ページを書き直し、ヘッダーとフッターを空にします。そのためこれらのページには柱もノンブルもありません。口絵は偶数ページの2ページに来るので、見開きで本扉と向き合います。

### 5 · 偶数ページに著者、奇数ページに表題

<Excerpt region="heads" />

`parity`で偶数ページに著者を、奇数ページに表題を置きます。`pages: 'body'`で章扉にはどちらも出さず、章扉では`pages: 'opener'`を指定した地のノンブルが代わりに入ります。`SHIFT`は各柱を版面の中央に移します。2つの余白の幅が違うので、版面の中央はページの中央から0.5 mmずれています。

### 6 · ラベルのない5点の版画

<Excerpt region="pictures" />

絵は`captionPrefix`が空のリソース種別に属するので、番号もラベルも付きません。それぞれピクセル寸法で宣言し、組版の前にファイルIDで読み込みます。保存する前に白をページのクリーム色に、黒をインクの色に置き換えてあるので、上に貼った写真ではなく、ページの一部として印刷されます。

## アレンジ

### 代名詞の部分でも分割させる

既定の`compounds: true`では、*d’inaugurar-se*を*d’inau-gurar-se*と分けられ、7ページのゆるい行がなくなります。その代わり、このページ範囲では`titil-` | `laven`の分割が行末から外れます。

```diff
-  hyphenation: { compounds: false },
+  hyphenation: { compounds: true },
```

### どの章も奇数ページで始める

`parity: 'odd'`は、偶数ページで始まるはずの章の前に白ページを入れます。余裕のある版の組み方です。26ページで始まる第IV章は、白ページのあとの27ページに移ります。

```diff
-  breakBefore: { enabled: true, parity: 'any' }, // a chapter opens on the next page, either side
+  breakBefore: { enabled: true, parity: 'odd' },
```
