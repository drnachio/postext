## できあがり

『紅樓夢』の薄い読本です。第1回から第3回のうち、登場人物が初めて現れるくだりを再録し、巻末に47人の名前の索引を置きます。ほかの呼び名からの参照も4つあります。同じマークから2つの版を組みます。中国本土向けの簡体字版は名前を拼音の頭文字F、H、J…で分類し、台湾向けの繁体字版は最初の字の画数、三畫、四畫…で分類します。どちらも140 × 203 mmの大32开のペーパーバックで、本文はNoto Serifで1行26字、回の題は楷体の書体で、キッカー、ノンブル、索引の見出しはNoto Sansで組みます。カードには簡体字版の索引の最初の組、FからLまでを拡大して載せています。<RecipeLink slug="names-and-subjects-indexes">人名索引と事項索引</RecipeLink>では、英語の研究書で同じ種類の索引を組んでいます。

## 作り方

### 1 · 読者が初めて出会う箇所に名前の印をつける

コードは上の[手短な答え](#手短な答え)にあり、残りはMarkdownの中にあります。マークは、本文が何を印字していても、フルネームで項目を立てます。`字:index[士隐]{term="甄士隐" main}`は士隐と印字し、そのページを甄士隐の項目に入れます。`main`はそのページを太字にします。索引の表題の下の注記は、ここでの太字の意味、つまりその人物が本人として登場するページであることを説明しています。賈宝玉は第2回で名前を出されないまま生まれる（又生了一位公子）ので、印字する文字のないマーク`:index{term="贾宝玉"}`を置き、項目は4, **6**となります。別名やあだ名にはそれぞれ参照項目を立てます。`:index[凤辣子]{term="凤辣子" see="王熙凤"}`は、Postextが中国語の流儀、つまり句点の後に空白を入れずに、凤辣子。见王熙凤と印字します（[索引マーク](/ja/docs/document-format#索引マーク)）。

### 2 · 並べ方はロケールに選ばせる

<Excerpt region="editions" />

2つの版は設定を共有し、索引について切り替えるのは`locale`だけです。`groupBy: 'auto'`は`zh-Hans`の索引を拼音で、`zh-Hant`の索引を画数で分類します。手短な答えでは、見てわかるように2つの値を書き出しています。項目は見出しと同じ基準で並ぶので、同じ名前でも順番が入れ替わります。甄费はZの組で甄士隐の前に来ますが（fèiはshìより前）、十四畫の組では後になります（士は3画、費は12画）。宁国公と荣国公はNとRに分かれますが、寧國公と榮國公は14画の名前の中で並んだままです（[索引](/ja/docs/configuration#索引)）。読みと画数はブラウザーの中国語の照合順序によるものです。読みを誤る姓（曾、单、解）には、正しい読みを表す字で`sort`キーを与えます。

### 3 · 書体ごとに、組む字だけを読み込む

<Excerpt region="voices" />

Fontsourceは中国語の各ウェイトを約100のファイルに分けており、`loadCjkFonts`はテキストが触れるファイルだけを取りに行きます。宋体には本全体を渡すので、柱の文字に追加の負担はありません。宋体のボールドには主要ページを示す数字、黒体には`kicker`属性のテキスト、索引の見出し、ノンブルの数字、楷体には3つの対句と人名索引を渡します。PDFも同じ道をたどります。`cjkPdfProvider`はそれらのファイルを、ページで使う字だけに絞って埋め込むので、空の四角になる字はありません。楷体は版によって変わります。Fontsourceにある唯一の本文用の楷体LXGW WenKai TCは旧字形で描き（冷の旁の令の下が古い卩の形）、読点と句点を字面の中央に置きます。そのため簡体字版の題は、本土の字形を持つ筆書きの楷体Ma Shan Zhengで組んでいます（[中国語・日本語・韓国語のフォント](/ja/docs/configuration#中国語日本語韓国語のフォント)）。

### 4 · 注記は索引の扉に置く

<Excerpt region="opener" />

注記は見出しの属性`# 人名索引 {style="index" kicker="按汉语拼音排列" note="…"}`で、2段組みの上に行長いっぱいで組みます。段の中の段落にしていたときは、段末そろえの調整に使われてしまいました。繁体字版の最終ページの段をそろえるために、14字の段で1行12字までゆるめられたのです。注記は`本索引收录前三回选文中的人物，粗体页码为人物出场之页；别名与原名另立参见条目。`という1つの文で、デザインが行を折り返します。中国語の本のデザインテキストは本文と同じ禁則処理と約物の幅に従うので、，；は簡体字版では半角、繁体字版では全角になり、本文とそろいます。注記の行が約物で始まることもありません。回の扉も同じデザインを使い、キッカーは`第{numberHan}回`です。これは文書の文字体系で第一回と印字します。

### 5 · 2つの版の索引ページを並べて見せる

<Excerpt region="side-by-side" />

CodePenのサンプルは両方の版をビルドし、デスクには簡体字版を表示します。简体版と繁體版のボタンでデスクを切り替えると、そのたびに表示中の版のPDF、`chinese-name-index-hans.pdf`か`chinese-name-index-hant.pdf`が提供されます。キャプチャーは両方のビルドを記録します（`capture.doc: ['first', 'last']`）。上の最初の8ページが簡体字版、その後の4ページが繁体字版で、最初のページと画数順の索引です。デスクの上の帯には、それぞれの版の索引の最初のページを並べています。レシピに添えたPDFは簡体字版のものです。

## アレンジ

### 繁体字の索引を拼音で分類する

名前を読みで引く読者向けの繁体字版なら、拼音で分類できます。両方の版で`groupBy: 'pinyin'`にすると、見出しはA–Zになり、項目は繁体字の字形のままです。キッカーは索引の並べ方を示しているので、繁体字のMarkdownでも`kicker="依漢語拼音排列"`に変えてください。

```diff
-  groupBy: e.locale === 'zh-Hans' ? 'pinyin' : 'stroke', // A B C… or 三畫 四畫…
+  groupBy: 'pinyin', // A B C… in both scripts
```

### 見出しなしで名前を並べる

短い名前の一覧なら、組のあいだを1行空け、見出しを置かなくても読みやすく組めます。分類はそのままにして、見出しだけを消します。`groupBy: 'none'`ではうまくいきません。これは記号、数字、単語だけを分けるもので、ここでは名前がすべて漢字で始まるため、47人が一塊になってしまいます。

```diff
-  groups: { fontFamily: e.sans, fontSize: pt(9.5), fontWeight: 700, color: col('cinnabar'),
-    marginTop: pt(7) },
+  groups: { enabled: false, marginTop: pt(14) }, // no heads; a blank line between groups
```

## よくあるつまずき

- `index`の設定は文書に属するので、1つの文書で印字できる並べ方は1つです。拼音順の索引と画数順の検字表の両方がほしい本は、このCodePenのサンプルと同じように2回ビルドします。
- 字詰めグリッドでは段末そろえが既定でオフなので、そのままでは各索引の最終ページで第1段が地まで埋まります。簡体字版の奥付はZの下で始まり、第2段の頭で終わります。`headings.balancing: { enabled: true }`にすると、このページの2つの段がそろい、奥付は第2段の名前の下にまとまって入ります（[段末そろえ](/ja/docs/configuration#段末そろえ)）。
