## 成品一览

一本薄薄的《紅樓夢》读本，从第一回到第三回中选印了人物初次登场的段落，书末附一份人名索引，收47个人名，另有四条从别名指过来的参见。同一套标记生成两个版本。大陆版用简体字，按拼音首字母F、H、J……归组；台湾版用繁体字，按首字的笔画数三畫、四畫……归组。两版都是大32开平装，140 × 203 mm，每行26字，正文用Noto Serif，回目用楷体，眉题、页码和索引分组标题用Noto Sans。卡片上放大的是简体版索引的前几组，F到L。<RecipeLink slug="names-and-subjects-indexes">人名索引与主题索引</RecipeLink>为一本英文专著做了同类的索引。

## 做法

### 1 · 在读者遇到人名的地方加标记

代码见上文的[简短回答](#简短回答)，其余都在Markdown里。无论正文印的是什么，标记都以全名归档：`字:index[士隐]{term="甄士隐" main}`印出士隐，在甄士隐名下记一个页码。`main`让这个页码排成粗体，索引标题下的说明交代了粗体在这里的含义：人物亲自登场的那一页。贾宝玉在第二回出生时没有提名字（又生了一位公子），所以这里的标记不印任何文字，写作`:index{term="贾宝玉"}`，他的条目读作4, **6**。别名和绰号有自己的参见条目，`:index[凤辣子]{term="凤辣子" see="王熙凤"}`，Postext按中文习惯印出，前面是句号，不留空格：凤辣子。见王熙凤（[索引标记](/zh/docs/document-format#索引标记)）。

### 2 · 让语言区域决定排序

<Excerpt region="editions" />

两个版本共用同一份配置，索引只需要`locale`这一个开关：`groupBy: 'auto'`让`zh-Hans`索引按拼音分组，让`zh-Hant`索引按笔画分组；简短回答把这两个值明确写了出来，方便你看清。条目按分组标题所依据的顺序排列，所以同样的人名会换位置：在Z组下，甄费排在甄士隐之前（fèi在shì之前），在十四畫下则排在其后（士三画，費十二画）；宁国公和荣国公分入N和R两组，而寧國公和榮國公在十四画的人名中仍然挨在一起（[索引](/zh/docs/configuration#索引)）。读音和笔画数来自浏览器的中文排序规则；遇到读错的姓（曾、单、解），就用读音正确的汉字给它一个`sort`键。

### 3 · 每种字体只加载它要排的字符

<Excerpt region="voices" />

Fontsource把每个中文字重拆成约一百个文件，`loadCjkFonts`只取文本用到的那些。宋体拿到整本书，所以书眉不额外占用它的文件；宋体粗体拿到主要页码的数字；黑体拿到`kicker`属性的文字、索引分组标题和页码的数字；楷体拿到三副对联和人名索引。PDF走同样的路线：`cjkPdfProvider`嵌入这些文件，每个文件都裁剪到页面上实际用到的字符，没有哪个字会变成空框。楷体随版本而变。LXGW WenKai TC是Fontsource上唯一的楷体正文字体，它用传承字形，比如冷字里令的下部写成旧式的卩，逗号和句号也居中，所以简体版的标题改用Ma Shan Zheng，一种采用大陆字形的毛笔楷体（[中日韩字体](/zh/docs/configuration#中文日文和韩文字体)）。

### 4 · 把说明放进索引首页

<Excerpt region="opener" />

说明是标题的一个属性，`# 人名索引 {style="index" kicker="按汉语拼音排列" note="…"}`，排在两栏上方，占满整个行长。如果把它作为栏内的段落，它就会成为各栏齐底的调节手段：为了让繁体版最后一页齐底，排版把它放松到每行十二字，而栏宽是十四字。设计文本没有中文避头尾规则，所有标点都排全角，而简体正文把，、；排成半角，所以说明写成三个短句，每句一行（属性中用`\n`），每句只有句末一个句号。章首页也用这个设计，眉题是`第{numberHan}回`，按文档的字形印出第一回。

### 5 · 把两个索引页并排展示

<Excerpt region="side-by-side" />

这个pen构建两个版本，桌面上显示简体版。简体版和繁體版两个按钮切换桌面，每次切换都提供当前版本的PDF，即`chinese-name-index-hans.pdf`或`chinese-name-index-hant.pdf`。截图记录两次构建（`capture.doc: ['first', 'last']`）：上面前八页是简体版，其后四页来自繁体版，即它的第一页和笔画索引。桌面上方的条带放着两个版本各自的索引首页。随食谱提供的PDF是简体版的。

## 变化

### 繁体索引按拼音分组

面向按读音查名字的读者，繁体版也可以按拼音归档。在两个版本中都设`groupBy: 'pinyin'`：分组标题为A–Z，条目保留繁体字形。眉题说明了索引的排列方式，所以繁体版的Markdown里也要把它改成`kicker="依漢語拼音排列"`。

```diff
-  groupBy: e.locale === 'zh-Hans' ? 'pinyin' : 'stroke', // A B C… or 三畫 四畫…
+  groupBy: 'pinyin', // A B C… in both scripts
```

### 不带分组标题的人名表

简短的人名表可以不加分组标题，只在各组之间空一行。保留分组，关掉标题即可。`groupBy: 'none'`做不到这一点：它只把符号、数字和词语分开，而这里每个人名都以汉字开头，47个人名会连成一整块。

```diff
-  groups: { fontFamily: e.sans, fontSize: pt(9.5), fontWeight: 700, color: col('cinnabar'),
-    marginTop: pt(7) },
+  groups: { enabled: false, marginTop: pt(14) }, // no heads; a blank line between groups
```
