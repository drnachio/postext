## できあがり

樋口一葉の『たけくらべ』（1895〜96年）の第1章を、四六判の版として4ページに組みます。作品が描く昔の吉原について、7つの注を付けます。注は傍注（ぼうちゅう）、つまり古典の文庫本で使われる傍らの注です。説明する語のあとの行の右に小さな（1）が立ち、見開きの両ページで引用された注は、左ページの小口側に、行長の3分の1の罫の下に、5分の1小さい文字で組まれます。読者はページをめくらずにどの注にもたどり着けます。本文は9.25 ptのShippori Minchoで1行42字、17行です。一葉の長い1つの段落と、ぎつちよんちよんに打たれたゴマの圏点をそのまま残しています。ヨーロッパの小説で段の下に注を置く例は<RecipeLink slug="novel-footnotes-column-foot">No. 071</RecipeLink>です。

## 作り方

### 1 · 見開きの注を左ページの小口側にまとめる

コードは上の[手短な答え](#手短な答え)にあります。`footnotes.placement: 'spread'`は、2ページと3ページで引用された注を3ページの本文の最後、つまり右綴じの本ではその小口側に組みます。`numbering: 'spread'`で、注の番号は見開きごとに（1）から始まります（[脚注](/ja/docs/configuration-notes-references#脚注)）。右ページで引用された注は左ページを待ちます。注のせいで左ページに本文が1行も残らなくなる場合は、残りの注は右ページの地に置かれます。JLReqが認めているとおりです。`ja`のタグを付けた文書では、縦組みの本の合印はすでに行の右に0.7 emの`（{n}）`として、数字を正立させて組まれます。明示的に書いた2行はそれを示すためのものです。`numberGap: 'em'`で番号のあとに注の文字の全角1字分をあけ、`hangingIndent: em(2)`で折り返し行をその先にそろえます。

### 2 · 日本語の慣習どおりの位置に合印を書く

Markdownでは、注が説明する語のあとに`見返り柳[^1]`と書き、注は章の最後に`[^1]: …`の段落として書きます。合印は注が説明する語のあとに置きます。文末に来る合印は。の前に置き（`…先生[^1]。`）、エンジンは。や合印を行頭に置きません。7つの注はこのレシピのために書いたもので、見返り柳とお齒ぐろ溝が何だったか、大音寺前がどこにあったか、酉の市で何が売られていたかを、平易な現代の日本語で説明しています。

### 3 · 底本のゴマの圏点を残す

`cjk.emphasisMark`は、この本で`*…*`と`:dots[…]`が何を印字するかを決めます。縦組みの行の右に打つゴマ点です。`ja`の文書はすでにゴマ点を使います。明示的に書くと、機能一覧の圏点の項目が有効になります。青空文庫のテキストはぎつちよんちよんに傍点を付けており、`aozora.py`はそれを`:dots[ぎつちよんちよん]{style=sesame}`と書きました。中国語の本では代わりに行の下に点を打ちます（[圏点と傍線、ルビ、割注](/ja/docs/configuration-east-asian#圏点と傍線ルビ割注)）。

### 4 · 見開きで始める

<Excerpt region="opener" />

章の最初の文は、最初の3行のうちに4つの注を引用します。1ページの表題の下に組むと、本文には3行分の場所しか残りません。左ページに入るのはその見開きの注だけで、ほかのページの注は入りません。1ページに扉だけを単独で置くと、章は右ページの2ページへ移り、最初の見開きに本文とそのすべての注が収まります。扉は第1レベルの見出しで、そのデザインがページを埋めます。仕上がりに固定しているので、表題はページの中心線上に立ちます。

### 5 · 柱とノンブルを小口側に縦に入れる

<Excerpt region="furniture" />

表題は左ページの小口側の余白に、注の外側に縦に入ります。漢数字のノンブルは、扉を除くすべてのページの下に入ります。

## アレンジ

### 注を章の最後にまとめる

`placement`を指定しないと、縦組みの`ja`の本は注を後注（こうちゅう）として組みます。章の本文のあとに、同じ罫の下に、章を通した番号で組まれます。ここでは注が4ページの左半分を埋めます。

```diff
-  placement: 'spread', // 傍注; 'chapterEnd' sets 後注 after the chapter instead
-  numbering: 'spread',
+  placement: 'chapterEnd', // 後注, the default for a vertical ja book
+  numbering: 'chapter',
```

### 合印を語の横に置く

`markerPosition: 'side'`にすると、行間のルビのように、行の横のあきに小さな合印を組みます。合印は行の中の場所をまったく取りません。

```diff
-  markerPosition: 'right', markerTemplate: '（{n}）', // written out: 'ja' sets them so
+  markerPosition: 'side', markerTemplate: '{n}',
```
