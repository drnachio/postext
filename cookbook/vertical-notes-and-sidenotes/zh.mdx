## 成品一览

四六判樋口一葉《たけくらべ》（1895–96）的四页，第一章，附七条注释，讲它所写的旧吉原一带。这些注释是傍注（bōchū），日本古典文库本的旁注：小号的（1）标在所释词语之后、行的右侧，一个跨页两页上引出的注释都排在左页的切口一侧，上面一条长为行长三分之一的线，字号小五分之一。读者不必翻页就能找到每一条注。正文每行42字、共17行，用9.25 pt的Shippori Mincho，保留一葉那一整个长段落和ぎつちよんちよん上的芝麻点。欧洲小说的栏脚注见<RecipeLink slug="novel-footnotes-column-foot">Nº 071</RecipeLink>。

## 做法

### 1 · 把跨页的注释集中在左页切口

代码见上文的[简短回答](#简短回答)。`footnotes.placement: 'spread'`把第2、3页上引出的注释排在第3页正文的末尾，在右侧装订的书中就是它的切口一侧；`numbering: 'spread'`让每个跨页的注释从（1）开始编号（[脚注](/zh/docs/configuration-notes-references#脚注)）。在右页引出的注释要等到左页才排；如果注释让左页剩下不到一行正文，其余的注释就留在右页的脚部，JLReq允许这样做。标为`ja`的文档已经把竖排书的注释编号排成`（{n}）`，放在行的右侧，0.7 em，数字直立：这里写出的两行只是展示这一点。`numberGap: 'em'`在编号后放一个注释字号的全角空格，`hangingIndent: em(2)`让转行与编号之后的文字对齐。

### 2 · 把编号放在日文放它的位置

Markdown在所释词语之后写`見返り柳[^1]`，把注释写成章末的`[^1]: …`段落。编号跟在所释词语之后；结束一句的编号放在。之前（`…先生[^1]。`），引擎不让。或编号出现在行首。七条注释是为本食谱写的，用平实的现代日文说明見返り柳和お齒ぐろ溝是什么，大音寺前在哪里，酉の市上卖什么。

### 3 · 保留原文的芝麻点

`cjk.emphasisMark`决定本书中`*…*`和`:dots[…]`印出什么：芝麻点，位于竖排行的右侧。`ja`文档本来就用它；写出来之后，用料列表里会出现着重号这一项。青空文库的文本给ぎつちよんちよん加了傍点，`aozora.py`把它写成`:dots[ぎつちよんちよん]{style=sesame}`；中文书则把点放在行的下方（[着重号、注音与夹注](/zh/docs/configuration-east-asian#着重号注音与夹注)）。

### 4 · 从一个跨页开始

<Excerpt region="opener" />

本章的第一句在头三行里就引出四条注释。如果在第1页的标题下排正文，这些注释只给正文留下三行的地方：左页只放自己的注释，不放别页的。把书名页单独放在第1页，本章就移到第2页，一个右页，于是第一个跨页同时容纳正文和它的全部注释。书名页是一个一级标题，它的设计占满整页，锚定在成品页面上，所以书名立在页面的中轴上。

### 5 · 柱和页码排在切口

<Excerpt region="furniture" />

书名沿左页的外页边距竖排，在注释之外；除书名页外，每一页的底部都有汉字页码。

## 变化

### 把注释集中在章末

不设`placement`时，竖排的`ja`书把注释排成后注（後注，kōchū）：放在本章正文之后，上面是同样的线，全章连续编号。在这里它们占满第4页的左半。

```diff
-  placement: 'spread', // 傍注; 'chapterEnd' sets 後注 after the chapter instead
-  numbering: 'spread',
+  placement: 'chapterEnd', // 後注, the default for a vertical ja book
+  numbering: 'chapter',
```

### 把编号放在词语旁边

`markerPosition: 'side'`把一个更小的编号放在行旁的空隙里，就像行间注音那样，所以它在行内不占任何位置。

```diff
-  markerPosition: 'right', markerTemplate: '（{n}）', // written out: 'ja' sets them so
+  markerPosition: 'side', markerTemplate: '{n}',
```
