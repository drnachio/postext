## 成品一览

海岸杂志《Littoral》的三页：一篇关于菲涅耳透镜的长文，开篇是一幅画，画的是灯室里点亮的透镜。正文用 Public Sans 排成两栏齐左，段与段之间空一条网格线；寡行和孤行规则要求每段在断开处两侧至少各留两行。示例把这篇文章排了两遍。不开启设置时，在<PageRef page={1}>开篇页</PageRef>上，左栏比右栏早结束一行：下一段不能只在栏底放一行。开启后，在<PageRef page={4}>同一页</PageRef>上，第一段多排了一行，两栏都结束在网格的最后一行。翻到下一页，这个设置还收回了平衡在两个小标题上方多加的空白。

## 做法

### 1 · 给齐左排的栏一个自己的手段

<Excerpt region="answer" />

栏平衡补满短栏的办法是：在标题上方、列表之后、方框或插图下方加网格线，最后才把两端对齐的段落放松一行。齐左排的正文栏在小标题之间没有这些位置，寡行和孤行规则留下的那一行就空着。`fillShortColumns` 让这一栏里某个齐左的段落按自身的词距多排一行；如果没有段落能做到，就把某段少排一行，让断开处后面的段落上移补满这一行。只有当短栏变少时引擎才保留这一改动，所以开启它不会让任何一页变差。`maxLinesBeforeLoose: 0` 先试段落再试标题，于是每个小标题上方都只保留一条网格线的空白。

### 2 · 排两遍再比较

<Excerpt region="builds" />

两份文档出自同一份配置和同一段 Markdown。第二遍直接使用配置；第一遍使用关闭了该设置的副本，因此在 Sandbox 中打开的文件包带有 `fillShortColumns: true`。桌面上方的两个按钮在两遍之间切换。只有文字继续流向下一页的页面才会排到栏底：第 3 页是文章的结尾，两遍中它的各栏都被截成一样高。

### 3 · 用画作开篇

<Excerpt region="opener" />

这幅画是锚定在出血线上的图像元素，高 150 mm，所以三边都延伸到裁切线，浮动元素做不到这一点。眉题、标题、导语和署名都来自 `#` 行的属性。署名下方有 6 mm 的内边距，计入开篇的高度，所以正文栏从它下面的第一条网格线开始。

### 4 · 开篇页不放书眉

<Excerpt region="heads" />

左页书眉从 frontmatter 取杂志名和期号，右页取文章标题，`pages: 'body'` 让两者都不出现在开篇页上，开篇页只在页脚放页码。标签比页码低 0.35 mm，让两种字号共用一条基线。下方的细线长 197 mm，等于版心宽度。

## 变化

### 让小标题先吸收空白

按默认顺序，标题在段落被拉长之前最多可取两条网格线，下一页的小标题上方又会变宽。

```diff
-  maxLinesBeforeLoose: 0,
+  maxLinesBeforeLoose: 2,
```

### 改为两端对齐

两端对齐的段落在不开启设置时就能在 `maxWordSpacing` 以内多排一行。开启 `fillShortColumns` 后，它也可以少排一行，而且不会比它自己最松的一行更松。

```diff
-  textAlign: 'left', firstLineIndent: pt(0), paragraphSpacing: true, // a grid line between
+  textAlign: 'justify', firstLineIndent: pt(0), paragraphSpacing: true, // a grid line between
```

## 常见问题

- 这个设置只补一行的空缺。缺两行的栏，比如在段间空行之后只剩放下一段一行的位置，可能仍然偏短：增删一句文字来调整。
- 如果某段重排后会以过短的末行结束，就不会采用它，所以只有短段落的一栏可能仍然偏短。
