## できあがり

115 × 180 mm の文庫判ページの校正刷りを二つ組みます。中身は『クリスマス・キャロル』（*A Christmas Carol*）の冒頭で、Spectral を 83 mm の行長で両端揃えにしています。行長が狭いと改行の選択肢が少なく、五か所で続く二行が同じ語で終わるか始まります。*sole* の下に *sole*、*his* の下に *his*、*No* の下に *No*。初校は `stacks: 'warn'` で組みます。改行は一つも変えず、重複を一つずつ報告し、二つの語に淡い赤の帯をつけ、奥付のあとの校正票に並べます。再校は `'avoid'` で組み、五つのうち四つが消えます。スペイン語版は Clarín の *¡Adiós, Cordera!* の冒頭を同じ方法で組みます。

## 作り方

### 1 · まず報告し、次にコストに入れる

<Excerpt region="answer" />

続く二行が同じ語や同じ末尾の文字で終わるとき、または同じように始まるとき、それを重複と呼びます。何文字そろえば重複とみなすかは `stackMinCharacters` で決めます。既定値は三文字で、スペースも数え、アクセントと大文字小文字は区別しません。*The* の下の *the* も重複です。`'warn'` は報告するだけなので、組版者はまず文章のどこで重複が起きるかを確かめられます。`'avoid'` は重複を生む改行位置ごとに `stackPenalty` をコストに加え、Knuth–Plass の改行処理は段落の別の分け方を探します。`optimalLineBreaking` が必要です。一行ずつ決める改行処理には、加えるべきコストがありません。

スペイン語の組版の手引きは、この重複を組版上の欠陥として、リバーやハイフンの連続と並べて扱います。左端に戻った目が違う行の同じ語に引っかかり、同じ行を二度読んだり一行飛ばしたりします。右端では重複がこだまのように響きます。スペイン語の規則は語だけでなく音節の重複も対象にするので、スペイン語版では `stackMinCharacters` を 2 にしています。

既定のペナルティ 3000 は、二行続けてハイフンで終わるときのコストと同じで、一音節の語の重複はその二倍になります。この行長では 3000 だと各版に二つずつ重複が残りました。避けると、改行処理が受け入れるより緩い行ができるからです。10000 にすると、その緩い行を受け入れます。`maxWordSpacing` は既定値の 2 のままにします。もっと厳しくすると改行処理にほかの選択肢がなくなり、`'avoid'` は何も変えませんでした。

### 2 · 本文の重複に印をつける

<Excerpt region="marks" />

警告はそれぞれ、一行目が原稿のどこにあるかを示します。スクリプトは組み上がった文書でその行と次の行を探し、それぞれの重複している端を取り出して、語全体を `:mark[…]` で囲みます。マークは普通の文字の下に帯を塗るだけで、改行は変えません。印をつけるのは語全体だけです。語の一部だけを囲むとその語のハイフネーションが変わり、警告が見つかった位置で行が分かれなくなります。

### 3 · 同じ文章から二つの校正刷り

<Excerpt region="proofs" />

校正刷りはそれぞれ二回組みます。一回目で重複を見つけ、二回目で同じ文章に印と校正票を加えて組みます。校正票は奥付のあとに置くので、最終ページに来ます。各校正刷りの一回目、印のない文章は公開するページに入れません。`capture.doc` には印のある二回分 `[1, 3]` だけを並べます。

<PageShot page={6} crop="0,0.04,1,0.32" caption="再校2ページ。同じ段落を別の位置で改行。残るのは even と event だけ。" />

英語版に残る重複は *even* の下の *event* です。二つの語は最初の三文字が同じで、この段落のほかの分け方はどれもコストが高くなりました。スペイン語版は二文字で数えるので、初校で五つ見つかります。*con* の下の *como* の *co*、*levantar* の下の *vacilar* の *ar* などです。再校では一つもありません。

### 4 · 本文の上の章扉

<Excerpt region="opener" />

見出しの `art` 属性が絵を指定するので、一つのスタイルで両方の版をまかなえます。`minHeight` で十六行分を確保し、本文は十七行目から始まります。続くページと同じ行送りの格子に乗ります。

### 5 · 柱と下のノンブル

<Excerpt region="heads" />

偶数ページに著者名、奇数ページに書名を、それぞれノンブルの横に置きます。章扉では柱を消し、ノンブルを下に移します。

## アレンジ

### 長い語だけを数える

既定値は三文字です。五文字にすると *his* や *No* のような短い語は重複とみなされず、改行処理はその周りで詰まった行を保ちます。

```diff
-  stackMinCharacters: t({ en: 3, es: 2 }),
+  stackMinCharacters: 5,
```

### 既定のペナルティで本を組む

既定値では語間が詰まったままになり、重複を避けると行がさらに緩くなる箇所では、各版で二つの重複を受け入れます。

```diff
-  stackPenalty: 10000,
+  stackPenalty: 3000,
```

## よくあるつまずき

- 重複は、改行が決まった行の中で探します。判型や文字サイズ、文章を変えると初校で見つかる重複も変わります。組むたびに警告を読み、前の組版の位置を写さないでください。
- 重複は一つの段落の中でだけ数え、語をスペースで区切る文字体系だけが対象です。二つの段落がどちらも *Scrooge* で始まっても重複にはならず、中国語や日本語の文章では警告は出ません。
