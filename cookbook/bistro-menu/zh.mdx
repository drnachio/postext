## 成品一览

虚构的巴黎小酒馆Les Tanneurs的秋季菜单：一张230 × 310 mm的单页，双面印刷。正面，一顶条纹遮阳篷悬在用Limelight排的店名上方。每个菜类标题夹在两条延伸到页边距的黄铜色细线之间，下面列四道菜。每道菜由粗体法文菜名及配菜、下一行的英文斜体说明，以及右对齐的粗体价格组成。深绿色V圆标表示素食，描边的SG胶囊标表示无麸质。背面，酒单排在一排酒瓶之下，杯卖和瓶卖价格分列在表头为12 cl和75 cl的两栏里。Postext没有制表位，所以每一栏价格都属于一个不带线、不带题注的表格。

## 做法

### 1 · 在本该用制表位的地方用表格

代码见上文的[简短回答](#简短回答)。每个菜类是一个两列表格。菜名、一个换行和斜体译文共用第一个单元格，价格在第二个单元格中右对齐，与菜名的第一条基线平齐，因为两个单元格都从所在行的顶端开始。`columnWidths`接受权重，所以`[6, 1]`在158 mm的行长中分给价格22.6 mm。`rules: 'none'`和`headerBackgroundEnabled: false`去掉了[默认表格样式](/zh/docs/configuration#表格样式)画出的格线和灰色表头行。`cellPadding: pt(LEAD / 4)`让每道菜占14.5 pt行距的两行半，所以四道菜的一个菜类结束在第十条网格线上。如果用默认内边距0.375 em，每个菜类会比这条线低0.9 mm，其后的每个标题都下移一行，菜单会排到四页。

### 2 · 一种资源类型，就地放置，从不编号

<Excerpt region="type" />

内置的图和表类型会印出题注行，并把每个资源浮动到首次引用之后的第一个空位。`menu`类型没有题注前缀，其中各部分也没有题注，所以菜类下面不印任何东西。给它加上`captionPrefix: 'Menu'`，每一部分下面都会印出一行编号，从遮阳篷下的“Menu 1.”开始，菜单也就排到了四页。`defaultPlacement`让每个表格和插图都放在各自的`::resource`行上（[块嵌入](/zh/docs/document-format#块级嵌入可选显式的行内放置)）。没有它，三个菜类标题会挤在正面顶部，表格浮动到它们下面，甜点排在最前。遮阳篷和酒瓶是同一类型的SVG资源，用代码画出，并用工具包的`loadSvg`注册。

### 3 · 合并产区行

<Excerpt region="wines" />

在1.4.1中，`parseTSV`不会把任何一行标记为表头，所以`wineList`手动设置`headerRowCount: 1`。这样Appellation · cépage、12 cl和75 cl就用表头字体Josefin Sans印在各自的列上方。只有一个字段的行表示产区名。它的单元格成为居中的表头单元格，`mergeCells`把它横跨三列展开，并把它覆盖的两个单元格标为`hiddenBy`（[构建表格模型](/zh/docs/configuration#构建表格模型)）。如果只在第一列居中，BLANCS会比La Cave和Le Comptoir居中的轴线偏左22.6 mm。TSV中的空行会变成一行空单元格，高一行半，这一行就是Blancs和Rouges上方的空隙。

### 4 · 在菜类标题两侧各挂一条线

<Excerpt region="heads" />

菜类标题是栏内的一个版面设计。`{titleText}`元素不设宽度，所以它的框和大写字母一样宽，`'top'`锚点让它在栏中居中。每条线用`'left-of'`或`'right-of'`挂在标题的一侧，并一直填到栏的边缘（[元素定位](/zh/docs/configuration#元素定位)），所以PLATS两侧的线长66.7 mm，LE COMPTOIR两侧的线长56.2 mm，与字母都相距4 mm。标题的`lineHeight`是倍数0.96，使它的框高14.4 pt，保持在一条14.5 pt的网格线之内。设为1时框高15 pt，每个标题占两行，菜单会排到四页。

### 5 · 标识用行内标签，小字用段落样式

<Excerpt region="badges" />

行内标签在行内给一段文字加框（[行内标签样式](/zh/docs/configuration#行内标签样式)），所以在配菜后面输入`:chip[V]{style="veg"}`，圆标就会出现在菜的法文行上，在表格单元格里和在段落里都一样。行内标签样式设了`bold: true`，因为行内标签沿用周围文字的字重，跟在配菜后面就是400，而`FONTS`只加载了700字重的Josefin Sans。甜点下的说明和背面的版权说明是9 pt和7.5 pt的`:::paragraphs`块，两种样式都带一行的`marginTop`（[段落样式](/zh/docs/configuration#段落样式)），因为设为`'here'`的表格不会在自身下方留出空间。没有这个外边距，说明会紧接在奶酪拼盘英文行的下一行开始，看起来像是那道菜的一部分。

### 6 · 让整张菜单沿一条轴线居中

<Excerpt region="centred" />

`headings.textAlign`和`bodyText.textAlign`让所有非表格内容都位于菜单的中轴线上。`lineHeight: pt(3 * LEAD)`给48 pt的店名三条网格线。没有它，店名使用默认行距占四行，说明的第二行会移到单独一页，菜单排到四页。在1.4.1中，任何`headings`对象都会取消H1分页，而一级标题仍然写明`breakBefore: { enabled: false }`，因为店名和La Cave应当和上方的插图在同一页。恢复默认值`{ enabled: true, parity: 'always-odd' }`，每幅插图都会独占一页，一共七页。配置没有设置`locale`，因为1.4.1只对两端对齐的正文断词，而这张菜单上没有两端对齐的内容。

## 变化

### 让细线停在固定长度

用固定宽度代替`'fill'`，每条线就保持20 mm长、离标题4 mm，所以PLATS两侧的一对线比LE COMPTOIR两侧的更靠近中心。

```diff
-    size: { width: 'fill' }, // 延伸到栏的边缘
+    size: { width: mm(20) }, // 20 mm，无论标题在哪里结束
```

### 像账本一样给每行画线

`rules: 'horizontal'`在每行上下各画一条0.5 pt的黄铜色细线。线不占空间，所以正反两面的版面都不变，Blancs和Rouges上方的空行也会各自多出一对细线。

```diff
-const tableStyle = { rules: 'none', cellPadding: pt(LEAD / 4), // 一道菜：LEAD的两行半
+const tableStyle = { rules: 'horizontal', borderColor: col('brass'),
+  borderWidth: pt(0.5), cellPadding: pt(LEAD / 4),
```

## 常见问题

每个线条元素都要设`thickness`。在1.4.1中，没有设置粗细的线什么也画不出来，尽管配置参考文档写的默认值是0.5 pt。把它从`rule()`里删掉，每个菜类标题两侧的线都会消失。
