## 成品一览

虚构的巴黎小酒馆Les Tanneurs的秋季菜单：一张230 × 310 mm的单页，双面印刷。正面，一顶条纹遮阳篷悬在用Limelight排的店名上方。每个菜类标题夹在两条延伸到页边距的黄铜色细线之间，下面列四道菜。每道菜由粗体法文菜名及配菜、下一行的英文斜体说明，以及右对齐的粗体价格组成。深绿色V圆标表示素食，描边的SG胶囊标表示无麸质。每道菜是一个段落，制表符把价格送到右页边距处的制表位。背面，酒单排在一排酒瓶之下，杯卖和瓶卖价格分列在表头为12 cl和75 cl的两栏里，放在一个不带线、不带题注的表格中。

## 做法

### 1 · 在价格的位置设一个制表位

代码见上文的[简短回答](#简短回答)。每个菜类是一个`:::paragraphs{style="dish"}`组，一道菜一个段落（[段落样式](/zh/docs/configuration#段落样式)）。菜品样式只有一个制表位，位于`'end'`即行长末端，并设`align: 'end'`：制表符之后的文字止于这个制表位。所以在配菜和标识之后写`:tab **7**`，无论菜名多长，价格都会靠右页边距排齐（[制表符与制表位](/zh/docs/document-format#制表符与制表位)）。`:tab`会并入它两侧的空格；行末的反斜杠是强制换行，所以斜体译文另起同一段落的第二行，价格留在第一行。`spaceBetween`在两道菜之间留出半行，所以每道菜占14.5 pt行距的两行半。`indent`和`endIndent`各为四分之一行，让菜品与背面酒单单元格中的文字对齐。含制表符的段落逐行排版；这里的每一行本来就是不齐行的。

### 2 · 一种资源类型，就地放置，从不编号

<Excerpt region="type" />

内置的图和表类型会印出题注行，并把每个资源浮动到首次引用之后的第一个空位。`menu`类型没有题注前缀，其中各部分也没有题注，所以插图和酒单下面都不印任何东西。给它加上`captionPrefix: 'Menu'`，每一部分下面都会印出一行编号，从遮阳篷下的“Menu 1.”开始，菜单也就排到了四页。`defaultPlacement`让酒单和每幅插图都放在各自的`::resource`行上（[块嵌入](/zh/docs/document-format#块级嵌入可选显式的行内放置)）。没有它，酒单会浮动到背面的页脚，排在Le Comptoir和版权说明之下。遮阳篷和酒瓶是同一类型的SVG资源，用代码画出，并用工具包的`loadSvg`注册。

### 3 · 合并产区行

<Excerpt region="wines" />

酒单仍是表格：两种价格分列在各自的表头12 cl和75 cl之下，而一行制表位无法给它们配上表头。`parseTSV(tsv, { headerRows: 1 })`把第一行读作表头行，所以Appellation · cépage、12 cl和75 cl用表头字体Josefin Sans印在各自的列上方。只有一个字段的行表示产区名。它的单元格成为居中的表头单元格，`mergeCells`把它横跨三列展开，并把它覆盖的两个单元格标为`hiddenBy`（[构建表格模型](/zh/docs/configuration#构建表格模型)）。如果只在第一列居中，BLANCS会比La Cave和Le Comptoir居中的轴线偏左22.6 mm。TSV中的空行会变成一行空单元格，高一行半，这一行就是Blancs和Rouges上方的空隙。

### 4 · 在菜类标题两侧各挂一条线

<Excerpt region="heads" />

菜类标题是栏内的一个版面设计。`{titleText}`元素不设宽度，所以它的框和大写字母一样宽，`'top'`锚点让它在栏中居中。每条线用`'left-of'`或`'right-of'`挂在标题的一侧，并一直填到栏的边缘（[元素定位](/zh/docs/configuration#元素定位)），所以PLATS两侧的线长66.7 mm，LE COMPTOIR两侧的线长56.2 mm，与字母都相距4 mm。标题的`lineHeight`是倍数0.96，使它的框高14.4 pt，保持在一条14.5 pt的网格线之内。设为1时框高15 pt，每个标题占两行，菜单会排到四页。

### 5 · 标识用行内标签，小字用段落样式

<Excerpt region="badges" />

行内标签在行内给一段文字加框（[行内标签样式](/zh/docs/configuration#行内标签样式)），所以在配菜后面输入`:chip[V]{style="veg"}`，圆标就会出现在菜的法文行上，位于制表符之前。行内标签样式设了`bold: true`，因为行内标签沿用周围文字的字重，跟在配菜后面就是400，而`FONTS`只加载了700字重的Josefin Sans。甜点下的说明和背面的版权说明是9 pt和7.5 pt的`:::paragraphs`块，两种样式都带一行的`marginTop`（[段落样式](/zh/docs/configuration#段落样式)）。没有这个外边距，说明会紧接在奶酪拼盘英文行的下一行开始，看起来像是那道菜的一部分。

### 6 · 让整张菜单沿一条轴线居中

<Excerpt region="centred" />

`headings.textAlign`和`bodyText.textAlign`让菜品和酒单以外的所有内容都位于菜单的中轴线上。`lineHeight: pt(3 * LEAD)`给48 pt的店名三条网格线。没有它，店名使用默认行距占四行，说明的第二行会移到单独一页，菜单排到四页。一级标题用`breakBefore: { enabled: false }`关闭H1分页，因为店名和La Cave应当和上方的插图在同一页。保留默认值`{ enabled: true, parity: 'always-odd' }`，每幅插图都会独占一页，一共七页。配置没有设置`locale`：这张菜单上没有两端对齐的内容，而不齐行的文字只有在开启`bodyText.hyphenation.ragged`时才断词。

## 变化

### 让细线停在固定长度

用固定宽度代替`'fill'`，每条线就保持20 mm长、离标题4 mm，所以PLATS两侧的一对线比LE COMPTOIR两侧的更靠近中心。

```diff
-    size: { width: 'fill' }, // 延伸到栏的边缘
+    size: { width: mm(20) }, // 20 mm，无论标题在哪里结束
```

### 用点引到价格

前导符填满制表位之前的空白。`'. '`重复一个句点和一个空格，从菜品最后一个标识或最后一个词之后半个em开始，到价格之前半个em为止。

```diff
-  tabStops: [{ position: 'end', align: 'end' }],
+  tabStops: [{ position: 'end', align: 'end', leader: '. ' }],
```

### 像账本一样给酒单的每行画线

`rules: 'horizontal'`在酒单每行上下各画一条0.5 pt的黄铜色细线。线不占空间，所以正反两面的版面都不变，Blancs和Rouges上方的空行也会各自多出一对细线。

```diff
-const tableStyle = { rules: 'none', cellPadding: pt(LEAD / 4), // 一行：LEAD的一行半
+const tableStyle = { rules: 'horizontal', borderColor: col('brass'),
+  borderWidth: pt(0.5), cellPadding: pt(LEAD / 4),
```

## 常见问题

在菜品的第一行给价格留出位置。如果菜名和配菜越过了价格所需的位置，制表位会把菜名的最后一个词连同价格一起移到下一行，英文行排在它们之后：这道菜于是占三行，整个菜类也结束得低一行。
