## できあがり

架空のパリのビストロ、Les Tanneursの秋のメニューです。230 × 310mmの1枚の紙の両面に刷ります。表面では、ストライプの日よけがLimelightで組んだ店名の上に掛かります。コースの見出しはそれぞれ余白まで伸びる2本の真鍮色の罫に挟まれ、その下に4品の料理が並びます。料理は、付け合わせを添えた太字のフランス語の名前、その下のイタリックの英語の行、右端にそろえた太字の価格でできています。濃い緑のVの円形マークはベジタリアン料理を、輪郭線だけのSGの角丸マークはグルテンフリーの料理を示します。裏面では、ボトルの棚の下にワインリストがあり、グラスとボトルの価格が12 clと75 clの見出しの下に列をなします。Postextにはタブがないので、価格の列はどれも、罫もキャプションもない表に属しています。

## 作り方

### 1 · タブを置く場所に表を

コードは上の[手短な答え](#手短な答え)にあります。コースはそれぞれ2列の表です。料理名、改行、イタリックの訳が1つ目のセルに入り、2つ目のセルの価格は右端にそろって、料理の1行目のベースラインに並びます。どちらのセルも行の上端から始まるからです。`columnWidths`は重みを取るので、`[6, 1]`は158mmの行長のうち22.6mmを価格に割り当てます。`rules: 'none'`と`headerBackgroundEnabled: false`は、[既定の表スタイル](/ja/docs/configuration#表スタイル)が描く罫と灰色の見出し行を取り除きます。`cellPadding: pt(LEAD / 4)`で各料理は14.5ptの行送りの2.5行分になり、4品のコースは10本目のグリッド線で終わります。既定のパディング0.375emでは各コースがその線より0.9mm下で終わり、続く見出しがすべて1行ずつ下がって、メニューは4ページに延びます。

### 2 · 番号を振らず、その場に置く1つのリソースタイプ

<Excerpt region="type" />

組み込みの図と表のタイプは、キャプションの行を印刷し、各リソースを最初の参照のあとの最初の空き位置にフロートとして配置します。`menu`タイプにはキャプションの接頭辞がなく、各ピースにもキャプションがないので、コースの下には何も印刷されません。`captionPrefix: 'Menu'`を与えると、日よけの下の「Menu 1.」から始まる番号付きの行がすべてのピースの下に印刷され、メニューは4ページになります。`defaultPlacement`は、表と図をそれぞれの`::resource`の行に置きます（[ブロックの埋め込み](/ja/docs/document-format#ブロック埋め込み任意本文中への明示的な配置)）。これがないと、3つのコースの見出しは表面の上部に固まり、表はその下にデザートから順にフロートします。日よけとボトルは同じタイプのSVGリソースで、コードで描いてキットの`loadSvg`で登録します。

### 3 · 産地の行を結合する

<Excerpt region="wines" />

1.4.1の`parseTSV`はどの行も見出し行にしないので、`wineList`は`headerRowCount: 1`を手で設定します。これでAppellation · cépage、12 cl、75 clがそれぞれの列の上に、見出しの書体Josefin Sansで印刷されます。フィールドが1つしかない行は産地の名前です。そのセルは中央そろえの見出しセルになり、`mergeCells`がそれを3列に広げて、覆われる2つのセルに`hiddenBy`を付けます（[表モデルの構築](/ja/docs/configuration#表モデルの構築)）。1列目の中だけで中央にそろえると、BLANCSは、La CaveとLe Comptoirがそろう中心線から22.6mm左に立ってしまいます。TSVの空行は空のセルが並ぶ1.5行分の高さの行になり、この行がBlancsとRougesの上のアキになります。

### 4 · コースの題の両側に罫を掛ける

<Excerpt region="heads" />

コースの見出しは段の中のデザインです。`{titleText}`要素には幅がないので、その箱は大文字の幅だけになり、`'top'`アンカーがそれを段の中央に置きます。罫は`'left-of'`または`'right-of'`で題の片側の端に掛け、段の端まで伸ばします（[要素の配置](/ja/docs/configuration#要素の配置)）。そのため、PLATSの両側の罫は66.7mm、LE COMPTOIRの両側は56.2mmになり、どれも文字から4mm離れます。題の`lineHeight`は倍率の0.96で、箱は14.4ptとなり、14.5ptのグリッド1行に収まります。1にすると箱は15ptになり、見出しがそれぞれ2行を取って、メニューは4ページになります。

### 5 · マークはチップで、細かい文字は段落スタイルで

<Excerpt region="badges" />

チップは行の中の文字列を箱で囲みます（[チップスタイル](/ja/docs/configuration#チップスタイル)）。付け合わせのあとに`:chip[V]{style="veg"}`と書けば、段落の中と同じく表のセルの中でも、料理のフランス語の行に円形マークが付きます。チップは周りの文字のウェイト、付け合わせのあとなら400を受け継ぎますが、`FONTS`はJosefin Sansを700しか読み込まないので、チップスタイルには`bold: true`を設定します。デザートの下の注記と裏面の奥付は9ptと7.5ptの`:::paragraphs`ブロックで、どちらのスタイルも1行分の`marginTop`を持ちます（[段落スタイル](/ja/docs/configuration#段落スタイル)）。`'here'`に置いた表は自分の下にアキを残さないからです。このマージンがないと、注記はチーズの盛り合わせの英語の行のすぐ次の行から始まり、その料理の一部のように見えます。

### 6 · メニューを1本の軸で中央にそろえる

<Excerpt region="centred" />

`headings.textAlign`と`bodyText.textAlign`は、表以外のすべてをメニューの中心線に置きます。`lineHeight: pt(3 * LEAD)`は48ptの店名にグリッド3行分を与えます。これがないと店名は既定の行送りで4行分を取り、注記の2行目が別のページに送られて、メニューは4ページになります。1.4.1では`headings`オブジェクトがあるだけでH1の改ページがなくなりますが、それでもレベル1には`breakBefore: { enabled: false }`を明記します。店名とLa Caveは、その上の絵と同じページに属するからです。既定値の`{ enabled: true, parity: 'always-odd' }`に戻すと、絵がそれぞれ1ページを占め、全部で7ページになります。1.4.1がハイフネーションするのは両端そろえの本文だけで、このメニューには両端そろえの箇所がないので、設定に`locale`は入れていません。

## アレンジ

### 罫を一定の長さで止める

`'fill'`の代わりに固定の幅を与えると、罫はどれも20mmの長さで題から4mm離れます。そのため、PLATSの両側の罫はLE COMPTOIRの両側より中心寄りに並びます。

```diff
-    size: { width: 'fill' }, // to the column's edge
+    size: { width: mm(20) }, // 20 mm, wherever the title ends
```

### 帳簿のように行ごとに罫を引く

`rules: 'horizontal'`は、すべての行の上下に0.5ptの真鍮色の細い罫を引きます。罫は場所を取らないので両面ともレイアウトは変わらず、BlancsとRougesの上の空の行にもそれぞれ1組の罫が付きます。

```diff
-const tableStyle = { rules: 'none', cellPadding: pt(LEAD / 4), // a dish: 2½ lines of LEAD
+const tableStyle = { rules: 'horizontal', borderColor: col('brass'),
+  borderWidth: pt(0.5), cellPadding: pt(LEAD / 4),
```

## よくあるつまずき

罫の要素にはどれも`thickness`を指定してください。設定リファレンスでは既定値が0.5ptとされていますが、1.4.1では太さの指定がない罫は何も描きません。`rule()`からこの指定を削除すると、すべてのコースの見出しで両側の罫が消えます。
