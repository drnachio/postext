## できあがり

架空のパリのビストロ、Les Tanneursの秋のメニューです。230 × 310mmの1枚の紙の両面に刷ります。表面では、ストライプの日よけがLimelightで組んだ店名の上に掛かります。コースの見出しはそれぞれ余白まで伸びる2本の真鍮色の罫に挟まれ、その下に4品の料理が並びます。料理は、付け合わせを添えた太字のフランス語の名前、その下のイタリックの英語の行、右端にそろえた太字の価格でできています。濃い緑のVの円形マークはベジタリアン料理を、輪郭線だけのSGの角丸マークはグルテンフリーの料理を示します。料理はそれぞれ1つの段落で、タブが価格を右の余白のタブ位置へ送ります。裏面では、ボトルの棚の下にワインリストがあり、グラスとボトルの価格が12 clと75 clの見出しの下に列をなします。この列は、罫もキャプションもない表に組んであります。

## 作り方

### 1 · 価格を置く場所にタブ位置を

コードは上の[手短な答え](#手短な答え)にあります。コースはそれぞれ`:::paragraphs{style="dish"}`グループで、1品が1段落です（[段落スタイル](/ja/docs/configuration#段落スタイル)）。料理のスタイルには、行長の終わりである`'end'`にタブ位置が1つだけあり、`align: 'end'`を指定しています。タブのあとのテキストは、このタブ位置で終わります。そのため、付け合わせとマークのあとに`:tab **7**`と書けば、料理名の長さにかかわらず価格が右の余白にそろいます（[タブとタブ位置](/ja/docs/document-format#タブとタブ位置)）。`:tab`は前後のスペースを含みます。行末のバックスラッシュは強制改行なので、イタリックの訳は同じ段落の2行目から始まり、価格は1行目に残ります。`spaceBetween`が料理と料理のあいだに半行を空けるので、各料理は14.5ptの行送りの2.5行分を取ります。行の4分の1の`indent`と`endIndent`で、料理を裏面のワインリストのセルの文字にそろえます。タブを含む段落は1行ずつ組まれますが、ここではどの行ももともとラグ組みです。

### 2 · 番号を振らず、その場に置く1つのリソースタイプ

<Excerpt region="type" />

組み込みの図と表のタイプは、キャプションの行を印刷し、各リソースを最初の参照のあとの最初の空き位置にフロートとして配置します。`menu`タイプにはキャプションの接頭辞がなく、各ピースにもキャプションがないので、絵やワインリストの下には何も印刷されません。`captionPrefix: 'Menu'`を与えると、日よけの下の「Menu 1.」から始まる番号付きの行がすべてのピースの下に印刷され、メニューは4ページになります。`defaultPlacement`は、ワインリストと各図をそれぞれの`::resource`の行に置きます（[ブロックの埋め込み](/ja/docs/document-format#ブロック埋め込み任意本文中への明示的な配置)）。これがないと、ワインリストは裏面の地までフロートし、Le Comptoirと奥付の下に置かれます。日よけとボトルは同じタイプのSVGリソースで、コードで描いてキットの`loadSvg`で登録します。

### 3 · 産地の行を結合する

<Excerpt region="wines" />

ワインリストは表のままです。2つの価格がそれぞれ12 clと75 clの見出しの下に列をなしますが、タブ位置を並べただけでは列に見出しを付けられません。`parseTSV`はどの行も見出し行にしないので、`wineList`は`headerRowCount: 1`を手で設定します。これでAppellation · cépage、12 cl、75 clがそれぞれの列の上に、見出しの書体Josefin Sansで印刷されます。フィールドが1つしかない行は産地の名前です。そのセルは中央そろえの見出しセルになり、`mergeCells`がそれを3列に広げて、覆われる2つのセルに`hiddenBy`を付けます（[表モデルの構築](/ja/docs/configuration#表モデルの構築)）。1列目の中だけで中央にそろえると、BLANCSは、La CaveとLe Comptoirがそろう中心線から22.6mm左に立ってしまいます。TSVの空行は空のセルが並ぶ1.5行分の高さの行になり、この行がBlancsとRougesの上のアキになります。

### 4 · コースの題の両側に罫を掛ける

<Excerpt region="heads" />

コースの見出しは段の中のデザインです。`{titleText}`要素には幅がないので、その箱は大文字の幅だけになり、`'top'`アンカーがそれを段の中央に置きます。罫は`'left-of'`または`'right-of'`で題の片側の端に掛け、段の端まで伸ばします（[要素の配置](/ja/docs/configuration#要素の配置)）。そのため、PLATSの両側の罫は66.7mm、LE COMPTOIRの両側は56.2mmになり、どれも文字から4mm離れます。題の`lineHeight`は倍率の0.96で、箱は14.4ptとなり、14.5ptのグリッド1行に収まります。1にすると箱は15ptになり、見出しがそれぞれ2行を取って、メニューは4ページになります。

### 5 · マークはチップで、細かい文字は段落スタイルで

<Excerpt region="badges" />

チップは行の中の文字列を箱で囲みます（[チップスタイル](/ja/docs/configuration#チップスタイル)）。付け合わせのあとに`:chip[V]{style="veg"}`と書けば、料理のフランス語の行の、タブの前に円形マークが付きます。チップは周りの文字のウェイト、付け合わせのあとなら400を受け継ぎますが、`FONTS`はJosefin Sansを700しか読み込まないので、チップスタイルには`bold: true`を設定します。デザートの下の注記と裏面の奥付は9ptと7.5ptの`:::paragraphs`ブロックで、どちらのスタイルも1行分の`marginTop`を持ちます（[段落スタイル](/ja/docs/configuration#段落スタイル)）。このマージンがないと、注記はチーズの盛り合わせの英語の行のすぐ次の行から始まり、その料理の一部のように見えます。

### 6 · メニューを1本の軸で中央にそろえる

<Excerpt region="centred" />

`headings.textAlign`と`bodyText.textAlign`は、料理とワインリスト以外のすべてをメニューの中心線に置きます。`lineHeight: pt(3 * LEAD)`は48ptの店名にグリッド3行分を与えます。これがないと店名は既定の行送りで4行分を取り、注記の2行目が別のページに送られて、メニューは4ページになります。レベル1は`breakBefore: { enabled: false }`でH1の改ページを切ります。店名とLa Caveは、その上の絵と同じページに属するからです。既定値の`{ enabled: true, parity: 'always-odd' }`のままにすると、絵がそれぞれ1ページを占め、全部で7ページになります。設定に`locale`は入れていません。このメニューには両端そろえの箇所がなく、ラグ組みのテキストがハイフネーションされるのは`bodyText.hyphenation.ragged`をオンにしたときだけだからです。

## アレンジ

### 罫を一定の長さで止める

`'fill'`の代わりに固定の幅を与えると、罫はどれも20mmの長さで題から4mm離れます。そのため、PLATSの両側の罫はLE COMPTOIRの両側より中心寄りに並びます。

```diff
-    size: { width: 'fill' }, // to the column's edge
+    size: { width: mm(20) }, // 20 mm, wherever the title ends
```

### 価格まで点を並べる

リーダーはタブ位置の前のアキを埋めます。`'. '`はピリオドとスペースを繰り返し、料理の最後のマークまたは最後の語の0.5em後から、価格の0.5em前まで続きます。

```diff
-  tabStops: [{ position: 'end', align: 'end' }],
+  tabStops: [{ position: 'end', align: 'end', leader: '. ' }],
```

### 帳簿のようにワインリストの行ごとに罫を引く

`rules: 'horizontal'`は、ワインリストのすべての行の上下に0.5ptの真鍮色の細い罫を引きます。罫は場所を取らないので両面ともレイアウトは変わらず、BlancsとRougesの上の空の行にもそれぞれ1組の罫が付きます。

```diff
-const tableStyle = { rules: 'none', cellPadding: pt(LEAD / 4), // a row: 1½ lines of LEAD
+const tableStyle = { rules: 'horizontal', borderColor: col('brass'),
+  borderWidth: pt(0.5), cellPadding: pt(LEAD / 4),
```

## よくあるつまずき

料理の1行目に価格の入る場所を残してください。料理名と付け合わせが価格に必要な位置を越えると、タブ位置は料理名の最後の語を価格と一緒に次の行へ送り、英語の行はそのあとに続きます。すると料理は3行を取り、コースは1行下で終わります。
