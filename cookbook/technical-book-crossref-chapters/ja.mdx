## できあがり

短い技術的な手引き『Power for a Cabin』を、178 × 233 mmのページにIBM Plexで組みます。太陽の軌道をコードで描いた表紙、目次のページ、夜空の青の帯の下に3つの章があります。この本は小さな太陽光発電システムの容量を見積もるもので、どの章もほかの章に寄りかかっています。第3章は第1章の負荷の表と第2章の日照時間のグラフを引き、第1章は読者を先の2.3節へ送り、そのページを示します。著者は4つの別々のMarkdownファイルに、pandoc-crossrefが読むとおりに`@tbl:loads`や`@sec:array-size`と書きます。`buildBundle`がそれらを1冊の本としてレイアウトするので、どの参照も、参照先がその章で得た番号、参照先が置かれたページ、参照先へのリンクを印字します。

## 作り方

### 1 · 参照先には本全体で一度だけ名前をつける

コードは上の[手短な答え](#手短な答え)にあります。見出しには`## Sizing the array {#sec:array-size}`のように、接頭辞つきのPandoc識別子をつけます。図と表はスクリプトで宣言するリソースで、そのidも`fig:sun`、`tbl:loads`と同じ形で書きます。こうすれば、図が2段落先にあっても2章前にあっても、本文には`@fig:sun`と書けます。idは章の中だけでなく、本全体で一意でなければなりません。

### 2 · 章を1冊の本としてレイアウトする

<Excerpt region="answer" highlight="6" />

`buildBundle`は図と表のカウンターを章から章へ引き継ぐので、第3章の最初の表は3.1になり、第3章の`@tbl:loads`も*table 1.1*と印字します。自分の持たない見出しを本文で参照する章は、本全体のアウトラインを使ってレイアウトし、そのアウトラインのページが動かなくなるまで（最大3回）レイアウトし直します。第2章がまだ紙の上に存在しないうちに、第1章が*section 2.1 … p. 6*と印字できるのはこのためです。

### 3 · 参照が印字する言葉を選ぶ

`crossRefs`は*chapter*、*section*、*p.*（スペイン語では*capítulo*、*apartado*、*pág.*）を設定します。図や表の参照は種類の`shortLabel`を印字し、ここではpandoc-crossrefと同じく小文字で*fig. 2.1*、*table 1.1*となります。`@Tbl:loads`や`@Sec:array`のように接頭辞を大文字にすると、文頭用にラベルの頭が大文字になります。`[-@tbl:losses]`は*tables 2.1 and 3.1*のための番号だけを印字します。

### 4 · 節は先へ、図は後ろへ参照する

図や表は、最初に引かれた場所で番号を振られ、フロートとして配置されます。第1章に`@fig:soc`と書けば、それは図1.2になり、第1章に置かれてしまいます。そこで第1章は先の`@sec:autonomy`を指し、図と表はそれぞれ自分の章で最初に引くようにしています。後の章はどれも、自由にそれらを振り返れます。ページは節の参照につけます（`:ref{id="sec:sun-hours" style=page}`）。リソースの参照が印字するのはラベルと番号だけで、ページは印字しません。

### 5 · 章扉と表紙は同じ帯から

<Excerpt region="opener" />

帯は、同じ要素を使い回すすべての章と目次のページで、仕上がりの上端から55 mmの高さに伸びます。章番号は`{chapterNumber}`、リードは見出しの属性です。

## アレンジ

### 本文に「Figure 2.1」と印字する

参照を略さずに書く本では、短いラベルの代わりに種類の正式な名前を使います。

```diff
-  shortLabel: type.id === 'table' ? t({ en: 'table', es: 'tabla' })
-    : t({ en: 'fig.', es: 'figura' }),
+  shortLabel: type.id === 'table' ? t({ en: 'Table', es: 'Tabla' })
+    : t({ en: 'Figure', es: 'Figura' }),
```

### 節に段落記号で番号を振る

```diff
-  section: t({ en: 'section {n}', es: 'apartado {n}' }), // @sec:losses → "section 2.2"
+  section: '§ {n}',
```

## よくあるつまずき

- どの章も設定していないidへの参照は「*?*」と印字されます。ある章で見出しの名前を変えたら、idを確かめてください。その見出しへの参照はほかの章にあります。
- `buildDocument`で章を1つずつレイアウトすると、カウンターも本のアウトラインも失われます。どの章も図の番号を1から振り直し、ほかの章への参照は「*?*」と印字されます。`buildBundle`を使うか、`continuation`をつないで自分で`outline`を渡してください。
- Postextの数式には専用の番号づけがないので、`@eq:`が見つけるのは自分で設定したアンカーだけで、そのテキストを印字します。この本では2つの数式を番号なしで書いています。
