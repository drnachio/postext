## できあがり

学校の菜園を題材にした、アラビア語練習帳2年生用の1単元です。判型は17 × 24 cm。水彩画の帯で始まり、単元のタブと題名、名前・組・日付の点線が続きます。そのあとに、アラブの小学校の本が刷る練習が並びます。أ) ب) ج)を1行に3つ並べて正しい答えを選ぶ問題、2列を線で結ぶ問題、語群の枠から空欄を埋める問題、صحかخطأに印をつける問題、文字の表から菜園の言葉を7つ探す問題、言葉を並べ替えて文を線の上に書く問題です。単元の最後に解答が付きます。同じ本文を2回組みます。マシュリク版は番号をすべてアラビア・インド数字١ ٢ ٣で、マグリブ版はヨーロッパ数字で刷ります。どちらも右から読み、右綴じです。

## 作り方

### 1 · 左右を書かない

コードは上の[手短な答え](#手短な答え)にあります。`locale: 'ar'`で本文は右から左へ流れ、本は右綴じになり、数字も決まります。練習のスタイルは、選択肢のアブジャド文字と正誤のصحとخطأを言語から取ります。線で結ぶ2列、語群の枠、単語探し、書き込み線は枠のデザインとして描くので、右から左のページでは鏡像になります。最初の列は右に立ち、表を横に読む言葉は右から左へ進み、結ぶ点は中央で向かい合います。

### 2 · 菜園の扉

<Excerpt region="opener" />

絵はページに固定され、位置を保ちます。タブと題名はページの流れの中に置きます。そこでは`left`が行頭を指すので、自分の座標を持たなくても右側に立ちます。ノンブルは柱と同じく物理的なページに置き、左右をそれぞれ指定します。

### 3 · 2つの版、2種類の数字

<Excerpt region="editions" />

設定は関数なので、組むたびに別のオブジェクトができ、2回目はロケールだけを変えます。`ar-MA`は練習番号、小問、解答、ノンブルをヨーロッパ数字で書きます。文字の向き、綴じ、アブジャド文字、解答の言葉はそのままです。

## アレンジ

### 教師用を刷る

解答が`answers`の色でそれぞれの場所に入ります。点は結ばれ、言葉は空欄に入り、正しい枠は塗られ、表の言葉は丸で囲まれます。

```diff
-const exercises = { solutions: { placement: 'directive' } };
+const exercises = { edition: 'teacher', solutions: { placement: 'none' } };
```

## よくあるつまずき

- アラビア語の書体の多くには✓も✗もありません。正誤の言葉はصحとخطأで、指示文は枠に印をつけるよう求めます。
- 単語探しは、空いたマスを自分の言葉の文字で、独立形のまま埋めます。文字の種類が多い言葉を選ばないと、表がةだらけになります。
