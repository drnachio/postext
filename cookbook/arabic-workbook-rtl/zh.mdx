## 成品一览

阿拉伯文二年级练习册中的一个单元，页面17 × 24 cm，主题是学校菜园。单元以一条水彩画开篇，下面是单元标签和标题，姓名、班级、日期各一条点线。接着是阿拉伯小学课本常印的几类练习：选出正确答案，أ) ب) ج)每行三个；两栏连线；用词语框里的词填空；判断صح或خطأ；在字母方阵里找出七个菜园里的词；给词语排序，再把句子写在线上。单元最后是答案。同一份文本排两次：马什里克版的编号全用阿拉伯-印度数字١ ٢ ٣，马格里布版用欧洲数字。两版都从右边读起，都在右侧装订。

## 做法

### 1 · 不写哪一边

代码见上文的[简短回答](#简短回答)。`locale: 'ar'`让文字从右向左排，让书在右侧装订，并选定数字；练习样式从语言里取出选项用的abjad字母，以及判断题用的صح和خطأ。连线的两栏、词语框、找词方阵和书写线都画成框的设计，从右向左的页面会把它们镜像过来：第一栏在右边，方阵里横读的词从右往左走，连线的点在中间相对。

### 2 · 菜园开篇

<Excerpt region="opener" />

画固定在页面上，位置不变。标签和标题放在页面的排版流里，`left`在这里指行首，所以它们不用自己的坐标就落在右边。页码和书眉一样按实际页面放置，左右两侧分别写明。

### 3 · 两个版本，两套数字

<Excerpt region="editions" />

配置是一个函数，每次排版都得到自己的对象，第二次只换语言。`ar-MA`把练习编号、小题、答案和页码写成欧洲数字，其余保持不变：文字方向、装订、abjad字母，以及答案里的词。

## 变化

### 印教师用书

答案用`answers`的颜色印在原位：点已经连好，词填进空格，正确的方框涂满，方阵里的词圈了出来。

```diff
-const exercises = { solutions: { placement: 'directive' } };
+const exercises = { edition: 'teacher', solutions: { placement: 'none' } };
```

## 常见问题

- 大多数阿拉伯文字体没有✓和✗：判断题的对错写作صح和خطأ，题目要求在方框里做记号。
- 找词方阵用它那些词的字母填满空格，用的是字母的独立形式。挑字母多样的词，否则方阵里会满是ة。
