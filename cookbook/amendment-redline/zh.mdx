## 成品一览

一份随法案印发的委员会文件：五页，展示 1998 年《桑尼·波诺版权期限延长法》第 102 条对《美国法典》第 17 编做了哪些修改。法律本身只说“删去‘fifty’，插入‘70’”；这份文件把修改前的法律排出来，每处改动标在原位，删去的划删除线，新增的加下划线，上面印着联邦和各州起草人员在这类文本前印的图例；随后是修正后的第 302 条，放在一个浅色底的框里，各款字母在框边，正文及其转行悬挂在后。西班牙语版用同样的办法排出西班牙宪法 1992、2011 和 2024 年在《国家官方公报》（BOE）上公布的三次修改。

## 做法

### 1 · 在改动发生的地方标出改动

代码就是上面的[简短回答](#简短回答)。标记写在 Markdown 里：`~~fifty~~ :underline[70]` 划掉旧词，给新词加下划线（[删除线](/zh/docs/document-format-inline#删除线)、[下划线](/zh/docs/document-format-inline#下划线)）。两种线都不占位置，所以一段六行的被删条款和周围的正文一样两端对齐、断词；第 3 页上旧的第 304(b) 款整段划掉，新条文在同一段里加下划线。每条线都按字体本身的删除线和下划线参数画出，颜色跟随文字，所以小型大写的款目标题有自己高度上的线。

### 2 · 让框里的条款悬挂排列

在框样式里设 `body.hangingIndent`，框内所有段落都悬挂排列（[框内的排版](/zh/docs/configuration-callouts#框内的排版)）：首行从框的内边开始，其余各行退进 7 mm。在同样 7 mm 处设一个制表位，把“(a)”或“(c)”后面的正文带到这条边上，不管字母多宽；所以 Markdown 里写 `(a):tab In General.—…`。法案条款和修正后的条文用同一套排版，只是框不同：法案上方一条红线，现行条文后面一层底色。法案的框可以拆开（`keepTogether: false`），所以第 1 页以它的前两项结束。

### 3 · 开篇的色带

<Excerpt region="opener" />

深蓝色带从页面上边和左右两边出血，栏目标签和导语来自标题行上的属性（[标题属性](/zh/docs/document-format#标题属性)）。`minHeight` 决定图例从哪里开始，在色带下方几毫米处。

### 4 · 按奇偶页排的书眉

<Excerpt region="running-heads" />

偶数页印文件标题，奇数页印该页开头所在的部分，取自页上第一个二级标题。`pages: 'body'` 让书眉不出现在开篇页，开篇页改在页脚印页码。

## 变化

### 把新增部分写成 `++text++`

打开 `plusUnderline` 后，`++70++` 和 `:underline[70]` 一样加下划线，这是 Pandoc 和 markdown-it 表示插入文字的写法。

```diff
     textAlign: 'justify', firstLineIndent: mm(4.5), indentAfterHeading: false,
+    plusUnderline: true, // ++text++ underlines; C++ in the text is then written C\+\+
```

### 让法案的条款不拆开

去掉 `keepTogether: false`，整个框移到第 2 页，第 1 页停在引出它的那一行。

```diff
-    padding: pad(2.5, 0), body: clauses, keepTogether: false, // it may run on to the next page
+    padding: pad(2.5, 0), body: clauses,
```

## 常见问题

- 以数字加句点开头的段落（`2. Solamente…`）会被当作列表项，在句点前加反斜杠则会把反斜杠印出来。西班牙语版在正文里于数字和句点之间放一个字连接符（U+2060），在框里则把制表符紧跟在句点后面写成 `1.:tab`，这不是列表标记。
- 只靠颜色经不起复印，而这类文件常常就是复印着传阅的；删除线和下划线在黑白复印件上照样看得清，起草人员正是因此选用它们。
