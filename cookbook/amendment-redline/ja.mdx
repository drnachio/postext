## できあがり

法案に添えて配られる委員会資料です。1998年のソニー・ボノ著作権保護期間延長法の第102条が、合衆国法典第17編をどう変えたかを5ページで示します。法律そのものは「“fifty”を削り“70”を加える」と書くだけです。この資料では改正前の法律を組み、変更のある箇所ごとに、削る語に取り消し線、加える語に下線を引きます。上には、連邦や州の立案担当者がこうした文書の頭に刷る凡例を置きます。そのあと改正後の第302条を淡い色の囲みに入れ、各項の記号を囲みの端に、本文と折り返しの行をその内側にぶら下げてそろえます。スペイン語版は、1992年、2011年、2024年に官報（BOE）で公布されたスペイン憲法の3回の改正を同じ方法で組みます。

## 作り方

### 1 · 変更はその場所で示す

コードは上の[手短な答え](#手短な答え)です。印はMarkdownに書きます。`~~fifty~~ :underline[70]` で旧い語に取り消し線を、新しい語に下線を引きます（[取り消し線](/ja/docs/document-format-inline#取り消し線)、[下線](/ja/docs/document-format-inline#下線)）。どちらの線も幅を取らないので、6行にわたって線を引いた条項も、まわりの本文と同じように両端そろえとハイフネーションを受けます。3ページでは旧い第304条(b)項全体に取り消し線を引き、差し替えの文言に下線を引いて、ひとつの段落に収めています。線はフォントそのものの取り消し線と下線の値で引かれ、色は文字と同じなので、見出しのスモールキャップスにはその高さに合った線が付きます。

### 2 · 囲みの中で項をぶら下げる

囲みスタイルの `body.hangingIndent` は、囲みのすべての段落をぶら下げにします（[囲みの中の文字組み](/ja/docs/configuration-callouts#囲みの中の文字組み)）。1行目は囲みの内側の端から始まり、2行目以降は7 mm内側に下がります。同じ7 mmにタブ位置を置くと、「(a)」や「(c)」に続く本文が、記号の幅にかかわらずその位置にそろいます。そこでMarkdownには `(a):tab In General.—…` と書きます。法案の条項と改正後の条文は同じ文字組みで、枠だけが違います。法案の上には赤い罫、現行の条文の後ろには地色です。法案の囲みは分割してよい（`keepTogether: false`）ので、1ページはその最初の2項で終わります。

### 3 · 扉の帯

<Excerpt region="opener" />

紺の帯はページの上と左右に裁ち落としで広がり、見出しラベルとリード文は見出し行の属性から取ります（[見出しの属性](/ja/docs/document-format#見出しの属性)）。`minHeight` は凡例の始まる位置を決め、帯の数ミリ下になります。

### 4 · 偶数・奇数ページで分ける柱

<Excerpt region="running-heads" />

偶数ページには資料の題名を、奇数ページにはそのページが始まる部分の名を置きます。後者はページの最初の第2レベルの見出しから読み取ります。`pages: 'body'` で扉には柱を出さず、扉には代わりに下部にノンブルを置きます。

## アレンジ

### 加える語を `++text++` と書く

`plusUnderline` をオンにすると、`++70++` は `:underline[70]` と同じく下線になります。Pandocやmarkdown-itが挿入された文字に使う書き方です。

```diff
     textAlign: 'justify', firstLineIndent: mm(4.5), indentAfterHeading: false,
+    plusUnderline: true, // ++text++ underlines; C++ in the text is then written C\+\+
```

### 法案の条項を分けない

`keepTogether: false` を外すと、囲みはまるごと2ページに移り、1ページはそれを導く行で終わります。

```diff
-    padding: pad(2.5, 0), body: clauses, keepTogether: false, // it may run on to the next page
+    padding: pad(2.5, 0), body: clauses,
```

## よくあるつまずき

- 数字とピリオドで始まる段落（`2. Solamente…`）は箇条書きの項目として読まれ、ピリオドの前にバックスラッシュを置くとそれがそのまま印刷されます。スペイン語版では、本文では数字とピリオドの間にワードジョイナー（U+2060）を入れ、囲みではピリオドのすぐ後にタブを書いて `1.:tab` とします。これは箇条書きの記号にはなりません。
- 色だけではコピーに耐えません。こうした資料はコピーで回ることが多いものです。取り消し線と下線は白黒でも読めるので、立案担当者はこれを選びました。
