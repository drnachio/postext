## 成品一览

一个虚构的天文俱乐部为2027年8月2日日全食之前的四个周四晚间讲座做的海报。群青色天空填满A3页面的上方三分之二。右侧，黑色的月亮遮住一轮被裁切线切掉一块的柠檬黄太阳，一圈用代码画出的日冕在两者身后散开。标题*The Shadow Returns*用120 pt的Funnel Display，立在导语之上，位于天空底部。地平线下，四个蓝色日期领起各场讲座，小字说明分两栏排在一条蓝色色带之上。每个元素都挂在出血、页面、所在设计槽或另一个元素上，偏移量从那里算起。第二张重复这张海报，在每个元素的框以及页眉、页脚容器周围画一圈粉色边框，并给十三个元素加上标记，印出各自的定位方式。

## 做法

### 1 · 把两个元素钉在页面上，其余挂在它们身上

代码见上面的[简短回答](#简短回答)。其中`anchor.to`指明元素挂在什么上：`'bleed'`和`'page'`是页面的两个框（`page.cutLines`关闭时二者是同一个框），`'container'`是设计槽自己的框，`'#id'`是另一个元素（[元素定位](/zh/docs/configuration#元素定位)）。没有宽度的框会一直伸到其参照框的另一侧边缘，所以天空从左到右填满出血。相对天空定位的元素从天空的左边缘量起，也就是出血的左边缘，所以导语的`x`取`INSET`，即18 mm。标题区从天空下边缘往上搭：`'align-bottom'`让导语框的底边位于该边缘之上`AIR`（14 mm）处，`'above'`让每个元素的底边落在下面那个元素的顶边上，所以标题多占几行时，会把眉题往上顶，而不会压住导语。设计区域下方，小字说明从最低元素（主讲人那一行）之下至少3.2 mm处的第一条16 pt网格线开始；这3.2 mm是标题默认的下外边距。

### 2 · 把月亮和日冕挂在太阳上

<Excerpt region="eclipse" />

太阳是唯一钉在页面（成品框）上的元素。从`'top-right'`角量起，正的`x`会越过右边缘，所以圆盘有30 mm被切掉。月亮和日冕用`'align-top'`挂在太阳上，移动太阳，两者跟着动。它们的偏移量从太阳的左上角算起：月亮向右2 mm、向下2.5 mm，在左上方露出一弯太阳；日冕向左上方退`HALO`（75 mm），使它300 mm的正方形以150 mm的圆盘为中心。日冕是一个图像元素，尺寸取其框的大小（[图像元素](/zh/docs/configuration#图像元素)），并在列表中排在两个圆盘之前，所以画在它们后面。

### 3 · 把各场讲座串成栏

<Excerpt region="programme" />

每个日期、讲座题目和主讲人行都有固定的`size.width`，值为`COL`；`'right-of'`加上`GUT`把下一个日期放到右边一栏。没有宽度时，日期会收缩到数字本身的宽度（“8”宽17 mm），于是“15”会紧跟其后7 mm开始，每个讲座题目也会排成一行伸进下一栏。`COL`把正文宽度分成四份，栏间距同下方两栏小字一样是7 mm，这样小字的第二栏正好位于22之下。每个讲座题目`'below'`挂在其日期下，每行主讲人挂在其题目下，所以一个题目折成三行时，只会把它自己的主讲人往下推。

### 4 · 把色带放进页脚，每页都印

<Excerpt region="footer" />

凡是每页都要印的东西，比如这条色带，都放进页眉或页脚设计槽；带有自己页眉或页脚的标题样式，会在其所属章节的页面上替换这个设计槽。guides样式的页脚重复了这四个元素，并加上边框和标记，所以色带和标志在两张上都会印出。页脚的容器就是下页边距，从正文一直到裁切线：`'bottom-left'`从裁切线往上量，`'top-right'`从正文往下量，标志的−10和“Free entry”一行的+10落在色带中间同一条10 mm宽的带上（[页眉和页脚](/zh/docs/configuration#页眉与页脚)）。页脚在正文之后绘制，不占用正文空间，所以`FOOT`同时设定下页边距和色带高度，色带也就不会碰到上面的文字。

### 5 · 用同一份配置画出结构线

<Excerpt region="guides" />

`guides()`遍历海报的所有元素。文本元素在其框上加边框，方形框在其样式上加边框；两者都不会移动任何东西，因为只有内边距会让框变大。图像或圆盘则得到一个与自身同尺寸、挂在其左上角的方框，这样月亮和日冕所挂的太阳左上角也画了出来。每个标记是一段挂在所属元素上的文本，由`describe()`根据该元素自己的`placement`写成，因此标记不会与它所标注的配置不一致。第二个标题上的`{style="guides"}`引入这套设计以及它自己的页眉和页脚（[标题样式](/zh/docs/configuration#标题样式)）。没有宽度的标记只能用它的锚点到容器右边缘之间的空间，所以`#free`的标记从其文本左侧30 mm处开始。内容`continuation`中的`pageIndexOffset: 1`让海报成为左页，查看器因此把两张并排显示。

## 变化

### 加3 mm出血和裁切标记

把`BLEED`设为3 mm会打开裁切线，并把天空和底部色带推进它们所挂的出血3 mm，而`INSET`让文字留在页边距上；太阳、月亮和日冕挂在页面上，由于1.4.1不会把设计元素裁切到出血范围，它们会越过白色页边距一直延伸到纸边。

```diff
-const BLEED = 0; // 毫米；交付印刷时设为3，下面的page.cutLines随之打开
+const BLEED = 3; // 毫米；交付印刷时设为3，下面的page.cutLines随之打开
```

### 抬高地平线

从`SKY`减去20 mm会抬高天空的边缘，导语、标题、眉题和讲座的十二段文字随之上移，小字说明也从更高的一条网格线开始；太阳挂在页面上，所以第二处改动把它同样抬高20 mm，否则*Shadow*的“w”会碰到月牙。

```diff
-const SKY = 272; // 从裁切框上边缘到地平线（即天空下边缘）的毫米数
+const SKY = 252; // 从裁切框上边缘到地平线（即天空下边缘）的毫米数
-  disc('sun', 'sun', at('page', 'top-right', 30, 25)), // 有30 mm越过右边缘
+  disc('sun', 'sun', at('page', 'top-right', 30, 5)), // 有30 mm越过右边缘
```

## 常见问题

- 在pen里，1.4.1既不报告循环锚点，也不报告悬空锚点。沙盒的“检查”面板会列出页眉、页脚、篇页和各标题层级中的这类问题，但不检查`guides`这样的标题样式。钉在一个不存在的`#id`上的元素会相对容器定位：`'below'`这类元素边退回到容器左上角（偏移量照算），`'top-right'`这类容器边也退回到那个角。出现循环时，其中一个元素同样这样退回，其余元素再从它串下去。
- 在1.4.1中，`'align-left'`和`'align-top'`落在同一点：两者都把元素的左上角放在锚点的左上角。
- 边框以框的边缘为中线绘制，所以每条1 pt的粉色边框会超出所描的框0.5 pt，尽管配置文档说描边画在框内。
