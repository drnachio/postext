## できあがり

高校の生物の教科書『Living Matter』の第2章を、210 × 280 mmのページに組みます。章はページの天の角で断ち切られた細胞の図の下で始まり、細胞の核に章番号が入ります。その後に3色6種類の囲みが続き、それぞれが独自の目印を持つので、生徒は読む前に目標と注意を見分けられます。マゼンタは、的のアイコンを入れた帯に載せる学習目標と、枠の外にチェックの入ったタイルを置く確認問題に使います。緑は、電球のバッジを頭に載せた細い罫を添える学習のヒントと、3つの安全のピクトグラムを付けた実験の囲みに使います。注意は黄色で、外側の角に注意のバッジを掛けます。BOX 2.1は、黒いタブとフラスコの下にラベンダーの地色を敷きます。太字の用語はその囲みの色になり、BOX 2.1ではマゼンタです。

## 作り方

### 1 · 囲みの種類ごとに色を決める

<Excerpt region="palette" />

6種類の囲みが3つの色相を分け合います。マゼンタは目標と確認問題、緑は学習のヒントと実験、黄色は注意です。BOX 2.1はラベンダーの地色で、キーワードにはマゼンタを使います。各色相には地色用の淡いティントがあり、色の設定はすべてパレットの項目にリンクしているので、色相を変えるときは値をひとつ書き換えるだけです。この大きさの文字には4.5:1のコントラストが必要です。ラベンダーの上のマゼンタは4.9:1ありますが、注意の地色の上の黄色は2.2:1しかありません。そこで注意の囲みは、枠とバッジに黄色を使い、タイトルとキーワードは5.2:1の暗い黄色`warnInk`で組みます。

### 2 · それ以外はすべて共有する

<Excerpt region="base" />

`box()`には、すべての囲みが共有する設定をまとめます。マージン、パディング、タイトルと本文の文字、リストの間隔です。引数の`hue`は、タイトル、箇条書きの記号と番号、太字の部分に色を付けます。`body.boldColor`により、目標の囲みでは**fluid mosaic model**がマゼンタに、注意の囲みでは**cell wall**が黄褐色になります。本文中の太字は墨のままです（[囲みの中の文字組み](/ja/docs/configuration-styles#囲みの中の文字組み)）。`calloutStyles`を宣言すると、エンジンが標準で持つ唯一のスタイル、灰色の囲み`note`が置き換えられます。`type`がないか綴りを誤ったフェンスは最初のスタイルになるので、どの章にもある目標をリストの先頭に置きます。

### 3 · 帯、タブ、バッジ

コードは前出の[手短な答え](#手短な答え)にあります。目標の帯は幅7.5 mm、的のアイコンは5 mmなので、アイコンは左右に余裕を残して色の中に収まります。タブの`offset`を`height`と同じにすると、タブは囲みの上辺に立ち、タイトルにかかりません。`'top-left'`はこの偶数ページの外側の角です。フラスコはタブの後に続き、罫はフラスコから上辺に沿って反対の角まで伸びます。`position: 'corner'`は注意のバッジを幅の半分だけ辺の外に掛け、`cornerSide: 'outer'`はバッジを小口側、つまりこの偶数ページでは左に送ります。その側では、パディングがバッジの半分とタイトルの間隔をすでに覆っていない限り、エンジンがタイトルを字下げしてバッジを避けます。そこで注意の囲みは両側に`BADGE / 2 + GAP`のパディングを取り、タイトルを本文にそろえます。`borderRadius`を持つのはこの囲みだけです。枠線のある囲みはこれひとつで、1.4 mmの角丸が四隅をやわらげます。帯のある囲みに角丸を付けると、帯の外側の角も一緒に丸くなります（[囲みスタイル](/ja/docs/configuration-styles#囲みスタイル)）。

### 4 · さらに3つの目印

<Excerpt region="more" />

学習のヒントの帯は幅2.5 ptで、6.4 mmの電球のバッジに対して細い罫として刷られ、その上端にバッジが載ります。左のパディングをバッジの半分に2 mmを足した値にして、本文を電球から離します。`icon.width`は絵を正方形ではなく横長の枠に収めます。これで1枚の24.5 mmの画像として描いた3つの安全のピクトグラムが、実験の囲みのアイコン列になり、本文に対して中央に置かれます。確認問題の目印は枠の外にあり、目印、罫、間隔、囲みの順に並びます。0.75 ptの罫に載せた四角いタイルが、丸いバッジを持つ学習のヒントとの違いを示します。フェンスに`span="page" placement="bottom"`を加えて、確認問題を<PageRef page={3}>29ページ</PageRef>の地にフロートとして配置します。

### 5 · アイコンはリソース

<Excerpt region="icons" />

すべてのアイコン、タブの横のフラスコ、章扉の細胞は、コンテンツと一緒に宣言してファイルidで登録したSVGのリソースです。スタイルはリソースidでそれらを指定し、本文からは引用しないので、どれも番号付きの図にはなりません。✓や☞のようなグリフのほうが短く書けますが、ページが読み込むFontsourceのlatinファイルにはこれらがありません。Canvasはシステムフォントから借りて描き、PDFでは消えてしまいます。図にも文字は入れていません。色はキャプションで説明するので、同じ図を両方の版で使えます。

### 6 · 細胞で章を始める

<Excerpt region="opener" />

細胞は、ページの右上の角に固定して角の外まで押し出した画像要素です。そのため見えるのはおもに左下の4分の1で、核に数字が入ります。どちらも`minHeight`が章扉のために確保する66 mmの中に収まります。キッカーとリードは見出しの行`# Cells and \\ Membranes {unit="The cell" lead="…"}`から取り、`\\`は章扉でだけタイトルを改行します。

## アレンジ

### 囲みを両段にまたがらせる

フェンスに`span="page"`を付けると、どの種類の囲みも両段にまたがって組まれます。BOX 2.1はさらに`:::columns`のグループを入れ子にして、図を本文の横に置いています。

```diff
-:::callout{type="warning" title="Membrane or wall?"}
+:::callout{type="warning" title="Membrane or wall?" span="page"}
```

### バッジをのど側に掛ける

`'inner'`はバッジをのど側、つまり奇数ページでは左、偶数ページでは右に移します。囲みの外に掛かる半分のために、その側に場所を空けておいてください。

```diff
-    icon: icon('caution', BADGE, { position: 'corner', cornerSide: 'outer' }) }),
+    icon: icon('caution', BADGE, { position: 'corner', cornerSide: 'inner' }) }),
```

### タブを右の角に立てる

既定値の`'top-right'`はラベル全体を左右反転させます。タブは右の角に、フラスコはその左に移り、罫は左から伸びます。

```diff
-      position: 'top-left', // this verso's outer corner, above the badge ('top-right' by default)
+      position: 'top-right',
```

## よくあるつまずき

- タブが刷られるのは、フェンスに`label="BOX 2.1"`があり、スタイルに`label`オブジェクトがある場合だけです。`label`オブジェクトのないスタイルはこの属性を無視します。
- Postextは囲みに番号を振りません。ラベルはフェンスに書いた文字列そのものなので、BOX 2.1、BOX 2.2と番号を一つひとつ手で打ちます。
- コーナーバッジは囲みの辺から幅の半分だけはみ出し、ページの外側では余白に掛かります。同じページのもう一方の段では段間に掛かるので、バッジ付きの囲みは外側の段に置くか、場所を空けておいてください。
- 囲みの`lists.color`は、箇条書きの記号と番号付きリストの番号の両方に色を付けます。ここでは番号の付いた手順と問いが、それぞれの囲みの色で刷られます。囲みの記号だけに色を付けたいときは、そのスタイルに`lists.color`を書かず、文書の`unorderedLists.color`を設定します。番号は`orderedLists.color`のまま残ります。
