## できあがり

<RecipeLink slug="tebeo-album-page">No. 152</RecipeLink>のアルバムの二つ目のお話『おじいちゃん！』を、向かい合う二ページで語ります。十二月の土曜日、市場は人でいっぱいで、ローラは人ごみでおじいちゃんとはぐれてしまいます。見開きの上半分は幅432mmのパノラマ一枚。左端に小さなローラ、右端に彼女を探すパコ、そのあいだを市場の通路が走ってノドへ続きます。その下に三コマ。大人の脚のあいだで一人きりのローラ、果物の箱に乗って指笛を吹くパコ、ベレー帽が宙に舞う再会です。コマ割りは二ページ分を一度だけ書くので、パノラマはノドをまたぎ、下の段のコマ間はちょうどノドに落ちます。原作はスペイン語で、英語、カタルーニャ語、中国語、アラビア語、日本語の版が同じ見開きに写植します。

## 作り方

### 1 · 二ページで一つのコマ割り

コードは上の[手短な答え](#手短な答え)にあります。漫画全体が `spread` を付けた一つのディレクティブです。

```md
:::page{spread split="55 / * [25 | 25 | *]"}
::panel{art=ds1}
caption: 十二月の土曜日、市場は人でいっぱいだった。
lola: おじいちゃん？
paco{shout}: ローラ？ ローラーッ！
```

枠は偶数ページの小口側の余白から奇数ページの小口側の余白まで続き、ノド側の余白はなくなります。一段目は高さの55%で、ノドをまたぐ一コマです。二段目では `25 | 25 | *` が一本目の線を25%、二本目を50%、つまりノドそのものに置きます。正方形の二コマが偶数ページに、再会のコマが奇数ページに入ります。見開きは偶数ページから始まり、文書の1ページ目は奇数ページなので、ビルドに `continuation: { pageIndexOffset: 1 }` を渡します。このお話はアルバムの2ページ目から続くことになり、前に白ページは入りません。

### 2 · 二ページを埋める大きさのパノラマ

<Excerpt region="art" />

ノドをまたいで印刷されるのはパノラマだけで、432 × 144mmあるので1,900px（380KB）で用意しています。ほかの三枚は1,000〜1,200pxです。安全領域は横幅のほぼ全体にわたる帯で、話す二人は横幅の6%と92%の両端に立っています。ノドの近くの吹き出しは製本に飲みこまれてしまうからです。絵の中央は顔のない通路で、そのままノドへ続きます。

### 3 · アルバムの吹き出し

<Excerpt region="balloons" />

吹き出しのスタイルはNo. 152と同じです。白い吹き出し、淡い黄色のナレーション枠、パコの叫びには爆発形、ローラのささやきには破線、指笛はアルバムの擬音の書体（ラテン文字の版ではBangers）。`cast` は、PDFとEPUBがせりふの前に読み上げる名前を渡します。

## アレンジ

### 本を見開きから始める

continuation を外すと、エンジンは1ページ目を白ページ（役割 `blank`）にし、見開きはやはり2・3ページに入ります。

```diff
-const continuation = { pageIndexOffset: 1, pageNumbering: { startAt: 2 } };
+const continuation = {};
```

## よくあるつまずき

- 吹き出しはノドの両側8mmの帯には入りません。`at`で固定したものも同じです。ノドの上に立つ話者の吹き出しは片側へ押し出されます。ノドをまたぐコマでは、話者を真ん中から離してください。
- 顔が触れ合う二人（抱き合う、組み合う）の上には、話している本人の分も含めて吹き出しを置きません。日本語版とアラビア語版では見開きを右から読み、再会のコマは左ページに移り、右上の角は舞い上がるベレー帽がふさぎます。パコの二つの吹き出しは抱き合う二人の上ではなく、頭の横の市場の上に置かれます。エンジンが顔の触れ合いを見分けられるよう、絵には二人の顔（`face`）を指定してください。
