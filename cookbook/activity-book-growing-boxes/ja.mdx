## できあがり

架空の小学4年生向け理科ワークブック『Water on the move』の単元3から5ページを、210 × 280 mmで組みます。表紙は拡散モデルで生成した水の循環の画像が塗り足しまで広がり、下端で紙に溶け、その上に5本のベクターの矢印が重なり、その下に54 ptの書名と名前を書く罫線があります。プリントはどれも同じページテンプレートから組みます。単元名の行、青い帯の見出し、小さな画像を添えた短い本文、番号のタブが付いた水色の活動の囲みが三つ。一つめと三つめの囲みの下には答えを書く罫線があります。囲みの高さは中の文章で決まるので、あちこちで1行ずつ長くなるフランス語版では、テンプレートの位置を何も変えなくても英語版より罫線が下に来ます。工作はペットボトルで雨量計を作るもので、手順が1ページに収まりません。手順の囲みはページの下端で *Continued* を付けて切れ、追加されたページの上で続き、そのあとに観察を書く6本の罫線が続きます。タブや観察欄の見出しを含め、文字はすべてMarkdownに書きます。

## 作り方

### 1 · 活動を名前で自分の囲みに流し込む

テンプレートは上の[手短な答え](#手短な答え)です。Markdownでは、プリント1枚が1つの`::::page`ブロックです。最初の見出しは`takes: 'h1'`の枠へ、段落は流し込み枠へ、`:::frame{slot="…"}`はそれぞれ同じ名前の枠へ入り、タブの文字は`label`に書きます。解答の枠には何も入らないので`optional: true`を付けます。付けないと空の枠が`slotEmpty`の警告を出します。絵を描く活動は`:::space{lines=3}`で自分の囲みの中に白い場所を取ります。どれだけの場所が要るかは、問題の一部だからです。

```md
:::frame{slot="act-1" label="1 · Read and answer"}
Tom lives in Leeds. The water from his tap comes from a reservoir in the hills…
:::
```

### 2 · 罫線を囲みと一緒にスタックで動かす

囲みにはどれも描いたときの高さ22 mmを`minHeight`に指定し、それより上は`auto`の高さにします。グループは、本文の下に置いた`act-1`の位置から5つの枠を4.5 mm間隔で縦に並べるので、ある囲みが伸びるとその後ろがすべて下がります。罫線は空の枠そのものに属します。その`rules`が、枠の高さ8 mmごとの下端、文字の下に1本ずつ線を引くので、罫線は枠と一緒に動き、解答欄を長くすれば枠が高くなります。解答の枠には高さと同じ`minHeight`を指定してください。グループの場所が足りなくなると、[リフローの段階](/ja/docs/composed-pages#それでも収まらないとき)はグループの枠から最小値まで場所を取り戻しますが、空の枠の最小値はゼロなので、罫線が次の囲みに重なってしまいます。ワークシートの最後の囲み`act-3`は、文章がページに収まらないと次のページへ続き（`overflow.continueIn: 'next-page'`）、その下の解答の罫線も一緒に移ります。

### 3 · 工作を次のページへ続ける

<Excerpt region="continue" />

手順の囲みには決まった高さがなく、文章に合わせて伸び、版面の下端で止まります。別のページへ続けられる枠は、文字を縮める前に続きへ送ります。そのため囲みは本来の文字サイズのまま行と行のあいだで切れ、言語ごとの継続マーカー（`locale`に応じて *Continúa*、*Continued*、*À suivre*）で終わり、`proyecto-sigue`のページの同じ名前の枠で続きます（[文章が追加ページに続くとき](/ja/docs/composed-pages#文章が追加ページに続くとき)）。追加されたページは囲みの続きの下に観察の罫線を引き、見出しにはページブロックに書いた`notas="What I noticed"`の文字を使います。文字はMarkdownに残り、版ごとに変わります。

### 4 · 表紙を裁ち落としまで描く

<Excerpt region="cover" />

表紙もテンプレートページです。画像は塗り足しに固定した装飾で、書名、シリーズ名、名前欄が版面の上から162 mmの位置から始まる縦の積み重ねになります。名前の罫は枠の下端に固定してあるので、別の言語でラベルが2行になっても罫は文字の下にあります。`header: false`と`footer: false`で表紙にはノンブルを付けません。

## アレンジ

### 活動の罫線を増やす

罫線の本数は解答の枠の高さで決まります。`rules`が入るだけの線を引くので、テンプレートでこの値を変えれば、それを使うすべてのワークシートにその本数の罫線が付きます。

```diff
-    answer('lineas-1', 3),
+    answer('lineas-1', 5),
```

### 続ける前に手順を縮めてみる

別のページへ続けられる枠は、文字を縮める前に続きへ送ります。`fit.preferContinue: false`を指定すると、段階はまず手順を`fit.minScale`（90 %）まで小さく組み、それでも足りないときだけ別のページへ送ります。子どもの本では、1ページ減らすことより文字の大きさのほうが大事なので、このレシピは既定のままにしています。

```diff
-      overflow: { continueIn: 'next-page' } },
+      fit: { preferContinue: false }, overflow: { continueIn: 'next-page' } },
```

## よくあるつまずき

- 何も入らない枠は、`optional: true`を付けないと`slotEmpty`を出します。ここでは解答の枠すべてに付けています。
- 積み重ねでは囲みを置くのはグループで、囲み自身の`placement`は使われません。ただし最初の一つは例外です。グループの最初の囲みの位置を決めておかないと、積み重ねは版面の上端から始まり、見出しに重なります。
