## できあがり

『Five Ways to Begin』は章扉について書いた7ページの本で、判型は180 × 240 mm、各章はその章が説明する章扉で組まれます。第1章は小説の章扉です。字間を空けたキッカー（題の上の小さな見出し）、細いイタリックの題、5行分の赤い頭文字が入り、続くページには柱が付きます。第2章は、2本の青い罫で描いたクリーム色のカルトゥーシュの中に題と花形装飾を収めます。第3章は、ページから裁ち落としたマゼンタの地に白いFraunces Blackで題を積み上げ、その下に箱から白抜きにした等幅書体の頭文字を置きます。マニュアルである第4章は、等幅書体の柱、題の横のオレンジの番号バッジ、Geistの2段組みです。終章は何もないページの中ほどに題を置き、その下に突き出しの頭文字を置きます。第1章はレベル1自身の章扉を使い、ほかの4章は見出し行で見出しスタイルの名前を指定します。

## 作り方

### 1 · 本の章扉をレベルに設定する

<Excerpt region="literary" />

第1章にはスタイルがないので、レベル1自身のデザインを使います。どのスタイルもこのデザインを出発点にします（レベルとスタイルは[手短な答え](#手短な答え)にあります）。章の最初の段落はMarkdownにあり、本文より一回り大きい`:::paragraphs{style="lead"}`のグループに入っています（本文の10.8/14.5 ptに対して12/17 pt）。レベルの`dropCap`がこの段落を頭文字で始めます（[ドロップキャップ](/ja/docs/configuration#ドロップキャップ)）。Mは5本目のベースラインに立ち、`fontSize`を指定しなければ上端が1行目の大文字とそろいます。どちらのキャップハイトもFrauncesとLoraから測ります。章扉は題の17 mm下に置いた空の箱`room()`で終わり、書き出しの段落はそこから始まります。書き出しの段落の下の`:::space`が1行空け、本文を字下げなしで始めます。

### 2 · 題を2つの箱で囲む

<Excerpt region="framed" />

配列の順が描画の順なので、箱を先に、文字を上に置きます。飾りは画像要素で、登録したSVGリソースを描きますが、そのリソースが番号付けされたり参照されたりすることはありません。章ごとに独自の写真を与えるのも画像要素です。postext 1.8から`resourceId`がプレースホルダーを受け付けるので、`resourceId: '{attr.photo}'`とすれば、1つのスタイルで各見出しが名前を指す写真を描けます。`# The Frame {style="framed" photo="lake"}`のように書き、<RecipeLink slug="recipe-card">レシピカード</RecipeLink>の料理写真と同じ仕組みです（[画像要素](/ja/docs/configuration#画像要素)）。手短な答えの`framed`スタイルは`palette`を設定してこの章のページで`accent`を青に変えるので、罫、キッカー、地側のノンブルが青で刷られます。また`margins`で版面を枠の下の中央に置きます。スタイル自身の`dropCap`は`col('accent')`を指定し、パレットはこれも青に変えるので、3行分のLは枠と同じ色になります。

### 3 · 題を積み上げ、頭文字を箱に入れる

<Excerpt region="stacked" />

積み上げはMarkdownに書きます。`# Say it \\ out \\ loud.`は`\\`ごとに`{titleText}`を改行し、柱とPDFのしおりは題を1行として読みます（[タイトル内の改行](/ja/docs/document-format#タイトル内の改行)）。地色は裁ち落としの上端から全幅で130 mmの深さまで下がり、書き出しの段落はその8 mm下の最初のグリッド線から始まります（`TEXT_TOP`）。箱の頭文字は2つの部品からなります。スタイルの`dropCap`がMを書き出しの段落の3行分に白で組み、章扉はその下にマゼンタの箱を描きます。箱の位置は`TEXT_TOP`、書き出しの段落の行送り、Geist Monoのメトリクスから決めるので、Mの上下の色の幅はサイドベアリングと同じになります。箱は章扉の中に場所を取りません（`reserve: false`）。空の`room`の箱が、書き出しの段落の始まる位置で章扉を終えます。

### 4 · マニュアルにバッジ、2段組み、独自の柱を与える

<Excerpt region="spec" />

バッジは地色とパディングを持ち、幅を持たないテキスト要素なので、幅は`{chapterNumber}`に従います。題はその`right-of`に置きます。第10章になるとバッジは数字1つ分、5.5 mm広がり、題もそれに合わせて動きます。行ボックスは数字の下にそれだけ多く余白を持つので、下パディングを上より1 mm少なくし、4が中央に来るようにしています。`spec`スタイルでは`layout`がこの節を2段組みにし、レベルの`span: 'page'`が章扉を両段にまたがらせます。`margins`は版面を144 mmに広げ、`bodyStyle`は本の14.5 ptのグリッドに左そろえのGeistを組み、`header`は本の柱を置き換え、空の`footer`はノンブルを消します。

### 5 · 終章に余白を残す

<Excerpt region="quiet" />

キッカーは版面の頭から92 mm下に下がり、突き出しの頭文字は`quiet`スタイルの1行のドロップキャップです。足は1本目のベースラインに立ち、46 ptなので段落の中へ沈まずに上の余白へ伸びます。段落はこの突き出しの分を上に行単位で空けておくので、題の下の章扉の`room`は3 mmで足ります。`quiet`スタイルでは、`margins`が行長を106 mmに狭め、`bodyStyle`が本文を12.5/17.5 ptの左そろえで組み、`footer`が地側のノンブルを小口の角の小さなノンブルに替え、`palette`がキッカーを灰色にします。このページには章番号を刷るものがないので、`numbered: false`の効果が見えるのは終章の後に章を足したときだけで、その章はやはり5番目になります。

## アレンジ

### すべての章を奇数ページから始める

`'odd'`にすると、すべての章が右ページで始まり、第2章から第5章まではそれぞれ前に白い偶数ページが入るので、本は7ページから11ページに増えます。

```diff
-  breakBefore: { enabled: true, parity: 'any' },
+  breakBefore: { enabled: true, parity: 'odd' },
```

### 頭文字を3行分にする

`fontSize`を指定しなければ大きさは行数に従うので、3行分の頭文字でも1行目の大文字とそろいます。

```diff
-  dropCap: { lines: 5, fontFamily: 'Fraunces', fontWeight: 400, color: col('accent'),
+  dropCap: { lines: 3, fontFamily: 'Fraunces', fontWeight: 400, color: col('accent'),
```

### 頭文字に続く語をスモールキャピタルにする

`leadIn`は、多くの小説がするように、頭文字に続く最初の語をスモールキャピタルで組みます。`words: 'line'`にすると1行目全体が対象になります。

```diff
-    gap: mm(2.5) } });
+    gap: mm(2.5), leadIn: { words: 'line' } } });
```

## よくあるつまずき

- 書き出しの段落は、雑誌の章扉のように左そろえで組んでいます。5行分の頭文字の横で両端そろえにすると、語の少ない行で語間が大きく開くことがあります。
- マゼンタの箱は、Lora 12/17、Geist MonoのM、そして行ボックスの0.8の位置にある行のベースライン（`BASE`）に合わせて手で調整しています。書き出しの段落の書体、サイズ、行送り、頭文字、行数、地色の深さのいずれかを変えたら、箱を1行目の大文字と照らし合わせて確かめ直してください。
- 題が回転したり縦に組まれたりすることはありません。デザインのテキストはつねに横組みです。代わりに、第3章のように`\\`で語を積み上げてください。
