## 成品一览

*Five Ways to Begin*是一本讲章首页的七页小书，180 × 240 mm，每一章都用它所讲的那种章首页排。第一章是小说式的：加宽字距的眉题、细斜体标题和五行高的红色首字母，后续页面带书眉。第二章把标题和一个花饰放在奶油色花框里，框由两条蓝线画成。第三章把标题以白色Fraunces Black堆叠在出血的品红色底上，下面是反白在方框里的等宽首字母。第四章是手册：等宽字体书眉、标题旁的橙色编号徽标，以及两栏Geist正文。尾声把标题排在空白页的中部，下面是一个上升首字母。第一章使用一级标题自己的章首页，其余四章在标题行上点名一种标题样式。

## 做法

### 1 · 在标题级别上设定本书的章首页

<Excerpt region="literary" />

第一章没有样式，所以采用一级标题自己的设计，所有样式都以它为起点（[简短回答](#简短回答)列出了这一级别和各样式）。本章的第一段写在Markdown里，放在`:::paragraphs{style="lead"}`组中，字号比正文大一档（12/17 pt，正文是10.8/14.5），由这一级别的`dropCap`开头（[首字下沉](/zh/docs/configuration-text#首字下沉)）：M立在第五条基线上，不设`fontSize`时，它的顶端与首行大写字母齐平，两者的大写字母高度都从Fraunces和Lora中量得。章首页以一个空方框`room()`结束，它位于标题下方17 mm，导语从那里开始；导语下的`:::space`空出一行，正文从下一行不缩进地开始。

### 2 · 用两个方框给标题加框

<Excerpt region="framed" />

数组顺序就是绘制顺序，所以方框在前，文字在上；花饰是一个图像元素，绘制一个已注册的SVG资源，这个资源不编号也不被引用。每一章要有自己的照片，也是靠图像元素：从postext 1.8起，它的`resourceId`接受占位符，于是用`resourceId: '{attr.photo}'`，一种样式就能绘制每个标题点名的照片，例如`# The Frame {style="framed" photo="lake"}`，<RecipeLink slug="recipe-card">菜谱卡片</RecipeLink>里的菜品就是这样做的（[图像元素](/zh/docs/configuration-page-layout#图像元素)）。简短回答里的`framed`样式设置了`palette`，把本章各页的`accent`变成蓝色，于是线条、眉题和底部页码都印成蓝色；它的`margins`让文字块在花框下居中。这个样式自己的`dropCap`指定`col('accent')`，调色板同样把它变成蓝色，所以三行高的L与花框颜色一致。

### 3 · 堆叠标题，给首字母加框

<Excerpt region="stacked" />

堆叠写在Markdown里：`# Say it \\ out \\ loud.`在每个`\\`处给`{titleText}`换行，而书眉和PDF书签把标题读作一行（[标题中的换行](/zh/docs/document-format#标题中的换行)）。色底从出血的顶端垂下，通宽，高130 mm，导语从它下方8 mm处的第一条网格线开始（`TEXT_TOP`）。加框的首字母由两部分组成。样式的`dropCap`把白色的M排成导语的三行高，章首页在它下面画一个品红色方框，位置根据`TEXT_TOP`、导语的行距和Geist Mono的字体度量确定，让M上下露出的颜色与它的左右侧边距一样宽。这个方框在章首页里不占空间（`reserve: false`）；一个空的`room`方框让章首页结束在导语开始的地方。

### 4 · 给手册加上徽标、两栏和自己的书眉

<Excerpt region="spec" />

徽标是一个带填充和内边距、但没有宽度的文字元素，所以宽度跟随`{chapterNumber}`；标题用`right-of`放在它右侧：到第10章，徽标多一位数字，加宽5.5 mm，标题也随之移动。它的下内边距比上内边距少1 mm，因为行框在数字下方多留了这么多空间，这样4才居中。在`spec`样式里，`layout`把这一节排成两栏，而这一级别的`span: 'page'`让章首页横跨两栏。它的`margins`把文字块加宽到144 mm，`bodyStyle`在本书14.5 pt的网格上排齐左的Geist，`header`替换本书的书眉，空的`footer`去掉页码。

### 5 · 给尾声留出空间

<Excerpt region="quiet" />

眉题挂在文字块顶端以下92 mm处，上升首字母是`quiet`样式一行高的首字下沉：它的底部立在第一条基线上，字号46 pt，所以向上伸进空白，而不是沉入段落。段落会在上方以整行为单位为这段升高留出空间，所以章首页在标题下的`room`只有3 mm。在`quiet`样式里，`margins`把行长收窄到106 mm，`bodyStyle`把正文排成12.5/17.5 pt的齐左，`footer`把底部页码换成外侧角上的小页码，`palette`把眉题变成灰色。这一页上没有印章号，所以`numbered: false`只会在尾声之后新增的章里显出效果，那一章仍会是第五章。

## 变化

### 让每一章都从右页开始

改成`'odd'`后，每章都在右页开始，第二至第五章之前各多一个空白左页，全书从7页增加到11页。

```diff
-  breakBefore: { enabled: true, parity: 'any' },
+  breakBefore: { enabled: true, parity: 'odd' },
```

### 首字母下沉三行

不设`fontSize`时，字号随行数而定，所以三行高的首字母同样与首行大写字母对齐。

```diff
-  dropCap: { lines: 5, fontFamily: 'Fraunces', fontWeight: 400, color: col('accent'),
+  dropCap: { lines: 3, fontFamily: 'Fraunces', fontWeight: 400, color: col('accent'),
```

### 首字母后的小型大写字母

`leadIn`把首字母后的头几个词排成小型大写字母，许多小说都这样做；`words: 'line'`则取整个第一行。

```diff
-    gap: mm(2.5) } });
+    gap: mm(2.5), leadIn: { words: 'line' } } });
```

## 常见问题

- 导语齐左排，和杂志的章首页一样；两端对齐的导语排在五行高的首字母旁，词少的行会把词距撑得很开。
- 品红色方框是按Lora 12/17、Geist Mono的M和该行的基线手工调好的，基线位于行框往下0.8处（`BASE`）。只要改了导语的字体、字号或行距、字母、行数或色底的高度，都要重新对照首行大写字母检查方框。
- 标题不会旋转，也不会竖排：设计文本总是横排的。改用`\\`堆叠单词，就像第三章那样。
