## 成品一览

*Peek-a-boo! Who’s in the Garden?*（西班牙语版《¡Cucú!》），十四页纸板书，160毫米见方，四个角都切圆。每幅画都有一个孔，孔正好开在下一幅画最能骗过眼睛的部位：一只睡着的猫的条纹侧腹，像老虎；一只羊的毛，像云；一盏灯笼，像月亮。封面的窗比后面的孔大，所以第一眼就能看到两页深。左页的文字让孩子猜，翻页就是答案。交给印厂的PDF把模切线放在单独的色版上。

## 做法

### 1 · 孔开在下一幅画露馅的地方

代码见上方的[简短回答](#简短回答)。每个形状从成品尺寸左上角起定位，`dieCuts.pages`指明它切哪一页，从全书第一页数起。孔的位置要量在它露出的那幅画上，而不是开孔的那一页：树篱、篱笆和谷仓门是哪里开孔都行的纹理，猫和灯笼不行。

### 2 · 画面与孔对准

<Excerpt region="pictures" />

孔以从裁切线量起的毫米表示，所以每幅画都挂在裁切线上，四边各伸出出血，屏幕和印刷一致。画页样式只去掉下边距：设计一直画到页脚，画后面那个左页上的文字保留44毫米的上边距，正好落在小孔顶端之下。

### 3 · 模切线在自己的色版上

<Excerpt region="die-line" />

PDF把每一页完整印出，并把每个孔和每张切圆纸页的轮廓描在一个叠印、从不上墨的`Die`分色上。`convertImages: false`让画保持为标记sRGB的RGB JPEG，PDF/X-4允许这样做，文件也就不大。

### 4 · 拿在手里的书

<Excerpt region="folio" />

Folio在每张纸页上切出孔，并连同切口的侧壁显示下面的页面，阶梯式的窗就有了深度。纸板翻起来很硬，每张纸页都切了圆角。

### 5 · 平铺的页面也能透视

<Excerpt region="see-through" />

在画布上，如果渲染器拿不到下面的页面，孔里显示的是画布后面的东西。`beneath`按索引返回这些页面，每页都带着自己的孔绘制，于是封面露出树篱，透过树篱又露出猫。

## 变化

### 只切圆切口一侧的角

绘本常把远离书脊的两个角切圆，书脊一侧保持直角。

```diff
-  corners: { radius: mm(9), edges: 'all' }, // board books are rounded on all four corners
+  corners: { radius: mm(6), edges: 'fore' },
```

### 把每张纸页切成一个形状

用`viewBox`单位写的轮廓切每一张纸页，左页镜像；它优先于圆角。

```diff
   corners: { radius: mm(9), edges: 'all' }, // board books are rounded on all four corners
+  outline: { d: 'M0 0.35 L0.5 0 L1 0.35 L1 1 L0 1 Z', viewBox: [1, 1] }, // a house
```
