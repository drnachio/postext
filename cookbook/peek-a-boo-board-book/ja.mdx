## できあがり

*Peek-a-boo! Who’s in the Garden?*（スペイン語版は『¡Cucú!』）。160ミリ角、14ページのボードブックで、四隅を丸く抜いています。どの絵にも穴があり、その穴は次の絵の、目をだます部分にぴったり重なります。眠っている猫のしま模様の脇腹はトラに見え、羊の毛は雲に、ちょうちんは月に見えます。表紙の窓は奥の穴より大きいので、最初のひと目で2ページ奥までのぞけます。左のページの文が当てっこをさせ、めくると答えが出ます。印刷所に渡すPDFには、抜き型の線が専用の版に載ります。

## 作り方

### 1 · 次の絵が正体を見せる場所に穴を

コードは上の[手短な答え](#手短な答え)です。形は仕上がりの左上の角から置き、`dieCuts.pages`で抜くページを、本の最初のページから数えて指定します。穴は、それを抜くページではなく、穴からのぞく絵の上で測ります。生け垣、柵、扉はどこに穴があってもよいテクスチャーですが、猫とちょうちんはそうはいきません。

### 2 · 穴と位置をそろえた絵

<Excerpt region="pictures" />

穴の位置は仕上がり線からのミリで決まるので、どの絵も仕上がり線から下げ、四辺とも塗り足し分はみ出させます。画面でも印刷でも同じ位置です。絵のスタイルは下マージンだけをなくします。デザインはページの下端まで届き、絵の裏の左ページの文字は44ミリの上マージンを保って、小さな穴の上端より下から始まります。

### 3 · 専用の版に載る抜き型の線

<Excerpt region="die-line" />

PDFは各ページを丸ごと印刷し、穴と角丸の丁の輪郭を、オーバープリントでインキを載せない`Die`の分版に描きます。`convertImages: false`で絵はsRGBタグ付きのRGB JPEGのまま残り（PDF/X-4で認められています）、ファイルは小さく収まります。

### 4 · 手に取った本

<Excerpt region="folio" />

Folioは各丁に穴を抜き、切り口の壁ごと下のページを見せるので、段になった窓が奥行きとして読めます。厚紙は硬くめくれ、角丸はすべての丁で抜かれます。

### 5 · 平らなページでものぞける

<Excerpt region="see-through" />

キャンバスでは、レンダラーが下のページを受け取らないと、穴にはキャンバスの後ろが見えます。`beneath`がページを番号で返し、それぞれ自分の穴ごと描かれるので、表紙から生け垣が、生け垣の穴から猫が見えます。

## アレンジ

### 小口側の角だけ丸める

絵本では背から遠い2つの角を丸め、背側は直角のままにします。

```diff
-  corners: { radius: mm(9), edges: 'all' }, // board books are rounded on all four corners
+  corners: { radius: mm(6), edges: 'fore' },
```

### 丁ごと形に抜く

`viewBox`単位の輪郭で各丁を抜きます。左ページでは左右反転し、角丸より優先されます。

```diff
   corners: { radius: mm(9), edges: 'all' }, // board books are rounded on all four corners
+  outline: { d: 'M0 0.35 L0.5 0 L1 0.35 L1 1 L0 1 Z', viewBox: [1, 1] }, // a house
```
