## できあがり

漫画『ポースコーヴの灯』の一ページぶんのレイアウト校正です。表紙と、同じページを三案に組んだもので、作者が一つを選びます。五枚の絵（灯台へ登るマヤ、黙ったラジオの前の祖父、床を指さすマヤ、コードの上で眠る猫、夜にともった灯）と六つのせりふは変わらず、変わるのは各`:::page`の`split`だけです。絵はコマごとに切り直され、吹き出しは話し手のそばに置き直されます。判型はアメリカのコミックブックの168 × 259 mmで、校正は六つの版に分かれ、それぞれの言語で写植されます。

## 作り方

### 1 · 分割ツリーでページを割る

コードは前の[手短な答え](#手短な答え)にあります。`:::page`は版面いっぱい、ここでは144 × 227 mmを占め、その`split`属性がページを割ります。`/`は段を、`|`は列を分け、数値は割る対象のコマに対する百分率、`*`は残りを等分し、角かっこはそのコマをもう一方の向きでさらに割ります（[ページの分割](/ja/docs/comics#ページの分割)）。C案の`30 [30 | 20 | *] / *`は、高さ30%の段を作って幅30%と20%と残りの三コマに割り、その下に縦長の一コマを残します。コマ間はそれぞれの分割線をまたいで取られ、段と段の間が4 mm、同じ段のコマの間が3 mmです。`::panel`の行は読む順にコマを埋めます。段は上から、列は始まりの側からです。

<PageShot page={4} crop="0,0,1,0.34" caption="C案：30 | 20 | 残りの段。猫は三コマ目に重ねた小ゴマ。" />

### 2 · 絵ごとにセーフエリアを決める

<Excerpt region="art" />

絵は一度だけ描き、入るコマを埋めるように切り抜かれます。セーフエリアは、どの切り抜きでも欠けずに残る部分です（[コマと絵](/ja/docs/comics#コマと絵)）。ラジオの絵のセーフエリアは灯台守だけで幅の24%なので、C案の幅26 mmのコマでは帽子から長靴まで彼が見え、ラジオは外れます。A案とB案の横長のコマでは両方が見えます。コマの形にセーフエリアが収まらないときは、絵の上下か左右に余白が出て、組版時に警告が出ます（`comicPanelLetterbox`）。アンカーは各人物の口と顔を同じ比率で示すので、どの切り抜きでも吹き出しのしっぽは話し手に届きます。

### 3 · コマの上にコマを重ねる

C案の割り方では、五コマに対してセルが四つしかありません。猫は`inset="50 50 46 46"`で入れます。直前のコマ（マヤのコマ）の幅と高さの46%の大きさで、その50%、50%の位置に置く小ゴマです。小ゴマはセルを使わないので後のコマの位置は変わらず、重なっているコマのすぐ後に読まれます。

### 4 · 一つのレイアウトで六つの版を写植する

<Excerpt region="editions" />

割り方、絵、切り抜き、アンカーはどの言語でも同じです。`content.<lang>.md`には言葉だけを、同じ話者ID（`maya`、`tomas`）で書きます。日本語版は吹き出しを縦組みにし、一行八字までで、文末の「。」を取ります。アラビア語版は右から左へ読むので、各段のコマの並びが左右逆になりますが、絵そのものは反転しません。写植の文字サイズはどの版も8 ptです。せりふが長ければ吹き出しが大きくなり、文字が小さくなることはありません（[写植](/ja/docs/comics#写植)）。

## アレンジ

### 中段を斜めに割る

`30~40`と書いた数値は、そのコマの終わりのコマ間を一端の30%から他端の40%まで斜めに引きます。斜めのコマは角が丸くなりません。

```diff
-:::page{split="30 / 35 [* | * | *] / *"}
+:::page{split="30 / 35 [30~40 | * | *] / *"}
```

### アラビア語版で絵を反転する

絵は初期設定では向きを変えません。文字も時計も描かれていない漫画なら、読む向きに合わせて反転できます。

```diff
 const comics = {
+  mirrorArt: true, // 右から左の版では絵を反転する
   gutter: { horizontal: mm(4), vertical: mm(3) },
```

## よくあるつまずき

- ページ幅の五分の一のコマには、8 ptで一行に英単語四つほどしか入りません。C案の灯台守は顔がコマの真ん中にあり、嵐を告げる二つのフキダシは顔の上にも下にも収まりません。そこでC案だけ、二行のうち最初の行に`break`を付けています（`tomas{break}:`）。二つのフキダシは枠を越えて隣のマヤのコマへ入ってもよく、エンジンは二つ目を一つ目の後に置き、ページの余白へは出しません。`break`がなければビルドは`comicBalloonOverflow`を警告します。
- セーフエリアを狭くすると多くのコマできれいに切り抜けますが、外側にあるものは欠けることがあります。A案の上段の長靴、C案のラジオがそうです。
