## できあがり

ソローが『ウォールデン』第1章に載せた家計簿の小さな版です。家にいくらかかったか、豆畑でいくら得たか、8か月で何を食べたか。140 × 216 mm のページに Alegreya ファミリーで組み、冒頭には1854年版の小屋の版画を置きます。数字は役目によって変わります。本文の *March, 1845* や *$13.34* はオールドスタイル数字で、小文字のように上下に伸びるので、日付が行から浮きません。見出しはスモールキャップで、その年号は大文字と同じ高さです。家計簿ではどの数字も同じ幅なので、板、木摺、釘など13行のセントが合計まで縦にそろいます。

## 作り方

### 1 · テキストのスタイルごとに数字を一種類

この手順のコードは上の手短な答えです。`figureStyle` はスタイルのフォントに OpenType の数字を指定します（[数字のスタイル](/ja/docs/configuration-fonts-colors-viewers#数字のスタイル)）。本文は何も指定しません。Alegreya の標準の数字がすでにプロポーショナルなオールドスタイル数字だからです。1 の幅は342ユニット、0 は533です。第2レベルの見出しは Alegreya SC に `'lining'`、つまり `lnum` の数字を指定し、まわりの大文字と同じ高さにします。表のスタイルは `'tabular'`、フォントの `tnum` を指定します。数字はオールドスタイルの形のまま、すべて450ユニットの同じ幅になり、値段の列が上から下へまっすぐ読めます。`'lining-tabular'` にすると大文字の高さになります（「アレンジ」を参照）。

### 2 · 家計簿は5列の表

<Excerpt region="accounts" />

ソローの家計簿は TSV として `content.accounts.en.md` に、1つの勘定ごとに1ブロックで置いてあります。スペイン語版はコードに手を触れずに品目を訳し、小数点をコンマに替えます。各行は品目、ドル記号、金額、分数、書き込みの5つです。2分の1と4分の3は別の列にします。½ は713ユニット、¾ は689ユニットで、タビュラー数字より広く、Alegreya にはほかの金額を埋める数字幅のスペースがありません。合計はヘッダーのセルで作るので、`groupRules` がその上に細い罫を引きます。ソローの印刷所が *In all* の前に引いた線と同じです。ドル記号は `\$` と書きます。単独の `$` は本文と同じくセルでも数式を始めるからです。リソースの種類 `account` は番号もキャプションの接頭辞も持たず、既定の配置は `'here'` なので、各勘定はそれを紹介するソローの文のすぐ後に置かれます。

### 3 · 冒頭のデザインは自分の数字を指定する

<Excerpt region="opener" />

デザインのテキストは自分のファミリーを持つので、本文の数字の指定は届きません。*Concord, 1845–1847* は Alegreya SC で、見出しと同じく自分で `'lining'` を指定します。挿絵は1854年版の扉の版画で、切り抜いて白地に黒へ整えました。小見出し、表題、年号は版面の幅をとり、その下で中央にそろえます。

### 4 · 奇数ページの柱に節の名前

<Excerpt region="running-heads" />

偶数ページの柱は書名、奇数ページは現在の節 `{firstMark.h2}` なので、3ページには *The Bean-Field, 1845* と出ます。ノンブルは Alegreya で、オールドスタイル数字のままです。

## アレンジ

### 家計簿をライニング数字で組む

現代の本の帳簿や価格表は、数字を大文字の高さに組むことがよくあります。

```diff
-  figureStyle: 'tabular', bodyFontFamily: TEXT, bodyFontSize: pt(9.8), bodyColor: col('ink'),
+  figureStyle: 'lining-tabular', bodyFontFamily: TEXT, bodyFontSize: pt(9.8), bodyColor: col('ink'),
```

### ノンブルをライニング数字で組む

ライニング数字のノンブルは、大文字で組んだ柱に合います。

```diff
-const folio = { fontFamily: TEXT, fontSize: pt(9.5), fontWeight: 400, letterSpacing: pt(0),
+const folio = { fontFamily: TEXT, fontSize: pt(9.5), fontWeight: 400, letterSpacing: pt(0),
+  figureStyle: 'lining',
```

## よくあるつまずき

- Fontsource が配る latin のファイルは `onum` を省いていることがよくあります。Lora、EB Garamond、Source Serif 4、Crimson Pro、Newsreader、Literata は `pnum` と `tnum` しか持っていません。これらのファイルでは `figureStyle: 'oldstyle'` を指定しても何も変わらず、本文はライニング数字のままです。Alegreya、Gelasio、Cormorant Garamond のように標準の数字がオールドスタイルで、見出し用に `lnum` を持つ書体を選ぶか、フォントメーカーの完全なファイルを読み込んでください。
- Markdown や表のセルの `$` は行内の数式を始めます。本文では `\$14.72½`、セルでは `\$` と書きます。
