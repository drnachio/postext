## できあがり

沿岸地域の雑誌の3ページです。河口の町の仕事を取り上げた特集で、扉には裁ち落としの写真を1枚、段の中には写真を5枚置きます。CodePenのサンプルは同じテキストから特集を2回組みます。1回目は写真がファイルの形のままで、<PageRef page={2}>2ページ</PageRef>では両方の段がグリッドの1行手前で終わります。左の段は最後の段落の下で、右の段は地に置いた写真の上で終わります。2回目は写真ごとに、常に見せる必要のある部分を指定し、エンジンはその外側を切り落とします。<PageRef page={5}>同じページ</PageRef>では、貝を採る人と網を繕う人の写真がそれぞれ1行ぶん高くなり、両方の段がグリッドの最終行で終わります。どのトリミングも、人が選ぶ必要はありませんでした。

## 作り方

### 1 · 残すべき部分だけを指定する

コードは前の[手短な答え](#手短な答え)にあります。セーフエリアは、画像の左上の角から測る4つの割合です。エンジンは写真を、ファイル全体からその長方形までの間の任意の形で、段の幅いっぱいに表示できます。左右を切れば縦長に、天地を切れば横長になります。セーフエリアの外側は両側の余白に比例して切り落とされるので、岸壁で中央より右に立つRosaは、左右を切っても中央より右に残ります。

### 2 · 段末そろえが余りを吸収するのは写真だけにする

同じコードで段末そろえも設定しています。通常の調整手段は白を足すものです。見出しの上に1行加える、写真の下にアキを入れる、段落を1行長く組む、といった方法です。ここではそれらをオフにしているので、セーフエリアのない組版では短い段がそのまま見えます。セーフエリアのある写真は、オフにしていなくても、それらの調整手段より先に試されます。写真が高くなってもテキストに穴は残らないからです。

### 3 · セーフエリアはリソースに属する

<Excerpt region="photos" />

`safeArea`はリソースの上で、ファイル、キャプション、配置と並んで指定します。そのため写真はどこにフロートしても、それを使うどの文書でもセーフエリアを保ちます。サンプルはこれを渡すか省くかだけで、2つの組版の違いはそれだけです。扉の河口の写真は見出しスタイルが描くもので、フロートではないので、セーフエリアは要りません。

### 4 · 両方を組んで比べる

<Excerpt region="builds" />

2つの文書は1つの設定と1つのMarkdown文字列から作ります。地まで埋めるのは、次のページへ続くページだけです。<PageRef page={3}>3ページ</PageRef>は特集の最後のページで、最後のページでは段の終わりの高さを互いにそろえるだけです。ここではすでにそろっているので、そのページで高くなる写真はありません。「PDF」ボタンは表示している方の組版を書き出し、PDFでも各写真は同じように枠でクリップされます。

## アレンジ

### インラインの写真をテキストのそばに残す

`position: 'here'`で組んだセーフエリアのある写真は、段に残った余地に対して少し高すぎるとき、次の段へ移る代わりに天地を切り落とされます。

```diff
-const PLACEMENT = { pulpeira: { position: 'here' } }; // the rest float to the first free slot
+const PLACEMENT = { pulpeira: { position: 'here' }, faro: { position: 'here' } };
```

### 段末そろえにほかの調整手段を戻す

初期設定でも写真が先に試され、写真のセーフエリアで吸収しきれない分を見出しとフロートが引き受けます。

```diff
-const balancing = { enabled: true, maxLinesPerHeading: 0, stretchAfterLists: false,
-  stretchAfterFloats: false, looseParagraphs: false };
+const balancing = { enabled: true };
```

## よくあるつまずき

- 画像全体を覆うセーフエリアや、辺が画像の2%未満のセーフエリアは無視されます。写真はセーフエリアがないときと同じく、全体が表示されます。
- 高くなるのは段のフロートとインラインの写真だけです。2段にまたがってフロートする写真は形を保ちます。高くすると、その下にあるすべての段を一度に押し下げてしまうからです。
