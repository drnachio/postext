# 3けたのたし算とひき算 {kicker="さんすう　12" pic="tanuki"}

:::paragraphs{style="namae"}
名前:chip[　]{style="sen"}　　:chip[　]{style="waku"}点
:::

:::exercise{type=arithmetic}
ひっ算でしましょう。（1つ5点）

- 345 + 278
- 902 - 456
- 124 × 3
- 864 ÷ 4
:::

:::exercise
□にあてはまる数を書きましょう。（1つ5点）

:::columns{count=2}
25 + 37 = [[62]]

90 − 46 = [[44]]

8 × 7 = [[56]]

400 + 600 = [[1000]]

1000 − 1 = [[999]]

63 ÷ 9 = [[7]]
:::
:::

:::exercise{columns=3}
正しいものをえらんで、記号で答えましょう。（1つ5点）

1. 1000は、100を何こ集めた数ですか。
   - [ ] 1こ
   - [x] 10こ
   - [ ] 100こ
2. 500円玉を2まい出すと、何円ですか。
   - [ ] 700円
   - [ ] 520円
   - [x] 1000円
:::

:::exercise{type=truefalse}
正しいものには○、まちがっているものには×を書きましょう。（1つ5点）

- [x] 345 + 278 の答えは、600より大きい。
- [ ] 902 − 456 の答えは、500より大きい。
- [x] 124 × 3 と 3 × 124 は、同じ答えになる。
:::

:::exercise{type=open area=lines lines=2}
354円のノートと278円のペンを買いました。あわせて何円ですか。（式5点・答え5点）

:::solution
式　354 + 278 = 632　　答え　632円
:::
:::

:::exercise{type=open area=lines lines=2}
456ページの本を、きのうまでに278ページ読みました。のこりは何ページですか。（式5点・答え5点）

:::solution
式　456 − 278 = 178　　答え　178ページ
:::
:::

# 春のことば {kicker="こくご　12" pic="kitsune"}

:::paragraphs{style="namae"}
名前:chip[　]{style="sen"}　　:chip[　]{style="waku"}点
:::

:::exercise{style=kaki}
□に漢字を書きましょう。（1つ5点）

:::columns{count=3}
[[{春|はる}]]

[[{花|はな}]]

[[{風|かぜ}]]

[[{空|そら}]]

[[{朝|あさ}]]

[[{昼|ひる}]]
:::
:::

:::exercise
線を引いた漢字の読みがなを書きましょう。（1つ5点）

1. :sideline[春風]がふく。（[[はるかぜ]]）
2. :sideline[朝日]がのぼる。（[[あさひ]]）
3. 花の:sideline[色]がきれいだ。（[[いろ]]）
:::

:::exercise
文に合うことばを、○でかこみましょう。（1つ5点）

1. 春の風がふいて、さくらの花が [[(ちりました) | のぼりました]]。
2. 朝、つばめが南の国から [[(やってきた) | ねむっていた]]。
:::

:::exercise{columns=1}
ことばのいみに合うものを、えらびましょう。（10点）

「うららか」とは、どんなようすですか。

- [ ] 雨がはげしくふるようす
- [x] 空が晴れて、日の光がやわらかいようす
- [ ] 風がつめたくふくようす
:::
