## 成品一览

虚构的音乐小志《Pink Noise》第7期：八页A5，骑马钉装订，在一台有两个滚筒的机器上印刷。一个滚筒印黑色，另一个印荧光粉红，除此之外没有任何东西印到纸上。粉红用于封面标题、访谈开篇页的色带、问题、引文和封底；它的30 %网点色调填满演出预告的框。三张照片是灰度原图，印成双色调：暗部是黑色，中间调是粉红。Folio把这本小志摊开放在一张深色桌子上，粉红在纸面上格外醒目。

## 做法

### 1 · 两块印版，粉红是荧光色

代码就是上面的[简短回答](#简短回答)。`print.plates`列出这项活儿要印的印版，`Black`和`PANTONE 806 C`，PDF里就只有这两个分色版，别无其他（[双色印刷](/zh/docs/configuration-pdf-output#专色)）。粉红是专色；它的工艺写在油墨表里，就像写在给印刷厂的订单上一样，这让它成为荧光油墨：它有自己的印版，Folio把它照得比纸还亮（[工艺](/zh/docs/special-inks-die-cuts#工艺)）。`images`把照片放到两块印版上，`CURVES`分别决定每一块的形状：黑色只在暗部，粉红在中间调，到暗部逐渐减弱，这样粉红永远不会把黑色弄脏。

### 2 · 屏幕上也显示双色调

<Excerpt region="duotone" />

画布和Folio按图片文件本来的样子绘制，所以灰度照片在那里会显示为灰色，尽管它印出来是粉红和黑色。本食谱为屏幕另外登记一张图片：同样的灰度经过同样的`CURVES`读取，黑色以正片叠底的方式叠在粉红上，就像油墨在纸上叠在一起那样。PDF仍从`imageBytes`拿到灰度原图，由它自己分色。

### 3 · 黑色叠在粉红上

<Excerpt region="cover" />

黑色只占K版，设成带`overprint: true`的CMYK颜色。黑色文字或封面的黑色色带碰到粉红的地方，黑色叠印在上面，而不是把粉红镂空，所以即使某一张纸套准稍有偏差，也不会露出白边。粉红标题则在黑色上镂空，深色色带上的文字本该如此。

### 4 · 深色桌面上的Folio

<Excerpt region="folio" />

荧光油墨周围要有一点暗，才看得出是荧光。小志摊开在访谈那一页，放在一块平整的深色台面上，照着阴天平淡的光，粉红色带和照片里的粉红在白纸上格外醒目。

## 变化

### 照片只用黑色印

图片只用一块印版时，照片在黑版上印成普通的灰度，粉红留给文字和框。

```diff
-  plates: { inks: ['Black', 'PANTONE 806 C'], images: ['Black', 'PANTONE 806 C'],
+  plates: { inks: ['Black', 'PANTONE 806 C'], images: ['Black'],
```

### 换成荧光黄

改掉油墨和它的屏幕颜色；印版、工艺和曲线都随名称而变。

```diff
-const PINK = { name: 'PANTONE 806 C', cmyk: { c: 0, m: 77, y: 0, k: 0 } };
+const PINK = { name: 'PANTONE 803 C', cmyk: { c: 0, m: 0, y: 92, k: 0 } };
```

同样在`CURVES`、`PRINT`和调色板的hex里把`PANTONE 806 C`改名。

## 常见问题

- 两块印版都不印的颜色会被投影到这两种油墨上。样式里遗留的一个四色蓝会印成发黑的粉红；发送文件前先看印前检查给出的`offPlateColor`结果。
- 荧光油墨没有忠实的CMYK替代色。打样或RGB的PDF显示的是hex，比纸上的油墨暗淡。
