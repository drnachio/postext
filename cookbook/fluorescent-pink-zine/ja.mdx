## できあがり

架空の音楽ジン『Pink Noise』の第7号です。A5で8ページの中綴じで、ドラムが2つある印刷機で刷ります。片方は黒、もう片方は蛍光ピンクを刷り、紙にはそれ以外何も載りません。ピンクは表紙のタイトル、インタビューの扉の帯、質問、プルクオート、裏表紙に使い、30 %の網点がライブ情報の囲みを埋めます。3枚の写真はグレーの原稿で、シャドウが黒、中間調がピンクのダブルトーンで刷られます。Folioはジンを暗いテーブルの上に開いて置き、ピンクが紙から浮き立ちます。

## 作り方

### 1 · 版は2枚、ピンクは蛍光

コードは上の[手短な答え](#手短な答え)にあります。`print.plates`はこの仕事で刷る版、`Black`と`PANTONE 806 C`を指定し、PDFにはその2つの分版だけができます（[2色刷り](/ja/docs/configuration-pdf-output#特色)）。ピンクは特色です。その加工は、印刷所への発注書に書くのと同じようにインキ表に書き、これで蛍光インキになります。専用の版を持ち、Folioでは紙より明るく照らされます（[加工](/ja/docs/special-inks-die-cuts#加工)）。`images`で写真を両方の版に載せ、`CURVES`でそれぞれの形を決めます。黒はシャドウだけ、ピンクは中間調に置いて暗部では弱め、ピンクが黒を濁らせないようにします。

### 2 · 画面でもダブルトーンを見せる

<Excerpt region="duotone" />

キャンバスとFolioは画像をファイルのとおりに描くので、グレーの写真は、刷り上がりがピンクと黒でも、画面ではグレーに見えてしまいます。このレシピは画面用に2枚目の画像を登録します。同じグレーを同じ`CURVES`で読み、紙の上でインキが重なるように黒をピンクに乗算したものです。PDFには引き続き`imageBytes`からグレーの原稿が渡り、PDFの側で分版します。

### 3 · ピンクに重ねる黒

<Excerpt region="cover" />

黒はK版だけを使うCMYKの色として、`overprint: true`付きで定義します。黒の文字や表紙の黒い帯がピンクと重なるところでは、ピンクをノックアウトせずにその上に刷られるので、少し見当がずれた紙でも白いすき間が出ません。ピンクのタイトルは逆に黒をノックアウトします。暗い帯に載る文字はそうあるべきです。

### 4 · 暗いテーブルの上のFolio

<Excerpt region="folio" />

蛍光インキは、まわりに少し暗さがあって初めて蛍光らしく見えます。ジンはインタビューのページで開いたまま無地の暗い面に置かれ、曇り空のフラットな光を受けて、ピンクの帯と写真の中のピンクが白い紙から浮き立ちます。

## アレンジ

### 写真を黒だけで刷る

画像用の版を1枚にすると、写真は黒の普通のグレースケールで刷られ、ピンクは文字と囲みのために残ります。

```diff
-  plates: { inks: ['Black', 'PANTONE 806 C'], images: ['Black', 'PANTONE 806 C'],
+  plates: { inks: ['Black', 'PANTONE 806 C'], images: ['Black'],
```

### 蛍光イエローに替える

インキとその画面用の色を変えます。版、加工、カーブは名前に従います。

```diff
-const PINK = { name: 'PANTONE 806 C', cmyk: { c: 0, m: 77, y: 0, k: 0 } };
+const PINK = { name: 'PANTONE 803 C', cmyk: { c: 0, m: 0, y: 92, k: 0 } };
```

`CURVES`、`PRINT`、パレットの`hex`でも同じように`PANTONE 806 C`の名前を変えてください。

## よくあるつまずき

- どちらの版も刷らない色は、2つのインキに投影されます。スタイルに残ったプロセスの青は黒ずんだピンクになります。ファイルを送る前に、プリフライトの`offPlateColor`の指摘を読んでください。
- 蛍光インキには忠実なCMYKの代替色がありません。校正刷りやRGBのPDFは`hex`の色を見せますが、紙の上のインキよりくすんで見えます。
