## 成品一览

一本给九到十一岁孩子的暑假作业：一个封面、三个关于大海的谜题和一页答案。第2到第5页都在一块底边呈波浪形的色块下开始（依次为海蓝、薄荷绿、珊瑚色，答案页为黄色），标题用46 pt的Lilita One。代码由一行行字母生成填字游戏和找词游戏的表格，并给每个表格一套自己的表格样式：填字游戏用带格线的方格，找词游戏用淡色方砖，白色砖缝，四角为圆角。填字游戏的黑格和找词游戏中已找到的词都是单元格填色，线索编号是角上的上标。迷宫是由种子绘制的SVG。最后一页用同一份数据并排印出三个答案，下面是一个讲红海龟如何筑巢的框。

## 做法

### 1 · 一个表格样式，三种外观

代码见上文的[简短回答](#简短回答)。`tableStyle`为所有网格设定Chivo Mono。`tableStyles`中的每个命名样式各自设定字号、内边距和格线，表格用`table.styleId`选用其中一个。一列的宽度是它在表格宽度中所占的份额，而一行的高度是其中文字行的总高再加上内边距，所以内边距决定了每个方格的高度。找词游戏沿用填字游戏9.41 mm的方格，里面是一行15 pt的大写字母，`pad()`算出这一行上下各剩2.9 pt。它的格线宽2.4 pt，用纸张的颜色，把淡色底切成一块块方砖；`borderRadius`把边框四角做成4 mm圆角，并把填色裁切到圆角内。在答案页上，`key()`把九个或十二个方格排进54 mm：填字游戏是6 mm方格配8 pt字母，找词游戏是4.5 mm方格配6 pt字母。迷宫答案画成54 mm见方，所以三个答案一样高，它们的题注共用一条距上边缘106.4 mm的基线。

### 2 · 九个方格，十五行

<Excerpt region="crossword" />

一个白格在1 pt内边距内容纳两行8.9 pt的Chivo Mono（线索编号和一个空行），合计26.7 pt，即9.41 mm，是表格宽度的九分之一。九个方格高84.7 mm，等于十五行16 pt正文的高度，线索框从下一行的基线网格开始。只要有横向或纵向的单词从某个方格开始，这个方格就按阅读顺序得到一个编号。编号是5.2 pt的粗体上标（8.9 pt的58 %），上移3 pt（8.9 pt的三分之一），落在方格的上角。空行是一个单词连接符（U+2060）。真正留空的一行不会给单元格增加高度，网格就只有45.5 mm高。黑格是一个带有自己`background`的空单元格，关联到`ink`。

### 3 · 由代码在网格中找词

<Excerpt region="search" />

网格是单独内容文件中的十二行大写字母，排在待找单词列表之后。`locate()`在八个方向上查找每个单词，匹配不是恰好一处就抛出异常，所以网格或列表中的错字会在印出一个谁也找不到的单词之前中止构建。`setCellBackground`返回一个新的表格模型，多填一个方格。填色关联到调色板中的一项，覆盖样式的方砖：第3页上UMBRELLA用珊瑚色，第5页上全部十个单词用薄荷绿。第一个变化用表格样式的`bodyAlternateBackground`给隔行加底色，单元格自己的填色会盖住这层底色。方阵上方的词库是两行居中的标签：UMBRELLA的标签与它的方格一样填成珊瑚色，其余九个是白底海军蓝边框。

### 4 · 一个章首页设计，四种颜色

<Excerpt region="openers" />

第2到第5页共用一个设计。色块从上边缘向下40 mm，末端是一道用纸张颜色画的波浪形底边；眉题、标题和白色胶囊里的主题取自标题行及其属性。色块和页码圆片都关联到调色板中的`band`，每页的标题样式给`band`一个自己的值，所以`# Word Search {style="sopa"}`让第3页上的两者都变成薄荷绿。虽然这本书只有一栏，一级标题仍设了`span: 'page'`：留在栏内的设计会在栏底被裁掉，那样封面的图画就会在离下边缘16 mm处被切断。色块的框计入章首页预留的高度，所以正文从下一条网格线开始，距上边缘44.2 mm，在波浪下方4 mm。

### 5 · 答案来自同一份数据

<Excerpt region="answers" />

答案页用`solved`调用`crossword()`，用全部十个单词调用`wordSearch()`，所用的内容文件与谜题相同，所以改动一个网格，它的答案也随之改变。谜题和插图使用Plain类型，它的`captionPrefix`为空，对没有题注文字的资源不印题注。答案使用Solution类型，按阅读顺序编号为1到3，与眉题Puzzle 1到Puzzle 3对应。它们放在正文中的`:::columns{count=3 breaks="2,3" gap=6mm}`组里，外面不套框（postext 1.25）：`breaks`在第二个和第三个答案处另起一栏，`gap`让各栏相隔6 mm；每个答案宽54 mm，所在栏宽55.3 mm。Did you know?框里也有一个这样的组，以`breaks="2"`把巢穴剖面图排在它的段落旁边。

## 变化

### 给找词方阵加隔行底色

每隔一行用深一点的黄色，能帮小读者顺着一行字母看下去。单元格自己的填色会盖住隔行底色，所以UMBRELLA仍是珊瑚色；答案网格用的是另一个样式，不加隔行底色。

```diff
     bodyBackgroundEnabled: true, bodyBackground: col('tint'), // tiles with white joints
+    bodyAlternateBackgroundEnabled: true, // 每隔一行，比方砖深一个色阶
+    bodyAlternateBackground: { hex: '#ffdd80', model: 'hex' },
     borderColor: col('paper'), borderWidth: pt(2.4), borderRadius: mm(4) },
```

### 画一个更难的迷宫

二十一乘十一个方格，每格8.4 mm，放得进同样的宽度；第5页的答案也按新迷宫绘制。

```diff
-const theMaze = maze(17, 9, 2027);
+const theMaze = maze(21, 11, 2027);
```

## 常见问题

- 框里的线索编号是在内容文件中手写的，而网格中的编号是计算出来的。改动网格后，请对照检查线索，因为代码不会比较两者。
- 标题样式的调色板会给设计元素、文字以及表格的格线和填色重新着色，但不会改变SVG内部的颜色，所以每个色块底部的波浪用纸张颜色绘制，一幅图就能用于全部四个色块。
