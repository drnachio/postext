## 成品一览

《Cartografías imaginarias》是一个虚构的展览，展出想象之地的地图。这里做的是它交付印刷厂的展厅说明单，本页两种语言版本上都是西班牙文。每个170 × 227 mm的页面放在一张大22 mm的纸上，多出的部分承载出血和裁切线。封面上，一条橙色路线穿过层层渐变绿色的群岛，越过裁切边伸进出血区。内页中，四个展厅用齐左的Karla排，各在一个路标式眉题下开头，一个橙色标签把页码带到书口外侧；封底在一条地形色带上方放一张平面图。示例导出两份文件：印刷用PDF，采用CMYK，带字体、书签和页面标签；另一份是灰度校样。印刷用PDF中的地图和平面图取自手工选定油墨的印刷母版；文字、标签和路标圆环则按普通公式转换。

## 做法

### 1 · 按印版挑选屏幕颜色

<Excerpt region="palette" />

设置`colorSpace: 'cmyk'`后，postext-pdf用一个简单公式转换每个十六进制颜色，不用ICC特性文件：黑版等于1减去RGB三个通道中的最大值，青、品红、黄各由自己的通道和这个黑版算出。因此中性灰只印在黑版上（`#161616`变成K91），一个通道满值的颜色则完全不用黑版：橙色`#ff6626`在标签、圆环和路线上变成C0 M60 Y85 K0。只要绿色是最高的通道，品红就是0，所以森林绿变成C82 M0 Y25 K76，校样上是一种石油蓝绿色。正因如此，地图和平面图取自印刷母版（第5步），这种三色叠印只留给眉题、图引用和题注标签中那些小号粗体的森林绿文字。

### 2 · 经得起裁切刀的书口标签

<Excerpt region="tab" />

标签的框挂在出血框上，比成品标签宽`BLEED`，所以即使裁切落在成品线外1 mm，切口处仍有橙色；页码挂在页面框，也就是成品线上，在剩下的10 mm内居中。`parity`决定每个元素出现在哪些页上，`edge`随之改变，好让元素抵达书口；`pages: 'body'`让标签和书眉（取自frontmatter的`{title}`和`{subtitle}`）不出现在封面和封底上。封面和封底都算章首页，因为它们各以一个通栏或另起一页的标题开头。任何页眉或页脚元素都能这样重复，所以一个带`parity`和`pages`的`image`可以在每页放一个水印或装饰图。这些槽位画在文字上方，文字下方的底色要放在`page.backgroundColor`里。

### 3 · 图稿到出血，文字在成品线内

<Excerpt region="covers" />

`cutLines`在页面每边加上出血、标记偏移和5 mm长的裁切线，这里合计11 mm。由于简短回答把偏移设得与出血相等，裁切线从出血边开始向外延伸，印在黑版上。一个锚定在出血框、设了`width: 'fill'`的图片元素取该框的宽度，并保持自身比例：封面地图按176 × 233 mm绘制，即成品尺寸每边加3 mm，所以它恰好到达裁切线起点所在的出血边，而文字挂在版心上，远在成品线以内。封底是一个标题样式，它的页脚取代文档的页脚：同一个生成器画出的色带锚定在出血框底部，下页边距让正文止于色带上方8 mm。

### 4 · 变成书签的标题

<Excerpt region="levels" />

`renderToPdf`根据标题生成书签，所以每个展厅都是一个一级标题，接排而不分页；`numberingTemplate`给眉题提供`{number}`，也给书签提供前缀。PDF中依次列出封面、从“Sala 1 Una isla en ninguna parte”到“Sala 4 La isla del tesoro”的四个展厅，以及参观信息。设计过的标题会隐藏自身文字，但仍保留它供书签和标签结构使用；如果不设`fontFamily`，这段隐藏文字会用Open Sans 700排，页面要为此加载这个字体，PDF也要为这几段文字单独嵌入它。页面标签遵循`page.pageNumbering`，这里保持默认，即从1开始的阿拉伯数字，所以PDF阅读器中的第3页就是书口标签上印着3的那一页。

### 5 · 用准确油墨制作印刷母版

<Excerpt region="master" />

每幅图只以路径定义一次。art区域把它们转成Canvas绘制用的SVG，这个区域则把同样的路径写进一个单页CMYK PDF，所选的叠印让校样与屏幕一致：海面是C100 M45 Y80 K55，而不是普通转换得到的C82 M0 Y25 K76。每个资源在`svg.pdfFileId`中指明自己的母版，简短回答里的`pressPdf()`把母版的字节以SVG的id交给`renderToPdf`，postext-pdf原样嵌入那一页，保持矢量，使用母版自己的油墨。平面图是一幅图，封面地图和封底色带是设计图片，三者都是如此。灰度校样则改用SVG，因为嵌入的母版从不转换，会保持彩色。

## 变化

### 印刷厂要求5 mm出血

图稿、标签和比例尺都以`BLEED`定尺寸，裁切线通过`markOffset`跟随它，所以要5 mm出血只需改这一处，每张纸随之变为200 × 257 mm。

```diff
-const BLEED = 3; // 图稿越过成品线的毫米数：封面、书口标签和封底色带都延伸到这里
+const BLEED = 5; // 图稿越过成品线的毫米数：封面、书口标签和封底色带都延伸到这里
```

### 用SVG印图稿

没有`pdfFileId`时，印刷文件用各自的SVG绘制每张图，仍是矢量，但走普通转换，海面印成C82 M0 Y25 K76，一种石油蓝绿色。

```diff
-  updatedAt: 0, ...extra, svg: { fileId: `${id}.svg`, pdfFileId: `${id}.pdf`,
+  updatedAt: 0, ...extra, svg: { fileId: `${id}.svg`,
```

## 常见问题

- postext-pdf 1.4.1把每页写成单一的MediaBox，即整张192 × 249 mm的纸，没有TrimBox或BleedBox，裁切线只印在黑版上。请把成品尺寸170 × 227 mm告诉印刷厂；如果对方要求PDF/X，就在印前工具里补上这些框。
- 在1.4.1中，裁切线从成品线外`markOffset`处开始，而不是从出血边外开始，所以出血比默认的3 mm偏移宽时，裁切线会压在图稿上。让偏移等于出血，就像这里的`cutLines`那样。
- `renderToPdf` 1.4.1不读取`config.pdfGeneration`。`pressPdf()`把色彩空间作为选项传入，书签和标签结构（tagging）默认开启。
- 生成之后，每个按钮会变成一个“Open the PDF ↗”链接和一个下载链接，只有下载链接带文件名。
