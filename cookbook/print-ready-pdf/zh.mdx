## 成品一览

《Cartografías imaginarias》是一个虚构的展览，展出想象之地的地图。这里做的是它交付印刷厂的展厅说明单，本页两种语言版本上都是西班牙文。每个170 × 227 mm的页面放在一张大22 mm的纸上，多出的部分承载出血和裁切线。封面上，一条橙色路线穿过层层渐变绿色的群岛，越过裁切边伸进出血区。内页中，四个展厅用齐左的Karla排，各在一个路标式眉题下开头，一个橙色标签把页码带到书口外侧；封底在一条地形色带上方放一张平面图。示例导出两份文件：印刷文件是按FOGRA51分色的PDF/X-4（FOGRA51即150 g铜版纸所用的PSO Coated v3印刷条件），带字体、书签和页面标签；另一份是灰度校样。提供这两份文件之前，示例先对版面做印前检查。印刷文件中的地图和平面图取自手工选定油墨的印刷母版，文字、标签和路标圆环则通过一套用CMYK指定的调色板，使用同样的油墨。

## 做法

### 1 · 按印版挑选屏幕颜色

<Excerpt region="palette" />

配置中的`print: { standard: 'pdfx4', outputProfile: 'fogra51' }`用postext自带的FOGRA51特性文件为每一种颜色分色。中性灰只印在黑版上，K值按明度匹配选取：`#161616`变成K95，书眉的`#666666`变成K66，100% K的文字叠印。按特性文件，森林绿会印成C90 M43 Y71 K62，橙色会印成C0 M70 Y90 K0，与母版中的路线（第5步）略有色差，所以这两种颜色连同鼠尾草绿和纸色都用CMYK指定：`ColorValue.cmyk`保存油墨配比，十六进制值留给屏幕，凡是链接到调色板的地方都按写下的配比印刷。纸色是C0 M0 Y0 K0：在森林绿上反白的文字不用任何油墨，所以没有哪块印版能让它错位。

### 2 · 经得起裁切刀的书口标签

<Excerpt region="tab" />

标签的框挂在出血框上，比成品标签宽`BLEED`，所以即使裁切落在成品线外1 mm，切口处仍有橙色；页码挂在页面框，也就是成品线上，在剩下的10 mm内居中。`parity`决定每个元素出现在哪些页上，`edge`随之改变，好让元素抵达书口；`pages: 'body'`让标签和书眉（取自frontmatter的`{title}`和`{subtitle}`）不出现在封面和封底上。封面和封底都算章首页，因为它们各以一个通栏或另起一页的标题开头。任何页眉或页脚元素都能这样重复，所以一个带`parity`和`pages`的`image`可以在每页放一个水印或装饰图。这些槽位画在文字上方，文字下方的底色要放在`page.backgroundColor`里。

### 3 · 图稿到出血，文字在成品线内

<Excerpt region="covers" />

`cutLines`在页面每边加上出血、标记偏移和5 mm长的裁切线，这里合计11 mm。偏移默认是3 mm，与这里的出血相等，所以裁切线从出血边开始向外延伸；出血更宽时，裁切线仍从出血边开始，绝不进入出血区。一个锚定在出血框、设了`width: 'fill'`的图片元素取该框的宽度，并保持自身比例：封面地图按176 × 233 mm绘制，即成品尺寸每边加3 mm，所以它恰好到达裁切线起点所在的出血边，而文字挂在版心上，远在成品线以内。封底是一个标题样式，它的页脚取代文档的页脚：同一个生成器画出的色带锚定在出血框底部，下页边距让正文止于色带上方8 mm。

### 4 · 变成书签的标题

<Excerpt region="levels" />

`renderToPdf`根据标题生成书签，所以每个展厅都是一个一级标题，接排而不分页；`numberingTemplate`给眉题提供`{number}`，也给书签提供前缀。PDF中依次列出封面、从“Sala 1 Una isla en ninguna parte”到“Sala 4 La isla del tesoro”的四个展厅，以及参观信息。设计过的标题会隐藏自身文字，但仍保留它供书签和标签结构使用；如果不设`fontFamily`，这段隐藏文字会用Open Sans 700排，页面要为此加载这个字体，PDF也要为这几段文字单独嵌入它。页面标签遵循`page.pageNumbering`，这里保持默认，即从1开始的阿拉伯数字，所以PDF阅读器中的第3页就是书口标签上印着3的那一页。

### 5 · 用准确油墨制作印刷母版

<Excerpt region="master" />

每幅图只以路径定义一次。art区域把它们转成Canvas绘制用的SVG，这个区域则把同样的路径写进一个单页CMYK PDF，所选的配比让校样与屏幕一致：海面是C100 M45 Y80 K55，也就是调色板中的森林绿。每个资源在`svg.pdfFileId`中指明自己的母版；`renderToPdf`按这个id索取文件，简短回答里的`pressPdf()`用母版的字节作答，postext-pdf原样嵌入那一页，保持矢量，使用母版自己的油墨。平面图是一幅图，封面地图和封底色带是设计图片，三者都是如此。灰度校样则改用SVG，因为嵌入的母版从不转换，会保持彩色。

## 变化

### 印刷厂要求5 mm出血

图稿、标签和比例尺都以`BLEED`定尺寸，裁切线从出血边开始，所以要5 mm出血只需改这一处，每张纸随之变为196 × 253 mm。

```diff
-const BLEED = 3; // 图稿越过成品线的毫米数：封面、书口标签和封底色带都延伸到这里
+const BLEED = 5; // 图稿越过成品线的毫米数：封面、书口标签和封底色带都延伸到这里
```

### 用SVG印图稿

没有`pdfFileId`时，印刷文件用各自的SVG绘制每张图，仍是矢量，同样经过特性文件：用CMYK指定的森林绿保持C100 M45 Y80 K55，岛屿的其他绿色则采用特性文件的分色，而不是手工选定的配比。

```diff
-  updatedAt: 0, ...extra, svg: { fileId: `${id}.svg`, pdfFileId: `${id}.pdf`,
+  updatedAt: 0, ...extra, svg: { fileId: `${id}.svg`,
```

## 常见问题

- PDF/X标准总是写出CMYK，不管`colorSpace`怎么设，所以灰度校样除了`colorSpace: 'grayscale'`，还要用`{ standard: 'none' }`覆盖`print`。
- 没有输出特性文件，PDF/X渲染就会失败。`renderToPdf`从`profileBaseUrl`（这里是postext.dev的`/icc/`）下载`fogra51.icc`；要自己提供，就把文件的字节作为`outputProfile`传入。
- 印前检查会标出小于9 pt、用一种以上油墨印刷的文字。森林绿的7.5 pt粗体标签印在铜版纸上，用四种油墨也能保持清晰，所以`print.preflight.smallTextSize`设为7 pt；6.3 pt的版权说明如果用鼠尾草绿，会在四色色带上用三种油墨印刷，所以改为反白成纸色。
- PDF/X文件不带链接注释，因为交付印刷的文件在出血框内不能有注释；书签保留。
- 生成之后，每个按钮会变成一个“Open the PDF ↗”链接和一个下载链接，只有下载链接带文件名。
