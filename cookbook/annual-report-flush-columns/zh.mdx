## 成品一览

Tidewell Community Energy的2025年度报告。这是一家虚构的合作社，拥有两台风机、一片太阳能电站和21个屋顶上的光伏板。共五页，开本210 × 280 mm。封面上，一年的风电和光伏发电量画成两条曲带，排在150 pt的“2025”下方。之后是理事长的信、运营报告和财务主管的账目，都用Brygada 1918排成两栏两端对齐的正文，基于50行的网格。排满的栏止于网格的最后一行，未排满的栏与相邻栏齐平收尾。一个含三个关键数据的框横跨理事长信所在的那一页，框上方的信文齐平截断；一则关于计量的说明浮动到第4页顶部。末页两栏在利润表之上止于同一行。一个调色板属性把运营部分的页面变成青绿色，财务页面变成砖红色。

## 做法

### 1 · 所有行都在网格上，由调节手段补齐空缺

代码见上面的[简短回答](#简短回答)。版心正好是50行13.4 pt的高度，下页边距（21.6 mm）由这个高度推算出来。小标题在上方占一条网格线，自身再占一条，所以短了的栏总是短整数行，而<Feature id="column-balancing">各栏齐底</Feature>补的也正是整行。在<PageRef page={3}>第3页</PageRef>，三行的冰雹那一段因为`avoidOrphans`整段移到第4页（`avoidOrphans`是Postext的规则名，防止段落最后一行单独留在栏首），右栏于是少了两行。`maxLinesPerHeading: 1`把其中一行给*The Saltings and the roofs*上方的空白，另一行留给下一项调节手段，它把这一行加在屋顶列表之后。取默认值4时，两行都会加到这个标题上方。

### 2 · 在横跨页面的框上方齐平截断正文

<Excerpt region="figures" />

`span="page"`的框把两栏页面切成若干横带。在<PageRef page={2}>第2页</PageRef>，理事长的信在框上方每栏排八行后停下，在框下两栏继续。框内，`:::columns{count=3 breaks="3,5"}`让第二、第三栏分别从第二、第三个数字开始（即该组的第三和第五个块），而不是在各栏最齐平的地方切开。`figure`段落样式把这些数字设为26 pt，其`boldColor`把它们印成黄色。

### 3 · 让框浮动到下一页顶部

<Excerpt region="aside" />

在Markdown中，关于计量的说明紧跟在第3页介绍Harrow Down的第一段之后；`placement="top"`把它移出文本流，放到下一页顶部。报告填满第3页的其余部分，<PageRef page={4}>第4页</PageRef>以横跨两栏的这个框开头。框下，站点表和环形图都是`position: 'top'`，各占一栏的顶部；由于框有3.5 mm的下内边距，它们比没有框时低一条网格线。

### 4 · 不用分隔页，给每个部分配上自己的颜色

<Excerpt region="palette" />

设了`parts: { page: false }`，`:::part{number="02" title="Operations" palette="band=#1c6e67"}`这样的围栏就不会另起一页。它为章首色条和页脚提供该部分的名称，并在下一部分开始之前的每一页替换`band`。色条、小标题、项目符号、题注标签和旁注框的线都取`band`，所以运营部分的页面印成青绿色，财务页面印成砖红色，理事长的信则保留基础的海蓝色（<Feature id="part-palettes">按篇配色</Feature>）。

### 5 · 从数据生成表格，并让末页齐平收尾

<Excerpt region="data" />

`statement()`把`DATA.accounts`逐行转成利润表。以`=`开头的标签会在浅色底上用粗体印出每年的累计和；成本在数据中是负数，所以*Operating surplus*直接由这个累计得出，不用手工输入任何合计。没有数字的标签，如*Income*或*Operating costs*，会变成一个横跨整表的斜体单元格，用`mergeCells`合并，它还会写入合并所需的占位单元格。在<PageRef page={5}>第5页</PageRef>，利润表浮动到页面底部，横跨页面，排在结束全文的财务主管报告之下。不做齐底的话，左栏会排12行，右栏9行；末页截断把两栏都定为11行，再由标题调节在*Cash and reserves*上方补上右栏还差的那一行。

## 变化

### 让标题占用全部空缺

第3页空出的两行这时都加到*The Saltings and the roofs*上方，列表之后不再加行。

```diff
-const balancing = { maxLinesPerHeading: 1 }; // 每个标题一行；多出的由下一项调节手段承担
+const balancing = {}; // 默认值：每个标题上方最多4行
```

### 关闭各栏齐底

这时第3页右栏少两行。第5页左栏排12行、右栏9行，利润表也低一行开始。

```diff
-const balancing = { maxLinesPerHeading: 1 }; // 每个标题一行；多出的由下一项调节手段承担
+const balancing = { enabled: false };
```

## 常见问题

- 末页两栏只差一行时保持原样，左栏多一行，和排字工的做法一样；末页截断只在相差两行或以上时才起作用。要让两栏一起结束，就把文稿加长或缩短一行。
- Postext 1.4.1会删掉表格单元格末尾的空白，不换行空格也不例外。为了让正数与括号里的成本对齐，pen在每个正数后加一个不换行空格和一个词连接符（word joiner，U+2060）。
