## できあがり

Tidewell Community Energyの2025年次報告書です。風車2基、太陽光発電所1か所、21棟の屋根のパネルをもつ架空の協同組合で、判型は210 × 280 mm、全5ページ。表紙では150 ptの「2025」の下に、その年の風力と太陽光の発電量が2本のリボンになって流れます。続いて理事長の手紙、事業報告、財務担当の決算報告が、Brygada 1918の両端そろえ2段組みで、50行のグリッドに組まれます。いっぱいの段はグリッドの最終行で終わり、短い段は隣の段と高さをそろえて終わります。理事長のページには3つの主要数値を収めた囲みがページ幅で入り、手紙はその上で高さをそろえて切られます。計量についての注記は4ページ目の頭にフロートします。最終ページでは、左右の段が損益計算書の上の同じ行で止まります。パレット属性によって、事業報告のページは青緑に、財務のページはれんが色になります。

## 作り方

### 1 · すべての行をグリッドに乗せ、すき間は調整手段に埋めさせる

コードは上の[手短な答え](#手短な答え)にあります。版面はちょうど13.4 ptの行が50行分の深さで、地の余白（21.6 mm）はその深さから導きます。小見出しは上に1行、自身に1行のグリッド線を使うので、段が短く終わるときの不足は行単位になり、<Feature id="column-balancing">段末そろえ</Feature>が足すのも行単位です。<PageRef page={3}>3ページ目</PageRef>では、3行のひょうの段落が`avoidOrphans`によってまるごと4ページ目へ送られます。これは段落の最終行が段の頭にひとりで立つのを防ぐ、Postextでの規則の名前です。その結果、右段は2行短く終わります。`maxLinesPerHeading: 1`はそのうち1行を*The Saltings and the roofs*の上の空きに回し、残る1行を次の調整手段に任せます。次の手段はそれを屋根のリストの後に加えます。初期値の4のままなら、2行とも見出しの上に入ります。

### 2 · ページ幅の囲みの上で本文の高さをそろえて切る

<Excerpt region="figures" />

`span="page"`を指定した囲みは、2段組みのページを上下の帯に分けます。<PageRef page={2}>2ページ目</PageRef>では、理事長の手紙が囲みの上で左右とも8行で止まり、囲みの下で再び2段に続きます。囲みの中では、`:::columns{count=3 breaks="3,5"}`が2番目と3番目の段を2番目と3番目の数値（グループの3番目と5番目のブロック）から始めます。段の高さがいちばんそろう位置で切るのではありません。`figure`段落スタイルがこれらの数値を26 ptにし、その`boldColor`が黄色で印刷します。

### 3 · 囲みを次のページの頭へフロートさせる

<Excerpt region="aside" />

Markdownの中で、計量についての注記はHarrow Downについての最初の段落の後、3ページ目にあります。`placement="top"`はこれを流れから取り出し、次のページの頭に置きます。報告は3ページ目の残りを埋め、<PageRef page={4}>4ページ目</PageRef>は2段にまたがる囲みで始まります。その下で、拠点の表とリンググラフ（どちらも`position: 'top'`）がそれぞれ1段の頭に入ります。囲みの下パディング3.5 mmがあるため、囲みがない場合より1グリッド線低い位置です。

### 4 · 区切りページなしで節ごとに色を変える

<Excerpt region="palette" />

`parts: { page: false }`のもとでは、`:::part{number="02" title="Operations" palette="band=#1c6e67"}`のようなフェンスはページを開きません。節の冒頭の帯と地側の柱に出す節の名前を決め、次の部まですべてのページで`band`を差し替えます。帯、小見出し、行頭記号、キャプションのラベル、傍らの囲みの罫がすべて`band`を使うので、事業報告のページは青緑、財務のページはれんが色で刷られ、理事長の手紙は基本の海の青のままです（<Feature id="part-palettes">部ごとの色</Feature>）。

### 5 · 表をデータから組み、最終ページの段末をそろえる

<Excerpt region="data" />

`statement()`は`DATA.accounts`を1行ずつ損益計算書に変えます。`=`で始まるラベルは各年度の累計を淡い地色の上に太字で印刷します。費用はデータ上で負の値なので、*Operating surplus*はその累計から出てきて、手で打ち込む合計はありません。数値のないラベル（*Income*や*Operating costs*）は、表の幅いっぱいのイタリックのセル1つになります。結合は`mergeCells`で行い、結合に必要なプレースホルダーのセルもこれが書き出します。<PageRef page={5}>5ページ目</PageRef>では、計算書が文書を締めくくる財務担当の報告の下、ページの地側にページ幅でフロートします。段末をそろえなければ、左段は12行、右段は9行になります。末尾の切りそろえで両段を11行にし、見出しの調整手段が右段にまだ足りない1行を*Cash and reserves*の上に加えます。

## アレンジ

### 見出しにすき間をすべて渡す

3ページ目の2行の空きは、2行とも*The Saltings and the roofs*の上に入り、リストの後には入りません。

```diff
-const balancing = { maxLinesPerHeading: 1 }; // one line per heading; the next lever takes more
+const balancing = {}; // the default: up to 4 lines above each heading
```

### 段末そろえを切る

3ページ目の右段は2行短く終わります。5ページ目では左段が12行、右段が9行になり、計算書は1行下から始まります。

```diff
-const balancing = { maxLinesPerHeading: 1 }; // one line per heading; the next lever takes more
+const balancing = { enabled: false };
```

## よくあるつまずき

- 最終ページの段の差が1行なら、組版職人が組むのと同じく、左段を1行長くしたまま手を加えません。末尾の切りそろえが働くのは差が2行以上のときだけです。両段を同時に終わらせたいなら、原稿を1行分長くするか短くしてください。
- Postext 1.4.1は表のセルの末尾の空白を、ノーブレークスペースも含めて削ります。正の数値を括弧付きの費用と縦にそろえるため、CodePenのサンプルでは正の数値の末尾にノーブレークスペースとワードジョイナー（U+2060）を置いています。
