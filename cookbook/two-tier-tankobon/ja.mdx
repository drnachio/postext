## できあがり

右綴じのA5判の全集から取った7ページです。芥川龍之介の『蜘蛛の糸』と『尾生の信』を、1段25字、横に21行の二段組に組みます。Noto Serif JPの9ptで、段のあいだに細い罫を引きます。各編は奇数ページ、つまり左ページで始まり、20ptの題が2段を通して縦に立ち、地の近くに作者名が入ります。ノンブルは211ページから続きます。節の一、二、三はその段の3行を取ります。作品が終わると、最終ページは本文が流れたままにします。これが成り行きです。214ページでは上段がページいっぱいに続き、下段には3行と日付だけが入ります。中国語の縦組みの段組みの新聞は<RecipeLink slug="vertical-newspaper-tiers">No. 084</RecipeLink>、横組みの2段に章題を通す例は<RecipeLink slug="five-chapter-openers">No. 017</RecipeLink>にあります。

## 作り方

### 1 · 90度回した2段は、上下の2段になる

コードは上の[手短な答え](#手短な答え)にあります。`writingMode: 'vertical-rl'`のページでは、`layoutType: 'double'`は2つの段を上下に重ねます。1段目は上段を右から埋め、次に下段に移り、段間は2段のあいだの帯になります（[縦組み](/ja/docs/configuration-page-layout#縦組み)）。[文字グリッド](/ja/docs/configuration-east-asian#文字グリッド)は1段の中の縦の字数を数えるので、各段は9ptの文字25字で、段間はちょうど2字分に丸められます。横に並ぶ15.75ptの21行は、148mmのページのうち116.7mmに収まります。段のあいだの罫はページを横切り、暖かいグレーの0.4ptです。

Postextの段末そろえは、作品の最終ページの2段を同じ行で終わらせようとします。中国語の新聞やヨーロッパの2段組みの本の多くは、章をそうして閉じます。日本語の段組みの本は本文を成り行きに任せ、上段がページいっぱいに続いてから下段が始まります。`balancing.trailing: false`がその選択です。縦組みの段は、`enabled: true`で段末そろえをオンにしない限り、そもそもそろえられません（[段末そろえ](/ja/docs/configuration-text#段末そろえ)）。

### 2 · 作品の題を2段に通す

<Excerpt region="opener" />

`span: 'page'`を付けた見出しレベルは、ページの高さ全体、つまり2つの段と段間にまたがって、流れの先頭、縦組みのページでは右端に組まれます。段はそのデザインが確保する7行のあとから始まります。このような見出しは必ずページを改め、`breakBefore.parity: 'odd'`がそれを左ページにします。『蜘蛛の糸』は偶数ページの214ページで終わるので、『尾生の信』は白ページを挟まずに215ページで始まります（[幅と詳細デザイン](/ja/docs/configuration-text#幅と詳細デザイン)）。デザインでは、`x`はページを下へ、`y`は版面の右端から横へ進みます。作者名は下段の地から3字上に置きます。

### 3 · 節番号はその段の3行取り

レベル2は`lineSpan: 3`と`indent: em(8)`で、一、二、三を段の8字下げの位置に3行幅の帯で組みます。青空文庫のテキストの指定（八字下げ、中見出し）どおりです。これで節番号のあとの本文も、隣の段の行に乗ったままになります（[レベルごとの上書き](/ja/docs/configuration-text#レベルごとの上書き)）。作品を締めくくる日付「（大正七年四月十六日）」は、`:::paragraphs{align=end endIndent=1}`で段の地から1字上げます（地から一字上げ）。青空文庫の変換スクリプトはこれを地にそろえる`aozora-end1`スタイルとして書き出し、フェンスの属性が1字上げを加えます。

### 4 · 巻名と作品名を小口に縦に入れる

<Excerpt region="furniture" />

`anchor.to: 'outer'`で柱を小口側の余白に置きます。右ページには巻名「芥川龍之介集」、左ページには作品名を入れ、`pages: 'body'`で作品の始まるページからはどちらも外します（[縦組みのテキスト要素](/ja/docs/configuration-page-layout#縦組みのテキスト要素)）。ノンブルは、多くの全集の刷り方にならい、余白を横切るようにアラビア数字で組みます。小口に沿って縦に組むと、3桁の数字が横倒しになってしまうからです。`pageNumbering.startAt: 211`で、巻のとおりにページを数えます。最初の作品の見出しスタイルは、`pages: 'opener'`で奥付を持ちます。スタイルのフッターはその節のすべてのページに効くからです。

## アレンジ

### 最終ページの段末をそろえる

段末そろえをオンにすると、各作品の最終ページは段末がそろいます。214ページは上段10行、下段11行で終わります。中国語やヨーロッパの段組みの本が使う終わり方です。字詰めのグリッドでは段末そろえが足すのは行単位だけなので、どの字も自分のマスから動きません。

```diff
-const balancing = { trailing: false };
+const balancing = { enabled: true }; // the closing band is cut level
```

### 各作品を次のページから始める

`parity: 'any'`にすると、作品はすぐ次のページから始まります。雑誌や、ごく短い作品を集めたアンソロジーがこうしています。

```diff
-const work = { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'odd' } };
+const work = { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'any' } };
```

### 作品を1段で組む

長編小説や文庫は本文を段間なしの1段で組みます。<RecipeLink slug="bunko-novel-furigana">No. 117</RecipeLink>はそのように文庫を組んでいます。
