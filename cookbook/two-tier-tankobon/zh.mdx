## 成品一览

一卷全集的七页，A5页面，右侧装订：芥川龍之介的《蜘蛛の糸》和《尾生の信》，排成上下两栏（二段組），每栏竖向25字，横向21行，用9 pt的Noto Serif JP，两栏之间一条细线。每篇从奇数页也就是左页开始，20 pt的篇名从上到下贯穿两栏，作者名靠近底部；页码从第211页接着往下编。一、二、三各节的节号在本栏内占三行。一篇结束时，最后一页任文字自然落下，日文叫成り行き（nariyuki）：第214页上栏排满全页，下栏只有三行和日期。分栏竖排的中文报纸见<RecipeLink slug="vertical-newspaper-tiers">Nº 084</RecipeLink>，横跨两栏的横排章首页见<RecipeLink slug="five-chapter-openers">Nº 017</RecipeLink>。

## 做法

### 1 · 转了四分之一圈的两栏就是上下两栏

代码见上文的[简短回答](#简短回答)。在设了`writingMode: 'vertical-rl'`的页面上，`layoutType: 'double'`把两栏叠放：先从右往左排满上栏，再排下栏，栏间距就是两栏之间的那条带（[竖排](/zh/docs/configuration#竖排)）。[字符网格](/zh/docs/configuration#字格)按一栏竖向的字数计数，所以每栏是25个9 pt的字，栏间距取整为两个字；21行、行距15.75 pt，横向占148 mm宽页面中的116.7 mm。两栏之间的线横贯页面，0.4 pt，暖灰色。

Postext的齐底功能会让一篇最后一页的两栏在同一行结束，中文报纸和大多数欧洲双栏书就是这样收章的。分栏的日文书让文字自然落下：上栏排满全页之后才开始下栏。`balancing.trailing: false`就是这个选择；`enabled: false`包含了它，还会阻止齐底功能在字符网格上往标题上方加行（[各栏齐底](/zh/docs/configuration#各栏齐底)）。

### 2 · 让篇名贯穿两栏

<Excerpt region="opener" />

带`span: 'page'`的标题级别横跨整个页高排出，包括两栏和栏间距，位于文字流的开头，在竖排页面上就是右边；两栏从它的设计所预留的七行之后开始。这样的标题总是另起一页，`breakBefore.parity: 'odd'`让这一页是左页：《蜘蛛の糸》在偶数页第214页结束，所以《尾生の信》从第215页开始，中间没有空白页（[通栏与高级设计](/zh/docs/configuration#通栏与高级设计)）。设计中`x`沿页面向下，`y`从版心右边缘横向延伸；作者名从下栏底端往上三字处放置。

### 3 · 节号在本栏内占三行

第二级标题设`lineSpan: 3`和`indent: em(8)`，把一、二、三排在本栏内低八字、三行宽的带里，与青空文库文本的标法一致（八字下げ，中見出し），这样节号后面的正文仍与旁边一栏的行对齐（[按级别覆盖](/zh/docs/configuration#按级别覆盖)）。结束各篇的日期（大正七年四月十六日）用`:::paragraphs{align=end endIndent=1}`在本栏内离底边空一字（地から一字上げ）；青空文库转换脚本把它们写成`aozora-end1`样式，让它们与底边齐平，围栏上的属性再加上空出的那一字。

### 4 · 卷名和篇名排在切口

<Excerpt region="furniture" />

`anchor.to: 'outer'`把柱放在切口一侧的页边距里，右页是卷名芥川龍之介集，左页是篇名；`pages: 'body'`让两者都不出现在一篇开始的页面上（[竖排文本元素](/zh/docs/configuration#竖排文本元素)）。页码用阿拉伯数字横排在页边距里，很多全集这样印：沿切口竖排时，三位数字会躺倒。`pageNumbering.startAt: 211`按这一卷的页码编号。第一篇的标题样式用`pages: 'opener'`带上版权说明，因为一个样式的页脚会出现在其所在一节的每一页上。

## 变化

### 让末页齐底

去掉`balancing`，每篇的最后一页就会切平：第214页上栏10行、下栏11行结束，这是分栏的中文书或欧洲书收尾的方式。

```diff
-const balancing = { enabled: false, trailing: false };
+const balancing = {}; // the defaults: the closing band is cut level
```

### 每篇从下一页开始

`parity: 'any'`让一篇从紧接着的下一页开始，不论奇偶，杂志和收录极短篇目的选集这样做。

```diff
-const work = { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'odd' } };
+const work = { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'any' } };
```

### 只排一栏

长篇小说和文库本只排一栏，没有栏间距；<RecipeLink slug="bunko-novel-furigana">Nº 117</RecipeLink>就是这样排一本文库本的。
