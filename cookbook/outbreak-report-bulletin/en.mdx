## What you'll build

Six pages of a weekly epidemiology bulletin on US Letter, reprinting the two reports in which the Centers for Disease Control first described what became known as AIDS: five cases of *Pneumocystis* pneumonia in Los Angeles (June 5, 1981) and the cases of Kaposi's sarcoma that followed (July 3, 1981). The masthead is an original design in the spirit of a government bulletin of the period, a blue band with a condensed wordmark over two columns of Plex Serif. Each voice of a report has its own style: case histories under bold numbered labels, the *Reported by* line in small italics, the *Editorial Note*, references in parentheses and a numbered list. The text, the references and the tables are as CDC printed them; the timeline and the case table on page 2 are the editors' own.

## Method

### 1 · One paragraph style per voice

The code is [the short answer](#the-short-answer) above. A bulletin report is written in several registers: the case histories, the list of the people who reported them, the editors' comment. Wrapping each run in `:::paragraphs{style="…"}` gives it a look without touching the words, so the *Reported by* line drops to 7.8 pt condensed italics off the baseline grid while the case histories keep the body texture with their `**Patient 1:**` labels in the accent. The citations are written `[@walzer1974]`; `american-medical-association` with `marker: 'parentheses'` prints them as (1) and lists the works in citation order, the way the weekly did, `numbering: 'chapter'` counts each report's citations from 1, and `scope: 'chapter'` sets its list under it with the same numbers.

### 2 · A masthead that opens the first report

<Excerpt region="masthead" />

The masthead is the design of the first report's heading style, so it prints once, on page 1, and the running heads skip that page (`pages: 'body'`). The kicker and the dateline come from attributes of each report's H1, and the title is `{titleText}`: a text element with `inlineMarks: true` keeps the italic genus of the heading. The July report opens with the same three elements under a double rule. Its heading style spans the page with `spanBreak: false`, so the heading opens where the June report ends: the columns above it end level and the text goes on in both columns below, the way the weekly ran one report on after another.

### 3 · Three tables from tab-separated text

<Excerpt region="resources" />

Each table is a content slot of tab-separated text, the format a spreadsheet copies, and `parseTSV` turns it into a model. A column of counts aligns right with its heading centred; four `mergeCells` calls build the two-row header of the notifiable diseases summary. The table type restarts its counter at every H1 (`resetOn: 'h1'`), so each report has its own Table 1, as in 1981.

### 4 · One blue, linked everywhere

<Excerpt region="palette" />

The band, the labels, the folios, the table headers and the chart all name the same palette entry, so a reader who swaps `accent` for a bulletin's own colour retints the six pages at once.

## Variations

### Superscript reference numbers

Most medical journals raise the numbers instead of setting them in parentheses.

```diff
-const citations = { style: 'american-medical-association', marker: 'parentheses',
+const citations = { style: 'american-medical-association', marker: 'superscript',
```

### Start each report on a new page

A reprint series that files its reports separately opens each one on a fresh page.

```diff
-    { id: 'report', span: 'page', spanBreak: false, advancedDesign: opener },
+    { id: 'report', span: 'page', advancedDesign: opener },
```

## Pitfalls

- Without `numbering: 'chapter'` the reference numbers run on through the document and `scope: 'chapter'` only splits the lists: the July report would cite works 4 and 6 to 23 where the weekly printed 1 to 19.
- The 1981 note *Paired specimens not run in parallel* is marked with an asterisk: `footnotes.numberFormat: 'symbols'` sets *, †, ‡ and starts them again on every page. Of these marks only the asterisk is in the latin file of a Fontsource face (the dagger is in latin-ext, the double dagger in neither), so a page with two or three notes needs a face that has them, or `symbols: ['*', '§', '¶']`.
- The 1981 wording stays as printed, terminology of the period included, and the colophon says so. A reprint corrects nothing in the text it reproduces; what the editors add (the timeline, the case table, the blue italic line under the first paragraph) is set in its own style and labelled.
