## できあがり

よいタイポグラフィーがなぜ気づかれないのかを論じる2段落のエッセイで、出典は6つです。叙述的な引用、ページ付きの引用、文中で名前を挙げているため著者を省く引用、2つの著作をまとめた引用が含まれます。テキストを155 × 235 mmのページに4回組み、4つのビルドのあいだで変わるのは`citations.style`だけです。APA 7、Chicagoの著者・年方式、IEEE、ISO 690です。各ページは独自の色の帯にスタイル名を掲げるので、並べると比較表として読めます。引用は形、順序、句読点が変わり、一覧は並べ方と名前の書き方が変わりますが、エッセイそのものは同じファイルです。

## 作り方

### 1 · 設定は1つ

コードは上の[手短な答え](#手短な答え)にあります。引用は本文の中にPandocの記法で一度だけ書き、文献は末尾のBibTeXブロックに置きます。`citations.style`がCSLのスタイルを指定し、citeproc-jsがそれに従ってすべての引用とすべての項目を書きます。APAは年の前にコンマを置いて2つの著作を著者順に並べ、Chicagoは書かれた順を保ち、IEEEは最初に引用された順に番号へ置き換え、ISO 690は一覧の姓を大文字で組みます。執筆中の本なら、変更はこれだけです。設定の値を1つ変えるだけで、本文には触れません。

### 2 · 4つのビルド、2つの見開き

<Excerpt region="build" />

スタイルは文書全体に効くので、4つの版は同じMarkdownの4回のビルドです。それぞれ`pageIndexOffset`を1つずつ増やすので、各ページは架空の本の次のページになります。デスクはそれらを2つの見開きに組み合わせ、違いの最も小さい2つの著者・年方式を隣り合わせに置きます。

### 3 · 帯にスタイル名を掲げる

<Excerpt region="band" />

見出しのデザインが、仕上がり線から始まる帯、スタイルの番号と方式を示す肩書き、54 ptの名前を描きます。名前と方式はMarkdownからではなくスクリプトから取ります。テキストは4つの文書すべてで同じだからです。

<Excerpt region="palette" />

各文書は`main-color`を自分の帯の色に向けるので、4つの色はリンクされたパレットの項目になります。設定が指定していない既定値は、どれもそのページの帯の色に従います。

## アレンジ

### 注方式のスタイルを試す

Chicagoの注と参考文献の方式では、引用はそれぞれ脚注になり、一覧は参考文献になります。この場合も本文は変わりません。

```diff
-  { style: 'apa', band: 'apa', name: 'APA 7', system: t({ en: 'author-date', es: 'autor-año' }) },
+  { style: 'chicago-notes-bibliography', band: 'apa', name: 'Chicago', system: 'notes' },
```

### 番号を上付きで書く

番号方式のスタイルは、一覧はそのままに、NatureやVancouverのように引用を上付きの番号で印刷することもできます。

```diff
-  link: true,
+  link: true, marker: 'superscript',
```

## よくあるつまずき

- 位置指定子は一度だけ書き、各スタイルがそれぞれの語で印刷します。ここでは4つとも「p. 17」です。同梱されているISO 690のスペイン語スタイルは、節や章を含めどの種類の位置指定子にも「p.」を印刷するので、このテキストではページを引用しています。
- 版の番号はBibTeXに数値で書きます（`edition = {3}`）。そうすれば各スタイルが「3rd ed.」「3.ª ed.」「3.」とそれぞれの形で書きます。「3rd」と書くと、その語がそのまま印刷され、スタイル独自の形が失われます。
