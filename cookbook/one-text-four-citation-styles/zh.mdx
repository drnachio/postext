## 成品一览

一篇两段的短文，谈好的排版为什么让人察觉不到，引用了六种文献：一处叙述式引文，一处带页码，一处因句子已提到作者而省去作者，还有两部一起引用的著作。正文在155 × 235 mm的页面上排了四遍，四次排版之间唯一的差别是`citations.style`：APA 7、Chicago著者-出版年制、IEEE和ISO 690。每页在各自颜色的色带上印出样式名，并排放在一起就是一张对照表。引文的形式、顺序和标点都变了，文献表的排序和姓名写法也变了，而短文本身是同一个文件。

## 做法

### 1 · 一项设置

代码就是上面的[简短回答](#简短回答)。引文按Pandoc的语法在内容里写一次，文献放在末尾的BibTeX块里。`citations.style`指定一种CSL样式，citeproc-js据此写出每条引文和每个条目：APA在年份前加逗号，并按作者给两部著作排序；Chicago保持书写的顺序；IEEE按首次引用的顺序改成数字；ISO 690把文献表里的姓氏改成大写。对于正在写的书，要改的就只有这些：配置里的一个值，正文一字不动。

### 2 · 四次排版，两个对开页

<Excerpt region="build" />

样式对整份文档生效，所以四个版本是同一份Markdown的四次排版。每次的`pageIndexOffset`比上一次多一，让这一页成为一本假想书的下一页；展示台于是把它们配成两个对开页，差别最小的两种著者-出版年样式并排。

### 3 · 色带上的样式名

<Excerpt region="band" />

标题的设计从裁切边画出色带，再写上标明样式序号和体系的眉题，以及54 pt的样式名。样式名和体系来自脚本而不是Markdown，因为四份文档的正文完全相同。

<Excerpt region="palette" />

每份文档把`main-color`指向自己的色带，所以四种颜色都是调色板里的关联条目，配置没有写明的默认值会跟随本页的色带。

## 变化

### 试试注释样式

换成Chicago注释-书目样式，每条引文变成脚注，文献表变成书目；正文仍然不变。

```diff
-  { style: 'apa', band: 'apa', name: 'APA 7', system: t({ en: 'author-date', es: 'autor-año' }) },
+  { style: 'chicago-notes-bibliography', band: 'apa', name: 'Chicago', system: 'notes' },
```

### 把编号写成上标

顺序编码样式可以保留文献表，把文中引文印成上标数字，Nature和Vancouver就是这样。

```diff
-  link: true,
+  link: true, marker: 'superscript',
```

## 常见问题

- 定位信息只写一次，各样式用自己的词印出来：这里四种样式都印作"p. 17"。引擎自带的西班牙文ISO 690样式对任何定位信息都印"p."，章节也不例外，所以这篇文字引的是页码。
- BibTeX里的版次要写成数字（`edition = {3}`），各样式才会按自己的方式写成"3rd ed."、"3.ª ed."或"3."。写成"3rd"就会原样印出，样式自己的写法便丢了。
