## できあがり

架空の港町で出る架空の日刊紙『الساحل』の2ページを、246 × 328 mmのコンパクト判に組みます。1面には84 ptのAref Ruqaaで組んだ題字、町の新しい路面電車についてのトップ記事とページ幅の見出し、コードで描いた地図、地の3本の短信の帯が入ります。2ページは青い面名の下で地域面を始め、記事4本とその日の礼拝時刻を載せます。本文の第1段、短信、表の列、題字の耳と、すべてが右から読まれます。<RecipeLink slug="newspaper-front-page">英語の新聞1面</RecipeLink>は同じ要素を左から右に組んでいます。

## 作り方

### 1 · 2段組みで、第1段は右

コードは前出の[手短な答え](#手短な答え)にあります。`layoutType: 'double'`と段間罫は英語の新聞と同じ設定です。`locale: 'ar'`でページの向きが変わり、記事はまず右の段を埋め、左の段の頭へ続きます（[ページの順序と右綴じ](/ja/docs/arabic-layout#ページの順序と右綴じ)）。両段にまたがる見出しは枠のないページ幅の囲みで、その下の段は同じ高さから始まります。「短信」欄は地にフロートとして配置したページ幅の囲みで、中に`:::columns{count=3}`を入れます。その段も右から左へ流れます。2ページの礼拝時刻の表も同じで、文書の方向で組んだ表は第1列を右に置きます。

### 2 · 2つの耳に挟まれた題字

<Excerpt region="nameplate" />

1面の1レベル見出しが紙名で、見出しスタイルで描きます。そのデザインは左右反転したページに描かれるので、`top-right`が行の始まりになります。号数と日付をそこに、都市名と価格を反対の端に置きます（[左・右・始端・終端の意味](/ja/docs/arabic-layout#左右始端終端の意味)）。ルクア体は数語を大きく見せるための見出し用の書体で、カシーダがなく、本文には使いません。

### 3 · 面名とノンブル行

<Excerpt region="inside" />

中面は、太罫の上の面名として描いた1レベル見出しで始まります。ノンブル行はヘッダーなので、物理的な左右を保ちます。偶数ページである2ページでは、ノンブルは右の角にあり、右開きの新聞ではそこが小口側です。1面では見出しスタイルでヘッダーを消しています。

### 4 · コードで描いた地図

<Excerpt region="art" />

路面電車の地図はパレットの色を使ったパスと円のSVGで、文字を含みません。地名はキャプションに置き、紙面の書体で組みます。この図版の種別には番号もラベルもありません。新聞は図版に番号を振らないからです。

## アレンジ

### 短信は3段、幅の広いページでは4段

帯は独自の段組みを持つ囲みなので、本文の2段より多くできます。

```diff
-:::columns{count=3 breaks="2,3"}
+:::columns{count=4 breaks="2,3,4"}
```

### マグレブの新聞ではヨーロッパ数字

```diff
-  locale: 'ar', // written out, never LANG (gotcha: arabic-locale-tag): rtl, digits ٠–٩
+  locale: 'ar-MA', // rtl, digits 0–9
```

## よくあるつまずき

- 礼拝時刻は表のセルにアラビア・インド数字で入力しています。`locale`が変えるのはエンジンが書く数字だけなので、マグレブ版では入力し直します。
