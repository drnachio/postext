## 成品一览

这是虚构厂商Pyxis Microdevices出品的温度传感器PX-7021的四页数据手册。内容大多是表格：表头里满是合并单元格，寄存器表比一栏还长。首页以一条紫色色带开头，上面有型号和三项关键指标。第2页有一张通栏表格，两行表头把Value放在Min、Typ和Max之上；参数组在第一列向下合并，参数隔一个染一次灰色。寄存器表在第3页页脚断开，到第4页接续并重复表头，旁边是订货型号，下方是封装图。这些表格都是以TSV粘贴的电子表格数据，因为Postext不解析Markdown表格。

## 做法

### 1 · 先粘贴数据，再整理表格

代码见上文的[简短回答](#简短回答)。`parseTSV(tsv, { headerRows: 2 })`把前两行标为表头；表格拆分时，两行都会在每一部分重复。`columnWidths`的权重加起来是180，即版心的毫米宽度，所以每个权重就是该列在页面上的宽度。`mergeCells`让每个被覆盖的单元格留在原位并标为`hiddenBy`，因此没有列会错位。`setAlignment`逐个单元格生效，省略垂直对齐时会把它清掉，所以大多数调用都要再传一次`'middle'`。灰色按参数交替，而不是按行交替，这样Accuracy的两行保持同一底色；按行交替（表格样式自带的`bodyAlternateBackground`就是这样）会让第二行变成白色。

### 2 · 每个模型都成为资源

<Excerpt region="resources" />

每张表格和每幅图都是带题注的资源，表格还加上一条注释和一个命名样式。题注和注释支持斜体、下标和上标：电气特性表在题注中用`*V*~DD~`写出测试条件，在注释中用`^1^`给脚注编号。浮动体放在首次`:ref`之后的第一个空位。表1在第1页被引用，放置在页面顶部通栏，所以它排在第2页开头。外形图放置在页面底部通栏，其余表格保持默认放置方式，即一栏宽的浮动体。放置为`here`的表格留在正文里；本栏余下的空间放不下时，它同样在行与行之间拆分。

### 3 · 让长表格自行拆分

<Excerpt region="split" />

引脚表和寄存器表都由`groupedTable`生成。只填了第一个单元格的行会横跨全表合并，并作为组标题染成紫色。TSV单元格不能含换行，所以数据里写`\n`，由函数把它换成换行；以`•`开头的行随后排为列表项。短代码用`code`行内标签样式，它没有底色、边框和左右内边距，用0.9 em的Fira Mono排。浮动表格放不进分给它的空栏时，引擎会在行与行之间把它切开，把余下部分排到下一个空位，放在重复的表头下，并在题注后加`(continued)`。`continuesMarker`那一行“Continued on the next page”放在第一部分下方，注释则留到最后一部分（[高于页面的表格](/zh/docs/configuration-resources#比页面还高的表)）。

### 4 · 一套统一样式，每张表一个变体

<Excerpt region="styles" />

`tableStyle`存放所有表格共有的设置。`tableStyles`中的每一项只设置其表格要改的部分，资源用`table.styleId`选用其中一项。电气特性表把灰色细线换成1.4 pt的白线，把底色切开，并显示出每处合并的范围。订货型号表加了圆角外框，并使用Fira Sans Condensed，使四列能放进一栏。

### 5 · 在PDF中保持为文本的标签

<Excerpt region="drawing" />

引脚图、电路图和封装外形图的标签都是`<text>`元素，指定文档的标签字体Fira Mono。SVG以图像形式进入Canvas，所以工具包的`loadSvg`先把标记交给`inlineSvgFonts`，由它把文字用到的字体嵌进SVG；Canvas于是用Fira Mono画出标签。PDF把每个`<text>`用它嵌入的字体排成可选中的文本。

### 6 · 章首、书眉和页脚

<Excerpt region="furniture" />

型号是一级标题，它的设计槽画出章首页：一个延伸到出血的紫色框、标志，以及从标题属性读取的眉题、导语和三项关键指标。图像元素既能用在章首页，也能用在页眉页脚设计槽中，所以页脚以一个指向标志资源的图像元素开头。书眉的各元素带有`pages: 'body'`，因此首页上一个都不印。

## 变化

### 每一行都用灰线分隔

用调色板中灰色`rule`颜色的0.5 pt细线分隔每一行，不论有无底色；白线在两行无底色的行相接处会看不见。

```diff
-    { id: 'electrical', borderColor: col('paper'), borderWidth: pt(1.4), cellPadding: mm(1.1) },
+    { id: 'electrical', borderColor: col('rule'), borderWidth: pt(0.5), cellPadding: mm(1.1) },
```

### 把表格题注排在色条上

表格类型的题注样式可以在题注后面画一条色条，这里用墨色，标签用警示黄。

```diff
-    ...(type.id === 'table' && { captionStyle: { position: 'above' } }) })),
+    ...(type.id === 'table' && { captionStyle: { position: 'above', backgroundEnabled: true,
+      background: col('ink'), color: col('paper'), labelColor: col('hazard') } }) })),
```

## 常见问题

- 拆分表格的第一部分下方如果还能放下三行或更多，就会把所在栏的底部留给正文；在已有浮动体的栏里，它总是这样做。长表格应从一个没有其他浮动体的栏开始，就像寄存器表那样，并调整行数，让第一部分排到栏底。
- 设计文本元素默认居中。导语有固定宽度，所以需要`align: 'left'`才能与型号左对齐。
- 在一章的最后一页，Postext会把排在正文下方的通栏浮动体上移到正文下方一个正文行处，所以那里的`bottom`图会紧贴最后一行正文，而不是在页面底部。第4页的文字经过调整以填满各栏，外形图画成48.3 mm高，让它上方的正文结束在一条网格线上。这样外形图没有上移的空间，底边与其他页的页脚平齐。设置`layout.hugClosingFloats: false`可以关掉这种上移。
