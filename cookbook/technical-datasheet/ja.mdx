## できあがり

架空のメーカーPyxis Microdevicesの温度センサーPX-7021の、4ページのデータシートです。大半は表で、見出しには結合したセルが多く、レジスターマップは1段より長くなります。表紙ページは、品番と3つの主要な数値を載せた紫の帯で始まります。2ページ目では1つの表がページ幅にまたがります。2行の見出しはValueをMin、Typ、Maxの上に置き、パラメーターのグループは第1列で縦に結合し、パラメーターは1つおきに灰色の地を敷きます。レジスターマップは3ページ目の地で切れ、4ページ目で見出しを繰り返して続き、型番の表の横、パッケージ図の上に置かれます。PostextはMarkdownの表を解析しないので、表は表計算のデータをTSVとして貼り付けたものです。

## 作り方

### 1 · データを貼り付け、表を整える

コードは前の[手短な答え](#手短な答え)にあります。`parseTSV(tsv, { headerRows: 2 })`が先頭の2行を見出しにします。表が分割されれば、両方の行が各部分で繰り返されます。`columnWidths`の比率は合計180で、これは版面の幅をmmで表した数なので、各比率がそのままページ上の列幅になります。`mergeCells`は覆われたセルをすべてその場に残して`hiddenBy`の印を付けるので、列はずれません。`setAlignment`はセルごとに働き、縦方向のそろえを省くと消してしまうため、ほとんどの呼び出しで`'middle'`をもう一度渡します。灰色はパラメーター単位で交互に付けるので、Accuracyの2行は同じ地色になります。表スタイルの`bodyAlternateBackground`のように行単位で交互にすると、2行目は白になってしまいます。

### 2 · 表と図はすべてリソースにする

<Excerpt region="resources" />

各表と図はキャプションを持つリソースで、表にはさらに注記と名前付きのスタイルが付きます。キャプションと注記にはイタリック、下付き、上付きが使えます。電気的特性の表は、キャプションで`*V*~DD~`を使って試験条件を示し、注記では`^1^`で脚注に番号を振ります。フロートは最初の`:ref`のあとの、最初の空き位置に置かれます。表1は1ページ目で引用され、ページの頭にまたがって置かれるので、2ページ目の冒頭に来ます。外形図はページの地にまたがって置かれ、ほかの表は初期設定の配置、つまり1段幅のフロートのままです。`here`に置いた表は本文の中にとどまり、段の残りに収まらないときは同じように行の間で分割されます。

### 3 · 長い表は自分で分割させる

<Excerpt region="split" />

ピンの表とレジスターマップは、どちらも`groupedTable`から作ります。最初のセルだけが埋まった行は表の幅いっぱいに結合され、グループ見出しとして紫の地になります。TSVのセルは改行を持てないので、データには`\n`と書き、関数がそれを改行に変えます。`•`で始まる行は、さらにリスト項目として組まれます。短いコードは`code`チップスタイルで組みます。このスタイルは地色、枠、左右のパディングを持たず、Fira Monoの0.9 emで組みます。フロートした表が、割り当てられた空きの段に収まらないとき、エンジンは行の間で表を切り、残りを次の空き位置に、繰り返した見出しの下に置いて、キャプションのあとに`(continued)`を付けます。`continuesMarker`の行「Continued on the next page」は最初の部分の下に入り、注記は最後の部分まで待ちます（[ページより高い表](/ja/docs/configuration#ページより高い表)）。

### 4 · 共通のスタイルと、表ごとの変種

<Excerpt region="styles" />

`tableStyle`はすべての表に共通する設定を持ちます。`tableStyles`の各項目は、その表が変える部分だけを設定し、リソースは`table.styleId`で1つを選びます。電気的特性の表は、灰色の細い罫を1.4 ptの白い罫に替えて地色を切り分け、各結合の終わりを見せます。型番の表は角丸の外枠とFira Sans Condensedを使い、4列を本文の1段に収めます。

### 5 · PDFでテキストのまま残るラベル

<Excerpt region="drawing" />

ピン配置図、回路図、パッケージ外形図のラベルは`<text>`要素で、文書のラベル用書体Fira Monoを指定しています。SVGは画像としてキャンバスに届くので、キットの`loadSvg`はまずマークアップを`inlineSvgFonts`に通し、テキストが指定する書体をSVGの中に埋め込みます。これでキャンバスはラベルをFira Monoで描きます。PDFは各`<text>`を、埋め込んだ書体で選択可能なテキストとして組みます。

### 6 · 扉、柱、フッター

<Excerpt region="furniture" />

品番は第1レベルの見出しで、そのデザインスロットが扉を描きます。塗り足しまで届く紫のボックス、ロゴ、そして見出しの属性から読む肩見出し、リード、3つの主要な数値です。画像要素は扉だけでなく柱やフッターのスロットでも使えるので、フッターはロゴのリソースを指定する画像要素で始まります。柱の要素は`pages: 'body'`を持つので、どれも表紙ページには刷られません。

## アレンジ

### すべての行を灰色の罫で区切る

パレットの灰色`rule`の0.5 ptの罫が、地色の有無にかかわらずすべての行を区切ります。白い罫は、地色のない2行が接するところでは見えなくなります。

```diff
-    { id: 'electrical', borderColor: col('paper'), borderWidth: pt(1.4), cellPadding: mm(1.1) },
+    { id: 'electrical', borderColor: col('rule'), borderWidth: pt(0.5), cellPadding: mm(1.1) },
```

### 表のキャプションを帯の上に組む

表タイプのキャプションスタイルは、キャプションの後ろに帯を塗れます。ここでは墨の帯に、ラベルを警告色の黄色で組みます。

```diff
-    ...(type.id === 'table' && { captionStyle: { position: 'above' } }) })),
+    ...(type.id === 'table' && { captionStyle: { position: 'above', backgroundEnabled: true,
+      background: col('ink'), color: col('paper'), labelColor: col('hazard') } }) })),
```

## よくあるつまずき

- 分割した表の最初の部分は、下に3行以上入るとき、段の地を本文に譲ります。すでにフロートのある段では、かならず譲ります。長い表は、このレジスターマップのように、ほかのフロートのない段で始め、最初の部分が段の地まで届くように行を調整してください。
- デザインのテキスト要素は初期設定で中央そろえです。リードは幅が固定なので、品番の下にそろえるには`align: 'left'`が必要です。
- 章の最後のページでは、Postextは本文より下に置いたページ幅のフロートを、本文の1行下まで持ち上げます。そのため、そこに置いた`bottom`の図はページの地ではなく、本文の最終行の下に来ます。4ページ目は段を埋めるように文面を調整し、外形図は上の本文がグリッド線で終わるよう、高さ48.3 mmで描いてあります。こうすると外形図には上へ動く余地がなく、ほかのページの地と同じ高さで終わります。`layout.hugClosingFloats: false`にすると、この持ち上げは行われません。
