## 成品一览

海洋主题儿童杂志《Splash!》的益智游戏页，共两页，A4大小，双栏。第一页上部是一幅珊瑚礁的画，标题落在开阔的海面上。下面每个游戏各占一张米色卡片，编号是珊瑚色的：一个用六种海洋动物和提示组成的填字游戏，一个把八个单词按横向、纵向、斜向和倒序藏起来的找字游戏，一个有三个选项可圈的谜语，一段要排好顺序的海龟一生，一句打乱了词序的冷知识，还有要和名字连起来的动物宝宝。每个游戏下面、卡片之内，答案用灰色小字倒着印，益智杂志一向这样把答案藏起来。

## 做法

### 1 · 每个游戏一张卡片，答案倒过来

代码见上文的[简短回答](#简短回答)。练习样式的`box`指定一个框样式，所以每个游戏都排在一张卡片上，编号在圆片里，标题作为题目说明的第一行。`placement: 'inverted'`把答案放在每个游戏后面、卡片之内一个旋转180°的框里，所以题目和答案永远不会分在两页；格子和书写线都留在卡片的内边距之内。

### 2 · 让引擎生成格子

Markdown里只有单词：填字游戏写`- OCTOPUS: Eight arms and three hearts`，找字游戏写`- SHELL`。引擎排填字游戏时让每个词都和另一个词交叉，并按阅读顺序给起点编号。找字游戏的单词按指令里写的方向藏进去（`directions="across down diagonal backwards"`），其余格子用这些单词自己的字母填满。两种格子都用固定的随机种子，所以每次排版、每种输出里的格子都一样，西班牙文版则用自己的单词生成自己的格子。

### 3 · 珊瑚礁横跨两栏

<Excerpt region="opener" />

开篇横跨两栏（`span: 'page'`），所以每一栏的游戏都从画的下方开始。图片按开篇区的比例裁切，并锚定在页面上，因此顶边和两侧都出血；导语放在深色框里，压在海水上也看得清。

## 变化

### 隐藏单词表

难一点的找字游戏只印格子：在指令里加上`hidden`。

```diff
-:::exercise{type=wordsearch size=9 directions="across down diagonal backwards"}
+:::exercise{type=wordsearch size=9 directions="across down diagonal backwards" hidden}
```

### 把答案印在杂志末尾

`chapterEnd`把所有答案集中到末尾，不再逐个倒印。

```diff
-  solutions: { placement: 'inverted', box: 'turned' },
+  solutions: { placement: 'chapterEnd' },
```

## 常见问题

- 填字游戏里不和任何词交叉的词会被舍弃，并报告`exerciseWordUnplaced`。选有相同字母的词，或者加一个把两组词连起来的词。
- 游戏卡片不会拆开，所以较高的填字游戏放不下时会移到下一栏。检查一下西班牙文版，那里的单词更长。
- 栏平衡已打开（`headings.balancing.enabled`），所以收尾页会被齐平截断：最后几张卡片分占两栏，而不是挤满第一栏、让第二栏几乎空着。让最后一页的卡片高度相近，否则一张高卡片仍会独自占满一栏。
