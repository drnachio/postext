## できあがり

海をテーマにした子ども向け雑誌『Splash!』のパズルページです。A4判の2ページで、2段組みです。1ページ目の上部をサンゴ礁の絵が埋め、タイトルはひらけた海面の上に置きます。その下で、パズルは1つずつ、サンゴ色の番号が付いたクリーム色のカードに載ります。6種類の海の生き物とそのカギで作るクロスワード、8つの単語をヨコ、タテ、ななめ、逆向きに隠したワードサーチ、3つの選択肢から丸で囲むなぞなぞ、ウミガメの一生を順番に並べる問題、語順がばらばらの豆知識、海の動物の赤ちゃんを名前と結ぶ問題です。どのパズルも、カードの中の問題の下に、小さな灰色の文字で答えを逆さに刷ります。パズル雑誌が昔から使ってきた答えの隠し方です。

## 作り方

### 1 · パズルを1つずつカードに載せ、答えを回す

コードは上の[手短な答え](#手短な答え)にあります。練習問題スタイルの`box`は囲みスタイルを指定するので、どのパズルもカードの上に組まれ、番号は円の中に、タイトルは問題文の1行目になります。`placement: 'inverted'`は、各パズルのあとに答えを180°回転した囲みに入れてカードの中に置くので、問題と答えが別のページに分かれることはありません。マス目と書き込み線はカードの内側の余白に収まります。

### 2 · マス目はエンジンに作らせる

Markdownに書くのは単語だけです。クロスワードは`- OCTOPUS: Eight arms and three hearts`、ワードサーチは`- SHELL`です。エンジンはどの単語もほかの単語と交わるようにクロスワードを組み、読む順に単語の頭に番号を振ります。ワードサーチの単語はブロックが指定する方向（`directions="across down diagonal backwards"`）に隠し、残りのマスは同じ単語の文字で埋めます。どちらもシード値が固定なので、マス目は何度組んでもどの出力でも同じです。スペイン語版は自分の単語で自分のマス目を作ります。

### 3 · 2段にまたがるサンゴ礁

冒頭の帯は2段にまたがる（`span: 'page'`）ので、どの段でもパズルは絵の下から始まります。画像は帯の比率に合わせて切り抜き、ページに固定しているので、上と左右が裁ち落としになります。リード文は暗い色の囲みに入れ、海の上でも読めるようにします。

## アレンジ

### 単語リストを隠す

難しくしたワードサーチではマス目だけを刷ります。ブロックに`hidden`を加えます。

```diff
-:::exercise{type=wordsearch size=9 directions="across down diagonal backwards"}
+:::exercise{type=wordsearch size=9 directions="across down diagonal backwards" hidden}
```

### 答えを雑誌の最後に刷る

`chapterEnd`は答えを1つずつ回さず、すべて最後にまとめます。

```diff
-  solutions: { placement: 'inverted', box: 'turned' },
+  solutions: { placement: 'chapterEnd' },
```

## よくあるつまずき

- ほかのどの単語とも交わらないクロスワードの単語は外され、`exerciseWordUnplaced`として報告されます。文字を共有する単語を選ぶか、2つのグループをつなぐ単語を1つ足します。
- パズルのカードは分割しないので、背の高いクロスワードが入りきらないときは次の段へ移ります。単語が長いスペイン語版で確かめてください。
- 段の釣り合わせをオンにしている（`headings.balancing.enabled`）ので、最終ページは高さをそろえて切られます。最後のカードは1段目を埋めて2段目をほとんど空けるのではなく、2つの段に分かれて入ります。最終ページのカードの高さを近づけておかないと、背の高いカードが1枚だけで段を閉じることになります。
