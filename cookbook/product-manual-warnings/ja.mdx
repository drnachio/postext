## できあがり

架空の電気ケトルVerra W1の取扱説明書7ページを、A5判にドイツ語で組みます。安全上の注意のページでは、2段階の危険の度合いを囲みで示します。信号色の帯が左側を縦に走って警告の三角形を載せ、同じ色の細枠が囲みを閉じます。WARNUNGは赤、VORSICHTは黄色です。機器の損傷を示す段階のHINWEISは、帯と三角形を使わず、角丸のティールの地色にします。囲みの上の段落では、3つの信号語をすべて塗りのチップで示します。3ページ目には番号付きの引出線を付けた部品図と、その下に凡例があり、4ページ目では大きな手順番号の横に、キーの名前を枠線のチップで組みます。トラブルシューティングの表は6ページと7ページにまたがります。キャプションはAbbildungとTabelleで、分割した表には両方のページにFortsetzungと入ります。

## 作り方

### 1 · 三角形を載せる帯

コードは前出の[手短な答え](#手短な答え)にあります。`stripe`が左端に帯を塗ります。側面に帯のある囲みでは、アイコンは専用の列を取らず、帯の中央に置かれます（[囲みスタイル](/ja/docs/configuration-styles#囲みスタイル)）。`align: 'top'`でアイコンの上端をタイトルの上端にそろえます。同じ色の`border`が帯を閉じて枠にします。これがないと、囲みの本文は色のついた帯の横で、紙の上にむき出しで立つことになります。`PAD_Y`は、タイトル、その下の間隔、上下のパディングの合計が12.8 ptのグリッドの2行分になるように計算します。本文はグリッドの行送りを保つので、どの囲みも高さが行の整数倍になり（WARNUNGは10行、VORSICHTは8行）、`marginTop: pt(LEAD)`が2ページ目の2つの囲みの間をちょうど1行空けます。VORSICHTは帯と枠に黄色を使い、タイトルと箇条書きの記号は墨で組みます。白地に黄色のコントラストは2.0:1しかなく、小さな文字には4.5:1が必要だからです。HINWEISは同じ土台（`...notice(…)`）から作り、帯と枠をオフにします。そのためinfoアイコンには専用の列が与えられ、`borderRadius`が無地の地色の角を丸めます。

### 2 · 図と表のドイツ語の名前

<Excerpt region="types" />

`locale: 'de'`で取扱説明書にドイツ語のハイフネーションが適用され、組み込みの種類もドイツ語の名前になります。ほかに何も指定しなければ、キャプションはAbbildung 2.1やTabelle 5.1となり、分割した表の前半の下の注記はWird fortgesetztになります。表スタイルではこの注記とキャプションの接尾辞を省略せずに書き、`defaultResourceTypes('de')`は2か所を変えるために渡しています。1つ目が`counted`です。`resetOn: 'never'`を付けた`{n}`で、節ごとにやり直さず取扱説明書全体を通して数えます（Abbildung 1、Tabelle 1から3）。`captionStyle.position: 'above'`を指定するのは表の種類だけなので、表はキャプションを上に置き、図はキャプションを下に置いたままです。

### 3 · キー、信号語、部品番号をチップにする

<Excerpt region="chips" />

`taste`は、ボタンに刷られたラベルのように、キーの名前を等幅書体で塗りなしの枠線で囲みます。信号語のチップはそれぞれの囲みの色で塗り、黄色のチップはVORSICHTのタイトルと同じく語を墨で組みます。`nr`は部品番号に高さの半分より大きい角丸を与えるので、図の番号付きの丸と同じ円形になります。チップのサイズは周囲のテキストのemで指定します。キーは本文中では8.6 pt、表のセルでは7.5 ptになります（[チップスタイル](/ja/docs/configuration-styles#チップスタイル)）。

### 4 · ベースラインに立つ手順番号

<Excerpt region="steps" />

手順は番号付きリストで、番号はRed Hat Display 800、15 pt、ティールで、区切り記号は付けません。リストの番号はベースラインに立たず、1行目の中央に置かれるので、9.3 ptの本文の横の15 ptの数字は行から約1 pt下がります。`numberVerticalOffset: pt(-1)`はキャプチャー上で測った値で、数字の下端をベースラインまで持ち上げます。`itemSpacing`で手順の間を5 pt空け、大きな数字の場所を作ります。手順の下に入れ子になった箇条書きは6.5 mmから始まり、手順の本文にそろいます。記号はティールのダッシュで、3階層目は灰色です（[番号付きリスト](/ja/docs/configuration-text#番号付きリスト)）。

### 5 · 白抜きのタブに入れる節番号

<Excerpt region="section" />

各節は段内のレベル1の見出しで、デザイン要素の枠から描きます。タブはティールの正方形に`{number}`（`numberingTemplate: '{1}'`で埋まる）を白で刷り、タイトルはその3 mm右から始まります。番号とタイトルはサイズと行の高さが同じなので、同じ上パディングでひとつのベースラインにそろいます。タブは22 ptの正方形で、12.8 ptのグリッドの2行分より3.6 pt小さいため、見出しはグリッド2行の中に収まります。表紙も番号なしの見出しスタイルで組んだレベル1の見出しなので、Sicherheitshinweisesが第1節になります。

### 6 · セルを結合したトラブルシューティングの表を分割する

<Excerpt region="tables" />

表はそれぞれ専用のコンテンツファイルにTSVで書きます。トラブルシューティングのデータでは、最初のセルが空の行はその上の故障に属します。`mergeCells`はそうした最初のセルをひとつの縦長のセルに結合し、覆われたセルを非表示にします。`parseTSV`は見出し行を設定しないので、`headerRowCount: 1`で宣言します。7ページ目で繰り返されるのがこの行です。表は1ページより高いので、分割されて次のページに続きます。`position: 'top'`で6ページの頭に置くフロートにします。postext 1.25からは`'here'`に置いても同じように分割されますが、その場合は表の後の本文が7ページのもっと下から始まり、最後の数行が8ページ目に送られます。分割は行と行の間で行われ、結合したセルの途中では切れないため、どの故障もその原因と同じページに収まります（[ページより高い表](/ja/docs/configuration-resources#ページより高い表)）。表は5ページ目で引用され、引用の後で上のフロートを置ける最初のページである6ページ目の頭に来ます。`fold`はリストを半分ずつ横に並べます。凡例と技術データに使い、凡例では`align: 'center'`で番号のチップを中央にそろえます。

## アレンジ

### 図と表に節ごとの番号を振る

テンプレートに節番号を入れ、節ごとにリセットすると、部品図はAbbildung 2.1、トラブルシューティングの表はTabelle 5.1になります。

```diff
-const counted = { numberingTemplate: '{n}', resetOn: 'never', counterFormat: 'decimal' }; // 1, 2…
+const counted = { numberingTemplate: '{h1}.{n}', resetOn: 'h1', counterFormat: 'decimal' };
```

## よくあるつまずき

- 段末そろえは、ページを締めくくる囲みをページの最後のグリッド行まで押し下げるので、ページに残った余白は囲みの上に開きます（[段末そろえ](/ja/docs/configuration-text#段末そろえ)）。2ページ目の本文は、段をちょうど埋めるように調整しました。VORSICHTの箇条書きを1つ削っても囲みは地で終わりますが、2つの囲みの間隔は4.5 mmから13.6 mmに広がります。`headings: { balancing: { enabled: false } }`にすると、囲みはWARNUNGの1行下にとどまり、ページの終わりが2行足りなくなります。
