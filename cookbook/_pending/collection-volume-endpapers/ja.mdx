## できあがり

セルバンテスの『模範小説集』12編の11番目『偽りの結婚』を、1編を1冊の上製本にする叢書の第11巻として組みます。本文26ページは120 × 185 mmのページにCrimson Pro 11/15.2で組みます。そこから `buildCover` が製本所向けの用紙を3枚作ります。叢書のえんじ色に刷った表紙（絵のまわりに金の枠、巻数は金の輪の中）と、前後の見返しで、見返しにはその表紙を縮小した12巻分の絵と番号付きの書名一覧が並びます。巻のISBNを載せたバーコードの横には、全巻のISBNが刷られます。

## 作り方

### 1 · 叢書は本のデータ

コードは上の[手短な答え](#手短な答え)です。`production.collection` に叢書の名前、ISBN、そして各巻のID・書名・画像を並べた `catalogue` を持たせます。Postextが実際に刷るのは版の `workIsbn` で、バーコードの上に6.5ポイントの黒い1行「全巻ISBN」が本の言語で入ります。目録は `.postext` ファイルに入って本と一緒に運ばれ、設定のチェックも読みますが、`buildCover` は目録から何も描きません。そのため手順3でコード自身が組みます。2つのISBNはどちらも978-84-0000ブロックの見本番号で、どの本にも割り当てられていません。

### 2 · 全巻に同じ装丁

<Excerpt region="livery" />

表紙のデザインは叢書のどの巻でも同じオブジェクトで、変わるのは `VOLUME`、絵、文字だけです。各要素は置かれたゾーンを基準に配置されるので、ページ数が多く背の厚い巻では表表紙がその面と一緒に動きます。背では `basis` が帯を描いたときの10 mmの背幅を記録し、背が8.3 mmでも14 mmでも帯は幅に合わせて伸縮し、輪は中心線に残ります。バーコードの上の行は黒で刷られるので、バーコードは淡いラベルの上に置きます。

### 3 · 見返しは目録から組む

<Excerpt region="endpapers" />

ある用紙にないゾーンに置いた要素は、その用紙には描かれません。縮小図は `pastedown` と `flyleaf`（効き紙と遊び紙）に置くので、見返しに出て表紙には出ず、`front` の絵は見返しには出ません。文字も同じで、1つの表紙用Markdownがすべての用紙に使われ、見返しでは裏表紙の枠が、表紙では見返しの枠が捨てられます。見返しの枠はコードが目録から書き出すので、一覧と縮小図が食い違うことはありません。前後の見返しは同じデザインと文字で、本の後ろでは効き紙が右に来るため、そこでは第7〜12巻が先に並びます。

### 4 · 1冊の本から3枚の用紙

<Excerpt region="sheets" />

同じ呼び出しに `sheet: 'cover'`、`'endpaperFront'`、`'endpaperBack'` を渡すと、表紙と2枚の見返しができ、それぞれ固有の寸法の1ページ文書になります。26ページは16ページの折丁2つに切り上げられ、240 µmの紙16枚。0.5 mmの余裕を加えて本文は4.3 mm、2 mmの板紙2枚を足して表紙の背は8.3 mmです。チェックは4.3 mmの本文について `spineTooThinForText` を出しますが、背文字は表紙の8.3 mmの背に入り、最小値6 mmを超えています。PDFは本文26ページのあとに表紙と見返しが続きます。

## アレンジ

### 表紙にカバーを掛ける

上製本では `flaps` でカバーが加わります。自前の袖を持つ4枚目の用紙で、その裏表紙にも表紙と同じくバーコードと全巻ISBNが入ります。

```diff
   versions: [{ id: 'hardcover', name: t({ en: 'Hardcover', es: 'Tapa dura' }),
     binding: 'case-flat', isbn: '978-84-0000-198-8', isbnAddOn: '90000',
-    workIsbn: collection.isbn }],
+    workIsbn: collection.isbn, flaps: true }],
```

### 次の巻を組む

第12巻ではデザインはそのままで、巻数、見返しの金の枠、強調される書名が `VOLUME` に従います。本文、絵、ISBNはその巻のものにします。

```diff
-const VOLUME = 11; // this book's place in the collection
+const VOLUME = 12; // this book's place in the collection
```

## よくあるつまずき

- キャプチャされる一覧では、用紙は本のページのあとに来ます。表紙は27ページ目、つまり本のページ数に1を足した位置です。本に1ページ増える変更をすると、用紙の位置もずれます。
- レシピ集の `contentInConfig` チェックは、`buildCover` がバーコードの上に刷る行をデザインに置いた文字と見なします。コードはそれを `checks.contentInConfig.allow` に、エンジンが使う関数 `workIsbnCaption` の文言で登録します。
- バーコードの数字はOCR-Bを指定しますが、どのフォントサーバーにもありません。コードがすでに読み込んでいる `font-family` に置き換えてバーコードを読み込まないと、PDFが失敗します。
