## 成品一览

爱伦·坡的两篇小说《红死病的假面舞会》和《椭圆形画像》（英文版用原文，西班牙文版用卡洛斯·奥利韦拉1884年的译本），排成125 × 195毫米的平装本，外加它的封面印张。封面上没有一段文字写了坐标，每段都是挂在别处的文本框。封面上，书名挂在区域顶部，副书名挂在书名下面，作者名立在底部。两个版本的书名都要排两行，所以书名框长高，副书名也跟着往下移。封底上，简介填满一个50毫米高的框，放不下的行接着排进第二个框，位于一句小说引文的下面。页面上方，示例把印张画了两遍：一遍是印出来的样子，一遍给每个框画上轮廓并标出串接关系。

## 做法

### 1 · 每个框挂在某个区域或另一个框上

代码就是上面的[简短回答](#简短回答)。`anchor`指定印张上的一个区域或另一个文本框，再指定一个点。在区域上，这个点是其安全区的九个点之一，文本框把自己对应的点放到那里：`edge: 'top'`让书名在封面上居中，顶边对齐安全区的顶边；`edge: 'bottom'`让作者框的底边落在区域底边上。在文本框上，这个点还可以是`below`、`above`、`right-of`或`left-of`。`x`和`y`以毫米为单位从这个点移动文本框。有了锚点，`rect`只提供尺寸，所以书脊变厚或开本改变时，各个框仍留在原位。

### 2 · 书名长高，副书名随之下移

<Excerpt region="cover-type" />

书名用Cinzel，30磅字、33磅行距。书名框高14毫米，正好一行。“The Masque of the Red Death”和“La máscara de la muerte”都要两行，所以框随文字长高，最多到`maxHeight`的40毫米；超过这个高度才会缩小字号。副书名用`below`锚定在书名下方2毫米处，往下移了第二行的高度。作者名锚定在区域底部，位置不变。

### 3 · 简介接着排进另一个框

简介框带有`next: 'blurb-end'`。放不下的内容在行与行之间切开，接着排进那个框；那个框在封面的Markdown里没有自己的frame。引文挂在简介下面，`blurb-end`挂在引文下面，所以第一个框加高时，三者之间的间距不变。只有第二个框也不够时，整条串接的文字才会一起缩小，默认最小到90%（`fit.minScale`）。那行金色小型大写字母是简介frame里的最后一段，所以它落在第二个框里，收住全文：

```md
:::frame{slot="front"}
:::

:::frame{slot="blurb"}
:::paragraphs{style="cover-blurb-first"}
While a plague empties his country, Prince Prospero shuts himself up …
:::

:::paragraphs{style="cover-note"}
From the Raven Edition of Poe's works
:::
:::
```

空的`front` frame让`buildCover`不再根据书的元数据在封面上排书名、副书名和作者：这些由文本框来排。

### 4 · 书脊按页数算出的平装本

<Excerpt region="binding" />

PUR胶装，16页一帖，用120 g/m²、松厚度2.2的书刊纸。书有21页，装订后32页，书脊约4.7毫米，低于默认印字所需的6毫米；所以这个版本把`spineText.minSpine`设为4.5，书脊上印书名和作者。ISBN是示例号码，不属于任何书。

### 5 · 书芯

<Excerpt region="pages" />

半书名页、书名页和版权页，然后每篇小说从奇数页开始，下沉50毫米，上面是Cinzel排的篇名和一条短红线。书眉在偶数页印作者，在奇数页印篇名，版本说明放在最后一个奇数页上收尾。

### 6 · 印张由排好的内页生成

<Excerpt region="sheet" />

`buildCover`接收页面、元数据和封面的Markdown，返回只有一页的文档，这一页就是印张。文本框成为这一页的frame，像组版页面的frame一样排版。条码数字要用OCR-B，没有哪个字体服务器提供，所以示例改用Cinzel。

### 7 · 每个框最后落在哪里

<Excerpt region="views" />

印张这一页的frame在`page.composed.frames`里，每个frame带着锚定和长高之后得到的矩形；文字接着排到别的frame时，还带有`continuesTo`。第二个视图在印张上画出六个框的轮廓，并从简介框的底边画到`blurb-end`的顶边，标出串接。

## 变化

### 把作者名挂在副书名下面

这样作者名也会随书名下移，而不是留在区域底部。

```diff
-  { name: 'author', rect: size(100, 8), anchor: { to: 'front', edge: 'bottom', y: -6 } },
+  { name: 'author', rect: size(100, 8), anchor: { to: 'subtitle', edge: 'below', y: 6 } },
```

### 把长书名缩到一行

去掉`maxHeight`，书名框保持14毫米，排版会缩小书名直到放得下：这里缩到一行，约为原字号的三分之二。

```diff
   { name: 'title', rect: size(100, 14), anchor: { to: 'front', edge: 'top', y: 8 },
-    maxHeight: 40 },
+    fit: { minScale: 0.6 } },
```

## 常见问题

- 被另一个框的`next`指向的框，接收那个框传过来的文字。不要在封面的Markdown里给它单独的frame；应该收尾的内容放在第一个框的frame末尾，就像这里的那行说明。
- 锚点指向不存在的名字、指向自己或形成循环时会报出来，文本框则留在它的`rect`上。每个锚定的框都要给一个尺寸真实的`rect`。
- `maxHeight`对旋转的框（`rotate`）不起作用，旋转的框保持`rect`的尺寸。
