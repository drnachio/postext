## できあがり

寒い谷でリンゴを育てる人のための小さな手引きです。判型は150 × 220 mmで、六つのMarkdown文書で書き、一冊の本として組みます。第I部の二つの章は、Source Serif 4 の両端揃えの一段組です。第II部の付録では組み方が変わります。台木の表と月ごとの作業暦は、小さな文字のラグ組みの二段組です。作業小屋で作業台に本を開いて読む類いの内容だからです。品種の一覧はサンセリフの三段組です。後書きは部扉を入れずに本のデザインに戻ります。判型、余白、ハイフネーション、言語はどのページでも同じです。

## 作り方

### 1 · スタイルには変える部分だけを書く

コードは上の[手短な答え](#手短な答え)にあります。章スタイルは、id、Sandbox に表示する名前、`config` を持ちます。`config` は、言語ごとの層と同じように本の設定に重ねてマージされます。オブジェクトはキーごとに、リストは `id` か `level` で項目ごとにマージされます。そのため `smallOpener` は章頭の要素の一つである題だけを指して文字を小さくし、その下の罫やほかのすべては本の設定のまま残ります。付録のスタイルが決めるのは、二段組、小さめの本文サイズ、ラグ組み、項目間のアキだけです。

本全体に属する設定もあります。`page` の判型・解像度・製本、言語と書字方向、数字、フォント、印刷と PDF の出力です。スタイルでこれらを設定しても、その部分は無視され、`chapterStyleBookSetting` の警告が出ます。そのため付録も、章と同じ150 mmの判型とイギリス英語のハイフネーションのままです。

### 2 · 部がスタイルを指定する

<Excerpt region="chapters" />

三つ目の文書は `:::part{number="II" title="Appendices" style="appendix"}` で始まり、そこから次の部までの章はすべて付録のスタイルで組まれます。五つ目の文書は front matter で `chapterStyle: "reference"` と独自のスタイルを指定し、こちらが部のスタイルより優先されます。本では、最初の文書の front matter だけが本全体のものです。二つ目以降の文書では `chapterStyle:` の行だけが生きます。

<PageShot page={9} crop="0,0.05,1,0.66" caption="付録C。部の二段組に代わって、この章独自のスタイルであるサンセリフの三段組。" />

### 3 · 部扉のある部と、ない部

<Excerpt region="parts" />

`:::part` はそれぞれ部扉を開き、部の番号と題を緑の帯に置きます。後書きは `:::part{title="Afterword" page=false}` で始まります。部扉は刷られず、この部はスタイルを指定していないので、その章はまた本の設定で組まれます。`page=false` の部は、付録のあとに続けて置く後付に向いています。

<PageShot page={6} crop="0,0,1,0.45" caption="第II部の部扉。" />

### 4 · 一つの章頭を二つの大きさで

<Excerpt region="opener" />

章頭はページの幅いっぱいに広がるので、付録では二つの段の上をまたぎ、本文はその下から二段で始まります。付録と参照用のスタイルは、要素の id を通じて題を16 ptに、章頭下げを24 mmに縮めます。本の後ろのほうの内容は場所を取らず、題は本文よりはっきり大きいままです。

### 5 · 柱は本の設定から

<Excerpt region="running-heads" />

左ページの柱に書名、右ページの柱に章名が入ります。どのスタイルも柱を変えないので、本のどの部でも柱は同じです。

## アレンジ

### 本全体の設定をスタイルで変えようとする

判型や言語を設定したスタイルは、そのキーについては無視されます。キーごとに `chapterStyleBookSetting` の警告が出て、付録は本の判型のままです。

```diff
   { id: 'appendix', name: t({ en: 'Appendix', es: 'Apéndice' }), config: {
+    page: { width: mm(170) }, locale: 'fr',
     layout: { layoutType: 'double', gutterWidth: mm(6) },
```

### デザインを別の本で使う

コマンドラインツールは、本のデザインを章スタイルも含めてデザインファイルに書き出し、`--design` で別の本をそのデザインで組みます。[design コマンド](/ja/docs/command-line#design)を参照してください。

```bash
postext design apples.postext -o handbook.postext
postext pdf pears/ --design handbook.postext -o pears.pdf
```

## よくあるつまずき

- `:::part` の行は章の冒頭、見出しの前に置きます。章の本文が始まったあとに部の行を置くと `partStyleMidChapter` が出て、スタイルは次の章から始まります。
- `chapterStyles` にないスタイル名を書くと `chapterStyleUnknown` が出て、その章は本の設定で組まれます。
