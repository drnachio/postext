## できあがり

架空の野鳥観測所の冬の会報 *Tideline* の 2 ページ。判型は 225 × 297 mm、60 mm の三段組です。扉の緑の帯の下に河口の写真が横に走り、水彩の図版四点がそれぞれ一段幅に鳥のまわりで切り抜かれて並びます。図版には Libre Franklin の両端揃えのキャプションと短い注がつきます。記事の最後は最大個体数の表です。この号を二度組みます。一度目は既定値のままです。キャプションは一行ずつ改行され、単語は分割されないので、60 mm の段で *Acrocephalus scirpaceus* を含む行は四語に引き伸ばされます。二度目はキャプション、注、表のセルにハイフネーションを加え、語間が本文とそろいます。

## 作り方

### 1 · キャプションを本文と同じように組む

コードは上の[手短な答え](#手短な答え)にあります。`captionStyle.hyphenation: true` を指定すると、キャプションは `hyphenation: true` の段落スタイルと同じように分割されます。両端揃えのとき、本文のパターン（`locale`）とハイフンの規則で分割し、本文自体のハイフネーションが切ってあっても働きます。`bodyText.optimalLineBreaking` が有効なら、キャプション全体を Knuth–Plass の改行処理でまとめて改行し、語間は本文の `minWordSpacing` と `maxWordSpacing` の範囲に収まります。ラベル *Figure 4.* は分割されません。`note.hyphenation` は、キャプションの下の行 `Resource.note` に同じことをします。

`lineHeight` はキャプションに独自の行送りを与えます。ここでは 8.2 pt の文字に 10.8 pt です。`note.lineHeight` は 6.8 pt の注に 8.8 pt を与えます。`em` で書くと、それぞれ自分の文字サイズが基準になります。指定しなければ、どちらも本文の行送りを文字サイズの比で使います。

### 3 · 左揃えのセルにハイフネーション

<Excerpt region="table" />

`tableStyle.hyphenation: true` は、各セルを最適な改行処理でまとめて改行します。セルは左揃えなので、単語が分割されるのは左揃えの文章が単語を分割する場合だけです。`bodyText.hyphenation.ragged: true` が必要で、しかも単語をまるごと次の行に送ると `zone` より広い空きが残るときに限ります。既定のゾーン 3 em は 7.4 pt で 7.8 mm になり、20 mm のセルには広すぎるので、このデザインでは 1.5 em にしています。本文は両端揃えなので、左揃え用のスイッチが効くのは表、奥付、表のキャプションだけです。表のキャプションは、その資源タイプが表の上に左揃えで置きます（`resourceTypes[].captionStyle`）。名前つきの表スタイルも同じ項目 `tableStyles[].hyphenation` を受け付けます。

### 4 · 鳥のまわりで切り抜いた図版

<Excerpt region="plates" />

図版は 1200 × 600 ピクセルで、広いクリーム色の地の中央に鳥がいます。`Resource.crop` は各鳥のまわりの部分だけを残し、図は段の中でその形になります。ページは図版と同じクリーム色 `#f6f3ea` で刷るので、見えるのは絵の縁で、ファイルの縁ではありません。キャプション、注、代替テキストは言語ごとのコンテンツファイルに、資源ごとに一つのブロックとして置きます。

### 5 · 色面の上の扉

<Excerpt region="opener" />

扉は高さ 100 mm の緑の帯を描き、そこに会報の題字、見出しの肩、タイトル、リードを置きます。その下に高さ 66 mm の河口の写真が判型の全幅に広がります。`minHeight` によって三つの段は写真の 6 mm 下から始まり、帯と写真で最初のページの半分以上を占めます。

## アレンジ

### 図のキャプションだけを分割する

資源タイプの `captionStyle` も同じ項目を受け付け、文書全体の設定より優先されます。そのため一つのタイプだけにハイフネーションをかけられます。

```diff
 const resourceTypes = defaultResourceTypes(LANG).map((type) => ({ ...type,
   numberingTemplate: '{n}', resetOn: 'never',
+  ...(type.id === 'figure' && { captionStyle: { hyphenation: true } }),
```

### 左揃えのキャプション

`hyphenation: true` の左揃えのキャプションは、`bodyText.hyphenation.ragged` が有効であれば、左揃えの文章のハイフネーションゾーンの中で単語を分割します。

```diff
-  align: 'justify',
+  align: 'left',
```

## よくあるつまずき

- `bodyText.hyphenation.ragged` が無効だと、左揃えのキャプションや `hyphenation: true` のセルは最適な改行処理で改行されますが、単語は分割されません。
- `bodyText.optimalLineBreaking` がないと、キャプションは一行ずつ改行されます。単語の分割はそれでも行われます。
