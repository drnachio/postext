## 成品一览

《The Wexcombe Lantern》是一份虚构的海滨周报，这一期出版于1933年6月，版面是280 × 430 mm的小报，分四栏，栏间有线：窄体报头，一篇头条配一张横跨三栏的图片，另一篇配两栏宽的图片，还有潮汐表、分类小广告和一个体育版。每张图片都是一段五秒的黑白影片。印刷版里，以及查看器下方的平面页面里，每张都是它的首帧。在Folio里，它是一份印在浅色新闻纸上的对折报纸，打开的版面上的图片同时动起来，而且一直动：市长在讲话，女飞行员在挥手，渔夫在笑，守门员扑出去又站起来。页面本身什么也不画；版式就是一份普通的报纸，其余交给这些片段。

## 做法

### 1 · 把每张图片做成和其他片段一起循环的视频

代码就是上面的[简短回答](#简短回答)。视频资源把海报帧当作图片印出，所以这些片段可以代替照片，也像照片一样带图注。三个播放器选项让页面动起来：`autoplay`在片段所在的页面显示时开始播放（总是静音，这是浏览器的要求），`loop`让它从头再放，`exclusive: false`让它和其他片段同时播放。视频默认是独占的：一段开始播放，其他正在播放的都会暂停，这适合讲课视频，却不适合一整版会动的照片。播放标记和二维码都关掉了，所以纸上的片段看起来就是新闻照片。

### 2 · 给每段循环视频在网格上安排位置

<Excerpt region="clips" />

版式是`layoutType: 'multiple'`加`columnCount: 4`。浮动体的`columns`决定它占几栏：市长占三栏，女飞行员、渔夫和女演员各占两栏，钟楼占一栏。跨几栏的浮动体会占据一组顶端齐平的空栏的顶部，或者占据引用它的那一栏及其后各空栏的底部，所以`::resource`行放在哪里，决定了它落在哪个空位。市长的片段在第一段之后引用，于是第1栏留给正文，图片排在第2到第4栏上方。

### 3 · 排报头和各版的版名

<Excerpt region="nameplate" />

头版的一级标题就是报名，由一个设计槽位画出：上方两个报眼，报名用Oswald大写字母，日期行夹在一细一粗两条线之间。内页以3 pt横条上的红色栏目旗标开头（`pages`区域），除第一页外，每页顶部都有页码行。

### 4 · 在Folio里打开报纸

<Excerpt region="folio" />

`config.folio`把报纸放在日光下的橡木桌上：45 g/m²的新闻纸，能透出下一页；`binding.type: 'folded'`表示纸张对折一次，一张套一张，没有订书钉，也没有书脊，报纸就是这样叠起来的。Folio把打开的跨页上的所有片段画进同一张纹理，一次最多八段；每次翻页停在某一页，它就开始播放这一页上自动播放的循环片段，这一页翻走时就停下。点击一段独占视频，它仍会单独带声音播放，循环片段等它停下再继续。

## 变化

### 让读者自己开始每段片段

去掉`autoplay`，图片在读者点击之前一直静止；开始播放之后，循环片段照样一起播放。

```diff
-  player: { autoplay: true, loop: true, muted: true, exclusive: false, controls: false },
+  player: { loop: true, muted: true, exclusive: false, controls: false },
```

### 一段带声音的独占片段

单独一段视频可以保留默认值，按自己的方式播放：在这个资源的`video`上设置`player: { exclusive: true, muted: false }`，它开始播放后，循环片段会等到它结束。

## 常见问题

报纸的一个分版是一个另起一页的一级标题，浮动体从不越过它。在本版最后一页找不到空位的图片，会单独排在下一版之前的一页上，所以要让文字适合版面：这里电车那篇报道转到第2页，而不是把女飞行员挤出头版。
