## できあがり

『The Wexcombe Lantern』は、1933年6月の号という設定の架空の海辺の週刊紙です。280 × 430 mmのタブロイド判のページを、罫で区切った4段に組みます。長体の題字、3段にまたがる写真を添えたトップ記事、2段の写真を添えたもう1本の記事、潮汐表、案内広告、スポーツ面が入ります。写真はどれも5秒の白黒映画です。印刷では、またビューアーの下の平面のページでは、どれも最初のフレームです。Folioで淡い新聞用紙の折った新聞として開くと、開いたページの写真がいっせいに動き、動き続けます。市長が話し、飛行士が手を振り、漁師が笑い、ゴールキーパーが飛び込んではまた立ち上がります。ページは何も描いていません。レイアウトはふつうの新聞で、動きはクリップが受け持ちます。

## 作り方

### 1 · どの写真もほかと一緒にループするクリップにする

コードは前の[手短な答え](#手短な答え)にあります。動画リソースはポスター画像を図版として印刷するので、クリップは写真の代わりになり、写真と同じようにキャプションが付きます。ページを動かすのはプレーヤーの3つのオプションです。`autoplay`はページが表示されたときにクリップを始め（ブラウザーの要件どおり常にミュート）、`loop`は最初から再生し直し、`exclusive: false`はほかのクリップと並行して再生させます。既定では動画は排他的で、再生を始めるとほかに再生中のものはすべて一時停止します。講義には合っていますが、動く写真を並べたページには向きません。再生マークとQRコードはオフにしてあるので、紙の上のクリップは報道写真として読めます。

### 2 · ループごとにグリッド上の位置を決める

<Excerpt region="clips" />

レイアウトは`layoutType: 'multiple'`で、`columnCount: 4`です。フロートの`columns`が占める段数を決めます。市長は3段、飛行士、漁師、女優は2段、時計塔は1段です。複数の段にまたがるフロートは、上端のそろった空いた段の並びの頭に入るか、それを参照した段とそれに続く空いた段の下端に入ります。そのため、`::resource`の行をどこに置くかで空き位置が決まります。市長は最初の段落の後で参照されるので、1段目は本文に残り、写真は2段目から4段目の上に入ります。

### 3 · 題字と各面の欄名を組む

<Excerpt region="nameplate" />

第1面のレベル1見出しは新聞の名前で、デザインスロットから描きます。上に2つの耳、Oswaldの大文字の題字、細い罫と太い罫に挟まれた日付行です。中面は3 ptの帯の上の赤い欄名で始まり（`pages`リージョン）、第1面を除く各ページの頭にノンブルの行が付きます。

### 4 · Folioで新聞を開く

<Excerpt region="folio" />

`config.folio`は新聞を昼の光の中でオークの机に置きます。45 g/m²の新聞用紙には次のページが透けて見えます。`binding.type: 'folded'`は、紙を一度だけ折って一方を他方の中に重ねたもので、ホチキスも背もありません。新聞はこう組まれています。Folioは開いた見開きのクリップをすべて一つのテクスチャーに描き（一度に8本まで）、ページめくりがそのページで止まるたびに自動再生のループを始め、ページがめくられると止めます。排他的な動画をクリックすれば、これまでどおり音声付きで単独で再生され、ループはそれが止まるまで待ちます。

## アレンジ

### クリップを読者に始めさせる

`autoplay`をなくすと、読者がクリックするまで写真は止まったままです。一度始まれば、ループはやはりそろって再生されます。

```diff
-  player: { autoplay: true, loop: true, muted: true, exclusive: false, controls: false },
+  player: { loop: true, muted: true, exclusive: false, controls: false },
```

### 音声付きの排他的なクリップを1本

1本の動画だけを既定のままにして、単独で再生させることもできます。そのリソースの`video`に`player: { exclusive: true, muted: false }`を設定すると、それを再生し始めたとき、ループはそれが終わるまで止まります。

## よくあるつまずき

新聞のセクションは新しいページを始めるレベル1見出しで、フロートはそれを越えません。セクションの最後のページに空き位置のない写真は、次のセクションの前に単独のページに組まれます。そのため原稿をページに合わせてください。ここでは、飛行士を第1面から押し出す代わりに、路面電車の記事を2ページ目へ送っています。
