## できあがり

袖付き並製本に入れたベッケルの二つの伝説を、もう一度綴じて120 × 190 mmの上製本にします。37ページはそのままです。この本には版が二つになり、それぞれに製本の仕方とISBNがあります。上製本の版からは、製本所に渡す展開図が四枚出ます。表紙は濃い緑のクロス張りで、表表紙と背に書名と著者名を金箔で押します。カバーには絵、紹介文、バーコード、二つの袖が入ります。表紙の内側には絵入りの見返しが二枚。前はドゥエロ川の上のソリア、後ろは二つ目の伝説の泉です。

## 作り方

### 1 · 本文は一つ、版は二つ

コードは上の[手短な答え](#手短な答え)にあります。二つの版は同じ`folio.paper`と同じ組み上がったページを読みます。37ページは16ページ折3折に切り上げられ、240 µmの紙が24枚です。並製本は糊の分を足して背幅6.3 mm。上製本はさらに2 mmの板紙を2枚足して、背幅10.3 mmになります。ISBNは版ごとに一つで、どちらもどの本にも割り当てられていない出版社記号の見本番号です。背を角背にしたのは、6 mmに満たない本文は丸背にするには薄すぎるからです。`case-round`にすると3 mm足して丸背にします。表紙をクロス（`cloth`）にしたのは、絵も文字もバーコードもカバーに載っていて、その下は箔押しの書名で足りるからです。

### 2 · 表紙：くるみ、溝、チリ

<Excerpt region="sheets" />

並製本の表紙は仕上がり寸法で断ち、袖を小口で折り込みます。上製本の表紙は二枚の板紙をくるむ表装材です。板紙は背の側でページより7 mm狭く切り、天、地、小口でページから3 mm出します（チリ）。そのため116 × 196 mmになります。板紙と背のあいだには7 mmの溝があり、表紙はそこで曲がります。周りには15 mmのくるみが付いて板紙の縁に折り返されるので、クロスの地は286.3 × 226 mmの展開図いっぱいまで広がります。表紙はISBNを外した版から作るので、クロスにバーコードは入りません。表紙の文章も空にしているので、表表紙と背はメタデータから書名、副題、著者名だけを取り、ここでは金色にしています。

### 3 · カバーは表紙のデザインと文章をそのまま使う

<Excerpt region="cover-type" />

カバーは本の`cover`、同じ段落スタイル、並製本と同じ表紙のMarkdownから作ります。面は広くなり、板紙一枚と溝、さらに板紙の縁に回る3 mmで、合わせて126 mmです。袖はページ幅の3分の2の80 mmになり、これがカバーの標準値です。絵は表の面を折り目まで埋め、バーコードは書店が読み取る裏の面に入ります。

### 4 · 二枚の見返しを一つの文書に

<Excerpt region="endpapers" />

見返しはページ二つ分の幅があります。片方は板紙に貼り付け、もう片方の遊び紙はページと同じようにめくれます。前見返しでは貼る側が左、後ろ見返しでは右に来ます。展開図はどちらも246 × 196 mmで、天、地、外側に3 mmの塗り足しがあり、折り目にはありません。折り目には5 mmの糊しろがあり、ここで本文に貼り付けます。折り目が通るので、どちらの絵も中央を静かにしてあります。二枚は同じ寸法なので、一つの文書に1ページずつ収めます。

## アレンジ

### クロスを張らずに表紙を印刷する

`looks`から表紙の項目を消すと、表紙は本のデザインを使います。夜の地色で、表表紙に絵が入ります。

```diff
 const looks = {
-  cover: { cover: { background: col('cloth') }, paragraphStyles: gold },
   endpaperFront: { cover: { image: { resourceId: 'soria' } } },
```

### 丸背にする

もっと厚い本なら、`case-round`で表紙の背が3 mm広がり、カバーの背もそれに合わせて広がります。

```diff
-    { id: 'hardcover', name: t({ en: 'Hardcover', es: 'Cartoné' }), binding: 'case-flat',
+    { id: 'hardcover', name: t({ en: 'Hardcover', es: 'Cartoné' }), binding: 'case-round',
```

## よくあるつまずき

- キャプチャしたページの並びでは、展開図は本のページの後に来ます。表紙が38、カバーが39、見返しが40と41です。本が1ページ増えると、番号がすべてずれます。
- カバーの下のクロス装の表紙にバーコードはいりません。ISBN付きの版をbuildCoverに渡すと、裏表紙にもバーコードを刷ってしまいます。
