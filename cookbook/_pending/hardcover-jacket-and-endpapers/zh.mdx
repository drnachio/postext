## 成品一览

还是那本带勒口平装书里贝克尔的两篇传说，这次再装订一遍，做成120 × 190毫米的精装书。37页书页原样不动。这本书现在有两个版本，各有自己的装订方式和ISBN，精装版要交给装订厂四张展开图。书壳裱深绿色的布，封面和书脊上烫金印出书名和作者。护封上是那幅画、简介文字、条码和前后两个勒口。封面里侧是两张彩绘环衬：前面是杜罗河畔的索里亚，后面是第二篇传说里的那眼泉水。

## 做法

### 1 · 一个书芯，两个版本

代码就是上面的[简短回答](#简短回答)。两个版本读取同一个`folio.paper`和同一批排好的书页：37页，向上取整为三个16页的书帖，24张，每张厚240微米。平装版加上胶的余量，书脊6.3毫米。精装版再加上两块2毫米的纸板，书脊10.3毫米。每个版本有自己的ISBN，两个都是出版社号段里的示例号码，不属于任何一本书。书脊做成平背，因为不到6毫米厚的书芯太薄，没法起圆；换成`case-round`会再加3毫米，做成圆背。书壳用布面（`cloth`），因为画、文字和条码都已经在护封上，底下烫一个书名就够了。

### 2 · 书壳：包边、书槽和飘口

<Excerpt region="sheets" />

平装书的封面按成品尺寸裁切，勒口在前口折进去。精装书的书壳是一层包住两块纸板的面料。每块纸板在书脊一侧比书页窄7毫米，在天头、地脚和前口比书页多出3毫米（飘口），所以是116 × 196毫米。每块纸板和书脊之间留一道7毫米的书槽，书壳在这里弯折。四周还有15毫米的包边翻折到纸板边上，所以布面的底色一直铺到286.3 × 226毫米的整张展开图。

每张展开图都用同一个`config`和同一份封面文字来做。书壳的设计来自`cover.sheets.case`，只有一层布面底色；文字来自标了`sheet="case"`的文本框：封面纸板和书脊上的书名、副书名和作者，用的`case-`样式就是护封的样式改成金色；封底纸板上放一个空文本框，布面上就不会出现内容简介。条码只印在护封上，收银台扫的就是它。

### 3 · 护封沿用封面的设计和文字

<Excerpt region="cover-type" />

护封在`cover.sheets`里没有自己的一项，所以用书本身的`cover`和不带`sheet`的文本框，段落样式和封面Markdown都与平装版相同；书壳的文本框在这里不用，护封的封面和书脊就从元数据里取文字。它的面板更宽：每块盖住一块纸板、书槽，再多3毫米折到纸板边上，一共126毫米。勒口宽到80毫米，是书页宽度的三分之二，也是护封的默认值。画铺满封面面板，一直到折线，条码在封底面板上，书店在那里扫码。

### 4 · 两张环衬放在一个文档里

<Excerpt region="endpapers" />

一张环衬有两页宽：一半粘在纸板上，另一半是可以翻动的扉页。前环衬粘在纸板上的那一半在左边，后环衬在右边。每张展开图246 × 196毫米，天头、地脚和外侧各有3毫米出血，折线处没有出血，那里有一条5毫米的胶条把它粘在书芯上。两幅画都让中间保持安静，因为折线从那里穿过。两张展开图尺寸相同，所以放进同一个文档，每页一张。每幅画都是对应环衬在`cover.sheets`里的设计，横跨两页。

## 变化

### 印刷书壳，不用布面

把`case`从`cover.sheets`里删掉，书壳就用书本身的设计：夜色底子，画在封面纸板上。书壳自己的文本框照样把书名印成金色。

```diff
   sheets: {
-    case: { background: col('cloth') },
     endpaperFront: { image: { resourceId: 'soria' } },
```

### 做成圆背

书再厚一些，`case-round`会给书壳的书脊加3毫米，护封的书脊也跟着变宽。

```diff
-    { id: 'hardcover', name: t({ en: 'Hardcover', es: 'Cartoné' }), binding: 'case-flat',
+    { id: 'hardcover', name: t({ en: 'Hardcover', es: 'Cartoné' }), binding: 'case-round',
```

## 常见问题

- 在截取的页面列表里，展开图排在书页后面：书壳是第38页，护封第39页，环衬第40和41页。书多一页，这些编号都会跟着变。
- 在精装书上，`sheet="cover"`既指书壳，也指平装书的封面；`sheet="case"`只指书壳。某张展开图自己的文本框只在这张图上替换同一区域的通用文本框，空的文本框就让这块区域留白。
