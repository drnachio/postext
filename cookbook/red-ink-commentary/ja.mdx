## できあがり

脂硯斎の評語を伝える甲戌本『石頭記』（The Story of the Stone、『紅楼夢』）第1回の冒頭を、評本として6ページに組み直します。判型は16开（184 × 260 mm）、縦組みで右綴じです。曹雪芹の本文はNoto Serif TCで、1行36字、1ページ18行です。写本では、この抜粋の61の傍らの評語（側批）が行の横に朱で書かれています。Postextは2つの行のあいだには何も組まないので、この版では各評語を行の中に移し、注釈する語句の直後に、半分の大きさの朱の2行に折りたたんで入れます。刊本の評本が雙行夾批を組むのと同じやり方です。10の頭注の評語（眉批）は、本文の上の42 mmの段に朱の楷書体で、論じる箇所の上に立ちます。読者は本文と評語を一度に追えます。

## 作り方

### 1 · サイド段を天の余白に変える

コードは上の[手短な答え](#手短な答え)にあります。縦組みのページは横組みのページを90度回したものなので、[段と半段のレイアウト](/ja/docs/configuration-page-layout#レイアウトの種類)のサイド段はページを横切る段になり、`sideColumnSide: 'left'`でその段が天に来ます（[縦組み](/ja/docs/configuration-page-layout#縦組み)）。[文字グリッド](/ja/docs/configuration-east-asian#文字グリッド)は`sideColumnPercent: 19`を本文の10字分（120 pt）に、段間を2字分に丸めます。段間罫は評語と本文のあいだの細罫になります。評語のスタイルにはボックスがありません。7 ptの楷書体で1行17字、この大きさなら10の評語のどれも最後の行が1字だけになりません。`snapToGrid: false`で、評語は本文の21 ptではなく自身の10 ptの送りで積み重なります。

どちらの評語も、写本で書かれている位置に印を付けます。傍らの評語は[`:warichu[…]`](/ja/docs/document-format#中国語の記号ルビ割注)のスパンで、`cjk.warichu`がその色を決めます。頭注の評語は、論じる箇所の直前に`span="side"`でフェンスを置いたボックスです。

```markdown
:::callout{type="meipi" span="side"}
妙！自謂落墮情根，故無補天之用。
:::

原來女媧氏煉石補天之時，:warichu[補天濟世，勿認真，用常言。]于大荒山:warichu[荒唐也。]…
```

### 2 · 回の番号と対句を最初の行に縦に組む

<Excerpt region="opener" />

縦組みのページでは、章扉は流れの座標系で組まれます。文字は下へ進み、`below`は左を意味し、`x`のずらしは要素を行の下方向へ動かします。最初に朱の黒体で書名、次に30 ptの第一回を自身の2字分下げて、続いて[見出しの属性](/ja/docs/document-format#見出しの属性) `{a="…" b="…"}`から対句の2句をさらに下げて組みます。こうして刊本の回目のように、番号と対句がページを段々に下がっていきます。`minHeight: mm(46)`で、対句と本文のあいだに空いた行を1行確保します。

### 3 · 柱を小口に沿って縦に流す

<Excerpt region="fore-edge" />

これは[縦組みのテキスト要素](/ja/docs/configuration-page-layout#縦組みのテキスト要素)の小口側の柱です。`anchor.to: 'outer'`は背から遠い側の余白、右綴じの本では奇数ページの左、偶数ページの右を指します。`writingMode: 'vertical-rl'`で文字をページの下方向へ組みます。ここでは版面に評語の段も含まれるので、「天から4字下」は朱の評語の上端から測ります。`trad-chinese-informal`でノンブルは一〜六と印字されます。

### 4 · 各書体を、それが組む文字だけで読み込む

<Excerpt region="voices" />

Fontsourceは中国語の書体を、ウェイトごとにおよそ100のファイルに分けて配信しています。宋体はサンプル全体を標準のウェイトで組み、ボールドは第一回だけに使います。楷書体は頭注の評語と版の説明だけ、黒体は柱、ノンブル、奥付だけを組むので、各呼び出しは自分の文字に必要なファイルだけを取得します。`vertical: true`で、Canvas用に各書体の縦組み用の約物も読み込みます。

### 5 · 2つのインク

<Excerpt region="palette" />

写本が書かれたとおり、ページは2色で印刷します。本文は温かみのある黒、すべての評語と回のキッカーは朱で、朱はそれ以外には使いません。朱は用紙に対して5.5 : 1で読め、傍らの評語の6 ptの行にも十分です。`main-color`が朱を指しているので、設定で指定し直していない既定値も青ではなく朱で印字されます。

## アレンジ

### 評語を1色で印刷する

1色刷りにするなら、注は墨でかっこに入れ、頭注の評語は落ち着いたインクで組みます。かっこは本文の大きさで、注の最初の行の前と最後の行のあとに組まれます。

```diff
-  warichu: { color: col('vermilion') },
+  warichu: { color: col('ink'), open: '〔', close: '〕' },
-  body: { fontFamily: KAI, fontSize: pt(7), lineHeight: pt(10), color: col('vermilion'),
+  body: { fontFamily: KAI, fontSize: pt(7), lineHeight: pt(10), color: col('muted'),
```

### ラテン文字の版と比べる

横組みのページで同じ手法を使ったのが<RecipeLink slug="annotated-classic-glosses">小口の余白に傍注を組んだ古典の注釈版</RecipeLink>です。サイド段は小口側に立ち（`sideColumnSide: 'outer'`）、各注釈は説明する段落の上ではなく横に置かれます。

## よくあるつまずき

- 頭注の評語は、そのフェンスの位置まで本文が進んだ行と同じ位置に立つので、フェンスは論じる箇所の直前に置きます。あとに置くと、評語は次の段落の横から始まります。フェンスは2つのブロックのあいだに置くもので、段落の中には置けません。そのため写本が長い段落の奥深くの語句に評語を付けている箇所では、この版はそこで段落を分けています。石頭聽了の前、廟傍住着の前、そして石の台詞の中で1回、竟不如我の前です。最後の箇所では、2つの段落にまたがる引用と同じように、新しい段落を「で始め直しています。
- 段に入るのは、そのページに入る分だけです。段の残りに収まらない長い評語は、最後の行が本文の左端にそろうまで右へ戻り、それでも収まらなければ、そのあとにフェンスを置いた評語すべてとともに次のページを待ちます。各評語は本文の行の位置から始まり、前の評語とのあいだに本文1行分をあけます。石の台詞に付いた写本の3つの評語は、段の11行分を占めます。翻刻にあるとおり今之人の前にフェンスを置くと、最後の斯亦太過が<PageRef page={5}>5ページ</PageRef>まで待つことになり、そこにある評語を1つずつ後ろへ押し出しました。この版では台詞を1文早く、竟不如我の前で分けているので、3つとも<PageRef page={4}>4ページ</PageRef>に立ちます。
- `avoidWidows`を有効にすると、ページの最終行で始まるはずの段落はまるごと次へ送られ、ページは1行短く終わり、その段落の前にフェンスを置いた評語は取り残されます。中国の本ではどの行から段落を始めてもかまわないので、`avoidWidows: false`にして各ページを18行で埋めます。`avoidOrphans`は有効のままにします。段落の最終行だけがページの先頭にひとり立つこと（孤行）は、中国の編集者が避けるものです。
- 続けて書かれた2つの傍らの評語は、2行に折りたたむと1つの注のように読めてしまいます。Markdownでは、そのあいだに全角スペース（U+3000）を入れています。
- Noto Serif TCには、縂、竒、数など、写本の字形の一部のグリフがありません。Canvasはそれをシステムの書体で補い、PDFは空白のまま残してC25の下に列挙します。この版ではそれらを標準の字形で組み、書体にある異体字は残しています。
