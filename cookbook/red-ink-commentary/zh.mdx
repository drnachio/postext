## 成品一览

甲戌本《石头记》是带有脂砚斋评语的抄本，这里把它第一回的开头重排成评点本的六页：16开，184 × 260 mm，竖排右翻。曹雪芹的正文用Noto Serif TC，每列36字，每页18列。抄本把节选中的61条侧批用红笔写在各列旁边。Postext不在两列之间排任何内容，所以本版把每条侧批移入行内，紧跟在它所评的文字之后，以半号字折成两行朱字，就像刻本评点排双行夹批那样。十条眉批用红色楷体排在正文上方42 mm高的天头一栏里，位于所评段落上方，读者读正文和评语一气呵成。

## 做法

### 1 · 把侧栏变成天头

代码就是上面的[简短回答](#简短回答)。竖排页面是把横排页面旋转90度，所以[一栏半版式](/zh/docs/configuration-page-layout#版式类型)的侧栏变成横贯页面的一栏，`sideColumnSide: 'left'`把这一栏放到天头（[竖排](/zh/docs/configuration-page-layout#竖排)）。[字符网格](/zh/docs/configuration-east-asian#字格)把`sideColumnPercent: 19`取整为正文的10个字，即120 pt，栏间距取整为两个字；栏线成为评语与正文之间的细线。评语样式不带框：7 pt楷体，每列17字，这个字号下十条评语没有一条以只有一个字的列结尾；`snapToGrid: false`让评语按自己10 pt的间距排列，而不是正文的21 pt。

两种评语都标在抄本原有的位置。侧批是[`:warichu[…]`](/zh/docs/document-format#中文标记注音和双行夹注)行内片段，由`cjk.warichu`着色；眉批是一个用`span="side"`围起的框，紧放在所评段落之前：

```markdown
:::callout{type="meipi" span="side"}
妙！自謂落墮情根，故無補天之用。
:::

原來女媧氏煉石補天之時，:warichu[補天濟世，勿認真，用常言。]于大荒山:warichu[荒唐也。]…
```

### 2 · 把回数和回目排在开头几列

<Excerpt region="opener" />

在竖排页面上，章首按文字流的坐标排版，所以文字向下走，`below`指向左边，`x`偏移让元素沿列向下移。先是红色黑体的书名，然后是30 pt的第一回，下移两个自身字高，再是来自[标题属性](/zh/docs/document-format#标题属性)`{a="…" b="…"}`的回目上下联，又下移一次，于是回数和回目像刻本回目那样逐级向下错开。`minHeight: mm(46)`在回目和正文之间留出一列空白。

### 3 · 书口处的竖排书眉

<Excerpt region="fore-edge" />

这些是[竖排文字元素](/zh/docs/configuration-page-layout#竖排文本元素)中的书口书眉：`anchor.to: 'outer'`指远离书脊的页边距，在右翻书里是右页的左边、左页的右边；`writingMode: 'vertical-rl'`让文字竖排。这里的版心包括评语一栏，所以“天头下四格”是从红色评语的顶端量起。`trad-chinese-informal`把页码印成一到六。

### 4 · 每种字体只加载它要排的文字

<Excerpt region="voices" />

Fontsource把每种中文字体按字重各拆成约一百个文件。宋体用常规字重排整个样张，只有第一回用粗体；楷体只排眉批和本编说明；黑体只排书眉、页码和版权页，所以每次调用只取它自己的字符所需的文件。`vertical: true`还会为Canvas加载每种字体的竖排标点。

### 5 · 双色

<Excerpt region="palette" />

页面用两种颜色印刷，和抄本的书写一致：正文用暖黑，每条评语和本章的眉题用朱红，别的都不用。朱红在纸色上的对比度为5.5 : 1，足够排6 pt的侧批双行。`main-color`指向朱红，所以配置里没有重设的默认值都印成红色，而不会是蓝色。

## 变化

### 评语用单色印刷

单色印刷时，把夹批排成黑色并加括号，眉批用浅墨色；括号以正文字号排在夹批第一行之前和最后一行之后。

```diff
-  warichu: { color: col('vermilion') },
+  warichu: { color: col('ink'), open: '〔', close: '〕' },
-  body: { fontFamily: KAI, fontSize: pt(7), lineHeight: pt(10), color: col('vermilion'),
+  body: { fontFamily: KAI, fontSize: pt(7), lineHeight: pt(10), color: col('muted'),
```

### 对比拉丁文字的版本

同样的技法用在横排页面上，就是<RecipeLink slug="annotated-classic-glosses">带页边注释的古典注释本</RecipeLink>：侧栏位于书口一侧（`sideColumnSide: 'outer'`），每条注释在所释段落旁边，而不是上方。

## 常见问题

- 眉批与正文排到其围栏时所在的列对齐，所以围栏要紧放在所评段落之前；放在段落之后，评语就从下一段旁边开始。围栏只能位于两个块之间，不能放在段落内部，所以抄本评的是长段中间某句话时，本版就在那里把段落拆开：在石頭聽了之前、在廟傍住着之前，以及石头的答话中竟不如我之前一次；新段落再以「开头，就像跨两段的引语那样。
- 天头一栏只容纳本页所能容纳的内容。一条评语排不进剩余空间时，会往右退，直到它的最后一列与正文左缘对齐；仍排不下就等下一页，它之后围起的所有评语也一起等。每条评语从一个正文列开始，与前一条之间空出一个正文列。抄本对石头答话的三条评语在天头占十一列：若按抄本的位置围在今之人之前，最后一条斯亦太過会等到<PageRef page={5}>第5页</PageRef>，把那里的评语都往后推一步。本版把答话提前一句拆开，放在竟不如我之前，三条就都排在<PageRef page={4}>第4页</PageRef>。
- 开启`avoidWidows`时，一个会在页面最后一列开头的段落会整段移到下一页，这一页少排一列，围在该段之前的评语留在原页。中文书允许段落从任何一列开始，所以`avoidWidows: false`让每页排满18列。`avoidOrphans`保持开启：段落的最后一列单独排在一页开头（孤行），是中文编辑要避免的。
- 前后相连的两条侧批会折成看起来像一条的双行。Markdown在它们之间保留一个全角空格（U+3000）。
- Noto Serif TC缺少部分抄本字形，如縂、竒和数。Canvas用系统字体补上，PDF则留空并在C25下列出。本版改用这些字的通行字形，保留字体中有的异体。
