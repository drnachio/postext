## できあがり

地球科学の入門講座 *The Restless Planet* の第4モジュールです。地震を扱う4ページで、判型は 176 × 250 mm、乾いた平原を横切る断層の絵で始まります。本文のあとに練習とテストが続き、どちらも Markdown に答え付きの `:::exercise` ブロックとして書きます。印刷したモジュールには練習の解答が載り、テストの解答は載りません。画面では同じページにそのまま答えられます。練習は何度でも答え合わせとやり直しができ、テストの各問は答え合わせが一回だけで、やり直しはできず、その一回を使い切ったときに初めて解答が見られます。ページの横のパネルは、学習プラットフォームが記録する内容をまとめます。得点、テストが終わったかどうか、70 % での合否です。

## 作り方

### 1 · 二つのスタイル、二つのルール

コードは[手短な答え](#手短な答え)にあります。問題そのものは何を問うかだけを書き、ブロックの `style` がふるまいを決めます。`practice` は本の既定値のままなので、バーには答え合わせ、解答を見る、やり直すが回数の制限なしに並びます。`test` はそれを `digital` ブロックで拡張します。`maxChecks: 1`、`reset: false`、`showSolution: 'noChecksLeft'` によって、バーは「答え合わせは終わりです」まで数え、そこで初めて解答を出します。紙では同じスタイルが解答を印刷せず（`placement: 'none'`）、練習の解答は `:::solutions` の行がある位置に印刷されます。

### 2 · 保存した解答をストレージから戻す

<Excerpt region="attempt" />

`attachExercises` は各問の解答を `getItem` で読み、`setItem` で書きます。キーは `storageKey` とその問題のアンカーです。この三つのメソッドを持つオブジェクトなら何でも `localStorage` の代わりになり、学習プラットフォームは同じ JSON を生徒のデータとして保存します。ここでは答え合わせ済みのテスト三問を返し、そのうち二か所が誤り（文3を正しいとし、距離を 180 km としたもの）です。そのためページは、戻ってきた生徒が見るとおりに開きます。三問は締め切られ、解答が見られ、並べ替えの問題だけがまだ残っています。

### 3 · ページで答え、答え合わせのたびに受け取る

<Excerpt region="screen" />

`renderToHtml` がページと問題のデータを書き出し、`attachExercises` がその上に入力欄、選択肢、バーを重ねます。`onResult` は各問の準備ができたときと、答え合わせ、やり直し、解答表示のたびに呼ばれ、採点対象の正答数（`right`）と総数（`total`）、使った答え合わせの回数、締め切られたかどうか（`locked`）を受け取ります。パネルは SCORM プレーヤーと同じようにテストを集計します。テスト全体の正答数を採点数で割り、各問が答え合わせ済みか締め切りなら完了、`passingScore` 以上で合格です。ページは `dpi: 96` なので、印刷ページの 1 mm が画面の CSS の 1 mm になります。

### 4 · 同じ問題を EPUB に

<Excerpt region="epub" />

固定レイアウトの EPUB には問題のデータと、答えられるようにするスクリプトが入ります。スクリプトを実行するリーダーでは同じ入力欄と同じ制限が使え、実行しないリーダーでは書き出し側が添える解答が残ります。フォントはバイト列で渡し、ページが読み込んだのと同じ Fontsource のファイルを使います。

## アレンジ

### 学習プラットフォーム向けにまとめる

`postext-scorm` は同じ文書を受け取り、SCORM 1.2 または 2004 の zip を書き出します。中のプレーヤーがストレージと結果を LMS につなぎます。一つの SCO は含まれる問題をすべて数え、練習も含まれるので、テストだけを採点する講座では `items` でテストを独立した SCO にします（<Feature id="scorm-packages">SCORM パッケージ</Feature>を参照）。

```diff
+import { renderToScorm } from 'https://esm.sh/postext-scorm';
+const zip = await renderToScorm([doc], { version: '1.2', layout: 'fixed',
+  metadata: { title: doc.metadata.title, language: LANG }, fonts: await epubFonts(FONTS),
+  resourceBytes: (fileId) => ({ bytes: imageBytes(fileId), mediaType: 'image/jpeg' }) });
```

### 答えるそばから採点する

答え合わせボタンのない小テストにするなら、`exercises.digital` に `check: 'instant'` を指定します。即時採点では答え合わせの回数制限がなくなり、テストのスタイルは `showSolution` を保ちます。

```diff
-  digital: { passingScore: 70 },
+  digital: { passingScore: 70, check: 'instant' },
```

## よくあるつまずき

採点する問題にはすべてアンカーを付けます（`:::exercise{#test-scales}`）。解答はアンカーをキーに保存されます。アンカーがないとキーは文書内の位置から作られ、前に問題を一つ足しただけで、戻ってきた生徒に別の問題の解答が返されます。
