## できあがり

架空の翻訳財団Dar al-Dadの2025年度年次報告書です。ページは幅をA4にそろえた210 × 280 mm、書体はひとつの書体ファミリーの両半分にあたるIBM Plex Sans ArabicとIBM Plex Sansです。報告書の本体はアラビア語で、右から左へ進み、ノンブルも٢、٣と振ります。アラビア語の各段落のあとには、ひと回り小さいスレートグレーの英語版が続き、左から右へ、行末不ぞろいで組まれます。アラビア語の見出しには、反対側の端に英語のラベルが付きます。アラビア語の文中のラテン文字の名前は自分の語順を保ち、年度の数字は2回、右から読むアラビア語の表と左から読む英語の表に出てきます。スペイン語版では、2つ目の言語がスペイン語になります。

## 作り方

### 1 · 2つ目の言語は印を付けたブロックで

コードは上の[手短な答え](#手短な答え)にあります。文書はアラビア語なので、Markdownで指定しないかぎり、どのブロックも右から左です。`:::paragraphs`のフェンスや見出しに`{dir=ltr}`を付けると、そのブロックの向きが反転します。`textAlign: 'start'`は各ブロックを書き始める側へ寄せ、アラビア語なら右、英語なら左にそろえます（[文書、ブロック、インラインの方向](/ja/docs/arabic-layout#文書ブロックインラインの方向)）。アラビア語の行内にあるラテン文字の名前、:ltr[Harbour Modern Classics]はアイソレートです。bidiアルゴリズムはこれをひとかたまりの中立的な要素として扱うので、まわりのアラビア語の語やカンマは位置を変えません（[アイソレート](/ja/docs/arabic-layout#アイソレート)）。`emphasis: 'italic'`で、英語の文中の『Middlemarch』はイタリックのまま残ります。設定がどうであれ、エンジンがアラビア文字をイタリックにすることはありません。

### 2 · 方向ごとに表をひとつずつ

<Excerpt region="tables" />

アラビア語の表は文書の方向に従います。最初の列（事業名）が右にあり、`align: 'end'`で数字はセルの左端に寄ります。英語の表は`direction: 'ltr'`を指定しているので、最初の列が左に来て、`'end'`はセルの右端を指します（[左・右・始端・終端の意味](/ja/docs/arabic-layout#左右始端終端の意味)）。アラビア語の表の数字は٠–٩で、英語の表の数字は0–9で入力します。文書の数字の設定が効くのは、キャプション中の表番号جدول ١-١のように、エンジンが自分で書く数字だけです。英語の表に番号を振らない専用の種類を与えているのも同じ理由で、番号を振ると٢と印字されてしまいます。

### 3 · 1本の帯に2つの表題

<Excerpt region="cover" />

表紙は第1レベルの見出しのデザインです。デザイン要素の文字は文書の方向をとるので、アラビア語の名称と表題には何も指定しません。英語の表題は`direction: 'ltr'`を指定し、ページの左端に固定します。帯は裁ち落としに固定した深さ86 mmのボックスで、章扉の`minHeight`によって理事長のあいさつがその下に来ます。

## アレンジ

### 英語を先にする

アラビア語を読まない理事会向けの報告書なら、役割を入れ替えます。文書を英語にしてそのブロックには印を付けず、アラビア語のブロックに`{dir=rtl}`を付けます。

```diff
-  locale: 'ar', // written out, never LANG (gotcha: arabic-locale-tag)
+  locale: 'en-us', // Arabic blocks then carry {dir=rtl}
```

## よくあるつまずき

- 英語のブロックの中でも、リストの番号やキャプションのラベルなど、エンジンが書く数字は文書の数字をとります（アラビア語の報告書なら٢）。こうした表には番号を振らないリソースの種類を与えるか、数字を自分で書いてください。
