## できあがり

イタリア語で書かれた家庭菜園の暦の、3月のページです。27ページは、淡い空の下で黒い土に並ぶ苗の水彩画で始まり、84ptの月名と農村のことわざが添えられます。2段組みの本文の下には、その月のカレンダーが入ります。これはサンプルのコードが日付から計算したものです。日曜はクリーム色の列に赤字で、復活祭の日曜と月曜はピンクの上に置き、月の4つの相はその日の横に描きます。28ページはその月の作業を2段組みの囲みに並べ、10×10のコンパニオンプランツの表を緑、ピンク、クリーム色に塗り分け、対角線上に各作物の絵を置きます。1年の種まき時期を38作物、半月刻みで示す表はページより幅が広いため、90度回して29ページと30ページに組み、2ページ目で表頭を繰り返します。

## 作り方

### 1 · 表を回し、次のページへ続ける

コードは上の[手短な答え](#手短な答え)にあります。`rotate: 'ccw'`は、表を専用のページに置く全幅のフロートにします（[配置](/ja/docs/document-format#配置)）。表頭はページの左端を向き、奇数ページでも偶数ページでも背の側に寄ります。表は版面の高さ方向に組まれ、237mmのうち227mmを使います。収まる14ptのグリッド行47行分から、フロートの間隔の1行を引いた長さです。行は176mmの幅を横切って積み重なり、幅を超えると表は2つの行のあいだで切られ、2行の表頭とキャプションを付けて次のページへ続きます。キャプションの末尾には`(segue)`が付きます（[ページより高い表](/ja/docs/configuration#ページより高い表)）。回転も分割もフロートにしかできません。`position: 'here'`では回転は無視され、表は分割されません。表頭のセルは3通りに結合しています。`Coltura`は表頭の2行を縦に通し、各季節はその月の上に、各月はその2つの半月の上にまたがります。

### 2 · 日付から計算するカレンダー

<Excerpt region="calendar" />

`Date.UTC`から得る通日で各日付の曜日が決まり、グリッドは3月1日の月曜から始まって5週分続きます。復活祭はコンプトゥス（復活祭の日付計算）から、月の相は平均朔望月から求めます。この方法では相が1日前後にずれることがあり、キャプションでもそう断っています。月を描くループは、その日付をキャプションにも書き込みます。セルの画像は常にテキストの上に置かれるため、各日は月の列と日付の列の2列を取ります。月を日付と同じセルに入れると、4日だけ日付が下に押されてしまいます。日曜と祝日は色だけを変えるチップスタイルで赤にし、注記は半分の大きさのチップにします。注記のない日には2行目にワードジョイナー（U+2060）を入れ、5週の高さをそろえます。

### 3 · 貼り付けた記号から表を塗る

<Excerpt region="matrix" />

作物の組み合わせはTSVで、セルごとに記号を1つ入力します。postext 1.4.1の`parseTSV`は素のセルを作り、`headerRowCount`は設定しません。そこで作物名の行を表頭にするため、`headerRowCount: 1`を手で加えます。`columnWidths`の重みは176mmの行長に対するミリメートルで、名前に26、各作物に15です。各記号は色見本の項目を指し、`setCellBackground`がそれをセルの塗りにします。`+`と`−`も1.4emのチップで刷るので、グレースケールで複写しても表は読めます。対角線上は作物とそれ自身の組み合わせなので、そこには`setCellImage`が作物の絵を、セルの内側の幅の62%で置きます。

### 4 · 色の凡例を色見本で示す

<Excerpt region="resources" />

`:swatch{color="leaf"}`は、文字サイズの4分の3の正方形を色見本の色で塗り、本文の色で縁取ります。これらのページでは、本文中、2つのキャプション、1つの注で使っています。表の凡例はキャプションに入れます。分割した表は各部分でキャプションを繰り返しますが、注は最後の部分の下にしか組まれないからです。カレンダーは独自のリソースの種類で、キャプションの接頭辞は空です。そのキャプションは`Tabella`のラベルではなく凡例で始まります。`position: 'bottom'`と`span: 'page'`で、カレンダーと表をそれぞれのページの下端に2段にまたがって組みます。28ページは本文の最後のページです。1.4.1はそうしたページで全幅のフロートを本文の1行下まで引き上げるため、表は地の余白より10mm上で終わります。

### 5 · 共通のスタイルと表ごとの変種

<Excerpt region="styles" />

`tableStyle`で共通のスタイルを決めます。墨色の表頭にCommissionerの紙色のラベル、行のあいだにヘアライン、そしてイタリア語の続き表示の文字列です。1.4.1には英語とスペイン語の文字列しか入っていません。名前付きの各スタイルには、その表が変える点だけを書きます。カレンダーは日付をGilda Displayの15ptで組み、コンパニオンプランツの表は表頭の塗りを外します。この表と種まき表は、紙の色で幅2ptと1ptの罫を引き、塗りをタイルに切り分けます。

### 6 · 月は1枚の絵で始まる

<Excerpt region="opener" />

レベル1の見出しは要素のスロットから描きます。水彩画はページの頭に置いた画像要素で、キッカー、ことわざ、その出典は見出しの属性から取ります。1.4.1では画像要素は高さを確保しないので、`minHeight`で補います。絵の92mmに余白5mmを足し、天の余白22mmを引くと75mmで、14ptの行16行（79mm）に切り上がります。本文の1行目はページの上端から101mm、土の9mm下に来ます。題は1.5mm左へずらします。これは84ptのGilda DisplayのMのサイドベアリングで、Mのセリフがキッカーとそろいます。ことわざは同じ量だけ戻します。

## アレンジ

### 表を時計回りに回す

表頭はページの右端を向き、読者は本を反対向きに回します。

```diff
-const chartPlacement = { rotate: 'ccw' }; // a float, never 'here' (gotcha: here-table-no-split)
+const chartPlacement = { rotate: 'cw' }; // a float, never 'here' (gotcha: here-table-no-split)
```

## よくあるつまずき

- 表のセルの画像は、常にセルのテキストの上に描かれ、テキストと同じそろえ方になります。数字の横にアイコンを置くには、カレンダーが月にしているように、アイコンに専用の列を与えます。
- 分割した表の下の注は最後の部分にしか出ません。どの部分にも要る凡例はキャプションに入れます。
