## できあがり

『史記』の読本のための見本ページ3枚を、中国の大32開の本の仕上がり寸法、140 × 203 mmで組みます。本文は「項羽本紀」の冒頭で、古典の校訂本の全式標点を施しています。人物、地名、国、王朝のすべてに直線を、書名と篇名のすべてに波線を付け、どちらも朱で刷ります。1ページ目は前書きと編者の凡例を楷書体で組みます。2ページ目と3ページ目は同じMarkdownを縦組みと横組みで2度組むので、見開きで印の位置の違いがわかります。縦組みでは名前の左、横組みでは名前の下です。本は右綴じで、藍色の帯がそれぞれのタイトルを載せます。<RecipeLink slug="critical-edition-line-numbers">No. 044、1645年版の本文による『Lycidas』</RecipeLink>では、名前をヨーロッパの流儀でイタリックにして区別しています。

## 作り方

### 1 · 印はマークアップが付け、位置は組み方向が決める

コードは前出の[手短な答え](#手短な答え)にあります。`:name[項梁]`と`:book[史記]`は文字をテキストに残したまま、その横に印を付けます（[中国語の記号、ルビ、割注](/ja/docs/document-format#中国語の記号ルビ割注)）。そのため検索、コピーしたテキスト、PDFでは項梁と史記として読めます。印の側は組み方向だけで決まります。`layout.writingMode: 'vertical-rl'`は線を文字の左に置き、レイアウトが`'horizontal-tb'`の見出しスタイル`across`は線を下に置きます。`bookTitleMark: 'wavy'`は`zh-Hant`の文書の既定値ですが、明示しています。`zh-Hans`に切り替えたときに書名が《》で刷られないようにするためです。東漢班固や史記項羽本紀のように同じ種類の印が2つ接する場合は、接する側の端をそれぞれ8分の1 emずつ詰めるので、線は2つの名前として読めます。

### 2 · 印の場所を確保した行送り

<Excerpt region="type" />

印は行と行の間に置かれ、行送りを変えることはありません（[圏点と傍線、ルビ、割注](/ja/docs/configuration#圏点と傍線ルビ割注)）。10.5 ptの文字を18 ptの行送りで組むと行間は0.71 emで、1ページ目の5つ目の凡例のように、ある行の名前の線と隣の行の点の両方が収まります。グリッドはページを字数で数えます。1行42字、17行です。版面がちょうどその大きさになるよう余白を動かし、天に25.7 mm、地に21.7 mmの余白を取ります（[文字グリッド](/ja/docs/configuration#文字グリッド)）。

### 3 · ページとともに向きを変えるひとつの章扉

<Excerpt region="opener" />

見出しのデザインはそのページの流れに沿ってレイアウトされるので、ひとそろいの要素で両方の組み方向に対応できます（[縦組み](/ja/docs/configuration#縦組み)）。裁ち落としの左上に固定した帯は、横組みのページでは天を横切り、縦組みのページでは読み始めの右端を縦に走ります。キッカー、タイトル、著者名も流れに沿って積み重なります。横組みでは上から下へ、縦組みでは右から左へ並びます。帯の長さは流れの方向に測ります。181.3 mmにすると、縦組みでは本文の地で止まってノンブルにかからず、横組みのページでは仕上がり線を越えて伸びます。

### 4 · 右綴じの本のノンブル

<Excerpt region="folios" />

縦組みの本は右綴じになります（[綴じ](/ja/docs/configuration#綴じ)）。1ページ目は背の左にあり、奇数ページの小口は左側です。奇数ページのノンブルは左下、偶数ページのノンブルは右下で、欧文の本とは逆になります。`pageNumbering.format: 'trad-chinese-informal'`で、一、二、三と刷ります。その間に入るスラグの行は、各見出しの属性`slug="…"`から取ります。奥付とこのスラグが、英語版とスペイン語版で変わる部分のすべてです。

### 5 · 2色目のインク

<Excerpt region="palette" />

古典の校訂本では、印を本文と同じインクで刷ります。学生向けの読本なら、2色目で刷って文字の画と区別できます。`annotationColor`は印をパレットの`mark`、つまり朱で書き入れた注釈の朱色にリンクします。この項目をひとつ変えるだけで、本のすべての線と点の色が変わります。

## アレンジ

### 書名を《》で刷る

古典以外の中国大陸の本では、書名を括弧でくくります。Markdownはそのままで、括弧は本文の約物として刷られます。

```diff
-  bookTitleMark: 'wavy', // zh-Hant's default; mainland editions of the classics use it too
+  bookTitleMark: 'brackets', // 《史記》《項羽本紀》
```

### 印を本文のインクで刷る

`annotationColor`を指定しなければ、各印はそれが付くブロックの色になります。

```diff
-  annotationColor: col('mark'), // unset, the marks print in the colour of the text
```

## よくあるつまずき

- デザインで描く見出しはタイトルをデザインを通して刷り、デザイン要素のテキストは印を落とします。`# :book[項羽本紀]`と書いても、帯には波線が出ません。柱、キャプション、表のセルも、テキストを印なしで刷ります。
- Postextは`cjkMarksExceedLeading`で止まりません。ビルドは`doc.contentWarnings`にこれを挙げ、Sandboxの「検査」パネルにも表示されますが、ページはそのまま刷られ、印が次の行に食い込みます。行送りを変えたらこの一覧を確かめてください。15 ptにすると、これらのページの印の付いた段落がすべて一覧に入ります。
