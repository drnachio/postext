## 成品一览

为一本《史记》读本排的三张样张，采用中文大32开图书140 × 203 mm的成品尺寸。正文是《项羽本纪》的开头，用古籍整理本的全式标点：每个人名、地名、国名和朝代名旁加一条直线，每个书名和篇名旁加一条波浪线，都用朱红色。第1页用楷体排题解和编者凡例。第2、3页把同一份Markdown排了两次，一次竖排，一次横排，于是这个跨页能看出标记的位置：竖排时在专名左侧，横排时在专名下方。这本书右侧装订，每个标题都印在一条靛蓝色色带上。<RecipeLink slug="critical-edition-line-numbers">Nº 044，1645年文本的《Lycidas》</RecipeLink>用欧洲的方式区分专名，即排成斜体。

## 做法

### 1 · 标记由标记语法给出，位置由书写方向决定

代码见上文的[简短回答](#简短回答)。`:name[項梁]`和`:book[史記]`把字符保留在正文中，所以搜索、复制出的文字和PDF读到的都是項梁和史記，同时在字旁加上标记（[中文标记、注音和割注](/zh/docs/document-format#中文标记注音和双行夹注)）。标记排在哪一侧只取决于书写方向：`layout.writingMode: 'vertical-rl'`把线放在字的左侧，而版式为`'horizontal-tb'`的标题样式`across`把线放在字的下方。`bookTitleMark: 'wavy'`本是`zh-Hant`文档的默认值；这里明确写出来，是因为一旦改成`zh-Hans`，书名就会印成《》。同类标记首尾相接时，比如東漢班固或史記項羽本紀，两条线在相接的一端各让出八分之一em，这样读起来是两个专名。

### 2 · 为标记留出空间的行距

<Excerpt region="type" />

标记位于行与行之间的空隙中，从不改变行距（[标记、注音和割注](/zh/docs/configuration#着重号注音与夹注)）。10.5 pt字号配18 pt行距，空隙是0.71 em，足以容纳一行的专名线和下一行的着重点，如第1页第五条凡例所示。网格以字数计算页面：每行42字，共17行；它会调整页边距，使版心正好是这个大小：天头25.7 mm，地脚21.7 mm（[字符网格](/zh/docs/configuration#字格)）。

### 3 · 一个章首页设计，随页面转向

<Excerpt region="opener" />

标题设计在所在页面的文本流中排版，所以同一组元素可以用于两个方向（[竖排](/zh/docs/configuration#竖排)）。色带锚定在出血框的左上角，在横排页上横贯页首，在竖排页上则沿右边缘竖下，那里正是阅读的起点。眉题、标题和署名也在文本流中堆叠：横排时上下相接，竖排时左右相接。色带的长度沿文本流方向度量：181.3 mm让它在竖排正文的底端停下，避开页码，而在横排页上则伸过成品线。

### 4 · 右侧装订书的页码

<Excerpt region="folios" />

竖排文字让书在右侧装订（[装订](/zh/docs/configuration#装订)）：第1页位于书脊左侧，右页（奇数页）的外侧边是它的左边。奇数页码放在左下，偶数页码放在右下，与西文书相反；`pageNumbering.format: 'trad-chinese-informal'`把页码印成一、二、三。两者之间的书眉文字来自每个标题的属性`slug="…"`；它和版权说明是英文版与西班牙文版之间仅有的不同之处。

### 5 · 第二种油墨

<Excerpt region="palette" />

古籍整理本用正文的墨色印标记。给学生用的读本可以把标记印成第二种颜色，使它们与字的笔画分开：`annotationColor`把标记关联到调色板中的`mark`，即朱批的朱红色；改动这一项，全书每一条线、每一个点都会随之变色。

## 变化

### 书名印成《》

古籍之外，大陆图书用书名号括住书名：Markdown保持不变，书名号作为正文标点印出。

```diff
-  bookTitleMark: 'wavy', // zh-Hant的默认值；大陆的古籍整理本也用它
+  bookTitleMark: 'brackets', // 《史記》《項羽本紀》
```

### 标记用正文墨色印

不设`annotationColor`，每个标记就取它所标注的块的颜色。

```diff
-  annotationColor: col('mark'), // 不设时，标记印成正文的颜色
```

## 常见问题

- 由版面设计绘制的标题通过设计印出标题文字，而设计中的文字会丢掉标记：`# :book[項羽本紀]`在色带上不会显示波浪线。书眉、题注和表格单元格印出的文字也不带标记。
- Postext不会因`cjkMarksExceedLeading`而停止：构建会把它列入`doc.contentWarnings`，沙盒的检查面板也会显示，但页面照样印出，标记挤到下一行上。改动行距后，请查看这个列表；在15 pt行距下，这几页中每个带标记的段落都在列表里。
