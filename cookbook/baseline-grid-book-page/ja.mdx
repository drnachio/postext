## できあがり

製本をテーマにした作品集『The Ruled Page』の9〜11ページには、中世の写字生がページに与えた比率を論じるエッセイ「The Secret Canon」が載っています。余白はエッセイが説くカノンのとおり2:3:4:6で、見開きで左右対称にとり、210 × 280mmの仕上がりの中にVollkornの2段組みを収めます。ページの上には淡い赤でベースライングリッドを描き、両段と向かい合う両ページの本文がその上に並びます。Playfair Displayの題は章扉の第1段を埋め、カノンの図は第2段の頭に立ちます。節見出しはグリッドから半行ずれ、その下の本文はグリッドに戻ります。小さな文字の工房ノートは、独自の10ptの行送りで組みます。11ページでは、ページ幅の図の下でエッセイが同じ長さにそろえた2段で終わり、第2段を奥付が締めくくります。

## 作り方

### 1 · 見出しはグリッドを外れてよく、リストは外さない

<Excerpt region="flow" />

見出しの上のアキは設定したとおりに保たれるので、行送り1.5行分にすると見出しは2本のグリッド線のあいだに入り、その下の本文は次の線にスナップされます（[ベースライングリッド](/ja/docs/configuration-page-layout#ベースライングリッド)）。リストは最初の項目の前ではスナップされないため、手短な答えではリストのマージンを0にしています（行送りの整数倍でもかまいません）。既定の1.5emのままだと、10ページの3つの項目が隣の段の行より1.3pt下に並びます。題は46ptの2行がそれぞれ行送り4行分を取り、下マージンがさらに1行分を取るので、エッセイは10行目から始まります。

<PageShot page={2} crop="0.14,0.1373,0.795,0.3207" caption="10ページ。第2段のリストは隣の段落と同じグリッドに乗っています。工房ノートはグリッド線のあいだに落ち、その下の見出しは線から半行ずれ、見出しの下の本文はグリッドに戻っています。" />

### 2 · 意図してグリッドを離れ、そして戻る

<Excerpt region="note" />

ノートは文字サイズ7.8pt、行送り10ptで組んだ`:::paragraphs`コンテナーで、グリッドから外れています。最後の段落のあと、位置は次のグリッド線まで切り上げられるので、続く見出しは本文のあとと同じ位置に立ちます（[`:::paragraphs`コンテナー](/ja/docs/configuration-styles#paragraphsコンテナー)）。奥付も同じコンテナーを7.5pt、行送り10ptで使います。4行で40ptとなり、行送り3行分に0.2pt足りないだけなので、エッセイの最後の段は隣の段と同じ高さで終わります。

### 3 · 図はグリッドが吸収できる位置に置く

<Excerpt region="figures" />

フロートは、それを参照する段落より上には置かれません（[配置](/ja/docs/document-format#配置)）。カノンの図は第1段で参照されますが、9ページの第2段の頭には入ることができます。10ページで参照されるページ幅の比較図は、11ページまで待ちます。図の帯はそれぞれ行送りの整数倍に切り上げられるので、図の下の本文はグリッド線から始まり、隣の段とも向かいのページともそろいます。図の大きさはこの切り上げに合わせて決めてください。61.8mmならカノンの帯はキャプションを含めて行送り17行分ですが、62.5mmにすると18行分になり、キャプションの下にほぼ1行分の白が残ります。

<PageShot page={3} crop="0.05,0.07,0.83,0.435" caption="11ページ。ページ幅の図の下の本文はグリッド線から始まり、エッセイは高さのそろった2段で終わって、第2段を奥付が締めくくります。" />

### 4 · 段末そろえで段の長さをそろえる

<Excerpt region="balance" />

9ページと10ページの満杯の段は、どれも44行目で終わります。版面がちょうど行送り44行分で、原稿をそれに合わせて調整したからです。次の行と離さない設定（keep-with-next）と、ウィドウ、オーファン、ラントの規則は既定で有効です。どれかが段を1行短く終わらせると、段末そろえは足りない分のアキをそれより前の見出しの上に入れ（[段末そろえ](/ja/docs/configuration-text#段末そろえ)）、そこが隙間として見えてしまいます。段末そろえが埋めるものがなくなるまで原稿を調整してください。最終ページでは、段末そろえが残りの行を割り振り、両方の段が同じ行で終わります。

### 5 · 余白を左右対称にし、9ページから数える

<Excerpt region="heads" />

手短な答えでは地の余白を計算で求めます。280mmの仕上がりから天の余白24mmと、ちょうど`LINES`行分の版面（44 × 13.4pt = 208mm）を引くと48mmが残り、2:3:4:6の比が求める6単位になります。`mirror: true`にすると、`left`として設定した16mmはのど側の余白になり、奇数ページでは左、偶数ページでは右に来ます（[見開きの余白](/ja/docs/configuration-page-layout#見開きの余白)）。そのため、ページの端から`OUTER`mm離して置いた柱は、小口側で版面と同じ位置で終わります。`pages: 'body'`は柱を章扉から外します。`startAt: 9`でノンブルは9〜11となり、`pageIndexOffset: 8`がその前の8ページを数えるので、左右対称の配置、柱の奇数・偶数、`breakBefore: 'odd'`が製本された本と一致します。オフセットを7にすると最初のページが偶数ページとして数えられ、奇数ページへの改ページでエッセイの前に白ページが1枚入ります。

## アレンジ

### 印刷用にグリッドを隠す

`enabled`が切り替えるのは、仕上がったページの上に描く線だけです。どちらの場合もレイアウトは13.4ptのグリッドに従うので、行は1本も動きません。

```diff
-  baselineGrid: { enabled: true, color: col('grid') },
+  baselineGrid: { enabled: false },
```

### 段末そろえの効果を見る

段末そろえを切ると、11ページは最後の8行と奥付を第1段に流し込み、第2段を空のまま残します。

```diff
-const balancing = { enabled: true };
+const balancing = { enabled: false };
```

## よくあるつまずき

- `top`フロートを参照元のページに置かないという規則は、ページ幅のフロートに当てはまります。段の`top`フロートは、あとの段の頭であれば参照元のページにも置かれます。9ページの図1.1がその例です。
- ページサイズ、余白、段間は絶対単位（mm、pt、cm、in）で指定します。そこでの`em`には基準となる文字サイズがないため、ビルドは「dimensionToPx: baseFontSizePx is required for unit "em"」で止まります。
- Vollkornの語間は0.2emと狭いため、約50字の段では両端そろえの行の一部がゆるくなったり詰まったりします。見本はキャプチャのゆるい行のレポートと照らして1行ずつ調整しました。本文や行長を変えたら、もう一度確認してください。
