## 成品一览

书籍制作文集*The Ruled Page*的第9页到第11页，收的是“The Secret Canon”，一篇讨论中世纪抄写员所定页面比例的随笔。它的页边距遵循文中描述的比例法则，即左右对称的2:3:4:6，成品尺寸210 × 280 mm，版心是两栏Vollkorn。页面上用浅红色画出基线网格，两栏以及左右两页的正文都落在网格上。Playfair Display标题占满章首页的第一栏，第二栏栏首是比例法则的示意图。小标题偏离网格半行，其下的正文重新回到网格上。一段字号较小的工作室注释使用自己的10 pt行距。在第11页，随笔在一幅通栏图下以两栏等长结束，版权说明收尾于第二栏。

## 做法

### 1 · 让标题离开网格，但列表不行

<Excerpt region="flow" />

标题上方的间距严格按设定保留，所以1.5个行距会让标题落在两条网格线之间，标题下的正文则对齐到下一条网格线（[基线网格](/zh/docs/configuration#基线网格)）。列表在第一项之前不会对齐网格，所以简短回答把列表的外边距设为零（任何整数倍行距也可以）；如果用默认的1.5 em，第10页的三个列表项会比旁边一栏的行线低1.3 pt。标题的两行46 pt各占四个行距，下外边距再占一个，所以随笔从第10行开始。

<PageShot page={2} crop="0.14,0.1373,0.795,0.3207" caption="第10页：第二栏里的列表与旁边段落的网格保持一致；工作室注释落在网格线之间，下面的标题偏离网格半行，标题下的正文又回到网格上。" />

### 2 · 有意离开网格，再回来

<Excerpt region="note" />

注释是一个`:::paragraphs`容器，字号7.8 pt、行距10 pt，不在网格上。最后一段结束后，位置向上取整到下一条网格线，所以后面的标题与跟在正文后时的位置相同（[`:::paragraphs`容器](/zh/docs/configuration#paragraphs容器)）。版权说明用同样的容器，字号7.5 pt、行距10 pt：四行占40 pt，比三个行距少0.2 pt，因此随笔的最后一栏与旁边一栏齐底。

### 3 · 把图放在网格能消化的地方

<Excerpt region="figures" />

浮动体永远不会落在引用它的段落之上（[位置](/zh/docs/document-format#位置)）。比例法则示意图在第一栏被引用，仍然可以占据第9页第二栏的栏首；占满页宽的对比图在第10页被引用，要等到第11页。每个图带的高度都向上取整为整数个行距，所以图下的正文从网格线开始，与旁边一栏和对页齐平。图的尺寸要考虑这种取整：比例法则示意图宽61.8 mm时，连同题注占17个行距；宽62.5 mm就要占18个，题注下会留出将近一行的空白。

<PageShot page={3} crop="0.05,0.07,0.83,0.435" caption="第11页：通栏图下的正文从网格线开始，随笔以两栏齐底结束，版权说明收尾于第二栏。" />

### 4 · 让各栏齐底来补齐栏位

<Excerpt region="balance" />

第9页和第10页每个排满的栏都结束在第44行，因为版心恰好是44个行距，文稿也按它调整过。与下段同页，以及段末孤行、段首孤行和孤字规则默认都是开启的。如果其中某条规则让一栏少了一行，各栏齐底会把缺少的空间加到前面某个标题的上方（[各栏齐底](/zh/docs/configuration#各栏齐底)），在那里显出一道空隙，所以要调整文稿，直到各栏齐底无需填补为止。在最后一页，它把剩下的行分配好，让两栏结束在同一行。

### 5 · 页边距左右对称，页码从9开始

<Excerpt region="heads" />

简短回答算出了下页边距：280 mm的成品高度减去24 mm的上页边距，再减去恰好`LINES`个行距的版心（44 × 13.4 pt = 208 mm），剩下48 mm，即六个单位，符合2:3:4:6的比例。设了`mirror: true`后，作为`left`设定的16 mm就是内页边距，在右页位于左侧，在左页位于右侧（[对称页边距](/zh/docs/configuration#镜像页边距)），所以锚定在距页面边缘`OUTER`毫米处的书眉会在切口一侧与版心同时结束；`pages: 'body'`让章首页不印书眉。`startAt: 9`印出第9到第11页的页码，`pageIndexOffset: 8`计入之前的八页，于是左右对称、书眉的奇偶和`breakBefore: 'odd'`都与装订成书时一致。如果偏移量设为7，第一页会算作左页，奇数页分页会在随笔前插入一张空白页。

## 变化

### 交付印刷时隐藏网格

`enabled`只控制成品页面上画出的网格线；无论如何版面都遵循13.4 pt的网格，所以没有任何一行会移动。

```diff
-  baselineGrid: { enabled: true, color: col('grid') },
+  baselineGrid: { enabled: false },
```

### 看看各栏齐底做了什么

关闭各栏齐底后，第11页会把最后八行和版权说明都排进第一栏，第二栏留空。

```diff
-const balancing = { stretchAfterFloats: false };
+const balancing = { enabled: false };
```

## 常见问题

- 设了`span: 'page'`而没有`advancedDesign`的标题级别本应横跨两栏，但postext 1.4.1按一栏的宽度来测量它：“The Secret Canon”在页面上印成一行，却预留了两行的高度，栏间线还穿过这条标题带。所以这里的标题留在第一栏。
- `top`浮动体永远不会落在引用页的规则，适用于占满页宽的浮动体。栏内的`top`浮动体可以落在引用页上，位于后面一栏的栏首，就像第9页的图1.1那样。
- 页面尺寸、页边距和栏间距使用绝对单位（mm、pt、cm、in）。在这些地方用`em`没有可参照的字号，构建会停止并报错“dimensionToPx: baseFontSizePx is required for unit "em"”。
- Vollkorn的词间距很窄，只有0.2 em，所以在大约50个字符宽的栏里，有些两端对齐的行会显得松散或拥挤。示例文字是对照截图的松行报告逐行调整过的；正文或行长有任何改动后都要重新检查。
