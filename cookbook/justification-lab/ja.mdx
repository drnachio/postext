## できあがり

文字組みの研究所が出す専門誌『Galley』の第12号です。A5判に1行約40字の2段組みで組み、両端そろえの行が余りを吸収するための語間は5つか6つしかありません。章扉はグラファイト色の帯にKnuth–Plassのモデルを描きます。語の箱が1列に並び、グルーの黄色いばねが伸びて行長を埋める図です。論考は狭い段がなぜゆるくなるかを説明し、各規則を支える設定を段落の間に等幅書体で印刷します。3ページ目の地では、比較テストが1つの段落を左そろえ、ハイフンなしの両端そろえ、ハイフンありの両端そろえで組みます。CodePenのサンプルは同じ号をファーストフィットの改行で、ウィドウとオーファンの保護を切って組んだ版も作り、このレシピのカードと同じように、2つの2ページ目をページの上に並べて見せます。ゆるい行は蛍光イエローで塗り、孤立した行とラントには余白に札を付けます。

## 作り方

### 1 · 語間の柵を狭め、保護は残す

この手順のコードは上の[手短な答え](#手短な答え)にあります。[Knuth–Plass](/ja/docs/justification#knuth-plass段落全体を見渡す)、ハイフネーション、ウィドウ・オーファン・ラントのペナルティー、次の段落と離さない見出しは初期設定で有効なので、公開版は[語間の上下限](/ja/docs/justification#語間の上限と下限)を通常の語間の0.8倍と1.6倍に狭めるだけです（初期値は0.6と2）。上限を超える行はどのハイフンやラントよりも高くつくので、改行処理はまずほかの改行位置を試します。2つの上下限を消すと、この論考では1.6を超える行が2行できます。ハイフネーションは`locale`のコードに完全一致で従います。`'es'`、`'fr'`、`'de'`はそれぞれのTeXパターンを使いますが、`'es-ES'`は警告なしにアメリカ英語としてハイフネーションされます。

### 2 · レイアウトツリーからゆるい行に印を付ける

<Excerpt region="marks" />

`debug.looseLineHighlight`に従うのはSandboxだけで、`doc.warnings`がゆるい行を挙げることはないので、`marks()`が自分で[VDT](/ja/docs/justification#ゆるい行のデバッグ)を読みます。両端そろえの行はすべて`justifiedSpaceRatio`を持ちます。2つの段に分かれた段落は断片ごとに1ブロックとして返ってきます。3倍を超える行には比率がありません。エンジンがその行を[左そろえで組み](/ja/docs/justification#行分割で埋めきれない行)、代わりに`line.ragged`の印を付けるからです。1行40字では上下限だけですべての行を1.6未満に保つことはできません。論考の原稿を調整している間、どの文を書き換えればよいかを印が示しました。

### 3 · 対照版を公開版のページと並べる

<Excerpt region="compare" />

2つの版は同じデザインを共有するので、2つの2ページ目の違いはすべて改行処理とその保護から来ます。英語版では、貪欲法の対照版は両端そろえの110行のうち47行が1.6を、30行が2を超え、うち3行は3倍を超えてエンジンが左そろえで組みます。一方、Knuth–Plass版は105行すべてを0.80から1.60の間に収めます。2ページ目では、対照版は段落の最終行を1行だけ段の頭へ送ってもいます。これは`avoidOrphans: false`が許すものです。さらに別の段落はラントで終わります。

### 4 · 設定ごとに専用の箱を与える

<Excerpt region="bench" />

囲みは[`:::columns`](/ja/docs/document-format#columns)グループのすべての段を1つの本文スタイルで組むので、各試し刷りはそれぞれ`body`を持つ入れ子の囲みにし、`breaks="3"`で左そろえとハイフンなしの試し刷りを1段目に積みます。左そろえのテキストはハイフネーションされないので、左そろえの試し刷りに`hyphenation: false`は要りません。比較テストは`placement: 'bottom'`で3ページ目の地にフロートします。最後の試し刷りの`marginBottom`は囲みの終わりで捨てられるので、下パディングで4 mmの枠を繰り返しています。

### 5 · モデルを章扉に描き込む

<Excerpt region="opener" />

図はH1のデザインの[画像要素](/ja/docs/configuration#画像要素)です。図として置けばページ幅の`top`フロートになり、1ページ目で参照された`top`フロートは2ページ目の頭に入ってしまいます。帯は箱で、箱は章扉が確保する高さに数えられますが画像は数えられないので、本文は`minHeight`なしで帯の下から始まります。H1の初期設定の`marginBottom`があるため、さらに1行下からです。ラベルは図の座標の上に置いたデザインのテキストです。画像として描くSVGはページのWebフォントを使えないからです。

## アレンジ

### ドイツ語のテキストをハイフネーションする

パターンはコードの完全一致で引かれるので、ドイツ語のテキストには`'de'`が必要です。

```diff
-const locale = t({ en: 'en-us', es: 'es' }); // config().locale; 'es-ES' would be English
+const locale = 'de'; // German patterns; 'de-DE' would hyphenate as English
```

### 最もゆるい行にだけ印を付ける

しきい値を1.6から2に上げると、蛍光ペンは語間が2倍を超えた行にだけ印を付けます。

```diff
-        if (line.justifiedSpaceRatio > FENCES.maxWordSpacing || line.ragged) {
+        if (line.justifiedSpaceRatio > 2 || line.ragged) {
```

## よくあるつまずき

- 段の終わりに残った囲みは、段末をそろえるときに段の地へ落ち、属する段落から離れます。「Fences for the glue」の下の設定の囲みで必要だったように、原稿を調整して段を埋めてください。
- ハイフンなしの試し刷りには、本来必要な最も広い語間は現れません。語間が通常の3倍を超えて伸びる両端そろえの行は、本文と同じく囲みの中でも自然な語間のまま左そろえで組まれるため、この試し刷りの最初の2行は行長より手前で終わります。3倍に届かない行は両端そろえのままで、試し刷りに見える広い語間はそれらの行のものです。
