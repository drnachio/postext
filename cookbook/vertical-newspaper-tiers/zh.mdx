## 成品一览

这是1912年、民国元年一份中文报纸的两张，那时报纸仍然竖排。文字取自上海《申报》：孙中山在西湖出席公宴，陈其美起身反对一篇演说，随后又起身致歉；浙江为攻克南京阵亡的将士举行追祭；杭州为凯旋的军队建立纪念碑。临时政府公报创刊号上的四则电报排在一个框里。正文分两栏（欄），每栏25字，中间隔一条栏线；电报分三栏。朱红色的报头和贯穿版面全高的头条标题开启第一张。<RecipeLink slug="newspaper-front-page">Newspaper front page</RecipeLink>用横排做了同样的版面。

## 做法

### 1 · 把两栏变成上下两栏

代码见上文的[简短回答](#简短回答)。设了`writingMode: 'vertical-rl'`之后，页面相当于把横排页面转了四分之一圈，所以`layoutType: 'double'`会把两栏上下叠放，先读上栏，原来的栏线也就成了横贯页面、隔开两栏的一条线（[竖排](/zh/docs/configuration-page-layout#竖排)）。字符网格把每栏设为25个五號（10.5 pt）字，这是报纸一栏的较长规格，整页设为29行；它把栏间距取整为两个字宽，并放大页边距，让各栏居于其中（[字符网格](/zh/docs/configuration-east-asian#字格)）。

正文保持两栏，只有电报需要三栏，所以把电报放进一个框：`span="page"`让框与版心等高，`placement="bottom"`把它浮动到文字流的末尾，在竖排页面上就是左边缘，`:::columns{count=3}`再把它切成三栏。`columnGap`取的是版心的546 pt减去三栏、每栏18个9 pt字之后剩下的部分，所以每栏都容纳整数个字。

### 2 · 把报头和头条标题放进同一个设计

<Excerpt region="front" />

头条的标题必须在报头之下跨越两栏。带`span: 'page'`的标题会作为章首页排在页面开头，所以在报头之后再放一个这样的标题，它就会自己另起一页。因此本页的H1就是头条，它的标题样式在标题上方画出报头：一块6.5行深的朱红色块，报名反白印在里面，下面是出版信息，即民国纪年和干支纪年，以及“今日出紙兩張”；然后是44 pt的Noto Serif TC 900标题。在文字流中，这个设计的宽度就是版心在纸面上的高度，所以`size: { width: 'fill' }`配合`align: 'center'`，让标题在两栏范围内居中。设计深13行，是网格线的整数倍，所以它后面的正文从网格的一行开始。

<PageShot page={1} crop="0.54,0.1,0.44,0.82" caption="第1页：报头色块、在两栏范围内居中的标题、旁边的副题，以及位于行首的电头。" />

### 3 · 每篇报道用一个标题设计开头

<Excerpt region="heads" />

栏内的标题设计位于它所在的那一栏里。它的线在文字流中是`direction: 'horizontal'`，所以在纸面上沿着这一栏竖向延伸，成为两篇报道之间的一条细线。标题从这一栏的顶端开始，副题低两格，电头给出地点、报纸和报道刊出的日期。`minHeight`让每个标题都占四行，所以每个标题下面的正文都从网格上开始。

### 4 · 给第二张加报眉，在底部署名

<Excerpt region="pagehead" />

按照clreq的说明，竖排页面上的书眉仍然横排。页眉的框是各栏上方的页边距；网格会放大这段页边距，`HEAD`重复网格的计算结果，让那条线位于第一个字上方6 mm处。`pages: 'body'`把第1页留给报头。版权说明是H1的一个属性，所以英文版和西班牙文版在同样的中文页面下各自印出自己的一行。

### 5 · 每种字体只加载它要排的文字

<Excerpt region="voices" />

Fontsource把这些字体的每个字重拆成大约一百个文件提供，`loadCjkFonts`只取文本用到的那些。Noto Serif TC 400拿到全部样文；它的700和900只拿标题和电报的标签，Noto Sans TC拿报头信息、电头和版权说明，LXGW WenKai TC拿副题、碑文和报名。给某个字体的文字太少，截图检查就会失败（C12），并列出它从别的字体借来的字。

## 变化

### 让电报分四栏

四栏、每栏14字，放在同样的高度里正好，框也收窄到这些行所需的宽度。

```diff
-  columnGap: pt((HEIGHT - 3 * 18 * 9) / 2), // 三栏，每栏18个9 pt字
+  columnGap: pt((HEIGHT - 4 * 14 * 9) / 3), // 四栏，每栏14个9 pt字
```

Markdown里写`:::columns{count=4}`。

### 把报道排成一栏

一栏52字贯穿版心全高，每一行在纸面上都长193 mm。每篇报道的标题现在要占整页的四行，两张也变成三张。

```diff
-  layoutType: 'double', writingMode: 'vertical-rl', // binding 'auto' 变为 'right'
+  layoutType: 'single', writingMode: 'vertical-rl', // binding 'auto' 变为 'right'
```

网格里同时设`charsPerLine: 2 * CHARS + 2`。

## 常见问题

- Fontsource的Noto Serif TC在它某个文件的字符范围里声明了爲，也就是《申报》所用的字形，但这个文件里并没有它的字形：Canvas用一个系统字体画出了它，PDF里则没有这个字（C25）。报道里改用為。
- 维基文库的录文有几处笔误，本页作了更正：公宴报道中己紀应为已紀，倍侍应为陪侍（两处）；追祭报道中的勸勵一番現在將土，土应为士，宾语应在一番之前，这里排作勸勵現在將士一番。本页还把四个异体字换成了标准字形：电报中寗作寧，縂作總（三处），决作決（两处），碑文中刋作刊。
- Fontsource提供的LXGW WenKai TC把為画成爲，所以用楷体排的碑文显示的是宋体文字里没有的那个旧字形。
- 框里的三栏是版心的三等分，与正文的两栏对不齐。报纸会给这样的栏目单设一套网格；框右边缘的那条线把两套网格隔开。
