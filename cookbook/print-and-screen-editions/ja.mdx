## できあがり

小さな雑誌の秋のセクション『Notes on Weather』を、同じMarkdownから2回組みます。紙では225 × 297 mmの号です。雨のような青の部扉、淡い霧色の帯の下で始まる3つの記事、両端そろえの2段、雨量計と風配図の図、霧に包まれた谷の写真で構成されます。画面では、Newsreaderで組んだ左そろえ（行末不ぞろい）の1段で、ほぼ黒の地に淡い灰色の文字です。読者が選択してコピーできるHTMLのテキストで、部扉も霧色の帯もノンブルもありません。ペインは雨量計の位置で開き、雨量計はペインの高さに合わせて縮められ、夜の配色で描かれます。その横には雨量計が載っている印刷ページがあります。上へスクロールするとRainの章扉が現れ、ペインの角をドラッグすると、テキストが新しい大きさで組み直されます。画面のデザインは、印刷用の設定の中の`htmlViewer.overrides`にある9つのキーです。

## 作り方

### 1 · 色の名前は1組、値は2組

<Excerpt region="palette" />

設定の中のすべての色はパレットのidを指し、その横に書いた16進値は昼の配色の予備にすぎません。そのため画面版は配列を1つ置き換えるだけで夜の配色に切り替わります。[手短な答え](#手短な答え)にある[上書き](/ja/docs/configuration-fonts-colors-viewers#htmlビューアー)は、オブジェクトをキーごとに、見出しの階層を`level`ごとにマージし、それ以外の配列は`colorPalette`も含めてまるごと置き換えます。`main-color`はパレットの一部なので、それを使うエンジンの既定値も変わります。新しいパレットは、リンクされた色のすべてに届きます。本文、キャプション、章扉のデザイン要素、参照の色です。

### 2 · 章扉は、紙では帯、画面では言葉

<Excerpt region="opener" />

肩書き、題、リードの要素は一度だけ定義して両方のデザインに展開するので、2つの版は同じ見出し属性`{attr.kicker}`、`{attr.lead}`と部の`{partTitle}`を表示します。紙では第1階層の見出しは改ページして両段に渡り、そのデザインが裁ち落としから霧色の帯を垂らします。`minHeight`は、天の余白から下の帯の深さに`AIR`、つまり帯と1行目のあいだの9 mmを加えた分を確保します。印刷版の題を54 ptで組むのは、どれも短い1語で、そのページで唯一の大きな文字だからです。画面では同じ階層を、帯も空きもない段内の見出しとして組みます。上書きは`level`ごとにマージされるので、改めて指定しなかった見出しの設定はすべて印刷版のまま残ります。

### 3 · 紙にしかない部扉

<Excerpt region="part" />

印刷版では`:::part`が<PageRef page={1}>雨のような青の部扉</PageRef>を開きます。四方を裁ち落としにした箱、文字を避ける雨の線の画像要素、囲いから取った数字と題、白抜きの記事一覧です。画面の上書きは`parts.page: false`を指定するので、ページは開かず一覧も組まれません。それでも[部](/ja/docs/configuration-styles#部)は後に続く記事に番号と題を与え、画面の肩書きも印刷版と同じく「Autumn · Note 1」になります。

### 4 · どの図も2回描く

<Excerpt region="figures" />

パレットを入れ替えてもSVGの色は変わらないので、各図はパレットごとに1つずつ作ります。谷は写真で、2つの版で1つのJPEGを共有します。`figures(edition)`は両方の版に同じリソースを作り、それぞれがその版のファイルを指します。印刷版では`gauge-day.svg`、画面版では`gauge-night.svg`です。id、キャプション、代替テキスト、配置は変わらないので、Markdownの`:ref`はどちらの版でも同じ図と番号に解決されます。画面版では代替テキストが各`<img alt>`に入り、スクリーンリーダーがそこから読み取ります。

### 5 · 画面版を組み込む

<Excerpt region="screen" />

画面のページはどれもペインと同じ高さなので、`fitFiguresToPage`が雨量計をキャプションといっしょに1ページに収まるまで縮めます（[レイアウト](/ja/docs/configuration-page-layout#レイアウト)）。CSSが前提とする96 dpiでは、印刷版から受け継いだミリメートルとポイントが公称の大きさで描かれます（[HTMLビューアーの統合](/ja/docs/configuration-programmatic-usage#htmlビューアーの統合)）。CodePenのサンプルは、`renderToHtml`が絶対配置で出力する行をShadow DOMに書き込みます。そこならページのセレクターは届きません。`letter-spacing`のような継承プロパティはこの境界を越えて入ってきますが、エディションのルート要素が自分でリセットします。エンジンはそれらなしで行を計測しているからです。HTMLのページは塗らなければ透明なので、`page.backgroundColor`がパレットから夜の紙色を取ります。ResizeObserverは150 ms待ち、ペインの幅か高さが変わったときだけ、新しく作った`config()`から組み直します。組み直したあと、ペインは高さに対して同じ割合の位置までスクロールを戻します。

## アレンジ

### 昼の配色で読む

夜のパレットを外し、ペインと図に昼の値を使います。画面版は白いページ、濃いインク、昼の図で表示されます。

```diff
-  colorPalette: paletteOf(night), // arrays are replaced whole: the night values
   parts: { page: false }, // no divider page; the part still names the notes after it
@@
-pane.style.background = night.paper; // the pane's own ground, beside the pages and the scrollbar
+pane.style.background = day.paper; // the pane's own ground, beside the pages and the scrollbar
@@
-  const screenDoc = buildDocument({ markdown, resources: figures('night') },
+  const screenDoc = buildDocument({ markdown, resources: figures('day') },
```

### 印刷版の章扉に色帯と章番号を付ける

彩度の高い帯と大きな章番号を持つ、より重厚な印刷版の章扉については<RecipeLink slug="chapter-opener-bleed-band">裁ち落としの帯を敷いた章扉</RecipeLink>を参照してください。画面の上書きはそのまま使えます。

## よくあるつまずき

- ペインの高さは400 px以上に保ってください（CodePenのサンプルの`min-height`）。高さが約350 px未満の狭いペインでは、画面の章扉がページの内容領域より高くなります。すると章扉だけで1ページを使い、記事の最初の段落は次のページから始まります。
- レイアウトする前にペインに大きさを与えてください。非表示になったり、flexの行で押しつぶされたりして幅のないペインは、幅0のページになります。そのため`showScreen()`は、幅か高さが`FOLDED`の200 pxに満たないペインを飛ばします。
