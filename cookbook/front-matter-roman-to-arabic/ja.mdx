## できあがり

ポケット版の古典として組んだ『フランケンシュタイン』の最初の丁です。判型は129 × 198 mm。モンブランに落ちる稲妻を描いた表紙（裏は白）、前扉、氷に閉じこめられたウォルトンの船を描いて本扉と向かい合う口絵、本扉の裏の下部に置いた権利表示、ミルトンのエピグラフの上に置いたゴドウィンへの献辞、目次、そして1818年の序文が続きます。この10ページはiからxまで数えますが、番号を刷るのは目次と序文だけです。Letter Iはオーロラの下、右ページで小説を始め、そのノンブル1は向かいのページのxと同じ位置にあります。手紙はウォルトンの署名まで続きます。目次で序文の横に付くixと、手紙の横に付く1は、組み上がったページから取ったものです。PDFビューアーもページに同じラベルを付けます。表紙、口絵、オーロラは拡散モデルで生成した絵で、JPEGのビットマップとして読み込みます。出版社のマークと氷の結晶はコードで描いています。

## 作り方

### 1 · どの丁もデザインを持つ見出し

<Excerpt region="leaves" />

見出しはそれ自身のページを開き、PDFのしおりになります。スタイルのデザインが、その丁の文字と絵を配置します。`numbered: false`と`toc: false`を指定すると、これらの丁は章の数えにも目次にも入りません。ヘッダーとフッターを空にすると、印刷の世界で隠しノンブルと呼ぶものになります。本扉は番号を刷りませんがvページであることに変わりはなく、そのため序文がixになります。奇数ページへの改ページを残すのは前扉だけで、それによって表紙の裏が白ページになります。権利表示、献辞、エピグラフ、ウォルトンの結びは`:::paragraphs`ブロックで、抜粋の最後にあるスタイルで組みます。

### 2 · 目次は番号をレイアウトから取る

<Excerpt region="contents" />

`:::toc`は、スタイルが許すすべての見出しを、それが置かれたページのラベルとともに並べます（[目次](/ja/docs/configuration-notes-references#目次)）。目次と序文は`front`スタイルを共有し、このスタイルは`toc: false`を指定しますが、序文は`{toc="true"}`でそれを上書きします。序文もLetter Iも番号なしなので、その項目には章番号が付きません。手紙の項目の2行目は、その`to="…"`属性です。ページ番号はノンブルの書体で組みます。項目は序文の1行目と同じベースラインから始まるので、向かい合う2ページの行がそろいます。

### 3 · 小説はオーロラの下、奇数ページで始まる

<Excerpt region="letter" />

絵はページの天へ裁ち落とし、地に向かって紙に溶け込み、そこから手紙が始まります。章扉は絵の下端、ページの上端から104mmまでを確保します。`minHeight`はそこから2mm下に下限を置くので、手紙はグリッド1行分あとから始まり、絵の溶け込む部分にかかりません（[幅と詳細デザイン](/ja/docs/configuration-text#幅と詳細デザイン)）。肩見出しと日付行は、見出しの`to`属性と`dateline`属性から取ります。Letter Iには`{style="letter"}`も付けます。これは`numbered: false`だけを指定したスタイルです。ウォルトンの手紙はChapter Iより前にあり、章番号を持たないからです。

### 4 · 小説とともに柱が戻る

<Excerpt region="heads" />

節は、スタイルが置き換えないかぎり文書のヘッダーとフッターを使います。前付けは両方を置き換え、手紙のスタイルは置き換えません。そのため1ページ目から、小説は本文ページにこの柱を刷り、章扉には手短な答えで定義した章扉用のノンブル（ドロップフォリオ）を刷ります。`{pageNumber}`は置かれたページのラベルを刷るので、`folio()`ヘルパーは同じデザインのまま、のどの片側にx、反対側に1を組みます。

### 5 · PDFも同じページ番号を持つ

<Excerpt region="build" />

`buildDocument`は目次のページラベルが変わらなくなるまでレイアウトを繰り返すので、呼び出しは1回で足ります。`renderToPdf`はそのラベルをPDFに書き込みます。ページラベルを読むビューアーでは、ページ番号欄がiからx、続いて1から進み、「1ページへ移動」でLetter Iが開きます。どの見出しも本文をそのまま名前にしたしおりになるので、丁の題名は飾りのないものにしてあります。Cover、Half title、Frontispiece、Title page、Imprint、Dedicationです。

## アレンジ

### 前付けを大文字で数える

大文字のローマ数字はノンブルの書体でフルサイズのキャピタルになり、小文字の数字が出すスモールキャピタルより背が高くなります。

```diff
-const pageNumbering = { format: 'lower-roman', startAt: 1 }; // startAt spelled out: cover = i
+const pageNumbering = { format: 'upper-roman', startAt: 1 }; // startAt spelled out: cover = I
```

### 通しで番号を振る

`startAt`を外すと算用数字のまま数え続けるので、Letter Iは11ページになります。前付けを本文と通しで数える本と同じです。

```diff
-:::numbering{format="decimal" startAt=1}
+:::numbering{format="decimal"}
```

### 口絵を外す

`# Frontispiece`見出しを削除し、本扉を奇数ページへ送ります。ivページは白ページのまま残り、序文はixのまま、Letter Iも1のままです。

```diff
-  { id: 'title', ...blind, advancedDesign: design([ // v: four frontmatter fields, one attribute
+  { id: 'title', ...blind, breakBefore: { enabled: true, parity: 'odd' },
+    advancedDesign: design([ // v: four frontmatter fields, one attribute
```

### 印刷用に塗り足しとトンボを付ける

`cutLines`を指定すると、どちらも塗り足しに固定した表紙と章扉が、仕上がりから3 mm外へ延びます。ノンブルとページ数は変わりません（[トンボ](/ja/docs/configuration-page-layout#トンボ)）。

```diff
     backgroundColor: col('paper'), pageNumbering,
+    cutLines: { enabled: true }, // a 3 mm bleed and crop marks
```

## よくあるつまずき

- 丁はレベル1の`'odd'`改ページを継承します。そのままにすると、どの丁も右ページを待ちます。前付けは10ページでなく14ページになって白い偶数ページが4つ増え、口絵は本扉ではなく白ページと向かい合います。このレシピのように`parity: 'any'`で改ページを指定し直すか、`breakBefore: { enabled: false }`で外してください。ページ幅の見出しは、どちらの場合もそれ自身のページを開きます。
- レベル1が`'always-odd'`（エンジンのH1の初期値）で改ページする場合は、`:::numbering`の前の`:::pagebreak`を外してください。その前の本文が右ページで終わると、pagebreakが次の奇数ページまで埋め、見出しが区切りのページを足してもう一度埋めるので、白ページが1つでなく3つ続きます。ここでのように`'odd'`改ページのあとでは、pagebreakは何も変えません。`'any'`のあとでは、これが1ページ目を奇数ページに置きます。
- 序文が1ページ増えると、Letter Iは2ページ先へ移ります。奇数ページへの改ページが、その前に白い偶数ページを足すからです。前付けを編集したら、そのつどページ数を確認してください。
- 目次のリーダー点はページ番号の書体と色で組まれ、`toc.leader`には独自の色がありません。そのためここではスチールブルーで刷られます。
