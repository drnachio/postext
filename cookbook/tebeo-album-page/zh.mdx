## 成品一览

一本西班牙漫画画册的第一个故事《卡门的橙子》：偶数页是扉页，对面是一页七格、分四排的漫画，正是法比漫画画册的画法。九岁的萝拉星期天跟帕科爷爷去菜市场，从卡门的橙子塔最底下抽了一个橙子。画面是平涂色彩的清线风格；边框细而直角，旁白放在贴住格角的黄色方框里，对白按欧洲嵌字师的习惯大小写混排。文字写在 Markdown 里，每种语言一个文件：西班牙语原文，然后是英语、加泰罗尼亚语、中文、阿拉伯语和日语，引擎在同一套分格、同一批画面上逐一嵌字。

## 做法

### 1 · 画册的样子就是一份 comics 配置

代码就是上面的[简短回答](#简短回答)。`comics.panel` 设定所有边框（0.75 pt 的墨线、直角），`panelStyles` 再加一个无边框的命名样式，最后一格用 `style=open` 取用它：公园长椅上的尾声，已经离开了市场。内置的对话框样式按 id 重新定义：`caption` 变成带细边的淡黄色方框，`shout` 是十六个尖角的爆炸框，`sfx` 用橙子的橙色加墨色描边。嵌字保留 `textTransform: 'none'`；美式漫画会设成 `'uppercase'`。

这一页在内容里只是一个指令：一棵分格树和七个画格，每格带自己的台词：

```md
:::page{split="25 [60 | *] / 25 [55 | *] / 24 / * [50 | *]"}
::panel{art=t1}
caption: 每个星期天，帕科爷爷和我都去菜市场。
caption{at=bottom-end}: 总是同一个时间，总是走同一扇门。
::panel{art=t4}
lola{thought}: 最下面那个最大。
paco{shout}: 萝拉，别拿那个！
```

`caption` 是旁白框（第一个放在阅读起始一侧的上角），`{at=bottom-end}` 把第二个送到对角，`lola`、`paco` 这样的说话人 id 会画出对话框，尾巴指向画面声明的嘴巴位置。

### 2 · 画面知道谁在哪里说话

<Excerpt region="art" />

每幅画都声明裁切时必须保留的部分（`safeArea`）、每个说话人的嘴、头和脸的位置（`anchors`），以及不许被对话框遮住的地方（`avoid`），全部用画面的比例表示。橙子塔倒塌的那一格占满第三排，200 毫米宽、63 毫米高，所以它的安全区是人脸和飞起的橙子那一条；方形的画格则裁掉地面。这些都与语言无关，六个版本共用。

### 3 · 扉页对着故事

<Excerpt region="title-page" />

扉页是一个标题样式：系列名用嵌字字体，书名用拟声词的字体（Bangers，其他文字分别是 Dela Gothic One、ZCOOL KuaiLe 和 Lalezar），下面是一幅卡门水果摊的小图，保持 3 : 2 的原比例。构建时传入 `continuation: { pageIndexOffset: 1 }`，扉页就落在偶数页，故事从对面的第 3 页开始。

## 变化

### 像美式漫画那样用大写字母嵌字

把嵌字设为大写；旁白和对白都随之改变，没有大小写的文字（中文、日文、阿拉伯文）保持原样。

```diff
-    color: col('ink'), textTransform: 'none' }, // European letterers write in mixed case
+    color: col('ink'), textTransform: 'uppercase' },
```

## 常见问题

- 全书的嵌字字号只有一个：译文更长时，对话框会变大、挪位置，但字不会缩小。改动分格之后，请检查加泰罗尼亚语和阿拉伯语的页面。
- 每格的替代文字以六种语言写在画面清单里，由 `t({ … })` 选取；列表里缺的语言会读第一种。在内容文件里写 `::panel{alt="…"}` 可以替换某一格的替代文字。
