## できあがり

スペインの漫画アルバムの最初のお話『カルメンのオレンジ』です。偶数ページに扉、その向かいにフランス・ベルギーのアルバムと同じ四段・七コマのページを組みます。九歳のローラは日曜日にパコおじいちゃんと市場へ行き、カルメンのオレンジの山のいちばん下から一個を抜いてしまいます。絵は平塗りのリーニュ・クレール。枠線は細く角は直角で、ナレーションはコマの角にぴったり付けた黄色い枠に入り、せりふはヨーロッパの写植と同じく大文字と小文字で組みます。テキストは言語ごとに一つのMarkdownファイルで、スペイン語の原作のほか英語、カタルーニャ語、中国語、アラビア語、日本語があり、エンジンが同じコマ割りと同じ絵の上に写植します。日本語版の吹き出しは縦書きです。

## 作り方

### 1 · アルバムの見た目は comics の設定

コードは上の[手短な答え](#手短な答え)にあります。`comics.panel` がすべての枠（0.75ptの墨の線、直角の角）を決め、`panelStyles` に枠線のない名前付きスタイルを足します。最後のコマは `style=open` でそれを使い、市場を出た公園のベンチでのエピローグになります。組み込みの吹き出しスタイルはidで上書きします。`caption` は細い輪郭の淡い黄色の枠に、`shout` は十六の角のある爆発形に、`sfx` はオレンジ色に墨のふちどりにします。写植は `textTransform: 'none'` のまま。アメリカの漫画なら `'uppercase'` にします。

ページそのものは本文のディレクティブ一つで、コマ割りの木と七つのコマにそれぞれのせりふが付きます。

```md
:::page{split="25 [60 | *] / 25 [55 | *] / 24 / * [50 | *]"}
::panel{art=t1}
caption: 日曜日になると、パコおじいちゃんとわたしは市場へ行った。
caption{at=bottom-end}: いつも同じ時間に。いつも同じ入り口から。
::panel{art=t4}
lola{thought}: 一番下のが、一番大きい。
paco{shout}: ローラ、それはだめだ！
```

`caption` はナレーション枠で、一つ目は読み始める側の上の角に付きます。`{at=bottom-end}` は二つ目を反対の角へ送ります。`lola` や `paco` のような話者のidを書くと、絵が示す口の位置へしっぽを向けた吹き出しが描かれます。

### 2 · 絵は誰がどこで話すかを知っている

<Excerpt region="art" />

それぞれの絵が、どう切り抜いても残す範囲（`safeArea`）、話者の口・頭・顔の位置（`anchors`）、吹き出しで隠してはいけない所（`avoid`）を、絵に対する比率で持っています。オレンジの山が崩れるコマは三段目いっぱい、幅200mm・高さ63mmなので、安全領域は顔と宙を飛ぶオレンジの帯にしてあります。正方形の絵は床が切れます。どれも言語に関係なく、六つの版で共有します。

### 3 · 扉はお話の向かいに

<Excerpt region="title-page" />

扉は見出しスタイルです。シリーズ名は写植の書体で、題名は擬音の書体（Bangers、ほかの文字ではDela Gothic One、ZCOOL KuaiLe、Lalezar）で組み、カルメンの店のカットを元の3 : 2のまま置きます。ビルドに `continuation: { pageIndexOffset: 1 }` を渡すので扉は偶数ページになり、お話は向かいの3ページから始まります。

## アレンジ

### アメリカの漫画のように大文字で写植する

写植を大文字にします。ナレーションもせりふもそれに従い、大文字・小文字のない文字（中国語、日本語、アラビア語）はそのままです。

```diff
-    color: col('ink'), textTransform: 'none' }, // European letterers write in mixed case
+    color: col('ink'), textTransform: 'uppercase' },
```

## よくあるつまずき

- 写植の文字サイズは本全体で一つです。訳文が長くなると吹き出しが大きくなって位置が動きますが、文字は小さくなりません。コマ割りを変えたら、カタルーニャ語とアラビア語のページを確かめてください。
- 各コマの代替テキストは絵のマニフェストに六言語で書き、`t({ … })` で選びます。一覧にない言語は最初のものを読みます。内容ファイルに `::panel{alt="…"}` を書くと、そのコマだけ置き換わります。
