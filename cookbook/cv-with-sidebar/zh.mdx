## 成品一览

Irene Salcedo是马德里一位虚构的图书设计师，这是她的简历，排在一张A4纸上。一条66 mm宽的紫红色色带沿左边缘从纸张顶端一直延伸到底端。色带顶部是一摞用代码画出的布面精装书，与她姓名的基线平齐。书下方依次是联系方式、排成标签的技能与工具、语言、教育背景、教学经历和工作之外的爱好。她的姓名用46 pt的Hedvig Letters Serif排出，位于118 mm宽的正文栏顶部，下面是五行简介、三份工作和她设计过的图书列表。每份工作的标题行左边是职位，右边是起止年份，两者在同一条基线上，雇主以斜体列在下一行。侧栏的第一个标题与姓名下方的职业头衔共用一条基线。

## 做法

### 1 · 把各部分嵌套在一个侧栏框里

<Excerpt region="sections" />

在侧栏里，色带就是[简短回答](#简短回答)中的那个框。它的围栏写在姓名之前，所以`span="side"`把它放在纯浮动栏的顶部。各部分是嵌套在它里面的框，自身没有填充色，于是紫红色从Contact一直连到Outside work，中间不断开。如果把它们做成各自独立的侧栏框，即使`marginBottom`设为0，彼此之间也会隔开4.7到9.1 mm。标签高约3.9 mm。Skills和Tools用单独的部分样式`chips`，其16 pt行距让两行标签之间留出1.8 mm；其他部分用的12.4 pt只会留出半毫米（[行内标签样式](/zh/docs/configuration#行内标签样式)）。

### 2 · 给栏外的页边上色

<Excerpt region="margins" />

侧栏位于页边距以内，所以侧栏框离左边缘还差9 mm，离顶端还差18 mm。三个页眉框分别填满栏上方的上页边距、从顶到底的左页边距，以及栏下方的下页边距。页眉元素在文字之后绘制、盖在文字之上，所以本食谱把它们限制在没有文字的页边里。它们还会在每一页重复，如果有第二页，也会带上这条色带（[页眉与页脚](/zh/docs/configuration#页眉与页脚)）。顶部和左侧的框与侧栏框重叠0.5 mm，底部的框比栏底高出1 mm，盖住侧栏框的末端，这样接缝处不会露出一丝纸色。结束侧栏框的`:::space`把框延伸到278.0 mm，比栏底高0.8 mm；英文版用2.76行，西班牙文版用1.76行。

### 3 · 把姓名放在正文栏顶部

<Excerpt region="name" />

H1保留默认的`span: 'column'`。设为`'page'`时，它会变成横跨两栏的章首标题；由于它排在侧栏框之后，就会移到第2页，而那里的侧栏要到姓名下方45.9 mm处才开始。`breakBefore`关闭，因为侧栏框已经在这一页上：如果分页，姓名和整个正文栏都会移到第2页。这一级标题的`marginBottom`为一个网格行，使简介从45.9 mm而不是41.3 mm处开始。侧栏框的上内边距是`ROLE_Y`，即姓名的高度加上其下方的间距，所以侧栏的第一个标题与职业头衔共用一条基线，距离顶边39.3 mm。

### 4 · 把日期放在职位那一行

<Excerpt region="jobs" />

每份工作是一个H3，其属性带着雇主和起止年份：`### Art director {org="Ediciones del Albardín, Madrid" dates="2021 – present"}`（[标题属性](/zh/docs/document-format#标题属性)）。职位和日期都锚定在同一个容器的顶部，各占一角，字号和行距相同，因此落在同一条基线上。职位限宽84 mm并允许换行：过长的职位会在碰到日期之前折到第二行，雇主随之下移。加上上方的空白，每个部分标题正好占三个网格行，所以无论工作标题跟在部分标题还是列表之后，都位于某条网格线下方9 pt处。

## 变化

### 给色带换色

每种颜色只在`palette`里写一次，色带框、侧栏框、标签、职业头衔、各级标题和插图都从那里取色。下面三行把色带、强调色和标签改成青绿色。

```diff
-  band: '#3a2235', // 侧栏
+  band: '#1d3b3a', // 侧栏
-  accent: '#8f3b62', // 用在纸面上：职业头衔和各部分标题（7.1:1）
+  accent: '#2b5f5b', // 用在纸面上：职业头衔和各部分标题（7.3:1）
-  chip: '#744d6c', // 用在色带上：技能标签
+  chip: '#456d69', // 用在色带上：技能标签
```

### 把图浮动到同一栏

<RecipeLink slug="textbook-margin-column">带边注栏的教科书</RecipeLink>把图、侧边题注和旁注放在每页外侧的一个纯浮动栏里。

## 常见问题

- 让`:::space`与页面吻合。英文版中，2.76行使框结束在栏底上方0.8 mm处。设为2.96行时，框超出栏底0.1 mm，整个侧栏会移到第2页；设为2.66行时，框与底部的框之间会露出一条纸色。
- 姓名的版面设计里的框画不了这条色带。如果框结束在栏底稍上方，标题要预留265 mm，超过栏高260.8 mm，正文就会移到第2页；如果框一直延伸到纸张底部，标题的预留高度就不再生效，简介会上移到30.3 mm处，压在职业头衔上。
