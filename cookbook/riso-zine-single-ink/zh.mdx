## 成品一览

*Night Buses*是一本关于某座城市夜班公交的免费小志：四页，120 × 160 mm，一张纸对折，供一台有蓝色和荧光粉两个滚筒的孔版印刷机印刷。配置里的每种颜色都是两种墨之一、粉色的25%网调，或者奶油色纸张本身。插图按全彩绘制（六色线路图、灰色的月亮、黑底琥珀色的线路牌），从粉色滚筒印成粉色的深浅网调，颜色越深网调越密。<PageRef page={3}>线路图</PageRef>印成粉色，同一页靠下的一幅小插图保留原来的六种颜色。封面标题排两次，粉色副本比蓝色的向右偏0.8 mm、向上偏0.5 mm。CodePen示例还能生成彩色PDF和灰度打样。

## 做法

### 1 · 两个滚筒，每种颜色都取自其一

<Excerpt region="inks" />

孔版印刷机的每种墨由自己的滚筒印出，所以配置里任何地方出现第三种颜色，都需要第三个滚筒。`screen()`把一种墨按比例与纸色混合，就像网屏只印一部分网点、网点之间留出纸色。粉色的25%网调是`#f2c7d3`，用作行内标签和题注的底色。`main-color`指向粉色，所以配置里没有改动的默认值都从这个滚筒印出，而不是引擎自带的蓝色`#295AA3`。

### 2 · 每种输出各重新着色一次

代码就是上面的[简短回答](#简短回答)。开启`diagramStyle.singleInk`后，`renderToPdf`把SVG的每种颜色变成`inkColor`的一个网调，浓度为1减去该颜色的相对亮度（[图示样式](/zh/docs/configuration#图示样式)），于是深蓝的N12印成84%，黄色的N50印成24%。用`singleInk: true`注册的图片，Canvas也按同样的方式着色，所以`registerArt()`带着这个开关注册每幅原图，并把同一份SVG留给`resourceBytes`。在Canvas上和按300 dpi栅格化的PDF里取样，N12线路都是(242, 109, 171)，正是公式在浓度0.836时给出的网调。每种输出只给插图着色一次：若把它过两遍公式，这条线会减淡到44%。

### 3 · 标题印两次，故意套印不准

<Excerpt region="cover" />

孔版印刷机一个滚筒接一个滚筒地印，纸张两次落下的位置绝不会完全相同。`twice()`返回一个文字元素的两份副本，粉色的在前，向右0.8 mm、向上0.5 mm。数组顺序就是绘制顺序，所以蓝色副本盖住粉色，只在每个字母的上缘和右缘露出一条细边。Canvas和PDF绘制的是不透明颜色，所以重叠处保持蓝色，而真正的孔版会印出紫色。这个版面设计是通栏的，因为站牌杆伸出版心底部，而限定在栏内的设计会在栏底被裁掉。

### 4 · 小字用深色墨

<Excerpt region="inside" />

在奶油色纸上，蓝色的对比度是6.4:1，荧光粉只有2.9:1，印8或9 pt的字太淡。所以引擎排的每个字都从蓝色滚筒印出。行内标签是25%网调底上的蓝色Space Mono（4.85:1），外加粉色描边；题注是同一网调底上的蓝色Epilogue。粉色印引文上方的色条、标签描边、项目符号、页码方块和标题的错位副本。插图里的文字属于插图本身，随插图印成粉色。说话人的名字是框的标题，用7.5 pt粗体Space Mono大写字母排在引文上方。

### 5 · 把小插图放在短文旁边

<Excerpt region="drawn" />

在单栏里，浮动体占满所在区域的整个宽度，所以浮动一幅小图会让区域的其余部分空着。于是这幅小插图改用标题的版面设计：`### As drawn {style="drawn" note="…"}`印出图片，并在图片右边把标题排成标签，下面是短文。图片计入版面设计预留的高度，所以即使短文变短，下一个块也从图片下方开始。`registerSnapshot()`把同一张`network()`线路图画成PNG，而单色墨只对SVG重新着色，所以这幅小插图在屏幕上和PDF里都保留六种颜色。

## 变化

### 换上橙色滚筒

月亮、线路图、线路牌、行内标签、色条和两个标题的错位副本都变成橙色，文字仍是蓝色；题注、短文和版权页仍写着粉色滚筒，直到你改写它们。

```diff
-const DRUMS = { ink: '#1d4fb8', spot: '#f0509a' };
+const DRUMS = { ink: '#1d4fb8', spot: '#ff6c2f' };
```

### 印一本双色教材

白纸上用黑色文字加蓝色专色，同样的插图印成蓝色的深浅网调，就像双色课本里的示意图；题注、短文和版权页仍写着粉色滚筒，直到你改写它们。

```diff
-const DRUMS = { ink: '#1d4fb8', spot: '#f0509a' };
-const PAPER = '#f3efe6'; // 奶油色纸：不着墨的地方
+const DRUMS = { ink: '#1f1f1f', spot: '#0078bf' };
+const PAPER = '#ffffff'; // 白纸：不着墨的地方
```

## 常见问题

- 在PDF里，重新着色改写的是SVG标记：十六进制颜色、`rgb()`、`rgba()`、`hsl()`和`hsla()`，以及关键字`white`和`black`。用`red`命名颜色或让填充保持默认黑色的形状在那里会保留原色，那就需要第三个滚筒。每个填充和描边都要给十六进制值。
- `colorSpace: 'grayscale'`把postext绘制的内容变成灰色，但位图按原样嵌入，所以PNG小插图在灰度打样里仍是彩色。只有CodePen示例的第二个按钮生成打样；上面的页面是Canvas，本页提供的PDF是彩色版。
- 各栏齐底可能在顶部浮动体下方、上一页段落的续文之前留出一行空白；`headings.balancing.stretchAfterFloats: false`让文字紧贴浮动体。这里的文字不会触发它。改动文字后，检查线路图下方的第一行，因为多出一行就可能把小插图推到第五页。
- CodePen示例里两个按钮都写着“Build the PDF”。第一个生成彩色PDF，第二个生成灰度打样；文件生成后，按钮换成一个“Open the PDF ↗”链接和一个带文件名的下载链接。
