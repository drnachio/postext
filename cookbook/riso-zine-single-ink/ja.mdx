## できあがり

『Night Buses』は、ある町の深夜バスを取り上げた無料のZineです。120 × 160 mmの4ページで、1枚の紙を一度折って作ります。青と蛍光ピンクの2ドラムを持つリソグラフで刷ります。設定の色はどれも2色のインクのどちらか、ピンクの25%の網、またはクリーム色の紙のどれかです。線画はフルカラーで描かれています（6色の路線図、グレーの月、黒地に琥珀色の行先表示幕）が、ピンクのドラムからピンクの濃淡で印刷され、暗い色ほど濃い網になります。<PageRef page={3}>地図</PageRef>はピンクで印刷され、同じページの下の小さな挿図は描いたとおりの6色を保ちます。表紙の表題は2回組み、ピンクの複製を青より0.8 mm右、0.5 mm上に置きます。CodePenのサンプルは、カラーのPDFとグレーの校正刷りも生成します。

## 作り方

### 1 · 2つのドラムと、そのどちらかに属するすべての色

<Excerpt region="inks" />

リソグラフはインクごとに別のドラムで刷るので、設定のどこかに3色目があれば3つ目のドラムが必要になります。`screen()`はインクの一定割合を紙の色と混ぜます。網が点の一部だけを刷り、そのあいだに紙を残すのと同じ考え方です。ピンクの25%の網は`#f2c7d3`で、チップとキャプションの地色です。`main-color`はピンクを指すので、設定で触れていない既定値もエンジン本来の青`#295AA3`ではなく、このドラムから印刷されます。

### 2 · 出力ごとに一度だけ線画の色を置き換える

コードは前出の[手短な答え](#手短な答え)にあります。`diagramStyle.singleInk`を指定すると、`renderToPdf`はSVGのすべての色を`inkColor`の濃淡に変えます。濃度は1からその色の相対輝度を引いた値です（[ダイアグラムスタイル](/ja/docs/configuration#ダイアグラムスタイル)）。そのため濃紺のN12は84%、黄色のN50は24%で印刷されます。Canvasも、`singleInk: true`を付けて登録した画像を同じように置き換えます。そこで`registerArt()`は元の線画をその指定付きで登録し、同じSVGを`resourceBytes`のために残しておきます。Canvasと、300 dpiでラスタライズしたPDFで色を採取すると、N12の線は(242, 109, 171)で、濃度0.836に対して式が与える濃淡と一致します。どの出力でも置き換えは一度だけです。式を二度通すと、この線は44%まで薄くなります。

### 3 · 表題を見当をずらして2回刷る

<Excerpt region="cover" />

リソグラフはドラムを1つずつ順に刷り、紙が二度とまったく同じ位置に来ることはありません。`twice()`はテキスト要素の複製を2つ返し、ピンクを先にして、0.8 mm右、0.5 mm上に置きます。配列の順が描画の順なので、青の複製がピンクを覆い、各文字の上辺と右辺に沿った細い縁だけが残ります。CanvasとPDFは不透明な色で描くため、リソなら紫に刷られる重なりの部分も青のままです。ポールは版面の下端より下まで伸びるので、デザインはページ全体に広げます。段の中に置いたデザインは、段の下端で切り取られるからです。

### 4 · 小さな文字は濃いインクで刷る

<Excerpt region="inside" />

クリーム色の紙の上では、青のコントラスト比は6.4:1、蛍光ピンクは2.9:1で、8 ptや9 ptの文字には薄すぎます。そこでエンジンが組む語はすべて青のドラムから印刷します。チップは25%の網（4.85:1）の上に青のSpace Monoを置き、ピンクの輪郭で囲みます。キャプションも同じ網の上の青のEpilogueです。ピンクで刷るのは、引用の上の帯、チップの輪郭、行頭記号、ノンブルの正方形、表題のずらした複製です。線画の中の文字は絵の一部なので、絵と一緒にピンクで刷られます。話し手の名前は囲みの見出しで、引用の上に7.5 ptの太字のSpace Monoの大文字で組みます。

### 5 · 挿図を注記の横に置く

<Excerpt region="drawn" />

1段組みではフロートはその帯の幅全体を占めるので、小さな絵をそこにフロートとして配置すると帯の残りが空いてしまいます。そこで挿図は見出しのデザインにします。`### As drawn {style="drawn" note="…"}`は絵を印刷し、その右に見出しをラベルとして、その下に注記を置きます。絵はデザインが確保する高さに数えられるので、注記が短くなっても、次のブロックは絵の下から始まります。`registerSnapshot()`は同じ`network()`の地図をPNGに描きます。単色化はSVGの色しか置き換えないので、挿図は画面でもPDFでも6色を保ちます。

## アレンジ

### オレンジのドラムを入れる

月、地図、表示幕、チップ、帯、2つの表題のずらした複製がオレンジになり、文字は青のままです。キャプション、注記、奥付は、書き換えるまでピンクのドラムの名前を挙げたままです。

```diff
-const DRUMS = { ink: '#1d4fb8', spot: '#f0509a' };
+const DRUMS = { ink: '#1d4fb8', spot: '#ff6c2f' };
```

### 2色刷りの教科書を刷る

白い紙に黒の文字と青の特色を使うと、同じ線画が2色刷りの教科書の図のように青の濃淡で印刷されます。キャプション、注記、奥付は、書き換えるまでピンクのドラムの名前を挙げたままです。

```diff
-const DRUMS = { ink: '#1d4fb8', spot: '#f0509a' };
-const PAPER = '#f3efe6'; // cream stock: where no ink falls
+const DRUMS = { ink: '#1f1f1f', spot: '#0078bf' };
+const PAPER = '#ffffff'; // white stock: where no ink falls
```

## よくあるつまずき

- PDFでの置き換えはSVGのマークアップを書き換えます。対象は16進の色、`rgb()`、`rgba()`、`hsl()`、`hsla()`と、キーワードの`white`と`black`です。`red`と名指しした図形や、塗りを既定の黒のままにした図形はPDFでその色を保ち、3つ目のドラムが必要になります。塗りと線にはすべて16進値を指定してください。
- `colorSpace: 'grayscale'`はpostextが描くものをグレーにし、ビットマップはそのまま埋め込むので、PNGの挿図はグレーの校正刷りでもカラーのままです。校正刷りを生成するのはCodePenのサンプルの2つ目のボタンだけです。上のページはCanvasで、このページで提供しているPDFはカラーのほうです。
- 段末そろえは、上部のフロートの下で、前のページから続く段落の残りの前に1行分の空きを残すことがあります。`headings.balancing.stretchAfterFloats: false`を指定すると、本文はフロートのすぐ下に付きます。ここの本文ではそれが起きません。本文を書き換えたら地図の下の最初の行を確かめてください。1行増えるだけで挿図が5ページ目に押し出されることがあります。
- CodePenのサンプルでは、どちらのボタンにも「Build the PDF」と書かれています。1つ目がカラーのPDFを、2つ目がグレーの校正刷りを生成します。ファイルができると、そのボタンは「Open the PDF ↗」リンクと、ファイル名の付いたダウンロードリンクに置き換わります。
