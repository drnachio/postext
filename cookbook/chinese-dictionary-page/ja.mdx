## できあがり

『康熙字典』（1716年）の読者向けの版から、中ほどの4ページを取り出し、天（tiān）から庭（tíng）までピンイン順に並べ替えたものです。見出し字は赤の宋体Blackで組み、上にピンインを添えます。韻書の読み（反切）と字義は1つの段落に続け、字義には同じ赤で①②と番号を付けます。判型は大32开、140 × 203mm。小五（9pt）の17字詰め2段を31行のグリッドに組み、どの段も最後の行まで埋めます。各ページの小口側の隅にある柱は、そのページの最初と最後の見出し字を示すので、蜩を探す読者は柱が「腆—髫」のページを開きます。比べるなら、ラテン文字の辞書<RecipeLink slug="dictionary-thumb-index">The Sailor’s Word-Book</RecipeLink>があります。

## 作り方

### 1 · 見出し字から柱の見出し語を作る

コードは上の[手短な答え](#手短な答え)にあります。見出し字はどれもレベル2の見出しで、`{firstMark.h2}`と`{lastMark.h2}`は、そのページで始まる最初と最後のレベル2見出しのテキストを印字します（[テキスト要素](/ja/docs/configuration#テキスト要素)）。マークになるのは見出しの文字です。`## {天|tiān}`は天をマークし、読みは見出し字の上に残ります。あるページから次のページへ続く項目は、見出し字のあるページでだけ数えます。<PageRef page={2}>635ページ</PageRef>は殄の終わりで始まり、柱は「腆—髫」です。レベル1はアルファベットの見出し用に取ってあります。この4ページでは1つも始まりませんが、アルファベットの見出しは柱の見出し語には数えられません。

### 2 · 見出し字の上にピンイン

<Excerpt region="headwords" />

`{天|tiān}`は`:ruby[天]{rt="tiān"}`の短縮形で、1文字に1つの読みを付けます（[中国語の記号、ルビ、割注](/ja/docs/document-format#中国語の記号ルビ割注)）。独自のデザインを持たない見出しは読みを組みますが、見出しにデザインを付けると天だけが印字されます。読みは、`cjk.ruby.fontFamily`で書体を指定しないかぎり見出しと同じBlackになるので、レギュラーの宋体を指定しています。15ptの半分は7.5ptで、見出しの30ptの行には見出し字の上にそれを置く余地があります。そのため見出しはグリッド2行分になり、その下の本文は両段とも15ptの行に乗ったままです。ピンインの読みは、その書体のディセンダーの深さに0.04emを足した分だけ持ち上がるので、tīngのgは汀の仮想ボディの0.6pt上で終わります。

### 3 · 1項目を1段落に

<Excerpt region="senses" />

『康熙字典』は項目を追い込みで組みます。まず韻書の読み、続いて又で始まる各字義です。ここでは又を丸数字に替えて`**②**`と入力し、`boldColor`で見出し字と同じ朱色に印字しています。本文にほかの太字はありません。『康熙字典』が別の読みを示す字義は、跳の②が徒刀切を持つように、自分の読みを保ちます。組版処理は①から⑳を漢字として扱うので、行が番号で終わってその字義が次の行から始まることはなく、番号と本文の間に漢字と欧文の間のアキも入りません。番号はそのまま入力すれば足ります。段末そろえはオフ（`headings.balancing.enabled: false`）なので、見出し字の上にアキを作る段はなく、どの項目も前の項目と同じ間隔で続きます。

### 4 · Tのつめ

<Excerpt region="tab" />

ピンインの音節は26文字のうち23文字で始まる（I、U、Vで始まるものはない）ので、版面の高さを7.13mmずつ23段に分け、Tは19番目を占めます。つめは幅9mmで、仕上がり線の3mm外から始まるので、小口では断裁で角がまっすぐに切られ、丸みが見えるのは内側の角だけです。`page.cutLines`を指定した印刷用ファイルなら、その3mmは裁ち落としに入ります。文字はページの内側に残る6mmの中央に置きます。4ページともTの範囲なので、つめは同じ高さにとどまります。<RecipeLink slug="dictionary-thumb-index">The Sailor’s Word-Book</RecipeLink>では、文字が変わるたびにつめが小口を下へ移っていきます。

### 5 · 書体ごとに自分の字を読み込む

<Excerpt region="voices" />

Fontsourceは中国語の書体を文字範囲ごとに100ほどのファイルに分けており、`loadCjkFonts`は渡されたテキストを含むファイルを読み込みます。レギュラーの宋体には、奥付の英語も含めて見本全体を渡します。Blackには30の見出し字、ボールドのウェイトには字義の番号、黒体には見出し字と柱の数字、楷体には奥付の中国語の1文を渡します。`cjkPdfProvider`は同じファイルをPDFに埋め込み、それぞれをページで使う文字だけに絞ります。

## アレンジ

### 偶数ページに最初の見出し字、奇数ページに最後の見出し字

1ページに柱の見出し語を1つだけ出す辞書もあります。偶数ページの上に最初の見出し字、奇数ページの上に最後の見出し字を置くので、見開きは天…髫と読めます。

```diff
-  head('verso-guide', '{firstMark.h2}—{lastMark.h2}', 'even', SIDE + 8, GUIDE),
-  head('recto-guide', '{firstMark.h2}—{lastMark.h2}', 'odd', SIDE + 8, GUIDE),
+  head('verso-guide', '{firstMark.h2}', 'even', SIDE + 8, GUIDE),
+  head('recto-guide', '{lastMark.h2}', 'odd', SIDE + 8, GUIDE),
```

### ɑとɡのピンイン

中国語の辞書は、ピンインを1階建てのaとgを持つ書体で組みます。読みにAndikaを指定し、`FONTS`に加えます（`'Andika': ['400']`、OFLのクレジットも添えて）。

```diff
-  ruby: { fontFamily: SONG, fontSize: em(0.5), color: col('cinnabar') },
+  ruby: { fontFamily: 'Andika', fontSize: em(0.5), color: col('cinnabar') },
```

### 本文と同じ大きさの見出し字

小型の辞書は、見出し字を段落の頭に太字で組みます。項目を`:::paragraphs{style="entry"}`に入れ、それぞれを`**{天|tiān}**`で始めて、`{firstMark.entry}`を印字します。太字の連なりで始まる段落は、その文字でページにマークを付けます。

## よくあるつまずき

- 段末そろえをオンにすると、次の見出し字をその下の本文2行（`bodyText.widowMinLines`）とともに入れられない段は早めに終わり、余った行は見出し字の上に、多くても1行ずつ配られます。そのため、前の項目から1行離れる項目と離れない項目ができます。オフなら、そのような段は短く終わります。
