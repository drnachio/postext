## 成品一览

一部《康熙字典》（1716）读者版中间的四页，按拼音从天 tiān排到庭 tíng。每个字头用红色的特粗宋体，上方标拼音；韵书读音（反切）和各义项接在同一段里，义项以同样的红色①②编号。开本为大32开，140 × 203 mm，两栏，每栏17个小五（9 pt）字，网格31行，每栏都排满到最后一行。每页外侧上角的书眉标出本页第一个和最后一个字头，所以查蜩的读者会翻到书眉为腆—髫的那一页。可以拿拉丁字母字典<RecipeLink slug="dictionary-thumb-index">The Sailor’s Word-Book</RecipeLink>来对照。

## 做法

### 1 · 从字头取书眉检字

代码见上文的[简短回答](#简短回答)。每个字头都是一个二级标题，`{firstMark.h2}`和`{lastMark.h2}`印出本页开始的第一个和最后一个二级标题的文字（[文本元素](/zh/docs/configuration-page-layout#文本元素)）。标记取的是标题中的汉字：`## {天|tiān}`标记的是天，读音仍在字头上方。从一页跨到下一页的词条，只在字头所在的那一页计入：<PageRef page={2}>第635页</PageRef>以殄条的结尾开始，书眉却是腆—髫。一级标题留给字母：这四页中没有字母开篇，不过即使有，字母标题也不会算作检字字头。

### 2 · 字头上方的拼音

<Excerpt region="headwords" />

`{天|tiān}`是`:ruby[天]{rt="tiān"}`的简写，一个字上方标一个读音（[中文标记、注音与割注](/zh/docs/document-format#中文标记注音和双行夹注)）。没有自己版面设计的标题会排出注音；如果标题用了版面设计，就只印出一个天。注音默认使用标题本身的字体，即特粗宋体，除非`cjk.ruby.fontFamily`另外指定，所以这里指定了常规宋体。15 pt的一半是7.5 pt，标题30 pt的行高在字头上方为它留出了空间，因此标题占网格两行，下方的正文在两栏中都仍落在15 pt的行上。拼音注音会抬高其字体降部的深度再加0.04 em，所以tīng的g在汀的字身框上方0.6 pt处结束。

### 3 · 一个词条一段

<Excerpt region="senses" />

《康熙字典》的词条是连排的：先是韵书的读音，然后每个义项以“又”引出。这里把“又”换成了圈码，写作`**②**`，由`boldColor`用字头的朱红色印出；正文中没有别的粗体。《康熙字典》另有读音的义项，保留它自己的读音，如跳②的徒刀切。排版器把①到⑳按汉字排：行尾不会出现编号而它的义项到下一行才开始，编号与其后的文字之间也不加中西文间距，所以编号照原样输入即可。各栏齐底已关闭（`headings.balancing.enabled: false`），所以没有哪一栏会在字头上方加空，每个词条与前一条的间距都相同。

### 4 · 字母T的书边索引

<Excerpt region="tab" />

拼音音节以26个字母中的23个开头（没有以I、U、V开头的），所以版心高度被分成23档，每档7.13 mm，T占第19档。书边索引宽9 mm，从裁切线外3 mm处开始，因此裁切后在切口处是方角，只有靠内的两个角显出圆角；如果印刷文件设了`page.cutLines`，这3 mm就落在出血里。字母在页面内的6 mm中居中。四页都在T部，所以书边索引高度不变；<RecipeLink slug="dictionary-thumb-index">the Sailor’s Word-Book</RecipeLink>则让它随字母沿书边逐级下移。

### 5 · 每种字体加载自己的字符

<Excerpt region="voices" />

Fontsource把每种中文字体按字符范围拆成约一百个文件，`loadCjkFonts`只加载包含所给文本的那些文件。常规宋体拿到整个样本，包括版权说明中的英文。特粗宋体拿到三十个字头，宋体粗体拿到义项编号，黑体拿到字头和书眉中的数字，楷体拿到版权说明中那句中文。`cjkPdfProvider`把同样的文件嵌入PDF，每个文件都裁剪到页面上实际用到的字符。

## 变化

### 左页印第一个字头，右页印最后一个

有些字典每页只印一个检字字头，左页上方印第一个，右页上方印最后一个，于是一个跨页读作天……髫。

```diff
-  head('verso-guide', '{firstMark.h2}—{lastMark.h2}', 'even', SIDE + 8, GUIDE),
-  head('recto-guide', '{firstMark.h2}—{lastMark.h2}', 'odd', SIDE + 8, GUIDE),
+  head('verso-guide', '{firstMark.h2}', 'even', SIDE + 8, GUIDE),
+  head('recto-guide', '{lastMark.h2}', 'odd', SIDE + 8, GUIDE),
```

### 用ɑ和ɡ的拼音

中文字典的拼音常用单层a和g的字体。给注音指定Andika，并把它加入`FONTS`（`'Andika': ['400']`，附上它的OFL出处）。

```diff
-  ruby: { fontFamily: SONG, fontSize: em(0.5), color: col('cinnabar') },
+  ruby: { fontFamily: 'Andika', fontSize: em(0.5), color: col('cinnabar') },
```

### 字头与正文同字号

小型字典把字头用粗体排在段首。把词条放进`:::paragraphs{style="entry"}`，每条以`**{天|tiān}**`开头，并印出`{firstMark.entry}`：以粗体开头的段落会用这段粗体标记所在的页面。

## 常见问题

- 各栏齐底开启时，如果某一栏放不下下一个字头及其下方两行正文（`bodyText.widowMinLines`），就会提前结束，剩下的行分到字头上方，每处最多一行：于是有的词条与前一条隔开一行，有的不隔。关闭后，这样的栏会短一截。
