## できあがり

マシャード・ジ・アシスが1899年に発表した小説『Dom Casmurro』の終わり近くから本文5ページを、ポルトガル語の原文のまま、架空の叢書「Coleção Casuarina」の110×178mmのポケット版として組みます。プラム、クリーム、プラムの帯で構成した表紙にはAbril Fatfaceの題と叢書のサフラン色の丸い紋章が載り、拡散モデルで生成したフラメンゴ沖の重い海を描いた口絵が213ページと向かい合います。本文は第CXVIII章の終わりから第CXXIII章の終わりまで続き、ページの頭で始まる章はひとつもありません。各章は前の章の終わりから2行あけて（213ページを埋めるためCXIXだけは3行）、プラムのローマ数字、字間を広げた大文字の題、短いサフラン色の罫の下から始まります。214ページには章見出しが2つ、215ページと216ページには1つずつあります。最後のページを除き、本文のどのページも33行目で終わり、1行だけで始まるページはありません。

## 作り方

### 1 · 章を追い込みで続け、見出しを本文から離さない

<Excerpt region="answer" highlight="17-24" />

章のレベルでは改ページをオフにし、`marginTop`で各見出しを前の章の最終行から2行下に置きます。そのデザインには`span`がないので、見出しは段の中に3行分の深さのブロックとして描かれ、その下の本文はグリッドに乗ったままです（[前で改ページ](/ja/docs/configuration#前で改ページ)、[幅と詳細デザイン](/ja/docs/configuration#幅と詳細デザイン)）。ページをまたぐときの保持の規則は既定値のままです。CXIXとCXXIの下にある4行の段落は、それぞれページの下端に2行を残し、2行を次のページへ送ります。`avoidOrphans: false`にすると3行と1行に分かれ、214ページと215ページは1行だけで始まります（[オーファン、ウィドウ、ラント](/ja/docs/configuration#オーファンウィドウラント分割禁止の規則)）。段末そろえがCXIXの上に3行目の空きを加え、213ページが33行目で終わるようにします（[段末そろえ](/ja/docs/configuration#段末そろえ)）。

<PageShot page={3} crop="0,.683,1,.317" caption="213ページ。第CXIX章はCXVIIIの終わりから3行下で始まり、ページの下端に本文の2行を保ちます。" />

### 2 · ポルトガル語のハイフネーションで33行のページを組む

<Excerpt region="text" />

地の余白は16.3mmです。178mmの高さから天の余白15mmと12.6ptの33行を引いた残りなので、すべての満ページが同じ行で終わります。Times New Romanと同じ字幅を持つTinosを9.5ptで組むと、84mmの行長に1行約59字が入ります。`locale: 'pt'`はポルトガル語のパターンでハイフネーションします。「at-tracção」「af-fluencia」「genealogica-mente」のように分かれます（[対応するロケール](/ja/docs/justification#対応するロケール)）。ポルトガルやブラジルの版の多くと同じく、見出しの直後の最初の段落も含めてすべての段落を字下げするので、`indentAfterHeading`は既定値のままです。

### 3 · 偶数ページの柱に書名、奇数ページの柱に章名

<Excerpt region="heads" />

`{title}`はフロントマターの題を、`{chapterTitle}`はそのページかそれより前で始まった最後の章を印刷します。そのため217ページの柱は216ページで始まったCXXIIIの名を示します（[テキスト要素](/ja/docs/configuration#テキスト要素)）。213ページの柱は、最初の25行でCXVIIIを締めくくっているにもかかわらず、下端で始まるCXIXの名を示します。`{chapterTitleAtTop}`ならページの頭が属する章を示しますが、この抜粋にはCXVIIIの見出しがありません。`SHIFT`は柱を版面の中央へ移します。のどの余白が小口より2mm広いので、ページの中央から1mmずれます。

### 4 · 表紙と口絵を見出しとして描く

<Excerpt region="cover" />

どちらも`numbered: false`を付けた[見出しスタイル](/ja/docs/configuration#見出しスタイル)なので、最初の番号付きの章はやはりCXIXです。`span: 'page'`でそれぞれを扉のページにします。これがないと、表紙の下の帯と口絵の絵は版面の下端で止まり、柱とノンブルが両方のページに印刷されます。口絵のキャプションは見出しから作られます。CAPÍTULO CXXIIIが見出しのテキストで、イタリックの引用はその`quote`属性です（[見出しの属性](/ja/docs/document-format#見出しの属性)）。どちらのデザインもページの下端まで届くので、見出しはページ全体を確保し、本文は`:::pagebreak`なしで次のページから始まります。

### 5 · 抜粋に本の中での位置を伝える

<Excerpt region="excerpt" />

`continuation.headings`は、抜粋が始まる時点の見出しのカウンターを与えます。`h1: 118`で最初の番号付き見出しが第CXIX章になります。これがないと5つの章はIからVと番号が振られます。章のレベルの`numberingTemplate: '{1:I}'`がその番号をローマ数字にし、デザインは`{number}`でそれを印刷します。表紙の改ページの後にある`:::numbering{startAt=212}`は、口絵を212、本文のページを213から217とします（[番号付け](/ja/docs/document-format#numbering)）。

## アレンジ

### 章ごとに新しいページで始める

各章の前で改ページすると、本文の5ページは7ページになります。214ページにはCXIXの見出しと4行しか入らず、章が始まらない213ページは口絵の題CAPÍTULO CXXIIIを柱にします。

```diff
-  breakBefore: { enabled: false }, marginTop: pt(2 * LEAD), advancedDesign: chapterHead };
+  breakBefore: { enabled: true, parity: 'any' }, marginTop: pt(2 * LEAD),
+  advancedDesign: chapterHead };
```

### 奇数ページの柱に章番号を入れる

`{chapterNumber}`は、題を取るのと同じ章の数字を印刷します。「CXIX · NÃO FAÇA ISSO, QUERIDA」となります。

```diff
-  head('recto-chapter', '{chapterTitle}', 'odd', SHIFT),
+  head('recto-chapter', '{chapterNumber} · {chapterTitle}', 'odd', SHIFT),
```

## よくあるつまずき

- `widowMinLines`を3に上げると、CXIXの下の4行の段落は分ける場所がなくなります。3行と1行に分ければ、214ページが1行だけで始まるからです。見出しは本文と一緒に次のページへ移り、213ページは6行短く終わります。
- CXVIIIが数行増えると、CXIXの見出しの下には1行分の場所しか残りません。すると`keepWithNext`が見出しを214ページへ送り、213ページは4、5行足りないまま終わります。`keepWithNext: false`にすると、見出しが本文を伴わずに213ページの最後に来ます。
- 口絵はH1なので、`{chapterTitle}`は口絵に戻ってしまいます。CXIXが先へ移ったときの213ページのように、口絵の後でまだ章が始まっていない本文のページは、CAPÍTULO CXXIIIを柱に印刷します。口絵のスタイルに`runningChapter: false`を指定すると、柱は口絵を飛ばします。
- `avoidRunts`をオフにすると、本の最後の行は「nadador da manhã.」ではなく「manhã.」だけになります。
- これらの改ページが成り立つのは、このテキストを9.5/12.6ptで84mmの行長に組んだときだけです。テキスト、サイズ、行長を変えたら、すべてのページの下端とすべての見出しの上の空きを見直してください。
