## できあがり

唐詩を集めた小さな対訳本を、古典の対訳版の組み方で組みます。中国語は右ページに、古い紙のような色を付けた丁に置き、その向かいの左ページにハーバート・A・ジャイルズによる1901年の押韻の英訳を置きます。李白、杜甫、王維の4篇の詩がそれぞれ見開きを占め、各言語で表題が付き、詩人の名前が添えられます。中国語は筆の運びを写した楷書体のLXGW WenKaiで、詩句2句を1行に組みます。こうすると各行が、それを訳した英語の2行と同じ高さに並びます。読み手の言語による注釈は、中国語のページの下に置きます。<RecipeLink slug="bilingual-facing-verse">対訳の詩を連ごとにそろえる</RecipeLink>はスペイン語の詩とその英訳を1ページに並べて組みますが、ここでは言語ごとに1ページを使います。

## 作り方

### 1 · 見開きの左右それぞれに見出しスタイルを

コードは上の[手短な答え](#手短な答え)にあります。各詩は第1レベルの見出し2つでできています。ジャイルズの訳詩を収めた`# Night Thoughts {style="en" …}`と、詩を収めた`# 靜夜思 {style="zh" …}`です。`en`のスタイルは次の偶数ページへ、`zh`のスタイルはそれと向かい合う次の奇数ページへ改ページします。各詩が1ページに収まっているあいだは白ページは入りません。英訳がページからあふれると、原文は白の偶数ページをはさんで次の奇数ページへ押し出されます（[前で改ページ](/ja/docs/configuration#前で改ページ)）。どちらのデザインもグリッドの6行分を確保するので、英語と中国語は同じ行から始まります。中国語のスタイルには`span: 'page'`を指定します。最初の要素であるページ大のボックスが色の付いた丁で、段の中に置いたデザインは段の下端で止まってしまうからです（[幅と詳細デザイン](/ja/docs/configuration#幅と詳細デザイン)）。

### 2 · 中国語の1行に英語の2行

<Excerpt region="verse" />

中国語の行送りは英語の2倍で、16 ptに対して32 ptです。五言の句を2つ並べた1行が、ジャイルズがそれを訳した2行の対句と向かい合います。<PageRef page={4}>4〜5ページ</PageRef>の月の詩では、両方の文章に同じ`:::space{lines=1}`を入れているので、3つの連が見開きをまたいで同じ高さにそろいます。中国語の行は51 pt字下げして始まります。これでグリッドの28字分の中で12字分が中央に来ます。各注の合印は行の。のあと、12字分の外に置きます。行の中に置くと、それより後ろの字がすべて0.6 em右へずれ、下の行とそろわなくなります。英語の字下げは、各詩のいちばん長い行を測って決めます。ジャイルズは1行おきに字下げしています。Markdownはその2つのスペースを残し、`indentVerse`がそれを単語結合子のあとのemスペースに変えます。段落は先頭のスペースを捨ててしまうからです。

### 3 · 中国語のページの下に注釈

<Excerpt region="notes" />

注釈は脚注で、1行に1つです。`疑是地上霜。[^bed]`が詩の1行目を閉じ、そのあとに`[^bed]: …`が続きます。番号はもう語の横にないので、注は注釈する語をボールドで示します。番号は中国の本が注に振るのと同じ形（页下注）で、ベースラインに置いた丸数字を、ページごとに①から数え直します（`numberFormat: 'circled-decimal'`、`numbering: 'page'`）。詩の中の合印は詩の文字の0.6倍、`markerSize: em(0.6)`で、注の文字に近い大きさです。ページの下では、各注は注の文字と同じ大きさの①で始まります（[脚注](/ja/docs/configuration#脚注)）。注は本文の書体で組まれます。注釈には漢字とピンインが混ざるので、この本の本文の書体はNoto Serif TCです。Noto Serif TCのラテン文字はSource Serifに由来するので、英語のページもSource Serif 4で組んでいます。注は版の言語で書きます。偶数ページの柱と本文についての注記とあわせて、スペイン語版で変わるのはこの部分です。

### 4 · 柱はそのページの言語で

<Excerpt region="heads" />

この本はどのページも見出しで始まるので、どのページも章扉で、柱には`pages: 'opener'`を指定します。改ページで加わった白ページには柱が付かず、扉のページは自分の空のヘッダーで柱を消します。偶数ページはフロントマターの`subtitle`から本の表題を取り、各版がそれぞれの言語でそれを書きます。奇数ページは中国語の見出しの`name`属性から詩人の名前を取ります（[柱とノンブル](/ja/docs/configuration#柱とノンブル)）。

### 5 · 月の上の扉

<Excerpt region="title" />

扉のページも見出しスタイルで、`runningChapter: false`にして章の名前を出しません。月は角の半径を1辺の半分にしたデザインのボックスで、唐詩は計算でその中央に置きます。月の中心から表題の高さの半分を引いた位置です。印は`writingMode: 'vertical-rl'`で明月を組み、印章を彫るときのように2字を縦に重ねます。

### 6 · 中国語の各書体は、組む文字だけを読み込む

<Excerpt region="voices" />

Fontsourceは中国語の各書体を文字の範囲でおよそ100のファイルに分けていて、`loadCjkFonts`は文字に必要なファイルだけを取得します（[中国語・日本語・韓国語のフォント](/ja/docs/configuration#中国語日本語韓国語のフォント)）。楷書体は詩と印を、黒体は詩人の行と名前を、宋体のボールドは4つの表題と注の見出し語を、そのブラックのウェイトは扉の2字を組みます。

## アレンジ

### 原文を偶数ページに置く

ローブ古典叢書（Loeb Classical Library）や多くの中英対訳の読本は、原文を左に置きます。2つの見出しスタイルと、本の表題と詩人の名前を出す2つの柱の奇偶を入れ替え、Markdownでは中国語の見出しと詩を英語の前に書きます。

```diff
-const english = { id: 'en', breakBefore: { enabled: true, parity: 'even' }, // a verso
+const english = { id: 'en', breakBefore: { enabled: true, parity: 'odd' }, // a recto
-const chinese = { id: 'zh', span: 'page', breakBefore: { enabled: true, parity: 'odd' },
+const chinese = { id: 'zh', span: 'page', breakBefore: { enabled: true, parity: 'even' },
-  head('verso-book', '{subtitle}', 'even', 'top-left', EDGE + 8,
+  head('verso-book', '{subtitle}', 'odd', 'top-right', -(EDGE + 8),
-  head('recto-poet', '{attr.name}', 'odd', 'top-right', -(EDGE + 8),
+  head('recto-poet', '{attr.name}', 'even', 'top-left', EDGE + 8,
```

### 注釈を詩のすぐ下に置く

中国の注釈付きの詩選（注釋本）は、注を各詩のあとに印刷します。ここでは各詩がそれぞれ1章なので、章末の注で同じことができます。

```diff
-const footnotes = { placement: 'column', numbering: 'page', // the page foot; ① again on each page
+const footnotes = { placement: 'chapterEnd', chapterEndAlign: 'text',
```
