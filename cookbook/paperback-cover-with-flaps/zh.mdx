## 成品一览

贝克尔的两篇传说《The Spirits’ Mountain》和《The Emerald Eyes》（西班牙文原题《El monte de las ánimas》《Los ojos verdes》），排成120 × 190毫米、带60毫米勒口的口袋本平装书，另外还有印封面用的整张印张。Postext先排好37页内页：半书名页、书名页、版权页、目录、每篇传说一张标题页，然后是Crimson Pro 11/15.2的正文。接着`buildCover`拿这些页面拼出印张：后勒口、带简介和条码的封底、书脊、画着蒙卡约山下一座废弃小教堂的封面，以及前勒口。书名、副书名和作者取自书的元数据，勒口上的文字来自单独的一份Markdown。

## 做法

### 1 · 装订决定勒口，纸张决定书脊

代码就是上面的[简短回答](#简短回答)。装订配置写的是装订厂的做法：PUR胶装，16页一个书帖，勒口60毫米，出血3毫米，书脊再加0.5毫米留给胶。版本里写着ISBN和五位附加码；这个ISBN是示例号码，不属于任何一本书。书脊宽度在哪里都没有写。37页向上取整为三个书帖，也就是48页、24张，每张100 g/m²、松厚度2.4的纸厚240微米：24 × 0.24 + 0.5，书脊为6.3毫米。默认情况下书脊不足6毫米就不印字（`spineText.minSpine`），所以这本书用的是松厚的纸。

### 2 · 先排内页

<Excerpt region="pages" />

书芯就是一份普通的Postext文档，它的每一页都算进书脊。前置页用标题样式，样式里的设计把书名、线条和出版社名放在页面上固定的高度。每篇传说都有自己的标题页（目录指向的就是它），正文在下一个右页重新开始，往下沉40毫米。改了字号或页边距，页数就会变，书脊在下一次排版时跟着变。

### 3 · 封面的样式和书的样式放在一起

<Excerpt region="cover-type" />

印张用书的配置来排，所以它的段落样式和版权页、版本记录的样式在同一个列表里。`cover-title`、`cover-subtitle`、`cover-author`和`cover-spine`是`buildCover`给它放置的元数据起的名字；`cover-blurb`、`cover-note`、`flap-head`和`flap-text`则由封面的Markdown指定。在夜色底上，文字左对齐、不断字，用调色板里的骨白和金色。

### 4 · 印张由排好的内页生成

<Excerpt region="sheet" />

`buildCover`接收页面、元数据和封面的Markdown，封底一个`:::frame`，每个勒口各一个。它返回一份文档，由`buildDocumentWithFonts`像别的文档一样排版，另外还有一个SVG格式的条码文件。条码的数字要求OCR-B字体，任何字体服务器都没有，所以示例把它们换成Josefin Sans，PDF本来就会嵌入这个字体。PDF里先是37页内页，后面是按自身尺寸输出的印张，印厂要的正是这样的文件。

## 变化

### 书脊文字从下往上排

默认的书脊文字从上往下排，符合ISO 6357，英美的书也是这样，书平放、封面朝上时字是正的。西班牙和欧洲大陆较旧的习惯是从下往上排。

```diff
   versions: [{ id: 'paperback', name: t({ en: 'Paperback', es: 'Rústica' }), binding: 'pur-flaps',
-    flaps: true, isbn: '978-84-0000-196-4', isbnAddOn: '90000' }],
+    flaps: true, isbn: '978-84-0000-196-4', isbnAddOn: '90000',
+    spineText: { direction: 'bottomToTop' } }],
```

### 换用薄一些的纸

80 g/m²、松厚度2.2的纸每张厚176微米，书脊降到4.7毫米，书脊上的字也就没了，因为它需要6毫米。

```diff
-const folio = { paper: { type: 'bookWove', grammage: 100, bulk: 2.4, shade: '#f7f1e3' } };
+const folio = { paper: { type: 'bookWove', grammage: 80, bulk: 2.2, shade: '#f7f1e3' } };
```

## 常见问题

- 在截取的页面列表里，印张排在书的页面后面，所以它的页号是书的页数加一。书多了一页，这个页号就会变。
- 条码的数字如果要求一种PDF找不到的字体，导出就会失败。加载它的SVG时，把`font-family`换成示例已经加载的字体。
