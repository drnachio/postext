## できあがり

ベッケルの伝説2編、『The Spirits’ Mountain』と『The Emerald Eyes』（原題『El monte de las ánimas』『Los ojos verdes』）を、120 × 190 mm、袖60 mmの並製本にします。表紙を刷る用紙も一緒に作ります。Postextはまず37ページを組みます。半扉、扉、権利表記、目次、伝説ごとの扉、そしてCrimson Pro 11/15.2の本文です。次に`buildCover`がそのページを受け取り、用紙を組み立てます。後ろ袖、紹介文とバーコードの入った表4、背、モンカヨ山のふもとの廃墟の礼拝堂を描いた表1、前袖です。書名、副題、著者名は本のメタデータから、袖の文字は別のMarkdownファイルから取ります。

## 作り方

### 1 · 袖は製本が、背は紙が決める

コードは上の[手短な答え](#手短な答え)にあります。製本プロファイルには製本所の仕事の仕方を書きます。16ページ折のPUR無線綴じ、袖60 mm、裁ち落とし3 mm、糊の分として背に0.5 mm足す、という具合です。版にはISBNと5桁のアドオンを入れます。このISBNは見本の番号で、どの本にも割り当てられていません。背幅はどこにも書きません。37ページは3折、つまり48ページ・24枚に切り上げられ、100 g/m²で嵩高2.4の紙は1枚240 µmなので、24 × 0.24 + 0.5で背幅は6.3 mmになります。標準では6 mm未満の背には文字を入れません（`spineText.minSpine`）。この本が嵩高の紙を使うのはそのためです。

### 2 · まず本文を組む

<Excerpt region="pages" />

本文はふつうのPostext文書で、そのページがすべて背幅に効きます。前付けは見出しスタイルを使い、そのデザインで書名、罫線、版元名をページ上の決まった高さに置きます。伝説ごとに専用の扉があり（目次が指すのはこの扉）、本文は次の奇数ページから40 mm下げて始まります。文字の大きさや余白を変えればページ数が変わり、次に組むとき背幅もそれについてきます。

### 3 · 表紙のスタイルは本のスタイルと一緒に置く

<Excerpt region="cover-type" />

用紙は本の設定で組むので、表紙の段落スタイルは権利表記や奥付のスタイルと同じリストに入ります。`cover-title`、`cover-subtitle`、`cover-author`、`cover-spine`は、`buildCover`が配置するメタデータに付ける名前です。`cover-blurb`、`cover-note`、`flap-head`、`flap-text`は表紙のMarkdownが指定します。夜の地色の上では、文字は左揃えでハイフネーションなし、パレットの象牙色と金色で組みます。

### 4 · 組んだページから用紙を作る

<Excerpt region="sheet" />

`buildCover`はページ、メタデータ、表紙のMarkdownを受け取ります。Markdownには表4用の`:::frame`と、袖ごとに1つずつの`:::frame`があります。返ってくるのは`buildDocumentWithFonts`でほかの文書と同じように組める文書と、SVGファイルのバーコードです。バーコードの数字はOCR-Bを指定していますが、どのフォント配信サーバーにもないので、この例ではPDFがすでに埋め込むJosefin Sansに置き換えています。PDFには37ページのあとに用紙がそれ自身の大きさで続きます。印刷所が求めるのはこの形のファイルです。

## アレンジ

### 背の文字を下から上へ

標準では背の文字は上から下へ並びます。ISO 6357の定めで、英米の本もこの向きです。表紙を上にして置くと正しく読めます。スペインやヨーロッパ大陸の古い習慣では下から上へ並べます。

```diff
   versions: [{ id: 'paperback', name: t({ en: 'Paperback', es: 'Rústica' }), binding: 'pur-flaps',
-    flaps: true, isbn: '978-84-0000-196-4', isbnAddOn: '90000' }],
+    flaps: true, isbn: '978-84-0000-196-4', isbnAddOn: '90000',
+    spineText: { direction: 'bottomToTop' } }],
```

### 薄い紙に刷る

80 g/m²で嵩高2.2なら1枚176 µmで、背幅は4.7 mmに減り、6 mm必要な背の文字が消えます。

```diff
-const folio = { paper: { type: 'bookWove', grammage: 100, bulk: 2.4, shade: '#f7f1e3' } };
+const folio = { paper: { type: 'bookWove', grammage: 80, bulk: 2.2, shade: '#f7f1e3' } };
```

## よくあるつまずき

- キャプチャしたページの一覧では用紙が本のページのあとに来るので、その番号は本のページ数に1を足したものです。本が1ページ増えれば番号も変わります。
- バーコードの数字がPDFの見つけられないフォントを指定していると、書き出しに失敗します。SVGを読み込むとき、`font-family`をこの例が読み込み済みのフォントにしてください。
