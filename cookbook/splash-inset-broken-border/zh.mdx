## 成品一览

《珀斯科夫灯塔》里暴风雨的两页。第一页是满版大图：一幅暴风雨中的灯塔铺满整页，四边都出血，右下角叠着一个带框的小格子，画着窗前的玛雅。第二页开头是一道三边出血的巨浪；下面，一只海鸥从守塔人那一格飞出，越过边框；旁边一个没有画面的窄格，在藏青底色上放了两个旁白框。开本是美式漫画书的 168 × 259 mm，出血 3 mm，有六种语言的版本。

## 做法

### 1 · 让满版大图四边出血

代码就是上面的[简短回答](#简短回答)。`split="*"` 让整个画框只有一个格子，页面上的 `bleed` 让碰到画框的每一格都延伸到出血框，超出裁切线 3 mm，这几边不画边框（[分割页面](/zh/docs/comics#分割页面)）。第2页上，巨浪那一格的 `bleed="top start end"` 只让这三边出血，底边仍和下面的格子保持格间距。`start` 和 `end` 跟随阅读方向，所以阿拉伯文版出血的边也一样。

### 2 · 在大图上叠一个插格

`inset="56 64 38 30"` 把玛雅那一格放在前一格的 56%、64% 处，宽 38%，高 30%。插格不占格子：它叠在大图上，有自己的边框，阅读时紧跟在大图之后。它的画面按自己的安全区裁切到自己的框里，这里保留的是玛雅的脸。

### 3 · 让海鸥飞出边框

<Excerpt region="art" />

`pop=sp-tomas-pop` 给守塔人那一格加第二张图：一张和他的画一样大小的透明 PNG，上面只有海鸥。Postext 用和这格画面完全相同的方式裁切、摆放它，然后在边框之后、不受格子裁剪地画出来，于是海鸥伸出格子的部分就飞过了边框和页边（[分格与画面](/zh/docs/comics#分格与画面)）。`focus="45% 50%"` 在安全区允许的范围内把取景往左移，让海鸥横跨左边框，而不是整只落在页边上。

### 4 · 留一个没有画面的格子

<Excerpt region="palette" />

没有 `art` 的 `::panel` 是一个空格子，带着格子样式的边框；`bg=night` 用调色板里的颜色填满它。它的两个旁白框 `at=top` 和 `at=bottom` 分别贴着上下边，是暴风雨之后的一个停顿。

## 变化

### 下面一层也出血

```diff
-::panel{art=sp-tomas pop=sp-tomas-pop focus="45% 50%"}
+::panel{art=sp-tomas pop=sp-tomas-pop focus="45% 50%" bleed="bottom start"}
```

### 给插格加白框

命名的格子样式只改一个格子，在格子上用 `style=` 选用。

```diff
   panel: { borderWidth: pt(1.2), borderColor: col('ink'), background: col('paper') },
+  panelStyles: [{ id: 'framed', borderWidth: pt(3), borderColor: col('paper') }],
```

## 常见问题

- 破格用的图层必须和这一格画面的像素尺寸完全一样：Postext 用同一个窗口裁切它，小一号的抠图会落到别的位置。
- 出血需要设置 `page.bleed`；没有它，出血的格子只到裁切线为止。
- 靠近出血边的拟声词可能伸进出血区，越过裁切线，被裁刀切掉。日文的“ザッバーン”是五个字高的竖行，所以固定得比拉丁字母的拟声词低，放在 `60% 44%`。
