## できあがり

『ポースコーヴの灯』の嵐の2ページです。1ページ目はスプラッシュで、嵐の中の灯台を描いた一枚の絵がページの四方の外まで広がり、下の角に窓辺のマヤを描いた枠つきの小ゴマが重なります。2ページ目は三方を裁ち切った波で始まり、その下で一羽のカモメが灯台守のコマから枠を越えて飛び出します。絵のない細いコマには、紺色の地にナレーションが二つ。判型はアメリカのコミックブックの168 × 259 mm、裁ち落とし3 mmで、六言語で出ます。

## 作り方

### 1 · スプラッシュを四方とも裁ち切りにする

コードは前の[手短な答え](#手短な答え)にあります。`split="*"`で枠全体を一つのセルにし、ページの`bleed`で枠に接するコマをすべて仕上がり線の3 mm外の裁ち落とし枠まで伸ばします。その辺には枠線を描きません（[ページの分割](/ja/docs/comics#ページの分割)）。2ページ目の波のコマは`bleed="top start end"`で、その三辺だけを裁ち切りにし、下の辺は下のコマとのコマ間を残します。`start`と`end`は読む方向に従うので、右から左へ読む日本語版とアラビア語版でも同じ辺が裁ち切りになります。

### 2 · スプラッシュに小ゴマを重ねる

`inset="56 64 38 30"`は、マヤのコマを直前のコマの56%、64%の位置に、幅38%、高さ30%で置きます。小ゴマはセルを使いません。スプラッシュの上に重なり、自分の枠線を持ち、スプラッシュのすぐ後に読まれます。絵は自分のセーフエリア（ここではマヤの顔）に従って、自分の枠に合わせて切り抜かれます。

### 3 · カモメに枠を破らせる

<Excerpt region="art" />

`pop=sp-tomas-pop`は灯台守のコマに2枚目の絵を与えます。彼の絵と同じ大きさの透明なPNGで、カモメだけが描かれています。Postextはこれをコマの絵とまったく同じように切り抜いて置き、枠線の後に、コマの切り抜きの外まで描きます。そのため、セルの外にはみ出したカモメの部分が枠線と余白の上を飛びます（[コマと絵](/ja/docs/comics#コマと絵)）。`focus="45% 50%"`はセーフエリアが許す範囲でトリミングを左へずらし、カモメが余白に出てしまわず、左の枠をまたぐようにします。

### 4 · 絵のないコマを置く

<Excerpt region="palette" />

`art`のない`::panel`は、コマのスタイルの枠線だけを持つ空のセルです。`bg=night`はそれをパレットの色で塗ります。ナレーションは`at=top`と`at=bottom`で上下の辺に寄せ、嵐の後のひと呼吸にします。

## アレンジ

### 下の段も裁ち切りにする

```diff
-::panel{art=sp-tomas pop=sp-tomas-pop focus="45% 50%"}
+::panel{art=sp-tomas pop=sp-tomas-pop focus="45% 50%" bleed="bottom start"}
```

### 小ゴマに白い縁を付ける

名前つきのコマのスタイルは一つのコマだけを変えます。コマの`style=`で選びます。

```diff
   panel: { borderWidth: pt(1.2), borderColor: col('ink'), background: col('paper') },
+  panelStyles: [{ id: 'framed', borderWidth: pt(3), borderColor: col('paper') }],
```

## よくあるつまずき

- 枠破り用のレイヤーは、コマの絵とまったく同じピクセルサイズにします。Postextは同じ窓で切り抜くので、小さい切り抜きでは別の場所に置かれてしまいます。
- 裁ち切りには`page.bleed`が必要です。ないと、裁ち切りのコマは仕上がり線で止まります。
- 裁ち切りの辺のそばの描き文字は、仕上がり線の外の裁ち落とし部分に入り、断裁で切られることがあります。日本語版の「ザッバーン」は五文字の縦の行なので、ラテン文字の効果音より低い`60% 44%`に固定しています。
