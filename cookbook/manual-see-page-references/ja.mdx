## できあがり

架空のツーリング自転車Ardena T3の取扱説明書です。Archivoで組んだA5判の4ページで、1ページ目の紺の帯に機種名が入ります。取扱説明書は順番どおりには読まれないので、ほかの指示を前提にする指示は、その指示がどこにあるかを書き添えます。「see section 3.2 on page 3」のようにです。書き手は見出し、段落、手順の中の語句に識別子で名前を付け、本文がそれを指すところに`:ref`と書きます。Postextは番号、題、ページのいずれかを印字し、それをリンクにします。表紙の目次も同じ書き方なので、節を移しても、説明書を翻訳して組み直しても、古い番号が残ることはありません。

## 作り方

### 1 · 本文が指すものに名前を付ける

コードは上の[手短な答え](#手短な答え)にあります。見出しにはPandocの識別子を付けます（`### Checking pad wear {#sec-pad-wear}`）。タイヤの空気圧についての警告は、目に見えない印`:anchor{#warn-pressure}`で始まります。車輪を取り付ける最後の手順は`[close the lever so that it points backwards]{#step-close-lever}`と書き、語句はそのまま残して、それに名前を付けます。囲みは`:::callout{#box-wet type="note" title="Wet weather"}`で始まります。手順への参照はその手順の語句を、囲みへの参照は囲みの題を印字します。

### 2 · 1つの参照先に4つの呼び方

`:ref{id="sec-pad-wear"}`は`crossRefs.section`の語を使って「section 3.2」と印字します。`style=page`は`crossRefs.page`の語で「page 3」、`style=title`は「Checking pad wear」、`style=pageNumber`は数字だけの「3」を印字します。表紙の目次は、数字だけの番号、題、数字だけのページを組み合わせるので、目次らしく読めます。スペイン語版では同じ参照が「apartado 3.2」「página 3」と印字されます。テンプレートが版の言語に従うからです。

### 3 · ページは自然に決まる

ページ番号は、説明書をレイアウトしてはじめてわかります。エンジンは説明書をレイアウトし、各参照先が収まったページを読み取り、どの参照も変わらなくなるまでレイアウトし直します。目次を埋めるのと同じループです。翻訳で長くなったテキストや前に移した節がページを変えても、参照は前方にも後方にもそれに従います。

### 4 · 番号はレベル2のカウンターから

<Excerpt region="numbers" />

説明書のレベル1の見出しは表紙の機種名の1つだけなので、節はレベル2から番号を振ります。`{2}`は1から5を、`{2}.{3}`は1.1、1.2を出します。

### 5 · 表紙はその見出しの章扉

<Excerpt region="cover" />

帯の高さはページの半分の104mmで、オレンジの線がそれを閉じます。キッカー、副題、版の行は見出しの属性なので、スペイン語版はそれを自分のテキストの中で変えられます。

## アレンジ

### 参照に「p.」と書く

ページ参照の多い参考書では、略記で紙面を節約します。

```diff
-  page: t({ en: 'page {n}', es: 'página {n}' }), // spelt out: a manual is read by anyone
+  page: t({ en: 'p. {n}', es: 'pág. {n}' }),
```

### 参照を墨のままにする

ページの大半が参照なら、本文の色の太字にとどめます。PDFでも画面でもリンクであることは変わりません。

```diff
-const references = { referenceColor: col('orange'), referenceBold: true };
+const references = { referenceColor: col('ink'), referenceBold: true };
```

## よくあるつまずき

- スタイルを指定しない`:anchor`への参照はページを印字します。目に見えないアンカーには自分の語句がないからです。参照に本文の語句を引かせたいときは`[words]{#id}`を使います。
- 識別子は本の中で一意でなければなりません。参照は最初の`{#sec-brakes}`に届き、Sandboxの**検査**パネルは2つ目を`duplicateAnchor`として示します。
