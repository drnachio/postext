## できあがり

プロビデンスにある架空の活版工房、Quoin Roomの修了証です。受講者ひとりにUSレター1ページを使います。スペイン語版は、サラゴサの工房La CuñaのA4判の証書として組みます。クリーム色のギョーシェのレンズ模様を詰めたティールの帯が紙面を囲み、四隅にはクリーム色のロゼットを置きます。どちらも正弦曲線とハイポトロコイドからコードで描いています。字間を空けた大文字の表題の下に、受講者の名前をPinyon Scriptの48ptで金色の罫の上に組み、文言はRosarivoで中央にそろえます。署名欄のあいだには2本のリボンを垂らした赤い印章を置き、その下に1行の刊記を入れます。ページ全体をひとつの見出しスタイルが描くので、受講者ひとりがMarkdownの見出しひとつにあたり、PDFにはクラス全員が名前ごとのしおりつきで収まります。

## 作り方

### 1 · ひとつの見出しスタイルにページを描かせる

スタイルそのものは上の[手短な答え](#手短な答え)にあります。見出しスタイルは、その節に属するページを受け持ちます（[見出しスタイル](/ja/docs/configuration#見出しスタイル)）。`header`と`footer`は文書のもの（ここでは空）を置き換え、`margins`は本文領域を決め、`advancedDesign`は章扉を描きます。章扉の高さは、17ptの本文グリッドの行単位に切り上げられます。`minHeight`の106 mmは18行になるので、文言は紙の上端から140 mmで始まります。A4では`y()`がこれを112.7 mm、つまり19行にし、文言は146 mmから始まります。表題のブロックだけなら、文言は128 mm（A4では134 mm）から始まるところです。`marginBottom: 0`がなければ、見出しの下に既定で入る0.5 emのせいで、同じ106 mmが19行になります。

### 2 · 枠はヘッダーからページに掛ける

<Excerpt region="frame" />

画像要素は、配置した大きさでリソースを描きます（[画像要素](/ja/docs/configuration#画像要素)）。ページの左上隅に固定し、縦横とも`'fill'`にすると、ギョーシェは仕上がり全体を覆います。SVGはページと同じ縦横比で宣言してあるので、伸び縮みせずに収まります。ヘッダーはこれを`page.backgroundColor`の上に描き、場所は取りません。本文を仕上がりから少なくとも32 mm、26 mmにある内側の罫より内に保つのは余白だけの仕事です。ヘッダーに透かしを置くと文字の上に刷られます。ヘッダーは本文の後に描かれるからです。ヘッダーの中の`{attr.serial}`は、そのページが属する節の見出しの属性を読むので、修了証はそれぞれ自分の番号を印字します。

### 3 · 章扉には表題のブロックだけを置く

<Excerpt region="title" />

各行はページの`'top'`辺に固定して中央にそろえ、`y`は仕上がりから測ります。こうすれば余白がどうであれブロックの位置は変わりません。`y()`はこの位置をレターからA4へ引き伸ばします。名前は見出しの本文そのもので、`{titleText}`で読むため、PDFのしおりとタグにも名前が入ります。`overflow: 'wrap'`にすると長い名前は2行目に送られます。既定のままだと、省略記号で切り詰められます。`centred()`は字間を空けた各行を、そのトラッキングの半分だけ右へずらします。これがないと、各行はその分だけページの中心より左に寄ります。上の小見出しで0.4 mm、*Certificate*で0.5 mm、*of completion*で0.7 mmです。

### 4 · 印章と署名をひとつの線から吊るす

<Excerpt region="signatures" />

フッターの中身はすべて、印章の上端である`SIGN`から測ります。スタイルの下余白も同じ線で本文領域を終わらせるので、ページに収まらないほど長い文言は、印章の下にもぐらずに次のページへ送られます。署名欄と名前を章扉に移すと、その高さに数えられてしまいます（[幅と詳細デザイン](/ja/docs/configuration#幅と詳細デザイン)）。それらは本文領域より下まで届くため、1.4.1では確保した高さ全体が捨てられ、文言は上余白から7.6 mm下、表題に重なる位置から始まります。`LINE`は左右の余白のあいだの幅から印章の円盤34 mmを引き、残りを半分にして3 mmを引きます。こうして各署名欄は、どちらの判型でも印章の3 mm手前で止まります（レターで56 mm、A4で53 mm）。名前と肩書きはそれぞれ署名欄と同じ幅のテキスト要素なので、欄の下の中央に収まります。

### 5 · 名簿を見出しに差し込む

<Excerpt region="merge" />

名簿の各行は、スタイルを指定し、通し番号を属性に持つ`#`見出しになり（[見出しの属性](/ja/docs/document-format#見出しの属性)）、その後に`content.en.md`の文言が続きます。3行なら3ページです。レベル1の`breakBefore`はパリティが`'any'`なので、見出しごとに新しいページを始め、修了証のあいだに白ページははさまりません。スタイルはこの設定を引き継ぎます。

### 6 · クラス全員でひとつのPDFにする

<Excerpt region="pdf" />

クラスはひとつの文書なので、`renderToPdf`は3ページのファイルを1本書き出し、見出しごとに受講者の名前のしおりをつけます。`renderToPdf`は本の各章のような文書の配列も受け取れますが、受講者ごとに文書を分けると、ひとりにつき`buildDocument`を1回呼ぶことになります。見出しにしておけばクラス全員が一度のビルドで組まれ、ビューアーはそのビルドから3枚の修了証をすべて表示します。PDFは、ページで使う4つの書体に加えて、RosarivoのボールドとボールドイタリックをFontsourceに求めますが、Fontsourceにはこの2つがありません。キットのフォントプロバイダーは、求められた書体をそれぞれファミリーにあるいちばん近い書体に寄せます（[なぜフォントプロバイダーが必要か](/ja/docs/configuration#なぜフォントプロバイダーが必要か)）。

## アレンジ

### 受講者ごとにPDFを分ける

受講者ひとりにつきボタンをひとつ置き、新しい`config()`で、その修了証だけを独立した文書としてビルドし、ファイル名に通し番号をつけます。1ファイルは約245 KBです。

```diff
-offerPdf(() => renderToPdf(doc, { fontProvider: fontsourceProvider, resourceBytes: imageBytes }),
-  `${RECIPE}.pdf`); // bookmarks: one per heading, so one per student
-document.querySelector('[data-postext-pdf]').textContent = t({ en: 'Class list → one PDF',
-  es: 'Toda la clase en un PDF' });
+for (const [name, serial] of CLASS) {
+  offerPdf(() => renderToPdf(buildDocument({ markdown:
+    `# ${name} {style="certificate" serial="${serial}"}\n\n${markdown}`, metadata, resources },
+    config()), { fontProvider: fontsourceProvider, resourceBytes: imageBytes }), `${serial}.pdf`);
+  document.querySelector(`[data-postext-pdf="${serial}.pdf"]`).textContent = name;
+}
```

### 枠と表題を紺で刷る

SVGの図版と設定は同じ`palette`オブジェクトを読むので、1項目を変えれば帯、ロゼットの模様、表題の行の色が変わります。

```diff
-  teal: '#1f5f5b', // the frame, the title lines
+  teal: '#2b3a67', // the frame, the title lines
```

## よくあるつまずき

- 1.4.1では、`letterSpacing`を指定して中央にそろえたデザインテキストは、アンカーから字間の半分だけ左に寄ります。右そろえのものは字間ひとつ分手前で終わります。テキストの幅に、最後の文字の後のトラッキングまで含まれるからです。`space()`は字間を空けた行を元の位置へ戻します。
- postext-pdf 1.4.1は、SVGを描くページごとに、そのコンテンツストリームへSVGを書き込み、共有のコピーを持ちません。枠はページごとに約210 KBを足すので、3ページのPDFは694 KB（枠なしなら58 KB）になり、30人のクラスなら約6.6 MBになります。
