## できあがり

小学2年生向けの练习册から2単元を、16开の判型で組みます。国語の単元「春天来了」と、100までのたし算とひき算を扱う算数の単元です。各単元は水彩画の帯、教科のタブ、クラスと名前と点数の行で始まり、中国の練習帳が刷る大問が続きます。看拼音写词语、丸で囲む読み、問いのあとに（　）があり A. B. C. D. を1行に並べる选择题、行末にかっこがある判断题、穴埋め、量詞と物を結ぶ连线、田字格に書く一文、4列の口算、1桁に1マスの竖式、そして文章題です。配点は各問題の指示文の中にあり、児童はそこで読みます。同じ Markdown を2回組みます。児童用は各単元の終わりに参考答案を付け、教師用はすべての答えを赤い楷書体でその場所に書きます。

## 作り方

### 1 · すべての大問をひとつのスタイルで

コードは上の[手短な答え](#手短な答え)にあります。大問は漢数字に全角の「、」を付けて数えるので、番号のあとに語間スペースは入りません。指示文は黒体で、太字にしません。かっこ内の配点が指示文の一部として読めるようにするためです。`options.bracket` が各問いのあとに（　）を書き、教師用では正しい記号がその中に入ります。2つの小さなスタイルはメインのスタイルを拡張します。`pinyin` は空欄ごとに語と同じ幅の枠を描いて `[[{春天|chūn tiān}]]` の読みをその上に印刷し（児童用にも印刷されます）、`kuohao` は何も描きません。「在（　）里填」のかっこはテキストの中にあるからです。

### 2 · 児童用と教師用をひとつのテキストから

<Excerpt region="editions" />

設定は関数なので、組むたびに別のオブジェクトができ、Sandbox のバンドルには児童用の設定が残ります。`edition: 'teacher'` は `answers` の色と書体で答えを書きます。語は枠に、記号はかっこに、判断题には √ と × を、竖式のマスには数字を、例文は1マスに1字ずつ書きます。児童用は各単元の終わりにある `:::solutions` の行に解答を刷ります。教師用には要りません。

### 3 · 絵の入った単元の扉

<Excerpt region="opener" />

絵はページに固定されるので、奇数ページでも偶数ページでも上端まで届きます。教科のタブと題は版面の上端から配置し、絵の下端より下に来ます。2つの単元は同じデザインを使い、違うのは見出しの属性 `kicker` と `pic` だけです。

### 4 · ノンブルは下に

<Excerpt region="furniture" />

中国の練習帳はノンブルをページの下に置きます。シリーズ名は Markdown のフロントマター（`{title}`）から、単元名は見出し（`{chapterTitle}`）から取ります。

## アレンジ

### 解答を章末に刷る

`:::solutions` の行がなければ、`chapterEnd` が各単元の解答を次のレベル1の見出しの前にまとめます。

```diff
-  solutions: { placement: edition === 'teacher' ? 'none' : 'directive' } });
+  solutions: { placement: edition === 'teacher' ? 'none' : 'chapterEnd' } });
```

### 語ごとに田字格を置く

記述問題に `cells="2 2 2 2"` を書くと、語ごとに一組のマスが並び、ピンインはその上の行に置けます。<RecipeLink slug="school-traditions-worksheet">十の伝統で組むワークシートの中国語版</RecipeLink>の最後の問題がこの形です。

## よくあるつまずき

- 楷書体は答えだけを組むので、空欄と模範解答の字だけを読み込みます。ほかの場所でこの書体を使う字があれば、そのテキストに加えてください。
