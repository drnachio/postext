:::exercise
用“○”圈出加点字的正确读音。（每题1分，共3分）

:::columns{count=3}

春*风* [[(fēng) | fēn]]

*发*芽 [[(fā) | fà]]
:::
:::

:::exercise
选择题。把正确答案的序号填在括号里。（每题2分，共4分）

1. “春风吹绿了柳树”中，“吹绿”的意思是
   - [ ] 把柳树涂绿了
   - [x] 使柳树发芽变绿
   - [ ] 把柳树吹弯了
2. 下面哪个词语和“温暖”的意思相近？
   - [ ] 寒冷
   - [ ] 凉快
   - [x] 暖和
   - [ ] 炎热
:::

:::exercise{type=truefalse}
判断对错。对的画“√”，错的画“×”。（每题1分，共3分）

- [x] 燕子是春天从南方飞回来的。
- [ ] “桃花”和“桃子”说的是同一样东西。
- [x] 可以说“一朵花”，也可以说“一朵云”。
:::

:::exercise
按课文内容填空。（每空1分，共4分）

春天来了，小草从地下[[探出]]头来，柳树长出了[[嫩绿]]的新芽。小燕子从[[南方]]飞回来了，田野里到处都是[[花香]]。
:::

:::exercise
连一连，给事物找到合适的量词。（共4分）

- 一朵 -> 桃花
- 一只 -> 燕子
- 一棵 -> 柳树
- 一片 -> 田野
:::

:::exercise{type=open area=tianzige lines=3}
用上“春风”“柳树”“燕子”中的两个词，写一两句话。（4分）

:::solution
春风吹来，柳树发出了嫩绿的新芽。
:::
:::
