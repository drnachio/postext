## 成品一览

一本二年级练习册的两个单元，16开：语文单元“春天来了”，数学单元讲100以内的加减法。每个单元开头是一条水彩画色带、一个科目标签和一行班级、姓名、得分，接着是中国练习册常见的各种大题：看拼音写词语，圈出正确读音，题干后带（　）、A. B. C. D. 排成一行的选择题，行末带括号的判断题，填空，量词和事物之间的连线，在田字格里写一句话，四栏口算，每位数字一个格的竖式，还有一道应用题。分值写在每道题的题目要求里，学生读题时就能看到。同一份 Markdown 排两次：学生用书在每个单元末附参考答案，教师用书把每个答案用红色楷体写在原处。

## 做法

### 1 · 所有大题用一个样式

代码见上方的[简短回答](#简短回答)。大题用中文数字编号，后面跟全角顿号“、”，所以编号后不加空格；题目要求用黑体，不加粗，括号里的分值读起来就是要求的一部分。`options.bracket` 在每个题干后写出（　），教师用书里正确的字母就填在里面。两个小样式继承主样式：`pinyin` 把每个空画成和所填词语一样宽的方框，并把 `[[{春天|chūn tiān}]]` 的拼音印在框的上方，学生用书也印；`kuohao` 什么也不画，因为“在（　）里填”的括号本来就在文本里。

### 2 · 学生用书和教师用书出自同一份文本

<Excerpt region="editions" />

配置是一个函数，所以每次排版都拿到自己的对象，Sandbox 的包里保存的是学生用书那一份。`edition: 'teacher'` 用 `answers` 的颜色和字体写出答案：词语写在方框里，字母写在括号里，判断题里写 √ 和 ×，竖式的格里写数字，例句一格一个字。学生用书在每个单元末 `:::solutions` 那一行印出参考答案；教师用书用不着。

### 3 · 带水彩画的单元开头

<Excerpt region="opener" />

画锚定在页面上，所以不论单页还是双页都铺到上边的纸边；科目标签和标题从版心顶部开始定位，落在画的下沿之下。两个单元共用这个设计，只在标题属性 `kicker` 和 `pic` 上不同。

### 4 · 页码放在页脚

<Excerpt region="furniture" />

中国的练习册把页码放在页脚。丛书名取自 Markdown 的 front matter（`{title}`），单元名取自单元标题（`{chapterTitle}`）。

## 变化

### 把参考答案印在章末

不写 `:::solutions` 行时，`chapterEnd` 把每个单元的答案收在下一个一级标题之前。

```diff
-  solutions: { placement: edition === 'teacher' ? 'none' : 'directive' } });
+  solutions: { placement: edition === 'teacher' ? 'none' : 'chapterEnd' } });
```

### 每个词一组田字格

简答题写上 `cells="2 2 2 2"`，每个词各有一组方格，拼音印在上面一行，<RecipeLink slug="school-traditions-worksheet">十种传统练习单的中文版</RecipeLink>最后一题就是这样排的。

## 常见问题

- 楷体只排答案，所以只加载空里和参考答案里的字；如果楷体还要排别处的字，必须把这些字加进那段文本。
