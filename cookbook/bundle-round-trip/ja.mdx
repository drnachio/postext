## できあがり

架空の入り江にある潮力水車小屋の来館者用DLリーフレット（99 × 210 mm）の両面です。おもて面は1枚の絵です。水際に水車があり、上半分は砂の上、下半分は青い水の下で淡く描かれます。表題は50 ptのDM Serif Displayイタリック、青いタブには版の言語（ENまたはES）が入ります。裏面は水車小屋の断面図で始まり、両端そろえのDM Sansの本文、青い見出し行の付いた開館時間の表、Instrument Sansのキャプション、奥付、発行者名の入った青い帯と続きます。各版は`.postext`ファイルに書き出され、ここに載せたページはすべて、そのファイルのバイト列から、ファイルに入った書体と図で組んだものです。

## 作り方

### 1 · 版を書き出し、バイト列だけを読み戻す

<Excerpt region="answer" highlight="14-17" />

`createBundle`は章、設定、リソース、そしてそれらが参照するすべてのファイルをzipにまとめます。`openBundle`が受け取るのはそのバイト列だけです。書体は`loadBundleFonts`から、図は`registerBundleImages`から、デザインは`bundle.config`から取ります。`files`に入れ忘れた書体はブラウザーの代替フォントで印字され、入れ忘れた図は警告とともに省かれ、その参照は(?)と印字されます。zipの中では各`fileId`がパスになり（`mill.svg`は`resources/mill.svg`になります）、`openBundle`が返すリソースと`customFonts`はすでに新しい名前を使っています（[バンドルを開く](/ja/docs/configuration-programmatic-usage#バンドルを開く)）。

### 2 · 書体をファイルに入れる

<Excerpt region="faces" />

バンドルが書体を持つのは、`customFonts`がその書体を指定し、`files`にそのバリエーションの`fileId`でバイト列が入っているときです。`createBundle`はDM Sans 400を`fonts/dm-sans-400-normal.woff2`として格納します。CodePenのサンプルはFontsourceから7つのwoff2ファイルをダウンロードしますが、どれも登録しません。`buildBundle`が行を測る前に`loadBundleFonts`がバンドル内の複製を`document.fonts`に加え、PDFも同じ7ファイルから書体を取ります。

### 3 · どのファイルもfileIdで名付ける

<Excerpt region="resources" />

2点の図はCodePenのサンプルが生成するSVGマークアップで、それぞれのリソースの`svg.fileId`の名前で`files`に渡します。表はデータなので、キャプションといっしょに`preset.json`に入って運ばれます。断面図と表は`position: 'here'`で配置します。断面図は裏面の先頭に、開館時間の表はそれを引用する段落の下に置かれます。このリーフレットは`layout.inlineResourceGap: 'above'`を設定し、行内のリソースの間隔を上側だけにして、裏面を1面に収めています。断面図のあとの見出しは自分の間隔を持ち、表のあとの`:::space{lines=0.5}`の行がキャプションの下に3.7 mmをあけます。

### 4 · ラベルをファイルの言語のままにする

<Excerpt region="labels" />

ファイルを開く側は、組み込みの種類をそのファイルの言語で組み立てます。設定に`resourceTypes`がなくても、スペイン語のリーフレットは、/en/sandboxのSandboxを含めてどこで開いてもFigura 1.1とTabla 1.1を印字します。このリーフレットが種類を書き込むのは番号のためだけです。`'{n}'`は章番号を落とします。2ページのリーフレットに章番号は不要です（[リソースの種類](/ja/docs/configuration-resources#リソースの種類)）。同じ`config()`で`locale`も設定し、これでスペイン語のハイフネーションパターン（裏面のcompuer-tas）と、PDFが宣言する言語が決まります。

### 5 · 同じバイト列を渡す

<Excerpt region="handoff" />

リンクからは、ページを組んだのと同じ`bytes`、フォント込みで132 KBのファイルを取得できます。Sandboxで読み込むと（**本 → 新規 → .postextファイルを開く…**）、ファイルはスペイン語または英語の本になり、`thumbnail`から取った水車の絵がその本の画像になります。PDFは書体を`bundleFontProvider`から取ります。これはバンドル内でウェイトが最も近い書体を、同じスタイルがあればそのスタイルで返します。図は`bundleResourceBytes`から取るので、フォントも画像も2度ダウンロードされることはありません（[バンドルを組んで描画する](/ja/docs/configuration-programmatic-usage#バンドルを組んで描画する)）。

### 6 · おもて面を見出しひとつで描く

<Excerpt region="cover" />

おもて面は表紙用の見出しのデザインです。図を原寸でページに固定し、見出しの文字は`{titleText}`で、キッカー、リード文、案内の1行は見出しの属性から取り、言語のタブはボックス付きのテキスト要素で描きます。H1のレベルは`span: 'page'`なので、図は用紙の下端まで届きます。見出しのデザインを段の中に置いたままにすると、版面の下端で切られ、図は下端の13 mm手前で止まります。

## アレンジ

### 2言語のバンドルを読む

Postextガイドは、英語とスペイン語の章、設定、キャプションを1つのファイルに収めています。`{ locale }`で版を選ぶと、どちらの言語でも48ページ、12章として開きます。このときリンクから取得できるのはリーフレットのファイルのままで、PDFボタンはガイドを組みます。

```diff
-const bundle = await openBundle(bytes);
+const guide = await fetch('https://postext.dev/bundles/postext-guide.postext');
+const bundle = await openBundle(await guide.arrayBuffer(), { locale: LANG });
```

### 図を章ごとに数える

種類を指定しないと、開く側がファイルの言語と既定の番号で種類を組み立て、図は表紙の見出しから数えられます。スペイン語版はFigura 1.1とTabla 1.1、英語版はFigure 1.1とTable 1.1を印字します。

```diff
-  resourceTypes: defaultResourceTypes(LANG).map((type) => ({ ...type, numberingTemplate: '{n}' })),
```

## よくあるつまずき

- ここでは版ごとに1つのファイルを書き出しています。2つの言語を1つのファイルに入れるには、`createBundle`に`localized`のマップを渡します（[多言語のバンドル](/ja/docs/configuration-programmatic-usage#多言語のバンドル)）。そうすれば`openBundle(bytes, { locale })`でどちらの版も読めます。
