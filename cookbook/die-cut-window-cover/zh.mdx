## 成品一览

*The Oval Portrait*（西班牙语版《El retrato oval》），爱伦·坡1842年的短篇，采用他1845年刊出的较短文本，做成130 × 195毫米、十页的小精装书。封面是一块旧锦缎，上面模切出一个椭圆窗。封面下是书名页，也就是那幅装在摩尔式镀金画框里的肖像；窗的位置让切口正好落在金边上：合上书时，画中的脸被框了两次，一次是金框，一次是切口。故事印在米色纸上，以首字下沉开头；封底重复锦缎图案，简介印在深色框里。交给印厂的PDF把窗的轮廓放在单独的色版上。

## 做法

### 1 · 与画框对准的窗

代码见上方的[简短回答](#简短回答)。窗是第1页上的一个`ellipse`，从成品左上角起定位。第1页上的孔看到的是第3页，所以要在书名页的画上量：这里先在图上以像素读出画框的内缘和外缘，再换算成毫米，把窗放在金边宽度的三分之一处，切口里就留下一圈细细的金边。

### 2 · 挂在裁切线上的画

<Excerpt region="plates" />

模切以从裁切线量起的毫米表示，画也一样。锦缎在四边各伸出出血；肖像放得比页面宽几毫米，让画框在页面和窗中居中。封面和书名页去掉下边距，各自从frontmatter印出书名和作者。

### 3 · 模切线在自己的色版上

<Excerpt region="die-line" />

PDF把封面完整印出，并把窗的轮廓描在一个叠印、从不上墨的`Die`分色上：做刀模的人从这里读形状，印刷时略过它。`convertImages: false`让画保持sRGB JPEG，PDF/X-4允许这样做，文件也不到1兆字节。

### 4 · 桌上合着的书

<Excerpt region="folio" />

`binding.cover: 'pages'`把第一页当作前封面，所以Folio显示合着的书，窗里是那张脸，切口的侧壁映着灯光。翻开封面就能看到完整的书名页。

### 5 · 平铺的封面也能透视

<Excerpt region="see-through" />

在画布上，`beneath`把第3页交给渲染器去填封面的窗，平铺的封面也会露出那张脸。封面背面下面什么都没有，所以那里的孔显示背景。

## 变化

### 按切割机的习惯给色版命名

数码切割台通常寻找名为CutContour的专色，一般是品红，并用极细的线。

```diff
-    dieLine: { output: 'page', ink: 'Die', width: pt(0.5) } },
+    dieLine: { output: 'page', ink: 'CutContour', cmyk: { c: 0, m: 100, y: 0, k: 0 },
+      width: pt(0.25) } },
```

### 圆形的窗

圆窗只露出脸；画框藏在封面下，翻开才看得到。

```diff
-    shape: 'ellipse', x: mm(26), y: mm(15.7), width: mm(78), height: mm(102) }],
+    shape: 'circle', x: mm(32), y: mm(24), width: mm(66), height: mm(66) }],
```
