## できあがり

*The Oval Portrait*（スペイン語版『El retrato oval』）。エドガー・アラン・ポーが1842年に発表し、1845年に短く改めた本文で、130 × 195ミリ、10ページの小さなハードカバーに組みました。表紙は古いダマスク織で、楕円の窓が抜いてあります。その下が扉で、ムーア風の金の額に入った肖像そのものです。窓は切り口が金の上にかかる位置にあり、本を閉じると、描かれた顔が金と切り口の二重の額に収まって見えます。本文はクリーム色の紙にドロップキャップで始まり、裏表紙はダマスク織を繰り返して、紹介文を暗い枠に載せます。印刷所に渡すPDFには、窓の輪郭が専用の版に載ります。

## 作り方

### 1 · 額縁と位置をそろえた窓

コードは上の[手短な答え](#手短な答え)です。窓は1ページ目の`ellipse`で、仕上がりの左上の角から置きます。1ページ目の穴からは3ページ目が見えるので、扉の絵の上で測ります。ここでは額の内側と外側の縁を画像上のピクセルで読み取ってミリに直し、窓を金の帯の3分の1の位置に置いたので、切り口の内側に細い金の輪が残ります。

### 2 · 仕上がり線から下げた絵

<Excerpt region="plates" />

抜き型は仕上がり線からのミリで測るので、絵もそうします。ダマスク織は四辺とも塗り足し分はみ出させ、肖像はそれより数ミリ広く置いて、絵の中の額がページの中央、つまり窓の中央に来るようにします。表紙と扉は下マージンをなくし、どちらもfrontmatterから題名と著者を刷ります。

### 3 · 専用の版に載る抜き型の線

<Excerpt region="die-line" />

PDFは表紙を丸ごと印刷し、窓の輪郭を、オーバープリントでインキを載せない`Die`の分版に描きます。抜き型の職人はそこから形を読み、印刷機はそれを飛ばします。`convertImages: false`で絵はsRGBのJPEGのまま残り（PDF/X-4で認められています）、ファイルは1メガバイトに収まります。

### 4 · 机の上の閉じた本

<Excerpt region="folio" />

`binding.cover: 'pages'`では最初のページが表表紙になるので、Folioは閉じた本を見せます。窓には顔がのぞき、切り口の壁がランプの光を受けます。表紙をめくると扉の全体が見えます。

### 5 · 平らな表紙でものぞける

<Excerpt region="see-through" />

キャンバスでは、`beneath`が表紙の窓のために3ページ目をレンダラーに渡すので、平らな表紙にも顔が見えます。表紙の裏の下には何もないので、その穴には背景が見えます。

## アレンジ

### カッティングマシンが探す名前で版を呼ぶ

デジタルのカッティングテーブルは、CutContourという名の特色（たいていマゼンタ）と極細の線を探します。

```diff
-    dieLine: { output: 'page', ink: 'Die', width: pt(0.5) } },
+    dieLine: { output: 'page', ink: 'CutContour', cmyk: { c: 0, m: 100, y: 0, k: 0 },
+      width: pt(0.25) } },
```

### 丸い窓

円の窓は顔だけを見せ、額は表紙をめくるまで隠れたままです。

```diff
-    shape: 'ellipse', x: mm(26), y: mm(15.7), width: mm(78), height: mm(102) }],
+    shape: 'circle', x: mm(32), y: mm(24), width: mm(66), height: mm(66) }],
```
