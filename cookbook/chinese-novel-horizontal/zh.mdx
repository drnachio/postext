## 成品一览

鲁迅《故乡》（1921）的开头，按大陆出版的他第一部小说集平装本的样子来排：大32开，140 × 203 mm，版心以字计，每行28字，每页28行，用Noto Serif SC五号（10.5 pt）。每段首行缩进两字；逗号和引号占半个字宽，与大多数大陆图书相同；句号。和逗号，不出现在行首，前引号“不出现在行末。小说在右页开篇，标题用宋体的特粗字重。对页是一幅绘画插页，画的是叙述者记忆中月下的瓜地，并用Ma Shan Zheng毛笔字体配上描写这一景象的文字。<RecipeLink slug="spanish-pocket-novel">口袋本小说里的西班牙文两端对齐</RecipeLink>为拉丁文字做了同样的事。

## 做法

### 1 · 以字计的页面

代码见上文的[简短回答](#简短回答)。`cjk.grid`把行长设为`bodyText.fontSize`的28个全角（294 pt，103.7 mm），把版心设为28行`lineHeight`（462 pt，163 mm），再调整页边距来容纳它们，所以一整行汉字正好28个，每一整页都结束在同一行（[字符网格](/zh/docs/configuration#字格)）。网格下面的五项设置是`locale: 'zh-Hans'`本来就会给出的值；把它们写出来，是为了让你可以逐项修改，不过在`punctuationWidth`设为`'fullwidth'`之前，`compressAdjacent`不起作用：开明式下，任何两个相邻标点加起来都不超过1.5个全角。在<PageRef page={2}>第71页</PageRef>上，某段末尾的。放不下，而行首禁则（`lineBreak`除`'none'`以外的每一级都有；`'gb'`还加上斜线）不允许它出现在行首。于是这一行把事后面的。排成半个字宽，把它挤进来（push-in），事。宏紧排，段落也不必多出一行（[标点宽度](/zh/docs/configuration#标点宽度)）。不满的行把空隙分到字与字之间，而不是词与词之间，在这几页上每处不超过0.05 em（[中日韩文字](/zh/docs/justification#中文日文和韩文)）。

### 2 · 天头更深的大32开页面

<Excerpt region="page" />

打开网格后，页边距是最小值：网格在它们留下的空间里放置版心，再把多余的部分分配出去。22 mm和18 mm正好留出163 mm，所以天头比地脚深4 mm，这是中文图书的习惯；两侧各18 mm，留下0.3 mm可分。如果要求的字数或行数超出能容纳的范围，网格会缩减到能放下为止，并给出`cjkGridClamped`警告；字号和行距保持不变。

### 3 · 下沉整数行的标题

<Excerpt region="opener" />

`minHeight`是八行16.5 pt，所以标题下方的正文从网格第九行开始，基线与其他各页相同。23 pt的字距在故和乡之间隔出半个字，这是两字标题常用的间隔；Postext在居中排行时不计最后一个字后面的字距，所以标题仍在页面的中轴上（[标题样式](/zh/docs/configuration#标题样式)）。

### 4 · 左页印书名，右页印篇名

<Excerpt region="heads" />

大陆的小说在左页书眉印书名，右页书眉印篇名，居中，页码在外侧，两者下方各有一条细线。`pages: 'body'`让书眉不出现在开篇页和插页上，开篇页的页码改排在页面底部。书眉用黑体Noto Sans SC，8 pt：字虽小，但与正文的宋体风格分明。

### 5 · 占满整张纸的插页

<Excerpt region="plate" />

插图属于一个单独的标题`# 月下的瓜地 {style="plate" …}`，它的样式绘制整页，并清掉这一页的书眉和页码。插页需要`span: 'page'`，因为留在栏内的标题设计会在栏底被截断，离裁切线还差18 mm。`runningChapter: false`加上`toc: false`让它不进入PDF书签，书签从故乡开始。引文的三行是三个属性和三个文本元素，因为设计文本有自己的断行器，不处理中文标点宽度；手工断行后，这几行也去掉了逗号，中文的展示性文字通常就是这样处理的。

### 6 · 中文正文里的拉丁字母和数字

<Excerpt region="styles" />

<PageRef page={7}>第76页</PageRef>上的注释和版权说明是数字、拉丁名称与汉字相遇的地方。`latinSpacing`在它们相接的地方加上四分之一个全角，如注释中的1921年和版权说明中的用Noto Serif SC五号，这些在输入时都没有空格（[汉字与拉丁字母之间的间距](/zh/docs/configuration#汉字与拉丁字母间距)）；在两端对齐的行中，这个间距最先被拉宽，最多到半个全角。注释的字号是9.1875 pt，而不是小五的9 pt，这样32个字正好排满行长：用9 pt时每行剩下三分之二个全角，被中西文间距吃掉了。Markdown中字体名称的单词之间用不间断空格（U+00A0）连接，中西文间距不会动它们：如果用普通空格，版权说明中左对齐不齐行的各行会把Noto Sans / SC断开。

## 变化

### 所有标点都排全角（全角式）

逗号、顿号和引号各占一个字宽，。”占两个字宽，每行容纳的正文字数就少了。

```diff
-  punctuationWidth: 'kaiming', // ，、：； quotes, brackets ½ em; 。？！ one em, ½ at a line end
-  compressAdjacent: true, // idle under Kaiming (no pair tops 1.5 em); 'fullwidth' needs it
+  punctuationWidth: 'fullwidth',
+  compressAdjacent: false,
```

### 排版时显示字格

Canvas为每一行的每个字位画一个浅灰色方格（稿纸）；PDF不画它，除非给`renderToPdf`传入`characterGrid: true`。

```diff
-  grid: { enabled: true, charsPerLine: CHARS, linesPerPage: LINES },
+  grid: { enabled: true, charsPerLine: CHARS, linesPerPage: LINES, show: true },
```

## 常见问题

- 插页是一个标题，而标题会得到一个PDF书签：如果插页的样式里没有`runningChapter: false`和`toc: false`，书签就会从月下的瓜地开始，它是故乡之前的一个一级书签。只设其中一项，书签仍会保留。带标签的PDF仍会把插页的标题保留为H1。
- 标题本身的字体必须是`FONTS`加载了的，即使每个标题都由版面设计绘制：在默认字重700下，工具包在版面中发现了Noto Serif SC 700，于是加载了它的拉丁文件并给出警告。`headings.fontWeight: 400`让标题块使用正文字体。
