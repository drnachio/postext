## 成品一览

一本收录杰拉德·曼利·霍普金斯五首诗的小诗集，140 × 216毫米，平装。封面和它后面那一页是深蓝卡纸，上面只有烫金：一个双框、Cinzel大写字母的书名、诗人的名字和目录。内页用米色直纹纸，诗以四色印刷，第二首诗对面是一幅画出来的夜景，页面上的每一条线都是烫金：书眉下的双线、每个标题下的短线、页码下的线。书名取自第一首诗，诗里的世界闪耀着，“like shining from shook foil”。Folio把合着的书转向光源，金色就显出金属的质感。

## 做法

### 1 · 烫金是带工艺的专色

代码就是上面的[简短回答](#简短回答)。`finish: { kind: 'foil' }`把专色变成特种油墨（[工艺](/zh/docs/special-inks-die-cuts#工艺)）。排版只看到一种颜色，什么都不会移动；画布绘制它的hex，Folio把它当金属照亮，PDF/X-4文件则把每个烫金元素放到同一个名为`Gold foil`的`Separation`上，制版厂据此蚀刻黄铜烫金版。烫金会把下面的内容镂空，和烫金机上的效果一样。

### 2 · 纸张是不印油墨的颜色

<Excerpt region="content" />

蓝色卡纸和米色直纹纸是调色板里的颜色，CMYK各通道都设为0 %：屏幕和Folio会画出纸色，但没有哪块印版会因此多一个网点，所以封面的PDF只有烫金版和四块空的四色印版。每个蓝色页面从自己的标题样式取得卡纸（`onCard`里的`palette: { paper: … }`），两个`:::paper`块则让Folio知道封面那张纸和后面一张纸的克重和挺度。

### 3 · 封面是一个框和四行字

<Excerpt region="cover" />

烫金能压出细线，所以外框是一条1.6 pt的线，往里2.5毫米再加一条0.4 pt的细线，各是一个盒子的边框，颜色都是烫金色。封面上的一切都是烫金：卡纸上没有第二种油墨，向装订厂订烫金封面就是这样下单的。

### 4 · 内页的线是烫金，诗是油墨

<Excerpt region="rules" />

书眉下是一组双线：一条0.9 pt，下方1.2毫米处再一条0.3 pt，宽度与版心相同。诗的标题设计在标题下加一条12毫米的线，页脚在页码下加一条6毫米的线。正文保持暖黑色油墨：小字烫金在机器上会糊。

### 5 · 在Folio里把封面转向光

<Excerpt region="folio" />

烫金只有在反射东西时才像烫金。`studio`环境有明亮的柔光箱，书倾斜24°、转动16°，柔光箱的反光就落在书名上。换成较暗的台灯光，同样的金色就成了暗淡的赭色。

## 变化

### 改烫银

改动hex和替代的CMYK值，工艺和印版不变。

```diff
-const foil = { hex: '#c9a24a', model: 'spot', spot: { name: 'Gold foil',
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+const foil = { hex: '#b8bcc2', model: 'spot', spot: { name: 'Silver foil',
+  cmyk: { c: 20, m: 12, y: 10, k: 25 }, finish: { kind: 'foil', sheen: 'gloss' } } };
```

### 用金属油墨印金色

金属油墨比烫金版便宜，和其他油墨一起印；Folio把它显示为缎面光泽。

```diff
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'metallic' } } };
```

## 常见问题

- 用普通hex写在`page.backgroundColor`里的色纸，会作为四色满版色块印满整页。如果这个颜色是纸本身的颜色，就像这里一样，用CMYK 0 %来定义纸张。
- 细于0.25 pt的线和小于8 pt的字在烫印时会糊。烫金只用于线条和标题字。
