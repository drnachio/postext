## できあがり

ジェラード・マンリー・ホプキンズの詩5編を収めた140 × 216 mmの小冊子で、並製です。表紙とその次の丁は濃紺の厚紙で、金の箔押しだけが乗ります。二重枠、Cinzelのキャピタルの書名、詩人の名前、目次です。中はクリームのレイド紙で、詩は4色で刷られ、2編目の詩の向かいには絵の夜景が入り、ページの罫線はすべて箔です。柱の下の二重罫、各題の下の短い罫線、ノンブルの下の罫線です。書名は1編目の詩から取りました。そこでは世界が「like shining from shook foil」と輝きます。Folioは閉じた本を光のほうへ傾けるので、金が金属として見えます。

## 作り方

### 1 · 箔は加工付きの特色

コードは上の[手短な答え](#手短な答え)にあります。`finish: { kind: 'foil' }`で特色が特殊インキになります（[加工](/ja/docs/special-inks-die-cuts#加工)）。レイアウトから見ればただの色なので、何も動きません。キャンバスは`hex`で塗り、Folioは金属として照らし、PDF/X-4のファイルは箔の要素をすべて`Gold foil`という1つの`Separation`に載せます。版の業者はこれをもとに真鍮の箔版を作ります。箔は、箔押し機で押したときと同じように、下にあるものをノックアウトします。

### 2 · 紙はインキを刷らない色

<Excerpt region="content" />

紺の厚紙とクリームのレイド紙は、CMYKの全チャンネルを0 %にしたパレットの色です。画面とFolioは紙の色を塗りますが、どの版にも網点は1つも乗りません。そのため表紙のPDFには箔の版と空のプロセス版4枚があるだけです。紺のページはどれも見出しスタイルから厚紙を受け取り（`onCard`の`palette: { paper: … }`）、2つの`:::paper`ブロックが表紙の丁とその次の丁に厚紙の坪量とこしをFolioへ伝えます。

### 3 · 表紙は枠と4行の文字

<Excerpt region="cover" />

箔は細い線を保てるので、枠は1.6 ptの罫線と、その2.5 mm内側の0.4 ptの細い罫線です。どちらも箔の色で引いたボックスの枠線です。表紙にあるものはすべて箔で、厚紙にはほかのインキが一切触れません。製本所に箔押しの表紙を頼むときと同じ形です。

### 4 · 中の罫線は箔、詩はインキ

<Excerpt region="rules" />

柱は二重罫の上に乗ります。0.9 ptの線と、その1.2 mm下の0.3 ptの線で、幅は版面と同じです。詩の題のデザインは題の下に12 mmの罫線を、フッターはノンブルの下に6 mmの罫線を加えます。本文は温かみのある黒インキのままです。小さな文字を箔で押すと、つぶれてしまいます。

### 5 · Folioで表紙を光に向ける

<Excerpt region="folio" />

箔は何かを映して初めて箔に見えます。`studio`の環境には明るいソフトボックスがあり、24°傾けて16°回した本では、その映り込みが書名の上を横切ります。暗めのランプの光では、同じ金がくすんだ黄土色にしか見えません。

## アレンジ

### 銀で押す

`hex`と代替のCMYKを変えます。加工と版はそのままです。

```diff
-const foil = { hex: '#c9a24a', model: 'spot', spot: { name: 'Gold foil',
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+const foil = { hex: '#b8bcc2', model: 'spot', spot: { name: 'Silver foil',
+  cmyk: { c: 20, m: 12, y: 10, k: 25 }, finish: { kind: 'foil', sheen: 'gloss' } } };
```

### 金をメタリックインキで刷る

メタリックインキは箔版より安く、ほかのインキと一緒に刷れます。Folioではサテンの光沢で表示されます。

```diff
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'metallic' } } };
```

## よくあるつまずき

- 色のついた紙を`page.backgroundColor`に普通の`hex`で指定すると、ページ全体にプロセスのベタとして刷られます。その色が紙そのものの色なら、ここと同じようにCMYK 0 %で指定してください。
- 0.25 ptより細い罫線と8 ptより小さい文字は、箔押しでつぶれます。箔は罫線と見出しの文字に限ってください。
