## ما الذي ستنضده

كتيّب يضم خمس قصائد لجيرارد مانلي هوبكنز، بمقاس 140 × 216 مم، بتجليد ورقي. الغلاف والورقة التي تليه كرتون أزرق داكن مختوم برقائق ذهبية ولا شيء غيرها: إطار مزدوج، والعنوان بحروف Cinzel الكبيرة، واسم الشاعر، والفهرس. وفي الداخل، على ورق مضلّع كريمي، تُطبع القصائد بالألوان الأربعة، وتقابل القصيدةَ الثانية لوحةٌ ليلية مرسومة، وكل خط في الصفحة رقائق ذهبية: الخط المزدوج تحت الترويسة، والخط القصير تحت كل عنوان، والخط تحت رقم الصفحة. العنوان مأخوذ من القصيدة الأولى، حيث يتلألأ العالم «like shining from shook foil». ويدير Folio الكتاب المغلق نحو الضوء، فيبدو الذهب معدنًا.

## طريقة التحضير

### 1 · الرقائق لون خاص له تشطيب

الشيفرة هي [الجواب المختصر](#الجواب-المختصر) أعلاه. يحوّل `finish: { kind: 'foil' }` اللون الخاص إلى حبر خاص ([التشطيبات](/ar/docs/special-inks-die-cuts#التشطيبات)). يرى التنضيد لونًا فلا يتحرك شيء؛ ترسم اللوحة قيمته `hex`، ويضيئه Folio معدنًا، ويضع ملف PDF/X-4 كل عنصر ذهبي على `Separation` واحد اسمه `Gold foil`، يحفر منه صانع القوالب قالب الختم النحاسي. وتفرّغ الرقائق ما تحتها، كما يحدث على آلة الختم الحراري.

### 2 · الورق ألوان لا تحمل حبرًا

<Excerpt region="content" />

الكرتون الأزرق والورق المضلّع الكريمي لونان في لوحة الألوان معرّفان في CMYK بنسبة 0 % في كل قناة: ترسم الشاشة وFolio لون الورق، ولا يتلقى أي لوح منه نقطة واحدة، فيحمل ملف PDF للغلاف لوح الرقائق وأربعة ألواح فارغة للألوان الأساسية. وتأخذ كل صفحة زرقاء الكرتون من نمط عنوانها (`palette: { paper: … }` في `onCard`)، وتعطي كتلتا `:::paper` لـFolio وزن الكرتون وصلابته في ورقة الغلاف والورقة التي تليها.

### 3 · الغلاف إطار وأربعة أسطر

<Excerpt region="cover" />

تحتمل الرقائق الخط الرفيع، فالإطار خط بسماكة 1.6 نقطة ومعه خط شعري بسماكة 0.4 نقطة إلى الداخل بمقدار 2.5 مم، وكل منهما حدّ صندوق بلون الرقائق. كل ما على الغلاف رقائق: لا يمسّ الكرتون حبر ثانٍ، وهكذا يُطلب الغلاف المختوم من ورشة التجليد.

### 4 · في الداخل الخطوط رقائق والقصائد حبر

<Excerpt region="rules" />

تقوم الترويسة فوق خط مزدوج، خط بسماكة 0.9 نقطة وآخر بسماكة 0.3 نقطة تحته بمقدار 1.2 مم، بعرض كتلة النص. ويضيف تصميم عنوان القصيدة خطًا طوله 12 مم تحت العنوان، ويضيف التذييل خطًا طوله 6 مم تحت رقم الصفحة. ويبقى النص بالأسود الدافئ: الحروف الصغيرة بالرقائق تنطمس على الآلة.

### 5 · يدير Folio الغلاف نحو الضوء

<Excerpt region="folio" />

لا تبدو الرقائق رقائق إلا حين تعكس شيئًا. في البيئة `studio` صناديق ضوء ساطعة وناعمة، وميل بزاوية 24° مع تدوير الكتاب 16° يمرّ بانعكاسها على العنوان. وتحت ضوء المصباح الأخفت يبدو الذهب نفسه مغرةً باهتة.

## تنويعات

### اختم بالفضة

غيّر قيمة `hex` والبديل في CMYK؛ ويبقى التشطيب واللوح كما هما.

```diff
-const foil = { hex: '#c9a24a', model: 'spot', spot: { name: 'Gold foil',
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+const foil = { hex: '#b8bcc2', model: 'spot', spot: { name: 'Silver foil',
+  cmyk: { c: 20, m: 12, y: 10, k: 25 }, finish: { kind: 'foil', sheen: 'gloss' } } };
```

### اطبع الذهب بحبر معدني

الحبر المعدني أرخص من قالب الختم ويُطبع مع الأحبار الأخرى؛ ويعرضه Folio بلمعان ساتاني.

```diff
-  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'foil', sheen: 'gloss' } } };
+  cmyk: { c: 15, m: 30, y: 75, k: 10 }, finish: { kind: 'metallic' } } };
```

## أخطاء شائعة

- الورق الملون المحدد في `page.backgroundColor` بقيمة `hex` عادية يُطبع مساحةً مصمتة بالألوان الأساسية على الصفحة كلها. عرّف الورق في CMYK بنسبة 0 %، كما هنا، حين يكون اللون لون الورق نفسه.
- الخطوط التي تقل سماكتها عن 0.25 نقطة والحروف الأصغر من 8 نقاط تنطمس عند الختم. اقصر الرقائق على الخطوط وحروف العناوين.
