## 成品一览

小杂志*Field Notes*里一篇旅行专题的开头几页。第1页是右页章首页：一张黄昏时盐田和沙丘的照片占满页面上方58%，标题用54 pt的Young Serif，下面两栏两端对齐的正文以粗体起首词开篇。翻过来的第2页在加宽字距的大写书眉下接排，结尾是文末符号和版权信息。整个设计由一个配置工厂函数和六种颜色的调色板决定。标题取自一级标题，导语、作者和日期取自Markdown字符串的frontmatter，所以只要标题能排进两行，同一支pen能排任何文章；只有那张照片专属这一篇。

## 做法

### 1 · 第一次构建之前，加载每一款字体

<Excerpt region="fonts" />

Postext用排版时浏览器里已有的字体测量文字，所以赶在字体到达之前运行的构建会留下后备字体的断行。`buildDocumentWithFonts`在第一次构建前加载配置里写到的每款字体和`FONTS`里的字体；`kitFonts(FONTS)`把Fontsource的文件交给它，也就是PDF会嵌入的同一批文件。随后它检查页面用到的字体，把还缺的加载进来，再构建一次。Fontsource没有的字体仍用后备字体，并在`doc.contentWarnings`里记为`fontFallback`。正文字体的粗体和斜体只在字族确实有时才加载。

### 2 · 先给颜色命名，再引用名字

<Excerpt region="palette" />

配置里的每种颜色都写成`col('id')`，即调色板id加上旁边的十六进制值。`bodyText.boldColor`、`italicColor`、`referenceColor`和`unorderedLists.color`引用`ink`，`headings.color`引用强调色。引擎对标题、粗体、斜体和项目符号的默认颜色都链接到`main-color`，而这个调色板把该项指向强调色，所以你没写的那些会变成靛蓝而不是蓝色。设计对象写成函数，`config()`在每次构建时调用它们，`col()`每次都从`palette`里复制当前的十六进制值，所以只改`palette`一处，正文、页码和章首页都会跟着变。文末符号是一个引用`band`的行内色块，所以换色也会影响它。默认书眉也链接到`main-color`，所以在替换它之前会印成强调色（第5步）。

### 3 · 裁成画框大小的照片

<Excerpt region="art" />

盐田、沙丘和石堆是一张用扩散模型生成的照片，取的是黄昏时分，这样浅色的标题在深色天空上清晰可读。这张JPEG按色带的画框裁成`PAGE.width` × `BAND`毫米，资源声明它的像素为1440 × 1120，所以排满宽度时照片正好填满色带。色带加深时，需要一张按新画框裁好的照片。章首页通过一个按id引用该资源的图像元素显示它。

### 4 · frontmatter写出章首页

<Excerpt region="opener" />

一级标题横跨两栏，它的章首页是一个元素槽：延伸到出血的照片，以及上下串联的四段文字。标题变长时会把导语和署名往下推，不会与它们重叠；但超过两行，署名就会落到浅色的盐田上。`{titleText}`是标题文字；`{subtitle}`、`{author}`和`{publishDate}`是frontmatter字段。标题里的`\\`在你指定的位置给标题换行（[标题中的换行](/zh/docs/document-format#标题中的换行)）。`minHeight`从上页边距起算，所以预留的高度止于色带下方5 mm。

### 5 · 用自己的书眉替换默认的蓝色书眉

<Excerpt region="running-heads" />

不写`header`，引擎的默认设置就会回来：每页都是Open Sans，下面一条通宽的线。这里每个页码都锚定在物理页面上并按奇偶筛选，所以总在外侧边缘。它的标签锚定在页码上，用`right-of`或`left-of`相隔`GAP`毫米；三四位数的页码会把标签往外推，而不会撞上它。`pages: 'body'`让这四个元素不出现在章首页。页脚只放章首页用的一个底部页码；既然设了`footer`，正文页也就没有了默认的居中页码。

### 6 · 用新的配置构建，然后绘制

<Excerpt region="build" />

`config()`是一个函数，这样每次构建都读到调色板当前的值：它会再次调用第2步里的设计函数。只用一个配置对象、就地修改也可以：从postext 1.25起，引擎会在下一次构建时发现改动。`buildDocumentWithFonts`接收内容、这份配置和套件的字体选项，返回排好的文档。`showPages`按装订成书的样子摆放页面，第1页单独在右侧，并用`renderPageToCanvas`绘制每一页。

## 变化

### 看看配置替换了什么

用空配置构建，同一段Markdown会排在17 × 24 cm的页面上，正文是8 pt的EB Garamond，标题是蓝色Open Sans，线上方是蓝色书眉；默认配置写到了这两个字族，所以引擎也会加载它们。

```diff
-const doc = await buildDocumentWithFonts({ markdown, resources }, config(), kitFonts(FONTS));
+const doc = await buildDocumentWithFonts({ markdown, resources }, {}, kitFonts(FONTS));
```

### 给整页换色

换掉强调色，下一次运行就会用新颜色画页码、小标题和文末符号，因为`config()`每次运行时`col()`都会复制id旁的新十六进制值。照片保留它自己的颜色。

```diff
-  band: '#2b3a67', // the one accent (an indigo): the folios, the subheads, the end mark
+  band: '#3f5b3a', // the one accent (a pine green): the folios, the subheads, the end mark
```

### 把一页画到你自己的Canvas上

`renderPageToCanvas`按文档的dpi（默认300）乘以`scale`把Canvas设成页面的像素尺寸，所以`scale: 0.5`大约是150 dpi，屏幕上显示多大由CSS决定。

```diff
-showPages(doc, {
-  title: t({ en: 'From a Markdown string to a designed page',
-    es: 'De una cadena Markdown a una página diseñada',
-    pt: 'De uma string Markdown a uma página diagramada' }),
-});
+const canvas = document.body.appendChild(document.createElement('canvas'));
+renderPageToCanvas(doc.pages[0], doc, canvas, { scale: 0.5 });
```

## 常见问题

- Young Serif只有一个字重。标题默认是粗体，所以这里必须写`headings.fontWeight: 400`：不写的话，标题会要Fontsource没有的粗体Young Serif，浏览器把常规体加粗凑数，`doc.contentWarnings`里会把这个字体记为`fontFallback`。
