## できあがり

自然雑誌『Boreal』冬号の特集ページで、判型は225 × 297mmです。記事は、ページ上部に裁ち落としで渡した山の湖の写真の下から始まります。写真の下では、字間を広げたキッカーが2行の見出しの上に乗り、その右にイタリックのリード、その下に署名が来ます。写真家のクレジットは写真のすぐ下に入ります。見出しはMarkdownの見出しのテキストで、キッカー、リード、署名、クレジットはその属性です。記事は見開きにわたって両端そろえの2段で続きます。偶数ページには引用符がぶら下がるプルクオートと、右の段の頭にデータ囲み。奇数ページには上部に松林の帯、地に暗色の数字のパネルがあります。小さな四角で記事が終わります。次のページでは、フィールドガイドが図版と錆色のキッカーで同じ扉を使います。

## 作り方

### 1 · 見出しの行から扉を組む

コードは上の[手短な答え](#手短な答え)にあります。`{attr.<key>}`はそれぞれ記事の`#`行にある`<key>="…"`の値を印字し、`{titleText}`は見出しそのものを印字します（[見出しの属性](/ja/docs/document-format#見出しの属性)）。そのため各記事は自分の言葉を自分のMarkdownに持ち、レベル1の見出しはすべて1つのデザインを共有します。写真はページの天の縁から吊り下がり、コンテナーは22mm下から始まるので、`depth - TOP`はコンテナーから測った写真の下端になります。クレジットはその線の2mm下の右上に、キッカーは9mm下の左上に置きます。見出しはキッカーの`below`に、118mmの`HEAD`の行長で組みます。リードは見出しの`right-of`に置いて独自の幅を持たせないので、コンテナーの端で折り返します。署名はリードの`below`に置くので、リードが長くなれば署名は重ならずに押し下げられます。このレベルには`minHeight`がありません。見出しと署名はどちらも空の5mmのパディングで終わり、それが扉の高さに数えられるので、それぞれが何行になっても、記事は2つのうち低いほうの下端から少なくとも5mm下の、最初のグリッド行から始まります。

### 2 · 写真は一度だけ、実際のピクセル数で宣言する

<Excerpt region="resources" />

デザイン要素は写真をリソースidで指すので、扉の写真はほかの図と同じように宣言しますが、引用はしません。描くのは扉だけで、どのフロートも届かない仕上がり線まで広げます。ビットマップはページの150`dpi`で測るので、松林の2000pxは339mmになり、195mmの行長に縮んで、印刷では約260dpiになります。写真には専用の種類を設け、キャプションの接頭辞と番号のテンプレートを空にしているので、松林のキャプションには図番号が付きません。帯はページ幅の`top`フロートで、トップフロートはそれを引用したページの次のページに置かれます。その`::resource`行は偶数ページの1944年の段落のあとにあるので、帯は奇数ページの頭に来ます。

### 3 · 引用符を余白にぶら下げる

<Excerpt region="quote" />

グリフのアイコンは本文の横に専用の列を取るので、そのままでは引用が字下げされます。負のgapで、グリフの正方形の右側の空いた部分に本文を戻します。続いて、その列の残りの幅（サイズ + gap、34pt）と同じ幅の負の左パディングで列を余白へ押し出すと、本文は段の端から始まります。ボックスの枠は段の上にとどまるので、背景を付けると引用符の手前で途切れます。正方形は12mm外から始まり、その中央に置いた引用符は、偶数ページの14mmの小口の余白に約6mmぶら下がります。スペイン語版では«を小さく組みます。ギユメは引用符より低い位置に座り、幅も広いからです。

### 4 · 囲みを段の頭とページの地にフロートさせる

<Excerpt region="boxes" />

`placement: 'top'`にするとデータ囲みはフロートになります。流れから外れて次の空いた段の頭を取るので、囲みが入りきらなかった場所にすき間を残さず、本文は段の地まで続きます。数字のパネルは逆にページの地へフロートし、両段にまたがります。3つの数字は記事が使わないレベル4の見出しで、`breaks="3,5"`で配置します。これは行ではなく子ブロックを数えます。エンドマークは見える文字のないチップです。`paddingX`が四角の幅を、チップのフォントサイズが高さを決め、どちらもチップ自身のサイズで1.05emです。

### 5 · 号と記事を示す柱

<Excerpt region="heads" />

ヘッダーの要素はページの上に描かれ、スペースを確保しないので、どの部品も天の余白の中でページに固定し、ミリメートル単位でずらします。偶数ページはフロントマターから誌名と号を、奇数ページは特集の題を示し、`pages: 'body'`でどちらも扉には出しません。扉には地のノンブルだけが入ります。デザインのテキストのベースラインは、サイズの1.2倍の行ボックスの上から0.8の位置にあるので、`baseline()`は7.5ptのラベルを8.5ptのノンブルより0.34mm下げ、四角を同じ行に立たせます。どちらかのサイズを変えても、3つの部品は1本のベースラインを共有したままです。

### 6 · 次の記事にも扉を使い回す

<Excerpt region="guide" />

扉は関数なので、フィールドガイドは見出しスタイル`# Five Kinds of Ice {style="guide" kicker="Field guide" …}`を通じて、自分の図版と深さで同じデザインを得ます。図版は160mmではなく126mmまで裁ち落としで下がります。クレジットとキッカーは`depth - TOP`から測り、ほかの文字はキッカーから吊り下がるので、すべて34mm上がり、ガイドの本文はより高い位置から始まります。スタイルのパレットはそれらのページで`lake`を錆色に対応させるので、キッカーと、`lake`にリンクした小見出しや囲みは、`opener()`に色の引数を渡さなくても錆色になります。`lake`にリンクしたチップも錆色になりますが、エンドマークはどちらの記事でもインクの色にしています。

## アレンジ

### どの記事も奇数ページから始める

`'odd'`にすると、フィールドガイドは61ページに移り、60ページは白紙のまま残ります。

```diff
- { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'any' },
+ { level: 1, span: 'page', breakBefore: { enabled: true, parity: 'odd' },
```

## よくあるつまずき

- 画像要素は写真をボックスの中に収め、切り抜くことはありません。JPEGをボックスの縦横比、ここでは225 × 160mmに切っておきます。そうしないと写真が縮み、ページの縁に白い帯が残ります。
- ぶら下がる引用符には余白が必要です。編集でプルクオートが右の段に移ると、引用符は6mmの段間を埋め、左の段の本文に触れます。引用を1段落前か後ろに移してください。
- 記事は59ページで、数字のパネルの上で終わるようにコピーフィットしています。数行増えると記事の末尾が独立したページに送られるので、編集したあとは両方の言語でもう一度コピーフィットしてください。
- `runtMinCharacters: 40`は1語だけの最終行を防ぎます。行分割で短い最終行を避けられないとき、エンジンは段落を1行短く組み、語間を詰め、それでも足りなければ字間を最大0.01em詰めます。編集したあとは、そこまで詰めて組まれた段落を探し、代わりに数語を削るか足してください。収録した原稿は、どちらの言語でもこの修正を必要としません。
