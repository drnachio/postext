## できあがり

朱熹の『論語』の注釈書『論語集註』から、巻頭の「學而」の3丁を、見返しの後に版本の刷りのとおりに組みます。各ページは121 × 213 mmの半丁で、見開きひとつが1丁全体にあたり、右から読みます。半丁ごとに20ptのNoto Serif TCで1行17字の行が9行、二重の枠（四周双辺）、行と行のあいだにはすべて細線が入り、折り目には書名、黒い魚尾、巻、丁付を入れた版心が来ます。朱熹の注は、説明する語の後に、10ptの文字の2行割りで行の中に入ります。天の余白は地の2倍です。

## 作り方

### 1 · 1ページに半丁、見開きに1丁

コードは上の[手短な答え](#手短な答え)にあります。版木は1丁（葉）全体を一度に刷り、その2つの半分は版心の両側に分かれます。刷り手は紙を刷った面を外にして版心で折り、開いた側を綴じたので、版心が本の小口になりました。このレシピのページは、版木から刷り上がったときの丁のままに並んでいます。各ページが半丁です。[右綴じの本](/ja/docs/configuration-page-layout#綴じ)では、1ページは背の左に1ページだけで置かれ、それ以降の見開きは右の偶数ページとその次の奇数ページの組になります。そのため見返しを1ページに置けば、どの見開きにも1丁が収まります。[文字グリッド](/ja/docs/configuration-east-asian#文字グリッド)が版木の行款、つまり9行17字を決め、グリッドが残す余白はきっちりした値になります。内側の余白は版心の半分です。

Postextが番号を振るのはページで、丁ではありません。各丁は[非表示](/ja/docs/configuration-text#レベルごとの上書き)のレベル1の見出しで始まります。この見出しは何も印字せず場所も取りませんが、`parity: 'even'`の`breakBefore`で右ページを始めます。`numberingTemplate: '{1:一}'`による番号「一」「二」「三」は、版心用の`{chapterNumber}`になります。

### 2 · 各丁の終わりで本文を区切る

版木を彫る職人のために本文を書き写した筆耕は、丁ごとに本文を版木に合わせました。Markdownでも同じことをします。丁の見出しは、前の丁の左半分の9行目が終わる位置に置きます。文の途中でも、注の途中でもかまいません。そこで切れた注はいったん閉じてからまた開きます。各行は注のうち自分の分を2行に割るので、割注の行は元のとおりになります。

```markdown
子曰巧言令色鮮矣仁:warichu[巧好令善也好其言善其色致飾於]

# 學而

:warichu[外務以悦人則人欲肆而本心之德亡矣…]
```

版木には句読点がないので、禁則処理で文字が動くことはなく、どの行も17字目で終わります。丁の区切りは一度数えれば動きません。朱熹の注は既定の半分の大きさの[`:warichu[…]`](/ja/docs/document-format#中国語の記号ルビ割注)で、割注の1行に小さな文字が34字入り、版木と同じく読みと語釈のあいだに○を置きます。

### 3 · 版木はグリッドの数値から描く

<Excerpt region="frame" />

ヘッダーは紙面全体にレイアウトされるので、枠、界線、版心は、グリッドを決めた数値を使い、ページの隅からのポイントで配置します。版面には29ptごとに[罫要素](/ja/docs/configuration-page-layout#罫線要素)を置き、細い線には本文を4.5ptの間隔で囲む[囲み要素](/ja/docs/configuration-page-layout#ボックス要素)、太い線にはさらに4.5pt外側にもうひとつの囲み要素を使います。文字の各行は字送りの中央に立つので、界線は行と行のちょうど中間に来ます。版心の文字は[縦組みのテキスト要素](/ja/docs/configuration-page-layout#縦組みのテキスト要素)でページの下へ組み、魚尾はSVGの[画像要素](/ja/docs/configuration-page-layout#画像要素)で、どちらも版心の2本の線の中央、折り目の上に置きます。各ページに見えるのは版心の17pt分です。各ページは版心の文字と魚尾を丸ごと描いて自分の側の部分だけを見せるので、2ページを並べると両方の部分がつながります。枠が折り目を越えて伸びているのも同じ理由です。

### 4 · 見返しには専用のスタイルを

<Excerpt region="title" />

見返し（內封）は、非表示で番号のない[見出しスタイル](/ja/docs/configuration-styles#見出しスタイル)を持つレベル1の見出しなので、丁は「一」から数えたままです。スタイルはその節のページを受け持ち、そこでは`header`が文書のものを置き換えます。見返しには、半丁の付き物の代わりに、3つの行に分けた閉じた枠が入ります。著者表示、赤い楷書によるこの版の注記、刊記は見出しの[属性](/ja/docs/document-format#見出しの属性)から取ります。刊記は、版の言語によって変わるただ1行です。属性の中の`\n`で次の行に移ります。

### 5 · 書体ごとに、組む字だけを読み込む

<Excerpt region="voices" />

Fontsourceは中国語の各書体を、ウェイトごとに約100のファイルに分けて配信しています。宋体は丁の本文、版心、丁付を組むので、その呼び出しには見本の本文とそれらの字を渡します。楷書体が組むのは書名と注記だけです。版木には句読点がないので、どちらの書体にも`loadCjkFonts(…, { vertical: true })`の縦組み用字形は要りません。

### 6 · 温かみのある紙に一色の墨

<Excerpt region="palette" />

本文と版木の線は、紙に対して14 : 1のコントラストを持つ温かみのある黒一色で刷ります。それでもパレットでは`ink`と`rule`の2項目に分けてあるので、本文を変えずに線の色だけを変えられます。赤は、この版が加えたものに取っておきます。

## アレンジ

### 界線を赤で引く

四庫全書のために作られた写本は、赤い罫を引いた紙（朱絲欄）に書かれていました。罫の色を変えると、魚尾もそれに従います。

```diff
-  rule: '#1f1b17', // the frame, the column rules and the fish tail: the same block, same ink
+  rule: '#b3412e', // 朱絲欄: red rules under black text
```

### 別の版木を彫る

版木の行款はさまざまで、半葉十行，行二十字はもっともよく見られるもののひとつです。枠、版心、見返しの3つの区画、著者表示の字下げはすべてこれらの数値から算出するので、自動的に追従します。Markdownの中の丁の区切りは数え直す必要があります。

```diff
-const [BODY, PITCH, CHARS, LINES] = [20, 29, 17, 9];
+const [BODY, PITCH, CHARS, LINES] = [17, 24.5, 20, 10];
```

### 欧文のグリッドのページと比べる

<RecipeLink slug="baseline-grid-book-page">ベースライングリッドに組む本のページ</RecipeLink>は、この丁が行と字数から版面を組むように、行数から版面を組みます。<RecipeLink slug="certificate-single-page">修了証</RecipeLink>は、ここでの見返しと同じく、見出しスタイルのヘッダーに縁取りを描いています。

## よくあるつまずき

- 丁の区切りはMarkdownの中にあります。本文、大きさ、行款を変えると、あふれた丁が次の見出しを1ページ先へ押し出し、見開きと丁が合わなくなります。足りない丁は、折り目の手前に空の行を残します。すべての左ページの最終行を確かめてください。
- 四庫全書の翻刻は、已も己も同じく巳と入力しています。この見本では、それぞれを文脈から読み分けています。それでもこのテキストは影印と照らし合わせた校正を必要としており、それが表に出ています。張敬夫の言葉は必開其政となっていますが、彼が引く『論語』では必聞其政です。また2字は字形の画像になっています。見本では聞、傳、邦と組んでいます。組む前に、一節を別の版と照合してください。
- 同じ翻刻には、Noto Serif TCにグリフのない字形（廹 徳 絶 逺 専 内）が含まれます。そのうち5字はFontsourceのいずれかのファイルの範囲に入るので、`loadCjkFonts`は通してしまい、Canvasはシステムの書体で描き、postext-pdfは空の四角を印字して警告を出します。廹はどのファイルの範囲にも入らないので、`loadCjkFonts`はエラーで止まります。見本では迫 德 絕 遠 專 內と組んでいます。
