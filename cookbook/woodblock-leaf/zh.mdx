## 成品一览

在一张内封之后，照刻本的样子排出朱熹《论语集注》（論語集註）开头《学而》篇的三叶。每页是半叶，121 × 213 mm，每个跨页是完整的一叶，从右往左读：每半叶九行，每行17字，用20 pt的Noto Serif TC，四周双边，每两行之间一条细线；折缝处是版心，上有书名、黑鱼尾、卷次和叶码。朱熹的注文用10 pt的小字折成双行，排在所注文字之后的行内。天头是地脚的两倍。

## 做法

### 1 · 一页半叶，一个跨页一叶

代码见上文的[简短回答](#简短回答)。一块书版一次印出一整叶（葉），两个半叶分在版心两侧；印工沿版心把纸对折，印面朝外，再把开口的一边缝起来，于是版心成了书的书口。这里的页面保持书叶刚从书版上印下来时的样子，每页是半叶。在[右侧装订的书](/zh/docs/configuration-page-layout#装订)中，第1页单独位于书脊左侧，此后每个跨页都由右边的偶数页和它后面的奇数页组成，所以内封放在第1页，每个跨页就正好是一叶。[字格网格](/zh/docs/configuration-east-asian#字格)设定书版的行款，九行，每行17字，它留下的页边距是精确的：内侧页边距正好是版心的一半。

Postext给页面编号，不给书叶编号。每叶都以一个[隐藏](/zh/docs/configuration-text#按级别覆盖)的一级标题开头：它什么都不印，也不占位置，但它带`parity: 'even'`的`breakBefore`会从一个右页开始，它的编号（由`numberingTemplate: '{1:一}'`得到一、二、三）就是版心所用的`{chapterNumber}`。

### 2 · 在每叶结束处断开正文

为刻工写样的抄手按书版一叶一叶地安排文字，Markdown也这样做：一叶的标题放在上一叶左半叶第九行结束的地方，即使那里在一句话或一段注文中间。在那里被截断的注文先关闭，再重新打开；由于每行都把自己那部分注文折成两行，双行小注排出来和原来一样：

```markdown
子曰巧言令色鮮矣仁:warichu[巧好令善也好其言善其色致飾於]

# 學而

:warichu[外務以悦人則人欲肆而本心之德亡矣…]
```

书版没有标点，所以没有哪条避头尾规则会挪动字，每行都在第17字结束：叶的断点只需数一次，之后不会变。朱熹的注文是[`:warichu[…]`](/zh/docs/document-format#中文标记注音和双行夹注)，使用默认的一半字号，每行34个小字，读音和释义之间像刻本一样用○隔开。

### 3 · 用网格的数值画出书版

<Excerpt region="frame" />

页眉排在整张纸上，所以框、界行和版心都用设定网格的那些数值，从页面一角以点为单位定位：在文字区域内每隔29 pt放一个[线条元素](/zh/docs/configuration-page-layout#线条元素)，在正文外4.5 pt处放一个[方框](/zh/docs/configuration-page-layout#方框元素)作细线，再往外4.5 pt放另一个作粗线。每行字都居于自己行宽的正中，所以界行正好落在相邻两行的中间。版心的文字由[竖排文本元素](/zh/docs/configuration-page-layout#竖排文本元素)自上而下排出，鱼尾是一个SVG[图片元素](/zh/docs/configuration-page-layout#图像元素)，两者都居中于版心的两条线之间，也就是折缝上：每页显示版心的17 pt。每页都把版心文字和鱼尾完整地画出来，只显示自己这一侧的部分，两页并排时两部分就对上了。框线越过折缝也是同样的道理。

### 4 · 给内封一个自己的样式

<Excerpt region="title" />

内封（內封）是一个一级标题，使用一个隐藏且不编号的[标题样式](/zh/docs/configuration-styles#标题样式)，所以书叶仍从一开始计数。样式管辖其所在章节的页面，它的`header`在那里取代文档的页眉：内封得到一个封闭的、分成三栏的框，而不是半叶的那些版面元素。署名、本版的红色楷体说明和版权说明来自标题的[属性](/zh/docs/document-format#标题属性)；版权说明是唯一一行随版本语言而变的文字。属性中的`\n`另起一栏。

### 5 · 每种字体只加载它要排的字

<Excerpt region="voices" />

Fontsource把每种中文字体的每个字重拆成大约一百个文件。宋体排书叶、版心和叶码，所以它的调用传入样本文本和这些字；楷体只排书名和说明。书版没有标点，所以两种字体都不需要`loadCjkFonts(…, { vertical: true })`提供的竖排字形。

### 6 · 暖色纸上只用一种墨

<Excerpt region="palette" />

正文和书版的线条用同一种暖黑色印刷，与纸色的对比度为14 : 1。它们仍是调色板中的两项，`ink`和`rule`，这样可以只改线条的颜色而不动正文。红色留给本版添加的内容。

## 变化

### 用红色画界行

为《四库全书》缮写的本子用的是画好红格的纸（朱丝栏）。改一下线条颜色即可，鱼尾会跟着变。

```diff
-  rule: '#1f1b17', // 框、界行和鱼尾：同一块书版，同一种墨
+  rule: '#b3412e', // 朱丝栏：黑字红格
```

### 换一种行款

书版的行款有很多种，半葉十行，行二十字是最常见的一种。框、版心、内封的三栏和署名的缩进都由这些数值算出，所以会跟着变；Markdown中的叶断点则要重新数。

```diff
-const [BODY, PITCH, CHARS, LINES] = [20, 29, 17, 9];
+const [BODY, PITCH, CHARS, LINES] = [17, 24.5, 20, 10];
```

## 常见问题

- 叶断点写在Markdown里。改动正文、字号或行款后，一叶排不下时会把下一个标题推到下一页，跨页就和书叶对不上了；一叶排不满时，折缝前会留下空行。要检查每个左页的最后一行。
- 《四库全书》的录文把已和己都录成巳；这个样本根据句意逐个判断。页面仍需对照书影校对，这一点看得出来：张敬夫的话录作必開其政，而他所引的《论语》原文是必聞其政，另有两个字是字形的图片。样本排作聞、傳和邦。排一段文字之前，先用另一个版本核对。
- 同一份录文中有Noto Serif TC没有字形的字（廹 徳 絶 逺 専 内）。其中五个落在某个Fontsource文件的范围内，所以`loadCjkFonts`会放行，结果Canvas用系统字体画出它们，postext-pdf则印出空框并发出警告。廹不在任何文件的范围内，`loadCjkFonts`会报错停止。样本排作迫 德 絕 遠 專 內。
