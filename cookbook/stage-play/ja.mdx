## できあがり

オスカー・ワイルド『まじめが肝心』（The Importance of Being Earnest）の冒頭を、140×216mmの5ページの上演台本として組みます。扉は金色の二重枠に囲まれたプラム色のプレイビルで、「Importance」と「Earnest」をファットフェイスの大文字で組み、題の下に金色のカーネーションを置きます。第1幕の向かいの配役表には、1895年にセント・ジェームズ劇場で各役を初演した俳優の名を並べます。各台詞は話者名を太字のプラム色で始め、折り返した行を5mmぶら下げるので、俳優は次のきっかけをひと目で見つけられます。ト書きは台詞の中にあってもあいだにあってもグレーのイタリックで、台詞をさらうときは目で飛ばせます。スペイン語版はスペインの舞台の慣習に従った新訳で、各名前のあとにダッシュを置き、ト書きを丸括弧に入れます。

## 作り方

### 1 · 幕はふつうの見出し

<Excerpt region="acts" />

幕の題は、デザインのスロットを持たないレベル1の見出しで、Abril Fatfaceの24ptです。`textTransform`で大文字にし、13.6ptのグリッド行3行分を取ることで、大文字は版面の上端から5.5mm下に来ます（[見出し](/ja/docs/configuration#見出し)）。`textAlign: 'center'`はレベルごとには設定できないので、配役表の見出しと「Scene」のラベルも中央にそろいます。`breakBefore`をparity `'odd'`にすると、幕は奇数ページから、配役表の向かいで始まります。設定ではこれを改めて書く必要があります。`headings`オブジェクトがあるだけで、レベル1の改ページが無効になるからです（[前で改ページ](/ja/docs/configuration#前で改ページ)）。

### 2 · 配役表はタブ区切りの行から読む表

<Excerpt region="cast" />

Postextにはパイプ記法の表がないので、表はどれもリソースです。行は`content.cast.en.md`にあり、1行が表の1行で、セルのあいだにタブを入れます。`parseTSV`がそれをモデルに変えます（[表モデルの構築](/ja/docs/configuration#表モデルの構築)）。タブのない唯一の行、つまり劇場と日付を添えた初演の配役は、結合した行になります。`mergeCells`は最初のセルに`colSpan: 2`を与え、2つ目のセルは`hiddenBy`の印を付けてグリッドに残します。`headerRowCount: 1`でこの行をプラム色の帯に組みます。ほかの行は塗りません。Canvasでは、塗ったセルが2つ並ぶとあいだに淡い継ぎ目が見えるからです。俳優の列は幅の3分の1を取り、そのセルはどれも右にそろえます。場面の一覧も同じ関数を通し、罫のない名前付きスタイルで組みます（[名前付きの表スタイル](/ja/docs/configuration#名前付きの表スタイル)）。表はセルの中の文字をすべて1色で組み、`bodyColor`で別の色を指定しないかぎり本文のインキの色になります。そのため登場人物の太字の名前は、ここでは墨で、台詞の中ではプラム色で刷られます。

### 3 · 番号もキャプションもない飾り

<Excerpt region="ornament" />

`captionPrefix`と`shortLabel`を空にしたリソースの種類は、絵を何も添えずに刷ります（[リソースの種類](/ja/docs/configuration#リソースの種類)）。その`defaultPlacement`は、`::resource{id="fleuron"}`のある位置にカーネーションを中央そろえで置き、幅は107mmの行長の0.24、約26mmです。2つの表は番号のない2つ目の種類を使うので、どちらにも「Table 1」のラベルは付きません。

### 4 · 扉は見出しスタイル

<Excerpt region="playbill" />

`# The Importance of Being Earnest {style="playbill" …}`は題を4つの属性に分けて持ち、デザインはそれを2つの書体で組みます。名詞はAbril Fatfaceの40ptと60pt、「The」と「of Being」はLibre Baskervilleのイタリック17ptです（[見出しの属性](/ja/docs/document-format#見出しの属性)）。プラム色の地、枠、カーネーションは、コードで描いた1つのSVGで、裁ち落としに固定します（[画像要素](/ja/docs/configuration#画像要素)）。本は1段組みですが、スタイルは`span: 'page'`を設定します。段の中に置くと、デザインは版面の上端と下端、つまり用紙の上端から20mm下と下端から23.3mm上で切れてしまいます。スタイルの空の`header`は、同じ節に属する配役表から柱を外します。空の`footer`は扉から下ノンブルを外します。扉に置くと、プラム色の上にプラム色で刷られてしまいます（[見出しスタイル](/ja/docs/configuration#見出しスタイル)）。

扉の画像は高さを確保しないので、見出しがページを押さえるのは、いちばん下の文字の行、176mmの初演の行までです。その下に残る空きは次の見出しには足りず、題のあとの`:::pagebreak`がなくても、キャプチャーしたページは同じになります。この改ページはあとの編集のためにあります。これがないと、劇場と初演の行を150mmと156mmに上げたとき、「The Persons of the Play」がプラム色の紙面で始まってしまいます。1.4.1では、`letterSpacing`を付けた中央そろえの行は、その字間の半分だけ中央から左にずれます。そこで`line()`は字間を空けた各行を同じ量だけ右へ動かします。「OSCAR WILDE」の中央からのずれは0.56mmではなく0.07mmになります。

### 5 · 幕の最初のページを飛ばす柱

<Excerpt region="heads" />

偶数ページにはフロントマターから戯曲の題を、奇数ページには`{chapterTitle}`から幕名を入れます。どちらもPlayfair Display SCの大文字で、ノンブルは外側の端にプラム色で置きます（[テキスト要素](/ja/docs/configuration#テキスト要素)）。幕の最初のページは、最初のブロックが改ページする見出しなので扉として数えられ、`pages: 'body'`でそこから柱を外し、フッターが代わりに下ノンブルを付けます。

<Note>
映画の脚本は台詞をぶら下げず、左右両側から字下げします。<RecipeLink slug="screenplay-format">映画脚本の書式</RecipeLink>では、各台詞を台詞ブロックの幅までパディングした枠なしの囲みとして組んでいます。
</Note>

## アレンジ

### ト書きを折り返しの行にそろえる

左そろえにして1行目を5mm字下げすると、1行のト書きは台詞の折り返しの行と同じ位置から始まり、舞台の設定は中央そろえのラベルの下で、字下げした2つの段落になります。

```diff
 const direction = { id: 'direction', fontSize: pt(8.6),
-  textAlign: 'center', firstLineIndent: pt(0) };
+  textAlign: 'left', firstLineIndent: mm(5) };
```

### 台詞のあいだに1行空ける

`paragraphSpacing: true`は、各台詞のあとに空のグリッド行を1行足します。英語版の幕は3ページから5ページに、スペイン語版は4ページに延びます。

```diff
   maxRuntTracking: 0, // gotcha: runt-tracking-unpainted
+  paragraphSpacing: true,
 };
```

## よくあるつまずき

- 台詞の中のイタリックはすべて、強調も含めて`italicColor`を取ります。そのためレインが強調する「is」も、ト書きのグレーで刷られます。1.4.1では段落スタイルがイタリックに独自の色を与えられないので、グレーは`bodyText`に設定するしかありません。「is」を墨のまま保てるのはローマン体だけです。
- ワイルドの台詞のうち3つは、1語だけの最終行で終わります。「information.」「that?」「you.」です。台本は`bodyText.maxRuntTracking: 0`を設定しています。つまずき「ラント（最終行に残った短い一語）の修正が、描画されないトラッキングを詰めることがある」のためです。既定のままだと、1.4.1は「that?」を2.0mmの負のトラッキングで前の行に引き上げますが、Canvasはそれを描画せず、その行は語間が半分の幅で刷られます。語間だけで「that?」を引き上げるには、`minWordSpacing`を0.5にするしかなく、これも同じように行を詰め込みます。あるいは行長を1.5mm広げる手もありますが、通常の語間の1.5倍よりゆるい行が2行から10行に増えます。英語のページは、ワイルドの言葉を変えるよりも3つのラントを残しています。スペイン語訳は、行が1文字の語で終わる箇所や音節が1つだけ残る箇所をすべて言い換えました。
- 名前もほかの語と同じくハイフネーションされます。5ページでは「Au-gusta」と「Gwen-dolen」が行をまたいで分かれています。「Augusta」の中にワードジョイナー（U+2060）を入れれば一語のまま保てますが、上の行の語間が通常の1.71倍に広がるので、英語のテキストはハイフンを残しています。
- Playfair Display SCはCanvasで「fi」を小文字の合字として描くので、「first」はスモールキャピタルの中に小文字の「fi」が混じって刷られます。配役表の帯が「The original cast」となっているのはそのためです。
