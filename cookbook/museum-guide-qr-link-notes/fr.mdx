## Ce que vous allez composer

Un guide de poche des salles hollandaises du Metropolitan Museum of Art : cinq tableaux, une heure à pied, un tableau par page. La couverture est la jeune femme de Vermeer à la fenêtre, coupée par le bord supérieur. Chaque étape s’ouvre sur le numéro de salle, le titre et le peintre, puis le tableau avec son cartel à côté, puis trois courts paragraphes. Le texte renvoie au catalogue du musée comme le ferait n’importe quelle page web. Sur papier, chaque lien devient un petit numéro, et en bas de page la note donne l’adresse courte et un code QR que le visiteur vise avec son téléphone devant le tableau.

## Préparation

### 1 · Écrire des liens, imprimer des notes

Le code est [la réponse courte](#la-réponse-courte) ci-dessus. Le Markdown garde des liens ordinaires, `[La fiche du catalogue](https://www.metmuseum.org/…/436616)`, et `links.print: 'notes'` change chacun en note numérotée avec l’adresse et le code ([liens sur papier](/fr/docs/configuration-notes-references#liens-sur-papier)). Ces notes sont des notes de bas de page : `numbering: 'document'` les compte sur toute la promenade, le lecteur rencontre donc les notes 1 à 7, et `repeat: 'first'` laisse la dernière étape citer le Hals par sa note 3 au lieu d’imprimer deux fois le même code. Dans le PDF, le code est dessiné en vectoriel et forme lui-même un lien.

### 2 · Une étape par page

<Excerpt region="stops" />

Chaque étape est un titre de second niveau dont le `breakBefore` ouvre une page, paire ou impaire : le visiteur tourne un feuillet par tableau. Le numéro de salle et le peintre sont des attributs du titre ; le dessin les place au-dessus et au-dessous du titre, et `minHeight` met le tableau à la même hauteur sur toutes les pages.

### 3 · Le cartel à côté du tableau

<Excerpt region="resources" />

`captionSide: 'inside'` place la légende et sa note de crédit à côté du tableau, comme un musée accroche son cartel, et `width` donne à chaque tableau sa part de la justification : moins au Hals, qui est haut, plus au Ruisdael, qui est en largeur, si bien que les cinq pages gardent une hauteur de texte voisine. Le cartel réunit la technique, les dimensions en centimètres avec des espaces insécables et la ligne de crédit du musée, avec une virgule décimale dans l’édition espagnole.

### 4 · L’étape dans le titre courant

<Excerpt region="heads" />

`{firstMark.h2}` imprime le titre de l’étape qui commence sur la page : la belle page nomme le tableau, la fausse page le guide. Aucun titre courant n’atteint la couverture, une page dont le rôle est celui d’ouverture.

## Variantes

### Imprimer l’adresse dans la ligne

Pour un guide lu chez soi, `'inline'` ajoute l’adresse entre parenthèses après le texte du lien, sans note ni code.

```diff
-  print: 'notes', // a note marker after the link text, the address in a note at the foot
-  show: 'both', // the short address for reading, the code for the phone
+  print: 'inline', // (metmuseum.org/…) after the link text
```

### Des codes sans adresse

`show: 'qr'` imprime le code seul à côté du numéro de note, pour une affiche ou un cartel où l’adresse ne ferait que prendre de la place.

```diff
-  show: 'both', // the short address for reading, the code for the phone
+  show: 'qr', // the code alone
```

## Erreurs fréquentes

Une note avec code est au moins aussi haute que le code. Quand la ligne qui porte le lien n’a pas la place de sa note en dessous sur la page, la ligne passe à la suivante avec sa note : gardez les liens hors des dernières lignes d’une page qui doit finir là où elle finit, comme le premier paragraphe de la couverture de ce guide.
