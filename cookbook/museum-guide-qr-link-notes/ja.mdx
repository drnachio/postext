## できあがり

メトロポリタン美術館のオランダ絵画の展示室をめぐるポケットガイド。5 点の絵を 1 時間で歩き、1 ページに 1 点を載せる。表紙はフェルメールの窓辺の若い女性で、絵は紙の上端で断ち切られている。各ストップは展示室番号、作品名、画家で始まり、その下に絵と横の作品ラベル、続いて短い 3 段落が来る。本文は美術館のカタログへ、ふつうのウェブページと同じようにリンクする。紙の上では各リンクが小さな番号になり、ページの下の注に短いアドレスと QR コードが入る。来館者は絵の前でスマートフォンをコードにかざす。

## 作り方

### 1 · リンクを書き、注を印刷する

コードは上の[手短な答え](#手短な答え)にある。Markdown にはふつうのリンク `[The catalogue entry](https://www.metmuseum.org/…/436616)` を書き、`links.print: 'notes'` がそれぞれをアドレスとコード付きの番号注にする（[印刷物でのリンク](/ja/docs/configuration-notes-references#印刷物でのリンク)）。この注は脚注として扱われる。`numbering: 'document'` で散策全体に通し番号を振るので、読者が見るのは 1 から 7 まで。`repeat: 'first'` により、最後のストップはハルスの絵を注 3 の番号で引き、同じコードを 2 度印刷しない。PDF ではコードがベクターで描かれ、それ自体もリンクになる。

### 2 · 1 ストップを 1 ページに

<Excerpt region="stops" />

各ストップは第 2 レベルの見出しで、`breakBefore` によって左右を問わず新しいページから始まる。来館者は絵ごとに 1 枚めくればよい。展示室番号と画家は見出しの属性で、デザインがそれを作品名の上と下に置く。`minHeight` によって、どのページでも絵が同じ高さから始まる。

### 3 · 絵の横に作品ラベル

<Excerpt region="resources" />

`captionSide: 'inside'` は、キャプションとクレジットの注を絵の横に置く。展示室の壁のラベルと同じ配置だ。`width` で絵ごとに版面の取り分を決める。縦長のハルスは少なめ、横長のロイスダールは多めにして、5 ページの本文の高さをそろえる。ラベルは技法、センチメートルの寸法（改行しないスペースでつなぐ）、美術館の収蔵の記載から組み立て、スペイン語版では小数点にコンマを使う。

### 4 · 柱にストップ名を

<Excerpt region="heads" />

`{firstMark.h2}` は、そのページで始まるストップの作品名を印刷する。奇数ページには絵の名、偶数ページにはガイドの名が入る。表紙は扉の役割のページなので、柱は出ない。

## アレンジ

### アドレスを行内に印刷する

家で読むガイドなら、`'inline'` でリンクの文字の後ろに丸括弧でアドレスを加え、注もコードも付けない。

```diff
-  print: 'notes', // a note marker after the link text, the address in a note at the foot
-  show: 'both', // the short address for reading, the code for the phone
+  print: 'inline', // (metmuseum.org/…) after the link text
```

### アドレスなしのコード

`show: 'qr'` は注の番号の横にコードだけを印刷する。アドレスが場所を取るだけのポスターや作品ラベルに向く。

```diff
-  show: 'both', // the short address for reading, the code for the phone
+  show: 'qr', // the code alone
```

## よくあるつまずき

コード付きの注は、少なくともコードと同じ高さになる。リンクを含む行の下に、そのページで注を置く余地がないと、その行は注と一緒に次のページへ移る。決まった位置で終わらせたいページでは、最後の数行にリンクを置かないこと。このガイドの表紙の最初の段落もそうしている。
