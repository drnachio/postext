## 成品一览

伊本·赫勒敦《历史绪论》（Muqaddima）第一部分“论历史学之可贵”的现代阿拉伯文校勘本，共十一页。前置部分按开罗和贝鲁特的版本习惯用abjad字母编页：书名页أ，其背面的版权页ب，然后是校者导言ج和د。正文在下一个奇数页从١重新开始。校者注放在每页页脚，编为(١)、(٢)、(٣)，每页重新起算，排在右侧一条短线下；注释解释生僻词，考订伊本·赫勒敦提到的人名地名，并为每段古兰经引文注明章节。书末是人名索引，按阿拉伯文索引的习惯排序，不计冠词ال。注释和导言都是为这个食谱撰写的。

## 做法

### 1 · 两套页码，按页编注

代码见上文的[简短回答](#简短回答)。`page.pageNumbering`让全书从`'abjad'`开始，即按abjad顺序排列的字母，五写作هـ。正文之前，两个指令在下一个奇数页用文档数字重新计数（[`:::numbering`](/zh/docs/document-format#numbering)、[数字系统与编号样式](/zh/docs/arabic-layout#数字系统与编号样式)）。脚注设为`numbering: 'page'`、`markerTemplate`为`'({n})'`、`noteNumberPosition: 'inline'`，所以注码在正文中上标，注释则以平排的序号开头（[脚注](/zh/docs/arabic-layout#脚注)）。

### 2 · 跳过冠词的索引

<Excerpt region="index" />

人名在正文里用`:index[المسعودي]`标记，`:::index`把它们印在书末。设了`ignoreArticle`后，المسعودي归在م下，الطبري归在ط下，而ابن إسحاق仍在ا下；一条参见把إسرائيل引向يعقوب（[目录与索引](/zh/docs/arabic-layout#目录与索引)）。索引中的页码是页面的标签，所以导言里的人名指向ج。

### 3 · 线上的书眉

<Excerpt region="furniture" />

偶数页书眉印书名，奇数页印章节名，下面是一条与版心等宽的细线，页码在外端。右侧装订的书，偶数页在跨页右边，所以它的页码在右上（[页序与右侧装订](/zh/docs/arabic-layout#页序与右侧装订)）。章首页和前置部分则把页码居中放在页脚。

### 4 · 书名页和版权页

<Excerpt region="title" />

书名页和它背面的版权页都是正文流里没有内容的标题样式：各行取自标题属性，所以版权页上随版本语言变化的拉丁文行，在Markdown里只是一个属性。

## 变化

### 改用abjad数字

`'arabic-abjad'`写出累加式的abjad数字，而不是简单的字母序列：第十一页是يا，而不是ك。

```diff
-const pageNumbering = { format: 'abjad', startAt: 1 }; // أ ب ج د هـ و ز ح…
+const pageNumbering = { format: 'arabic-abjad', startAt: 1 }; // … ط ي يا يب
```

### 整节连续编注

`numbering: 'chapter'`让注释跨页连续编号，一些旧版本就是这样做的。

```diff
-  numbering: 'page', markerTemplate: '({n})', noteNumberPosition: 'inline',
+  numbering: 'chapter', markerTemplate: '({n})', noteNumberPosition: 'inline',
```
