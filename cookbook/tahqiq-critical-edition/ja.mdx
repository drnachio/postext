## できあがり

Ibn Khaldūnの『歴史序説』（Muqaddima）のうち、歴史学の優れた点を論じる最初の節を、現代のアラビア語の校訂版、つまりタフキーク（taḥqīq）として11ページ組みます。前付けには、カイロやベイルートの版と同じようにアブジャドの文字でノンブルを振ります。扉がأ、その裏の刊記がب、続く校訂者の序文がجとدです。本文は次の奇数ページで١から数え直します。校訂者の注は各ページの地に、右寄りの短い罫の下に置き、(١)、(٢)、(٣)と番号を振って、ページごとに振り直します。注は珍しい語を説明し、Ibn Khaldūnが挙げる人物と土地を特定し、クルアーンの引用ごとに章（スーラ）と節を示します。巻末には人名索引を置き、アラビア語の索引の流儀どおり、冠詞الを除いて並べます。注と序文はこのレシピのために書いたものです。

## 作り方

### 1 · 2系統のノンブルと、ページごとの注

コードは上の[手短な答え](#手短な答え)にあります。`page.pageNumbering`は本を`'abjad'`、つまりアブジャド順の文字で始めます。5はهـです。本文の前に置いた2つのディレクティブが、次の奇数ページから文書の数字で数え直させます（[`:::numbering`](/ja/docs/document-format#numbering)、[数字と番号の書式](/ja/docs/arabic-layout#数字と番号の書式)）。注には`numbering: 'page'`、`markerTemplate`の`'({n})'`、`noteNumberPosition: 'inline'`を設定します。こうすると合印は本文の中で上がり、注は行の中でその番号から始まります（[脚注](/ja/docs/arabic-layout#脚注)）。

### 2 · 冠詞を飛ばす索引

<Excerpt region="index" />

名前は本文の中で`:index[المسعودي]`のように印をつけ、`:::index`が巻末に印字します。`ignoreArticle`を使うと、المسعوديはمに、الطبريはطに入り、ابن إسحاقはاのままです。参照項目でإسرائيلをيعقوبへ導きます（[目次と索引](/ja/docs/arabic-layout#目次と索引)）。索引のページ番号はページのラベルなので、序文に出てくる名前はجとなります。

### 3 · 罫の上の柱

<Excerpt region="furniture" />

偶数ページには書名、奇数ページには節の名前を、版面と同じ幅の細罫の上に置き、ノンブルは小口側の端に入れます。右綴じの本では偶数ページが右ページになるので、そのノンブルは右上に来ます（[ページの順序と右綴じ](/ja/docs/arabic-layout#ページの順序と右綴じ)）。扉と前付けでは、代わりに地の中央にノンブルを置きます。

### 4 · 扉とその刊記

<Excerpt region="title" />

扉とその裏の刊記は、本文の流れに何も持たない見出しスタイルです。行は見出しの属性から取るので、版によって変わる刊記の欧文の行は、Markdownの中の属性ひとつで済みます。

## アレンジ

### アブジャド数字を使う

`'arabic-abjad'`は、単純な文字の並びではなく、加算式のアブジャド数字を書きます。11ページ目はكではなくياになります。

```diff
-const pageNumbering = { format: 'abjad', startAt: 1 }; // أ ب ج د هـ و ز ح…
+const pageNumbering = { format: 'arabic-abjad', startAt: 1 }; // … ط ي يا يب
```

### 注の番号を節を通して振る

`numbering: 'chapter'`にすると、古い版のいくつかと同じように、注の番号はページをまたいで続きます。

```diff
-  numbering: 'page', markerTemplate: '({n})', noteNumberPosition: 'inline',
+  numbering: 'chapter', markerTemplate: '({n})', noteNumberPosition: 'inline',
```
