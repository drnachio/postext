## 成品一览

五页，按十九世纪布拉克印书馆及其后开罗各家印注释书的方式来排。伊本·阿基勒对伊本·马利克语法诗《千行诗》（Alfiyya）开篇诗句的讲解排在主栏，诗句用红色；外侧页边是一份页边注（ḥāshiya），每条简注都以所解释的原文字句开头，排在所属段落旁边。双线框住版心，顶部有一条书眉带，放章名和页码，一条单线把正文和页边隔开。真正的布拉克页面，页边注从三面环绕正文；Postext只能放在一侧，这个食谱如实说明了这一点。

## 做法

### 1 · 页边注有自己的边栏

代码见上文的[简短回答](#简短回答)。用一栏半版式，并让边栏只接收浮动内容，注释就不进入正文的文字流：每条边注写成`:::callout{type="hashiya" span="side"}`，放在所解释的段落之后，它就排在该段落旁边（[版式](/zh/docs/configuration#版式)）。这个框没有底色、边框和内边距，读起来就像排在页边的文字；词目用粗体，`boldColor`把它变成红色。`sideColumnSide: 'outer'`把边栏放在两页的外侧切口：在右侧装订的书里，偶数页位于跨页右边，边栏就在它的右侧。

### 2 · 跨页两侧各画一个边框

<Excerpt region="frame" />

边框是页眉里的三个页面设计元素：两个有边线、无填充的框，相距1.3 mm，以及书眉带下方的一条线。页面元素按纸页的物理方向放置，所以边框按奇偶各建一次，用该侧的页边距计算（[页序与右侧装订](/zh/docs/arabic-layout#页序与右侧装订)）。页码在每一页都放在书眉带的外端，章首页也不例外；章名居中，章首页上不放，因为标题本身就在它下面。

### 3 · 同一个边框里的书名页

<Excerpt region="title" />

书名页沿用这个边框，只是不要书眉带。各行文字取自标题属性`on`和`margin`，所以整个书名页只是一行Markdown，下方那行拉丁文随版本语言变化。

## 变化

### 把注释放在内侧

有些印书馆把页边注放在靠书脊的一侧，让正文保留较宽的外侧页边。

```diff
-const layout = { layoutType: 'oneAndHalf', sideColumnRole: 'floats', sideColumnSide: 'outer',
+const layout = { layoutType: 'oneAndHalf', sideColumnRole: 'floats', sideColumnSide: 'inner',
```

### 给每条边注加框

后来一些开罗印本在每条边注外加一道细线，这就是标注框自己的边框。

```diff
-  stripe: { enabled: false }, border: { enabled: false },
+  stripe: { enabled: false }, border: { enabled: true, width: pt(0.4), color: col('rule') },
```
