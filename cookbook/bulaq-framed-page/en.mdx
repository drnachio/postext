## What you'll build

Six pages set the way the Bulaq press and its Cairo successors printed a commentary in the nineteenth century. Ibn ʿAqīl’s explanation of the first verses of the Alfiyya, Ibn Mālik’s grammar in a thousand lines, runs in the main column, the verses in red; in the outer margin stands a ḥāshiya, short glosses that each open with the words of the text they explain, beside the passage they belong to. A double rule frames the type area, with a band at its head for the chapter and the folio, and a single rule parts the text from its margin. A real Bulaq page wraps the ḥāshiya round three sides of the text; Postext sets it on one side only, and this recipe says so.

## Method

### 1 · The ḥāshiya in a side column of its own

The code is [the short answer](#the-short-answer) above. A column-and-a-half layout whose side column takes only floats keeps the commentary out of the text’s flow: each gloss is a `:::callout{type="hashiya" span="side"}` written after the paragraph it explains, and it stands level with that paragraph ([Layout](/en/docs/configuration#layout)). The box has no background, border or padding, so it reads as text set in the margin, its lemma in bold, which the `boldColor` turns red. `sideColumnSide: 'outer'` puts the column at the fore-edge of both pages: on the right of the even page, which lies on the right in a book bound on the right.

### 2 · A frame drawn for each side of the spread

<Excerpt region="frame" />

The frame is three page design elements in the header: two boxes with a border and no fill, 1.3 mm apart, and a rule under the band that holds the running head. Page elements are physical, so the frame is built twice, once per parity, from the margins of that side ([Page order and right binding](/en/docs/arabic-layout#page-order-and-right-binding)). The folio sits at the outer end of the band on every page, openers included; the chapter title is centred and left off the opener, where the title itself stands under it.

### 3 · A title page inside the same frame

<Excerpt region="title" />

The title page reuses the frame without its band. Its lines come from heading attributes, `on` and `margin`, so the whole title page is one line of Markdown, and the Latin line under them changes with the edition.

## Variations

### Put the commentary on the inner side

Some presses set the ḥāshiya by the spine, so the text keeps the wider outer margin.

```diff
-const layout = { layoutType: 'oneAndHalf', sideColumnRole: 'floats', sideColumnSide: 'outer',
+const layout = { layoutType: 'oneAndHalf', sideColumnRole: 'floats', sideColumnSide: 'inner',
```

### Box each gloss

A thin rule round each gloss, as some later Cairo prints have, is the callout’s own border.

```diff
-  stripe: { enabled: false }, border: { enabled: false },
+  stripe: { enabled: false }, border: { enabled: true, width: pt(0.4), color: col('rule') },
```
