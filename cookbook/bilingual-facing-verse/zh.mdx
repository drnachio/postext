## 成品一览

一本收录五首诗的双语小诗集，写的是西班牙南部的一片盐田，开本156 × 234 mm，左边是西班牙语原文，右边是诗人自己的英文译本，逐行对应。书前是一张带火烈鸟的扉页和作者说明；诗作从一幅水彩画下开始，画的是日出时粉色的盐池、盐堆和火烈鸟。每首诗放在一个无边框的框里，上方是Castoro Titling字体的茜红色编号，西班牙语在一栏，英文在另一栏。英文与西班牙语从同一行开始，每一节都与原文齐平。英文诗行太长、一栏放不下时，余下部分转行并缩进2 em，对面的西班牙语诗节则在结尾多留一个空行。

## 做法

### 1 · 一首诗就是一个带固定分栏点的框

代码见上文的[简短回答](#简短回答)。每首诗都是一个标注框，里面放一个`:::columns`分栏组；它的样式去掉了填色和内边距，并印出围栏的`title`，也就是编号（[`:::columns`](/zh/docs/document-format#columns)）。不设`breaks`时，这一组在两栏高度相等的地方切开。这些诗的两半高度相同，所以切点本来就落在英文标题上；但如果把*The Rake*的两行加长到需要转行，切点就会下移一个块，让THE RAKE落在西班牙语栏的栏尾。`breaks="5"`指定开启第二栏的那个块，所以无论两半高度如何，英文标题都位于第二栏栏首。

### 2 · 每栏一个:::verse块，诗节之间一个空行

<Excerpt region="verse" />

每首诗的一半是一个`:::verse`块：Markdown的一行就是一行诗，齐左且不断词，诗节之间一个空行，在栏里留出一个空行（[`:::verse`](/zh/docs/document-format#verse)）。每个诗节是一个块，所以`breaks`数的是诗节而不是诗行。英文*each one standing on its own reflection.*对55 mm的栏来说太长，转行并缩进2 em；西班牙语一半在对面那一节之后结束自己的块，并在下一节之前放一个`:::space{lines=2}`，所以下一节从同一行开始。`:::space`不是块，`breaks`不计算它（[`:::space`](/zh/docs/document-format#space)）。

### 3 · 说明按它自己的语言断词

<Excerpt region="note" />

`locale`选择断词模式。用`'es'`时，西班牙语说明断成*ori-ginal*和*Duna-liella*；用英文模式时，这两个词都会整个移到下一行，只有*arras-traba*在两种模式下都会断开（[支持的语言](/zh/docs/justification#支持的语言区域)）。词间距可以压缩到正常宽度的0.8倍、拉伸到1.35倍，两篇说明中没有一行两端对齐的文字超过这个限度。说明的标题是一个版面设计，其中唯一的元素即标题，位于版心顶端下方36 mm处，所以说明从页面上边缘往下73 mm处开始。

### 4 · 扉页和水彩画都是标题

<Excerpt region="front" />

它们都是一级标题，各有自己的样式（[标题样式](/zh/docs/configuration#标题样式)）：扉页的版面设计从frontmatter取`{author}`，两个版面设计都从标题属性取`{attr.other}`。水彩画锚定在页面上边缘，在版心之上，标题一直预留到画的底边，即距页面上边缘84 mm处。样式设了`marginBottom: pt(0)`，所以画下面的空白就是诗自己两行的上外边距，诗I从画下方至少两行处的第一条网格线开始。

### 5 · 书眉写出两种语言

<Excerpt region="heads" />

左页书眉是西班牙语书名，右页是英文书名，顺序与栏的顺序一致。`pages: 'body'`让三个以标题开篇的页面不印书眉。说明和水彩画页改为在页脚印页码，扉页的样式则清空了页眉和页脚（[文本元素](/zh/docs/configuration#文本元素)）。

## 变化

### 加宽栏间距

栏间距为12 mm时，每栏缩窄到53 mm，诗III中的*Los turistas paran y hacen fotos:*会转行，于是第二节比英文晚一行开始；在该节之后结束英文的块，并在下一节之前放一个`:::space{lines=2}`，即可让两边齐平。

```diff
-const GAP = 8; // 原文与译文之间的毫米数：每栏宽55 mm
+const GAP = 12; // 原文与译文之间的毫米数：每栏宽53 mm
```

### 转行悬挂得更深

设为3 em时，第3页的*reflection.*会再往里缩进一个em。

```diff
-const verse = { id: 'verse', hangingIndent: em(2) };
+const verse = { id: 'verse', hangingIndent: em(3) };
```

## 常见问题

- 放在英文标题之前的`:::space`会消失：第二栏从`breaks`指定的块开始，这个空行正好落在切点上。应当把它放在标题之后，就像这里每个栏标题下的`:::space{lines=0.5}`。
- `breaks`要从西班牙语标题开始数：一个标题加三个诗节，英文标题就是第5块。每个诗节都是一个块，所以西班牙语多一个诗节，英文标题就变成第6块，`breaks`也要跟着加一；诗节内多一行则不影响。
