## 成品一览

一本四页A5的纪念小册，由一张A4纸对折而成，收录乔治·赫伯特*The Temple*中的两首图形诗，拼写依照1633年初版。扉页仿照1633年版，连《诗篇》第29篇的题词也照样保留。内页中，*The Altar*与*Easter Wings*相对。两首诗都没有一行靠缩进或空格来调整；每行都居中，于是祭坛立在一根窄窄的支柱上，翅膀的每个诗节收窄到两个词再放宽。最后一页在赫伯特的箴言下有一段说明，讲1633年的印刷商如何把翅膀横着排，版权信息一行比一行短。全部内容都用IM Fell字体排成正文或三级标题之一，不用具名样式，也不用页面设计。西班牙语版排的是一个逐行对应的译本，保留了两个图形。

## 做法

### 1 · 一行诗就是一个居中的段落

代码见上文[简短回答](#简短回答)。Postext会把Markdown段落中的各行连成一行，所以每行诗都是一个段落，后面跟一个空行。`textAlign: 'center'`把每行按其自然宽度排在行长的中轴上；而默认只对两端对齐的文字断词（除非打开`hyphenation.ragged`），所以没有词被拆开（[正文](/zh/docs/configuration-text#正文)）。每行都是所在段落的首行，所以默认1.5 em的首行缩进会把它推到标题中轴右侧3.3 mm处；`firstLineIndent: pt(0)`让诗和标题保持在同一条中轴上。

### 2 · 行长要容得下最长的一行

<Excerpt region="measure" />

放不下的行会折行，折出的两半各自居中，于是轮廓上多出一个赫伯特原图中没有的台阶。行长为75 mm时，*The Altar*有三行、*Easter Wings*有两行会折行，小册会增加到六页。这里最宽的一行是*Easter Wings*的第一行，英语为80.7 mm，西班牙语为80.0 mm，所以A5页面上110 mm的行长能让每一行完整排下。

### 3 · 简朴的居中标题

<Excerpt region="titles" />

各级标题都没有设计，只有字体设置，`headings.textAlign`让三级标题都居中（[标题](/zh/docs/configuration-text#标题)）。奇偶设为`'any'`时，每首诗从下一页开始，不论左右页，所以第2页的祭坛与第3页的翅膀相对。`marginTop`不能把这些标题往下移，因为开页标题上方的空白会被去掉。改由二级标题三行高的行框把每个标题降低约5 mm，两首诗都从版心第5行开始。一级标题是文档的开头，这里不需要分页；仍给它设了分页，是为了让第二个`#`标题从右页开始。三级标题用IM Fell English SC的小型大写字母、正文字号，排第1页和第4页的四个标签。

### 4 · 用Markdown安排间距和分页

<Excerpt region="pages" />

段落之间的空行不增加间距，所以这几页上的每一处空白都来自`:::space`：*Easter Wings*的两个诗节之间一行，扉页上《诗篇》标签上方五行、题词下方十行（[`:::space`](/zh/docs/document-format#space)）。按这些行数，第1页的出版信息在版心最后一行结束，《诗篇》上方和说明上方的两个标签都在第13行，距页顶94 mm。`:::pagebreak`开始最后一页（[`:::pagebreak`](/zh/docs/document-format#pagebreak)）。版权信息也是每行一个段落，在短语结束处断开，所以四行逐渐收窄，形成尾饰。

## 变化

### 每首诗从右页开始

奇偶设为`'odd'`时，*The Altar*和*Easter Wings*分别从第3页和第5页（都是右页）开始，小册增加到六页，第2、4页空白。

```diff
-      breakBefore: { enabled: true, parity: 'any' } },
+      breakBefore: { enabled: true, parity: 'odd' } },
```

### 诗行齐左

用`textAlign: 'left'`时，每行都从页边距开始，两首诗只剩右侧的轮廓；其余正文（从副标题到版权信息）也都齐左，只有标题仍然居中。

```diff
-  textAlign: 'center', // 两侧不齐；默认只对两端对齐的文字断词
+  textAlign: 'left', // 右侧不齐；默认只对两端对齐的文字断词
```

## 常见问题

- 对行长来说太长的诗行会折行，两半各自居中。选定字号和页边距之前，先量一量最宽的一行。诗行齐左、折行悬挂的排法，见<RecipeLink slug="poetry-collection">逐行排诗</RecipeLink>。
- 段落开头的空格会被去掉，所以不能用空格把一行垫成想要的形状。每行的宽度只取决于它的文字，译本必须找到与原作宽度相近的诗行，西班牙语版就是这样做的。
- 居中让每行保持自然宽度，所以*The Altar*的台面和底座排不成方形：台面的第三、四行比前两行窄。两端对齐也无法把它们排方，因为两端对齐段落的最后一行保持自然宽度，而这里每一行都是一个独立的段落。
- 扉页和最后一页都排满到网格的最后一行。扉页上多出一行，无论来自更长的题词、一行折行还是更大的`:::space`，都会把页脚的标签及其下两行挤到单独一页；最后一页多出一行，会把版权信息的最后一行单独挤到第五页。要在这两页上加一行，就从它上方的某个`:::space`中减去一行。
- Postext不能像1633年的印刷商排*Easter Wings*那样把文字横过来排：只有整个图和表可以旋转。这里诗节是竖直排的，第4页的说明也提到了这一点。
