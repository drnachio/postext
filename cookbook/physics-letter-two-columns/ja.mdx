## できあがり

初めて重力波をとらえたと発表したレター『Observation of Gravitational Waves from a Binary Black Hole Merger』（Abbott et al., 2016）を抄録し、USレター判の2段組みで組み直した5ページです。1ページ目は証拠から始まります。HanfordとLivingstonで記録されたひずみを、重力波オープンサイエンスセンター（GWOSC）のオープンデータのファイルから描き直し、表題の下で2段にまたがって置きます。その下に共同研究の著者表記と脚注、段をまたぐ抄録、本文が続き、引用はAPSの学術誌と同じく[1,2]や[25–27]と番号で示します。チャープ質量は式(1)です。表Iは非対称な誤差を上付きと下付きを重ねて表し、セルには数式として書きます。キャプションにもレターにある数式をそのまま組みます。自分のBibTeXとデータファイルに差し替えれば、同じスクリプトであなたのレターが組めます。

## 作り方

### 1 · IEEEスタイルから物理学の番号付き引用を作る

コードは上の[手短な答え](#手短な答え)にあります。postext-citeprocにはAPSスタイルが同梱されておらず、同梱スタイルでいちばん近いのは`ieee`です。引用順の番号、角括弧、姓の前の頭文字が共通しています。`STYLES.ieee`に4か所の文字列置換を加えると差が埋まります。`collapse="citation-number"`で連続番号をまとめ（*[25–27]*）、`layout`に角括弧を1組だけ置いて*[1,2]*と印刷し、`et-al-min`を11に上げて10人の著者名を省略せずに並べ、新しい`<bibliography>`ブロックでPhysical Reviewと同じく誌名、太字の巻、ページ、年を印刷します。たとえば*Phys. Rev. Lett.* **74**, 3515 (1995)です。43件の文献は独立した`:::references{format=bibtex}`ブロックに入れます。`{{J. Aasi et al.}}`のように二重の波括弧で囲んだ名前はそのまま印刷され、レターが自分たちの共同研究の長い著者リストを引くときの書き方になります。[引用と参考文献](/ja/docs/document-format#引用と参考文献)を参照してください。

### 2 · 表題の下で2段にまたがる図1

<Excerpt region="title" />

フロートは引用した行より上には置かれず、本文が図1を初めて引用するのは第II節なので、フロートのままでは1ページ目に届きません。そこでこのレターは図を直接置きます。`::resource{id="fig1"}`を表題のすぐあとに書き、配置を`{ position: 'here', span: 'page' }`とすると、その位置で2段にまたがって組まれ、段はその下に続きます。著者表記と抄録はそのあとのページ幅の囲み`front`に入り、その中の`:::paragraphs`ブロックで著者表記を中央に揃え、日付を小さく組みます。*et al.*のあとの脚注記号は注を1段目の下へ送ります。APSの学術誌が著者に関する注を置くのと同じ位置です。`footnotes.numberFormat: 'lower-alpha'`で脚注に文字の番号を振るので、参考文献の番号と取り違えることがありません。[ブロック埋め込み](/ja/docs/document-format#ブロック埋め込み任意本文中への明示的な配置)と[脚注](/ja/docs/configuration#脚注)を参照してください。

### 3 · セルに数式が入る表I

<Excerpt region="table" />

postext 1.19からは、セルも本文と同じように`$…$`を数式として組みます。各値は`$36^{+5}_{-4}\,M_\odot$`のようにTeXで書き、2つの誤差は数値の上と下に重なり、セルの行の高さに収まるよう縮められます。Markdownの`^+5^~−4~`では2つの誤差が横に並んでしまいます。キャプションと注にも同じ数式が使えます。図2は`$R_S = 2GM/c^2$`、図4は`$5.1\sigma$`と書き、MathJaxの字形で組まれます。本文の2つの書体にないギリシャ文字もこの字形にはあり、PDFではベクトルのパスとして残ります。リソースタイプは、キャプションでは*FIG. 1*と*TABLE I*、本文では*Fig. 1*と*Table I*と印刷します。`captionPrefix`と、表には`counterFormat: 'upper-roman'`を指定しています。[数式](/ja/docs/document-format#数式)を参照してください。

### 4 · オープンデータから描いた図

<Excerpt region="palette" />

4つの図はすべてコードで描いています。データはGWOSCがこのレターとともに公開したファイルで、ライセンスはCC BY 4.0です。各曲線は8サンプルごとに1点を残し、図1の0.21秒で430点になります。各点は直前の点からの変化をbase-64の1文字で記録するので、5本の曲線がスクリプトの中で3 KB未満に収まります。残差の段は原論文と同じく、データから波形を引いたものです。どの図でもHanfordはオレンジ、Livingstonは青で、本文はページの墨色と青1色だけを使います。ラベルはMathJaxのサンセリフ（`\textsf`）のパスです。軸の指数や記号が本文の数式と同じ組み方になり、PDFでは線もラベルもすべてベクターのまま残ります。

## アレンジ

### 同梱のIEEEスタイルをそのまま使う

置換を外すと、本文は*[2], [3], [4]*、文献一覧は*A. Einstein, “title”, journal…*の形になります。

```diff
-const citations = { style: 'custom', customStyle: aps, link: true,
+const citations = { style: 'ieee', link: true,
```

### Natureのように上付き番号にする

Natureのスタイルは上付きの番号を使い、文献の表題も載せます。同梱されています。

```diff
-const citations = { style: 'custom', customStyle: aps, link: true,
+const citations = { style: 'nature', link: true,
```

### A4判で組む

仕上がり寸法を変えれば、版面、段、すべての図がそれに合わせて変わります。

```diff
-const [TRIM_W, TRIM_H, TOP, BOTTOM, SIDE, GUTTER] = [215.9, 279.4, 21, 21, 16, 7];
+const [TRIM_W, TRIM_H, TOP, BOTTOM, SIDE, GUTTER] = [210, 297, 22, 22, 15, 7];
```

## よくあるつまずき

- postext 1.18までは、2段組みの流れの中で`span: 'page'`を付けた`'here'`のリソースが1段の幅で組まれ、キャプションやセルの`$`はそのまま印刷されました。1.19以降を指定します。
- キャプションやセルに文字として打ったギリシャ文字、⊙、≃は、画面ではシステムフォントに置き換わり、PDFでは欠落します。PDFには各書体のラテン文字のファイルしか埋め込まれないためです。`$\sigma$`や`$M_\odot$`のように数式として書き、図の中では描いて示します。
- 数百人の著者リストはBibTeXファイルには向きません。学術誌に印刷されたとおりの名前を二重の波括弧で囲んで書きます。`author={{B. Abbott et al.}}`。
- 論文とデータのライセンス表記は残します。このレシピでは脚注と奥付で削った部分を示し、各キャプションの注記でデータの出典と描き直した図で省いた部分を記しています。
