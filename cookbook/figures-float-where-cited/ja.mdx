## できあがり

200 × 250 mmのページに組む地形学の教科書『Mountain Landforms』の第2章です。章扉では、章番号を入れた青いリボンが天から垂れ下がり、その横に表題の氷青色の板が置かれます。続いてFaustinaの両端そろえの2段が流れます。拡散モデルで生成した絵にコードでラベルを付けた7点の図には、初出順に番号が振られます。6点は、最初に引用した段落から数えて、配置の指定が許す最初の空いた場所へフロートします。`auto`の図2.1は章扉の下部に、図2.3は28ページの右段の先頭に、図2.2は同じページの下部に収まります。図2.4と図2.5は29ページの2つの段の先頭に入ります。図2.6は本文が埋め込んだ位置に組まれます。図2.7は30ページで引用される`top`のフロートなので31ページを待つはずですが、フロートは章の外に出られないため、30ページの下部に入ります。

## 作り方

### 1 · ページと図にひとつのパレット

<Excerpt region="palette" />

設定のどの色もこのパレットのいずれかの項目にリンクしています。絵も同じスレート、氷河の青、苔の色で生成したので、図はページの色になじみます。絵は自分の色を保ちます。`glacier`の値を変えると、リボン、板、ラベルの色は変わりますが、図の中の氷の色は変わりません。アクセントの色は小さな文字にも使える暗さです。キャプションのラベルと引用では白に対して5.2:1、キッカーでは氷青色の板に対して4.5:1です。各図は、絵をJPEGのデータURLとして埋め込み、その上に細い白の縁取り付きの文字でラベルを重ねたSVGです。こうするとラベルはくっきりと保たれ、版の言語に従います。ラベルはSVGの上でIBM Plex Sans Condensedを名指しし、キットの`loadSvg`がエンジンの`inlineSvgFonts`を通して、使われている2つのウェイトを埋め込みます。画像として表示されるSVGは、それだけではページのフォントに届かないからです。

### 2 · 図の名前を読み手の言語で

<Excerpt region="captions" />

`locale`が、組み込みの種類に文書の言語で名前を付けます。キャプションは、英語版ではFigure 2.3、スペイン語版ではFigura 2.3となります。同じ`'es'`がスペイン語のハイフネーションのパターンも選びます。各引用は、その文に必要な形をとります。`case="lower"`で（fig. 2.1）、さらに`style="full"`を加えて（figure 2.2）、複数形のあとでは`style="number"`（「figures 2.4 and 2.5」）、そして`text="…"`で、番号を印字しない「the chapter’s first figure」のような語句になります。この語句は、すでに配置された図を指し戻すためのものです。初出として使うと、やはり図に番号が振られ、配置されます。

### 3 · 章扉のリボンと氷の板

<Excerpt region="furniture" />

章扉は2つのボックスと4つの文字でできています。天から垂れ下がり下端に章番号を入れたリボン、小口の外へはみ出す氷の板、見出しの`topic`属性から取るキッカー、その下に連ねた表題とリード文です。`minHeight`は板と、その下の少なくとも5 mmを確保し、グリッドの行単位に切り上げます（ここでは約7 mm）。こうして図2.1も同じページの下部の帯に収まります。柱は小口側の隅に、`rule`の色の細罫の上に置かれ、`pages: 'body'`で章扉には付けません。章扉には代わりにページの下にノンブルを入れます。

### 4 · 未知のidと引用されない図で止める

<Excerpt region="check" />

どのリソースにもないidを指す`:ref`や`::resource`は「?」と印字され、何も配置されません。ビルドはその1件ずつを、idとソース上の位置とともに`unknownResourceId`として`doc.contentWarnings`に記録します。だれも言及しない図は配置されず、警告も出ません。そこでこのチェックは、エンジン自身のパーサーである`parseMarkdown`でMarkdownを読み、言及と図を突き合わせます。未知のid、引用されない図、`::resource`の行がない`here`の図を、ページを表示する前に1つのエラーにまとめます。

### 5 · 本の現在位置から数え始める

<Excerpt region="build" />

これは長い本の第2章なので、continuationには前に1章あることを記録します。`{h1}.{n}`で番号を振る図は2.1から、ノンブルは27から始まります。<PageRef page={2}>28ページ</PageRef>では図2.3が図2.2の上に立ちます。図2.2の番号が小さいのは、本文がそちらを先に引用しているからです。Markdownの`![]()`は取り除かれるので、図はすべてリソースで、そのSVGはビルドの前に`svg.fileId`の名前で登録します。各図の配置は引用される位置から決めます。図2.1は板が章扉の上部を埋めるので`auto`、縦断面図は引用したページの下部にまだ入れるので`bottom`、段の図は次に空いている段の先頭を占めるので`top`です。図2.7も`top`ですが、フロートは章の中にとどまるので、30ページの下部に収まります。

## アレンジ

### 章番号を付けずに図番号を振る

番号から章を外すと、図は1〜7と印字されます。本全体で1つの通し番号にするには、章を`buildBundle`で組むか、各章に前の章の`continuationAfter()`を渡します。

```diff
-  inlineSvgFonts, parseMarkdown,
+  inlineSvgFonts, parseMarkdown, defaultResourceTypes,
@@
   locale: t({ en: 'en-us', es: 'es' }),
+  resourceTypes: defaultResourceTypes(LANG).map((type) => ({ ...type,
+    numberingTemplate: '{n}', resetOn: 'never' })),
```

### キャプションを上に、帯に載せて

キャプションは図の上に移り、パレットの氷青色の帯に載ります。クレジットの行は図の下に残ります。こうするとどちらの版も5ページ目にはみ出すので、本文の分量を調整し直してください。

```diff
   captionStyle: { // the text colour follows bodyText; the note is 0.85 × the caption size
+    position: 'above', backgroundEnabled: true, background: col('ice'),
     fontFamily: LABEL, fontSize: pt(8.3), gap: mm(2.2),
```

### 図を余白に置く

段と半段のページなら、本文が入らない小口側の溝を図とキャプションに与えられます。<RecipeLink slug="textbook-margin-column">余白に段を設けた教科書</RecipeLink>を参照してください。

### 表も同じようにフロートさせる

表もリソースで、同じ規則で引用され配置されます。長い表はページをまたいで分割されます。<RecipeLink slug="technical-datasheet">技術データシート</RecipeLink>を参照してください。
