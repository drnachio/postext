## できあがり

スペインの学校向け理科実習教材『Taller de ciencias』の4ページ、「Práctica 4」の「Construye un reloj de sol」（日時計を作る）です。42ページでは安全上の注意をひとかたまりのまま保ちます。14手順の作業手順は黄色の地にコンパスのバッジを角に付け、左の段の下端から始まって右の段の頭に続きます。続きの部分は同じ行長で、題はありません。マドリードのデータシートはそのページで本文の流れを離れ、43ページの頭に本文より上に置かれます。最後のページの地には、チャコールの「Autoevaluación · 10 min」のバッジを固定し、その横の余白に指さしの手を添えます。扉では、太陽のような黄色の帯に、マドリードの緯度で正午から午後5時までの棒の影を描いた図を載せ、材料の一覧をページ幅いっぱいの3段のパネルに並べます。

## 作り方

### 1 · すべての囲みに共通の基本スタイル

<Excerpt region="look" />

どのスタイルも`box()`から始まります。等幅書体の題、本文の9.4ptに対して8.8ptの文字、そしてパディングです。そこに、それぞれ1つずつ目印を加えます。安全上の注意にはチャコールの帯、作業手順には黄色の地、データシートには紙色に近い淡い色、まとめには上罫、バッジにはチャコールの角丸の形です。生徒は題を読む前に、その目印で囲みを見分けられます。作業手順では、地の色が続きの目印にもなります。右の段の頭にある部分には題がないので、左の段の下端にある手順1から4とつなげているのは黄色だけです。

### 2 · 保つ、分ける、フロートさせる、固定する

コードは前に掲げた[手短な答え](#手短な答え)です。作業手順の高さは192mmで、1段には211mm入ります。ひとかたまりに保つと囲みは右の段の頭へ跳び、左の段の下端に43mmの空きが残ります。`keepTogether: false`を指定すると、囲みは落ちた位置から始まり、次の段、あるいは2つ目のアレンジで示すように次のページへ続きます（[`:::callout`コンテナー](/ja/docs/configuration#calloutコンテナー)）。続きの部分では題とアイコンが省かれます。インラインのアイコンだと、続きの部分ではアイコンの列を本文に返し、残りを広い幅で組むことになります。そこでコンパスは囲みの外側の角に置き、幅を取らせずに、2つの部分が同じ行長を保つようにしています。データシートの囲みの記述には`placement="top"`があるので、囲みは<PageRef page={2}>42ページ</PageRef>で本文の流れを離れ、次のページの頭に置かれます。バッジは`fixed`で、負の`offset.x`が指さしの手とその罫を外側の余白へ移すので、バッジの左端は本文にそろいます。

### 3 · 3段のパネルでページを横切る

<Excerpt region="panel" />

`span: 'page'`を指定すると、材料の囲みは両方の段にまたがります。その上の導入文は高さをそろえて切られ、本文はパネルの下で2段組みに戻ります（<PageRef page={1}>41ページ</PageRef>）。囲みの中では、`:::columns{count=3 breaks="5,9"}`が、段をそろえるのではなく各段の始まる位置を決めます。`breaks`は子ブロックを数え、リストの項目は1つで1ブロックなので、2段目と3段目は5番目と9番目のブロック、つまり太字のラベルから始まります。`columnGap`はページの段間と同じ7mmなので、パネルの段の間隔は本文の段と同じです。

```markdown
:::callout{type="material" title="Necesitarás"}
:::columns{count=3 breaks="5,9"}
**Para la esfera**

- Cartón pluma de 20 × 30 cm
- La plantilla de la esfera
- Pegamento y rotulador

**Para el gnomon y la base**
…
:::
:::
```

### 4 · 面には黄色を、長い囲みには明るい黄色を

<Excerpt region="palette" />

太陽の黄色は色の面、つまり帯とパネルにだけ使います。そこではチャコールと墨色の文字がそれぞれ7.4:1と8.6:1で読めます。白地の文字色にすると1.8:1にしかならないので、文字には使いません。作業手順には淡い黄色の`light`を使います。墨色の文字は11:1で読め、ギャラリーのサムネイルでも分かれ目が見えます。データシートには紙色に近い`tint`を使い、見開きでもう1つの地色付きの囲みである作業手順と見間違えないようにします。`main-color`はチャコールを指すので、設定で上書きしていない既定の要素はエンジンの青ではなくチャコールで印刷されます。

### 5 · 黄色の帯で扉を開く

<Excerpt region="opener" />

帯はページにアンカーした箱要素で、図は小口側の画像要素です。見出し前置き、リード文、授業の行は見出し行の属性から作られます。帯がページにアンカーされているので、扉はすでに帯の下端までの高さを確保しており、本文はその3.6mm下から始まるはずです。`minHeight: BAND - TOP + AIR`は8mmを求めます。確保した高さは次のグリッド線にスナップするので、本文は帯の8.4mm下から始まります。

## アレンジ

### 作業手順をひとかたまりに保つ

この設定をなくすと、1段に収まる作業手順はそのまま右の段の頭へ移り、左の段の下端に43mmの空きが残ります。

```diff
-  box('pasos', { keepTogether: false, background: col('light'),
+  box('pasos', { background: col('light'),
```

### データシートを地へフロートさせる

`content.es.md`で`placement="bottom"`にすると、データシートは記述のある42ページの下端に入ります。押し出された作業手順は右の段の頭から始まり、ページをまたいで分かれ、43ページの頭で終わります。

```diff
-:::callout{type="datos" placement="top" title="Hoja de datos · Madrid, 40,4° N · 3,7° O"}
+:::callout{type="datos" placement="bottom" title="Hoja de datos · Madrid, 40,4° N · 3,7° O"}
```

## よくあるつまずき

- 1段より高い囲みは、`keepTogether`の値にかかわらず分割されます。この設定が効くのは、211mmの段に入る192mmのこの作業手順のように、1段に収まる囲みだけです。
- `splitMinLines`が数えるのは、切れ目の前後それぞれにある囲み全体の行数で、切られる手順の行数ではありません。そのため、ある手順の1行だけが切り離されることもあります。この作業手順の前の本文は、切れ目が手順4と5の間に来るように調整してあります。地へフロートさせるアレンジでは、手順11の最後の1行だけが43ページの頭に来ます。分割される囲みより前の本文を直すと切れ目が動くことがあるので、直すたびに切れ目の位置を確かめてください。
- インラインのアイコンは専用の列を取り、続きの部分ではその列を返します。手順の間で切れると、囲みの残りはアイコンとその間隔の分だけ左へずれます。手順の途中で切れると、その手順の残りは広い幅で組み直され、語が二重に印刷されることがあります。角に置いたアイコンか、アイコンを載せる側面の帯を使えば、2つの部分は同じ行長を保ちます。
- `placement="top"`でフロートさせた囲みは、記述のあるページの次のページの頭に置かれます。そのため記述は、囲みを置きたいページの1つ前のページに書きます。ここでは42ページの作業手順の直前にあります。
