## できあがり

登山道の整備作業員向けの現場マニュアルの第1章『Drainage』を、B5判3ページの2段組みで組みます。本文はIBM Plex Serif、見出しと節番号はIBM Plex Sans Condensed、ラベル、ノンブル、項番号はIBM Plex Monoです。章扉では、章番号を大きな琥珀色のピルに入れ、登山道の高低断面図の上に置きます。断面図では、琥珀色の点が新しい水切りを設ける12か所を示しています。小さなピルが節1.1から1.12に番号を付け、1.10で幅が広がります。見出し1.2.1、1.5.1、1.5.2は、緑の罫線の下に字間を広げたキャピタルで組みます。レベル4から6は番号を付けず、代わりに書体を変えます（セリフのイタリック、緑のコンデンスの太字、等幅のキャピタル）。灰色のイタリックの7番目の階層は道具名を示します。安全規則は緑の追い込みの用語で始まります。中抜きの四角を付けた番号なしのチェックリストが、1.、a)、i.と番号付けしたリストと2つのタスクボックスで章を締めくくります。

## 作り方

### 1 · 番号とともに広がるピルに番号を入れる

コードは上の[手短な答え](#手短な答え)にあります。`numberingTemplate: '{1}.{2}'`は章と節のカウンターをつないで1.1から1.12にします（[レベルごとの上書き](/ja/docs/configuration#レベルごとの上書き)）。高度なデザインを持つレベルは、タイトルの前に番号を印刷しなくなるので、デザインが`{number}`を自分で置きます。ここでは番号を、塗りと角丸のある幅指定なしの`box`を持つテキスト要素に入れているので、ピルの幅は番号とそのパディングの合計になります。1.9なら10.1 mm、1.10なら12.7 mmです。`'right-of'`はタイトルをピルの右端に吊るし、行を左そろえにします。1.5の長いタイトルが番号の脇で折り返すのはそのためです（[要素の配置](/ja/docs/configuration#要素の配置)）。タイトルには`overflow: 'wrap'`も必要です。既定では、収まらないデザインテキストは省略記号で切られるからです。ピルはグリッド2行分より3 pt短く、節の見出しはどれもグリッド線から始まるので、見出しが段の頭に来ても段落の後に来ても、その3 ptがピルとその下の本文の間隔になります。

### 2 · 3番目の階層に罫線を引き、字間を広げる

<Excerpt region="ruled" />

Postext 1.4.1では見出しのレベルに`letterSpacing`がありませんが、デザインテキストにはあるので、レベル3もデザインで描きます。0.75 ptの緑の罫線、IBM Plex Monoの番号、その脇に字間を広げたタイトルです。`'{1}.{2}.{3}'`の3番目のカウンターは節ごとにリセットされるので、1.2.1も1.5.1も1で終わります。`DROP`は罫線だけを下げます。番号は罫線の`LEAD - DROP`下に置くので、`DROP`がいくつでも、番号とタイトルは見出しの上端からグリッド1行下にとどまります。罫線が上の段落より番号に近いので、見出しの一部として読めます。

### 3 · レベル4から6へ段階的に下げる

<Excerpt region="levels" />

`numberingTemplate`のないレベルは番号を印刷しないので、レベル4以下の見出しは、代わりに書体、色、大文字小文字で区別します。レベル4はセリフのイタリック、5は緑のディスプレイ書体、6はセミボールドの等幅のキャピタルです。`headings`自体に設定した行の高さと余白はすべてのレベルに及び、各見出しを上に空行1行、下には空行なしでグリッドに載せます。`headings`オブジェクトがあると章の前の既定の改ページがなくなるので、レベル1でそれを指定し直しています。

### 4 · スタイルで7番目の階層と番号なしの節を作る

<Excerpt region="styles" />

Markdownは`######`で終わり、見出しは太字とイタリックの記号を落とすので、`###### *Rock bar*`はもう1つのレベル6として印刷されます。見出しスタイル`'level7'`は道具名を、レベル6の600より軽い、ウェイト500の灰色のコンデンスのイタリックで組み、`textTransform: 'none'`で、本来なら引き継ぐはずのキャピタルを解除します。8.4 ptなので上の等幅のラベルの7.8 ptより大きいものの、それより1段下に読めます（[見出しスタイル](/ja/docs/configuration#見出しスタイル)）。`numbered: false`はチェックリストを番号の数から外すので、その後に節を置いても1.13のままです。空の`{number}`でも琥珀色のピルは塗られるので、このスタイルは専用のデザインを持ち、ピルの位置に中抜きの四角を置きます。安全規則の緑の追い込みの用語は、段落スタイルの`boldColor`から来ています。

### 5 · 深さに応じてリストの記号を変える

<Excerpt region="lists" />

深さごとに、記号、色、区切りを`levels`から取ります。チェックリストは1.、a)、i.と数え（[番号付きリストのレベル別上書き](/ja/docs/configuration#番号付きリストのレベル別上書き)）、行頭記号は緑からセージ色へ薄くなります（[箇条書きリストのレベル別上書き](/ja/docs/configuration#箇条書きリストのレベル別上書き)）。レベル1は既定の書式`'arabic'`のままです。CSSで使う語の`'decimal'`にすると、「undefined」と印刷されます。チェックリストを締めくくる2つの`- [ ]`項目は、行頭記号の代わりに`taskCheckboxChar`（既定は☐）を、第1階層の行頭記号と同じ緑で印刷します（[タスクリストの拡張](/ja/docs/configuration#タスクリストの拡張)）。上下の余白を0にしているので、リストはどれもベースライングリッドに載ったままです。

### 6 · 章を登山道の断面図で始める

<Excerpt region="opener" />

断面図は章扉の画像要素で、ページにアンカーし、ページと同じ幅にしています。ページ幅の図を天にフロートさせて1ページ目で参照すると、2ページ目の頭に置かれていたはずです（[画像要素](/ja/docs/configuration#画像要素)）。章扉では画像は高さを確保しないので、`minHeight`が、画像の6 mm以上下にある最初のグリッド線から本文を始めます。緑の上の凡例はデザインテキストです。画像として描くSVGはページのフォントを使えないからです。大きなピルは節のピルの書体と塗りを再利用し、`{number}`は`numberingTemplate: '{1}'`から章自身の番号を印刷します。

## アレンジ

### ピルから章番号を外す

テンプレートから章のカウンターを外すと、ピルは1から12になり、10で幅が広がります。レベル3は、自分のテンプレートからも`{1}`を外すまで1.5.1と印刷します。

```diff
-const h2 = { level: 2, numberingTemplate: '{1}.{2}',
+const h2 = { level: 2, numberingTemplate: '{2}',
```

### すべてのピルを同じ幅にする

1.10の幅に固定すると、各番号が同じ幅のピルの中央に置かれ、タイトルが1列にそろいます。

```diff
-  placement: at('container', 'top-left') }; // plus its padding
+  placement: { ...at('container', 'top-left'), size: { width: mm(12.7) } } };
```

## よくあるつまずき

- 7番目の階層はスタイル`level7`を付けたレベル6の見出しなので、見本の中で、直前の見出しより2レベル以上下がる見出しはありません。「The trench」「Tools for the trench」「STEEL BARS」「Rock bar」は4、5、6、6と並びます。Sandboxの警告「見出し階層の飛び」はそうした飛びを報告するので、この章では出ません。
- コロンで終わる導入の行がリストと一緒にとどまるのは、残りのスペースに最初の項目が収まる場合だけです。Postext 1.4.1ではこの規則が1行分しか確かめないので、2行の最初の項目が空き1行に出会うと、その項目だけが次の段へ移り、コロンが取り残されます。節1.2は、どちらの版でも最初の項目を1行に収めています。
