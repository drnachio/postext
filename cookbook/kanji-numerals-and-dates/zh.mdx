## 成品一览

一份町内会报《東若葉台だより》第百二十号，竖排四页，B5，右侧装订：夏季祭典的通知、八月日历、会费说明和一张捐款收据，以及町会的简史。町会是虚构的，但其中的数字都按日本编辑的习惯书写。期号、祭典的第三十二回和到场的二千四百人用十、百、千计数；年份逐位书写，如二〇二六年、一九六〇年；收据金额用大写数字（大字）壱萬弐阡，无法添笔改动；时间和日期用阿拉伯数字，22在一格内直立。列表依次为一、→（一）→イ→あ，日历排在封底。

## 做法

### 1 · 按数字所处的位置选择写法

代码见上文的[简短回答](#简短回答)。`formatNumeral`就是引擎为页码、列表和标题编号所用的计数器，示例在自己组合的数字上调用它：`japanese-informal`计数（120 → 百二十，十、百、千前不加一），`cjk-decimal`逐位书写（2026 → 二〇二六），`japanese-formal`给出金额的大写（12000 → 壱萬弐阡）。正文里的`{{daiji:12000}}`会变成收据金额，数字只需用阿拉伯数字输入一次。同样的风格也用于序号：各节是`{2:一}、`，`orderedLists.levels`依次设为（一）、`katakana-iroha`（イロハ）和带“、”的`hiragana`（あ、い、う）。`cjk.uprightDigits: 2`让8月22日和23日不加标记就直立；「雨が降ったら中止!?」中的`!?`共用一格，这是日文的默认行为（[竖排中的数字](/zh/docs/configuration#竖排中的数字)）。

### 2 · 报头做成右边缘的色带

<Excerpt region="masthead" />

在竖排页面上，文字流的“顶端”是纸张的右边缘，所以锚定在出血框顶端的标题设计就是沿这条边的色带，它的`size.height`就是它在纸上的宽度。期号和日期是用`kan()`和`pos()`拼出的设计文字，日期以`align: 'right'`止于版心底端。

### 3 · 日历单独占一页

<Excerpt region="calendar" />

在竖排页面上，表格直立摆放、横向阅读，日文书一般这样印表；它会占用所在页的全部行。日历在最后一段之后作为整页浮动体引用，于是成为封底，前面的文字照常排满各页。`resourceTypes`用记号`一`给它编号（表一），`ja`文档默认把标签排成“表一　”：标签与序号相连，后面跟一个全角空格。

### 4 · 每种字体只加载它要排的文字

<Excerpt region="voices" />

Noto Serif JP排正文；Noto Sans JP排标题、列表、日历和收据标签；Zen Maru Gothic只排报名。每种字体只加载它自己所需字符的Fontsource文件，再加上示例生成的数字。

## 变化

### 年份一律计数书写

有人在正文中更喜欢二千二十六年而不是二〇二六年；改一下`pos`的风格即可。

```diff
-const pos = (n) => formatNumeral(n, 'cjk-decimal'); // 2026 → 二〇二六: digit by digit
+const pos = (n) => formatNumeral(n, 'japanese-informal'); // 2026 → 二千二十六
```

### 三位数字也直立

设为3后，正文中的100或365也各占一格。

```diff
-  uprightDigits: 2, // 8月22日: one or two Arabic digits stand in one cell (the default)
+  uprightDigits: 3,
```

## 常见问题

- 日历单独占一页，是因为直立的表格会占用竖排页面的全部行（缺口：竖排中的表格）。表格若要与正文同页，需要横排页面，或改用由标题设计放置的SVG图。
- 同一个计数器在中文里写成一百二十、一千零一，在日文里写成百二十、千一。要写明`locale: 'ja'`，否则记号一会选用中文写法。中文读本<RecipeLink slug="chinese-dates-upright">竖排中的日期与缩略词直立</RecipeLink>用同样的`uprightDigits`排日期。
