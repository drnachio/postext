## できあがり

台湾の並製本で組んだ『三国志演義』の11ページです。毛宗崗の改訂本による第1回の全文を、右綴じの148 × 210mmのページ（25開）に、右から読む上から下への行で組みます。扉は背の左側に単独で置かれます。次の見開きでは、1592年に彫られた桃園の誓いの木版画が章の始まりと向き合い、章の始まりでは第一回とその対句が朱色の罫のあいだに立ちます。本文のページはどれも1行40字で16行を収め、各文字は自分のマスの中央に置かれます。書名は右ページの外側の余白を、章名は左ページの外側の余白を縦に下り、その下に漢数字のノンブルがあります。同じ本の構成をヨーロッパの並製本で組んだのが<RecipeLink slug="trade-paperback-novel">No. 038</RecipeLink>です。

## 作り方

### 1 · ページを4分の1回転させ、右で綴じる

コードは上の[手短な答え](#手短な答え)にあります。`layout.writingMode: 'vertical-rl'`は、各ページを、時計回りに4分の1回転させた横組みのページとしてレイアウトします。流れの1行が文字の縦の行になって右から読まれ、改行、両端そろえ、2字の字下げは行を下へ向かって働きます（[縦組み](/ja/docs/configuration-page-layout#縦組み)）。`page.binding`は`'auto'`のままにします。縦組みの本はこれで右綴じになります。1ページ目は奇数ページのままですが左ページになり、`mirror: true`でそのページの内側の余白`left`が右側に来ます（[綴じ](/ja/docs/configuration-page-layout#綴じ)）。キットの`showBook`は本を開いたとおりに見開きを並べ、1ページ目を単独で、続いて`[3 | 2]`と置きます。PDFは`/Direction /R2L`でビューアーに同じ順序を求めます。Acrobatはこれに従い、Chromeのビューアーは無視します。

[文字グリッド](/ja/docs/configuration-east-asian#文字グリッド)は、版面を縦に10.5ptの40字、横に19ptの16行とし、148.2 × 107.2mmにします。`page`の余白は最小値です。グリッドは向かい合う余白を同じだけ広げ、天を33.9mm、地を27.9mm、のどを17.4mm、小口を23.4mmにします。`locale: 'zh-Hant'`で東アジアの設定は台湾の値になります。約物はどれも全角で自分のマスの中央に置かれ、約物どうしが続いても詰めません。`trad-chinese-informal`でノンブルは一から九まで刷られ、`第{1:一}回`が章に番号を振ります（[ノンブル](/ja/docs/configuration-page-layout#ノンブル)）。

### 2 · 回目を2行で罫に挟む

<Excerpt region="opener" />

縦組みのページでは、見出しのデザインは流れの枠の中に組まれます。`x`は版面の天から行を下へ、`y`はページの右端から横へ進みます。そのため`'horizontal'`の罫は紙面では縦の線になり、長さは行と同じです。0.5ptの3本の罫が、28.5pt離れた2つの題の行を囲みます。本文の行送りの1.5倍です。どちらの行も高さ28.5ptの行で、文字はその中央、2本の罫のちょうどあいだに立ちます。`{number}`はNoto Serif TC Boldで第一回を2字下げて組み、`{titleText}`はLXGW WenKai TCで対句をその1字あとから組みます。見出しは`# 宴桃園豪傑三結義 \\ 斬黃巾英雄首立功`と書き、強制改行で後半を次の行に送って、前半と頭をそろえます。`minHeight`は19ptの行を5行分確保するので、本文はグリッドに乗って始まります（[幅と詳細デザイン](/ja/docs/configuration-text#幅と詳細デザイン)）。柱やPDFのしおりのように題を1行で読む場所では、改行は全角スペースになります。

### 3 · 柱とノンブルを小口に沿って縦に置く

<Excerpt region="fore-edge" />

台湾の縦組みの本では、柱とノンブルを外側の余白に縦に置くことがよくあります。`writingMode: 'vertical-rl'`はヘッダーの要素を紙面の上から下へ組み、`anchor.to: 'outer'`はそれを外側の余白に置きます。右綴じの本では、奇数ページの左の余白、偶数ページの右の余白です（[縦組みのテキスト要素](/ja/docs/configuration-page-layout#縦組みのテキスト要素)）。オフセットは、要素自身の8.5ptを単位とするemで表します。本文の文字サイズの約80%です。柱は版面の天から4字下で始まり、ノンブルは版面の地から5字上で終わります。`parity`は右ページに「三國演義」を、左ページに章名を置きます。`pages: 'body'`は章の最初のページから両方の柱を外しますが、ノンブルは残します。

### 4 · 口絵を章の前に置く

<Excerpt region="front" />

扉と口絵は、それぞれ専用のスタイルを持つレベル1の見出し`# 三國演義 {style="title" …}`と`# 桃園結義 {style="plate" …}`です。`numbered: false`で数に入らないので、章は第一回のままです。また、どちらも空の`header`を持ち、それが小口の柱を置き換えます。章の`breakBefore`は奇数ページを求めるので、章は3ページ目から始まり、その見開きの右側に口絵があります。読者は本文の前に絵を見ることになり、繡像本と同じ並びです（[見出しスタイル](/ja/docs/configuration-styles#見出しスタイル)）。ノンブルもこの2ページを数に入れません。中国の編集者は正文をその最初のページから数えるので、章の見出しの直前に`:::numbering{startAt=1}`の行を置き、3ページ目で一から数え直します（[`:::numbering`](/ja/docs/document-format#numbering)）。扉と口絵も奇数・偶数の判定では紙面として数えられ、ビューアーとPDFではやはり一と二のラベルが付きます（下のアレンジで別のラベルにします）。

「三國演義」は題簽の縦方向の中央に置きます。`RUN`は40ptの4字と、そのあいだの3つの10ptの空きの長さで、最後の文字のあとのトラッキングは含めません。扉のフッターは、見出しの`colophon`属性から、刊記を地に横に、この版の言語で組みます。Noto Serif TCにはイタリックがないので、刊記はSource Serif 4で組みます。`inlineMarks: true`で書名を囲むアスタリスクを読み取り、属性の中の`\n`ごとに行を改めるので、行は意味の切れ目で分かれます（[テキスト要素](/ja/docs/configuration-page-layout#テキスト要素)）。ボックスの幅は、版面の左端から題簽の中心線までの距離の2倍なので、どの行も中央が「三國演義」の真下に来ます。口絵のデザインは、木版画とその二重枠を版面の右上の角から下げ、図題をその左に2行で縦に組みます。流れの枠ではボックスの幅がページを縦に進むので、絵の`width`は紙面での高さになります。絵はCanvas、HTML、PDFで正立し、タグ付きPDFはそれを代替テキスト付きの図として読みます。

### 5 · 各書体には、それが組む文字を渡して読み込む

<Excerpt region="voices" />

この本には3つの声があります。本文にNoto Serif TC（宋）、対句と韻文にLXGW WenKai TC（楷）、小口の柱にNoto Sans TC（黑）です。Fontsourceは中国語の書体の各ウェイトを約100のファイルに分けて配信し、ファイルごとに文字の範囲を受け持たせています。`loadCjkFonts`は、渡されたテキストを含むファイルを取得します（[中国語・日本語・韓国語のフォント](/ja/docs/configuration-programmatic-usage#中国語日本語韓国語のフォント)）。本文の書体には章全体を渡し、67ファイルを取得します。楷体には見出しと韻文を渡して25ファイル、黒体は15ファイル、ボールドは4ファイルです。ボールドが組むのは7字だけで約物がないので、縦組み用の字形は読み込みません。刊記のSource Serif 4は、ほかのラテン文字の書体と同じく`loadFonts`で、ローマンとイタリックを読み込みます。`renderToPdf`は、同じファイルをサブセットとして埋め込む`cjkPdfProvider`と、木版画のための`imageBytes`を受け取ります。

## アレンジ

### ノンブルを1桁ずつ書く

`cjk-decimal`は1桁を1つの数字で書きます。この章はノンブル九で終わり、そこまでは2つの形式が一致します。本文の10ページ目からは、十と十一が一〇と一一になります。

```diff
-  pageNumbering: { format: 'trad-chinese-informal' }, // folios 一, 二 … 九, from the chapter
+  pageNumbering: { format: 'cjk-decimal' }, // folios 一, 二 … 九, 一〇, 一一
```

### 前付けのページに別のラベルを付ける

扉と口絵にはノンブルが刷られませんが、ビューアーとPDFでは本文の最初の2ページと同じく一と二のラベルが付きます。前付けにローマ数字のラベルを使い、漢数字を`:::numbering`の行に移すと、PDFはi、ii、一、二…と数えます。

```diff
-  pageNumbering: { format: 'trad-chinese-informal' }, // folios 一, 二 … 九, from the chapter
+  pageNumbering: { format: 'lower-roman' }, // i, ii: the title page and the plate
```

```diff
-:::numbering{startAt=1}
+:::numbering{format="trad-chinese-informal" startAt=1}
```

### 章を横組みにする

中国本土の慣習では、同じ種類の章を、簡体字と開明式の約物で、左綴じの横組みにします。<RecipeLink slug="chinese-novel-horizontal">28字×28行のグリッドに組む中国語の小説</RecipeLink>を参照してください。
