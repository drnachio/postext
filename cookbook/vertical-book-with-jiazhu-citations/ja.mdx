## できあがり

中国の印刷を論じた架空の本『版刻叢談』（「木版印刷をめぐる談話」）の、ある章の終わりの部分です。繁体字を使い、右から読む上から下への行で、右綴じの140×203mmの大32開の判型に組みます。章は宋版の版式を扱い、実在する5つの文献を引きます。各引用は、中国の本が何世紀にもわたって注釈を組んできた方法で組みます。夾注、つまり本文の半分の大きさの2行の注を、引用のある行の中に置くのです。行の残りに収まらない注は次の行の天へ続き、ページをまたいで続く注も1つあります。注は中国本土の参考文献の規格GB/T 7714—2015の注形式に従い、章の最後には引用した文献の番号付き一覧を置きます。英語の文献は横倒しです。同じ章の注をページの地に置くなら、<RecipeLink slug="novel-footnotes-column-foot">No. 071</RecipeLink>のように組みます。

## 作り方

### 1 · 行の中に組む注形式

コードは上の[手短な答え](#手短な答え)にあります。GB/T 7714の注形式（`china-national-standard-gb-t-7714-2015-note`）は注のスタイルで、各引用は文献名をすべて記した注になります（[引用](/ja/docs/configuration-notes-references#引用)）。注のスタイルは、既定では注をページの地に送ります。`notes: 'warichu'`にすると、各注は行の中に残り、割注として組まれます。`cjk.warichu.fontSize`、つまり本文の半分の大きさの2行で、行の中央にそろえ、右の行から読みます（[圏点と傍線、ルビ、割注](/ja/docs/configuration-east-asian#圏点と傍線ルビ割注)）。Markdownはどのスタイルでも同じで、根拠を示す語のあとに`[@su1999]`と書きます。注は引用の位置、文末の。の前に入ります。

<PageShot page={1} crop="0.48,0.17,0.16,0.7" caption="1ページ。宿白の著書への注は3行目の地で始まり、4行目の天へ続きます。どちらでも右の行が先です。" />

2行は部分ごとに埋めていきます。3行目の地には「宿白. 唐宋時期」までしか入らないので、これを3字と4字の2行に分けます。注の残りは次の行の天を、やはり2行で埋めます。2ページでは、Twitchettの注が最終行の地で始まり、読者はページをめくって続きを読みます。

### 2 · 章末の引用文献

`:::bibliography{title="本章引用書目" scope=chapter}`は、書いた位置に一覧を組み、この章が引用した文献だけを並べます（[参考文献の一覧](/ja/docs/document-format#参考文献の一覧)）。文献はBibTeXのブロックから取ります。各項目は`langid`に`chinese`か`english`を持ち、スタイルはそれを文献の言語として読みます。漢字で書かれた人名は分けずにそのまま残ります。一覧は初出の順に番号が振られ、項目の折り返しの行はラベルの下から始まります。

### 3 · 繁体字を本土の規則で

`locale: 'zh-Hant-CN'`は、北京や上海の出版社が古典の研究書を組むように、繁体字を本土の規則で組むよう求めます。読点と句点は字面の右上に置き、縦組みの本は右綴じになります。引用もこのタグに従います。繁体字の表記はzh-TWのCSLロケールを選ぶので、スタイルが補う語も繁体字になります。Noto Serif SCは繁体字を本土の字形で描くので、この版に合います。台湾の書体LXGW WenKai TCは、約物のない章題だけに使います（数字がどうなるかは[縦組みの数字](/ja/docs/configuration-east-asian#縦組みの数字)で説明しています）。

注と一覧の中では、ラテン文字の題と4桁の年は横倒しになって行に沿って縦に流れます。ラベルの1のように中国語に隣り合う短い数字は、字面の中に正立します。

### 4 · 罫に挟まれた章扉

<Excerpt region="opener" />

縦組みのページでは、見出しのデザインは流れの枠の中に組まれます。`x`は行を下へ、`y`はページの右端から横へ進むので、`'horizontal'`の罫は紙面では縦の線になります。3本の罫が、30.4pt離れた2つの行を囲みます。1行目に太い黒体の「第三章」、2行目に楷書の題が立ちます（[幅と詳細デザイン](/ja/docs/configuration-text#幅と詳細デザイン)）。章番号は見出しの`startAt=3`とテンプレート`第{1:一}章`から、ノンブルは`pageNumbering`の`trad-chinese-informal`で45から振ります。柱とノンブルは<RecipeLink slug="vertical-novel-right-bound">No. 075</RecipeLink>と同じく小口に沿って縦に入ります（[縦組みのテキスト要素](/ja/docs/configuration-page-layout#縦組みのテキスト要素)）。

## アレンジ

### 各注を括弧で囲む

夾注を本文の大きさの括弧で囲む版もあります。`cjk.warichu`は、引用を含むすべての注に括弧を付けます。

```diff
-  warichu: { fontSize: em(0.5), color: col('ink') }, // no brackets: the half size sets it off
+  warichu: { fontSize: em(0.5), color: col('ink'), open: '〔', close: '〕' },
```

### 注の代わりに行の中に番号を

亀甲括弧を使うGB/T 7714の番号形式は、行の中に〔1〕を正立させて刷り、一覧はそのまま残ります。

```diff
-  style: 'china-national-standard-gb-t-7714-2015-note',
-  notes: 'warichu', // 夾注; 'footnote' sets the same notes at the foot of the page
+  style: 'china-national-standard-gb-t-7714-2015-numeric',
+  marker: 'corner', // 〔1〕, upright in vertical text
```

## よくあるつまずき

- 注のスタイルは、2度目に引用する文献を短い形で書き、GB/T 7714の注形式はそれを「注1に同じ」の意の「同1」に縮めます。割注には番号がないので、読者は注1を探せません。この章は各文献を1度ずつしか引用していません。同じ文献を再び引くテキストでは、2度目の引用を手で書くか、2つ目のアレンジの番号形式を使います。
- スタイルは中国語の項目に、規格の刷り方どおり欧文の約物を書き込みます（`宿白. 唐宋時期的雕版印刷[M]. 北京: 文物出版社, 1999.`）。縦組みの行の中でも、これらの約物は欧文の形のままです。本文の。や，と違って、横倒しになり、1字分より狭い幅しか取りません。
- 割注の1行は本文の半分の大きさです。本文が10.5ptなら各行は5.25ptで、ページでいちばん小さな文字になります。本文を五号以上で組むか、`cjk.warichu.fontSize`を大きくします。2行はいつも1行分の幅を分け合います。
