## 成品一览

一本虚构的印刷史小书《版刻丛谈》中一章的后半部分，繁体字，自上而下竖排、自右向左换行，大32开，140 × 203 mm，右翻。这一章讲宋刻本的版式，引了五种真实存在的著作。每处引文都按中国书籍沿用了几百年的办法处理：排成夹注，也就是正文行内两行半字号的小字。一行剩下的地方放不下的夹注，接到下一行的行首继续排，其中一条还跨了页。夹注采用GB/T 7714—2015《信息与文献　参考文献著录规则》的注释体，章末附编号的本章引用书目，英文书目横倒排。同一章若把注释放到页脚，排法可参看<RecipeLink slug="novel-footnotes-column-foot">脚注排在引用它的那一栏底部</RecipeLink>。

## 做法

### 1 · 注释体，排在行内

代码就是上面的[简短回答](#简短回答)。GB/T 7714的注释体（`china-national-standard-gb-t-7714-2015-note`）把每处引文变成一条注，注里写出文献的完整著录项目（[引用](/zh/docs/configuration-notes-references#引用)）。注释体默认把注排在页脚。`notes: 'warichu'`让每条注留在原来的行里，排成夹注：两行，字号为`cjk.warichu.fontSize`，即正文的一半，在行中居中，先读右边一行（[着重号、注音与夹注](/zh/docs/configuration-east-asian#着重号注音与夹注)）。Markdown的写法和其他样式一样，`[@su1999]`跟在所依据的文字后面，夹注就排在引文的位置，在句末的“。”之前。

<PageShot page={1} crop="0.48,0.17,0.16,0.7" caption="第1页：宿白一书的夹注从第三行行末开始，接到第四行行首，两处都是先读右边一行。" />

夹注是一段一段填的。第三行行末只容得下“宿白. 唐宋時期”，于是分成三格和四格两行；其余部分在下一行行首继续，仍然分成两行。第2页上，Twitchett那条夹注从最后一行行末开始，读者翻过页才能读完。

### 2 · 章末的引用书目

`:::bibliography{title="本章引用書目" scope=chapter}`把书目排在它所在的位置，只列本章引用的文献（[参考文献表](/zh/docs/document-format#参考文献表)）。文献数据来自BibTeX块。每条文献都有`langid`字段，`chinese`或`english`，样式据此判断文献的语种；用汉字写的姓名保持完整。书目按首次引用的顺序编号，每条文献转行时从编号下方开始。

### 3 · 繁体字，按大陆规范排

`locale: 'zh-Hant-CN'`表示用繁体字、按大陆规范排版，北京、上海的出版社排古籍和文史著作多是这样：逗号、句号放在字格的右上角，竖排的书右翻。引文跟随这个标签：繁体字会选用zh-TW的CSL语言文件，所以样式添加的用语也是繁体。Noto Serif SC按大陆字形画繁体字，正合这个版本的需要；LXGW WenKai TC是台湾字形的字体，只用来排章题，章题里没有标点（数字怎样处理见[竖排中的数字](/zh/docs/configuration-east-asian#竖排中的数字)）。

在夹注和书目中，拉丁字母的书名和四位数的年份横倒排，顺着行往下走。紧挨汉字的短数字，比如编号里的1，在字格里直立。

### 4 · 朱线之间的章首

<Excerpt region="opener" />

竖排页面上的标题设计按排版流的坐标布局：`x`沿行往下，`y`从页面右边缘横向往左，所以`'horizontal'`的线在纸面上是一条竖线。三条线隔出两行，行距30.4 pt。第一行是黑体粗体的“第三章”，第二行是楷体的章题（[通栏与高级设计](/zh/docs/configuration-text#通栏与高级设计)）。章号来自标题上的`startAt=3`和模板`第{1:一}章`，页码来自`pageNumbering`：`trad-chinese-informal`，从45起。书眉和页码沿书口一侧的页边竖排，做法与<RecipeLink slug="vertical-novel-right-bound">右翻的竖排中文小说</RecipeLink>相同（[竖排文本元素](/zh/docs/configuration-page-layout#竖排文本元素)）。

## 变化

### 给夹注加括号

有些版本给夹注加上与正文同字号的括号。`cjk.warichu`为所有夹注设置括号，引文的夹注也在内。

```diff
-  warichu: { fontSize: em(0.5), color: col('ink') }, // no brackets: the half size sets it off
+  warichu: { fontSize: em(0.5), color: col('ink'), open: '〔', close: '〕' },
```

### 行内只排序号

改用GB/T 7714的顺序编码制并加六角括号，行内只印直立的〔1〕，书目不变。

```diff
-  style: 'china-national-standard-gb-t-7714-2015-note',
-  notes: 'warichu', // 夾注; 'footnote' sets the same notes at the foot of the page
+  style: 'china-national-standard-gb-t-7714-2015-numeric',
+  marker: 'corner', // 〔1〕, upright in vertical text
```

## 常见问题

- 同一文献第二次被引用时，注释体会改用简略形式，GB/T 7714注释体写成“同1”，意思是“同注1”。夹注没有编号，读者找不到注1。本章每种文献只引一次；需要再次引用的文本，第二处请手写，或者改用第二种变化里的顺序编码制。
- 样式在中文条目里用西文标点，如`宿白. 唐宋時期的雕版印刷[M]. 北京: 文物出版社, 1999.`，这是标准规定的写法。在竖排行里这些标点保持西文的样子：横倒排，占不满一格，与正文的“。”“，”不同。
- 夹注的每一行是正文字号的一半：正文10.5 pt时每行只有5.25 pt，是全页最小的字。正文宜用五号或更大，或者调大`cjk.warichu.fontSize`；两行夹注总是合占一行的宽度。
