## 成品一览

*Into the Wood*（西班牙语版《Al fondo del bosque》），二十张纸板、150毫米见方的隧道书。每个右页是一层画出来的树林（橡树、毛地黄、知更鸟、蕨丛里的狐狸、猫头鹰、白桦），每层都开一个比前一个稍小的圆窗，圆心相同。最后一层是完整的：林间空地上，母鹿和小鹿在水塘边。从封面望进去，视线穿过十九个窗直到鹿，纸板的切口像树干一样围着隧道。每张纸页背面有一行诗，说出对面那一层。交给印厂的PDF把所有窗都放在模切色版上。

## 做法

### 1 · 同一轴心上的十九个窗

代码见上方的[简短回答](#简短回答)。窗由循环生成：第k张纸页得到一个半径为R1 · Q^(k − 1)、圆心相同的圆，`dieCuts.pages`把它放在第2k − 1页，即这张纸页的右页。孔会切穿纸页两面，所以背面有同一个窗，左右镜像。Q = 0.9162让半径分十八步从58毫米降到12毫米。

### 2 · 与窗对准的分层画面

<Excerpt region="planes" />

每幅画都有自己雾蒙蒙的中空处，所以图片进书前先缩放：在每幅画上以像素量出树叶占圆环一半的半径，再把画缩放到这个半径正好落在本页的窗上。从封面看，每层只露出窗外一圈细细的树叶，层层叠成隧道。每个模切去掉的中心是纯色，几乎不占文件大小。

### 3 · Die色版上的十九个圆

<Excerpt region="die-line" />

PDF把每个窗以及切口一侧圆角的每张纸页描在叠印、从不上墨的`Die`分色上。用`convertImages: false`，四十页画面的文件不到1.5兆字节。

### 4 · 拿在手里的隧道

<Excerpt region="folio" />

二十张纸板叠成厚厚一块，Folio把每个窗都切穿：合着的书显出隧道，切口的侧壁一级级向下通到林间空地。

### 5 · 平面页上的二十层

<Excerpt region="see-through" />

`beneath`用它自己的`beneath`去画后面第二页：封面的窗露出第3页，第3页的窗露出第5页，一直到第39页。每页只画一次，之后重复使用。

## 变化

### 圆角方窗

用`roundRect`，圆角半径取半宽的三分之一，看起来像剪纸，更柔和。

```diff
-    shape: 'circle', x: mm(CX - radius(k)), y: mm(CY - radius(k)),
+    shape: 'roundRect', radius: mm(radius(k) / 3), x: mm(CX - radius(k)), y: mm(CY - radius(k)),
```

### 四角都切圆

给小手用的纸板书，每张纸页四个角都切圆。

```diff
-  corners: { radius: mm(4), edges: 'fore' },
+  corners: { radius: mm(8), edges: 'all' },
```
