## できあがり

*Into the Wood*（スペイン語版は『Al fondo del bosque』）。150ミリ角、20枚のボードでできたトンネルブックです。右ページはそれぞれ描かれた森の一層で（オーク、ジギタリス、コマドリ、シダの中のキツネ、フクロウ、シラカバ）、どれも前より少し小さな丸窓を同じ中心に抜いてあります。最後の層だけは抜かず、空き地の池にいる母ジカと子ジカです。表紙からのぞくと19の窓を通ってシカまで目が届き、ボードの切り口が木の幹のようにトンネルを囲みます。各丁の裏には、向かいの層を名指す一行の詩があります。印刷所に渡すPDFには、すべての窓が抜き型の版に載ります。

## 作り方

### 1 · 同じ軸にそろえた19の窓

コードは上の[手短な答え](#手短な答え)です。窓はループで作ります。k枚目の丁には同じ中心で半径R1 · Q^(k − 1)の円が与えられ、`dieCuts.pages`がそれを2k − 1ページ、つまりその丁の表に置きます。穴は丁の両面を抜くので、裏にも同じ窓が左右反転して開きます。Q = 0.9162で、半径は18段階で58ミリから12ミリになります。

### 2 · 窓と位置をそろえた森の層

<Excerpt region="planes" />

どの絵にも霧の空き間があるので、本に入れる前に絵を拡大縮小しました。各画像で、葉が輪の半分を覆う半径をピクセルで測り、その半径がその丁の窓に重なるよう、窓の中心に合わせて縮めています。表紙から見ると、各層は窓のまわりの細い葉の輪だけを見せ、輪が重なってトンネルになります。抜き型が取り去る中央は単色なので、ファイルはほとんど重くなりません。

### 3 · Die版の19の円

<Excerpt region="die-line" />

PDFは各窓と、小口側の角を丸めた各丁の輪郭を、オーバープリントでインキを載せない`Die`の分版に描きます。`convertImages: false`で、40ページの絵でも1.5メガバイトに収まります。

### 4 · 手の中のトンネル

<Excerpt region="folio" />

20枚のボードは厚いかたまりになり、Folioはそのすべてに窓を抜きます。閉じた本にはトンネルが現れ、切り口の壁が段になって空き地まで下りていきます。

### 5 · 平らなページで20層

<Excerpt region="see-through" />

`beneath`は2ページ先のページを、それ自身の`beneath`で描きます。表紙の窓には3ページが、その窓には5ページが見え、39ページまで続きます。各ページは一度だけ描いて使い回します。

## アレンジ

### 角の丸い四角の窓

`roundRect`で角の半径を半幅の3分の1にすると、切り絵のようなやわらかい感じになります。

```diff
-    shape: 'circle', x: mm(CX - radius(k)), y: mm(CY - radius(k)),
+    shape: 'roundRect', radius: mm(radius(k) / 3), x: mm(CX - radius(k)), y: mm(CY - radius(k)),
```

### 四隅をすべて丸める

小さな手のためのボードブックは、各丁の四隅を丸めます。

```diff
-  corners: { radius: mm(4), edges: 'fore' },
+  corners: { radius: mm(8), edges: 'all' },
```
