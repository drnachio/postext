## できあがり

エドガー・アラン・ポーの短編「赤死病の仮面」と「楕円形の肖像」を、英語版は原文で、スペイン語版はカルロス・オリベラの1884年の訳で、125 × 195 mmの並製本にします。表紙用紙も作ります。表紙の文字には座標が一つもありません。どれも何かにぶら下がったテキスト枠です。表1では、書名がゾーンの上端から下がり、副題が書名から下がり、著者名は下端に立ちます。書名はどちらの版でも2行になるので、枠が伸び、副題も一緒に下がります。表4では、紹介文が高さ50 mmの枠を埋め、入りきらない行は短編からの引用の下にある2つ目の枠へ続きます。ページの上には用紙を2回描きます。刷り上がりのままと、各枠を囲んでつながりを示したものです。

## 作り方

### 1 · どの枠もゾーンか別の枠にぶら下がる

コードは上の[手短な答え](#手短な答え)です。`anchor`は用紙のゾーンか別のテキスト枠を指し、点を一つ選びます。ゾーンなら、その点は安全領域の9つの点のどれかで、枠は自分の同じ点をそこに合わせます。`edge: 'top'`は書名を表1の中央に置き、上端を安全領域の上端にそろえます。`edge: 'bottom'`は著者名の枠の下端をゾーンの下端にそろえます。枠に対しては`below`、`above`、`right-of`、`left-of`も使えます。`x`と`y`はその点からの移動量で、単位はmmです。固定すると`rect`は大きさだけを表すので、背が厚くなっても判型が変わっても、枠は同じ位置関係を保ちます。

### 2 · 書名が伸びて副題を押し下げる

<Excerpt region="cover-type" />

書名はCinzelの30ポイント、行送り33ポイントです。枠の高さは14 mmで1行分。「The Masque of the Red Death」も「La máscara de la muerte」も2行になるので、枠は文字に合わせて`maxHeight`の40 mmまで伸びます。文字が縮むのはその高さを超えてからです。副題は書名の`below`、2 mm下に固定されているので、2行目の分だけ下がります。著者名はゾーンの下端に固定されているので動きません。

### 3 · 紹介文は別の枠へ続く

紹介文の枠には`next: 'blurb-end'`があります。入りきらない分は行の間で切れてその枠に続き、その枠は表紙のMarkdownに自分のframeを持ちません。引用は紹介文から、`blurb-end`は引用からぶら下がるので、最初の枠を高くしても3つの間隔は変わりません。2つ目の枠でも足りないときに初めて、つながった文章全体が一緒に縮みます。既定では90 %まで（`fit.minScale`）。金のスモールキャピタルの1行は紹介文のframeの最後の段落なので、2つ目の枠で文章を締めくくります。

```md
:::frame{slot="front"}
:::

:::frame{slot="blurb"}
:::paragraphs{style="cover-blurb-first"}
While a plague empties his country, Prince Prospero shuts himself up …
:::

:::paragraphs{style="cover-note"}
From the Raven Edition of Poe's works
:::
:::
```

空の`front` frameがあると、`buildCover`は本のメタデータから書名、副題、著者名を表1に組みません。ここではテキスト枠がそれを組みます。

### 4 · ページ数から背幅を出す並製本

<Excerpt region="binding" />

PUR無線綴じ、16ページ折、120 g/m²、嵩高2.2の書籍用紙。本は21ページで、綴じると32ページになり、背幅は約4.7 mmです。既定では6 mm未満の背には文字を入れないので、このバージョンは`spineText.minSpine`を4.5にし、背に書名と著者名を入れます。ISBNは見本の番号で、どの本にも割り当てられていません。

### 5 · 本文

<Excerpt region="pages" />

小扉、扉、権利表記のページ。続いて各短編が奇数ページから50 mm下げて始まり、上にCinzelの題とごく短い赤い罫が入ります。柱は偶数ページに著者名、奇数ページに短編の題。奥付が最後の奇数ページで本を閉じます。

### 6 · 組んだページから用紙を作る

<Excerpt region="sheet" />

`buildCover`はページ、メタデータ、表紙のMarkdownを受け取り、1ページだけの文書を返します。そのページが用紙です。テキスト枠はそのページのframeになり、組版ページのframeと同じように組まれます。バーコードの数字はOCR-Bを求めますが、どのフォントサーバーにもないので、Cinzelで組みます。

### 7 · 各枠の行き先

<Excerpt region="views" />

用紙のページは`page.composed.frames`にframeを持ちます。それぞれ固定と伸びのあとの矩形を持ち、文章が別のframeへ続くときは`continuesTo`もあります。2つ目の図は用紙の上で6つの枠を囲み、紹介文の枠の下端から`blurb-end`の上端までつながりを描きます。

## アレンジ

### 著者名を副題の下に下げる

著者名もゾーンの下端にとどまらず、書名と一緒に下がります。

```diff
-  { name: 'author', rect: size(100, 8), anchor: { to: 'front', edge: 'bottom', y: -6 } },
+  { name: 'author', rect: size(100, 8), anchor: { to: 'subtitle', edge: 'below', y: 6 } },
```

### 長い書名を1行に縮める

`maxHeight`がなければ書名の枠は14 mmのままで、収まるまで書名を縮めます。ここでは1行になり、元の大きさのおよそ3分の2です。

```diff
   { name: 'title', rect: size(100, 14), anchor: { to: 'front', edge: 'top', y: 8 },
-    maxHeight: 40 },
+    fit: { minScale: 0.6 } },
```

## よくあるつまずき

- 別の枠の`next`が指す枠は、その枠から渡された文章を受け取ります。表紙のMarkdownで自分のframeを与えず、文章を締めくくる内容は最初の枠のframeの最後に書きます。ここの注記の1行と同じです。
- 存在しない名前、自分自身、または輪になる相手を指すanchorは報告され、枠は`rect`の位置に置かれます。固定する枠にも、実際の大きさの`rect`を与えてください。
- `maxHeight`は回転した枠（`rotate`）には効かず、回転した枠は`rect`の大きさのままです。
