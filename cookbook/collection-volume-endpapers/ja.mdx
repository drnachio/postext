## できあがり

セルバンテスの『模範小説集』12編の11番目『偽りの結婚』を、1編を1冊の上製本にする叢書の第11巻として組みます。本文26ページは120 × 185 mmのページにCrimson Pro 11/15.2で組みます。そこから `buildCover` が製本所向けの用紙を3枚作ります。叢書のえんじ色に刷った表紙（絵のまわりに金の枠、巻数は金の輪の中）と、前後の見返しです。見返しは叢書を半分ずつ受け持ち、第1〜6巻が本の前、第7〜12巻が後ろに入り、どちらも効き紙に絵、遊び紙に番号付きの書名一覧を載せます。巻のISBNを載せたバーコードの横には、全巻のISBNが刷られます。

## 作り方

### 1 · 叢書は本のデータ

コードは上の[手短な答え](#手短な答え)です。`production.collection` に叢書の名前、ISBN、各巻のID・書名・画像を並べた `catalogue`、そしてこの本にあたる目録項目のIDを示す `volume` を持たせます。Postextがバーコードの横に刷るのは叢書の `isbn` で、バーの上に6.5ポイントの黒い1行「全巻ISBN」が本の言語で入ります。版が自前の `workIsbn` を持つときはそちらが刷られます。2つのISBNはどちらも978-84-0000ブロックの見本番号で、どの本にも割り当てられていません。設定のチェックは、目録にない `volume` と、チェックディジットの合わない叢書ISBNを報告します。

### 2 · 全巻に同じ装丁

<Excerpt region="livery" />

表紙のデザインは叢書のどの巻でも同じオブジェクトで、変わるのは `VOLUME`、絵、文字だけです。各要素は置かれたゾーンを基準に配置されるので、ページ数が多く背の厚い巻では表表紙がその面と一緒に動きます。背では `basis` が帯を描いたときの10 mmの背幅を記録し、背が8.3 mmでも14 mmでも帯は幅に合わせて伸縮し、輪は中心線に残ります。バーコードの上の行は黒で刷られるので、バーコードは淡いラベルの上に置きます。

### 3 · 見返しごとに専用のデザイン

<Excerpt region="endpapers" />

`cover.sheets` は、ある用紙に表紙のデザインに代わる専用のデザインを与えます。ここでは `endpaperFront` と `endpaperBack` で、それぞれ地色（効き紙は表紙の色）と `catalogue` 要素を持ちます。この要素はゾーンの中の箱で、エンジンが目録の `first` から `last` までの書名の画像を `columns` 列、間隔 `gap` mmで並べ、各画像がそのセルを覆います。IDが `collection.volume` と一致する巻は要素の `stroke` で囲まれ、この見返しでは第11巻の金の枠になります。用紙はそれぞれ自分のデザインしか描かないので、表紙の装丁は見返しに出ません。本の前を開くと効き紙は左ページ、後ろでは右ページなので、絵はいつも板紙の上に来ます。

書名は表紙用Markdownから取られ、このMarkdownはすべての用紙に使われます。用紙を指定した枠は、その用紙にだけ入ります。

```md
:::frame{slot="flyleaf" sheet="endpaperBack"}
:::paragraphs{style="ad-head"}
Exemplary Novels
:::

::catalogue{numbers="I" first=7 last=12}
:::
```

`::catalogue` は目録の書名に置き換わり、1巻につき1段落になります。`numbers` が指定する番号スタイルでの順番、半角幅のスペース（en space）、書名の順です。各行は段落スタイル `cover-catalogue`、この巻の行は `cover-catalogue-current` を使います。コードは両方を定義し直し、Crimson Proの中央揃えにして、この巻を濃い赤にしています。裏表紙の枠は `case jacket` を指定しているので、見返しには入りません。

### 4 · 1冊の本から3枚の用紙

<Excerpt region="sheets" />

同じ呼び出しに `sheet: 'cover'`、`'endpaperFront'`、`'endpaperBack'` を渡すと、表紙と2枚の見返しができ、それぞれ固有の寸法の1ページ文書になります。26ページは16ページの折丁2つに切り上げられ、240 µmの紙16枚。0.5 mmの余裕を加えて本文は4.3 mm、2 mmの板紙2枚を足して表紙の背は8.3 mmです。背文字のチェックは表紙の背の幅で行われ、最小値6 mmを超えています。PDFは本文26ページのあとに表紙と見返しが続きます。

## アレンジ

### 表紙にカバーを掛ける

上製本では `flaps` でカバーが加わります。自前の袖を持つ4枚目の用紙です。バーコードと全巻ISBNはその裏表紙に移り、枠に `jacket` を指定した紹介文も一緒に移ります。

```diff
   versions: [{ id: 'hardcover', name: t({ en: 'Hardcover', es: 'Tapa dura' }),
-    binding: 'case-flat', isbn: '978-84-0000-198-8', isbnAddOn: '90000' }],
+    binding: 'case-flat', isbn: '978-84-0000-198-8', isbnAddOn: '90000', flaps: true }],
```

### 次の巻を組む

第12巻ではデザインはそのままです。`VOLUME` が `collection.volume` で目録のどの項目かを決め、巻数の輪、見返しの金の枠、強調される書名がそれに従います。表紙用Markdown、絵、ISBNはその巻のものにします。

```diff
-const VOLUME = 11; // this book's place in the collection
+const VOLUME = 12; // this book's place in the collection
```

## よくあるつまずき

- キャプチャされる一覧では、用紙は本のページのあとに来ます。表紙は27ページ目、つまり本のページ数に1を足した位置です。本に1ページ増える変更をすると、用紙の位置もずれます。
- レシピ集の `contentInConfig` チェックは、`buildCover` がバーコードの上に刷る行をデザインに置いた文字と見なします。コードはそれを `checks.contentInConfig.allow` に、エンジンが使う関数 `workIsbnCaption` の文言で登録します。
- `catalogue` 要素が描くのは画像だけです。書名一覧はMarkdownの `::catalogue` なので、その行がない用紙では絵の下に書名が出ません。
- バーコードの数字はOCR-Bを指定しますが、どのフォントサーバーにもありません。コードがすでに読み込んでいる `font-family` に置き換えてバーコードを読み込まないと、PDFが失敗します。
