## できあがり

『Reciclar en el barrio』は、架空のスペインの役所が作ったA4判4ページのごみ分別ガイドです。画面で読むことも、家で印刷することも想定しています。紺の表紙には、黄色の縁石の上に5つの街頭ごみ容器が並びます。2ページ目には目次と3つの囲み、その横に環境担当議員の挨拶文を置き、3・4ページ目に2つの節を、Atkinson Hyperlegible Nextの左そろえ（行末不ぞろい）2段組みで組みます。CodePenのサンプルは、veraPDFのPDF/UA-1検査に合格するタグ付きPDFを書き出します。見出し、リスト、囲み、表が読み上げ順に並び、図には代替テキストが、2つの表には見出しセルが付きます。ファイルは題と言語（`es`）を宣言し、しおりと目次の各行はそれぞれのページにリンクします。タグは印刷されないため、サンプルはプレビューの3ページ目にタグを描き込みます。ここに載せたのがそのページで、タグ付きの各ブロックを番号付きの枠で囲み、タグ名を添えています。ダウンロードしたPDFにはこの重ね描きはありません。

## 作り方

### 1 · 文書の言語と題

<Excerpt region="identity" />

postext-pdfはタグの言語を`locale`から書き込みます。ここでは`/Lang es`となり、画面読み上げソフトはガイドをスペイン語の発音で読みます。指定がなければファイルは`en-US`を宣言します。`content.es.md`のフロントマターにある`title`と`author`はPDFの題と著者になり、ファイルはビューアーに対して、ウィンドウのタイトルバーにファイル名ではなくこの題を表示するよう求めます。同じ`locale`が、キャプションと引用にスペイン語の名前を与えます（「Figura 1.1」「tabla 1.1」）。[手短な答え](#手短な答え)で、図と表にアクセシブルなテキストを与えます。`altText`は図の代替説明（`/Alt`）と各表の`/Summary`になり、2つの表の1行目と1列目は見出しセルとしてタグ付けされます。

### 2 · ひとつのアウトラインと、題だけを載せた表紙の帯

<Excerpt region="headings" />

タグツリーのH1要素とH2要素はMarkdownの見出しから作られ、PDFのしおりも同じ一覧から作られます。そのため表紙、目次、挨拶文、2つの節はレベル1、中見出しはレベル2になります。postext-pdfは見出しのデザインに含まれるテキスト要素をすべてその見出しの一部としてタグ付けします。そこで表紙の帯には題だけを載せ、リード文と役所の名前は帯の下に段落として組みます。紺の帯、縁石、並んだ容器はデザイン要素です。PDFはデザインの箱と画像をアーティファクトとして扱うので、代替テキストは要らず、画面読み上げソフトはこれらを読み飛ばします。

### 3 · リンクする目次

<Excerpt region="contents" />

`:::toc`はH1とH2を、印刷されるページ表記とともに並べます。PDFでは11行それぞれが該当ページの先頭にリンクします。3ページ目の`:ref`による引用「figura 1.1」「tabla 1.1」と、4ページ目の「tabla 2.1」は、図と表にリンクします。ページ番号は本文の書体、Atkinson Hyperlegible Next Boldで組みます。リーダーは項目のPublic Sansではなく、ページ番号の書体になります。

### 4 · ページに描いた読み上げ順序

<Excerpt region="reading-order" />

画面読み上げソフトはタグをたどります。`renderToPdf`はまず帯の題に、続いて各段の上から下へタグを付けます。フロートは、ページのどこに描かれても、それを参照する段落のすぐ後に読まれます。この関数は同じ順序をたどり直して3ページ目の枠に番号を振ります。PDFの構造ツリーにも同じ14の要素が同じ順に並びます。図と2つの表は`placement: { position: 'here' }`と`::resource`行で本文の流れの中に置いてあるので、目で読む人も、参照する文のすぐ下でそれぞれを見つけられます。2段目へ続くガラスの段落の番号が9ひとつなのは、PDFが2つの部分をひとつの段落としてタグ付けするからです。

### 5 · コントラスト比で選んだ色

<Excerpt region="palette" />

PDF/UA-1は色を検査しませんが、WCAG 2.2は文字と背景の間に4.5:1を求めます。墨色は白地で15.6:1、紺の帯の上の白文字は12.5:1、フッターの灰色は7.0:1です。黄色は白地では1.8:1しかないため、紺の上（6.9:1）と塗りにだけ使います。ピクトグラムはWCAGがグラフィックに求める3:1に従い、容器に対してその比に届くものは白、黄色の容器だけは墨色にしています。`cell()`は各容器の名前を色見本の横に書き、リサイクルセンターには空の四角を付けます。色の見分けに頼る指示はひとつもありません。

## アレンジ

### 図をフロートさせる

placementを外すと、図1.1は3ページ目の1段目の下端へフロートします。PDFは引き続き、図を参照する段落の後でそれを読むので、重ね描きの番号は3のままで、タグの順序も変わりません。

```diff
-  { id: 'contenedores', typeId: 'figure', kind: 'svg', placement: { position: 'here' },
+  { id: 'contenedores', typeId: 'figure', kind: 'svg',
```

## よくあるつまずき

veraPDFはブラウザーの外で動くため、サンプルは自分のPDFを検証できません。ファイルをダウンロードして`verapdf -f ua1 accessible-tagged-pdf.pdf`を実行してください。このページのために取得したファイルは合格しています。代替テキストが絵を正しく説明しているかは検査ツールには判断できないので、画面読み上げソフトでガイドを聞いて確かめてください。

奥付にウェブアドレスを省略せずに印刷しているのは、このガイドをpostext 1.4.1向けに書いたからです。このバージョンではMarkdownのリンクは文字を印刷するだけで、PDFにリンクを加えませんでした。postext 1.10からは`[text](url)`のリンクがPDF上で有効になり、リンクされた語をテキストとする`Link`要素としてタグ付けされます。
