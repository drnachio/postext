## できあがり

日本の学校で使う漢文の読本、つまり古典中国語を日本語として読む教材の3ページを、右綴じのA5判に組みます。内容は『論語』の3章と、孟浩然の絶句『春暁』です。各章は15 ptのZen Old Minchoで中国語の語順のまま組み、字の横に本文の半分の大きさで朱の訓点を付けます。字の左下の返り点は、先へ読み進めてからその字に戻るよう読者に指示し、字の右の送り仮名は日本語の語尾を補います。各章の下には書き下し文、つまり同じ本文を日本語として書き改めたものを、教科書体風の書体Klee Oneで組み、読みにくい箇所にはふりがなを付けます。中国の古典に中国式の読みの補助を付けた例は<RecipeLink slug="zhuyin-vertical-reader">No. 080</RecipeLink>にあります。

## 作り方

### 1 · `:kunten`で各字に印を付ける

コードは前出の[手短な答え](#手短な答え)にあります。`:kunten[習]{kaeri="レ" okuri="フ"}`は習に返り点レと送り仮名フを付けます。本文には字そのものが残るので、検索、コピー、PDFは書かれたとおりに本文を読み、訓点は本文の字を1つも占めません（[圏点と傍線、ルビ、割注](/ja/docs/configuration-east-asian#圏点と傍線ルビ割注)）。「学ビテ而時ニ習フレ之ヲ」を読むと、習のレが読者を先に之へ送ってから戻し、「之を習ふ」となります。而には印がなく、読みません。縦組みでは返り点は字の左下に置かれて行の半字分を占め、送り仮名は字の右、字の中ほどの高さから始まります。JIS X 4051の組み方です。`cjk.kunten`で大きさ（本文の半分）と色（読者が訓点を書き入れる朱）を指定します。1つの章は15 ptの字をグリッドの2行に組み、各行の横に送り仮名のための27 ptが残ります。

### 2 · 一二点と一レ点で返って読む

数字の付いた返り点は、読者をさらに前へ戻します。「不二亦タ説バシカラ一乎」では、二の付いた不を飛ばして「亦た説ばしから」と読み、一で不へ戻って「亦た説ばしからずや」となります。「為政」では、為に付いた一レの併用記号が両方の働きをします。「可二以テ為一レ師ト矣」は「以て」「師と」（レ）「為る」と読み、それから可へ戻って（一から二へ）「以て師と為るべし」となります。漢文用の符号位置㆑㆒㆓は、それぞれが表す字として読まれるので、ほかから写した本文も訓点を保ちます。

### 3 · 長い送り仮名で次の字を送る

字より長い送り仮名は、次の字の横にはみ出しません。「花落ツルコト知ル多少」では、「ツルコト」の4つの仮名が2字分の長さを取り、知は下へ移ってそのあとから始まります。JIS X 4051の組み方です（§5.6.4）。その行は長くなり、次の改行位置もそれに合わせて動きます。

### 4 · 各章に2行分の高さのラベルを付ける

<Excerpt region="headings" />

読本の各書は、「論語」や「唐詩」という表題でページを始め、最初の書には何を収めているかを示す朱の小さな注記を添えます。各章には本文2行分の幅（2行取り）のゴシック体のラベル「学而第一」や「春暁　孟浩然」を付けるので、その下の章はグリッドに乗ったままです。書き下し文は2字下げの`:::paragraphs{style="kudashi"}`の囲みで、本文と同じ書体と大きさで組み、熟語ルビを付けます。`{君子|くん|し}`は各字にそれぞれの読みを付けるので、字のあいだで改行できます。

### 5 · 声ごとに、その文字を含むフォントを読み込む

<Excerpt region="voices" />

漢文の本文と書き下し文は別の書体で組むので、それぞれ自分の文字のためのファイルを読み込みます。章とその訓点にはZen Old Mincho（訓点の仮名は`:kunten`の属性の中にあります）、書き下し文とそのふりがなにはKlee One、ラベルにはNoto Sans JPを使います。絶句は1行に2句ずつ、あいだに全角スペースを入れて組みます。よく見かける組み方で、これで詩とその書き下し文が表題の下の1ページに収まります。

## アレンジ

### 訓点を黒で印刷する

印刷された読本は訓点を本文と同じインクで組みます。色の指定を外します。

```diff
-  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'inline' },
+  kunten: { fontSize: em(0.5), placement: 'inline' },
```

### 訓点を行間に置く

`placement: 'interlinear'`は返り点を行の中から出して、字の下半分の横の行間に置くので、章は訓点のない本文（白文）と同じ字送りを保ちます。JISは訓点を行の中に置き、こちらが既定です。

```diff
-  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'inline' },
+  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'interlinear' },
```
