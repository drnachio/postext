## 成品一览

一本日本学校汉文（漢文，kanbun）读本的三页，也就是当作日文来读的古汉语，A5页面，右侧装订：三则《论语》和孟浩然的绝句《春晓》。每段用15 pt的Zen Old Mincho按汉语原来的语序排，字旁用朱色标出训点（訓点，kunten），字号为正文的一半：字左下方的返り点（kaeriten）告诉读者先往下读、再回到这个字，字右侧的送り仮名（okurigana）补上日文的词尾。每段之下是它的書き下し文（yomikudashi），即把同一段文字写成日文，用课本手写体Klee One，难读处标振假名。带有自身阅读辅助的中文经典见<RecipeLink slug="zhuyin-vertical-reader">Nº 080</RecipeLink>。

## 做法

### 1 · 用`:kunten`标注每个字

代码见上文的[简短回答](#简短回答)。`:kunten[習]{kaeri="レ" okuri="フ"}`给習加上返り点レ和送り仮名フ；正文仍是这个字，所以检索、复制和PDF都按原文读这一段，训点不占正文的任何字符（[着重号、注音与夹注](/zh/docs/configuration#着重号注音与夹注)）。读作学ビテ而時ニ習フレ之ヲ：習上的レ让读者先读之再回来，即之を習ふ；而没有训点，不读。竖排时，返り点位于所属字的左下方，在行内占半个字；送り仮名位于右侧，从字的一半高度开始，这是JIS X 4051的排法。`cjk.kunten`设定它们的字号（正文的一半）和颜色（读者书写训点用的朱色）；一段是排在网格两行上的15 pt字，每行旁边留出27 pt给送り仮名。

### 2 · 用一二点和一レ点跳读

数字让读者往回跳得更远。在不二亦タ説バシカラ一乎中，读者跳过带二的不，读亦た説ばしから，到一处再回到上面的不：亦た説ばしからずや。在《为政》中，為上的合用记号一レ兼有两种作用：可二以テ為一レ師ト矣读作以て、師と（レ）、為る，再回到可（从一到二），即以て師と為るべし。汉文训读符号的码位㆑㆒㆓按它们所代表的字来读，所以从别处复制来的文本保留着它的训点。

### 3 · 让长的送り仮名把下一个字往后推

比所属字长的送り仮名不会伸到下一个字的旁边：在花落ツルコト知ル多少中，ツルコト四个假名占两个字的长度，知往下移，从它们之后开始，这是JIS X 4051的排法（§5.6.4）。这一行因此变长，下一个断行点随之移动。

### 4 · 每段配一个两行高的标签

<Excerpt region="headings" />

读本的每一部分以书名论语或唐诗另起一页，前者带一条朱色小字，说明其中收了什么；每段配一个黑体标签，宽两个正文行（2行取り），如学而第一或春暁　孟浩然，所以下面的段落仍在网格上。读法是一个`:::paragraphs{style="kudashi"}`围栏，低两字，用正文的字体和字号，振假名采用熟语注音：`{君子|くん|し}`给每个字各自的读音，所以一行可以在两字之间断开。

### 5 · 每种字体只加载它要排的字

<Excerpt region="voices" />

汉文原文和读法用不同的字体排，所以各自只加载自己文字所需的文件：Zen Old Mincho排原文和训点，训点的假名写在`:kunten`的属性里；Klee One排读法和它的振假名；Noto Sans JP排标签。绝句每行排两句，中间隔一个全角空格，这是常见的印法，所以诗和它的读法都能排在标题下的一页里。

## 变化

### 训点印成黑色

印刷的读本用正文的墨色印训点；去掉颜色即可。

```diff
-  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'inline' },
+  kunten: { fontSize: em(0.5), placement: 'inline' },
```

### 把训点放在行间

`placement: 'interlinear'`把返り点移出行，放到字下半部旁边的空隙里，这样段落保持白文的字距。JIS把它们排在行内，这是默认值。

```diff
-  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'inline' },
+  kunten: { fontSize: em(0.5), color: col('vermilion'), placement: 'interlinear' },
```
