### 1 · 章首页是一个设计，而不是一个标题

代码就是上面的[简短回答](#简短回答)。一级标题在正文和目录里保留自己的位置，但它由一个元素槽位绘制：眉题取自标题的一个属性，标题按固定的宽度换行，短线锚定在标题实际占用的高度下方。`minHeight` 让每个章首页的正文都下沉到同一行，不论标题有多长。

### 2 · 书眉知道自己在哪一页

<Excerpt region="running-heads" />

每个元素锚定在物理页面上，并按奇偶页筛选，所以页码总在外侧边缘，书名总在左页。`pages: 'body'` 让它们避开章首页，章首页改由页脚在底部居中放一个页码。

### 3 · 一个强调色，处处关联

<Excerpt region="palette" />

配置里的每个颜色都指向调色板中的一项，所以改动一个色样，整本书的色调随之改变；一个部分或一种标题样式也可以按 id 给某一节重新着色。把 `main-color` 指向强调色，配置没有重新声明的默认值就都跟着它走。

### 把正文排成两栏

开本更宽时可以排两栏；章首页横跨两栏，书眉留在原处。

```diff
-  layout: { layoutType: 'single' },
+  layout: { layoutType: 'double', gutterWidth: mm(6) },
```
