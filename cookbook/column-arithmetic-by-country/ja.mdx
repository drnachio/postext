## できあがり

小学4年の計算ドリルの第3単元『四則計算』を、4つの版で組みます。まず3列に並べた暗算、次にたし算・ひき算・かけ算の筆算を1マスに1けたずつ、答えを書くマスの列をつけて置き、最後にわり算と方眼紙の文章題が来ます。版ごとの違いが出るのはわり算です。英語版はわる数を ⟌ の外に書き、商を上に置きます。スペイン語版とフランス語版は、わる数をわられる数の右のかこみに入れ、商をその下に書きます。ドイツ語版は `864 : 4 =` を1行に書いて下に途中の計算を書く場所を空け、かけ算の記号には点を使います。暗算に出てくる小数点がコンマか点かも、言語に合わせて変わります。ページの上のスイッチで児童用のプリントが先生用に変わり、答えがすべてオレンジ色でそれぞれのマスに入ります。

## 作り方

### 1 · 計算を Markdown に1行ずつ書く

<Excerpt region="answer" />

`:::exercise{type="arithmetic"}` には、リストの項目ひとつにつき1問を、`- 864 ÷ 4` のようにその国の記号（`÷`、`:`、`×`、`·`）で書きます。答え、商、余りはエンジンが計算し、筆算の描き方はスタイルが決めます。マスは 7.2 mm、`arithmetic.division` は `t()` で版ごとに選びます。小数は版ごとの記号で読み（`12,75 + 8,5`）、小数点が縦にそろいます。2けたの数をかけると部分積が一行ずつ印刷され、わり算の下には、ひき算を頭の中でするスペイン版では1段につき1行、ほかの版では2行の計算欄が残ります。暗算の列はふつうの穴埋め問題で、そのリストを `:::columns{count=3}` のグループに入れると、どの `[[70]]` もほかと同じ幅のマスになります。

### 2 · プリントの見出しを組む

<Excerpt region="head" />

単元のレベル1見出しが、オレンジの帯、札、題を描きます。名前と日付の欄は見出しの属性（`nombre="Name" fecha="Date"`）から作るので、どの版にもその言語で欄の名前が入ります。

### 3 · 児童用と先生用を切り替える

<Excerpt region="live" />

`exercises.edition: 'teacher'` を指定すると、すべての答えがそれぞれの位置に `answers.color` の色（ここではアクセント色）で刷られます。暗算のマス、各答えの数字、商と余り、文章題の解答例です。ページの上のフォームは設定をその場で書き換えて組み直します。フォントは読み込み済みなので、ふつうの `buildDocument` で足ります。キャプチャでは先に両方のプリントを組むので、公開されるページは児童用、先生用の順に並びます。

## アレンジ

### 答えを逆さにして問題の下に置く

パズル本でよく見るやり方です。各問題の答えを180°回して、その下に置きます。

```diff
-  exercises: { edition: 'student' }, // the switch above the pages sets 'teacher'
+  exercises: { edition: 'student', solutions: { placement: 'inverted', layout: 'key' } },
```

### どの版でも ⟌ でわり算を書く

日本や中国の学校もこの形を使います。リストにない言語は、その言語の既定の形になります。

```diff
-    division: t({ es: 'potence', fr: 'potence', de: 'inline', en: 'bracket' }) },
+    division: 'bracket' },
```

## よくあるつまずき

- `4,8 : 0,2` のような小数でわるわり算は読み取られず、書いたとおりに印刷されます。暗算の穴埋めに入れてください。そこでは答えをテキストとして扱います。
