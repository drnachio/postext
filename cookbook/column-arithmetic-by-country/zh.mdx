## 成品一览

一本四年级计算练习册的第 3 单元《四则运算》，共四个版本。先是一排分成三栏的口算，接着是加法、减法和乘法竖式，一位数字占一格，下面留一行方格写得数，最后是除法和一道印在方格纸上的应用题。各版本的差别在除法上：英文版把除数写在 ⟌ 的外面，商写在上方；西班牙文版和法文版把除数放在被除数右边的直角框里，商写在框下；德文版把 `864 : 4 =` 写成一行，下面留出写计算步骤的地方，乘号也写成圆点。口算里的小数用逗号还是小数点，同样跟着语言走。页面上方有一个开关，能把学生版换成教师版，每个答案都用橙色印在自己的格子里。

## 做法

### 1 · 把算式写成 Markdown 里的一行

<Excerpt region="answer" />

`:::exercise{type="arithmetic"}` 里每个列表项是一道算式，比如 `- 864 ÷ 4`，运算符号用该国学校的写法（`÷`、`:`、`×`、`·`）。得数、商和余数由引擎算出，算式怎么画由样式决定：方格边长 7.2 mm，`arithmetic.division` 用 `t()` 按版本选择。小数按各版本的写法识别（`12,75 + 8,5`），小数点上下对齐；乘数是两位数时，每个部分积各占一行；除法竖式在西班牙版每步留一行（减法在心里算），其他版本每步留两行。口算那一排是普通的填空题，它的列表放在 `:::columns{count=3}` 组里，每个 `[[70]]` 都是一个和其他空格一样宽的方框。

### 2 · 排练习单的页头

<Excerpt region="head" />

单元的一级标题画出橙色色带、圆角块和标题，姓名和日期两栏取自标题的属性（`nombre="Name" fecha="Date"`），所以每个版本都用自己的语言来标注。

### 3 · 在学生版和教师版之间切换

<Excerpt region="live" />

`exercises.edition: 'teacher'` 把每个答案印在它的位置上，颜色取自 `answers.color`，这里用的是强调色：口算的方框、每道题得数的各位数字、商和余数，以及应用题的参考答案。页面上方的表单直接修改配置并重新排版；字体已经加载，所以用普通的 `buildDocument` 就够了。截图时会先把两份练习单都排好，所以发布的页面先是学生版，后是教师版。

## 变化

### 把答案倒印在题目下方

这是谜题书的老做法：每道题的答案旋转 180°，印在题目下面。

```diff
-  exercises: { edition: 'student' }, // the switch above the pages sets 'teacher'
+  exercises: { edition: 'student', solutions: { placement: 'inverted', layout: 'key' } },
```

### 所有版本都用 ⟌ 写除法

中国和日本的学校也用这种除法竖式；没有列出的语言使用它自己的默认写法。

```diff
-    division: t({ es: 'potence', fr: 'potence', de: 'inline', en: 'bracket' }) },
+    division: 'bracket' },
```

## 常见问题

- 除数是小数的除法，比如 `4,8 : 0,2`，不会被识别，会按原样印出来。请把它留在口算的填空里，那里的答案是文字。
