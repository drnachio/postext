## 成品一览

在A4上排出五页生命科学期刊论文：Jumper等人的*Highly accurate protein structure prediction with AlphaFold*，依据CC BY 4.0许可从Nature原文删节。第一页由一条蓝色色带开头，下面是标题、7.4 pt的全部34位作者（单位序号为上标）和横跨全页的粗体摘要。其下是横跨全页的图1：一幅柱状图，画的是正文引用的CASP14精度；另一幅是根据PDB描出的靶标T1049主链，AlphaFold模型画在其中，按置信度着色。正文用Nature的上标数字引用。正文以参考文献1–35结束。方法部分随后排成8.2 pt；方法部分第一次引用的文献取下一个序号，所以它自己的文献表从36开始，与期刊原版相同。

## 做法

### 1 · 两份参考文献表，一套序号

代码就是上面的[简短回答](#简短回答)。引用按首次出现的先后编号，所以续编序号不需要任何设置：在方法部分首次引用的jackhmmer得到36，而正文中已引用过的Amber力场仍然是30。两份文献表来自`:::bibliography{scope=new}`，它只列出此前任何一份文献表都没有列过的文献。脚本把同一个块放在讨论之后和方法部分之后：第一份排出1–35，第二份排出36–55，Amber不会重复出现。方法部分的标题是一个一级标题，带有自己的样式；其`bodyStyle`把这一节排成8.2 pt字号、10.8 pt行距，`breakBefore: { enabled: false }`让它留在栏内，`runningChapter: false`让书眉继续显示论文标题。排你自己的论文时，把`.bib`导出内容贴进`:::references{format=bibtex}`块，在词后紧接着写`[@key]`引用，再把`nature`换成你投稿期刊的样式。

### 2 · 容纳34位作者的标题区

<Excerpt region="title" />

作者名单是标题的一个属性，`authors="John Jumper^1,4^, Richard Evans^1,4^, …"`，用7.4 pt的Noto Sans排满整个版心宽度，34个名字占五行。`inlineMarks`把单位序号排成上标。作者单位和同等贡献的说明放在文末的*Author information*下，与Nature的做法相同，这样第一页能留出摘要和插图的位置。没有删去任何作者：只有偶数页的书眉把名单缩写为*Jumper et al.*

### 3 · 横跨全页的摘要，其下的图1

<Excerpt region="resources" />

摘要是一个`span: 'page'`、没有边框的框，正文用Noto Sans半粗体。图1紧接其后，写作`::resource{id="fig1"}`，它的位置设置`{ position: 'here', span: 'page' }`让它在这一处横跨两栏；双栏正文从图注下方开始。图注以一句粗体开头，和Nature的图注一样；资源类型的`captionPrefix`和图注样式的`labelSeparator`让标签读作*Fig. 1 |*。表1用`position: 'here'`嵌在方法部分中它所在的位置，宽度限于所在的栏。

### 4 · 用公开坐标画出的蛋白质主链

<Excerpt region="art" />

坐标只在编写这份配方时读取了一次，来自PDB条目6Y4F（CC0）和AlphaFold Database中同一蛋白质的模型（CC BY 4.0），按Cα原子叠合，并转到实验结构的主轴上。脚本把它们保存在三个短数组里。每条轨迹是一串穿过Cα位置的贝塞尔曲线段，从最远的画到最近的，每段带一圈纸色描边，不用明暗也能看出前后。模型的颜色是AlphaFold Database使用的pLDDT分段，从其文件的B因子列读出。

### 5 · PDF中的希腊字母和带变音符号的字母

Fontsource把每款字体按文字系统拆分成多个文件。`kitFonts(FONTS)`读取传给它的文本：排到Ž或Š时加载每款字体的latin-ext文件，排到α或χ时加载希腊字母文件；`fontsourceProvider`根据每款字体所排的字符，把同样的文件嵌入PDF。Cα、χ、Žídek和Šali不需要另写代码：配方只需传入包含全部内容块的markdown和工具包的字体提供函数。

## 变化

### 方法部分用正文字号

有些期刊的方法部分与正文同一字号；去掉这一节的正文样式，保留标题即可。

```diff
-  bodyStyle: { fontSize: pt(8.2), lineHeight: pt(SMALL) } };
+};
```

### 序号放在方括号里

同一领域的有些期刊把[1]排在行内。

```diff
-  style: 'nature', // raised 1–4, "Nature 577, 706–710 (2020)." entries
+  style: 'nature', marker: 'brackets',
```

### 文末只排一份文献表

有些期刊把全部参考文献排在方法部分之后，例如*Science*，这时只保留第二个块。

```diff
-const markdown = [/* @content */ '', references, /* @content:methods */ '', references,
+const markdown = [/* @content */ '', /* @content:methods */ '', references,
```

### 改用温哥华格式的文献表

投医学期刊时，可以从内置的NLM样式开始，做法见<RecipeLink slug="medical-article-vancouver">温哥华格式的医学论文</RecipeLink>。

## 常见问题

- Nature最多列出五位作者，更长的名单只留第一作者，后接*et al.*。原文献表这样处理的条目，在BibTeX里写`and others`（`{Senior, Andrew W. and others}`），样式就会印出*Senior, A. W. et al.*；在CSL-YAML中，以`"others"`结束名单。
- 标题样式的`bodyStyle`改变正文的字号和行距，但不改变基线网格：方法部分的小标题用了`snapToGrid: false`，否则每个小标题下的那一行会跳到正文网格的下一行。
