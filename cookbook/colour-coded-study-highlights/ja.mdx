## できあがり

学校向けの歴史読本『Readings in Early Modern History』のある単元の「読み物2」です。1450年から1550年にかけて印刷術がマインツからヨーロッパへ広がった経緯を、170 × 240 mmのページ4枚で扱います。編集者は熱心な生徒のように本文に印を付けていて、その色の約束は本全体で変わりません。用語は緑の帯、年代は琥珀色、人物と場所は淡い青の上に載ります。タイトルの下の凡例はその3色そのものを使って約束を説明し、最後のページの用語集は各項目を緑の用語で始めます。印はふつうの文字の下に敷いた帯なので、改行もハイフネーションも両端揃えも、帯がないときと同じです。

## 作り方

### 1 · 語の種類ごとにひとつのスタイル

コードは上の[手短な答え](#手短な答え)にあります。`markStyles`で名前付きのスタイルを3つ宣言し、本文の各ハイライトがそのひとつを選びます。`:mark[Johann Fust]{style="name"}`、`:mark[1455]{style="date"}`、`:mark[colophon]{style="term"}`のように書きます（[ハイライト](/ja/docs/document-format-inline#ハイライト)）。各スタイルは意味を表すので（`name`は編集時に見える名前）、Markdownにはその語に印を付けた理由が残り、何色かは残りません。スタイルの色を変えれば、本のすべての年代がいっしょに変わります。帯の端は角のままで、postext 1.52からこれが既定です（[ハイライトのスタイル](/ja/docs/configuration-styles#ハイライトのスタイル)）。蛍光ペンの線は端が角張っていて、角を丸めた帯はチップに見えてしまいます。

### 2 · パレットの3つの淡い色

<Excerpt region="palette" />

3本の帯は、文字色やアクセント色と同じくパレットの項目です。Sandboxでこの本を開いた人は、色見本をひとつ変えるだけで約束の色を変えられます。色は囲みの地色に近い明るさまで淡くしてあり、上の文字は12.6:1以上のコントラストを保ちます。3色が1行の中で隣り合っても見分けられます。3ページの「In 1517 Martin Luther」がその例です。ハイライトは場所を取りません。`paddingX`は語句の横の空白へ0.12 em伸び、`paddingBottom`は帯をディセンダーの下まで下ろします。どちらも、もともとある空きに塗られます。

### 3 · 扉：タイトルの上の絵

<Excerpt region="opener" />

レベル1の見出しはデザインを印刷します。絵はページに固定してあるので、上と左右の端まで裁ち落としになり、大きさは170 × 96 mm、`fit: 'cover'`で収めます。見出しラベルとリード文は見出し行の属性から取り（[見出しの属性](/ja/docs/document-format#見出しの属性)）、凡例はふつうの`:::callout`で、そのリストの各項目が3つのハイライトで始まります。`minHeight`が扉の深さを決めるので、タイトルが長くても短くても凡例は同じ行から始まります。

### 4 · 偶数・奇数ページで分ける柱

<Excerpt region="running-heads" />

偶数ページにはシリーズ名、奇数ページには読み物のタイトルを入れます。どちらも`parity`で振り分け、`pages: 'body'`で扉には出しません（[テキスト要素](/ja/docs/configuration-headers-footers#テキスト要素)）。扉のノンブルは下に置きます。

## アレンジ

### 帯の端を丸める

文字サイズの5分の1の半径にすると、フェルトペンのような柔らかい端になります。

```diff
-  // borderRadius: 0 is the default (square ends, as a highlighter pen leaves them)
+  borderRadius: em(0.2), // soft ends, as a felt-tip pen leaves them
```

### 行ごとに帯を完結させる

`decorationBreak: 'clone'`にすると、行をまたぐハイライトは各行の部分の両端に余白が付きます。3ページで「pamphlets」が「pam-」のあとで分かれている箇所がその例です。

```diff
   paddingX: em(0.12), // the band reaches a little past the first and the last letter
+  decorationBreak: 'clone', // each line piece gets a whole band
```

## よくあるつまずき

- 色だけの区別は白黒コピーで消えます。そして多くの読み物は、コピーされて教室に届きます。この用語集では用語を太字にもしています。読者がページをコピーするなら、3種類のうちひとつに色以外の目印も付けてください。
- `markStyles`で宣言していないスタイルidは最初のスタイルになり、ページ上にはエラーが出ません（Sandboxは指摘します）。idは短くし、本文での綴りを確かめてください。
