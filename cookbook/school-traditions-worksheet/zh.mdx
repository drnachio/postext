## 成品一览

四年级科学与数学课程的第 7 张练习单《水的旅行》，排成十个版本。各语言的题目都一样：选一个答案，判断对错，用词语库里的词填空，把词语和意思连起来，圈出一个词，把水箱里的水平均分，说说为什么要节约用水。每个版本都照本国学校的样子印。西班牙文版和加泰罗尼亚文版把题号放在圆圈里，判断题标 V 或 F，除法把除数放在被除数右边的 L 形里。法文版用方块题号、*cases à cocher* 方框和点线空格，作答处是 Seyès 格纸。德文版写 *R* 和 *F*，填空题叫 *Lückentext*，`864 : 4 =` 写成一行，乘号用点。巴西版要在句子前面的括号里写 V 或 F。英文版在 ⟌ 下面做除法。中文版的大题用一、二、编号，每个题干后面有（　），A. B. C. 排成一行，判断题打 √ 或 ×，最后一题是“看拼音，写词语”，每个词两个田字格。日文版用ア イ ウ和○ ×，阿拉伯文版从右往左排，用 أ ب ج 和 صح 或 خطأ。

## 做法

### 1 · 把每种传统写进一张表

<Excerpt region="answer" />

所有版本的 Markdown 都一样：七个 `:::exercise` 块，答案就写在文字里（`- [x]`、`[[水蒸气]]`、`- 蒸发 -> 水变成水蒸气`、`- 864 ÷ 4`）。各国课本不同的地方在于形式，所以形式只放在这张表里：题号的形状和数字写法，选项的字母，学生是勾方框还是圈字母，判断题的样子，空格的样子，书写区，还有除法竖式的排法。加泰罗尼亚文版原样沿用西班牙文版那一行。

### 2 · 把传统铺在本社样式上

<Excerpt region="style" />

练习样式只有一个，叫 `ficha`，它带着十张练习单共有的东西（题号的蓝色、灰色的线、练习之间的空白），各版本的那一行再铺在它上面。表里没写的，由语言决定：T F、V F、R F、√ ×、○ × 和 صح خطأ 都是引擎自带的词，a) b) c)、A. B. C.、ア イ ウ 和 أ ب ج 也是，所以哪个版本都不用自己写。

### 3 · 给每种文字配字体

<Excerpt region="faces" />

拉丁字母的各版共用 Nunito 和 Baloo 2。中文版正文用宋体，题目要求用黑体；日文版正文用教科书体 Klee One，题目要求用一款黑体（ゴシック）；阿拉伯文版用 Noto Naskh Arabic。Klee One 最粗的字重是 600，所以日文版把粗体设成 600（`boldFontWeight`）：如果用 700，浏览器会自己画出加粗效果，页面捕获就会失败。

### 4 · 在练习单顶部留出写姓名的横线

<Excerpt region="head" />

一级标题画出色带、取自 frontmatter 的课程名和标题，还有两个带横线的栏目，栏目里的字取自标题的属性（`nombre="姓名" fecha="日期"`）。所以德文版写着 *Datum*，日文版写着“名前”，代码里却没有一个字符串。

## 变化

### 印教师版

每个答案都用品红色印在自己的位置上：括号、方框、空格和商。

```diff
   exerciseStyles: [ficha],
+  exercises: { edition: 'teacher' },
```

### 把答案集中到练习单底部

`placement: 'after'` 把每道题的答案排在题目下面；`'inverted'` 把答案倒过来印，就像谜题页那样。

```diff
+  exercises: { solutions: { placement: 'inverted', layout: 'key' } },
```

## 常见问题

- 字体如果没有 700 的字重，题干编号的粗体就是合成出来的。给这种正文字体设一个 `boldFontWeight`，用它实际带有的字重。
- 日文题目要求里的○和中文题目要求里的√只有 CJK 字体里才有：把它们放在 CJK 正文的句子里，不要放进拉丁字母的标签。
