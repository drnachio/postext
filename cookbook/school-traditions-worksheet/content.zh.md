# 水的旅行 {nombre="姓名" fecha="日期"}

地球上的水一直在流动。太阳晒热大海，水升到天空，又变成雨或雪落回地面。这段旅行叫作水循环。

:::exercise
选择题。（把正确答案的字母填在括号里）

1. 从云里落下来的水叫作
   - [ ] 水蒸气
   - [x] 雨
   - [ ] 雾
2. 太阳晒热大海时，海水会
   - [x] 蒸发
   - [ ] 结冰
   - [ ] 下沉
:::

:::exercise{type="truefalse"}
判断题。（对的打“√”，错的打“×”）

- [x] 云是由许多小水滴组成的。
- [ ] 天气变冷时，冰会融化。
- [x] 河流把水送回大海。
- [ ] 雨水是咸的，因为它来自大海。
:::

:::exercise{bank}
选词填空。

::bank[冰 | 风]

太阳晒热[[大海]]，海水变成[[水蒸气]]升上天空。水蒸气遇冷，聚成[[云]]。最后，水又变成[[雨]]或雪落下来。
:::

:::exercise
连一连。

- 蒸发 -> 水变成水蒸气
- 凝结 -> 水蒸气变成小水滴
- 降水 -> 水从云里落下
- 下渗 -> 水渗进土里
:::

:::exercise
圈出正确的词语。

1. 雪是[[液态 | (固态)]]的水。
2. [[(晴天) | 阴天]]的时候，水坑干得更快。
3. 地球上的水大部分是[[淡水 | (咸水)]]。
:::

:::
