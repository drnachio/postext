## できあがり

小学4年の理科と算数の講座から、プリント7「水のたび」を10の版で組みます。問題はどの言語でも同じです。答えを選び、正しいかどうかを答え、語群のことばで穴をうめ、ことばと意味を線で結び、ことばを丸で囲み、水そうの水を分け、水を節約するわけを書きます。各版は、その国の学校のやり方で印刷します。スペイン語版とカタルーニャ語版は番号を丸に入れ、V か F に印をつけさせ、わる数をわられる数の右の L 字の中に置いてわり算をします。フランス語版は四角の番号、*cases à cocher*、点線の空らん、答えを書く Seyès の紙を使います。ドイツ語版は *R* と *F*、*Lückentext*、1行で書く `864 : 4 =`、点で書くかけ算です。ブラジル版は文の前のかっこに V か F を書かせます。英語版は ⟌ の下でわり算をします。中国語版は大問を「一、二、」と数え、問題文のあとに（　）を置いて A. B. C. を横に並べ、√ か × を書かせ、最後は一語に二マスの田字格に書く「看拼音，写词语」です。日本語版はア イ ウと○×を使い、アラビア語版は右から左へ進んで、أ ب ج と صح か خطأ を使います。

## 作り方

### 1 · 国ごとの流儀を表にまとめる

<Excerpt region="answer" />

どの版も Markdown は同じです。7つの `:::exercise` があり、答えは本文に書いてあります（`- [x]`、`[[水じょう気]]`、`- じょう発 -> 水が水じょう気になる`、`- 864 ÷ 4`）。国によって違うのは形なので、形はこの表にだけ置きます。番号の形と数字、選択肢の記号、子どもがわくに印をつけるか記号を丸で囲むか、○×の見た目、空らんの見た目、書く場所、わり算の筆算の並べ方です。カタルーニャ語版はスペイン語版の行をそのまま使います。

### 2 · 共通のスタイルに国の流儀を重ねる

<Excerpt region="style" />

問題スタイルは `ficha` ひとつだけです。10枚に共通するもの（番号の青、灰色の罫線、問題と問題のあいだのあき）をこのスタイルが持ち、その上に版ごとの行を重ねます。行に書いていないことは言語が決めます。T F、V F、R F、√ ×、○ ×、صح خطأ はエンジンがもともと持っていることばで、a) b) c)、A. B. C.、ア イ ウ、أ ب ج も同じなので、どの版も自分では書きません。

### 3 · 文字ごとに書体を決める

<Excerpt region="faces" />

ラテン文字の版は Nunito と Baloo 2 を共有します。中国語版は本文を宋体、問題文を黒体で組みます。日本語版は本文を教科書体の Klee One、問題文をゴシック体で組み、アラビア語版は Noto Naskh Arabic を使います。Klee One のいちばん太いウェイトは 600 なので、日本語版は太字を 600 にします（`boldFontWeight`）。700 にするとブラウザーが太字を描き足し、キャプチャーが失敗します。

### 4 · プリントの頭に名前を書く線を置く

<Excerpt region="head" />

レベル1の見出しが、帯、frontmatter から取った講座名、題、線のついた2つの欄を描きます。欄のことばは見出しの属性から取ります（`nombre="名前" fecha="日付"`）。そのため、コードに文字列をひとつも書かなくても、ドイツ語版には *Datum*、日本語版には「名前」と出ます。

## アレンジ

### 先生用の答え入りを印刷する

答えはすべて、マゼンタでそれぞれの場所に入ります。かっこ、わく、空らん、わり算の商です。

```diff
   exerciseStyles: [ficha],
+  exercises: { edition: 'teacher' },
```

### 答えをプリントの下にまとめる

`placement: 'after'` は各問題の答えをその下に置きます。`'inverted'` はパズルのページのように、答えを上下さかさまにします。

```diff
+  exercises: { solutions: { placement: 'inverted', layout: 'key' } },
```

## よくあるつまずき

- 700 のウェイトがない書体では、問題番号の太字が合成されたものになります。そのような本文の書体には、実際にあるウェイトを `boldFontWeight` で指定します。
- 日本語の問題文の○と中国語の問題文の√は、CJK の書体にしかありません。ラテン文字のラベルではなく、CJK の本文の文の中に置きます。
