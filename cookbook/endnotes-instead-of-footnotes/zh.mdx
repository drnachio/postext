## 成品一览

这是Michael Faraday《*The Chemical History of a Candle*》的第一讲，排成一本小开本普及本，页面尺寸为156 × 234 mm。讲座以一片烟灰色区域开篇，一支点燃的蜡烛立在它的下缘，这是一张由扩散模型生成的照片，黑色背景与烟灰色区域相融；正文用Libre Bodoni排成一栏，两端对齐。在一般书里放脚注的地方，深橙色的小号上标数字把读者引向讲座末尾。注释单独成页，页首是一条烟灰色色带，里面的蜡烛已经熄灭；注释用8.2 pt分两栏齐左排出，每个粗体编号悬挂在缩进里。六条注释中有三条出自William Crookes，取自他1861年版本的1908年重印本；另外三条是新写的，署名*Ed.*。两栏结束在同一行，版权信息排在第二栏末尾。

## 做法

### 1 · 在排版之前把脚注改成尾注

预处理程序就是上面的[简短回答](#简短回答)。Postext自己就能排`[^1]`注释（[脚注](/zh/docs/document-format#脚注)），位置在引用它的栏底，或者设`placement: 'chapterEnd'`时，放在本章最后一个块之后。无论哪种方式，注释都留在本章的栏里，用正文字体，排在一条短线下。这个版本要给注释一个标题、一条色带和一个双栏页面，而标题样式只能作用于写在Markdown里的标题。所以pen在调用`buildDocument`之前改写Markdown，引擎根本不会看到`[^1]`。它按正文首次引用的顺序给标记编号，并按这个顺序把所有定义放在第一个定义所在的位置，排在`## Notes`之下。每条注释以`**1**`开头，因为`1. `会开始一个编号列表。每个标记以一个词连接符（U+2060）开头；没有它，`*Royal George*`之后那个标记的`**`会与斜体的闭合星号连成`***`，星号就会印出来。

### 2 · 把粗体留给标记

<Excerpt region="markers" />

预处理程序把每个标记写成`**^n^**`。插入符号把数字设为正文字号的58 %，并上移其三分之一（[行内格式](/zh/docs/document-format#行内格式)）；粗体则让它取`bodyText.boldColor`，这个颜色空着没用，因为Faraday从不用粗体。5.8 pt的数字需要与纸面达到4.5:1的对比度，而火焰橙只有2.6:1，所以标记改用更深的余烬色。<PageRef page={3}>第17页</PageRef>上的引用`[Fig. 1]`印成同一种颜色，但用正体，因为`referenceColor`默认取粗体颜色，而`referenceBold: false`去掉了粗体。

### 3 · 注释用小一号的字，编号放在悬挂缩进里

<Excerpt region="notes" />

注释为8.2 pt，行距10.7 pt，约为正文字号的五分之四。字体加载后，pen用Libre Bodoni测量这一样式的`hangingIndent`：一个粗体5加一个半角空格共1.12 em，所以每条注释的第一个词与其转行对齐（[段落样式](/zh/docs/configuration#段落样式)）。编号放到悬挂缩进里之后，注释之间就不需要空行。注释齐左排，因为两端对齐会拉宽那个半角空格，而在55 mm的栏里两端对齐8.2 pt的字会排得很松。波浪号设下标，就像插入符号设上标一样，例如注释4中的`C~25~H~52~`和注释5中的`H~2~O`。

### 4 · 给注释一个双栏页面

<Excerpt region="section" />

标题`## Notes {style="notes" …}`开始一个部分，这一部分的页面采用该样式的版式和版面设计。`parity: 'any'`让它从下一页开始，不论奇偶；`span: 'page'`让色带横跨两栏，一直伸到裁切边，第二栏从色带下方开始（[标题样式](/zh/docs/configuration#标题样式)）。预留高度由色带决定，但离开色带后的第一条网格线距烟灰色区域只有3 mm，所以`BAND_GAP`给`minHeight`加上5 mm，注释从低一行的位置开始。栏间细线是样式自身`layout`里的`columnRule`，所以只有注释的页面会画出它。各栏齐底默认开启，它会裁切末页，让两栏结束在同一行（[各栏齐底](/zh/docs/configuration#各栏齐底)）。

### 5 · 讲座以一片烟灰色区域开篇

<Excerpt region="opener" />

这片区域是一个锚定在页面上的框，蜡烛是一个装着JPEG的图像元素，立在框的下缘。讲座只有一栏，留在栏内的版面设计照样画在各元素锚定的位置，所以这片区域从裁切边起，越过天头和左右页边。眉题、副标题和作者署名来自标题行`# A Candle {kicker="Lecture I" subtitle="…" byline="…"}`，所以第二讲不需要新代码。这片区域延伸到标题下方，因此由它决定预留高度。标题默认的0.5 em下外边距加在上面，正文从离开烟灰色区域后的第一行再往下一个网格行开始。副标题宽86 mm，这样它只在破折号后折行，不会在破折号前折行。

### 6 · 烟灰上用火焰橙，纸上用余烬色

<Excerpt region="palette" />

火焰橙在烟灰色上的对比度为6:1，在纸上只有2.6:1。它用于深色色带上的眉题和Figure 1；纸上所有用橙色印的小字（标记、注释编号、图的标签）都改用更深的余烬色，对比度为5.1:1。`main-color`指向余烬色，所以配置里没有重新设定的默认值会跟随设计，而不会印成蓝色。

<Note>简短的附言可以用括号留在正文里。读者需要在行旁看到的注解可以放在侧栏里，参见<RecipeLink slug="textbook-margin-column">带边注栏的教科书</RecipeLink>。</Note>

## 变化

### 让Postext排注释

去掉`endnotes()`和`## Notes`标题，在各条定义之间加空行（引擎把一条定义读到下一个空行为止），并在配置里加上`footnotes: { placement: 'chapterEnd' }`。引擎会给标记编号，把注释排在讲座末尾、版权信息之后，仍在那一栏里；<RecipeLink slug="novel-footnotes-column-foot">排在引用栏底部的脚注</RecipeLink>讲的是如何设置引擎所排注释的样式。

### 用墨色印标记

如果正文自己用粗体表示强调，就把标记印成墨色，因为`boldColor`会同时给标记和每个粗体词上色。

```diff
-const markers = { boldColor: col('ember'), // **^n^**：上标，为正文字号的58 %
+const markers = { boldColor: col('ink'), // **^n^**：上标，为正文字号的58 %
```

### 让注释各栏不齐底

关闭末页的各栏齐底，第一栏会先排满到栏底，第二栏才开始。

```diff
-  headings: { fontFamily: DISPLAY, color: col('ink'), levels: [
+  headings: { fontFamily: DISPLAY, color: col('ink'), balancing: { trailing: false }, levels: [
```
