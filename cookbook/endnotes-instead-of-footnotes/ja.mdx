## できあがり

マイケル・ファラデーの『ロウソクの科学』（The Chemical History of a Candle）の第1講を、156 × 234 mmのページに小さな読者向けの版として組みます。講演は煤の色の地で始まり、その下端に火の灯ったろうそくが立っています。拡散モデルで生成した写真で、黒が煤の色とそろっています。本文はLibre Bodoniの両端そろえの1段です。本なら脚注を置くところに、濃いオレンジの小さな上付き数字があり、読者を講演の最後へ導きます。注は独立したページに続きます。ろうそくが吹き消された煤の色の帯の下に、8.2 ptの行末不ぞろいの2段で組まれ、ボールドの番号が字下げの中にぶら下がります。6つの注のうち3つは、ウィリアム・クルックスによる1861年の版の1908年の刷りからとったものです。残りの3つは新しく書いたもので、「*Ed.*」の署名があります。2つの段は同じ行で終わり、2段目は奥付で閉じます。

## 作り方

### 1 · ビルドの前に脚注を後注に変える

プリプロセッサーは上の[手短な答え](#手短な答え)にあります。Postextは`[^1]`の注を自分で組みます（[脚注](/ja/docs/document-format#脚注)）。置き場所は引用した段の下、または`placement: 'chapterEnd'`なら章の最後のブロックのあとです。どちらの場合も注は章の段の中にとどまり、本文の書体で、短い罫の下に組まれます。この版では注に見出し、帯、2段組みのページを与えますが、見出しスタイルがそれを行えるのはMarkdownに書かれた見出しだけです。そこでCodePenのサンプルは`buildDocument`を呼ぶ前にMarkdownを書き換え、エンジンが`[^1]`を目にすることはありません。プリプロセッサーは本文で最初に引用された順に合印へ番号を振り、すべての定義をその順で、最初の定義があった位置の`## Notes`の下にまとめます。`1. `と書くと番号付きリストが始まってしまうので、各注は`**1**`で始めます。各合印の先頭には単語結合子（U+2060）を置きます。これがないと、`*Royal George*`のあとの合印の`**`がイタリックの閉じのアスタリスクとつながって`***`になり、アスタリスクが印字されてしまいます。

### 2 · ボールドを合印専用にする

<Excerpt region="markers" />

プリプロセッサーは各合印を`**^n^**`と書きます。キャレットは数字を本文サイズの58 %にし、その3分の1だけ上げます（[インライン書式](/ja/docs/document-format#インライン書式)）。ボールドにすると`bodyText.boldColor`の色が付きます。ファラデーはボールドを使わないので、この色を合印に回せます。5.8 ptの数字には用紙に対して4.5:1のコントラストが必要ですが、炎の色は2.6:1しかないので、合印にはもっと暗い熾火の色を使います。<PageRef page={3}>17ページ</PageRef>の参照`[Fig. 1]`も同じ色のローマン体で印字されます。`referenceColor`の既定値はボールドの色で、`referenceBold: false`でボールドを外しているためです。

### 3 · 注は小さく、番号はぶら下げに

<Excerpt region="notes" />

注は8.2 pt、行送り10.7 ptで、本文サイズのおよそ5分の4です。CodePenのサンプルは、フォントの読み込みが済んでから、スタイルの`hangingIndent`をLibre Bodoniで測ります。ボールドの5とエンスペースで1.12 emになり、各注の最初の語が折り返し行の頭とそろいます（[段落スタイル](/ja/docs/configuration#段落スタイル)）。番号をぶら下げに出しておけば、注と注のあいだにあきは要りません。行末不ぞろいで組むのは、両端そろえにするとそのエンスペースが伸び、8.2 ptで幅55 mmの段を両端そろえにすると行がゆるくなるからです。キャレットが上付きを作るように、チルダは下付きを作ります。注4の`C~25~H~52~`や注5の`H~2~O`がその例です。

### 4 · 注に2段組みのページを与える

<Excerpt region="section" />

見出し`## Notes {style="notes" …}`が始める節のページには、そのスタイルのレイアウトとデザインが適用されます。`parity: 'any'`で節は奇偶を問わず次のページから始まり、`span: 'page'`で帯が両方の段にまたがるので、帯は仕上がりの端まで届き、2段目はその下から始まります（[見出しスタイル](/ja/docs/configuration#見出しスタイル)）。見出しが確保する高さは帯で決まりますが、帯にかからない最初のグリッド線は煤の色の地のわずか3 mm下にあるので、`BAND_GAP`で`minHeight`に5 mmを足し、注を1行下から始めています。段間の細罫はスタイル自身の`layout`にある`columnRule`なので、注のページだけに引かれます。段末そろえは初期設定で有効で、最後のページを切り分けて2つの段を同じ行で終わらせます（[段末そろえ](/ja/docs/configuration#段末そろえ)）。

### 5 · 講演を煤の色の地で始める

<Excerpt region="opener" />

地はページに固定したボックスで、その下端に、JPEGを収めた画像要素のろうそくが立っています。講演は1段組みです。段の中に置いたデザインも、各要素を固定した位置に描かれるので、地は仕上がりの端から始まり、天と左右の余白にかかります。キッカー、副題、署名は見出しの行`# A Candle {kicker="Lecture I" subtitle="…" byline="…"}`から取るので、第2講を組むときに新しいコードは要りません。地は見出しより下まで届くので、見出しが確保する高さは地で決まります。そこに見出しの既定の下余白0.5 emが加わり、本文は煤の色にかからない最初の行の1グリッド行下から始まります。副題の幅を86 mmにしてあるのは、ダッシュの前ではなく、あとで改行させるためです。

### 6 · 煤の上には炎の色、紙の上には熾火の色

<Excerpt region="palette" />

炎のオレンジは、煤の色の上では6:1のコントラストがありますが、用紙の上では2.6:1しかありません。そこで炎の色は暗い帯の上のキッカーと図1に使います。用紙の上にオレンジで印字する小さなもの（合印、注の番号、図のラベル）には、5.1:1のもっと暗い熾火の色を使います。`main-color`が熾火の色を指しているので、設定で指定し直していない既定値も青で印字されず、デザインに従います。

<Note>短い補足なら、本文中にかっこで入れておけます。読者が行の横に置いておきたい注釈は、<RecipeLink slug="textbook-margin-column">余白に段を設けた教科書</RecipeLink>のようにサイド段に置けます。</Note>

## アレンジ

### 注をPostextに組ませる

`endnotes()`と`## Notes`の見出しを外し、定義のあいだに空行を入れ（エンジンは次の空行までを1つの定義として読みます）、設定に`footnotes: { placement: 'chapterEnd' }`を加えます。エンジンが合印に番号を振り、注を講演の最後、奥付のあとに、1段のまま組みます。エンジンが組む注のスタイルは、<RecipeLink slug="novel-footnotes-column-foot">引用した段の地に置く脚注</RecipeLink>で扱っています。

### 合印を墨で印字する

本文が自分の強調にボールドを使うなら、合印は墨で印字します。`boldColor`は合印にもボールドのすべての語にも同じ色を付けるからです。

```diff
-const markers = { boldColor: col('ember'), // **^n^**: a superscript at 58 % of the text size
+const markers = { boldColor: col('ink'), // **^n^**: a superscript at 58 % of the text size
```

### 注の段をそろえずに流す

最後のページの段末そろえを切ると、1段目が下端まで埋まってから2段目が始まります。

```diff
-  headings: { fontFamily: DISPLAY, color: col('ink'), levels: [
+  headings: { fontFamily: DISPLAY, color: col('ink'), balancing: { trailing: false }, levels: [
```
