## 成品一览

一本虚构的日文排版手册《組版の言葉》（排版的用语）中的一章及其索引。这一章讲版面各部分、字号和标点规则的名称，排在A5页面上，每行36字，每页28行；每个术语在讲解它的地方加索引标记。索引是这里的主题：日文汉字没有字母顺序，所以索引按每个条目的假名读音，照五十音（gojūon）表的顺序排列，归入あ行、か行、さ行等行标题之下。带振假名的术语自己就给出了读音；其他含汉字的术语在`yomi`属性里写出读音。<RecipeLink slug="chinese-name-index">中文人名索引</RecipeLink>则按拼音和笔画给中文人名排序。

## 做法

### 1 · 每个含汉字的术语都要有读音

代码就是上面的[简短回答](#简短回答)。在正文里，`:index[{版面|はん|めん}]{main}`印出带有はんめん注音的版面，并按はんめん归档；`:index[明朝体]{yomi="みんちょうたい" main}`不印读音，按みんちょうたい归档。假名术语如ノンブル、のど，以及拉丁字母术语如DTP、JIS X 4051，都不需要读音（[索引标记](/zh/docs/document-format#索引标记)）。读音只决定排列顺序，条目照原文印出。汉字的读音没法推断，天在这里读てん，在别的词里读あめ，所以引擎从不去猜。

### 2 · JIS顺序和行标题

`locale: 'ja'`时，`'auto'`选的就是`groupBy: 'gojuon'`。条目按JIS X 4061排序：片假名按平假名排，小写假名按大写排，浊音紧跟在清音之后，ー按它前面的元音排。所以級（きゅう）排在行取り（ぎょうどり）之前，ゴシック体（ごしっくたい）排在小口（こぐち）之后。拉丁字母术语按JIS的规定排在最前面，归入各自的字母之下；符号和数字还会排在它们之前（[索引](/zh/docs/configuration#索引)）。

### 3 · →和も見よ

“见”条是带`see`的标记，`:index{term="振り仮名" yomi="ふりがな" see="ルビ"}`，印出振り仮名　→ルビ。“参见”用`seealso`，把目标词放在も見よ之前，印作級　10　→歯も見よ，这是日文索引的写法。`see: { italic: false }`让这些标签保持正体，因为日文字体没有斜体。每个术语后面的全角空格和页码之间的、来自`separator`和`locatorSeparator`。

### 4 · 双栏的索引

<Excerpt region="opener" />

索引标题用的标题样式设了`span: 'page'`和双栏的`layout`：它的设计，一条带标题的浅色色带，横跨整页，`:::index`在下方分两栏排。行标题用朱红色黑体，条目用正文的明朝体，8.5 pt，行距14 pt。

## 变化

### 按首个假名分组

`'kana'`用条目的第一个假名作组标题，词典和较长的人名索引都这样做：分成か、き、く几组，而不是一个か行。

```diff
-  groupBy: 'gojuon', // what 'auto' picks in a 'ja' document: heads あ行 か行 さ行 …
+  groupBy: 'kana', // heads か き く け こ…
```

### 正文不标振假名也能给出读音

想让术语第一次出现时不带注音，又要给出读音，就把读音移到`yomi`里。

```diff
-ページのうち、本文が組まれる範囲を:index[{版面|はん|めん}]{main}という。
+ページのうち、本文が組まれる範囲を:index[版面]{yomi="はんめん" main}という。
```

## 常见问题

- 含汉字而没有读音的术语会引发`indexReadingMissing`。去掉`yomi`后，明朝体落到了索引末尾，排在わ行之后，没有组标题，构建时还警告这个条目“有汉字而没有读音”。
- 写在`:index[…]`里的`:ruby[…]`必须给方括号加转义，因为标记在第一个`]`处结束；请用简写形式`{版面|はん|めん}`。
- 注音读音只有覆盖术语中的每个汉字时才算数：`:index[行{取|ど}り]`没给行注音，会报警告。`{行取|ぎょう|ど}り`给出ぎょうどり。
