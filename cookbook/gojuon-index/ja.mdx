## できあがり

架空の日本語組版の手引き『組版の言葉』の1章と、その索引です。章はページの各部の名前、文字サイズの名前、約物の規則を説明し、A5判、36字×28行のページに組みます。各用語は、説明している箇所で索引用にマークします。主役は索引です。日本語の漢字にはアルファベット順のような並びがないので、索引は各項目をかなの読みで、五十音表の順に、あ行、か行、さ行といった行見出しの下へ並べます。振り仮名の付いた用語はそれ自体が読みを示し、それ以外の漢字を含む用語は`yomi`属性で読みを書きます。<RecipeLink slug="chinese-name-index">中国人名の索引</RecipeLink>では、中国の人名をピンインと画数で並べます。

## 作り方

### 1 · 漢字を含む用語にはかならず読みを

コードは前の[手短な答え](#手短な答え)にあります。本文の`:index[{版面|はん|めん}]{main}`は、版面の上にはんめんを付けて刷り、項目をはんめんとして分類します。`:index[明朝体]{yomi="みんちょうたい" main}`は読みを刷らず、みんちょうたいとして分類します。ノンブルやのどのようなかなの用語と、DTPやJIS X 4051のようなラテン文字の用語には何も要りません（[索引マーク](/ja/docs/document-format#索引マーク)）。読みが決めるのは並び順だけで、項目は書いたとおりに刷られます。天はここではてんですが、別の文脈ではあめと読むように、漢字の読みは推測できません。そのためエンジンは推測を試みません。

### 2 · JISの順と行見出し

`groupBy: 'gojuon'`は、`locale: 'ja'`で`'auto'`が選ぶ値です。項目はJIS X 4061の順に並びます。カタカナはひらがなとして、小書きのかなは並のかなとして扱い、濁音のかなは清音のすぐあとに置き、ーは直前の母音とみなします。そのため級（きゅう）は行取り（ぎょうどり）の前に、ゴシック体（ごしっくたい）は小口（こぐち）のあとに来ます。ラテン文字の用語はJISの順どおり先頭に来て、それぞれの文字の見出しの下に並びます。記号と数字はさらにその前に来ます（[索引](/ja/docs/configuration-notes-references#索引)）。

### 3 · →と「も見よ」

「見よ」参照は`see`を持つマークで、`:index{term="振り仮名" yomi="ふりがな" see="ルビ"}`と書き、「振り仮名　→ルビ」と刷ります。「も見よ」参照は`seealso`を使い、日本語の索引の書き方どおり、参照先を「も見よ」の前に置いて「級　10　→歯も見よ」と刷ります。日本語の書体にはイタリックがないので、`see: { italic: false }`でラベルを立体のままにします。各用語のあとの全角スペースと、ページの間の「、」は、`separator`と`locatorSeparator`で決まります。

### 4 · 2段にわたる索引

<Excerpt region="opener" />

索引の見出しは、`span: 'page'`と2段の`layout`を持つ見出しスタイルです。そのデザイン（題名を載せた淡い帯）はページ幅にまたがり、その下で`:::index`が2段に流れます。行見出しは朱色のゴシック、項目は本文の明朝で、8.5 ptの文字を14 ptの行送りで組みます。

## アレンジ

### 先頭のかなで見出しを立てる

`'kana'`は、辞書や長い人名索引のように、各グループの見出しに項目の先頭のかなを使います。か行ひとつの代わりに、か、き、くと見出しを立てます。

```diff
-  groupBy: 'gojuon', // what 'auto' picks in a 'ja' document: heads あ行 か行 さ行 …
+  groupBy: 'kana', // heads か き く け こ…
```

### 本文で振り仮名を付けずに読みを与える

用語の初出には読みを付けず、それでも読みを与えるには、読みを`yomi`に移します。

```diff
-ページのうち、本文が組まれる範囲を:index[{版面|はん|めん}]{main}という。
+ページのうち、本文が組まれる範囲を:index[版面]{yomi="はんめん" main}という。
```

## よくあるつまずき

- 漢字を含み、読みのない用語は`indexReadingMissing`を出します。`yomi`がないと、明朝体は見出しのないまま索引の末尾、わ行のあとに落ち、組版時に、その項目は「has a kanji and no reading」という警告が出ました。
- `:index[…]`の中の`:ruby[…]`は角かっこをエスケープする必要があります。マークは最初の`]`で終わるからです。簡潔な形、`{版面|はん|めん}`で書いてください。
- ルビの読みが使われるのは、用語のすべての漢字を覆っているときだけです。`:index[行{取|ど}り]`では行の読みが欠けて警告が出ます。`{行取|ぎょう|ど}り`ならぎょうどりになります。
