## What you'll build

The first chapter of *The Porthcove Light*: a title page and two comic pages, laid out once and exported four ways. The PDF is for print. The fixed-layout EPUB keeps the printed pages and carries region-based navigation, so a reading system can show the book one panel at a time, zooming from the arrival panel to the radio, then to Maya. A second fixed EPUB adds Kindle Panel View; the reflowable one sets each panel as its cropped picture followed by its lines. The page lists each file as a reader will open it, with a download link, in six languages.

## Method

### 1 · Export the same document as EPUB

The code is [the short answer](#the-short-answer) above. `renderToEpub` takes the documents `renderToPdf` prints, so the EPUB's pages are the PDF's ([comics output](/en/docs/comics#comics-output)). With `layout: 'fixed'` and comic pages in the book, it also writes `regions.xhtml`: one `panel` region per panel in reading order, each a rectangle in percent of its page, with its balloons, captions and sound effects as regions inside it. The page progression follows the comics' reading direction, so the Japanese and Arabic editions turn right to left. `kindlePanelView: true` adds a tap target per panel and a magnified copy, with the metadata Kindle expects. The reflowable rendition has no pages to keep: each panel is its picture, cropped as on the page, then its lines, "**Maya**: Biscuit! Where's Grandpa?", with the names from `comics.cast`.

### 2 · Embed the faces the pages set

<Excerpt region="embed" />

A fixed-layout EPUB draws its text in the faces it carries, and a face left out is set in the reader's own. The lettering asks for regular, bold and italic; the comic faces ship fewer, so each request gets the file `loadComicFonts` chose for it, and a file that serves both weights goes in once with the range `'400 700'`. Japanese and Chinese faces take only the slices that hold the edition's characters, which keeps the Japanese book at 1.4 MB.

### 3 · Read each file back

<Excerpt region="shelf" />

`readEpub` opens the bytes as a reading system would: layout, page progression, spine. The list under each card is the guided view itself, read from `regions.xhtml`: five panels and their text regions, in the order a reader steps through them. The three files pass EPUBCheck 5.4 with no errors or warnings in English, Japanese and Arabic.

### 4 · One layout, six editions

<Excerpt region="editions" />

Each `content.<lang>.md` holds the words of one edition under the same speaker ids. The panel regions are the same in every language; the balloon regions move with the balloons, which are lettered again around each language's text.

## Variations

### Leave out the Kindle edition

Region-based navigation is written in every fixed EPUB; Kindle Panel View only adds to it.

```diff
-  kindle: await renderToEpub(doc, { ...book, layout: 'fixed', kindlePanelView: true }),
```

### Give the reflowable book a cover

```diff
-  reflowable: await renderToEpub(doc, { ...book, layout: 'reflowable' }),
+  reflowable: await renderToEpub(doc, { ...book, layout: 'reflowable',
+    cover: { bytes: imageBytes('lh-beam.jpg'), mediaType: 'image/jpeg' } }),
```

## Pitfalls

- A face embedded once per weight it serves would be copied four times; the Chinese edition weighed 5.3 MB before the weight ranges.
