## できあがり

『ポースコーヴの灯』の第一話です。扉と漫画2ページを一度だけ組み、4通りに書き出します。PDFは印刷用。固定レイアウトのEPUBは印刷ページをそのまま保ち、リージョンナビゲーションを持つので、読書アプリは灯台に着くコマからラジオ、そしてマヤへと、一コマずつ拡大して見せられます。二つ目の固定EPUBにはKindle Panel Viewを加え、リフロー版は各コマを切り抜いた絵とそのせりふで組みます。ページには、読書アプリで開いたときの各ファイルの中身とダウンロードのリンクを並べます。六言語で出ます。

## 作り方

### 1 · 同じ文書をEPUBに書き出す

コードは前の[手短な答え](#手短な答え)にあります。`renderToEpub`は`renderToPdf`が印刷する文書を受け取るので、EPUBのページはPDFのページと同じです（[漫画の出力](/ja/docs/comics#漫画の出力)）。`layout: 'fixed'`で本に漫画のページがあると、`regions.xhtml`も書きます。読む順にコマごとの`panel`領域があり、それぞれページに対する百分率の矩形で、中に吹き出し、ナレーション、描き文字の領域が入れ子になります。ページ送りの向きは漫画の読む方向に従うので、アラビア語版は右から左へめくります。`kindlePanelView: true`は、コマごとのタップ領域と拡大したコピー、Kindleが求めるメタデータを加えます。リフロー版には保つべきページがないので、各コマはページと同じに切り抜いた絵と、その後のせりふ「**マヤ**：ビスケット！　おじいちゃんは？」になります。名前は`comics.cast`から取ります。

### 2 · ページが使う書体を埋め込む

<Excerpt region="embed" />

固定レイアウトのEPUBは、自分が持っている書体で文字を描きます。足りない書体は読書アプリの書体に置き換わります。写植はレギュラー、ボールド、イタリックを求めますが、漫画用の書体はそれより少ない数しかないので、それぞれ`loadComicFonts`が選んだファイルを使い、二つのウエイトに使うファイルは`'400 700'`という範囲で一度だけ入れます。日本語と中国語の書体は、その版が使う文字を含む分割ファイルだけを入れるので、日本語版は1.4 MBに収まります。

### 3 · 各ファイルを読み戻す

<Excerpt region="shelf" />

`readEpub`は読書アプリと同じようにバイト列を開きます。レイアウト、ページ送りの向き、スパインです。各カードのリストは`regions.xhtml`から読んだガイドビューそのもので、五つのコマとその文字の領域が、読者がたどる順に並びます。三つのファイルは英語、日本語、アラビア語でEPUBCheck 5.4をエラーも警告もなく通ります。

### 4 · 一つのレイアウトで六つの版

<Excerpt region="editions" />

`content.<lang>.md`には、同じ話者IDで一つの版の言葉を書きます。コマの領域はどの言語でも同じで、吹き出しの領域は、各言語の文字に合わせて写植し直された吹き出しとともに動きます。

## アレンジ

### Kindle版を省く

リージョンナビゲーションはどの固定EPUBにも書かれます。Kindle Panel Viewはそれに加わるだけです。

```diff
-  kindle: await renderToEpub(doc, { ...book, layout: 'fixed', kindlePanelView: true }),
```

### リフロー版に表紙を付ける

```diff
-  reflowable: await renderToEpub(doc, { ...book, layout: 'reflowable' }),
+  reflowable: await renderToEpub(doc, { ...book, layout: 'reflowable',
+    cover: { bytes: imageBytes('lh-beam.jpg'), mediaType: 'image/jpeg' } }),
```

## よくあるつまずき

- 同じファイルをウエイトごとに埋め込むと4回コピーされます。ウエイトの範囲を使う前は、中国語版が5.3 MBありました。
