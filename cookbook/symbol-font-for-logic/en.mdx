## What you'll build

The first chapter of a pocket primer of logic, on a 155 × 235 mm page: a claret band with the chapter's signs set large, then four sections that read ∀, ∃, ∈, ∪, ∅ and ℵ aloud, with the formulas in the running text and displayed between paragraphs. The book is set in Crimson Pro, its headings in Cormorant Garamond and its labels in IBM Plex Sans Condensed. Not one of the three has ∀, ∈ or a Greek letter in the files Fontsource serves. One setting, `symbolFont`, lists Noto Sans Math after each of them, so every sign comes from the same face in the body, the headings, the running heads and the table cells, and the PDF prints them all.

## Method

### 1 · One symbol font behind every face

The code of this step is the short answer above. `symbolFont: 'Noto Sans Math'` ([symbol font](/en/docs/configuration-fonts-colors-viewers#symbol-font)) puts the family after every family the config names, so a character the face lacks is drawn from Noto Sans Math at the face's size and colour, and the rest of the line stays in the face. Fontsource serves Noto Sans Math whole in its file called `latin`, 3,033 characters, but the kit declares that file for the Latin range only, and the browser would then not ask it for ∀. The pen's `resolve` and `pdfFonts` hand the same file over with no range, on screen and to `renderToPdf`. Only the characters a face lacks change face: Crimson Pro has ¬, so the negation in the text stays in Crimson Pro.

### 2 · A first build without it shows what is missing

<Excerpt region="without" />

The first build leaves `symbolFont` empty and prints its `glyphFallbackAt` warnings, one for each paragraph, heading or table that sets characters its face has no glyph for, with the page and the characters. The English edition reports eighteen: fourteen paragraphs in Crimson Pro, three headings in Cormorant Garamond and the header row of Table 1.1 in IBM Plex Sans Condensed bold. Without a family that draws them, the canvas takes the signs from a font of the reader's system and the PDF prints an empty box for each. The second build, with the symbol font, is the one on the page; its warnings name `"Noto Sans Math"` as the family that draws them.

### 3 · The signs on the opener are text

<Excerpt region="opener" />

The line of seven signs under the title is a design text in Cormorant Garamond at 30 pt, fed by the heading's `signs` attribute. Cormorant Garamond has none of them, so all seven come from the symbol font, in the band's white. The tracking of 9 pt spreads them across the measure.

### 4 · Table cells and running heads take the same face

<Excerpt region="tables" />

The truth table is built from the connectives themselves: each column header is the formula, and each cell is what the formula gives for that row. The header cells are IBM Plex Sans Condensed bold italic and the body cells Crimson Pro; the symbol font serves both. Its one regular face draws for every weight and slant, so ∧ in the bold header and ∈ in an italic formula are the same upright sign. The recto running head prints the section in force, `{firstMark.h2}`, and *SETS: ∈, ∪, ∩ AND ∅* on page 3 takes its signs from Noto Sans Math as well.

## Pitfalls

- A face whose Fontsource files include Greek (Source Serif 4, Alegreya) sets φ and Γ itself, and the kit loads that file when the text has Greek: only the signs go to the symbol font then. Crimson Pro has no Greek file, so its Greek comes from Noto Sans Math.
- The symbol font has one upright regular face. A bold heading or an italic formula sets its signs in that face, which is how mathematics prints them.
