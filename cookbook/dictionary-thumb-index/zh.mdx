## 成品一览

这是Smyth海军上将《*Sailor’s Word-Book*》（1867）新版中的四页，收A到C三个字母，页面尺寸为150 × 200 mm。词条排成两栏两端对齐的8 pt Alegreya，栏间有一条细线；每个词头为藏青色粗体，每条的转行悬挂缩进1 em。一个字母在栏内开始，用一个四行高的藏青色首字母加一道黄铜色细线标出，词条接着排下去，不另起一页。每一页的书口都印着完整的书边索引，共22个浅色标签。当前字母的标签为藏青色，比其他标签宽3.2 mm，每换一个字母就下移一格。西班牙文版保留Smyth的英文词头，翻译了释义。

## 做法

### 1 · 给每个字母一种带自己标签的标题样式

代码就是上面的[简短回答](#简短回答)。`TABS`列出22个标签，少见的字母合用一个（QR、UV、XYZ）。每个标签高两行正文（7.34 mm），加起来正好填满版心的44行。循环为每个字母生成一种标题样式，其`header`在书眉和浅色索引之外，加上该字母的藏青色标签，位置比上一个低一格（[标题样式](/zh/docs/configuration#标题样式)）。每个单元格写两次，每种`parity`一次，并且锚定到页面外侧边缘，而不是页眉自身的容器。那个容器是上页边距区域，宽度与版心相同，从裁切边延伸到正文，而标签需要伸到书口，并且纵贯全部44行。一页采用最后一个在该页开始的部分的页眉，所以<PageRef page={2}>第2页</PageRef>从A开始，却显示B的标签。

### 2 · 第一页不印书眉

<Excerpt region="running-heads" />

书眉是锚定在页面上的文本元素，用`parity`和`pages: 'body'`筛选（[文本元素](/zh/docs/configuration#文本元素)）。第1页的书名横跨两栏，使第1页成为章首页。书眉会跳过它，它的页码来自页脚：一个设为`pages: 'opener'`的元素，印在版心下方6 mm处。在右页上，`{chapterTitle}`印出该页或此前最后一个一级标题的字母，即*Letter C*。从postext 1.5.0起，`{firstMark.<key>}`和`{lastMark.<key>}`可以印出一页的第一个和最后一个词头，也就是大多数词典都有的书眉词；本食谱是用1.4.1排的，保留了字母。

### 3 · 只给词头上色

<Excerpt region="entries" />

每个词条是`:::paragraphs{style="entry"}`块中的一个段落，转行悬挂缩进1 em（[段落样式](/zh/docs/configuration#段落样式)）。正文的`boldColor`让第1页上的**Note.**保持墨色，词条样式的`boldColor`把词头印成藏青色。段落样式没有`italicColor`，所以斜体的子词条保持正文的墨色。

### 4 · 在栏内放一个四行下沉的首字母

<Excerpt region="letter-heads" />

`LETTER`为55.8 pt：在这个字号下，Alegreya SC 900的大写字母（高0.652 em）立在第四条基线上，顶端正好到达第一行正文的大写字母高度线。字母和黄铜色细线在第五行之内结束，标题块向下对齐到下一条网格线，所以每个字母标题占五行，下面的词条仍在网格上。在<PageRef page={3}>第3页</PageRef>上，第二栏顶部的C与第一栏的前四行平齐。一级标题设置`breakBefore: { enabled: false }`，各字母样式继承这一设置。在1.4.1中，只要有`headings`对象，一级标题前就已经不分页；把这个值明确写出来，即使以后的版本恢复了分页，字母也会继续接排。

### 5 · 让书名横跨两栏

<Excerpt region="title" />

书名样式横跨整页，是一条色带，里面有锚、书名、从标题属性读取的副标题和作者署名，以及一道双线（[通栏与高级版面设计](/zh/docs/configuration#通栏与高级设计)）。细线结束在版心顶部下方45.1 mm处，所以色带对齐到13个网格行，即47.7 mm。在通栏标题下，栏间线仍从版心顶部开始，会穿过书名。一个纸色的框把色带一直盖到细线，栏间线只在它下方显示。`{titleText}`用空格连接隐藏标题折行后的各行，而1.4.1按栏宽为通栏标题折行。按默认的H1字号，色带上印出的是*Word- Book*，所以书名样式把隐藏标题设为正文字号，这样书名能在60 mm的栏宽里排成一行。

## 变化

### 只印当前标签

印刷的书边索引通常只显示当前字母的标签；从页眉中去掉`ladder`，藏青色标签仍会从A到C逐级下移。

```diff
-  header: { elements: [...runningHeads, ...ladder,
+  header: { elements: [...runningHeads,
```

## 常见问题

- 在postext 1.4.1中，通栏标题下的栏间线从版心顶部开始，即使色带的高度是整数个网格行（本例正是如此）。用一个页面底色的框，画在版面设计的其他元素之下，就能把它盖住。
- 60 mm的栏约容纳50个字符，而Smyth的英文不能改写。在截图中，218行两端对齐的英文里有18行（8 %）的词间距被拉到正常宽度的1.7倍以上，西班牙文版不到2 %，因为译文是按栏宽调整过的。在把排得最差的五个词条（*Aground*、*Aloft*、*Belay*、*Cockpit*、*Crow’s nest*）换成别的之前，英文版的这个比例是17 %。要么挑选排得好的词条，要么加宽栏。
