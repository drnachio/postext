## 成品一览

这是Solan群岛地图集的第一张图页。这个群岛是为本食谱虚构的，所有地图都用代码从同一个高程场画出。第1页以一条深海蓝的横带开篇，上面是56 pt的地图集名称和一个罗盘玫瑰；Map 1是整个岛群的地形图，占满页面下部。第2页两栏的栏首是主岛北端图和港口平面图。第3页上的海图转了四分之一圈，让8 km见方的格网铺满整页。第4页是地名表，十七个地点印在红色圆点里，并注明各自在海图上的方格，页脚是出版信息。每幅地图的题注都印在图上方的蓝色横条上，Map 1的图例是一行用地图本身颜色做的色块。

## 做法

### 1 · 页面和地图共用一套调色板

<Excerpt region="palette" />

六种地图色调和页面的颜色是同一个对象里的键，所以`colorPalette`把它们都列为调色板条目，图中的SVG填色取自`palette[id]`。`band`是章首横带、题注横条和表头行的蓝色，纸白色文字压在上面的对比度为9.2:1；`road`是唯一的红色，只用于道路、灯标和地点编号，与纸色的对比度为5.4:1。`main-color`取`band`的色值，而默认设置把标题、题注横条和列表符号都链接到这个id，所以配置里没有另行指定颜色的这些元素都印成地图集的蓝色。

### 2 · 每幅地图放在哪里

代码见上文的[简短回答](#简短回答)。Map 1是`bottom`浮动体，因为占满页宽的`top`浮动体永远不会落在引用它的那一页。Map 2和Map 3是在第1页引用的`top`栏内浮动体，所以它们占据第2页两栏的栏首（[位置](/zh/docs/document-format#位置)）。`rotate: 'ccw'`让海图的上方朝向左边缘，并让它独占第3页。转过来以后，图沿页面方向长247.6 mm，即版心的53条网格线减去浮动体间距占用的一条；横向宽182.2 mm，是196 mm行长扣除题注横条和注释后剩下的部分。图再高一些就会被缩小，页面顶部会留下空白。

### 3 · 用同一批id画出图例

<Excerpt region="legend" />

`RELIEF`列出各个高程带的调色板id和起始高度。地图用`palette[id]`填充每个高程带，Map 1下方的图例用同一个id写出`:swatch`，因此调色板里换一个色值，地图和图例会同时改变。图例只用文字写一次单位，因为注释用的是Alegreya Sans SC，这款字体会把小写的*m*印成小型大写字母M。在<PageRef page={2}>第2页</PageRef>，正文把同样的色块放在两种水深旁边。

### 4 · 地图是资源，按引用编号和定位

<Excerpt region="resources" />

资源的编号取决于正文第一次引用它的位置。`:ref{id="north"}`印出该类型的简称和这个编号，即Map 2，可以用在正文里，也可以用在题注注释里。海图和地名表都在第2页首次被引用，海图在前，所以海图占第3页，地名表排在第4页页首。罗盘玫瑰也是同一类型的资源，但只有章首页画它，正文从不引用，所以地图仍然从1数到4。港口图例的每一项都是一个没有填色、边框和内边距的行内标签，编号、名称和后面的圆点因此保持在同一行。

### 5 · 地图和地名表共用的编号

<Excerpt region="gazetteer" />

`PLACES`按从北到南排序并依次编号，地图把编号印在红色圆点里，表格把编号印在红色行内标签里。`square()`根据在地图上定位各个标记所用的同一组公里坐标算出海图方格，所以6号Kirkwick无论在海图上还是表格里都位于D3。隔行的浅蓝底色由表格样式给出：`bodyAlternateBackgroundEnabled`，并把`bodyAlternateBackground`链接到`sea`。

### 6 · 地图集名称印在自家蓝色的横带上

<Excerpt region="opener" />

横带是锚定到`'bleed'`、不设宽度的框，因此从页面一边通到另一边。大标题是`{title}`，即frontmatter里的地图集名称；标题本身的文字跟在眉题里的图页编号之后。单靠横带只会预留到它的底边为止，正文会从横带下方3.9 mm处开始；`minHeight`把预留空间加大到上页边距以下14条网格线，正文于是从横带下方8.7 mm处开始。

## 变化

### 把海图朝另一个方向转

顺时针转时，海图的上方和题注横条位于第3页的切口一侧，读者要朝与惯例相反的方向转动书本，`'ccw'`遵循的是通常的惯例。

```diff
-  chart: { rotate: 'ccw' }, // 转四分之一圈，上方朝左，独占一页
+  chart: { rotate: 'cw' }, // 转四分之一圈，上方朝右，独占一页
```

### 改为旋转表格

表格用同一个设置就能旋转；如果宽得一页放不下，会在下一页继续旋转排出，并重复表头行：参见<RecipeLink slug="garden-almanac">园艺年历</RecipeLink>。

### 把地图放进边栏

在一栏半的版面里，外侧那一栏可以只放图和题注、不放正文：参见<RecipeLink slug="textbook-margin-column">带边栏的教科书</RecipeLink>。
