## できあがり

漫画の一ページ『灯台の無線』です。嵐が近づくなか、マヤはおじいちゃんの灯台にやって来ますが、無線が壊れています。犯人はケーブルの上で眠る猫のビスケット。コマ割りと五枚の水彩画は固定で、版ごとに変わるのは九行のせりふだけです。このレシピの各版は自分の言語のページを組み、その隣にフランス語のページも組みます。英語とフランス語、スペイン語とフランス語、日本語・中国語・アラビア語も同じです。エンジンは吹き出しに入る言葉に合わせて、一つずつ描き直します。日本語はZen Antiqueで縦書きに写植します。日本語とアラビア語のページは右から読むので、中段の三コマの並びが入れ替わります。

## 作り方

### 1 · すべての言語に一つの設定

コードは上の[手短な答え](#手短な答え)にあります。設定の中で言語にかかわるのは `locale` だけです。`fontFamily` を指定しなければ、写植は文書の言語の漫画用書体（`defaultComicFont`）になります。Comic Neue、Zen Antique、Noto Sans SC、Playpen Sans Arabicで、擬音もそれに合う書体になります。`writingMode: 'auto'` で日本語の吹き出しは縦書きになり、`readingDirection: 'auto'` で日本語とアラビア語のページはそれぞれの言語どおり右から読むので、同じ `split="30 / 35 [* | * | *] / *"` が無線のコマを右に、猫のコマを左に置きます。話者のid（`maya`、`tomas`）はどの言語のせりふでも同じで、絵のアンカーはそれに対応します。

文字サイズは本全体で一つです。英語のせりふは216文字、スペイン語は220、フランス語は224、中国語は74字。長いせりふほど吹き出しが大きくなり、文字が小さくなることはありません。

### 2 · どの版にもフランス語が付く

<Excerpt region="editions" />

サイトにはフランス語のページがないので、各版は二つの文書をビルドします。自分のページを組んだあと、`content.fr.en.md` からフランス語のページを、同じ設定で `locale` を `'fr'` にして組みます。フランス語のせりふでは、フランスの組版の決まりどおり `!` と `?` の前に細いノーブレークスペースを入れています。

### 3 · 絵は変わらない

<Excerpt region="art" />

安全領域はこのコマ割りのコマより細く切ってあります。中段は幅およそ46mm、高さ80mmのコマが三つなので、正方形の絵はそれぞれ幅の約58%の帯が見え、安全領域はそのうち36〜42%で、話者の顔とせりふが指すものを収めます。日本語版でもアラビア語版でも絵は反転しません（`mirrorArt` は false のまま）。マヤは左から坂道を上り、読む向きに従うのはコマの並びだけです。

## アレンジ

### 右から左へ読む版で絵を反転する

`mirrorArt: true` にすると、ページを読む向きが絵の描かれた向きと逆のとき、すべての絵が反転します。文字や時計が描かれたコマは `::panel{mirror=false}` で反転させずに残します。

```diff
   readingDirection: 'auto', // the default, written out: it is what an edition flips
+  mirrorArt: true,
```

## よくあるつまずき

- せりふの行では話者を名前ではなくidで指定します。どの言語でも `maya:` と書きます。スクリーンリーダーが読み上げる名前は `cast[].name` です。
- フランス語のページは版と同じ絵を使うので、コマの代替テキストは版の言語になります。フランス語にしたいときは `content.fr.en.md` に `::panel{alt="…"}` を書きます。
