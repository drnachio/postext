## 成品一览

一页漫画《灯塔的电台》：暴风雨要来的时候，玛雅来到爷爷的灯塔，电台坏了，罪魁祸首是睡在电线上的猫饼干。分格和五幅水彩画是固定的，各个版本之间只换一份九行的台词。这份食谱的每个版本先排自己的语言，旁边再排一页法语：英语配法语、西班牙语配法语，日语、中文和阿拉伯语也一样。引擎围绕每个对话框里的文字重新画框。日文用 Zen Antique 竖排嵌字。阿拉伯文页面从右往左读，所以中间一排的三格互换了位置。

## 做法

### 1 · 所有语言共用一份配置

代码就是上面的[简短回答](#简短回答)。配置里只有 `locale` 提到语言。不设 `fontFamily` 时，嵌字采用文档语言的漫画字体（`defaultComicFont`）：Comic Neue、Zen Antique、Noto Sans SC 或 Playpen Sans Arabic，拟声词也用对应的展示字体。`writingMode: 'auto'` 让日文对话框竖排；`readingDirection: 'auto'` 让阿拉伯文页面从右往左读，于是同一个 `split="30 / 35 [* | * | *] / *"` 把电台那一格放到右边，猫那一格放到左边。说话人的 id（`maya`、`tomas`）在每份台词里都一样，画面上的锚点就按这些 id 对应。

全书只有一个字号。英语台词 216 个字母，西班牙语 220 个，法语 224 个，中文 74 个字；台词越长，对话框越大，字却不会变小。

### 2 · 每个版本都带上法语页

<Excerpt region="editions" />

网站没有法语页面，所以每个版本都构建两个文档：先是自己的那一页，然后用 `content.fr.en.md` 排法语页，配置相同，只把 `locale` 设为 `'fr'`。配置展开成一个新对象，因为引擎按对象身份缓存解析后的配置。法语台词在 `!` 和 `?` 前用窄的不换行空格，这是法语排版的规矩。

### 3 · 画面不变

<Excerpt region="art" />

安全区是按这套分格的格子裁定的：中间一排三格，每格约宽 46 毫米、高 80 毫米，所以每幅方形的画保留宽度 56%–58% 的一条，说话人的脸在里面。阿拉伯文版不镜像画面（`mirrorArt` 仍为 false）：玛雅依旧从左边走上小路，只有画格的顺序跟着阅读方向变。

## 变化

### 在阿拉伯文版里镜像画面

`mirrorArt: true` 会在页面的阅读方向与画面原本的方向相反时翻转每幅画。画里有文字或时钟的格子，用 `::panel{mirror=false}` 让它保持不翻。

```diff
   readingDirection: 'auto', // the default, written out: it is what an edition flips
+  mirrorArt: true,
```

## 常见问题

- 台词每一行用 id 指定说话人，而不是名字：每种语言都写 `maya:`。读屏软件念出的名字来自 `cast[].name`。
- 法文页和本版共用画面，所以它各格的替代文字是本版的语言；想用法文，就在 `content.fr.en.md` 里写 `::panel{alt="…"}`。
