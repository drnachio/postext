## 成品一览

虚构日报《The Corrington Despatch》的四个版，开本为375 × 597 mm的对开大报。正文分六栏，每栏55.2 mm，栏距4 mm，每条栏距里一条细栏线：9 pt字号下每行约38个字符，正是真实大报的行长。头版有带两个报眼的报头、一条导读条、标题和照片都横跨四栏的头条、配两栏照片的第二条新闻、一栏简讯、一张资金表和一个两栏宽的资料框，页脚是一则广告。第2版以头版的转版开头，第3版改为五栏，排社论、一篇评论和读者来信，末版是剧评和天气。

## 做法

### 1 · 对开大报上的六栏

这一步的代码就是上面的[简短回答](#简短回答)。`page.sizePreset: 'broadsheet'`设定375 × 597 mm的开本，`layoutType: 'multiple'`加`columnCount: 6`把351 mm宽的版心切成六个等宽的栏（[版式类型](/zh/docs/configuration-page-layout#版式类型)）。每栏宽(351 − 5 × 4) / 6 = 55.2 mm，9 pt的Newsreader每行约38个字符，所以正文需要断词，用`minWordSpacing: 0.8`防止词距收得过紧，用`maxJustifyTracking: 15`把松散行的空隙分摊到字母之间。栏线在每条栏距里画一条0.4 pt的细线，遇到横跨的浮动体或框就断开。postext 1.17及以前，正文最多两栏，所以<RecipeLink slug="newspaper-front-page">第027号</RecipeLink>只能把四栏简讯放进一个框里。

### 2 · 跨k栏的浮动体占用第一组空栏

<Excerpt region="pictures" highlight="1-6" />

`placement.columns`以栏数给出照片或表格的宽度，包括其间的栏距：头版的四栏是232.7 mm。引擎从正文所在的栏开始，从左往右找位置。`top`浮动体占用第一组还没有正文、顶边齐平的k个栏的栏头；`bottom`浮动体占用正文所在栏及其后各空栏的栏脚。所以资金表在第3栏的段落里被引用，就落在第3、4栏底部。在<PageRef page={2}>第2版</PageRef>，资料框先开，占了第1、2栏，第3至6栏便成为后面那张四栏照片的第一组齐平空栏。顺序反过来，框就会叠在照片下面。k等于或大于本页栏数时就是通栏，与`span: 'page'`相同。

### 3 · 标题框、资料框和广告

<Excerpt region="boxes" />

带`placement="top"`和`columns="4"`的`:::callout`像照片一样浮动在四栏上。头条的标题和导语就是这样一个框，放在正文之前，所以占第1至4栏，照片叠在它下面。第二条新闻的标题框放在头条之后、一个`:::columnbreak`后面：这时正文已在第5栏，第5、6栏是第一对空栏。每则广告都是`columns="6"`的通栏框，在本版开头就开出，使其底部在正文到来之前就预留好；第2版和第4版的转版标题是通页宽的框，与第027号相同。`balancing.trailing: false`让每一版都把各栏填到底，因为这里每一版都结束一个栏目。

### 4 · 报头是头版的H1

<Excerpt region="nameplate" />

`# The Corrington Despatch`使用`front`标题样式：报名为64 pt的Playfair Display Black，两个报眼由标题属性填充，日期行夹在一细一粗两条线之间。首页设计高九条网格线。其下的浅色导读条是一个通页宽的框，是头版自己的一个要素：它结束首页设计所在的横带，头条的标题框占用它开出的横带的第1至4栏。没有导读条时，标题框也会紧贴在首页设计下方占这四栏，因为首页设计下方第1栏的栏首和其他各栏的栏首一样是一个空位（在postext 1.24及以前不是，标题框会从第2栏开始）。

### 5 · 评论版改为五栏

<Excerpt region="sections" />

`# Opinion {style="opinion"}`开出一个栏目，其标题样式设定`layout: { layoutType: 'multiple', columnCount: 5 }`。栏目沿用文档的栏距和栏线，只改栏数，所以社论、评论和来信的行长为67 mm，约47个字符。评论的标题框是`columns="3"`，在社论已从第1栏开始之后才开出，因而落在第2至4栏，照片在其下；两行`:::columnbreak`把评论送到第2栏，把来信送到第5栏。

## 变化

### 排成五栏的柏林版

同一份报纸改用315 × 470 mm的柏林版：五栏，每栏55 mm，与对开大报六栏的行长相同。页眉线也改用较窄的宽度，然后逐版重新拼版。

```diff
-const layout = { layoutType: 'multiple', columnCount: 6, gutterWidth: mm(GUTTER),
+const layout = { layoutType: 'multiple', columnCount: 5, gutterWidth: mm(GUTTER),
-      size: { width: mm(375 - 2 * MARGIN.side) } }] };
+      size: { width: mm(315 - 2 * MARGIN.side) } }] };
-  page: { sizePreset: 'broadsheet', dpi: 150, backgroundColor: col('paper'), // 375 × 597 mm
+  page: { sizePreset: 'berliner', dpi: 150, backgroundColor: col('paper'), // 315 × 470 mm
```

## 常见问题

- 浮动体若在正文已经走过它的那几栏之后才开出，本版就没有位置，会开到下一版。头版的头条必须在第4栏结束：多一段，第二条新闻的标题和照片就会移到第2版。
- 每一版都要像编辑拼版那样手工调整：广告里的`:::space`行数和每篇稿子的长度决定各栏在哪里结束。改了一篇稿子，就要重新拼那一版。
