## 成品一览

豪尔赫·曼里克为父亲之死写的《悼亡父诗》（Coplas），英文版用朗费罗的译本，西班牙文版排原文，排成125 × 200毫米的平装书，另外还有封面印张：四色印完以后，它要送去做表面工艺。印张上有三道工艺。书名框上下两段画面做局部亮光上光。书名框的双层边框烫金，框里的底板起凸，书名就落在凸起的面上。封底有一枚素压的菱形：不上墨，只把纸板压凸。书的下方，示例把印张画了四遍：印出来的样子、上光版和烫金版的假色图、侧光下的样子，以及刻版师据以做压凸模的起凸版。PDF是PDF/X-4，每道工艺一块印版。

## 做法

### 1 · 每道工艺都跟着设计里的一个图形

代码就是上面的[简短回答](#简短回答)。一道工艺写明工艺类型、要印的油墨（如果有）和一个形状：封面上的一个元素（`{ element: 'cartouche' }`）、某个区域里的一个方框，或者方框里的一条轮廓。上光和烫金是调色板里带`finish`的专色，所以在PDF里各有一块印版，印前检查会把它们列出来。起凸什么都不印。它放在一块技术版上，印刷文件把它叫作Emboss，是刻版师用的那块，页面上不画它。

上光是两个方框，一个在书名框上面，一个在下面，都离书名框4毫米，免得上光压到烫金。封底和书脊保持哑光。全书27页，用120 g/m²、松厚度2.2的书纸，按16页一帖装订后是32页，书脊4.7毫米。默认书脊不足6毫米不印字，所以版本里把`spineText.minSpine`设为4.5。这个ISBN是示例号码，不属于任何一本书。

### 2 · 书名框是设计里的路径，不是图片

<Excerpt region="art" />

烫金和起凸严格沿着所指元素的轮廓走，所以边框必须是一个引擎知道路径的图形。封面路径是一组闭合轮廓，节点用元素方框的比例表示，曲线带进出控制柄。每个角是向内凹的四分之一圆，用三次曲线画。一个环由外轮廓和反方向走的内轮廓组成：按nonzero规则，两者之间是空的。两个环就是双层边框。边框和底板同色，四色印刷时什么也不印，全靠烫金版。封底的徽记是存好的一条轮廓：两个菱形，小的那个反向。

### 3 · 封面的样式

<Excerpt region="cover-type" />

`cover-title`、`cover-subtitle`、`cover-author`和`cover-spine`是`buildCover`给它放置的元数据起的名字；`cover-quote`、`cover-blurb`和`cover-note`写在封面的Markdown里。封面在高度上居中（`verticalAlign`），书名不管字号多大都落在书名框里。

### 4 · 书芯

<Excerpt region="pages" />

半书名页、书名页、版权页，然后诗从一个右页开始，往下沉46毫米，按诗行排，不把一节拆到两页上。书眉左页是作者，右页是书名。版本记录放在最后一个右页上收尾。

### 5 · 印张由排好的内页生成

<Excerpt region="sheet" />

`buildCover`接收页面、元数据和封面的Markdown，返回一份交给`buildDocumentWithFonts`的文档，外加SVG格式的条码。条码数字要用OCR-B，没有哪个字体服务器提供，所以示例改用已经加载的Alegreya Sans SC。

### 6 · 每块印版覆盖哪里

<Excerpt region="views" />

`renderPageToCanvas`有三种画工艺的方式。`flat`按印刷机落墨的样子画：烫金画成它的颜色，上光不画。`map`把印张调淡，用假色标出每块专色版。`sheen`让一道侧光扫过印张，上光和烫金会反光。起凸三种都不出现，因为它不印东西；第四幅图在调淡的印张上用黑色画出页面的技术版（`page.plates`），也就是PDF在Emboss分色上填充的轮廓。下面那一行从`preflightDocument`读出专色，从技术版读出工艺。

## 变化

### 把徽记改成压凹

压凹把图形压进纸板，而不是顶起来，放在单独的Deboss版上。

```diff
-    { id: 'emblem', process: 'emboss', shape: { outline: emblem,
+    { id: 'emblem', process: 'deboss', shape: { outline: emblem,
```

### 整幅画上光

画面元素上的一道工艺代替两个方框。这样上光也会盖过书名框和书名。

```diff
-    ...[[-3, 76], [127, 76]].map(([y, height], i) => ({ id: `gloss-${i + 1}`, process: 'varnish',
-      ink: col('varnish'), shape: { box: { zone: 'front', x: 0, y, width: 128, height } } })),
+    { id: 'gloss', process: 'varnish', ink: col('varnish'), shape: { element: 'art' } },
```

## 常见问题

- 起凸或压凹离裁切线或折线不到3毫米，印前检查会报出来（`reliefTrim`、`reliefFold`）：纸板在那里会裂。让凹凸远离书脊的折线。
- 起凸在屏幕上从来不画。到PDF的Emboss分色里去看，或者像示例这样画出`page.plates`。
- 工艺盖在文字框上，会遮住文字，视图里和印刷文件里都一样。留一部分文字在烫金之外，就像这里的书名放在书名框中间的空处。
