## できあがり

ホルヘ・マンリーケが父の死に寄せた『Coplas』を、英語版はロングフェローの訳で、スペイン語版は原文で、125 × 200 mmの並製本にします。表紙用紙も作ります。4色を刷り終えたあと、加工所に回る用紙です。加工は3つ。カルトゥーシュの上下の絵に部分グロスニスをかけます。カルトゥーシュの二重の枠は金箔押しにし、枠の中のパネルはエンボスで持ち上げるので、書名は浮き出た面に載ります。表4には菱形の空押し。インキは使わず、厚紙を押し上げるだけです。本の下には用紙を4回描きます。刷り上がりのまま、ニス版と箔版を擬似カラーで、斜めの光の下で、そして型を彫る人が使うエンボス版として。PDFはPDF/X-4で、加工ごとに版を持ちます。

## 作り方

### 1 · 加工はデザインの図形に沿う

コードは上の[手短な答え](#手短な答え)にあります。加工には工程、刷るインキがあればそのインキ、そして形を指定します。表紙の要素（`{ element: 'cartouche' }`）、ゾーンの中の矩形、矩形の中の輪郭のどれかです。ニスと箔はパレットで`finish`を持つ特色なので、PDFではそれぞれが版になり、プリフライトにも並びます。エンボスは何も刷りません。印刷ファイルがEmbossと呼ぶ技術版に載り、型を彫る人はこれを使います。ページには描かれません。

ニスは2つの矩形で、1つはカルトゥーシュの上、もう1つは下にあり、どちらもカルトゥーシュの4 mm手前で止まるので、ニスが箔に重なることはありません。表4と背はマットのままです。本は27ページ、120 g/m²、嵩高2.2の書籍用紙で、16ページ折で綴じると32ページになり、背幅は4.7 mmです。標準では6 mm未満の背に文字を入れないので、版で`spineText.minSpine`を4.5にしています。このISBNは見本の番号で、どの本にも割り当てられていません。

### 2 · カルトゥーシュは画像ではなく、デザインのパス

<Excerpt region="art" />

箔とエンボスは指定した要素の輪郭どおりにかかるので、枠はエンジンがパスを知っている図形でなければなりません。表紙のパスは閉じた輪郭のリストで、節点は要素の矩形に対する比率、曲線には入りと出のハンドルがあります。角はそれぞれ内向きの四分円で、3次曲線で描きます。環は外側の輪郭と、逆向きに回る内側の輪郭の組です。nonzeroの規則で、その間は空いたままになります。環2つで二重の枠になります。枠はパネルと同じ色なので4色では何も刷られず、箔版が受け持ちます。表4の紋章は保存した輪郭で、菱形2つ、小さいほうは逆向きです。

### 3 · 表紙の文字のスタイル

<Excerpt region="cover-type" />

`cover-title`、`cover-subtitle`、`cover-author`、`cover-spine`は、`buildCover`が置くメタデータに付ける名前です。`cover-quote`、`cover-blurb`、`cover-note`は表紙のMarkdownで指定します。表1は高さ方向の中央揃え（`verticalAlign`）なので、書名は文字の大きさにかかわらずカルトゥーシュに収まります。

### 4 · 本文

<Excerpt region="pages" />

半扉、扉、権利表記、そして詩が奇数ページから46 mm下げて始まります。連を2ページに分けない詩の組み方です。柱は偶数ページに著者、奇数ページに書名。奥付は最後の奇数ページで本を閉じます。

### 5 · 組んだページから用紙を作る

<Excerpt region="sheet" />

`buildCover`はページ、メタデータ、表紙のMarkdownを受け取り、`buildDocumentWithFonts`に渡す文書と、SVGのバーコードを返します。バーコードの数字はOCR-Bを求めますが、どのフォントサーバーにもないので、読み込み済みのAlegreya Sans SCで組みます。

### 6 · それぞれの版がかかる範囲

<Excerpt region="views" />

`renderPageToCanvas`は加工を3通りに描きます。`flat`は印刷機が載せるとおりにインキを描きます。箔はその色で、ニスは描きません。`map`は用紙を淡くし、特色版を擬似カラーで示します。`sheen`は用紙に斜めの光を当て、ニスと箔が光ります。エンボスは何も刷らないので3つのどれにも出ません。4つ目の図は、淡くした用紙の上にページの技術版（`page.plates`）を黒で描きます。PDFがEmbossの分版で塗る輪郭です。下の1行は、特色を`preflightDocument`から、工程を技術版から読んでいます。

## アレンジ

### 紋章をデボスにする

デボスは形を厚紙に押し込みます。版はDebossとして別になります。

```diff
-    { id: 'emblem', process: 'emboss', shape: { outline: emblem,
+    { id: 'emblem', process: 'deboss', shape: { outline: emblem,
```

### 絵全体にニスをかける

絵の要素に1つの加工をかければ、2つの矩形はいりません。ニスはカルトゥーシュと書名にもかかります。

```diff
-    ...[[-3, 76], [127, 76]].map(([y, height], i) => ({ id: `gloss-${i + 1}`, process: 'varnish',
-      ink: col('varnish'), shape: { box: { zone: 'front', x: 0, y, width: 128, height } } })),
+    { id: 'gloss', process: 'varnish', ink: col('varnish'), shape: { element: 'art' } },
```

## よくあるつまずき

- エンボスやデボスが仕上がり線や折り目から3 mm以内にあると、プリフライトが知らせます（`reliefTrim`、`reliefFold`）。そこで厚紙が割れるからです。背の折り目から離してください。
- エンボスは画面には描かれません。PDFのEmboss分版で確かめるか、このレシピのように`page.plates`を描きます。
- テキストの枠に加工をかけると、表示でも印刷ファイルでも行が隠れます。書名をカルトゥーシュの空いた中央に置いたように、文字の一部は箔の外に残します。
