## What you'll build

*Direct Preference Optimization* by Rafailov, Sharma, Mitchell, Ermon, Manning and Finn (NeurIPS 2023), abridged from its arXiv source and set as a ten-page preprint on a 7 × 10 in page. A plum band carries the title over a fan of logistic curves, the shape of the weight that the DPO gradient puts on each example. Below it, one generous column of Spectral holds thirteen numbered equations, the definition, lemmas and theorem of section 5 as boxes with run-in labels, a proof sketch and a full proof that end in a square, a pipeline figure redrawn in code and twenty works cited author–year. Every equation, statement and section reference in the text is a link, and every number comes from a label, as in LaTeX.

## Method

### 1 · Label equations and statements, refer to them by key

The code is [the short answer](#the-short-answer) above. Since postext 1.19 the engine keeps LaTeX's counters. A `\label{eq:dpo}` in a display formula numbers it in reading order, one number for each labelled row of an `align` and none for a row marked `\notag`; `resetOn: 'never'` carries the count from (1) through the appendix to (13), as this abridged paper is renumbered. A box opened as `:::callout{type="lemma" #lem:same-policy}` starts with “**Lemma 2.**”, because its style has `numbering: { label: 'Lemma' }` and a counter of its own. In the text, `\eqref{eq:dpo}` prints (7), `\ref{lem:same-policy}` prints 2 and `:ref{id="lem:same-policy"}` prints Lemma 2, each a link to its target; `Eq.~\eqref{…}` keeps LaTeX's tie. The restated lemma of the appendix opens with `***:ref{id="lem:same-preference"} Restated.***`, and the reference takes the bold of the label around it. Sections need no help: their numbers come from the heading templates, `{startAt=3}` keeps the paper's own numbering after the cut section 2, and `crossRefs.section` prints “Section 5” with a capital, as the paper does.

### 2 · Give each environment its own box

<Excerpt region="theorems" />

Each environment is a [callout style](/en/docs/configuration#callout-styles) with one device: a grey stripe for the definition, a plum stripe for the lemmas, a pale plum tint for the theorem. `box()` lays that look over the numbering of the short answer. `body.italic` sets the statement in italics as amsthm's plain style does, and the run-in label stays bold and upright inside it. A proof has no box at all: its label is italic and has no number (`counter: false`), `endMark: '□'` sets a square flush right on its last line, drawn from TeX's `\square` because maths runs, and `keepTogether: false` lets a long proof run on to the next page. `snapToGrid: false` keeps the same space around every statement; in one column with no neighbour to line up with, an exact gap reads better than one rounded to the grid.

### 3 · Cite author–year from the paper's own reference list

<Excerpt region="citations" />

The references are BibTeX in a `:::references{format=bibtex}` block, rebuilt from the paper's `.bbl` with only the twenty works the abridged text still cites. Cite Them Right Harvard sets them as “(Bong and Rinaldo, 2022)” in the text and “Ouyang, L. *et al.* (2022)” in the list, cutting author lists of four or more to the first name. `@ziegler2020finetuning` in the text prints the narrative form, Ziegler *et al.* (2020). The list stands where `:::bibliography` is, after section 7 and before the appendix, as in the paper.

### 4 · Put the title on a band, the source at the foot

<Excerpt region="title" />

The title is the only level-1 heading, and its `paper` style draws a slot of design elements instead: the band bleeds off the top of the page, the title wraps at the measure, and the authors and affiliations come from heading attributes, with ¹ ² and * written as characters. The footer element with `pages: 'opener'` prints the source, the licence and the changes made on page 1 only, so the first page says where the text comes from even when it travels alone.

### 5 · Redraw the figure in code

<Excerpt region="art" />

Figure 1 is drawn as SVG from the boxes and words of the original. An SVG drawn as an image cannot use the page's web fonts, so `inlineFace()` embeds the two Work Sans files the labels use, and `tex()` writes the `y_w ≻ y_l` labels as MathJax paths, the same glyphs the equations use. Arrowheads are drawn paths rather than SVG markers, so the figure stays vector in the PDF.

## Variations

### Cite with numbers, as the NeurIPS template does

The original paper uses natbib's numbered citations; IEEE prints [1] in the text and numbers the list in order of citation.

```diff
-const citations = { style: 'harvard-cite-them-right', link: true,
+const citations = { style: 'ieee', link: true,
```

### Count lemmas and theorems together

Some journals number every statement in one sequence (Lemma 1, Lemma 2, Theorem 3), as `\newtheorem{lemma}[theorem]` does. Point the lemmas at the theorem counter.

```diff
-  { id: 'lemma', numbering: { label: 'Lemma' } }, // counter: 'theorem' would share one sequence
+  { id: 'lemma', numbering: { label: 'Lemma', counter: 'theorem' } },
```

## Pitfalls

- `endMark` draws its squares (□ ∎ ■) from TeX only when maths runs. In a document without `initMathEngine()` the mark is set in the box's body face, and Spectral, like every Fontsource latin file, has no □: pick a mark the face can set there.
- Column balancing fills a page that a tall display leaves short by adding grid lines above its headings. `balancing: { maxLinesPerHeading: 1 }` keeps a paper's heads close to their own spacing; such a page may then end a few lines up.
- A display with an `\underbrace` label wider than the brace, such as the gradient in section 4, needs an `aligned` break; set wider than the measure, it overflows to the right.
