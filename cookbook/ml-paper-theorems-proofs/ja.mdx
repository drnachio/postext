## できあがり

Rafailov、Sharma、Mitchell、Ermon、Manning、Finnの論文*Direct Preference Optimization*（NeurIPS 2023）をarXivの原稿から抄録し、7×10インチ判で10ページのプレプリントとして組みました。プラム色の帯には表題と、ロジスティック曲線の束を置いています。DPOの勾配が各事例に掛ける重みの形です。その下はゆったりしたSpectralの1段組みで、番号付きの数式が13本、5節の定義・補題・定理は見出しを行頭に置いた囲み、四角で終わる証明の概略と完全な証明、コードで描き直した流れ図、著者–年形式で引いた20件の文献が並びます。本文中の数式・命題・節への参照はすべてリンクで、番号はすべてラベルから決まります。LaTeXと同じ考え方です。

## 作り方

### 1 · 数式と命題にラベルを付け、キーで参照する

コードは上の[手短な答え](#手短な答え)です。Postextは`\tag{7}`を付けたディスプレイ数式に番号を振り、`:ref`はどの[アンカー](/ja/docs/document-format#相互参照とアンカー)にもリンクできますが、数式や定理の数は数えてくれません。`latex()`が組版の前にその数え役を担います。ディスプレイ数式の中の`\label{eq:dpo}`は次の`\tag`に、`:::callout{type="lemma" #lem:same-policy}`は次の補題番号と行頭の見出しになり、本文の`\eqref{eq:dpo}`や`\ref{lem:same-policy}`は番号を印字してそこへリンクする`:ref`に変わります。ラベル付きの数式は、それを導く行のすぐ下に空行を入れずに書いてください。リンクの飛び先となるアンカーをその行に置くためです。節番号は手を加える必要がありません。番号は見出しのテンプレートから決まり、`{startAt=3}`で2節を削った後も論文本来の番号を保ち、`crossRefs.section`で原文どおり頭文字が大文字の「Section 5」になります。

### 2 · 環境ごとに囲みを一つ

<Excerpt region="theorems" />

各環境は[囲みスタイル](/ja/docs/configuration#囲みスタイル)で、使う手立ては一つだけです。定義は灰色の縦罫、補題はプラム色の縦罫、定理は淡いプラム色の地。`body.italic`でamsthmのplainスタイルのように命題をイタリックにし、`***Theorem 1.***`と書いた見出しはその中で立体に戻ります。証明には囲みを付けず、イタリックの行頭見出しと、`latex()`が末尾に加える四角だけです。`keepTogether: false`で長い証明は次のページへ送れます。`snapToGrid: false`で各命題の前後の空きをそろえます。隣の段とそろえる必要のない1段組みでは、ベースライングリッドに丸めた空きより正確な空きのほうが読みやすくなります。

### 3 · 論文自身の文献リストから著者–年形式で引く

<Excerpt region="citations" />

参考文献は`:::references{format=bibtex}`ブロックのBibTeXで、論文の`.bbl`から、抄録した本文がなお引いている20件だけを組み直しました。Cite Them Right Harvardは本文では「(Bong and Rinaldo, 2022)」、文献リストでは「Ouyang, L. *et al.* (2022)」とし、著者が4人以上なら筆頭著者だけを残します。本文に`@ziegler2020finetuning`と書くと、Ziegler *et al.* (2020)という叙述形になります。リストは`:::bibliography`の位置、つまり7節の後、付録の前に置かれ、論文と同じ並びです。

### 4 · 表題は帯の上に、出典はページ下端に

<Excerpt region="title" />

表題はただ一つのレベル1見出しで、その`paper`スタイルが代わりにデザイン要素の組を描きます。帯はページ上端に裁ち落とし、表題は版面の幅で折り返し、著者と所属は見出しの属性から取ります。¹、²、*は文字として書いています。フッターの`pages: 'opener'`付きの要素は、出典・ライセンス・加えた変更を1ページ目にだけ印字します。1ページ目だけが切り離されて出回っても、本文の出どころがわかるようにするためです。

### 5 · 図をコードで描き直す

<Excerpt region="art" />

図1は原図の枠と語句をもとにSVGで描いています。画像として描かれるSVGにはページのWebフォントが見えないため、`inlineFace()`でラベルが使うWork Sansの2ファイルを埋め込み、`tex()`で`y_w ≻ y_l`をMathJaxのパスとして書きます。数式と同じ字形です。矢じりはSVGのmarkerではなくパスで描いているので、PDFでも図はベクターのままです。

## アレンジ

### NeurIPSのテンプレートのように番号で引く

原論文はnatbibの番号方式です。IEEEなら本文に[1]と印字し、文献リストを引用順に番号付けします。

```diff
-const citations = { style: 'harvard-cite-them-right', link: true,
+const citations = { style: 'ieee', link: true,
```

### 補題と定理を通し番号にする

すべての命題を一つの系列で数える雑誌もあります（補題1、補題2、定理3）。すべての種類で一つのカウンターを共有させます。

```diff
-    labels.set(key, String((count[kind] = (count[kind] ?? 0) + 1)));
+    labels.set(key, String((count.statement = (count.statement ?? 0) + 1)));
```

## よくあるつまずき

- 太字の見出しの中の`:ref`は、周りの太字ではなく参照のスタイルになります。「Lemma 1 Restated.」では番号が普通の太さで出てしまうので、再掲の見出しの番号は文字で書きます。
- 段の均等化は、短いページを締めくくる囲みをページ下端まで下げます。ここでは表題部の下に隙間が開きました。`balancing: { enabled: false }`にすると要旨は著者行のすぐ下に、各節の見出しは本来の空きのままになり、その代わりにページが1行短く終わることがあります。
- `\underbrace`の注記が括弧より広い式（4節の勾配など）は`aligned`で2行に分けます。版面より広い式は右へはみ出します。
