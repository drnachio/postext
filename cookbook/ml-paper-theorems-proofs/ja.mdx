## できあがり

Rafailov、Sharma、Mitchell、Ermon、Manning、Finnの論文*Direct Preference Optimization*（NeurIPS 2023）をarXivの原稿から抄録し、7×10インチ判で10ページのプレプリントとして組みました。プラム色の帯には表題と、ロジスティック曲線の束を置いています。DPOの勾配が各事例に掛ける重みの形です。その下はゆったりしたSpectralの1段組みで、番号付きの数式が13本、5節の定義・補題・定理は見出しを行頭に置いた囲み、四角で終わる証明の概略と完全な証明、コードで描き直した流れ図、著者–年形式で引いた20件の文献が並びます。本文中の数式・命題・節への参照はすべてリンクで、番号はすべてラベルから決まります。LaTeXと同じ考え方です。

## 作り方

### 1 · 数式と命題にラベルを付け、キーで参照する

コードは上の[手短な答え](#手短な答え)です。postext 1.19からは、LaTeXのカウンターをエンジンが持ちます。ディスプレイ数式の中の`\label{eq:dpo}`は読む順に番号を付け、`align`ではラベルのある行ごとに一つ付き、`\notag`の行には付きません。`resetOn: 'never'`で番号は(1)から付録の(13)まで続き、この抄録版で振り直した番号と一致します。`:::callout{type="lemma" #lem:same-policy}`で開いた囲みは「**Lemma 2.**」で始まります。スタイルに`numbering: { label: 'Lemma' }`と専用のカウンターがあるためです。本文では`\eqref{eq:dpo}`が(7)、`\ref{lem:same-policy}`が2、`:ref{id="lem:same-policy"}`がLemma 2を印字し、どれも参照先へのリンクになります。`Eq.~\eqref{…}`ではLaTeXと同じく改行しない空白が入ります。付録で再掲する補題は`***:ref{id="lem:same-preference"} Restated.***`で始まり、参照は周りの見出しの太字を受け継ぎます。節番号は手を加える必要がありません。番号は見出しのテンプレートから決まり、`{startAt=3}`で2節を削った後も論文本来の番号を保ち、`crossRefs.section`で原文どおり頭文字が大文字の「Section 5」になります。

### 2 · 環境ごとに囲みを一つ

<Excerpt region="theorems" />

各環境は[囲みスタイル](/ja/docs/configuration#囲みスタイル)で、使う手立ては一つだけです。定義は灰色の縦罫、補題はプラム色の縦罫、定理は淡いプラム色の地。`box()`がその見た目を手短な答えの番号設定に重ねます。`body.italic`でamsthmのplainスタイルのように命題をイタリックにし、行頭見出しはその中でも太字の立体のままです。証明には囲みを付けません。見出しはイタリックで番号がなく（`counter: false`）、`endMark: '□'`で最後の行の右端に四角を置きます。数式エンジンが動いているので、四角はTeXの`\square`で描かれます。`keepTogether: false`で長い証明は次のページへ送れます。`snapToGrid: false`で各命題の前後の空きをそろえます。隣の段とそろえる必要のない1段組みでは、ベースライングリッドに丸めた空きより正確な空きのほうが読みやすくなります。

### 3 · 論文自身の文献リストから著者–年形式で引く

<Excerpt region="citations" />

参考文献は`:::references{format=bibtex}`ブロックのBibTeXで、論文の`.bbl`から、抄録した本文がなお引いている20件だけを組み直しました。Cite Them Right Harvardは本文では「(Bong and Rinaldo, 2022)」、文献リストでは「Ouyang, L. *et al.* (2022)」とし、著者が4人以上なら筆頭著者だけを残します。本文に`@ziegler2020finetuning`と書くと、Ziegler *et al.* (2020)という叙述形になります。リストは`:::bibliography`の位置、つまり7節の後、付録の前に置かれ、論文と同じ並びです。

### 4 · 表題は帯の上に、出典はページ下端に

<Excerpt region="title" />

表題はただ一つのレベル1見出しで、その`paper`スタイルが代わりにデザイン要素の組を描きます。帯はページ上端に裁ち落とし、表題は版面の幅で折り返し、著者と所属は見出しの属性から取ります。¹、²、*は文字として書いています。フッターの`pages: 'opener'`付きの要素は、出典・ライセンス・加えた変更を1ページ目にだけ印字します。1ページ目だけが切り離されて出回っても、本文の出どころがわかるようにするためです。

### 5 · 図をコードで描き直す

<Excerpt region="art" />

図1は原図の枠と語句をもとにSVGで描いています。画像として描かれるSVGにはページのWebフォントが見えないため、`inlineFace()`でラベルが使うWork Sansの2ファイルを埋め込み、`tex()`で`y_w ≻ y_l`をMathJaxのパスとして書きます。数式と同じ字形です。矢じりはSVGのmarkerではなくパスで描いているので、PDFでも図はベクターのままです。

## アレンジ

### NeurIPSのテンプレートのように番号で引く

原論文はnatbibの番号方式です。IEEEなら本文に[1]と印字し、文献リストを引用順に番号付けします。

```diff
-const citations = { style: 'harvard-cite-them-right', link: true,
+const citations = { style: 'ieee', link: true,
```

### 補題と定理を通し番号にする

すべての命題を一つの系列で数える雑誌もあります（補題1、補題2、定理3）。`\newtheorem{lemma}[theorem]`と同じく、補題に定理のカウンターを使わせます。

```diff
-  { id: 'lemma', numbering: { label: 'Lemma' } }, // counter: 'theorem' would share one sequence
+  { id: 'lemma', numbering: { label: 'Lemma', counter: 'theorem' } },
```

## よくあるつまずき

- `endMark`が四角（□ ∎ ■）をTeXで描くのは数式エンジンが動いているときだけです。`initMathEngine()`のない文書では囲みの本文の書体で組まれ、SpectralにはFontsourceのどのlatinファイルとも同じく□がありません。その場合は書体が持っている記号を選んでください。
- 段の均等化は、背の高い数式のせいで短くなったページを、見出しの上にベースライングリッドの行を足して埋めます。`balancing: { maxLinesPerHeading: 1 }`なら論文の見出しはほぼ本来の空きを保ち、そうしたページは数行短く終わることがあります。
- `\underbrace`の注記が括弧より広い式（4節の勾配など）は`aligned`で2行に分けます。版面より広い式は右へはみ出します。
