## できあがり

架空の3ページの短編映画『Lost Property』の撮影稿を、スタジオの台本と同じ体裁で綴じます。ゴールデンロッドのカードの表紙に真鍮のブラッド2本とタイプしたラベル、表紙の裏にはCOPY 07のスタンプがあり、続いて脚本本体を、パンチ穴を開けたUS Letterに、Courier Primeの12pt、行送り12ptで組みます。行長は脚本ソフトウェアのものと同じです。ト書きは1.5インチから7.5インチ、台詞は3.7インチに置いた人物名の下に2.5インチから6インチ、括弧書きの演技指示は3.1インチから始まり、CUT TO:とFADE OUT.は右の余白で終わります。各シーン見出しは両側の余白に番号を持ちます。脚本の1ページ目には番号を付けず、ほかのページは右上に番号をピリオド付きで刷ります。各台詞は枠のない囲みで、人物名を本文と同じ12ptの行送りに置きます。そのためト書きも台詞も1インチ6行を保ちます。

## 作り方

### 1 · 枠のない囲みを台詞ブロックに合わせてパディングする

コードは上の[手短な答え](#手短な答え)にあります。囲みのパディングは版面から測るので、左に1インチ、右に1.5インチ取ると、紙の端から2.5インチの位置で始まる3.5インチのブロックが残ります（[囲みスタイル](/ja/docs/configuration#囲みスタイル)）。人物名は囲みの題で、フェンスに`title="Dora (cont’d)"`と書きます。`textTransform`でそれを大文字にし、`indent`でパディングからさらに1.2インチ、3.7インチの位置まで動かします。`gap`は0にします。既定値では名前と台詞のあいだに半em、つまり6ptが空くからです。既定では、囲みの題は文字サイズの1.2倍、ここでは14.4ptの行に置かれます。`titleStyle.lineHeight`でこれを本文と同じ12ptにすると、名前はグリッドの行に乗り、台詞は12ptの行の整数倍になります。既定値のままだと、台詞はそれぞれ後ろのテキストをさらに2.4ptグリッドから押し出します。`snapToGrid`をオフにすると、ある台詞の下マージンと次の台詞の上マージンが重なって1つの空行になります。囲みは既定で分割されないので、収まらなくなった台詞は名前ごと次のページへ移ります。

### 2 · ページをインチで設定する

<Excerpt region="page" />

US Letterで、ブラッドを通す左の余白は1.5インチ、ほかの3辺は1インチです。Courier Primeは等幅の書体で、12ptでは1字の幅が10分の1インチになります。そのためト書きの行は60字、台詞は35字を収め、12ptの行送りでページは54行を収めます。本文は左そろえ（行末不ぞろい）で組み、`paragraphSpacing`で段落のあいだに空行を入れます。行末不ぞろいのテキストは、`bodyText.hyphenation.ragged`で求めないかぎりハイフネーションされないので、この書式が求めるとおり、脚本の中で分割される語はありません。

### 3 · 括弧書きとトランジションを段落スタイルにする

<Excerpt region="styles" />

台詞の中の`:::paragraphs{style="paren"}`コンテナーは、1行目を台詞の端からさらに0.6インチ、3.1インチの位置まで字下げします（[段落スタイル](/ja/docs/configuration#段落スタイル)）。括弧書きは1行に収めます。このスタイルが字下げするのは1行目だけだからです。台詞のスタイルの`body.paragraphSpacing: false`は、ト書きの段落の空行を囲みの中に持ち込まないので、`(then)`は前の行のすぐ下に来ます。`CUT TO:`と`FADE OUT.`は`transition`コンテナーに入れ、その`textAlign: 'right'`でト書きの行の終わりにそろえます。コンテナーは最後の段落のあとで流れをベースライングリッドに戻します。この脚本はグリッドを外れないので、`CUT TO:`のあとの見出しは2行の空行を保ちます。

### 4 · シーン番号を両側の余白に置く

<Excerpt region="slugline" />

`numberingTemplate: '{2}'`はレベル2の見出しを数え、`{number}`はその数をデザインの中に印字します（[レベルごとの上書き](/ja/docs/configuration#レベルごとの上書き)）。高度なデザインを持つ見出しは、段の中の自分の位置を保ったまま、テキストの代わりに要素を描きます（[幅と詳細デザイン](/ja/docs/configuration#幅と詳細デザイン)）。そのため2つの番号を、太字の見出しの横の余白に置けます。番号はどちらも見出し自身のボックスに固定し、そこから外へ押し出します。左は0.6インチ、右はテキストの終わりから4分の1インチ先です。どちらも幅半インチのボックスにテキストを左そろえで入れるので、シーン9を過ぎた脚本でも、1桁と2桁の番号が同じ位置から始まります。見出し自身のテキストは描かれませんが、測られはします。そこでこのレベルの文字サイズを12ptにしています。既定の15ptでは、シーン1の見出しが折り返して2行目を確保してしまいます。段末そろえはオフです。オンにすると、短いページを埋めるためにシーン見出しの上へ空行が加わります。脚本のページは、最後の台詞や段落が終わるところで終わるものです。

### 5 · 脚本のページだけに穴を開け、番号を付ける

<Excerpt region="furniture" />

脚本の題のスタイルは独自の`header`を持ち、題から最後までのそのセクションのページで、文書のヘッダーを置き換えます（[見出しスタイル](/ja/docs/configuration#見出しスタイル)）。文書自身のヘッダーは空なので、穴とページ番号は脚本にだけ刷られます。ページ番号は紙の上端から半インチの位置に固定し、`pages: 'body'`で章の最初のページには刷りません（[テキスト要素](/ja/docs/configuration#テキスト要素)）。題は改ページするレベル1の見出しなので、1ページ目は章の最初のページになり、書式が求めるとおり番号が付きません。表紙もレベル1の見出しです。表紙の裏と題のあいだに`:::numbering{startAt=1}`を置くと、題のページは1になり、次のページに2が刷られます。題のスタイルは12ptの行を指定します。レベル1自身の18ptでは、見出しは21.6ptの行に乗り、FADE IN:を9.6pt押し下げてしまいます。

## アレンジ

### 台詞をグリッドに戻す

こうすると各台詞は下マージンを保ち、次の台詞が上マージンを加えます。台詞のあいだに空行が2行（シーン見出しの前では3行）入り、脚本は4ページ目にはみ出します。

```diff
-  snapToGrid: false,
 };
```

### シーン見出しを標準のウェイトで組む

タイプライターで打った脚本では、シーン見出しは飾りのない大文字でした。太字は脚本ソフトウェアとともに広まったものです。

```diff
-  fontSize: pt(12), fontWeight: 700, lineHeight: 1, color: col('ink'), align: 'left',
+  fontSize: pt(12), fontWeight: 400, lineHeight: 1, color: col('ink'), align: 'left',
```

```diff
-      fontWeight: 700, lineHeight: 1, color: col('ink'), align: 'left', overflow: 'wrap',
+      fontWeight: 400, lineHeight: 1, color: col('ink'), align: 'left', overflow: 'wrap',
```

## よくあるつまずき

- Postextは、ページをまたいで分かれる台詞の下に`(MORE)`を刷ることも、続きの上に名前を繰り返すこともしません。台詞が丸ごと次のページへ移るよう、`keepTogether`は既定値のままにしておきます。
- 脚本ソフトウェアは名前に`(CONT'D)`を自動で付けます。ここではフェンスの`title`の一部なので、ト書きの行のあとで人物の台詞が再開する箇所には自分で入力します。
- `titleStyle.lineHeight`が台詞をグリッドに保てるのは、本文の行送りと同じ値のときだけです。名前を本文より大きく、または小さく組む場合もこの12ptにします。そうしないと、台詞のたびに後ろの行がグリッドから外れます。
