## できあがり

『A Beekeeper’s Year』は、季節ごとに1章、全4章の小さな手引き書です。養蜂家の1年は最後の蜜を採り終えたときに始まるので、本は秋の章から始まります。各章は別々のMarkdownファイルで、ページ番号も章番号も図番号も書かれていません。`buildBundle`がそれらの数をファイルから次のファイルへ引き継ぎ、表紙と目次を収めた5つ目のファイルとあわせて、11ページの1冊の本に組みます。どの章も右ページから始まり、章番号を収めたハニカムが隅に置かれます。秋の章と向かい合う偶数ページの目次は、その章扉を左右反転させた形で、表題をのど側にそろえ、各章のノンブルを並べます。コードで描いた巣枠の図が各章に1点ずつ、図1.1から図4.1として入ります。冬の章が1ページで終わり、春の章を奇数ページから始める必要があるため、6ページは白ページになります。

## 作り方

### 1 · 1章に1ファイル

<Excerpt region="chapters" />

季節ごとに独立した文書なので、ほかの章を開かずに1章だけを書き直せます。最初の文書にはフロントマター、表紙、目次が入ります。Postext 1.4.1では、2つ目以降の文書はそのメタデータを何も引き継がず、PDFは表題と著者を最初の文書からしか読みません。

### 2 · 文書をまたいで続く規則

この手順のコードは上の[手短な答え](#手短な答え)にあります。[`buildBundle`](/ja/docs/configuration#バンドルを組んで描画する)は共通の設定ひとつで文書を順に組み、各文書にそれまでの文書から求めた`continuation`を渡します。中身は、すでに組んだ物理ページの数（これで奇偶、左右対称の余白、奇数・偶数ページの柱が続きます）、次のノンブル、章と図のカウンターです。`parity: 'odd'`を指定すると、奇数ページで終わった章のあとの章は白の偶数ページから始まり、その白ページはあとの章の文書に属します（[前で改ページ](/ja/docs/configuration#前で改ページ)）。表紙と目次は`numbered: false`の[見出しスタイル](/ja/docs/configuration#見出しスタイル)なので、秋の章は第1章のままです。どちらも章のレベルから`span: 'page'`を受け継ぐので、`:::pagebreak`を書かなくてもそれぞれ独立したページに置かれます。目次のスタイルは受け継いだ奇偶の指定を切っています。切らないと2ページが白ページになるためです。

### 3 · 本全体の目次

<Excerpt region="contents" />

`:::toc`は最初の文書にありますが、本全体の章と節を並べます。`buildBundle`は本を組み、各見出しとそれに付いたページラベルを集め、その目次の骨組みを使って、ラベルが動かなくなるまで本を組み直します。最大で3回です（[目次](/ja/docs/configuration#目次)）。各章題の下の月は見出しの属性`{months="…"}`から取り、章扉にも同じ月が印字されます。

### 4 · 章扉をひとつ、目次用に反転して

<Excerpt region="opener" />

`{chapterNumber}`は先に組んだ文書から数を引き継ぐので、春の章扉にはファイルに番号がなくても3と印字されます。番号のボックスはハニカムのセルの中心から計算し、番号とハニカムはどちらも裁ち落としの右上の角から吊り下げます。仕上がりサイズを変えても、印刷用に裁ち落としを足しても、両者はいっしょに動きます。目次のページでは、`{subtitle}`から読むキッカー（表題の上の小さな見出し）と表題をのど側に右そろえし、ハニカムは偶数ページの小口側の隅に移します。こうすると目次の表題は、向かいのページの秋の章題と同じ高さに並びます。

### 5 · すべての文書に柱を

<Excerpt region="running-heads" />

フロントマターがあるのは最初の文書だけなので、Postext 1.4.1では秋の章を含む2つ目以降のすべての文書で`{title}`は何も印字しません。そこで偶数ページの柱には本の表題をそのまま文字で入力しています。`{chapterTitle}`と`{pageNumber}`はページごとに解決されるので、どの文書でも印字されます。唯一の右側の本文ページである11ページには、ノンブルの横にSUMMERが入ります。`pages: 'body'`で、章扉と白ページには柱を付けません。

### 6 · 画面では見開き、本はひとつのPDFに

<Excerpt region="build" />

`buildBundle`はMarkdownファイル1つにつき1つ、文書の配列を返します。`showPages`は`pageIndexOffset + page.index`でページを組み合わせるので、1ページは単独の奇数ページとして立ち、2と3、4と5……が見開きで向かい合います。`renderToPdf`は同じ配列を受け取り、本のページラベルと各章・各節のしおりを付けた1つのファイルを書き出します。

## アレンジ

### 1章だけを本のノンブルで印刷する

春の章だけを校正するなら、文書をひとつだけ`renderToPdf`に渡します。ノンブルは本と同じ6〜8のままです。章扉の前の白の偶数ページはその後に始まる章に属するので、6ページの白ページもいっしょに付いてきます。

```diff
-offerPdf(() => renderToPdf(docs, { fontProvider: fontsourceProvider, resourceBytes: imageBytes }),
+offerPdf(() => renderToPdf(docs[3], { fontProvider: fontsourceProvider, resourceBytes: imageBytes }),
```

### 図番号を本全体の通し番号にする

一度もリセットしない図のカウンターを使うと、4点の巣枠の図には1.1〜4.1ではなく、文書をまたいで1〜4の番号が振られます。

```diff
-  resourceTypes: defaultResourceTypes(LANG),
+  resourceTypes: defaultResourceTypes(LANG)
+    .map((type) => ({ ...type, numberingTemplate: '{n}', resetOn: 'never' })),
```

## よくあるつまずき

- ページの先頭や、ページの先頭にある図の下では、小見出しの`marginTop`が消えます。間隔を余白でとる小見出しは、その2か所では本文の1行上に、それ以外では1行半上に立ちます。ここでは間隔を小見出しの行そのものに持たせています。`lineHeight`を1行半、余白を1行にしたので、本のどの小見出しも本文から同じ距離に立ちます。
- 初期設定では、両端そろえの行は語間を元の幅の2倍まで広げられ、行分割はハイフンよりもそちらを選びます。この初期設定のままでは英語版にハイフンがひとつもなく、語間が通常の2倍近くまで広がった行と、0.7まで詰められた行が隣り合っていました。`maxWordSpacing: 1.7`にすると、行分割は代わりにハイフネーションを選びます。変更したら、各段落の最終行を確かめてください。上限を厳しくすると最終行に1語だけが残ることがあり、段落の数語を書き換えれば直ります。
