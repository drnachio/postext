## できあがり

漫画『ポースコーヴの灯』の7ページ、灯台の嵐の夜の話です。前に写植担当のスタイルシートを付けました。漁船のエンジンが止まり、灯台守が無線で導き、マヤは猫と待ち、翌朝、船長が礼を言いに来ます。このページはPostextが描くすべての吹き出しを使います。せりふ、つながったせりふ、思考、ささやき、叫び、無線、ナレーション、心の声、編集部注、描き文字、画面外の声、位置を固定した吹き出しです。判型はアメリカのコミックブックの168 × 259 mm、ページは六言語で出ます。

## 作り方

### 1 · 台本の行で種類を指定する

コードは前の[手短な答え](#手短な答え)にあります。台本の一行は`話者{種類}: せりふ`と書き、種類は吹き出しスタイルのIDです。組み込みの九つのスタイルで、よく使う種類はそろいます。せりふは曲がったしっぽの楕円、思考は泡の付いた雲、ささやきは破線の輪郭、叫びはくさび形のしっぽのフラッシュ、無線ごしの声はトゲトゲの輪郭とジグザグのしっぽです（[吹き出しのスタイル](/ja/docs/comics#吹き出しのスタイル)）。設定に同じIDのスタイルを書くと、書いた項目だけが変わります。ここでは線の色、ナレーションの黄色、フラッシュの16個のとがりです。`caption`、`note`、`sfx`は予約された話者で、角に寄せたナレーションの箱、0.8倍の大きさの編集部注、吹き出しのない描き文字になります。

### 2 · しっぽを話者に向ける

<Excerpt region="art" />

絵にはそれぞれ、絵に対する比率でアンカーを置きます。せりふのしっぽが向かう口、思考が向かう頭、吹き出しがかぶってはいけない顔です（[話者とアンカー](/ja/docs/comics#話者とアンカー)）。船長は一度も描かれません。嵐の絵では無線機が、海の絵では彼の船がアンカーです。話者がコマの中にいないときは、`tail=end`（または`start`、`top`、`bottom`）でしっぽをその辺まで伸ばします。`at="44% 22%"`は吹き出しの中心を絵の一点に固定し、トリミングが変わってもそこに置きます。同じ話者の行が二つ続くと、一つの輪郭にまとまり、しっぽは一本です。

### 3 · 人物に専用の声を与える

手短な答えのキャスト設定で、`skipper:`の行はすべて無線のスタイルになり、台本で`{radio}`をくり返さずにすみます。それでも行ごとに変えられます。翌朝のコマでは船長が船から呼びかけるので`skipper{speech tail=bottom}:`と書き、ふつうの吹き出しのしっぽをコマの下から外へ出します。

### 4 · 版ごとの書体で写植する

<Excerpt region="editions" />

同じページが六言語で出ます。`content.<lang>.md`に書くのは言葉だけです。日本語の吹き出しはZen Antiqueで縦に組み、描き文字はDela Gothic One。アラビア語はPlaypen Sans Arabicで、雷鳴はLalezarです。斜体と太字は書体にあるときだけ使われます。心の声は英語では斜体、日本語では正体です（[写植](/ja/docs/comics#写植)）。

## アレンジ

### 弱った声に波線の吹き出しを使う

ほかのIDを書けば新しいスタイルになり、せりふの吹き出しをもとにします。

```diff
 const balloonStyles = [
+  { id: 'weak', shape: 'wavy', stroke: col('ink'), fontScale: 0.9 }, // maya{weak}: …
   { id: 'speech', stroke: col('ink') },
```

### 二つの吹き出しを細い首でつなぐ

```diff
-  lettering: { fontFamily: LETTERING, fontSize: pt(7.5), color: col('ink'), inset: mm(1) },
+  lettering: { fontFamily: LETTERING, fontSize: pt(7.5), color: col('ink'), inset: mm(1),
+    joinSameSpeaker: 'connector' },
```

## よくあるつまずき

- 固定する位置は絵の上の点で、どうトリミングしても変わりません。コマからはみ出すほど端に固定した描き文字（`at="16% 28%"`のドドーン）はコマの中へ押し戻されるので、書いた点から少しずれることがあります。
- コマの外の声は、しっぽが向く辺のそばに置かれます。船長のお礼は`tail=bottom`なので、翌朝のコマの最初のせりふなのに下に来ます。先に読ませたいときは、しっぽを上の辺に向けてください。
