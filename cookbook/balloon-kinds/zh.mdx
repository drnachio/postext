## 成品一览

《珀斯科夫灯塔》第7页，一部讲灯塔暴风雨之夜的漫画，前面附上嵌字师的样式表。一艘渔船发动机熄火，守塔人用无线电指引它，玛雅抱着猫等着，第二天早上船长来道谢。这一页用上了 Postext 能画的所有对话框：对白、相连的对白、心想、耳语、大喊、无线电、叙述旁白框、内心独白、编者注、拟声词、画外音和固定位置的对话框。开本是美式漫画书的 168 × 259 mm，这一页有六种语言的版本。

## 做法

### 1 · 在脚本行里写明类型

代码就是上面的[简短回答](#简短回答)。脚本的一行写成 `说话人{类型}: 台词`，类型就是对话框样式的标识。九种内置样式涵盖常见的类型：对白是椭圆加弯尾巴，心想是云朵加小泡泡，耳语是虚线轮廓，大喊是带楔形尾巴的爆炸框，经过无线电的声音是锯齿轮廓加锯齿尾巴（[对话框样式](/zh/docs/comics#对话框样式)）。配置里同一标识的样式只改它写到的部分：这里改的是描边颜色、旁白框的黄色和爆炸框的 16 个尖角。`caption`、`note` 和 `sfx` 是保留的说话人：贴在角上的旁白框、0.8 倍字号的编者注，以及没有对话框的大字。

### 2 · 让每条尾巴指向说话人

<Excerpt region="art" />

每幅画面都按比例标出锚点：对白尾巴指向的嘴、心想指向的头，以及任何对话框都不能盖住的脸（[说话人与锚点](/zh/docs/comics#说话人与锚点)）。船长从没出现在画面里：在暴风雨那幅里，他的锚点是电台；在海上那幅里，是他的船。说话人不在这一格里时，`tail=end`（或 `start`、`top`、`bottom`）让尾巴伸到那一边；`at="44% 22%"` 把对话框的中心固定在画面的一个点上，不管怎么裁切都不变。同一个人连续两行会合成一个轮廓，只有一条尾巴。

### 3 · 给角色专属的声音

简短回答里的角色表让每一行 `skipper:` 都用无线电样式，脚本就不用一再写 `{radio}`。某一行也可以另作规定：早上那一格里，船长在船上喊话，写成 `skipper{speech tail=bottom}:`，是普通对话框，尾巴从格子底边伸出去。

### 4 · 每个版本用自己的字体嵌字

<Excerpt region="editions" />

同一页有六种语言：`content.<lang>.md` 只放台词。日文对话框用 Zen Antique 竖排，拟声词用 Dela Gothic One；阿拉伯文用 Playpen Sans Arabic，雷声用 Lalezar。中文版用站酷快乐体和站酷庆科黄油体。斜体和粗体只在字体有的时候才用：内心独白在英文里是斜体，在中文和日文里是正体（[嵌字](/zh/docs/comics#嵌字)）。

## 变化

### 用波浪形对话框表示虚弱的声音

任何其他标识都会成为新样式，以对白样式为基础。

```diff
 const balloonStyles = [
+  { id: 'weak', shape: 'wavy', stroke: col('ink'), fontScale: 0.9 }, // maya{weak}: …
   { id: 'speech', stroke: col('ink') },
```

### 用细颈连接两句

```diff
-  lettering: { fontFamily: LETTERING, fontSize: pt(7.5), color: col('ink'), inset: mm(1) },
+  lettering: { fontFamily: LETTERING, fontSize: pt(7.5), color: col('ink'), inset: mm(1),
+    joinSameSpeaker: 'connector' },
```

## 常见问题

- 固定位置是画面上的一个点，不管怎么裁切都不变。固定得太靠边、会跑出格子的拟声词（`at="16% 28%"` 的“轰隆隆”）会被推回格子里，所以可能和写下的位置稍有偏差。
- 画外的声音排在它尾巴所指的那条边旁边：船长的道谢写了 `tail=bottom`，所以排在早晨那一格的底部，尽管它是这一格的第一句。如果这样的一句必须先读，就让尾巴指向上边。
