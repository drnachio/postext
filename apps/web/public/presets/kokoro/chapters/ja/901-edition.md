# 本書について {style="back" id="edition-note"}

本文は青空文庫所収「こころ」（底本：集英社文庫、一九九一年）に、序は同「『心』自序」（底本：『漱石全集』第十六巻、岩波書店、一九九五年）による。

青空文庫の入力者が「漱石全集」を参照して正した次の箇所は、その訂正に従った。「私に」（底本「私は」）、「出せなかった」（底本「出せなかったの」）、「後始末は」（底本「後始未は」）。

青空文庫で外字注記とされている挘（てへん＋劣）、燄（陷のつくり＋炎）、愷（りっしんべん＋豈）、睜（目＋爭）は、それぞれの文字で組んだ。

振り仮名（四五六七箇所）は底本の通りとし、序の振り仮名は『漱石全集』編集部が現代仮名遣いで補ったものである。

下「先生と遺書」は手紙の全文であり、各段落を鉤括弧で起こし、閉じ括弧は最後の段落の末尾にのみ置く。底本の通りである。
